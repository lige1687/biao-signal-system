# 前端范围与阅读原则

- **强制说人话，严禁一切令人迷惑的金融黑话（2026-11-23 用户硬要求）。** 按钮名、卡片徽章、底部一句话、弹窗说明、图表图例和记分卡里，**严禁出现**「信贷免疫、走阔、传染、双低出清、存量出清、存量偏重、高赔率、赔率垫、钝化、弱势底座、多头底座、牛市底座、期限倒挂、Contango、Vol Crush、Washout、W3范式、右偏脉冲、右偏厚尾、单因子、因果计算、近正态对称」等黑话或洋词。一律改用普通股民 3 秒能懂的大白话（如「股市恐慌但债市没事」「企业借钱变贵」「长短线都跌透」「股票偏便宜」「过半股票在年线下」「按每次刚出现那天收盘价往后算」）；**如果翻不成大白话，宁可删掉不说**。每次修改前端展示文案后，必须运行 `node --test src/components/plainLanguageGuard.test.mjs` 验证零违规。
- **只做桌面端。** 用户于 2026-11-02 再次明确：不做手机适配，也不主动进行手机、移动端或窄屏设备验证；仅在用户明确提出新的移动端需求时开展。常规页面工作不能自行把手机验收加入完成条件。
- **有用才展示，适用于所有可见层。** 页面、卡片、图表、因子、弹窗、展开详情和 AI 解读只提供帮助用户理解、判断或操作的信息。路径、哈希、内部编号、实现术语、修复流水和开发交接不在界面显示；不能挪进详情了事。技术证据留在数据与开发记录。
- 每个指标优先回答“现在是多少、比何时变了多少、什么水平、该怎么看”。单位、日期、可信来源和影响判断的缺项保留；比较基准、费用、不利结果与未验证事项不能隐藏。原始错误转成具体用户影响和可用操作。
- 用正向用途解释：“可以看作什么、提供什么信息、接下来观察什么”。组合解读写清事实相加后的含义；缺项写明后续能补充哪种判断，实质负结果保留具体比较。避免以反复否定式免责声明代替读法。
- 图例与实际曲线颜色一致；实线读数、虚线参考、灰色零线清晰区分，关键数值突出，正文用中性色。高低参照须说明含义与依据，未经验证不称买卖阈值。
- 交付前逐句核对用户用途；删去不影响理解或判断的文字，不为完整感堆字段。普通读图细节可按需展开，开发信息不进入任何展示层。
- 宽度缩略图须直接呈现所用周期的高低参考区间和具体阈值，让人能同时看出位置与升降。历史分位只能称观察参考，不能把未经验证的区间宣称为可靠买卖点或已确认顶底。
- 本文件补充根目录 AGENTS.md；不改变研究、数据、授权或策略判定边界。
