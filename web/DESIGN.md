# 看盘首页视觉样板 · 2026-09-07

目的：让价格图、道路状态和既有触发条件更容易阅读。对应
`docs/trading-spec-v1.md` §2、§9、§13 的展示层，不产生或更改任何技术判定。
规则账本、MACD 唯一口径和板块方案保持原有含义。

用户已确认方向：先看首页真实效果；黑、灰、绿必须明显区分，灰色不能像禁用态。

- 底色 #f3f6fa、内容白色 #ffffff、正文 #202b3b、辅助文字 #536175、操作蓝 #2458c6。
- 中文采用苹方；价格和 BIAO 标识采用 Avenir Next，数字等宽对齐。
- 日常看盘和执行入口常驻；资讯与认知、策略研究分组展开，所有旧链接保留。
- 两层页头：页面和数据时间在上；标的、价格、道路状态、操作在下。
- 自选为连续列表；道路状态有固定图例和文字，黑色深底、灰色实体灰底、绿色浅绿底。
- 图表颜色及行情红涨绿跌不改；状态语义直接展示后端值。
- 修复 1400px 以下拖动分隔栏缺失列造成的图表换行；测试侧栏和解释栏开关。

实现仅限 web/。样板样式集中于 workspace-design.css，仅导航全局应用，其余限定首页。
验证：前端构建、桌面与窄屏实看、导航菜单键盘和跳转、三色切换、图表控件和分析抽屉。
