# 两篇X文章复查：把文稿接到视频制作

## 一句话结论（大白话）

最值得接入的是“先把内容写清楚，再把每句话变成画面”的文件交接流程。用户给主题就能开始，不需要先写齐文稿和分镜；AI负责补齐、核实和整理。现有制作工具可以继续用。这次已补准备清单、逐镜头模板和缺件检查；配音、自动对齐和自动选镜仍没有接成一键工具链。

## 哪些用得上，怎么接

| 来源中的方法 | 项目决定与当前状态 |
|---|---|
| 第一篇：把主题整理成明确的制作说明，逐镜预览 | 已有先图、再短片、最后全片；本次补统一材料索引，沿用用户已确认风格，不再每次重选三个方向 |
| 第一篇：共用时间、逐帧确定画面、长片先低成本核结构 | 已有Remotion及时间表，继续复用；不把作者自评分数当验收证据 |
| 第二篇：内容写作独立于镜头制作 | 本次补“资料→文稿→口语编辑→分镜”交接；朗读正文、屏幕短句和制作备注分开 |
| 第二篇：用实际声音安排镜头 | 写入有旁白分支：试听→录音→实测与文字对齐→细化分镜；尚未接自动配音/对齐工具 |
| 第二篇：情境表达与知识图形分别设计 | 分镜模板要求明确每镜头解释什么、主体如何变化，避免全部做成文字卡片 |
| 第二篇：复用角色设定和镜头样式 | 角色重复出现时才建外形参考；先用已做组件，需要时再查外部模板，不强加主持人 |

不采用：强行消除声音停顿；只改识别文字而不修说错的音频；用作者的一分钟试片覆盖用户10—15秒要求；未经检查安装依赖或生成收费素材；把整库媒体许可等同代码许可。

## 开始前需要什么

你最少给主题。受众、希望讲明白什么、参考片、长度/横竖屏和声音偏好能给更好，之前已说过的直接沿用。其余准备由AI完成：

1. **定位说明**：给谁看、讲清什么、什么不讲、沿用哪一版风格。
2. **资料与正文**：史实对应来源，写能直接说出口的正文；无旁白则准备屏幕稿。人名、年代和观点关系先核清。
3. **逐镜头表和素材清单**：一句话用人物、档案还是图形来解释；主体从什么状态变成什么，怎么接下一镜，素材从哪里来。
4. **风格图**：先看画面是否合适，再制作动态样片。已有批准不重复问。
5. **声音与时间**：无旁白按阅读和动作安排；要旁白则先取得可用录音，按实际语速和停顿排字幕、动作、音乐与音效。
6. **10—15秒→全片→归档**：短片认可后扩展，导出、播放和声音检查通过后附上定位、文稿、来源与文件清单，媒体写已核外盘。

不要求六份独立长文：短视频可合并成一份制作文档，索引只需准确指向对应材料。正文修改会影响声音、字幕和分镜；只改配乐通常无需重写文稿。

## 工具取舍

保留已用的humanizer-zh、图像生成、Remotion和FFmpeg。新增的本地检查器检查文件准备、声音时间结构及音文指纹，不会自动调用所有工具。
