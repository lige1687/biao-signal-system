# 从代码动画到有叙事的视频：两条 xilo 帖子的启发与我们的制作流程

整理日期：2026-10-08。适用范围：知识讲解、概念解释和历史编年短片。

## 一句话结论（大白话）

我们已经能做出清晰、可播放、风格统一的视频。下一步最值得加强的是镜头之间的联系、素材的表达能力和声音节奏；继续沿用“先看图、再看十几秒、最后做成片”的确认流程。工具可以帮助实现设计，但工具名称本身不保证观感。

证据说明：两条 X 原帖直接读取失败，浏览器连接超时。本次读到了注明原帖链接的转载文字，以及第一篇对应的 GitHub 仓库说明；没有完整观看原帖演示，也没有运行作者的开源工具。因此，下文将来源摘要、我们自己的制作记录与新的设计提案分别说明。本文不是作者原文的复制，也不把作者自述的商业成绩当作方法效果证明。

## 2. 我们现在做到了什么，还缺什么

以下判断来自本次实际制作记录和已检查的源文件，不是对原帖效果的复述。

| 项目 | 当前事实 | 仍可改进的地方 |
|---|---|---|
| 视觉风格 | 三张正式图已获认可：深色背景、暖金、宋体、档案照片和清晰图形 | 风格统一不等于每个镜头都有独特表达 |
| 动态样片 | 15 秒样片已获认可，包含报价机开场、价格线展开和三层运动 | 这个局部认可不能自动代表完整片所有段落都已认可 |
| 完整片 | 60秒、1080p，六个历史节点；实际完整播放通过 | 后半段多次使用左侧标题、右侧解释，可能仍有版式重复感；这是设计判断，尚无观众实验 |
| 转场 | 开场有推移，后续各段主要独立出现 | 可增加上一镜的物件在下一镜继续承担作用 |
| 音乐与音效 | 使用署名许可音乐和原创合成音效；动作时间已明确 | 目前是按动作放音效，未建立实测音乐节拍表，不能声称所有镜头都踩中重拍 |
| 声音 | 最终音轨已测量和调整，旁白暂不接入 | 响度正常仅说明声音强弱受控，不证明配乐风格、细节或情绪已到位 |
| 验收 | 看导出帧、完整解码、浏览器播放、检查文字与署名 | 仍需主观听看；技术检查不能替代用户对质感的判断 |

## 3. 针对趋势交易编年史的原创改进方案

以下是我们自己的下一版设计提案，尚未制作或获得观感确认。

**让“价格记录”成为贯穿全片的物件。** 报价机吐出纸带，纸带上的价格点展开成道氏分层图；其中一个关键位置被圈出，进入利弗莫尔的等待与纪律；边界线继续拉长，组成唐奇安的区间规则；规则再变成重复运行的流程；最后形成训练清单和研究材料。画面建立连续性，同时明确这是表现手法，并非历史人物的直接师承。

**把每一站新增的认识做成可看见的变化。** 唐奇安这一站，不只显示“写成规则”，而是先给出一段未突破的轨迹，再让价格跨过预先画好的边界。观众先看见条件成立，文字再命名它。示意图始终标明非真实行情，不加入收益承诺。

**对镜头尺寸作出取舍。** 人物页让照片承担气氛，原理页让图形占主要空间，关键规则可短暂铺满画面。年份和来源仍可读，但不与主体争抢位置。已经认可的字体和配色继续保留。

**声音设计先判断用途。** 纸带移动、关键条件成立、章节转换分别对应不同声音，重要结论可以少一点声音。下一次若要追求音乐节奏，应先标出可听见的重音，再决定哪些视觉动作适合跟随；知识读不完时优先保留阅读时间。

## 4. 固定制作流程

| 阶段 | 产物 | 前进条件 |
|---|---|---|
| 需求探讨 | 主题、观众、时长、比例、声音、内容限制 | 已明确的事项直接沿用，缺关键条件再问 |
| 参考样例拆解 | 实际观察位置、视觉特征、可借鉴动作、来源限制 | 不把标题和静帧当成完整观看 |
| 静态风格图 | 开场、人物或场景、解释图 | 用户认可具体版本 |
| 10—15秒动态小样 | 至少一个完整解释动作、一次转场、配乐音效 | 用户认可动作、阅读节奏和声音 |
| 完整成片 | 沿用认可方案、补齐内容、保存来源与可编辑材料 | 文件与播放检查完成，最终观感单独确认 |

确认后的制作说明要保存：版本、批准原话、固定素材、字体配色、动作规则、声音选择和下一阶段。不因看到新教程就推翻已认可方案，也不每次从头重复讨论。

## 5. 工具怎么分工

以下“已用”只指我们的实际工作，不代表跨工具排名。

| 工作 | 当前采用 | 状态与使用边界 |
|---|---|---|
| 整理内容、分镜和修改 | 当前编程助手 | 已用；负责事实、表达和执行，不能靠一句“高级感”代替具体镜头设计 |
| 情境素材 | 内置图像生成；合法档案照片 | 已用；准确文字独立排版，历史情境图不冒充史料 |
| 图形、文字与时间编排 | Remotion + React/SVG | 已用并导出成功，继续复用 |
| 混音、音量与文件检查 | FFmpeg 及现有检查工具 | 已用；保留初版与测量结果，不把音量达标当审美达标 |
| 多维空间或特殊材质 | 按镜头另行评估 | 当前没有证明需要新增三维库；先用一个局部样片验证价值 |
| 外部视频模型 | 仅在确实需要写实动作时评估 | 本轮未接入，费用、授权和素材许可需单独核对 |
| 旁白 | 当前关闭 | 后续明确恢复后再测自然度，不自动开通语音服务 |

## 6. 如果以后恢复旁白

可以把转载中的连续合成思路当成候选方案，但不能承诺一次合成就自然。我们的试听应使用同一段约20秒稿件，比较重音、停顿、句尾和专名读法。避免只比较音量大小。

录音完成后再根据真实声音确定字幕和动作时间，不用文字字数猜精确时间。保留自然停顿，不为让时间表“无空隙”而压缩呼吸。工具给出的毫秒数只是时间单位，仍要抽听核对。未经授权，不克隆第三方声音；当前一期继续无旁白。

## 7. 可复用的制作提示词

下面是结合本项目要求重新编写的提示词，不是作者原始提示词。

> 请沿用已经确认的主题、风格、素材和限制，先说明当前处于静态图、小样还是完整片阶段。
>
> 每个镜头只承担一个主要认识。请写出观众首先看见什么、随后发生什么、最后应理解什么，并标注内容来源。镜头之间优先用一个已经存在的物件承接，不能仅靠相同配色制造联系。
>
> 先输出静态画面让我确认；确认后制作10—15秒动态小样，包含完整解释动作、转场、音乐和音效。小样通过后才做全片。已有确认不重复索取。
>
> 字体、配色和素材清晰度沿用批准版本。准确文字和日期独立排版。主体运动时分别检查标签的位置和可读性。人物史料、生成情境和概念图要区分。
>
> 给声音事件标注用途和时间。若声称跟随音乐节拍，请提供实际节拍依据；读字与解释优先于机械卡点。无旁白时不自动接入语音服务。
>
> 最后交付实际视频、可编辑源、来源与许可、实际播放结果及待主观评价项。所有公开画面保持匿名，不出现自有系统品牌。不要把账号共享用量变化说成这条视频的精确成本。

## 8. 哪些说法先不当成结论

- 选择另一模型或框架就一定更好看：没有做同稿、同素材、同时间投入的对照。
- 特定提示词标记格式天然更有效：当前没有本项目对照证据，先把要求写清楚。
- 合成音乐必然比许可音乐高级：本项目没有这个证据，应由实际听感决定。
- 多加模糊、粒子和光晕就能提升质感：可能妨碍读字，必须看具体镜头。
- 作者自述的播放量或商单能预测我们的表现：题材、受众和账号条件不同，不能推算。

## 9. 本文的使用方式

本次完成方法整理，不重做已交付视频，不安装外部Skill，不开通配音或付费服务。后续需要升级观感时，从第3节选一个明确的镜头改进，仍然先给局部样片。

公开文档中不放本机磁盘路径、账号凭据或内部任务信息。可发布的成片链接需要独立可访问地址；本机预览地址不能替代云端视频。
