# 四分钟版史料与表达边界

## 一句话结论（大白话）

这一版把一分钟的人物清单扩成八章：先解释每个阶段要解决的问题，再展示其代表性贡献。它是一条有选择的思想线索，不是唯一源头、直接师承图，也没有用传奇故事证明收益。

这是视频制作中的来源复核，沿用code-explainer-video的正文、时间表和素材记录；不新设收益研究、不另造研究控制器。范围为新增历史解释是否有来源，制作验收另见validation.json。复用V11来源并于2026-10-09定向核对；已有源头争议用时代范围，不添加有争议的具体创立年。
