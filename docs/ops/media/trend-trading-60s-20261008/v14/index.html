一百多年的思想演变 · 序章

从观察价格，到形成方法

有人识别大方向，有人强调纪律， 后来的人把它写成规则，再交给数据检验。

这是一条代表性线索，不是人物直接师承图。

1900 前后 · 道氏思想

价格每天变，大方向未必每天变

道氏思想把市场运动区分为 主要趋势、次级回摆和日常小波动。

先回答：我们正在观察哪一个尺度？

上涨，也会有回落

短期价格逆着大方向走， 并不自动意味着主要趋势已经结束。

图中细线是波动，粗线强调主要方向。

还要看不同指数是否相互确认

道氏传统不只盯住一条价格线， 也重视不同平均指数之间的确认。

这是道氏理论的历史口径，不是所有趋势方法的统一规则。

理论不是一次写完的

道的报刊文章提供起点， Hamilton、Rhea 等人继续整理和阐释。

从观察市场，逐渐形成辨认趋势的语言。

20 世纪早期 → 1940 · 利弗莫尔

问题从“看对”走向“怎样做”

利弗莫尔的经验把注意力放在 时机、耐心，以及价格是否支持判断。

以下是交易思想的概括，不是人物原话。

等待条件出现

市场没有给出足够证据时， 等待本身也是交易过程的一部分。

先有可观察的条件，再考虑行动。

持有与退出，同样重要

方向延续时如何拿住， 判断失效时如何认错，都需要纪律。

只找到入场位置，仍然不是完整方法。

1940：经验写进著作

《How to Trade in Stocks》 把他的价格观察与交易经验留下文字。

历史人物的声望，不等于方法适合所有人。

20 世纪中期 · 唐奇安

从“好像要涨”到“什么条件成立”

唐奇安所代表的规则化方向， 把趋势跟随变成可以重复执行的条件。

同一组资料，应尽量得到一致的判断。

用过去的高低点定义范围

先观察一段时间里的价格范围， 再看价格是否突破边界。

图形只解释突破思想，不使用真实行情。

突破只是一个开始

还要说明判断错了怎么办， 什么时候退出，以及承担多少风险。

完整方法不能只有“买入”两个字。

规则化，让方法可以被检查

条件写清楚之后，别人可以复核， 也能用历史资料检查它的得失。

能写成规则，不代表规则已经有效。

1970 前后 · 计算机执行

塞柯塔：早期计算机趋势交易代表

趋势方法开始进入程序， 把价格输入转成明确的规则判断。

这里只称早期代表，不声称“世界第一个”。

程序解决的是一致执行

面对相同条件，执行同样流程， 减少因为兴奋或恐惧临时改规则。

价格 → 规则 → 执行 → 下一次仍按规则。

自动化，也保留方法本身的风险

程序不会让坏规则自动变好， 也不会消除亏损与回撤。

回撤，就是资金从曾经的高点往下跌。

1980 年代 · 1983 起 · 海龟训练

丹尼斯与埃克哈特的训练实验

他们把一套明确方法交给学员， 让不同的人按共同的规则交易。

问题从个人天赋，转向方法能否被学习和执行。

训练的是整套交易流程

入场、仓位、止损、退出， 以及交易哪些市场，都有相应安排。

仓位，就是一笔交易投入多大规模。

风险控制是方法的一部分

不同市场的波动并不一样， 交易规模和组合限制需要一起考虑。

公开原规则也包含加仓与相关市场的限制。

会背规则，不等于能坚持执行

连续亏损和利润回吐时， 能否继续按方法做，是另一道考验。

训练故事不意味着每个学员、每个使用者都能盈利。

2012 → 2017 · 现代研究

2012：时间序列动量

研究者考察58种期货及远期合约， 覆盖股指、货币、商品和国债。

问题：同一市场过去的方向，能否提供后续信息？

和“挑出比别人强的”有所区别

这里主要看一个市场自身的过去， 不只是把不同市场按强弱排队。

这是时间序列动量与相对强弱动量的重要区别。

2017：把历史拉得更长

后续研究把资料延伸到1880年， 考察更多时代里的趋势现象。

延伸历史样本，是为了检验观点的适用范围。

从故事到证据，仍然有边界

历史检验要考虑成本和执行条件， 过去发现的规律也不保证未来继续。

图表是概念示意，并非论文的真实收益曲线。

回看整条历史线索 · 今天怎样理解

共同主题：尊重已经发生的价格变化

识别方向、明确条件、控制损失， 再让方法接受一致执行和历史检验。

具体方法仍可能使用不同周期、规则和市场。

从“谁最传奇”转向“方法如何运作”

理解它观察什么、何时行动、何时失效， 比记住几个传奇名字更有帮助。
