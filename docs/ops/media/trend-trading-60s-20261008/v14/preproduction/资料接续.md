# 趋势交易简史：现有资料怎么接续

这是2026-10-09对既有作品的回顾，不是当时已经使用的开工表，也不重做已交付影片。

定位用../package/00-定位与描述.md；核实内容用../source-map.md；当前无旁白片的准确屏幕稿用../package/01-文稿.md。未来配音应读../narration/旁白稿-自然口语版.md，它只是候选稿，不能沿用现有240秒当作实际录音时长。

现有视觉规则集中在../studio/src/index.tsx及opening.tsx，深蓝暖金和宋体已经认可；静图确认原话在../../v9/stage-state.json，小样确认在../../v12/stage-state.json。素材沿用../assets-manifest.json，外盘路径和清单在../archive-plan.json与../package/04-文件清单.json。

当前缺口是单独的逐镜视觉编排表：chapters.json保存文字分段，cues.json保存章节/声音时间，但每镜“观众理解什么、图形怎样变化、怎样接下镜”没有集中在一份交接文件。新做或实质改版时先补这张表，不能把现有泛化action字段当成完整分镜。已完成V14仍可播放，不为补文档重新渲染。

如果继续无旁白：复用文字/已批风格和素材，补具体分镜后再做新的修改。若用户决定配音：先口语稿定稿与短段试听，再取得实际音频和短语时间轴，重排受影响镜头；此时才把production.json的voice_mode改为narration。当前没有自动接入语音接口或对齐工具。
