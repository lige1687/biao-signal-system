# LeiSignal 当前指标清单

整理日期：2026-11-08。清单按现有页面、接口、指标目录和已完成研究整理。**页面能显示、系统能计算、数据有历史、策略已验证，是四种不同状态。** 本文只把已实现功能列为“已做好”，并把数据和验证范围放在同一条里。

## 1. 看盘首页：指数、市场和自选标的

| 指标组 | 目前已做 | 读什么、适用范围 |
|---|---|---|
| 市场宽度 | A股、标普500的20/50/200日均线宽度；变化、历史位置及部分背离/历史图 | 各自市场有多少股票站在对应均线上方。A股与美股分开看，数据日期及覆盖范围随卡片显示。宽度极端是历史观察区，不是买卖触发器。 |
| 沪深300估值 | PE_TTM历史位置；盈利收益率减中国10年国债的股债利差（界面简称ERP）；三年参考上下轨 | 只对应沪深300。利差目前是**周频、3个日历年滚动窗口**；轨道用于观察相对自身历史的位置，不能推广到行业或个股。 |
| 标普500估值 | 标普500股债利差及美国CAPE历史位置 | 都是美国宽基估值背景。CAPE使用较长历史盈利；股债利差盈利端历史频率与国债端不同，均不等同确定的预期收益。 |
| 焦点股动量 | 固定300股观察池的过去20日平均表现、零线、历史位置/大图 | 反映活跃股票的价格表现，不是固定成分指数；每天入选的活跃股可能变化。已续接的研究样本截至2026-10-23，最新日期需看卡片。0线是涨跌分界，尚非已验证买卖线。 |
| 实现波动 | HV20/HV60等历史波动观察；个股详情另有ATR14 | 回看过去价格波动大小，不判断涨跌方向。各模块频率和年化口径不同，不要把HV、ATR、VIX混为一个数。 |

首页还提供按设置展示的补充观察卡：A股融资余额/融资买入额、美国VIX、高收益债OAS、沪深A股成交额集中度等。常用核心信息包括市场宽度与沪深300股债利差；卡片可增减，不能假设每个人首页配置一致。

## 2. 基本面参考与市场环境

| 指标组 | 已实现的指标 | 覆盖与注意事项 |
|---|---|---|
| 利率 | 中国、美国国债收益率（包括10年期及多期限历史）；中美10年利差、期限利差 | 作为利率和估值背景；差值要核对两边日期是否一致。 |
| 估值 | 沪深300 PE_TTM/历史分位；美国CAPE/历史分位；中美股债利差及历史图 | 标定窗口和资料日期会影响分位。沪深300已研究的窗口为3个日历年周频；美股盈利收益率历史频率较低。 |
| 波动与信用 | VIX、VXN、高收益债OAS、美国10年实际利率 | VIX对应标普500期权，VXN对应纳指100期权。波动没有涨跌方向；OAS是信用补偿，不是违约概率。 |
| 融资与交易活跃 | A股融资余额、融资买入额；A股股票成交额快照；融资占流通市值比的背景历史 | 融资买入额不是净流入；融资余额可能含融资标的基金。股票成交额目前是截至2026-09-29固定样本，不是今日自动更新值。 |
| 中国经济 | 制造业PMI、CPI、PPI及部分商品价格比值 | PMI 50是扩张/收缩的调查分界；月度宏观序列的发布日期与观测月份要分开读。 |
| 美国经济 | 初请/续请失业金、非农就业、WEI、新屋销售、房价、汽车销量、CPI、PPI、耐用品订单等 | 由FRED等来源组成，频率有周、月之分；部分系列日期或发布时间有缺口，显示值应以页面资料日期为准。 |
| 经济与股指叠图 | 指数价格与利率、两融、ERP、宽度等按时间叠加 | 用于看同期变化；叠图相关不说明因果，也不等于交易组合回测。 |

## 3. 市场参与、情绪与可选观察库

市场参与页把A股与美股分开：A股显示融资余额、融资买入、成交活跃度；美股可显示VIX、VXN、AAII看涨减看跌、NAAIM主动管理人自报敞口。调查读数只代表受访者，历史首次可得时间未逐期确认时，不用作历史交易信号。

观察库按参与结构、盈利支持、估值、信用与金融压力、融资与情绪、经济周期分类。截至当前源码目录有42个条目，其中21项标记为可读/可选。可读条目包括焦点股动量、成交集中度、下跌价格冲击、小盘换手快照、VIX/VXN、OAS、OFR金融压力、融资、AAII/NAAIM、Baker–Wurgler、沪深300 PE/股债利差、标普500股债利差/CAPE、PMI和WEI等。

部分候选也有定义和卡片占位，但资料尚不齐：例如行业上涨扩散、涨跌离散、新高新低、等权与市值权差、盈利预期上修广度、利润率/资本回报广度、盈利集中度、其他指数估值、ANFCI等。它们是**待补数据的候选项**，不算已接通的连续指标。

已读到的主要特殊限制：A股成交额集中度是不完整月度样本；焦点股动量研究历史止于已登记日期；小盘换手只有快照；Baker–Wurgler是月度慢变量且末期较早；NFCI只有有限固定快照；融资没有合格同口径长历史。卡片上带“过期、时点未核、历史不足、缺失”的状态，应按该项自己的日期判断。

## 4. 行业、板块与ETF

- **A股行业趋势工作台**：31个一级行业，并可切到二级/全部层级及自选方向。展示等权板块表现、相对强弱分位与20日变化、50日宽度、趋势阶段（上升/筑底/派发/下降）、检查依据、排行/快照和成分股。主要用于板块观察和排序，页面标注为研究代理；行业价格/分类历史的覆盖并不等于完整历史成分回测。
- **美股行业ETF比较**：11只Sector SPDR可与SPY比相对表现并观察风险偏好轮动。已核资料为2024-11-04至2026-10-30的499个交易日，所用价格不含现金分红；不能当成含分红账户收益。
- **ETF与底层指数估值**：目前有通信、半导体等ETF与跟踪指数的参考映射；尚未接齐适合回测的行业PE/PB/PS/股息率历史。不可把映射关系、个股快照或价格长期位置称作行业ERP。

## 5. 单标的技术、信号和风险状态

个股/ETF详情与今日概述可显示：OHLC价格与涨幅/振幅、相对滞后收盘价及EMA20/SMA20/EMA60乖离、ATR14、EMA20/SMA20双均线开口及变化、日线和已完成周线长趋势；量能倍数、20日均量、成交量、盘口换手率/量比；当日成交额、流通/总市值（行情源支持时）。

信号层另有LEI颜色及持续天数、机会阶段、独立风险状态、结构失效C点距离、B1参考距离、今日新事件数，以及买入的行动/等待/受阻和退出的硬/预警/提醒层级。它们属于系统既有技术结构与事件判断，不能与上文的宏观背景卡片相加成“多因子投票”。缺盘口、价格或源资料时，相关字段会显示为空/未知。

MACD（DIF/DEA/柱）、均线、ATR、BIAO结构事件等也在行情特征和图表工作台中计算/展示。MACD在系统说明中读作均线扩散强弱，不是独立的反转点。

## 6. 因子研究台

研究工作台另可查看截面动量20日/121日、波动率及分位、个股特质波动率60日、ADX14、站上EMA20/EMA120状态、因子排序/分位、部分估值与质量字段及策略回测统计。这些字段服务于筛选、比较和研究记录；其中数据池、历史成员、分红、费用或估值可得时间仍有各自缺口。研究页面明确标为研究代理，实验结论不会自动进入实盘规则。

## 一句话分层

**日常最成熟、最容易直接读的**是：价格/趋势结构、A股与美股宽度、沪深300股债利差、宏观利率/经济背景、融资/VIX/OAS等观察卡。**行业与因子页面已做出读数和排序**，但部分是研究代理或固定样本。**未做好成统一可交易指标的**是行业/个股通用ERP、拥挤度护栏、全行业连续估值历史及由估值直接推导仓位。

现有量化验证最完整的是沪深300 ERP × 均线仓位研究：2008-11-14至2026-11-06，周频ERP，4367个交易日。计分＋连续版净年化3.56%、最大回撤−29.86%，固定50%为2.74%、−25.76%；它相对纯计分趋势有历史增量，但相对固定50%回撤更深。因此当前ERP趋势用于观察和研究，未升级实盘交易规则。
