# 1.5σ 与 2σ：对象、原文和证据边界（2026-11-03）

## 结论

不能把“2σ”或“1.5σ”当跨指标通用的专业买卖线。沪深300 ERP 的 **2σ** 有同对象机构方法参照；**1.5σ** 是本项目对该轨道的本地灵敏度检验，尚无已核原文支持把它称为同一机构规则。价格 Bollinger Bands 的 20期/2σ 及窗口调整是发明人对**价格**波动带的规则；宽度百分比的 30/70 和 200日 50% 是**0–100% 参与率**参考线。三者统计对象、窗口和阈值语义不同。
