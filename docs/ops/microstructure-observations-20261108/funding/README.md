# 沪深A股融资买入参与度观察

## 读数与口径

资料覆盖 **2025-09-18 至 2026-11-05 的271个沪深共同交易日**。最新日（2026-11-05）融资买入额为 **1,565.96亿元**，沪深A股成交额为 **21,206.44亿元**，比值 **7.3843%**；按最近20个交易日逐日比值做算术平均，MA20 为 **6.4447%**。最新日比值在严格此前250个完整日比值中的中秩位置为 **15.20%**；MA20在严格此前250个完整MA20值中的中秩位置为 **0.80%**。

读数用于描述融资买入成交额相对股票成交额的规模。它不是净流入、持仓占比或交易信号。历史位置只是相对于当前样本中此前250日的排序，不是阈值或风险概率。

### 分子与分母

- 分子：上交所融资融券明细 `RZMRE`，只汇总六位证券代码以 `6` 开头的沪市A股；深交所融资融券导出表只汇总六位证券代码以 `0` 或 `3` 开头的深市A股。金额列均标为人民币元。基金、ETF以及其他非A股代码不计入；逐日纳入行数和被排除基金/ETF行数留在 `source-ledger.json`。
- 分母：上交所官方统计产品代码 `01`（主板A股）和 `03`（科创板A股）的成交金额，单位亿元，转换成人民币元；加上深交所官方统计类别“主板A股”和“创业板A股”的成交金额，源单位人民币元。
- 比值：`100 × (沪市A股标的融资买入额 + 深市A股标的融资买入额) / (上交所主板A股与科创板A股成交额 + 深交所主板A股与创业板A股成交额)`。

观察范围是沪深A股，不含北交所。分子只包括融资标的股票，分母包括对应交易所所有A股，因此两者股票资产类别一致、证券集合不同。融资买入额是买入成交额，不包含卖出融资偿还等信息。

### 历史位置与MA20

每日分位和MA20分位分别以当日值与**严格此前250个完整有效值**做比较；当前值不进入自己的参照窗，并列采用中秩（`100 × (小于当前值数量 + 并列数/2) / 250`）。缺失观察会令包含它的窗口结果留空，不压缩日期或前填。日比值在最后21个日期有250日历史分位；MA20在最后2个日期有250个此前完整MA20值分位。MA20卡片的历史曲线逐日计算，未将最新MA20复制到整段历史。

## 官方输入与资格核对

- 上交所融资明细：`https://query.sse.com.cn/marketdata/tradedata/queryMargin.do`，逐日请求 `detailsDate`，依响应 `pageCount` 读取完整分页，并校验日期、页号、页数、总行数和证券代码唯一性。每个日期的页数从1到2不等。
- 上交所成交统计：`https://query.sse.com.cn/commonQuery.do`，`sqlId=COMMON_SSE_SJ_GPSJ_CJGK_MRGK_C`，产品代码 `01,03`，逐行日期必须匹配请求日期。
- 深交所融资明细：`https://www.szse.cn/api/report/ShowReport`，`CATALOGID=1837_xxpl`、`TABKEY=tab2`、逐日 `txtDate`。导出表没有内嵌交易日期，因此日期由请求URL和请求账本绑定；表头及单位必须匹配。
- 深交所成交统计：同一官方导出接口，`CATALOGID=1803_sczm`、`TABKEY=tab1`、逐日 `txtQueryDate`。只取“主板A股”和“创业板A股”两行；表格自身不含交易日列，日期同样由带日期参数的请求账本绑定。
- 历史日历为官方交易日历的250个旧交易日（2025-09-18—2026-09-30），拼接当前采集的21个交易日（2026-10-08—2026-11-05）。没有跨日拼接。每一日都需上交所融资明细完整分页、上交所成交、深交所融资和深交所成交四类输入；上交所融资明细可为一或两页。请求状态、URL日期/页码和原件SHA须通过校验；XLSX解压读取工作表XML，不依赖可能错误的A1维度声明。
- 两组来源账本及日历指纹见 `source-ledger.json` 和 `../funding-history/README.md`。原始响应保存在授权外盘目录，逐文件字节数和SHA记录在source ledger。历史采集账本保留一次连接重置失败及随后成功的定向重试；失败不构成缺失日，成功原件须通过相同日期及SHA核验。
