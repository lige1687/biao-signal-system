## 修复了什么

补采 5,228 只近期上市期证券的日线，以及 79 只存在历史缺口的证券。近期 22 个交易日逐日与更新主表的上市期集合核对，11/6 的 5,224 股也与当日供应商股票列表一致。10/19、10/23 的原缺口涉及摘牌生效日；按已核公告修正生命周期门禁后得到完整日期，而非把缺行填零。

10/22 的旧名录漏了当天上市的 `sz.301718`。补入其成交额 2,187,703,775.42 元后，前 5% 从 43.893399% 修正至 43.900493%，前 10% 从 58.037304% 修正至 58.056347%；其余 5,224 股金额一致。这是历史资料修订，不是市场当天又发生了一次变化。原有其余 60 个有效日读数以及全部 84 个有效月值保持一致。

六条历史行情的成交状态字段与正成交量、正成交额冲突。逐证券、日期及原件 SHA 绑定后，另一来源的同日 OHLC 完全一致，金额差不超过 1 元、按每手 100 股换算后的股数差不超过 100 股，均价也在日内高低价之间。因此六条只接受原 BaoStock 数值，保留状态冲突和第二来源证据；通用 `qualified_amount` 规则没有放宽，也没有拼入另一来源的金额。
