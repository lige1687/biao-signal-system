# 行业换手率入口归并 · 2026-11-09

本地市场速览的指标分类现只展示一张「行业换手率」。点开可选通信设备、半导体设备、半导体材料、有色金属、电力、电网设备。候选小图标明是通信设备，展开后显示所选行业的日换手率和历史分位。加入首页占一个位置，刷新会保留上次所选行业。原有逐行业及高换手占比收藏会归并到同一入口。

原快照只有半导体总行业，定向补取东方财富半导体设备和半导体材料各一份日线。两条均有 2023-01-03 至 2026-11-06 的 930 个交易日，逐日对齐原行业快照。末日分别为 3.57% 和 5.17%，相对此前 756 个交易日的历史位置分别为 90.87% 和 93.25%。换手率沿供应商板块口径。两次公开查询合计 171,373 字节。[来源账](focused-source-ledger.json)

独立重算核对两条序列原值和分位。股票包添加两条，原 65 张卡逐字典比对一致；旧 56 板块汇总的样本口径保留。重建时按原件 SHA、板块身份和交易日序列验证两条新增输入。[数据验收](packet-acceptance.json)

桌面实页核过搜索只出现一张候选、六个选项切换、历史大图和分位、首页收藏 4→5→刷新后 5→撤回至 4。测试页与用户 Chrome 分开。定向前端、Python、TypeScript、内存构建和仓库归置均通过。源码与快照仅在本地共享工作区生效。
