## 文件怎么放

| 内容 | 目前位置与处理 | 原因 |
|---|---|---|
| 正在使用的交易数据库、持仓、计划、成交记录 | 内置盘，维持原路径 | 需要稳定连接和原系统的确认、备份流程 |
| 当前源码、依赖、Python 环境、Codex 正在用的运行环境 | 内置盘；不按体积直接删除 | 含可执行文件和依赖，移走可能使服务失效 |
| 已下载的公开视频、音频、固定模型权重 | 已核的外盘；原路径保留为链接 | 占空间较多、属于普通文件；每项有指纹和恢复记录 |
| 日报新音频 | 已配置的外盘专用目录 | 每条最多 100 MiB、30 分钟；已验证内容优先复用 |
| 日报文字、来源回执、通知比较记录 | 仓库私有缓存 | 较小且需要接续；比较记录不是消息送达证据 |
| 已冻结研究原始材料及其精确路径 | 原位保留 | 报告、登记和指纹会引用；不能直接挪走或清理 |
| Codex 会话、其他任务的工作树、更新包、Time Machine 快照 | 未清理 | 需要各自恢复、使用状态和授权，不能因大就删除 |

外盘当前是 exFAT，便于 Windows/macOS 共用；本次只放普通媒体、模型权重和归档，不把活动数据库或执行环境搬过去。Apple 列明了 exFAT 的跨平台用途及 APFS 的 Mac 用途：[磁盘格式说明](https://support.apple.com/en-gb/guide/disk-utility/dsku19ed921c/22.7/mac/26)。数据库留在内置盘是本系统的运行选择，不是说 SQLite 一概不能运行于 exFAT；SQLite 对文件锁与 I/O 故障的注意事项见 [官方说明](https://www.sqlite.org/howtocorrupt.html)。本任务未格式化分区、改备份设置或删除本地快照。

## 容量与设备规则

配置唯一入口：`configs/storage-policy.v1.json`。这些阈值只管运行空间，不改变技术判定或交易规则。

- 内置盘低于 15 GiB 提醒空间偏低；低于 5 GiB 提醒严重不足。新视频音频工作要求至少 2 GiB。
- 外盘补音频至少保留 1 GiB，再加每条最多 100 MiB 的余量；余量不足则暂停新增音频。
- 只认挂载点 `/Volumes/win+mac通用` 和卷 UUID `DEBA1C85-6059-3865-B50A-A8EE1F80E4D9`，同时核真实挂载、外置设备、文件系统、可写状态和文件所在设备。换一块同名盘也不会通过。
- 音频只认本日报已批准的固定路径，解析后必须位于上述外盘。模型只认固定逻辑路径，解析后必须位于仓库所在盘或同一合格外盘。
- 策略损坏、设备或容量未知时不启动新的音频任务；健康查询保留“无法核实”。没有向父目录回退、内部备用下载或自动改路径。

预检不是硬容量配额，也不能阻止其他进程在之后把盘写满。运行中断盘或写满仍可能使当前操作失败；应如实报告，保留原缓存及失败证据，不能把失败解释为“没有新闻”。

## 后续 AI 如何直接使用

项目根 `AGENTS.md` 有“AI 使用存储资源”入口，`CLAUDE.md` 已引用该说明；系统查询技能也指向同一流程。后续会话不需要翻旧聊天。资源表 `configs/storage-resources.v1.json` 登记四项：公开视频音频、公开视频文件、语音转写模型和持仓日报博主音频。它只保存位置、用途和恢复清单，不保存持仓、凭证或媒体正文。

先用上述 `storage` 查询（已加载 MCP 时可调用同名工具），核检查时间和外盘身份，再看 `resources_status` 与每项 `available`。只有 `available=true` 才可用该项 `read_path`；返回的路径是本次核对过的绝对目录，可直接传给现有读取程序。查询不创建目录、下载材料、配置链接或修改文件；它检查设备与路径，没有重新核每个内容指纹。重要复现仍按 `recovery_manifest` 对应清单校验。

| 返回的原路径状态 | AI 的使用方式 |
|---|---|
| `linked` | 本工作目录原路径与外盘目录一致，现有程序继续用原路径，也可只读使用 `read_path` |
| `not_configured` | 同机其他工作树没有本地链接，但外盘目录可核；直接只读使用 `read_path`，没有自动建链接 |
| `conflict` | 原路径已被不同链接、坏链接或真目录占用；不提供可读路径、不替换已有内容，先说明冲突 |
| `unchecked` | 外盘身份或实际目录未核；`read_path=null`，不能据清单中的预期位置冒充可用 |

外盘容量低或容量暂时无法取得，但设备身份和文件位置可核时，已有材料仍可读取；新增音频继续由原空间预检拒绝。磁盘查询可用不代表四项资源都可用，清单损坏会保留容量结果并单独报告资源不可核。返回后外盘仍可能断开，真正读取失败须说明，不能称缓存内容不存在。

当前共享工作区的四个原路径都有链接；其他工作树拉取代码不会带上私有缓存链接。另一台电脑还需要这块资源盘并核同一 UUID，代码同步不等于数据移交。盘上的 `._*`、`.DS_Store` 是 macOS 说明文件，读取音视频时排除；不因此删除说明文件或迁移记录。资源用途登记也不授权任何新写入、换盘或删除。
