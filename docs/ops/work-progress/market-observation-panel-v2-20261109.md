## 口径与阶段

- 数据先复用 Cboe、FRED、上交所、深交所和已核本地归档。四期指选当日持仓量最大合约，取当日期现收盘，用剩余自然日做简单年化。换月与临近到期可放大年化数值。
- 滚动轨道用当日及以前最近 252／156／60 个有效观测，标准差用总体口径。样本满窗才显示轨道与历史位置。日频和周频分别用连续20个和4个有效槽位做短均值。分位用并列中秩，唯一最小与最大映射为 0% 和 100%。标普固定成员历史存在批次间断档，断档与预热留空，复用同一组502只股票。
- Baker–Wurgler 作者原始序列保留至 2025-12。实时代理按月排列，当月为截至资料日的暂估。FINRA 融资同比、AAII 净看涨和 NAAIM 仓位近60个自然日均值分别用此前最多60个月标准化，至少24个有效月，三个分量等权。FINRA 使用保守的次月底可用规则。历史调查的可用日期含估计。NAAIM 最近三周采用公开图表估读，读数约有 ±0.1 个百分点误差。代理单列，历史位置基于作者序列。
- 组合诊断在浏览器本地确定计算。短期波动和宏观信贷各按最近资料比较。A股筹码要求集中度与焦点股动量同日，期指组合要求融资与 IH、IF 同日。缺数、陈旧或无可用对齐日显示具体限制。
- 对用户指定的固定数字按观察线绘制。简明解释保留市场含义与可观察条件。PCR 数据显示认沽相对认购的量，无法从量的比例识别主动买卖方向。

## 本地运行与验证

`scripts/refresh_market_observation_history.py --stage <可写暂存目录> --as-of YYYY-MM-DD` 可在适用的本地环境用 `PYTHONPATH=src` 运行。刷新结果先写入暂存目录，归档源数据只读。股指基差建议在交易日收盘后取源。A股和美股成分历史适配器分别为 `python3 -m lei_signal.market_context.observation_panel_cn`、`python3 -m lei_signal.market_context.observation_panel_members`，用 `--output` 指定新文件。

`scripts/launchd/build_market_observation_panel.py` 读取既有基本面 API 和官方波动序列，支持 `--snapshot-dir` 离线重放和多个 `--overrides`。经验证的观察包由前端本地读取。页面的“刷新读数”重读资料包，更新行情由采集和构建入口负责。
