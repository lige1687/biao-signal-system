### 新运行先做只读预检

下面 8 MiB 是调用示例，应换成这一次冻结合同批准的完整输出预算；不是所有实验的统一预算。默认保留 512 MiB 空间是运行保护配置，独立于策略阈值。

```bash
cd /tmp
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/Users/yongbiaoli/Desktop/lei-signal-lab/src \
python3 -m lei_signal.research.storage_guard \
  --output /private/tmp/lei-my-new-run \
  --max-output-bytes 8388608 \
  -- python3 /Users/yongbiaoli/Desktop/lei-signal-lab/scripts/run_factor_lab.py \
  --workflow-contract /absolute/path/to/frozen-contract.json \
  --out /private/tmp/lei-my-new-run
```

默认只打印检查结果，不创建目录、不启动命令。输出目录必须尚不存在，避免覆盖失败材料；统一研究入口的 `--out` 必须与受保护目录完全对应，否则拒绝。默认预算必须能在保留空间之外全部容纳。

在预算、合同和路径已经确认后，在 `--` 之前显式加入 `--execute` 才会运行。监控只停止它自己创建的进程组，不碰另外两条研究对话的运行。

运行中每 0.25 秒检查剩余空间和输出目录。超配额或低空间返回 `paused_storage`，保留部分结果；子进程失败返回 `failed`。终止权限被拒绝时返回 `paused_stop_unconfirmed` 和具体 `stop_errors`，不能当作已停止。退出码 4 表示启动受阻或存储暂停，1 表示命令等其他失败，0 仅表示只读计划通过或本次命令完成并通过最后磁盘检查。

### 写入前检查、缓存复用及清理计划

- `write_chunks()`：新适配器可以将结果分块写入，每块写入前检查空间与预计占用；超限块不会写入，已有部分文件留下。不覆盖已有文件。不自动接管已有 `write_text`/第三方写入。
- `verify_cache()`：调用方提供准确的定义版本、实际适配代码指纹、输入路径及指纹、参数和时间范围；与缓存清单完全相同，输入及产物的实际 SHA-256 也相同，才返回原文件引用，复制字节数为 0。不自动判定缓存对应研究已经验收。
- `cleanup_plan()`：只产生可恢复移动的清单，不执行移动或删除。默认引用盘点“不完整”则阻止；需明确临时用途、退休状态、完整引用盘点与保护目录。原始输入、归档 raw、失败材料等应在保护目录里；引用一个目录内的文件也会阻止移动整个目录。拒绝覆盖目的路径、同名目标冲突、跨卷移动和链接路径。同盘隔离预计释放字节始终为 0。
