## §1 四轨架构原型（现役认证形态）

系统由四条互相独立、各自管各自钱的轨道组成（分账制：独立复利、永不再
平衡、无跨腿调度）。前两条是 A 股市场，后两条是美股市场。

```
┌─ A股 ──────────────────────────────┐  ┌─ 美股 ──────────────────────┐
│ ① 宽度主仓（80%资金）              │  │ ③ 防守版（保险轨）          │
│    B9：9标的等权 × B200 择时        │  │    纳指3档宽度择时，40年认证 │
│    现役引擎：三档 43.3/56.7         │  │    年化5.0%/回撤-18.6%       │
│    ⚠ 换档候选：二元+滞回（见§2-D1） │  │    禁止合并/禁止加择时(AJ/AW)│
│                                    │  │                              │
│ ② LEI 个股执行卫星（20%资金）      │  │ ④ 模块E（低频入场轨）        │
│    A门禁+B'去重 217笔，1%风险      │  │    宽度极值择时，周频        │
│    与主仓日收益相关 -0.003(正交)   │  │    年化8.4%，v1@50 认证      │
│    合体认证 6/6 PASS(2026-08-31)   │  │    与防守版双轨独立(us-merge)│
└────────────────────────────────────┘  └──────────────────────────────┘
合体实绩（2017-03→2026-07，9.3年）：年化 9.43% / 最大回撤 -28.5% /
Calmar 0.331（对比主仓单腿 0.223，正交合体贡献 +49% 性价比）
```

**架构的三个支柱原则**（全部有实证背书，改动前先查对应证据）：

1. **分账制与正交性**：两腿月收益相关 ≤0.3 才值得做合并回测（us-merge
   美股侧 0.57 相关合体判负的方法论登记）；A 股合体 −0.003 是认证前提。
2. **基本面/消息面只是叙事层**：永不参与技术判定、不做硬过滤（Round 4
   原则，AGENTS.md 红线）。
3. **择时有效边界（AW/AU/AY 三轮划定，2026-09-04）**：*跟不跟全市场宽度走*
   是连续谱——A 股宽基（跟随度最高）配用宽度择时；A 股个股/独立行业（中
   低跟随）择时仍砍回撤但引擎用三档更稳；美股全境（指数+个股 14/14 输
   定投）不配用任何宽度择时。**未来扩任何新腿，先算它对沪深300/全A宽度
   的跟随度再决定引擎。**

## §2 决策台账（按优先级；状态：🔴待拍板 / 🟡观察 / ❎已结）

### D1 🔴 宽度主仓引擎换档：三档 → 二元+滞回

- **内容**：B9 主仓的择时引擎从三档（<43.3 满/43.3~56.7 半/>56.7 空）换成
  二元+滞回（≤43.33 进 / >45.33 出，全进全出）。
- **证据链**（完整三环）：AU 样本内四线全过（Calmar 6/8、终值 8/8、回撤
  8/8、赢定投 8/8）→ AX 走样本压线保持（6/11）→ 痛苦度量（预期管理数字）。
  报告：`experiments/binary-hysteresis-vs-t3-decision-2026-09-04.md` +
  `experiments/switch-walkforward-and-pain-2026-09-04.md`。
- **AX 的关键警告**：冻结参数前向只有 5/11——**每 2 年用过去 6 年 Calmar
  重选 E/带宽的协议是 edge 的一半，必须与换档同时落地**（协议照抄
  `scripts/agent_AX/run_walkforward_switch.py` 的 select_binary_params）。
- **预期管理（换前必读）**：相对三档"水下"可持续数年——中证1000 已连续
  水下 1576 天、科创50 水下 879 天（进行中），历史最大相对落后 10~19pp。
  优势兑现方式 = "难受很多年、深熊一把赚回"。
- **总评**：两个都可辩护的决策，非对错题。不换留三档也完全合理（组合层
  差距 ~8% 终值，非数量级）。
- **若拍板换，三件配套缺一不可**：①参数重选协议落地（定时任务可挂
  launchd，两年一次）；②登记换档事件戳（configs 或 docs，前向跟踪起点）；
  ③痛苦度量数字写入换档记录。

### D2 🟡 LEI 卫星腿加宽度环境闸（三档口径）

- **内容**：个股执行腿（20% 卫星）在 A 门禁之外加"全A 宽度三档"环境闸，
  深冷期收紧个股敞口。
- **证据**：AY 81 只个股面板——择时赢定投 84%、持有 Calmar 仅 23% 最高
  （个股深回撤被宽度闸大幅砍掉）；**但个股层面三档比二元稳**（二元只赢
  44%）。报告：`experiments/astock-panel-timing-2026-09-04.md`。
- **状态**：数据支持、但属新增改动，优先级低于 D1；若做，须走完整预注册
  回测（卫星腿历史流 × 环境闸叠加 vs 现行无闸），不得直接引用面板胜率
  当结论。

### D3 🟡 极端底部执行形态：价格阶梯（风险偏好题）

- **内容**：双≤20 警报日，用"价格阶梯"（1/3 即进、跌5%/10% 各接一批、
  一年截止）替代一次性满仓。
- **证据**：AV 两轮——中位 +6.1pp、81% 经历占优、5/5 标的正（过程型底
  +7.2pp）vs V 型左尾（中位 −6.9pp、最惨 −104pp）；追涨兜底判负（机制性
  对立）。报告：`experiments/price-ladder-execution-2026-09-04.md`。
- **状态**：不是对错题是风险偏好题——对左尾容忍高→pl3x5 可用；不能容忍
  2012-12 式单事件 −69pp→维持一次性（AM 已证为无代价基准）。语义九全部
  形态已收口，无后续实验计划。

### D4 🟡 10Y 创 5 年新高观察项（等前瞻样本）

- 2026-03 事件进行中（当前回撤仅 −4.5%），**2027-03 前后复查**；正交性
  已判不通过（tsy10y-high-orthogonality：它是"宽度满仓旁边的刹车片"，
  非独立第三套方法）。在那之前只配叙事标注，不进任何判定。

### ❎ 已结决策（防重复劳动，只列结论）

- 主从/多重确认/时间分层/隔夜联动/反脆弱/资金接力：全部证伪或结构性

  仓位系数/结构止损/时间止损/vt 系：维持原判负。

## §4 方法论纪律账本（本轮新增，做后续实验前先读）

1. **参数重选是 edge 的一部分**：任何"参数在某窗口选定"的引擎上样本外
   使用时，必须同时落地重选协议（AX 实证：冻结 5/11 vs 重选 6/11）。
2. **跟随度连续谱**：择时引擎选择不再按"A股/美股"二分，按标的对宽度的
   跟随度分位（AY 实证：胜率随分位单调）。
3. **痛苦度量入档**：任何"均值/中位更优"的引擎替换决策，必须同时报告
   相对曲线的水下时长与最大相对回撤（AX 实证：终值优势可伴随 6 年水下）。
4. 既有纪律继续有效：预注册判定线写死 docstring、双跑哈希、状态 vs 事件
   语义分开、参照系双窗口敏感、相关≤0.3 才做合并回测。
