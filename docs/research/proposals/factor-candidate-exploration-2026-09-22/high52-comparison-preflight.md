# 高点位置与普通动量：研究准备方案

> For agentic workers: 后续实施按 executing-plans 或 subagent-driven-development 逐项执行；本文件仅冻结研究设计选择，不授予运行权限。禁止提交。

**Goal:** 检验高点位置是否比已有动量更值得用于国内宽基 ETF 选择，先消除产品池与资料障碍。

**Architecture:** 复用既有六宽基名单、价格/行动资料和研究计算；新候选保持独立身份，不冒充旧动量。先核资料与计算，再申请一次小范围完整账户对照，不建 Agent 接口或通用研究平台。

**Tech Stack:** 现有 Python 研究模块、冻结资料、Markdown/JSON；本批只有文档和只读检查，无行情计算。

## 一句话结论（大白话）

旧混合池筛出国内宽基后只有三只产品、两个不同指数，直接“选前三”会全部选中，无法检验排序价值。应接回项目已有的六宽基名单，补清资料后，再比较两种选法和一个简单平均分配的办法。

## 1. 范围与选择理由

依据用户“下一轮因子建设你去推吧”和上一轮的候选设计，本轮完成资料元数据核查与协议准备，不解除预测统计、收益回测和 B4/R2 的既有暂停。

比较过三条路线：

| 路线 | 得失 | 决定 |
|---|---|---|
| 旧三只宽基直接选前三 | 几乎无需换输入，但不会改变所选集合，还重复持有沪深300 | 拒绝作为选强效果研究；可用于公式核验但不能宣称选择增量 |
| 旧14只混合池 | 样本较多但混有行业、风格、黄金、海外，回答的不是国内宽基问题 | 留旧证据，不作为本次主研究 |
| 已定六只国内宽基 | 复用2026-09-08专项范围，六个不同跟踪对象；须补数据 | 采用为本次准备清单，不代表已批准真实运行 |

六只固定为 `510300.SS / 510050.SS / 510500.SS / 512100.SS / 159915.SZ / 588000.SS`。对应沪深300、上证50、中证500、中证1000、创业板、科创50。来源：`docs/superpowers/plans/2026-09-08-broad-index-etf-research.md` §1。

这仍是已选定的当前存续产品集合，不是完整历史可投资市场；上证50与沪深300成分可能重叠，六种指数也不是六份独立证据。不能按新结果更换基金、增加黄金或去掉落后者。

本轮规范：研究原则1.1、执行合同1.0.1、定义标准1.1.0。策略层：独立选强研究扩展，不替代 `trading-spec-v1.md` 的道路、路牌、A/B/C/D 或过滤纪律，不改规则账本。

## 2. 输入与时间准备范围

- 拟观察历史范围：2022-01-01—2026-06-30。理由：最晚上市的科创50在旧元数据中于2021-12-27才达到273条报价；2022年作为第一个拟完整年，不按收益挑日期。
- 预热资料拟从2019-09-01起，科创50从其真实上市报价开始；首月信号需2021年12月的完整月末。日期来自既有资料，而非本轮重算；实际完整交易日历、预热和截止可用性必须另核。
- 如任何一只无法在拟首月满足完整输入与原有273条资格，不自动缩池、不降低到253、不后移起点后仍称同一实验；停止并返回新的范围选择。
- 只复用原始名义价格与已生效分红/拆分的经济指数含义。六只的历史停复牌、事件可知时点、供应商修订和价格口径分别记录，不能把混合池的资料标签整体套到新池。
- `available_at` 缺证就是缺证。当前重建只能标为当前重建，不能填历史收盘时间来满足条件；需要采用有限历史近似时，须另明确其允许范围，不能默认继承旧实验的近似授权。
- 本批没有打开并计算价格列，只核文件存在、内容哈希和已有元数据。旧报告所记日期不冒充新逐行审计结果。

## 4. 后续有限效果研究提案（未放行）

选择**完整资金对照**作为第一项效果问题，而非先跑大批相关性统计。三个方法：高点位置选前三、普通动量选前三、六只各分配相同金额。前三内部各分配三分之一；简单对照各六分之一。负分不自动空仓，三者规则事前一致，不增加择时。

- 拟本金各10万元，无后续入金、不借款，现金零息；这是旧研究沿用的比较金额，不是用户资金建议。
- 每完整月末形成选择，下一合法可成交开盘调整；不按当日已过去的开盘成交。期末按收盘估值，现金、应收和未卖持仓都保留，不虚构期末全卖。
- 拟成本情景每次买入/卖出分别按成交额0.1%、0.2%计入，合计最多 `3方法×2成本=6账户`，不是六个因子；研究成本不冒充实际渠道费率。滑点、数量单位、现金不足、停牌延迟和指令冲突必须沿最终选定引擎逐条冻结后才可执行。
- 首要观察量为扣费期末总资产与最大跌幅；同时列各完整年、2026上半年、恢复等待、换手、持有比例、每产品贡献和未成交。不能只报告最好年份或把未解释收益叫独特优势。
- **提议保留标准（研究判断，非论文门槛、待关键审阅）**：两档费用下均比普通动量多留期末资产；全期最大跌幅不多超过2个百分点；2022—2025四个完整年度至少三年的净回报差为正。全部满足也只保留继续观察，不判定有效。2026上半年单列，不当第五个完整年。若胜动量但不如简单六只平均分配，必须明确它尚未证明有实际采用价值。
- 失败表示这一固定方案未满足继续保留条件，不等于高点概念永远无效；不得靠改窗口/费用/池子当场救结果。
- 当前历史已被其他研究观察过，不能把切分后的任何部分宣称真正未见数据；未来新行情观察另开权限。

该段只是完整账户研究的待审范围；尚未确定的执行细节明确构成**禁止开跑的前置条件**，不是让执行者自由补默认值。预测目标、IC、收益差和账户仍零运行。`build_targets` 虽存在，本轮不调用，也不因为“历史描述”字样获得许可。
