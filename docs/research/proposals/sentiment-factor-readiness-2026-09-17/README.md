## 一句话结论（大白话）

我们把仓库里和"投资者情绪"有关的既有家底逐个核了一遍：目前**没有一个**
情绪对象登记进正式定义账本。两套美国周度调查（NAAIM 机构仓位、AAII 散户
调查）的本地数据**字段结构较完整**——每行都带观察周和可得时间等列；
但要诚实说明：这些时间列**只是记录**，列里没有时区信息，真实首次发布
时间、时区、来源许可本轮都**没有证实**（主控复核要点）。按"定义清晰、
数据可追溯、问题适配"三条标准，本轮只推荐**一个**候选进入下一步待批
实验：用 NAAIM 周度读数的状态分档，对美股宽基指数后续表现做**受限历史
描述**（不是择时、不是买卖点、不是硬过滤，是否适配仍待核）。A 股散户
资金流和"冰点机会"这次未选，原因见 candidate-review.md（未选≠排除）。
所有旧报告的收益类结论本轮**只转引、未复验**。

## 本轮做了什么（成果）

1. **核对既有情绪对象**（object-evidence.csv，4 个对象）：逐个给出公式、
   单位、频率、适用市场、真实来源、历史区间、三个时刻（观察时点 / 可得
   时点 / 本地取得时点，术语对齐 definition-standard.md §5 的 `time`
   字段口径）、回填情况、登记状态、历史使用、代码位置、数据指纹与证据
   限制。叙事仪表盘与可计算序列分列；AAII / NAAIM / VIX / 散户热度
   均按不同测量处理，未合并。
2. **验证了 2026-09-15 情绪档案（sentiment-dossier）的关键声明**：
   - 属实：情绪族在 `definitions.v1.json`（81 对象）中**零登记**；
     loader 强制 `survey_week/available_at/source/license_status` 列、
     缺列报错（sentiment.py:51-53）；`public_delayed` 永不合路
     （`_is_current_eligible_at`）；分位分类满 52 期才标状态
     （sentiment.py:255），分段为 ≤10/(10,25]/(25,75)/[75,90)/≥90
     外加 unknown；散户资金流 z 口径 20 日/120 日/阈值 1.5
     （sentiment_signals.py:30-33）；三票多数需 ≥2 票
     （market_mood.py:105）且自述"只标注不判定"。
   - **记录为不同输入快照的差异（不宣称旧档案错误）**：dossier §4/§6
     提到的文件名（aaii_clean/naaim_clean）在当前树中不存在；现行
     `data/sentiment/naaim.csv`、`data/sentiment/aaii.csv` 的列结构
     齐全。**未证明两者出自同一来源生成链，故不视为旧文件已迁移、
     不据此判定旧档案已过时**；仅记录"两个快照的字段结构不同"这一
     事实（主控复核 R2）。
3. **按标准选出唯一候选**（candidate-review.md）：NAAIM 周度敞口读数。
   选择依据是定义与资料结构，**不是**旧收益排名；旧政策层证据按其
   原范围保留引用且不作入选/落选依据。
4. **写出待批最小实验方案**（experiment-proposal.md）：明确假设下的
   受限历史描述研究，含载体备选、时间对齐（含时区/日历缺口）、主比较
   集合设计、重叠处理、能/不能解释什么的边界，以及**待裁定版**下一轮
   prompt 草案。**本提案不授权运行**；真实统计、联网、新数据源均需
   后续许可。

## 主要缺口（仍未解决）

- NAAIM 本地 127 行（2023-11-20→2026-09-07）；52 期预热后理论最多
  75 个可判点（受观察顺序与每点历史有效性限定）。**各状态带实际数量
  本轮未核算**；滚动历史排名不是全样本等分，不能按比例预估带内数量。
  样本期市场环境特征本轮未分析。
- `available_at` 无显式时区（127/127、84/84 行）；真实时区、首次发布
  时间、来源/许可自填值真伪、回填行时刻的生成依据均未核；文件 mtime
  不等于数据取得时刻。
- AAII 本地 84 行、30 处超 10 天缺口，覆盖稀疏，滚动排名稳定性未评估。
- A 股散户资金流无逐行发布时间，不能声称当时可知（仍可做明确假设下
  的受限描述）；板块覆盖缺口大（四输入审计转引：半导体 0 个完整
  140 日窗口）。
- "冰点机会"复合状态的定义权威在 `configs/sentiment_evidence.json`，
  与定义账本的映射关系需主控确认（方向提案 C3 同款待决）。
- 全部旧收益/胜率类数字（含冰点 92% 同向、VIX 归档各证伪项）本轮
  **未复验**，逐条复核深度见 sources-and-checks.json。
