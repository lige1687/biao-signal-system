## 一分钟说明（大白话）

这次只做了"查资料、对边界"，没有算任何新数字（v2 同样零安装、零真实统计）：

1. **统计库**：statsmodels 的回归误差函数（`cov_hac` 与
   `get_robustcov_results(cov_type='HAC')`，Bartlett 权重 1−l/(滞后+1)）和
   arch 8.0.0 的"历史分块重抽"（StationaryBootstrap：每步按概率重启、几何
   段长）。两者是不同算法，可对同一问题并存做两种不确定性估计，不混称同
   一种检验。**本地并非没有重抽能力**：factor_evidence 已有固定块长的成对
   循环分块重抽并真实用过；外部库只是"随机块长"这一形式未接入。
2. **Alphalens 0.4.5（源码逐项核对）**：三个入口的过滤默认值各不相同
   （顶层 20、单独调用 None、get_clean_factor 没有）；分组收益默认减同日
   平均是多空**对比口径**，不等于已定义多空账户；时区是输入一致性检查；
   索引层名必须是 date/asset（本地 symbol 要薄适配改名）。**结论降级为
   暂缓**：等出现已冻结的同日多 ETF 排序问题再按提案执行。
3. **外部"标准因子"分层对照**：市场超额收益（月度自 **1926-07** 起）和
   动量（高动量组减低动量组，公式本身不再减无风险）是美股组合的**收益
   序列**；本地动量是逐标的**分数**（raw）与**排名名单**（rank）两个对象。
   收益、分数、排名、账户四层分开；同名不统一 ID。

分组数与去均值开关、结论语言与授权。
