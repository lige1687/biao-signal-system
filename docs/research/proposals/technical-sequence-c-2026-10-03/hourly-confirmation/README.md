# 小时确认：同一次日线机会的研究设计

状态：design_only / blocked_inputs。2026-10-03；technical-factor-sequence；用户已授权推进该方向。本文件补C方案的下一问题，不是原策略修订、正式因子卡、冻结执行合同或已完成回测。

## 问题与交易意义

在当时已知的日线趋势、回调位置和底部构造相同的机会中，真实小时多头确认是否增加未来下跌风险信息？若等待它再参与，减少了多少损失，又因为买得更晚、价格更高或没有入场而放弃多少上涨？

主假设：较小周期恢复有助于区分回调结束和下跌继续。反例：它只是近期已经上涨的另一种表达；更高买价抵消改善；一直未确认的机会反而上涨；有效性只集中一个ETF或一年。这四类必须保留，不以确认者单独的胜率验收。

H使用同周期20/60/120，来自实现§4.5；EMA采用对应正式指标的SMA种子，不能混用Q01首价种子。H只含六线排列，等号不算严格排列；全部依赖已知才能判0或1，否则unknown。六条均线原值与每根完成/来源时间必须保留。正式对象/适配器尚未注册，不能把草案ID交给现有runner冒充支持。

原文“底部+低周期”与实现A3“至少一种”保持不同身份。主研究先在已知底部这一共同背景里单独测H；不把有H但无底部的旧机会混成完整原文机会。未满足原文其他条件的受限研究必须另命名，不能拿H补齐所有缺口。

## 同一起点、全部去向

共同观察日t0必须仅由此前及当日已经完成的日线/周线资料决定，发生在检验H之前；H不得用于选择母体。每个机会保存唯一身份、选定均线组、底部确认时刻、回调起止依据、目标和失效位来源。重复日不是新独立机会；身份无法唯一绑定时停止事件统计。

第一层“信息是否增加”：在所有相同日线条件中比较当时H=1与H=0，并控制原有信息；H未知另列，不能塞进0组。记录近期涨跌、波动、日线距离、当前方向和ETF身份；再核简单小时涨跌是否已解释所谓H帮助。必须面对只用过去平均的简单参照。输入/模型实际字段和预算要在资料资格后冻结，当前无拟合。

固定主观察为20个交易间隔：信号后下一交易日收盘到第21个后续交易日收盘。主要看途中最低收盘相对起点的下跌，同时交收益、上涨幅度及跌超5/10/15%的频率；5/10/60/120只作事前声明辅助，不挑最好期限。收盘风险不能冒充盘中风险，价格结果不当作资金收益。

第二层“等待是否值得”：每个同一t0建立两个研究账户。基准在共同条件可用后的下一合格交易日开盘参与；候选只多要求H。为隔离确认条件，第一对照两边都在日线收盘复核、下一交易日开盘成交，不同时改变为小时内交易。真实盘中成交的价值另研究，不把这一对照称原文小时执行完整版。

若H在t0已成立，两边可执行时点应相同。若后来才成立，候选只有在该时刻共同条件仍有效时才可成交；先失效就取消，不等未来恢复后补入旧机会。不加“最佳等待N天”；评价窗口到期仍未确认者记“截至截止日未确认”，其固定窗口评价已结束，不能推断此后永不确认。主报告从共同t0观察20间隔的金额差，同时保留延长观察与完整退出，不能给晚买一方重置全新的20天再直接相减。

每个机会必须落在下列明确去向之一，数据不足可以覆盖动作状态但不得丢行：

| 去向 | 如何保留 |
|---|---|
| 当日已确认 | 两边同起点；不能当等待成功案例来抬结果 |
| 后来确认且仍有效 | 记录实际可知/可成交时刻、等待期间涨跌、买价变化 |
| 确认前共同条件失效 | 保留基准经历，候选不交易；不能删除这次机会 |
| 到共同截止仍未确认 | 保留现金和错过的上涨；记截止时未确认而非永久失败 |
| 数据缺失/来源到达未知 | 单列影响范围；缺小时记录不等于小时未转强 |
| 同根K线内顺序无法判定 | 标未知/按冻结保守成交规则；不凭OHLC猜先止损还是先确认 |

## 资金验收与停止条件

沿已保存资金比较的六ETF、各独立10万元、无追加、现金零息、两档单边费用0.1%/0.2%作为可比研究假设；它不决定用户真实仓位。初始结构失效、分红/拆分/到账、整手、跳空和资金占用沿同一个已接受引擎。两边仅H要求不同，退出、目标与计价版本相同；不得让持仓阻塞后的新机会消失而不记原因。

交付至少包括每ETF净金额差、最大跌幅、恢复时间、成交费用、在场/现金时间、进入/取消/未确认/未知数量、确认带来的代价和反例。历史均已接触，只能称后期回顾检验，不能叫真正新观察。完整策略收益、线上收益本轮未测量。

先复用T4时间合同、T8数据字段、已接受日线/账户材料，禁止从归档raw/timing.py直接导入正式实现；它目前只是参考代码。现有factor workflow没有本H适配器，也不是通用等待账户引擎。资料、事件身份、共享模块归属和精确对象绑定齐备后，才冻结必要执行合同与预算。不得绕过入口或另造竞争平台。
