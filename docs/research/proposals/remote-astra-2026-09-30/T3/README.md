# T3：B 横盘埋伏与突破的定义核对（提案，draft / not approved）

## 一句话结论（大白话）

**现行模块 B 代码里，“横盘半年”“密集区上沿”和“两个失效动作”三处都和原文意思有出入：** 中间断断续续只有少数横盘日也算满半年，缺报价的日子也算进横盘时间；“上沿”只从密集达标那天起算，不含前面半年箱体的最高价，所以价格还在箱体里面就可能被算成“突破”；两个失效动作被要求同一天发生，相隔几天就永远不失效；失效后马上在同一个箱体里重开一轮、用更低的上沿再次“突破”；“刚形成多头排列”也没检查是不是刚形成。9 个人工小例子在生产代码上实际运行，代码行为与我运行前的预测 9/9 一致，其中 7 例与原文判断不同。另外在 GitHub 两只 ETF 的 13 年日线上，生产模块 B 只找到 1 个密集区（还是靠间歇凑满的半年），0 次埋伏、0 次突破——**在这个资料范围里 B 根本没有可研究的机会，先修定义也换不来样本。**

## 3. 推荐定义（研究代理 v0，一个版本）与备选

**推荐 B-R1：**
1. 整理寿命只数真实时钟三类日；离开不超过 20 个交易日时暂停计数（不加、不清零），超过即清零；缺报价日视同离开，并记录。
2. 箱体＝从寿命起点到开区日的全部 K 线；上沿＝箱体最高价，开区后继续随新高更新，突破判定用前一日的上沿。
3. 埋伏＝开区后多头排列由假变真的那一天；开区时已经是多头排列则不埋伏、记“排列早于开区”。
4. 突破失效＝突破后出现过“收盘跌回原上沿下方”，且当天“收盘低于 SMA20 和 20 日抵扣价”（推荐 Q1 的读法 A，见下）。
5. 失效后箱体身份保留；同一箱体再次突破必须收盘重新站上原上沿，记为第 2 次，不另开新区域。
6. 带宽、寿命、箱体起点、上沿来源逐日写进证据，供复查。

**备选 B-R0：** 保留现行 2.0.0 作为“历史对照”，任何新结果都与它并列，不覆盖旧口径。

## 4. 待确认（合并为最多两项）

- **Q1 两失效动作是否必须同一天成立？** 读法 A（推荐）：突破后“跌回”出现过即记下，此后某天“跌破 20 组且下弯”成立即失效；读法 B：两者同日（现行）。依据：体系 §3.5 原话“不分先后，必须全部满足”，同日要求会让 B5 这类先跌回、几天后才转弱的假突破永不出局。
- **Q2（低优先）埋伏底线是否要实现“不可避免要交叉”？** 推荐暂不实现（无客观口径），研究报告标明“只用已完成交叉”。
