拒绝理由：R2 不作首选，因为它解决的不是当前最大的阻塞，而且主电脑已有核过的同类资料；R3 不作日线首选，因为日线已有。日线代理（如“盘中刺穿后收回”）**不能**补小时缺口，也不能用今天仍在交易的 ETF 或指数点位顶替历史缺失。

## 3. 公开来源与许可（2026-10-02 现场核查）

- 上交所 [法律声明](https://www.sse.com.cn/home/legal/)：网站行情等资料知识产权归上交所；“任何机构或者个人可基于非商业目的浏览、下载本网站的内容”；“未经上海证券交易所书面许可，任何机构或者个人不得以向他人出售牟利为目的，使用本网站的任何内容”，并对准确性、完整性、及时性不作保证；页面无日期。**推论（非法律意见）**：非营利研究下载可行；公开仓库长期转载大批原件的边界不清，保守做法是只入库抽取出的事实（日期、金额）＋原链接＋原件指纹，原件放私有存储。
- 深交所：首页与“关于本所”页均未找到法律/版权声明（另试一个路径 404），**许可记“未知”**。仓库已存的深交所月历原始响应是否适合留在公开仓库，交主负责人判断。
- 小时行情供应商：未检索、未询价（任务书不授权采购，也不应猜价格）。
