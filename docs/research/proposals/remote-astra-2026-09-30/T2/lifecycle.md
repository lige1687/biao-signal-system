# T2-②③ 完整 A 回调的状态顺序与条件依赖（研究适配草案 v0）

可运行版本：`docs/experiments/raw/remote-astra-T2-2026-09-30/lifecycle_ref.py`（`RECOMMENDED` 与 `PRODUCTION` 两组开关）。只读当日及此前已完成日线；小时确认一律 `unknown_not_connected`。

## 1. 状态与每日处理顺序

对每个标的逐个已完成交易日处理；同一天内**先处理结束/取消，再更新证据，再判断入场，最后才找新触碰**（与 A03 适配器“退出先于进入和触碰”一致），保证同日触发与失效有唯一顺序。

| 层级 | 状态 | 进入条件 | 离开条件（按检查顺序） | 原文依据 |
|---|---|---|---|---|
| 趋势段 | 无 → 开启 | 时钟二类、SMA 与 EMA 三线多头、已完成周线多头，四者当日同时成立 | 缺价（下一段首次记未知）；SMA 排列破坏；收盘 < SMA120 | 体系 §4.4①；实现 A1、§6 简化版 |
| 均线组 g | 未武装 → 已武装 | 趋势段内某一整天最低价 > SMA_g＋1×ATR（价格离开触碰带） | 趋势段结束 | “回撤”以先离开为前提；A03 同口径 |
| 均线组 g | 已武装 → 回撤候选（触碰日 T） | 最低价 ≤ SMA_g＋1×ATR，且收盘 > g 日抵扣价，且时钟二类 | — | 实现 A2；§4.2 |
| 回撤候选 | 保持 | 每天：未缺价、趋势段未结束、收盘 > g 日抵扣价（方向未拐） | 缺价→取消；方向拐下→取消（本次回撤已用掉首次）；收盘超过回撤前高点仍未入场→结束 | 体系 §4.4②；A2 |
| 回撤候选 | 证据更新 | EMA20 收复（前一日收盘 ≤ EMA20、当日收盘 > EMA20，自 T 起）；底部构造＝[T, 今天] 内确认且**今天仍有效**的最新一个；最低价 L＝自 T 起最低 | 构造失效即不再算数，可换下一个构造 | 实现 A3；体系 §7.4 |
| 回撤候选 | → 入场信号 E | 时钟二类、周线多头、收盘 > EMA20、EMA20 上行、A3 满足（`any`＝构造或收复；`structure_required`＝必须构造，且小级别记未知）；确认版再要求收盘 > 20 日抵扣价 | — | 实现 A4；体系 §4.4③、§2.2 |
| 入场信号 | → 待成交 | 记录 A_ref＝E 日收盘、C＝L（到 E 日为止）、B＝E 日已存在的目标或“未知”、盈亏比（B 可得时） | 下一允许开盘成交；不可成交按执行合同处理（T6） | 实现 §3.2、§10、§14 |
| 持仓 | → 退出 | A6 所选版本；C 固定不移动 | 收盘 < C 等 | 实现 A6、§14 |

一次回撤结束（入场、取消或未入场结束）后，该组本段“首次”即已用掉；要出现下一次回撤，价格必须重新离开触碰带。多个条件**不要求同一天成立**：触碰、结构确认、EMA20 收复、趋势门禁可以分布在不同日期，只要在候选存续期内依次满足（案例 C5、C7）。

同一次下跌常先后碰到 20 组和 60 组。研究身份建议用“标的＋趋势段＋该段内第几次回撤”，把参与的均线组当属性记录（最深触碰组、各组是否各自发出信号），避免同一段价格被当成两次独立机会；这一点在 T7 合同里固定。

## 2. 与生产代码的差异及每项的实际影响

| 开关 | 推荐 | 生产（first_ma_pullback 3.0.0） | 单独改这一项会改变的案例（从生产出发 / 从推荐出发） |
|---|---|---|---|
| 转黑是否结束趋势段 | 否 | 是（:235） | C2 / C2 |
| 入场前收盘创新低是否作废 | 否 | 是（:284-314） | C1–C6 / C1、C2、C4、C5、C6 |
| 未入场时何时结束候选 | 收盘超过回撤前高点 | 收盘回到触碰带上方（:436-463） | C9 / C1、C2、C4、C6 |
| 武装条件 | 先有一整天离开触碰带 | 收盘在 SMA_N 上（:474-475） | C1–C6、C8、C9 / C3、C8、C9 |
| 方向核对 | 候选期每天 | 仅触碰日 | 无（被作废规则抢先）/ C3 |
| 构造是否每日重核 | 是 | 否，首次找到后缓存（:324） | C7 / C7 |
| 缺价后首次 | 未知 | 重新记首次 | C8 / 无 |

来源：`switch-attribution.json`。同一开关从不同起点改动，影响的案例不同——例如“方向核对”从生产出发单独改动没有任何变化，因为回撤中的作废规则先结束了候选。这正说明各条件互相依赖，“只改一个条件、其余不变”在这套规则上不成立。

另一个组合后果：对 60/120 组，站回 EMA20 的价格通常远高于 SMA_N＋1×ATR，生产规则的“回到触碰带上方即结束”使多日才完成的回升在站回 EMA20 之前就被结束（推荐起点下改为生产结束规则，C1 的有效首次入场消失）。

## 3. 条件依赖图

```text
趋势段（时钟二类 + 三线多头 + 周线多头）
 ├─ 定义“首次”计数范围（段结束 → 计数清零；缺价 → 下一段首次未知）
 └─ 每日门禁：触碰与入场当日都须满足时钟/周线
武装（离开触碰带）──必要──▶ 触碰日 T（位置条件）
触碰日 T 锚定：
 ├─ ① 底部构造查找窗口起点 [T, 今天]
 ├─ ② EMA20 收复的计数起点
 ├─ ③ 止损 C = min(low[T..E])  ← 也依赖入场日 E
 ├─ ④ SMA_g 方向逐日核对区间 [T, E]
 ├─ ⑤ 首次计数的消耗
 ├─ ⑥ 候选结束参照（回撤前高点）
 └─ ⑦ 归属均线组（20/60/120）
A3 证据（构造 / 收复）──▶ 入场日 E ──▶ A_ref、C、B（E 日已存在者）、盈亏比
入场日 E ──▶ 持仓与退出路径 ──▶ 资金占用 ──▶ 后续机会能否参与
```

结论：
- **回调位置（触碰日）决定结构起点、确认窗口、初始止损和首次计数。** 删除位置条件后必须另立锚点（例如“离开后第一次跌破 EMA20”），那是另一种机会定义，不能称“只删一个条件”。
- 改 A3（例如要求必须有底部构造）不改变 T，却可能推迟或取消 E；E 推迟会让 C 取到更低的低点、盈亏比随之改变，并改变资金占用和后面机会。
- 改“首次”规则不改变任何锚点，但改变哪些候选被计入；它依赖趋势段何时结束。

## 4. 研究适配器接口（草案）

```python
run_reference(rows, *, structures, atr, k_atr=1.0, entry_variant="early"|"confirmed",
              target=callable(as_of, close) -> float | None, **switches) -> list[event]
# rows: 按日期排序的已完成日线字典（open/high/low/close、sma/ema/close_lag 20/60/120、clock、weekly）
# structures: [{id, confirmed_date, invalidated_date}]，由按当时历史计算的构造识别器提供（不可用全历史回写）
# event.type ∈ episode_open | episode_end | touch | signal | cancel
# signal 字段：A_ref、C、B、B_status、rr、a3_source、a3_structure、lower_timeframe="unknown_not_connected"、execute="next_allowed_open"
```

正式研究使用前还须：由主负责人批准开关取值；构造识别器按“当日只看当日及此前”重算（主线已知完整历史会改写包含K线结果，见 `factor-system-increment-review-2026-09-27.md` §4）；ATR 口径沿用主线已选定的版本。
