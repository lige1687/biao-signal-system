## 例 1：真假组都随市场上涨

**设定**：真组目标 [0.02, 0.04]，假组目标 [0.01, 0.03]。

**独立手算**：

- 真组均值 = (0.02 + 0.04) / 2 = **0.03**；假组均值 = (0.01 + 0.03) / 2 = **0.02**；
- 组间差 = 0.03 − 0.02 = **0.01**，即 **1 个百分点**（不是"相对多涨 50%"，也不是 1% 的复利）；
- 两组上涨比例 = **100% / 100%**（两个目标都严格大于 0）。

**怎么读**：这段"历史"里，所有日子之后价格都在涨——这是一个整体上涨背景。真组比假组平均高 1 个百分点，允许的表述只有一种："在这份资料里，状态为真的观察之后，目标平均比状态为假的观察高 1 个百分点。"

**为什么不能多说**：

- 不能说"因子挣了 3%"：3% 是真组观察之后的**历史平均价格变化**，其中包含标的本身的上涨（假组也涨了 2%），没有任何对照能把这 3% 归因给状态；
- 也不能说"因子创造了 1% 收益"：1 个百分点是**两组平均值之差**，不是任何账户拿到过的钱——没有入场、仓位、费用，且两组可能处于不同市场时期（见例 3 与审阅表第 6 行）。差值是描述，不是贡献。

## 例 2：少数赢家

**设定**：真组目标 [−0.01, −0.01, −0.01, 0.15]。

**独立手算**：

- 均值 = (−0.01 × 3 + 0.15) / 4 = 0.12 / 4 = **0.03**；
- 中位数 = 排序后中间两值 −0.01 与 −0.01 的平均 = **−0.01**；
- 上涨比例 = 1 / 4 = **25%**；
- 赢家占比：总和 0.12 中，单个赢家贡献 0.15（即总和的 **1.25 倍**——其余三个观察合计 −0.03，赢家不仅贡献了全部正和，还填平了亏损）。

**怎么读**：只看均值（+3%）会以为"状态之后通常上涨"；中位数（−1%）和上涨比例（25%）说出真相：**四次里三次是小跌，一次大涨扛起了全部均值**。这就是首轮报告必须同报均值/中位数/上涨比例三个数的原因——三者放在一起，分布的形状才看得清。

**本例判断仅限本例**：均值与中位数方向相反，一般情况下只提示分布不对称、需要检查收益是否集中，**不能单凭异号就断言"依赖少数观察"**。反例（主控复核给出）：51 个 −1% 与 49 个 +2%，均值 +0.47%、中位数 −1%——接近一半是正值，并不是少数赢家。本例之所以能下"依赖少数赢家"的判断，是因为还看到了 4 个观察里的具体构成（3 个小跌 +1 个 15%），而不是因为异号本身。

**边界（同样重要）**：

- 本例**不要求**"删除赢家后仍赚钱"才算有效：趋势类规则的收益结构上就可能集中在少数大行情（原则 v1.1 §5：剔除大赢家只做依赖度检查，不机械要求删除后仍盈利）；
- 也不据此**淘汰**规则：4 个合成观察说明不了任何总体性质。本例只校准解读——报告若出现均值与中位数方向相反，必须显式写出"结果依赖少数观察"，而不是选一个好看的数。

## 例 3：目标窗口重叠

**设定**：按格点编号。观察日 t=0 的目标取价格格点 1..22（22 个格点、21 个价格变动区间）；t=1 的目标取格点 2..23；t=23 的目标取格点 24..45。

**独立手算**（价格格点与涨跌区间分开数）：

- t=0 与 t=1 的共同价格格点 = 2..22，共 **21 个**；
- 但涨跌区间是相邻点对：t=0 的区间为 (1,2)..(21,22)，t=1 的为 (2,3)..(22,23)，**共同区间只有 (2,3)..(21,22)，共 20 个**，占 21 个区间的 **20/21 ≈ 95.24%**；
- t=0 与 t=23 的共同格点 = **0 个**（区间也无交集）。

**怎么读**：相邻两个交易日产生的信号，它们的"未来表现"几乎由**同一批价格**决定——21 个涨跌区间里 20 个是同一段路，t=0 信号之后涨，t=1 信号之后大概率也涨。所以"连续 10 天状态为真、10 次目标都上涨"**不是 10 次独立成功**，它更接近同一段行情被数了 10 遍。首轮报告中状态段计数（state_segments）和稀疏视角存在的意义就在于此。

**为什么"无交集"也不等于独立**：t=0 与 t=23 的目标区间确实不共用任何价格，但两个观察仍处在同一标的、可能同一轮市场制度里（同一个月的趋势、波动环境、宏观背景）。区间无交集只是排除了**机械性重复**；排除之后，两个观察**仍可能相关，相关程度未估计**。所以：稀疏视角（每 23 格一格）减少的是重复计数，**不提供**"这些观察彼此独立、可以按二项式算概率"的许可。首轮报告禁止出现"独立命中 N 次"这类措辞。

## 例 4：分母不一致

**设定**：真组主目标 [0.02, 0.04]，辅助目标 [−0.03, **None**]（第二个观察路径缺价）；假组主目标 [0.01]；另有一个**未知状态**观察的主目标 [0.50]。

**独立手算**：

- 主比较共同合法集合 n = 2 + 1 = **3**（真 n=2，假 n=1；未知状态不进主比较）；
- 主比较均值 = (0.02 + 0.04 + 0.01) / 3 = **0.07/3 ≈ 0.0233**；
- 全资产背景 n = **4**（含未知状态），背景均值 = (0.07 + 0.50) / 4 = **0.57/4 = 0.1425**；
- 真组辅助目标：aux_n = **1**（不是 2），aux 均值 = **−0.03**。

**两个错误做法及代价**（脚本中作为对照验算）：

1. **把缺失辅助值填 0**：真组 aux 均值变成 (−0.03 + 0) / 2 = **−0.015**——下行风险被凭空稀释一半。缺失的意思是"这条观察的路径价格不全，算不出来"，不是"没有下跌"。所以 aux_n 必须与主目标 n 分别报告：本例主比较真组 n=2 但 aux_n=1，两个分母各有含义。
2. **混比分母**：把未知状态的 0.50 混进主比较，均值从 0.0233 跳到 **0.1425**，放大约 **6.1 倍**（独立手算：(0.57/4) ÷ (0.07/3) = 171/28 ≈ 6.107）。未知状态观察既不知道条件是否成立，就不能为"状态之后的表现"作证；它只能进背景。反过来，背景（含未知、且未知恰是大涨）与真假组不是同一集合——本轮范围选择不拿背景均值与真假组作差值比较；未来若作，只能是写明集合差异的描述，不得冒称因果贡献或严格超额。

**怎么读**：首轮报告每一张表都要能回答"n 是几、谁被排除、为什么"。任何均值旁边的 n 变动（主目标 n 对 aux_n，主比较 n 对背景 n），都必须能在缺失对账字段（`target_missing`、`aux_n`、`n_unknown_state`）里找到出处。
