# 首轮结果解读骨架（待主控采用的建议）

**性质**：这是给用户读首轮真实结果时用的解读骨架建议，**待主控采用**；不是第二份正式报告模板（正式模板仍是 `docs/research/experiment-report-template.md` v1.1.0），不填任何真实数字。方括号 `[ ]` 为届时填数位置。

## 一、固定阅读顺序（六步，不可调换）

**1. 测的是什么**
一句话：在 510300 的供应商调整价历史上，把每一天按"双均线共同确认状态"分成真/假/未知三组，看真/假两组各自之后"从下一个交易日收盘到第 22 个格点收盘"的价格变化有什么差别。
它不是：一次交易、一个策略、一次选股考试。状态只是"道路"上的路况描述，没有买卖动作。

**2. 数据限制（先于任何数字）**
逐条写清，缺一不可：
- 价格是供应商前复权快照，2026-09-08 取得；精确复权公式与锚点未知，历史各日价格不是当时可见的口径；
- 历史逐行"何时可知"（available_at）未知；研究截断 2026-02-03 收盘是事后设定的标签成熟线，不代表 2 月已持有此快照；
- 供应商调整价不是含分红财富，更不是成交收益；
- 单一标的（510300）、单一评价窗（2019-10-08 至 2025-12-31）：这段历史该标的的底色（涨/跌/震荡）会渗进所有数字。

**3. 有多少有效观察**
按此顺序报：评价窗内观察总数 [ ]；状态真 [ ] / 假 [ ] / 未知 [ ]；目标未成熟剔除 [ ]；目标缺失剔除 [ ]；最终主比较 n = [ ]（真 [ ] + 假 [ ]，须能对账相等）。
读法提醒：有效观察少（例如任一组不足几十）时，后面的差别只配叫"这批观察里的差别"。

**4. 真假状态后的差别**
同报三个数，两组并列：均值 [ / ]、中位数 [ / ]、上涨比例（严格大于 0）[ / ]；差值写作"真组均值比假组高 [ ] 个百分点"。
辅助下行同报：两组 aux_n [ / ]、平均最差收盘变化 [ / ]、最差单例 [ / ]。
措辞纪律：一律"状态为真的观察**之后**，目标平均为……"，禁止"状态带来了……"。背景组（含未知）只用于第 2 步底色说明，不参与差值。

**5. 是否依赖少数年份/大赢家**
- 逐年表（按信号发生年分组）：差别是多数年份同向，还是个别年份独扛；
- 状态段：真状态是分散出现还是集中在 [ ] 段长行情中；
- 稀疏视角（每 23 格一格，锚点预先固定）：稀释重复计数后方向是否仍在（命中数须带同口径分母）；
- 均值与中位数是否同号；若背离，必须写"结果依赖少数观察"。

**6. 仍不能证明什么**
照读不删：本轮不能证明状态有预测能力；不能证明差别会重演；不能证明任何交易能拿到这笔钱（无仓位、费用、成交检验）；不能推广到其他标的、其他时期；差值不是因子贡献，背景上涨不是状态功劳，稀疏无重叠不是统计独立。

## 二、三种合规结论措辞（只能三选一，不填数）

1. **描述上存在差异**："在这份资料里，状态为真的观察之后，目标分布与状态为假的观察存在可以描述的差异（均值/中位数/上涨比例同报如上）。这是历史关联描述，不是能力证明，不构成任何买卖依据。"
2. **没有清楚差异**："在这份资料里，真假两组观察之后的目标分布没有清楚差异（三个统计量同上）。这不等于状态被证伪——本轮设计的描述能力只能到此为止，不构成停用规则的依据。"
3. **资料/观察不足无法比较**："有效观察数量或资料口径不足以支持真假组的公平比较（缺口如上），本轮不作差异描述。"

三种措辞均不得自动升级为"因子有效/无效"，不得升级为交易指令，不得升级为冻结观察或生产建议。

## 三、三个将来阶段（一句话区分）

> 本轮是**第一阶段：描述历史关系**；第二阶段是检验这段关系在**其他未用于改规则的资料**中是否持续（本轮资料已参与规则形成，永远答不了这一问）；第三阶段是把状态接回**完整策略**（入场、退出、仓位、费用、成交）后检验**扣成本**的贡献。后两阶段不是本轮任务，本轮任何结果都不跳过它们。
