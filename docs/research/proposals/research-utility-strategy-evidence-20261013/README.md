2026-10-13；task-id `research-utility-review-20261012`。这是本次证据重核后的研究设计，不是新增市场运行合同，也不替代 `technical-factor-sequence` 的完整A/小时研究所有权。

用户目标：以策略为核心，为日常参与、等待、失效及退出提供可量化结果；研究专业判断由AI负责。当前可执行范围是核保存结果、方法与输入，不改变原策略、生产或真实交易。

## 完成单位

完整原文A的完成单位是一套可追溯判断和完整独立资金结果，再比较有明确业务意义的一项条件。完成必须包括：逐机会原文资格、判断时可知资料、进入/退出原因、订单及费用、每日现金和持仓、基准差额、未完成机会和资料不足。单独计算出因子值、获得一次正结果或界面显示通过，都不替代这些要求。

独立的日线信息问题不以完成全部A为前置条件。每项先写清它要帮助哪个已有判断、实际测了什么、还没有测什么；例如“未来收盘下探预测更准确”只能支持该预测用途，不能转写成“等待更安全”或“完整策略胜率更高”。2026-10-15流程审查确认：目标、指标与执行能力必须在选题时对应，不能因统一工具只会预测就持续把操作问题改写成预测问题。

## 指标与比较

1. 扣费闭仓胜率＝净盈利已退出交易数/全部盈亏可核的合格已退出交易数；持平、未退出和缺资料数量分别展示。原规则没有期末强制卖出就不补造卖出。
2. 固定20日价格上涨比例只解释价格目标，固定同起点与同终点；不代替买卖胜率。不把旧21段目标、旧20段目标与不同入场窗口混在一起。
3. 同时报告平均盈利、平均亏损、全部交易平均结果、费用、参与次数、持有时间、闲置资金、完整账户金额与最深跌幅；简单少投入和适当的简单趋势/持有参照保持可见。
4. 场景用当时已知的趋势状态、回调位置、首次身份、大周期同向分别展示。先逐维度，必要时再做有限交叉；两边机会不足只描述，不给可靠未来胜率。不事后按最终涨跌划分场景。
5. 条件联合概率直接数共同出现的事件；比较同一已知背景，双方数量、未知数量及覆盖比例齐全。相关条件的重要程度不能当成独立收益份额。
6. 操作层比较固定共同机会、产品、资金、报价时点与费用；保留未参加、等待失效、晚确认和错过上涨。若改变退出导致后续机会和现金占用改变，要解释完整路径，不能强行算成同一笔的纯退出贡献。

## 首个后续比较如何复用

沿用原 `technical-sequence-c-2026-10-03/hourly-confirmation/README.md` 的设计：先独立于小时条件确定日线共同机会，再对真实已完成小时资料计算六条均线的多头关系。六线关系是受限表达，不代表低周期向大周期传播的全部原文。

共同机会在首次发生后保留：当时已确认、后来确认且仍有效、确认前失效、到固定观察末端仍未确认、资料不足、同根内先后未知。信息层用共同固定终点；操作层遵守同一判断/下一合格开盘及原退出规则，不给晚入场组重新赠送完整观察期限，不寻找最佳等待天数。

仅在旧方案没有实际执行同一问题、输入及完整语义合格时，原负责人才能据新证据冻结一轮。研究假设、基准、唯一主要指标、产品/时期、费用、拟合及试验次数先固定。适用的独立信息问题走当前 `--workflow-draft` 实际资料/合成演练/冻结→`--workflow-contract`；完整A资金比较不能直接走这个预测入口。当前没有此轮市场授权合同，不代签或启动旧预算。

## 可信度与停止规则

- 事件按真实日期、产品及趋势经历说明重复程度，不逐行随机拆开让同一段行情同时出现在拟合和评价中。
- 任何拟合、阈值选择或标准化只使用当时训练资料；未来结果成熟后才可进入学习。已看过的旧历史不重新命名未见验证。
- 主要结论优先简单固定比较；如确需估计结果波动范围，方法依据真实时间跨度与相关性另行冻结，不能因范围太宽换方法。样本不足就报不足，不自行补造置信度。
- 保存失败、全部已知尝试及原预算。无改善、改进不足或缺资料均可形成有价值结论；只因新证据/明确修正才重开原问题。
- 开新比较前沿用原合同`history`/`question.trial_history`，列出关联旧家族与旧脚本、已经看过的时期、已知尝试及未知部分。本次11案清单见[流程审查原件](../../../experiments/raw/factor-research-process-audit-2026-10-15/empirical-audit.json)，这是已知相关记录，不能声称全项目试验总数已穷尽。当前家族账本仅按相同family累计预算；跨家族已见资料检查不等于全部尝试已统一计数或消除了挑赢家风险。改名不能把已见历史变成新验证。
- 不做自动权重搜索、按单次胜率分配真实资金或把模型解释值换成收益百分比。不增加情绪、宽度、宏观、账户政策或新的共同资金规则。
