# D 子合同：P1 方向裁决材料包（p1-direction-decision-package）

定位：**裁决权在用户**（方向选择非技术判断）；本线只准备材料、给建议，
不代裁。

## D1 裁决材料框架（glm-max，1 主派发）

- **方案 A（固定 14 只池四格优先）**：优点/缺点/需新增能力/长期维护成本；
- **方案 B（通用能力优先）**：优点/缺点/何时才需要固定池；
- **证据需求表**：是否需要固定池（使用场景）/是否需要四格（研究目的）/
  是否值得维护（成本）/是否可泛化（多池验证）；
- **现状事实底稿**：两线已有证据（受限试点的冻结样本经验、v0.3 通用
  能力成果、资格墙对四格验证的约束——research_signal 未解除前预测类
  四格验证无法开跑）；
- 输出：推荐方案＋风险＋**待用户决定项清单**（Q2）。

## 边界

不预设结论；不因材料准备启动任何固定池/四格执行；引用既有报告不改写；
裁决记录位留空待用户。
