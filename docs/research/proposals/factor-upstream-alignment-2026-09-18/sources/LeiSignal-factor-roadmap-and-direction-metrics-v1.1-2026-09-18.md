## 1. 不变的研究原则

| 原则 | 对实现和结论的约束 |
|---|---|
| **服务真实决策** | 每轮说明要改变什么：选谁、何时参与、买多少、何时退出/回补、怎样配置或怎样执行。增收、合理代价下少跌、减少成本和排除无用复杂度都可以有价值。 |
| **适配比名气重要** | 因子、论文、基准和统计方法先核市场、资产、币种、频率、多空及数据时点；不因来源著名直接采用，也不因结果不利事后替换。 |
| **类型、证据、授权分开** | 特征不是“未毕业的因子”。定义已明确、计算已核验、历史有效性和交易授权分开记录。 |
| **不是所有研究都先过IC** | 横截面预测、时间序列状态、政策对照、风险执行与收益解释分别选方法；指标不适用时写不适用，不填0冒充结果。 |
| **新增对象须说明增量位置** | 先说明它用于排序、准入、仓位、退出、回补、执行限制还是事后解释。名称不同、低相关或高统计分数，都不自动意味着值得加入。 |
| **公平对照先于好看结论** | 看新结果前固定主基准、主要目标和可接受代价。局部机制与完整方案比较分开；研究失败也保留。 |
| **时点与资金不能靠叙述补齐** | 所需输入必须满足对应定义和用途；完整账户保留现金、分红、应收、成本与未成交。风险不是一项可以从收益直接扣掉的手续费。 |
| **归因并行，不做伪精确加法** | 资金贡献、决策增量、风险/因子解释是三种视角；不得将同一利润重复记账，残差不自动等于α或运气。 |
| **控制选择偏差，不追救参数** | 探索可修改假设但全部留痕；确认阶段冻结。多个AI的参数、池、标签期限和模型选择纳入同一研究家族记录。 |
| **局部受限，不全局封锁** | 不要求所有研究等“归因可用”或所有数据A级；也不允许缺失、身份冲突或完整性失败被条件放行选项伪装成合格。 |

### 1.1 对象的建议划分

**Universe** 指研究谁；**Feature/State** 指描述什么；**Factor Return** 指按明确构造得到的收益序列；**Signal/Policy** 指如何改变决策；**Strategy** 指完整资金行为；**Experiment** 指如何检验；**Attribution** 指如何解释结果。

使用项目已有枚举和ID，必要时做映射，不为统一措辞批量重命名。一个基准收益可以被归因模型引用，但不因此消除它与信号、风险暴露的区别。

例如，B200计算值、B200三档目标仓位、50日价格确认、完整宽度策略，应当是有依赖关系的不同对象。验证之后新增条件证据，不必把B200“升级改名”。

### 1.2 “弱但真实且互补”的正确用法

寻找的是有证据支持、对既有系统有增量的信息，不是刻意找弱信号。信号不必每次正确，也不要求单独都能构成赚钱策略。

互补至少检查：原始信息是否重复、实际决策是否不同、底层风险是否仍集中。低相关的噪声没有因此获得价值；高度相关的输入也可能在有限决策环节提供增量，需对照验证。

**进入组合研究不以单独正IC或单独盈利为统一门槛。** 先明确新增输入承担排序、准入、仓位、退出或执行等什么职责，再按事先假设比较已有方案A与A+B；已有四格能够回答时直接复用。新增输入改变了哪些决策，以及相应收益、风险与成本交换，才是组合结论的依据。

## 3. 两条研究链路：共享起点，按问题分流

### 3.1 产生与选择策略的链路

**资金用途/研究问题 → 可检验假设 → Universe与合法输入 → 对应类型的验证 → 完整方案与简单对手比较 → 成本/稳健性/实际执行 → 有条件保留、补证或停止。**

| 研究类型 | 首先验证 | 最终怎样判断价值 | 禁止机械套用 |
|---|---|---|---|
| 横截面预测 | 同时点不同资产的排序与后续收益关系 | 在完整选择与账户路径中，是否增加净收益或改善风险/成本 | 给很小的ETF池强行切十组；把多空分组差冒充只做多账户收益 |
| 时间序列状态 | 相同市场/资产在不同状态后的收益与风险 | 是否改善参与节奏和风险暴露 | 给各ETF相同的全A B200计算当日截面IC；强求单调关系 |
| 政策改进 | 固定其他条件比较过滤、退出、回补、仓位或再平衡 | 完整资金路径的得失与交互 | 要求先发明“回补因子”；只看已买入交易、遗漏等待和错失 |
| 风险与执行 | 风险、成本、成交或约束估计是否可靠 | 是否降低可接受范围内的风险、摩擦或错误 | 要求必须预测平均收益；把风险估计值当获利信号 |
| 收益解释 | 资金记录和适配基准/因子是否能解释表现 | 是否减少对收益来源和风险的误判 | 将同期解释拟合当预测；以高R²或正截距直接证明稳定α |

**不强迫所有路线都先经过因子筛选。** 固定规则、无需拟合的策略不必人为加入训练环节；有参数拟合或学习时，才需要相应的训练、验证和标签成熟约束。

### 3.2 解释策略的链路

完整日账、交易、持仓及预先指定基准，分别进入三层分析：

1. **资金贡献：** 产品/时期/现金流在哪里赚亏，金额应能与账户核对。
2. **决策增量：** 固定对手之间发生了什么变化，局部诊断与完整账户差额分开。
3. **风险与因子解释：** 市场、行业/风格、趋势/动量、币种等适用暴露，以及模型解释不足。

三者综合形成结论与证据等级，不是逐项扣减直到剩下“真正α”。

若使用收益模型 `r_p - r_f = alpha + Σ(beta_k × f_k) + epsilon`，必须另有模型卡。`alpha`是该模型截距，`epsilon`是逐期未解释部分；两者不混称Residual Alpha。资金模拟现金零息也不等于模型无风险收益天然为0。

## 4. 分阶段路线图

### P0｜先封住已识别的输入资格漏放

**目标：** 失败、未知和合法输入在真实入口中被准确区分，不靠宽松开关洗成正常可用。

**前置与范围：** 读取现有修复任务与验收记录。若尚未验收，优先处理四类已识别问题；沿用该任务零网络、不跑收益、不修改冻结输入和定义的范围。本文件不扩大该范围。

**最小交付：**
- 四类反例的修复前失败、修复后正确处理，以及合法输入仍能通过获准检查的证据。
- `load_snapshot → check_snapshot → require_use`等实际调用链结果，包含跨模块测试。
- 基础完整性、定义依赖、研究用途三个层次的判定与残余限制。
- 受影响消费者、旧结论纠正及尚未接入项。

**验收重点：**
- 哈希失败、明确身份冲突、非法时间不能被`allow_conditional`或`accept_structural`覆盖成正常合格；诊断读取单独标记。
- 请求过月份不等于日历完整；日历按声明的表示方式和覆盖范围核验，未知不当休市。
- 每个产品自身缺口不得被全池并集掩盖；没有证据不把晚起报价解释为晚上市，停牌解释须匹配产品与日期。
- `available_at`缺失、非法、晚于某次决策分别处理；历史重建不伪造当时可知。
- 核验结果绑定实际输入、范围、定义和用途；更换输入后不沿用旧“通过”。

**进入下一阶段：** 与下一任务有关的硬性漏放已关闭，所需数据和用途允许进入，残余限制被明确接受或阻断。不能要求全市场历史都无缺口才交付。

**停止/退回：** 反例仍在正常链路漏放，或靠全部拒绝获得“通过”。旧收益是否受影响另行判断，本修复不自动宣布它们正确或错误。

### P1｜完成或核实 v0 的真实接入与独立验收

**目标：** 证明定义不是只贴在报告上的标签，而是决定实际数值、名单、账户和解释的代码依赖。

**执行底座：** 原v0已冻结的14只池、月度无退出四格、两档费用和最多8条正式路径。原计划的身份、资金和兼容检查继续有效。已经完成且证据有效的路径不重复执行；数据修复影响原输入资格时，只处理受影响范围。

**最小交付：** 计算绑定、四格名单和完整账户；资金贡献、风险描述与主对照；旧来源保护、版本快照、失败记录与主控复核结论。

**验收重点：**
- 先核原E11兼容，再解释新增版本；新增全池等权路径须验证4只以上产品确实进入账户，而不只是名单表正确。
- 公司行动与账户权益事件映射明确，期末应收和分期初始持仓不漏记。
- 结果分成工程可接受、条件性研究价值与生产未授权；不以发现“有效因子”为硬性完成条件。
- 主对照解释波动过滤；选前三同时改变集中持有，不叫纯动量溢价。

**研究价值问题：** 过滤排除了谁、替换成谁、是否改变现金和集中度；不能仅比较最终买到的赢家。

**停止/转向：** 过滤无明确增量，按协议归档并停止追参数；存在收益—风险交换则量化，不替用户确定可接受程度。该结论不自动改动11只池快速回补政策。

### P2｜下一批优先：验证目标＋时间对齐＋一种横截面诊断

**目标：** 不新增交易规则，先回答：现有月度动量排序与其对应期限的未来表现有什么关系？样本、计算和解释是否可复算？不能只交一个平均IC后写“有预测能力”。

**前置：** 现有动量定义、合法输入身份和决策序列可定位；有适合所选未来标签的价格/公司行动资料。部分标签无资料时标记缺失与原因，不为赶进度填假收益。固定Universe只意味着本轮对象一致，不意味着历史选池偏差已经解决。

**本阶段范围：**
- 一个已存在的动量定义，一个固定Universe版本，一种主要验证目标。
- 原有月度决策时间，不增加每日密集搜索。
- 复用已有数据和账户结果；不新跑策略账户，不扫描观察期限，不新增因子或拟合复杂模型。
- 一种主诊断，加上解释其经济意义所需的最小辅助结果；不将所有可能指标列为必做。
- 简单证据记录从本阶段开始，直接映射现有输出和合同，不等大平台建成。

**标签建议，需先与项目接口核对后冻结：** 从本次月调仓最早合法执行时点，到下次月调仓对应执行时点的单产品经济总回报。它用于信息诊断，不模拟策略实际每笔成交，不用未来已实现收益判断当日可选资格；诊断未扣费时明确标注，交易价值回到完整账户评价。

#### P2-A｜样本去向：先知道研究了谁

保留每个决策期的原始样本索引，能追溯当时资格、因子可算性、因子值、原始排名/分组、是否被既有规则过滤或选择，以及未来标签的成熟、有效、缺失和原因。至少汇总：原始合格产品数、因子有效数、有效标签数、配对数及排除原因；另说明因子值范围、并列、常数和异常情况。

**先用当时合法信息确定资格、排名和组别，再连接未来标签。** 未来价格缺失不能把原第二名重新变成“当时第一名”；原候选与组别不因标签清洗而改变。配对有效样本可用于相应统计，但须与原集合分开计数。

标签原因尽量互斥并能对回原索引；多个原因并存时保留附加标记，汇总口径不得重复计数或漏掉样本。缺失、未成熟、不可成交和真实零收益分开。

#### P2-B｜逐期诊断：不仅看上涨，还看相对参照

开跑前固定一种主诊断，例如逐月Spearman Rank IC；同时保留一种足以解释经济意义的辅助对照，例如固定强组相对当月同池等权参考的未来收益差。采用分组时提前确定少量组、方向、并列和最小样本处理；不在结果出来后选最好的分法或组数。

| 必须回答 | 最小输出要求 |
|---|---|
| 每期是否有可解释的样本？ | 对应原始资格数、配对数、组成员数、标签覆盖、统计是否可定义及原因 |
| 当月排序是否有信息？ | 主诊断逐月值；如采用分组，展示固定各组的当月未来收益与成员，不只展示最高组 |
| 相比什么有差异？ | 同期、同口径参考收益和强组相对差额；明确完整样本或已观测样本范围 |
| 跨期结果由什么构成？ | 逐月统计及固定阶段汇总；使用的月份和排除原因、跨月权重、必要的均值/中位数与样本数 |
| 还存在什么不确定性？ | 同期相关、标签重叠、时期与产品依赖、资料资格；是否有真正未见证据明确列出 |

默认先形成每个月的组收益、参考收益及差额，再逐月等权汇总。改变跨月权重须在协议中写明理由，不让后期产品较多的月份因行数更多而自动占更大权重。逐月Rank IC按相同原则保留有效期数与汇总规则。

**分组为信息诊断，不是可交易净值。** 高低组差、强组相对参考差，不冒充只做多策略的扣费收益；平均月度差额也不直接复利成年化α。

例如，强组未来收益均值为3%，同期参考为4%，表示相对该参考少1个百分点，不能只凭强组上涨声称选强有效。该数字仅为口径示例，不是本轮市场结果。

#### P2-C｜条件结论与已有账户关联

报告在逐期诊断之外，给出一条结构化条件证据：在什么定义、池、目标、时期与资料资格下，支持什么、不支持什么，尚未验证什么；绑定机器结果、尝试记录和已有账户的准确版本。

已有账户能够回答交易价值时引用并核对；不能对应时明确“不足以把信息诊断升级为净交易增量”，不为了补齐报告自动新跑账户。原始未过滤集合为主；已有过滤子集仅按冻结用途作辅助，不只观察实际买到的产品。

每条结论同时记录问题类别/可能原因、支持证据、建议动作及重新开启条件；原因未知可以保留，不强迫选一个确定根因。下一步允许归档、等待或停止，不要求总能生成新实验。

#### P2验收与退出

必须核清标签区间、成熟时点、公司行动、末端未完成、缺报价与未成交语义；按第6节检查逐期截面语义、跨期汇总、缺标签不重排、比较样本一致性和不可定义统计。

**下尾分位数、置信区间、重采样不是默认必做。** 必须说明不确定性，但只在样本和问题允许时，按事先规格增加一种必要分析。样本不足可展示原始较差月份及限制，不强制填出精确尾部风险。

**完成标准：** 一份TargetSpec和离线标签；样本去向、逐期主诊断及参照差额、条件结论三类输出；可复算证据、已有账户关联、实际成本与停止/后续建议。复用已有同等产物，不要求另造文件系统。

**停止/降级：** 合格产品不足、因子/标签为常数或标签未成熟时，不产生伪IC；可交付“方法可复算、市场信息不足”。无明确增量、资料不足和有风险收益交换分别报告。不得把低IC或单期结果直接推广为整个策略无效。

P2结束后，如有限稳健性诊断可能改变取舍，按第8.4节另立项；不是只给正结果补证，也不是每次都必须继续。

### P3｜按需补状态型验证与条件证据

**目标：** 让宽度类问题按状态研究，而不是照搬横截面排序；记录已有输入之外是否提供可解释的信息。

**前置：** P2的目标/时间基础可复用，或已有等价能力；宽度与价格状态有合法定义和质量记录。此阶段可与不依赖它的研究并行。

**本阶段范围：** 从一条已有宽度候选选一个解释问题。优先回答“相同价格背景下，宽度状态对应的后续收益/风险是否不同”，而不是另找阈值。状态划分和观察期在看新结果前固定；已有合适定义优先复用。

**最小交付：** 状态覆盖、条件收益/风险、样本相关与稀疏性说明、与原账户持仓差异的关联、正反证据记录。

**验收重点：** 不要求关系单调；不把同一次宽度极值的连续天数当独立机会；不利用未来牛熊标签产生历史信号；条件分析只提供描述或预测线索，不自动推出因果和交易门槛。

**停止/转向：** 条件样本太少或没有决策价值，保留局限并停止。不得为挽救结论更换大量分箱、期限或平滑方式；不重做已完成的纯50日挑战，不重新搜索已暂停的B50/B200转强版本。

### P4｜问题驱动的论文、外部参照与小型模型

**目标：** 补一个当前结果解释不了或验证不充分的问题，而不是扩充因子目录。

**三个可选分支，每次只选需要的一支：**
- **资料补证：** 历史名单、终止合并、公司行动、交易时点等，优先解决会影响已有结论的问题。
- **归因参照：** 对相对同质的权益部分引入少量适配因子收益，先验证币种、频率和定义，不把同一模型套整个混合池。
- **新信息候选：** 在现有波动四格形成结论后，才决定是否研究固定一种风险调整动量；残差动量需要合格解释模型，后置。

**最小交付：** 方法卡、外部资料/许可/版本、适配差异、小例核验、本地定义和一次有边界的研究。外部收益序列只读接入也可以是合格交付，不必立即参与交易。

**验收重点：** 原论文、作者数据和反证共同核查；未读全文就标实际阅读范围。月份数据不前向填充为日收益；外部指标同名异义用独立ID；用于解释不等于获准交易。

**停止/降级：** 数据不适配、原方法无法确认、局部信息无增量，停止该分支。高R²、正模型截距或论文名气不能替代本地证据。

### P5｜组合、执行与持续观察

**目标：** 检验候选进入整体系统后是否值得，而不只是单模块各自表现好。

**前置：** 候选规则、资金用途与数据边界已明确。真实本金、入金/用款、风险预算和交易授权未确定时，不编造配置比例。

**最小研究：** 对固定资金预算，比较“既有组合”与“加入一个候选的组合”；协议中明确资金从哪里来、总敞口和重叠方向、订单冲突、成本和现金。没有预算协议先做描述与影子记录，不搜索最佳权重。

**验收重点：** 同期亏损、重复风险、未恢复时间、相对长期落后、现金需求和实际执行差异一起评价。不得把单策略年化相加；不能让各模块重复花同一笔钱。

**监控分层：** 数据/运行异常、信号/暴露行为、账户/执行结果。硬性数据故障按既定规则暂停受影响路径；表现变差触发复查，不自动认定因子失效、重调参数或扩资金。

**停止/授权：** 组合无增量可拒绝加入；持续落后或执行不满足目标可降级。影子观察与前述阶段可并行，但实际采用必须另行授权，不由本路线自动发起。

## 5. 需要补齐的三个最小合同

这些是字段要求，不意味着必须新增数据库或服务。优先映射已有定义表、实验manifest和报告模板。具体文件名、枚举与接口由项目现状决定。

### 5.1 定义合同：这个对象是什么

至少包括：唯一ID/版本、对象类型、使用位置、公式与窗口端点、单位、方向、价格和收益口径、Universe/资格、预处理、输入依赖、时点、质量、计算绑定。

定义、数据与证据分别版本化。公式不变而输入修订，记录新数据版本；解释模型或策略使用方式改变，记录其自己的版本，不静默覆盖旧结果。

### 5.2 验证目标合同（TargetSpec）：究竟验证什么未来表现

| 字段组 | 至少写清楚的内容 |
|---|---|
| 身份与用途 | `target_id/version`、信息诊断或账户评价、对应的定义与研究问题 |
| 时间 | 信号形成、最早合法进入、区间结束、标签成熟时间、交易日历与时区；一个月和固定若干交易日不混用 |
| 数值 | 价格/经济总回报/相对收益/风险路径指标；币种、分红、拆分、费用和分母 |
| 可交易性 | 计划执行时点与实际成交时点是否相同；不可成交或缺开盘怎样标记；若延后，是否还属于原目标 |
| 缺失与末端 | 停牌、终止、缺报价、未成熟、期末尚未完整观察的状态与原因；保留原样本索引，不因未来不可见就悄悄删样本 |
| 防泄漏 | 标签依赖与特征依赖隔离；训练仅使用截止时已成熟标签；全样本预处理和基于未来结果的异常值筛除不得混入事前决策 |

**风险目标必须分清：** 从进入价格起的最大下跌，与期间自身高点到低点的最大回撤，不是同一指标；日内高低价、日收盘和执行后路径也不是同一口径。

**时点边界：** 有效的未来标签本来就包含未来结果，但只允许进入离线评价或标签成熟后的训练。因子、交易资格、历史预处理和当期决策不得依赖它。

### 5.3 条件证据合同：在什么条件下知道什么

最小证据键为：

`定义ID/版本 × Universe/输入版本 × 使用位置 × TargetSpec/持有周期 × 实验协议 × 基准 × 证据区间/质量`

证据至少记录：结论、支持/不支持的用途、主要差额、不确定性与时期依赖、尝试史引用、报告与机器结果、尚未核验项，以及下一步建议与实际授权。结论、执行状态和授权分开；“完成计算”不意味着“支持假设”，“建议补证”不意味着已获准继续运行。

同时区分：

- **定义与实现：** 已说明、已绑定、已独立核验、存在差异。
- **资料资格：** 可用于哪一种用途，哪些时间或产品受限。
- **市场证据：** 有条件支持、未见增量、存在交换、证据不足。
- **权限：** 仅描述、研究、影子观察或单独批准的实际用途。

不设一个永久的`factor.valid=true`替代上述维度。接口可以兼容旧状态，但不能把旧状态重新解释成更强授权。

#### 5.3.1 原因—证据—动作—重新开启条件

直接补入现有证据记录或交接模板，不新增全局状态平台。最少包含：

- **问题类别/可能原因：** 数据、时点、计算、样本不足、条件依赖、未见增量、决策映射/成本、资源停止，或原因未知；可以多标签，不把猜测写成已证实根因。
- **支持证据：** 指向哪段输入、反例、逐期差额、账户记录或已完成检查；没有证据的解释标为假设。
- **建议动作：** 修复、补证、保持候选、冻结观察、归档或停止；最多一个最可能改变当前取舍的后续问题，也允许无后续。
- **重新开启条件：** 需要什么新增资料、独立证据、机制假设或资金用途变化；注明责任人/复核角色与授权状态，不自动设置续跑任务。

| 当前发现 | 默认处理建议 | 重新开启依据 |
|---|---|---|
| 数据、时点或计算有已证实错误 | 暂停受影响市场结论，最小修复，不借机优化策略 | 修复通过，受影响输入及结果身份重新绑定 |
| 样本少、差额不确定 | 证据不足；评估补证价值或等待标签成熟 | 新成熟样本、合格资料或一项能改变取舍的诊断 |
| 既定目标下未见增量 | 归档并停止重复搜索，不推成普遍无效 | 新证据或新的、可检验的机制/用途问题 |
| 对选参、少数时期或产品依赖强 | 限定结论，必要时申请有限稳健性诊断 | 独立资料或事先限定的诊断能区分竞争解释 |
| 信息诊断有差异，账户未改善 | 查使用位置、替代对象、换手、费用和资金约束 | 已明确一种可能改变结果的映射或执行问题 |
| 有条件增量，但证据或执行有限 | 保留限定用途候选，评估冻结观察 | 资料资格、真实执行或未见证据满足新增用途 |
| 预算耗尽、任务中止或原因未明 | 记录已做/未做、成本和未知；不自动判无效 | 主控基于决策价值和预算另行授权 |

**结束一次研究是合法动作。** 不因模板有“下一步”字段，就必须再提出一个参数、因子或组合。

## 6. 最小统计与测试规则

### 6.1 IC、分组与汇总必须写清计算单位

#### 6.1.1 先规定每一期如何统计

对当期合法特征与已成熟标签的有效配对集合，设特征为`x(i,t)`，固定未来标签为`y(i,t,h)`：

- Pearson IC：`Corr_i(x(i,t), y(i,t,h))`。
- Spearman Rank IC：对同一有效配对集合中的x与y分别取秩后计算相关；明确并列、缺失及最小有效数规则。

**用于策略或分组的事前排名，与用于相关性估计的样本内秩，是不同字段。** Spearman在有效配对中计算秩，不得回写当时候选资格、原排序、TopK或组别。报告须保留原集合与统计配对集合及其差异。

样本不足、常数特征或常数标签时返回缺失及原因，不返回0。数学上可计算不等于具有足够统计信息；小截面结果要保留样本数，不据单个月份的极端相关宣称有效。

对于11/14只产品及早期更小的合格池，固定少量组或先以逐月排名为主，不强切十组。并列、组容量和不足样本时的处理在看标签结果前固定；因子完全相同不能仅按代码强行造出“信息分组”。策略已有并列排序可原样保留，但不能被解释为预测能力。

#### 6.1.2 横截面按日期分组，再跨日期汇总

必须先在每个月当时的合格产品中排名/分组，再计算当月结果。不得将牛熊所有日期的原始动量值合并切分位，却解释成“每个时点选相对强者”。跨期绝对值区间研究属于另一问题，须另有定义，不混入当前P2。

默认流程为：当月组内按冻结权重计算收益与同期参考差额 → 形成逐月序列 → 按冻结的跨月权重汇总，P2默认逐月等权。不得在最后一步直接平均全部“日期×产品”行，让产品更多的月份悄悄获得更高权重。

组内权重、参考集合、主差额、跨月权重和纳入月份均记录。主组与参照比较使用一致的标签口径与匹配月份；不能分别在不同可用月份求均值后相减。主诊断与辅助诊断使用不同有效期时，分别标注，不伪装成同样样本支持。

不把诊断均值自动转成可交易年化。若需要展示任何复利示意，须另有明确组合与时间连接口径；本P2不因此新增资金账户。

#### 6.1.3 不完整标签不能改变事前选择

处理顺序固定：合法时点输入 → 资格/因子值 → 事前排名和分组 → 标签连接 → 有效配对诊断。

未来缺价、尚未成熟或终止资料不足，不得倒流到当时的资格、排名与权重；保留原样本，逐项说明。缺失不自动等于零收益，也不自动等于全额亏损；依据目标合同与实际资料处理。

对固定组或参考组合，标签不完整时，默认不把剩余产品重新归一化后的收益作为“完整组收益”。完整标签月份可按冻结规则纳入主差额，但须展示被排除月份与成员，明确完整案例分析的选择限制；非随机缺失可能影响结论，不能靠排除后宣称无偏。

若另展示“原组已观测部分”的描述，必须标明覆盖率、原组成员、实际分母与权重变化，不冒充原组合或可交易收益。主对照若不足以成立，就交证据不足，不另选一个更好看的匹配样本。

#### 6.1.4 描述尾部之前先定义观察单位

区分“某月组内ETF收益分布”“逐月组平均收益分布”“逐月组相对差额分布”。它们不能共用一个没有定义的下尾分位数。

P2默认围绕逐月组收益和相对差额作描述；需要尾部或置信区间时事先规定对象、样本要求和方法。样本稀少可以展示较差月份与限制，不强行给出精确尾部估计，也不能事后挑一个最好看的分位数。

**不设通用IC通过阈值、最低胜率或统一年化目标。** 高IC不等于可交易净增量，低线性相关不直接否定非线性状态价值；本轮必须说明不确定性，不等于必须做一套统计模型。

### 6.2 时间切分必须检查实际信息区间

有训练时，特征与标签成熟时点分别检查。仅按样本日期切分不足以阻止训练样本使用验证期结果；应根据标签实际跨度隔离相关样本，并记录做法。

多资产面板评价未来表现时按时间共同切分。跨资产留出与未来时间留出是不同问题，不能把前者冒充后者。

预处理、特征选择与参数估计只在各训练部分确定。连续多日的重叠未来标签不是独立观察；采用预先固定的稀疏观察或适合依赖数据的不确定性方法，并注明限制。

已有数据被用于挑选规则，就不能通过重新切分或换Agent恢复为真正未见样本。未来冻结观察也不能被反复查看后用于修改同一版本，再称独立确认。

**统计汇总与不确定性要尊重样本结构。** 行数、月份数和经济方向数分别报告，不给“月份×ETF数”直接赋予独立样本含义。若另行采用重采样，按预先规定的时间块处理，保留同期产品共同结构、实际有效性掩码与配对关系，说明块长、样本量及限制；不得随机打散单行制造精确区间。重采样不产生新的市场证据。样本不支持可靠估计时，可以只报告逐期结果、固定阶段和不确定性限制。

### 6.3 对照必须覆盖未选、未买与等待

信息诊断使用原本当时可选的样本集合，不能只看实际赢家。过滤实验要记录原候选、排除原因、替补、实际仓位与现金。

局部事件分析可以说明发生了什么，但不能把局部浮盈相加直接称完整策略因果贡献。策略增量最终比较相同资金与约束下的完整账户。

新增条件B不必先单独盈利，再进入A与A+B的限定对照；应先说明B的职责、预期改变的决策与可否定的结果。组合结论至少解释排除、替补、投入、退出或执行中哪些行为变化，以及收益、风险和成本交换。低相关本身不是增量证明，已有四格足够时不重复建设。

### 6.4 独立复核必须独立产生关键期望

保留手算边界、负向与正向输入、真实调用链、小范围实际数据重算。预期值不能直接复制被测输出；第二个Agent复述“通过”也不是独立核验。

工程正确性、数据适用性、历史效果、实时可执行性与生产权限分别验收。已知错误准确被阻断可以是工程成功，不要求所有数据都放行。

P2应补到现有测试中的最小反例：两个月的动量绝对水平不同仍按各自截面分组；前后合格产品数不同但按冻结月权汇总；最高排名产品未来标签缺失不导致其余产品晋升原名次；标签未成熟/常数截面返回缺失与原因；主组和参考可用月份不一致时不直接相减。另保留合法完整样本的手算正向测试。测试不新增策略账户或改变已冻结市场规格。

### 6.5 结论能写到哪一步，由相匹配的证据限制

下列是建议加入已有报告检查的必要条件，不代表当前已经实现校验器；不另建一个自动“因子有效”裁判。

| 实际证据或缺口 | 可写的结论 | 不得升级为 |
|---|---|---|
| 只有定义、公式和调用测试 | 计算/接口在已测范围可复算 | 有预测信息、值得交易 |
| 已有合法目标、样本与预测诊断 | 固定条件下的信息差异及其不确定性 | 净交易增量已验证 |
| 无匹配的完整账户、成本或执行口径 | 明确交易价值未验证，可引用已有合格结果的实际范围 | 扣费后可采用 |
| 只有当前固定产品池且历史选池待证 | 在该池、该时期观察到的关系 | A股ETF普遍成立、历史选池无偏 |
| 没有未参与选择的验证或冻结观察证据 | 历史支持/敏感性诊断及限制 | 已通过独立样本外确认 |
| 历史尝试记录不完整 | 选择偏差评估受限，未知部分单列 | 尝试次数为0、不存在挑选偏差 |
| 模型或参照不适配、只有高拟合或残差 | 模型描述及未解释部分 | 独特α、可精确估计的运气占比 |
| 有账户和历史对照，但尚无生产授权 | 研究候选或允许范围内的影子观察 | 获准实际交易 |

检查时核对实际ID、版本、区间、用途、数据角色和复核记录；不是看到文件名含`oos`、填了一个`verified=true`或引用了论文就放行。工程检查能够阻止缺证据的越级主张，但字段齐全不是结论充分，模型适配、选择过程与解释仍需独立复核。

证据缺口可以限制或阻断特定主张，不应因此删除整份负结果或停止全部合法研究。检查器也要测试“应拒绝”和“合法但有限的结论应允许”，不能靠一律拒绝获得高通过率。

### 6.6 复用分析工具，不接受不透明的样本清洗

若使用Alphalens或类似库，先核对实际版本、实现和参数，明确一键清洗是否先按未来标签删行再排名/分组，是否按未来收益分布筛除异常，是否从报价推断交易日历。任何行为与本地合同冲突，使用已构造的本地资格/标签表接入必要函数，或做小型适配，不让工具默认值代替数据资格体系。

保留原始样本、排除日志和清洗前后配对数。所谓“专业工具”不能替代对字段、日期、收益口径和目标依赖的核验。本版不指定安装新依赖，也不声称用户当前安装版本存在某一种具体行为；专业资料入口仅供实施时复核。

## 7. 方向指标：衡量有没有向可用系统推进

以下指标用于主控阶段复盘，不是自动投资评分，也不要求立即开发仪表盘。每项先记录适用范围、分子分母与基线；没有数据就写未测量。

| 指标 | 记录方法 | 方向要求及防误用 |
|---|---|---|
| **结论可追溯率** | 本轮作出的正式研究结论中，能定位定义、输入、目标/不适用原因、协议、基准、结果和限制的条数/正式结论总数 | 正式交付范围内应逐条闭合；纯核账不强制填写不适用因子模型。文档存在不等于链路已验证。 |
| **已知漏放反例闭合** | 已确认反例中，实际正常调用链修复并通过正反测试的数量/本轮已确认反例数 | 本轮列出的硬性漏放不能遗留后仍宣称对应入口合格；不推论未知错误全部清零。 |
| **实际接入覆盖** | 声明已迁移的消费者中，真实调用统一定义且通过相应测试的数量/声明迁移数 | 防止只贴ID标签。全部登记对象不必一次迁移，未接入明确列出。 |
| **目标与时间可解释度** | 可解释的完整、未成熟、缺失/不可成交样本数，以及原因未确认样本数 | 不是提高有效标签比例的竞赛。允许覆盖低，但不允许靠删除差样本或伪造时间变高。 |
| **决策推进** | 本轮明确保留、淘汰、补证或拒绝采用的事项及依据 | 正确的负结果是产出；不设“每月必须发现几个有效因子”的指标。 |
| **组合边际价值** | 加入对象/模块与不加入时的净收益、风险、恢复、长期落后和成本差异 | 未做完整组合只标未验证，不用相关性低替代，不直接加总年化。 |
| **独立复核与复用** | 首次复核发现的问题、最小修复次数、被后续任务真实复用的对象/测试 | 记录改进方向，不以测试数量或引用次数替代质量。 |
| **研究成本** | 所有纳入本轮范围的任务与尝试：完成、失败、中止、阻塞及未形成结论分别记录；包含模型/工具调用、计算与数据、复核、人工介入、重跑和返工 | 不只统计成功交付。费用、Token、墙钟/CPU时间与人工时间分列；未知成本写未知，不当0，也不重复计入父子任务。不能为省调用删必要检查。 |
| **执行与授权偏离** | 输入/协议意外变化、未成交或成交假设偏离、越权写入及处理结果 | 授权外写入不能接受；历史研究未覆盖的真实执行不伪装成已验收。 |

### 7.1 P2主控只盯四件事

| 本批重点 | 最小检查 |
|---|---|
| **结果能否复算** | 合法输入、定义、TargetSpec、分组/汇总与输出身份明确，关键例独立核对 |
| **样本与时间能否解释** | 原候选、排名、未来标签、缺失/成熟、有效期和跨期权重都有去向 |
| **是否形成明确取舍** | 已知、未知和支持范围区分；给出有依据的保留、归档、补证或停止建议 |
| **本轮实际用了多少成本** | 全部任务状态与尝试纳入，不只统计有结论的运行，不把未发生的节约写成成果 |

第7节其余指标按阶段启用。P2未做完整组合或真实执行时写未验证，不为填满指标自动扩大研究。

### 7.2 长期方向复盘

**我们更清楚什么值得做了吗？** 看是否形成可行动取舍，而不是增加一批术语。

**结论更可信了吗？** 看输入、时间、账户和独立复核，不只看曲线变漂亮。

**系统更容易复用了么？** 看真实消费者接入、字段身份和失败信息，不只看卡片数量。

**质量与成本交换更清楚了吗？** 同等证据标准下记录重复研究、返工和人工负担是否下降；为补齐必要能力或可靠性增加成本可以有价值，但单独说明，不冒称降本。低调用次数、更多拒绝或更多“证据不足”都不能单独证明效率提高。

## 8. 论文与增量研究的立项办法

### 8.1 用一个未知引出论文，而不是先找一批有名因子

每个候选立项先写：原方法/论文身份 → 机制假设 → 反证或失败条件 → 本地市场/工具/数据差异 → 一个主要待检验问题 → 什么结果会停止投入。

论文可以提供新假设，也可以帮助解释已有失败；不要求所有候选一开始都有完整经济理论，但不得事后为好看曲线编造确定机制。

只读摘要、读过方法/附录、部分原环境复现、本地适配实验分别记录。当前v0禁止联网和新增文献的约束保持；未来确有需要的任务单独声明联网、资料和许可范围。

### 8.2 立项前先检查是否真的缺能力

按以下顺序判断，而不是给方向随意打一个综合分：

1. 这个问题是否会改变当前实际决策或消除一个明确阻碍？
2. 已有报告、定义和测试是否已经回答；能否复用而非重跑？
3. 所需资料是否足以做限定用途；缺口是局部还是整条路径？
4. 有无足够强、足够简单的对手；结果能否否定原假设？
5. 一批有限实验能否给出取舍；调用、资料与人工成本是否可控？

任一答案不足时，转为有边界的补证、方法核对或暂停。没有新增决策价值，不因“因子很经典”就立项。

### 8.3 尝试预算和停止条件

实验前声明主要版本数、主要标签期限、允许的敏感性检查、费用路径和结果范围。范围来自问题，不自动套用v0的8路径限制到所有研究。

探索可以产生新版本，但不得删失败、重置研究家族计数或将看过结果后的协议倒填成事前冻结。多个AI并行尝试必须汇总；参数、Universe、分组、目标期限、预处理和模型选择都要留痕。

局部失败不无限扩成平台建设；资料不足不无限抓取；基准已经足够好时允许选择基准。

### 8.4 需要时另开的有限稳健性补证

**入口：** P2或已有研究已经形成可解释结果，且某项诊断可能改变保留/停止/补证的决定。正、负或不确定结果都可能有检查价值；不是只给漂亮结果检查，也不是每轮必做。先区分实现问题与市场证据，已证实错误先修，不以改参数遮盖。

**单独冻结：** 少量邻近规格及选取理由、所用数据角色、必要目标、主对照、运行预算、诊断和停止条件。沿用主定义族，不把多个窗口、阈值、分组、期限和池组合成搜索网格。若改变原问题，另记研究版本；不得倒填事前选择。

| 检查问题 | 必须报告的证据 | 不能据此推出 |
|---|---|---|
| 参数附近是否有类似结果 | 事前选定的全部局部结果，包含不利结果 | 参数平台等于不过拟合 |
| 实际排名/决策变了多少 | 冻结一种可解释的重叠或变动统计，定位关键差异期 | 几乎相同的选择是多份独立成功 |
| 尖峰或骤降由什么造成 | 大量决策变化、少数事件、成本或资料差异的证据；原因不清写未知 | 一个尖峰即可判定因子无效 |
| 是否依赖少数时期或产品 | 固定切片与贡献/敏感性，不删除坏样本改正式成绩 | 去掉大赢家后必须仍同样赚钱 |
| 数据此前参与过什么选择 | 全研究家族的尝试和信息揭示记录，含他Agent与中止任务 | 重新命名或切分后重新成为未见验证 |

可用的结论示例（仅为输出格式，不是当前研究结果）：

```text
邻近规格：局部不敏感 / 敏感 / 证据不足
实际选择变化：较小 / 较大 / 尚未定位，附度量和日期
支持证据重叠：说明与原运行共享的样本和决策
时期或产品依赖：说明增量和不利结果集中在哪里
未见确认：有，附真实用途与版本 / 尚无
当前结论：限定范围的历史支持、未见增量或仍不确定
建议：保留原版本观察 / 有界补证 / 归档停止
后续授权：未授权或关联明确合同
```

不得输出笼统的“过拟合检查PASS、因子有效TRUE”。敏感性任务不自动替换主版本为邻近赢家；改用新参数属于后续选择，须记录相应选择偏差与新增验证需要，不重置尝试史。

### 9.2 完成后交什么

报告先给一句话结论，再给“问题—方法—结果—代价—证据—取舍”。同时交付真实命令、退出结果、版本、输入与协议身份、全部尝试及任务状态、实际成本、测试范围、未接入/未核验项。

P2报告必须能从总体结论回到逐月诊断，再回到当时原始样本与合法输入；结论中分开“同池上涨”“相对信息差异”和“已验证交易增量”。原因不确定时明确未知，按第5.3节给出建议动作、重启条件和实际权限；停止或不安排下一实验可以是最终交付。

发现问题先保存最小反例、第一处分歧和受影响范围；不修改测试期望来配合错误实现，不改变策略参数挽救旧成绩。输出新目录防覆盖，保护冻结结果和他人未提交修改。

主控独立收工程与研究结论，人决定资金用途和真实采用。文件写完、测试变多、另一个AI表示认同，都不能替代实际接入与核验。
