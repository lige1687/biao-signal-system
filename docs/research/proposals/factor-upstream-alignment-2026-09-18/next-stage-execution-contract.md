## 2. 目标与非目标

**目标**：在用途获准前提下，以一个已登记动量定义（`mixed.momentum.raw@1.0.0`
→ `mixed.momentum.rank@1.0.0`）、一份冻结输入（canonical-snapshot-v2 及配套
calendar/actions，14 只、18,916 行）、一套预先锁定的诊断口径，完成
"输入与规则 → 样本去向 → 逐月主诊断 → 独立复算 → 条件结论 → 本次成本记录"
的可审验证据链。

**非目标（四组边界）**：
1. 不证明实时可用性、真实预测有效性、可交易收益或样本外稳健性；不补造
   available_at，不用事件日期/快照日期/复算日期冒充当时可得时间。
2. 不新增因子筛选、参数搜索、池优化或目标比较；raw 与 rank 若只是同一
   定义的两种表示不算两项候选，不得按结果择优。
3. 不启动 P1 四格、P3 宽度线、成本三层次系统、评估器改造、自优化 replay、
   组合研究。
4. 不新增生产 API、前端页面、调度任务或第二套状态台账；不改交易规则、
   资格闸门与冻结目录（Streamlit `src/lei_signal/ui/` 冻结）。

## 7. 成功定义（避免"安全拒绝"与"诊断完成"混同）

- **PASS_HISTORICAL_DIAGNOSTIC**：用途确认；≥1 个可计算月份走完整链路；
  全部月份与样本状态可追溯；逐期结果经独立复算；成本证据达预先约定范围；
  结论保持事后重建限制。正负结果均可通过。**PASS 表示证据链通过，不表示
  因子诊断结论通过**（防摘要截断误读，GPT 第 4 轮建议）。
- **BLOCKED_QUALIFICATION / BLOCKED_INPUT / BLOCKED_COST_EVIDENCE**：必要
  条件不满足；可完成阻塞分析与安全性验收，但主目标不得标完成；无有效
  月份时不得凭空报告判成功。
- **FAILED_VALIDATION**：实现对账/时间配对/独立校验失败；仅在原合同与剩余
  预算内返修。

通过后的标准结论句：
"在指定冻结样本、既定动量定义和明确的事后重建用途下，已完成排序诊断
证据链及独立复算，样本去向、逐期结果、适用限制和本次成本证据可审验。
该结果不证明历史当时可得、不构成真实预测验证，也不证明因子可交易或
可推广。"
