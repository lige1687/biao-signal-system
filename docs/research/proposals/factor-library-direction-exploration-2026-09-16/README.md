## 一句话结论（大白话）

我们已经有三样家底：一套登记了 81 个研究对象的定义账本、一条能把
"双均线状态和之后涨跌的关系"在真实历史数据上算清楚并诚实标注边界的流水线
（510300 上已跑完第一次），以及一批生产在用的宽度/情绪环境数据。但这些
证据各自停留在不同的可信阶段——账本只证明"定义可追溯"，510300 结果只是
单一标的的历史描述（七个年份只有两年同向，没有任何预测能力证明），宽度/
情绪数据"生产在用"不等于"研究资格合格"。下一步最值得做的不是发明新因子，
而是把已有结论的"可信度"补齐，然后用预先固定方案的同一套口径，在另外几只
宽基 ETF 上做同样的**历史**描述（预先固定方案不等于未来新数据）。宽度与
双均线是否重复信息，只针对宽度这一类候选值得先问；波动、量能是之后的第二
梯队候选；新情绪测量和外部工具整包接入当前都不值得做（这是当前适配与权限
限制下的取舍，不是永久禁令）。

## 推荐与暂缓（详见 candidate-directions.md 与 roadmap-and-next-prompts.md）

**推荐推进（按顺序）：**

1. **双均线状态的预先固定方案历史跨载体描述**（B1 的延伸）：等"证据可靠性
   v1"交付并收口后，把 510300 上已算出的"状态成立组之后平均涨得略多"拿到
   预先指定的另外几只宽基 ETF 上，用完全相同的定义和流程复算。定义已有
   （候选卡）、B1 证据链机制已有；**但新载体的计算消费者/合同适配尚待设计
   与授权**（现有真实入口绑定 510300，详见 roadmap 草案一的修订说明）。
2. **宽度与双均线的信息重叠检验（限指定对象/载体/目标）**：只在"宽度类
   候选值不值得投资"这个问题上是前置输入，**不是所有第二类因子的通用闸门**；
   其负结果也不自动降低波动/量能/排序类候选的优先级。宽度分档单位与阈值
   须按登记卡实际口径（fraction，0—1）另定，见草案二修订说明。

**明确暂缓（当前取舍，非永久结论）：**

- 新的情绪测量（文本情绪、期权隐含信息、新的调查来源）——情绪线旧交接
  标注了丰富的局部研究状态（含"冰点机会"标注与证伪清单，本轮转引未复验），
  当前缺的不是新公式而是把已有资产纳入统一研究档案；在现有叙事层权限边界
  下情绪也不能作技术判定输入（体系扩展须另行批准）。
- Alphalens 等外部分析工具的安装适配——等出现真实的横截面排序研究问题再
  启动，现在装了没有问题可答。
- Qlib 整包、FactorHub 接入、外部因子收益数据库（Ken French / JKP 等）——
  暂缓理由是**当前没有具体问题与预算**，不是因为登记表 models 为空或任何
  通用禁令；出现具体问题可先行适配调研。
- vectorbt / Backtrader / LEAN 等账户引擎——维持既有"条件触发"待办不变。
