# 路线设计、自有因子发现流程与后续任务草案

日期：2026-09-16（v1.1 按主控复核 R1–R4 修订）。【来源：执行agent探索提案，待主控复核】

# 第一部分："发现自己的因子"的轻量流程（任务D）

不是平台，是一条纸面纪律，全部挂在已有物件上（候选卡、研究合同、
experiment-report-template、尝试史记录）：

1. **从问题与机制假设出发**：每个新候选先写一句"它为什么应该有信息"
  （机制），并绑定策略体系的一层（道路/路牌/触发/过滤/环境）。机制说不清
  的公式不立项，防止"先扫公式后编故事"。
2. **候选卡先行，登记表殿后**：定义未冻结前只有候选卡（如双均线 draft-1）；
  公式/窗口/池/时点任一语义变化=新版本。**用途降级是正常出口**：预测不
  成立但描述/风险披露价值可保留，明确写出 uses 与 not_for。
3. **数据资格逐载体**：复用 B1 证据链机制（path+sha256+来源裁定+档位一致）。
  资格不合格的载体宁可剔除，不降标准凑数。
4. **事前冻结**：目标合同（TargetSpec）、对照集合、主指标（只定一个）、
  停止条件、真实运行次数预算。看结果之前写死。
5. **合成小例先于真实数据**：factor_lab 模式——手算期望值对上才碰真实
  输入（这一步防算法错，不防过拟合）。
6. **真实最小证据**：一个载体起步；描述（description）优先于预测；全表
  报告含空格子，不并样本、不删年份。
7. **脆弱性而非选优**：年份留一（leave-one-year-out）、参数邻域检查、区块
  长度敏感性（如 #5 的 L=63/126 并排）。**邻域范围与"何为不稳定"的判定
  在实验冻结时确定并注明独立依据、逐格样本量与时间相关限制**；邻域结论
  不一致时如实登记"敏感"，不是换一组邻域参数重跑。
8. **重复度检查**：新候选与既有状态的同日重合率/条件表（C2 模式）。公式
  不同≠新信息；但**重合率高也不自动等于可替代或应登记别名**——两个状态
  在多数日期相同而少数日期不同时，那少数日期可能正是价值所在；反之低
  相关也不证明有用。重复度结论必须落到具体比较集合与用途上，不设通用
  判据数字。
9. **尝试史与已见数据**：同族假设的每次运行（含失败）计数入档；已用于
  看结果/选池/调参的数据永不改叫"未见验证数据"；跨任务不清零。
10. **窗口重叠与时间相关**：相邻观察共享评价区间时（B1 的 21 日窗口），
  如实标注重叠比例（#5 工具），不把观察数当独立样本数。
11. **统计纪律**：重抽范围只表述为"假设条件下的历史敏感性"，不报"因子
  有效的概率"、不承诺任何单一指标能"证明不过拟合"；区间估计不是赢面。
12. **因子通过≠策略采用**：任何候选要进入交易，另需完整账户对照（与
  "不加入它"比）+ 执行成本 + 单独授权——三层状态（历史回测通过/冻结
  观察/生产采用）不可跳。因结果弱而修改状态定义属另行立项，不混入纠错。

# 第二部分：三条路线比较与推荐组合（任务E）

| 路线 | 内容 | 现在做的收益 | 现在做的机会成本 |
|---|---|---|---|
| A. 完善现有因子证据可靠性 | #5 可靠性工具交付 + C1 跨载体历史描述 | 把唯一真实描述证据（B1）从"单点"变成"有敏感性范围、跨载体并排"的描述；后续研究共享口径 | 推迟新含义维度；但宽度类候选在重复度未测前投资存在重复信息风险 |
| B. 增加第二类含义的候选 | 宽度条件描述、波动、量能、情绪 | 库的"含义多样性"变好 | 在 C2 重叠检验前投资**宽度类**候选，可能买到已有信息的第二份拷贝（该风险判断不外推到波动/量能/排序类） |
| C. 接入成熟外部工具 | Alphalens 适配等 | 省自建分析引擎 | 当前无真实横截面问题可喂给它；纯工具轮空转，重演"修基础设施无研究产出" |

**推荐：A 先行（#5 已在实现）、C2 的资格准备并行、B 的首个候选（C2 本身）
殿后；C 严格触发制。** 依赖关系：C1 依赖 #5 交付并收口（主控 B1 收口既定
顺序）；C2 的宽度资格审计不依赖 C1，可并行准备，其计算可复用 C1 载体链
（若已建）也可独立；C（Alphalens）依赖 C6 类问题获准——目前没有。

## 阶段一（当前，已授权）：证据可靠性 v1 落地

- **用户获得的新判断**：B1 的全期差异对年份/连续行情有多敏感——
  "510300 上那 0.7 个百分点的组间差"是稳定存在还是被个别年份/一段行情
  拉出来的，附条件性重抽范围。
- **最小交付**：stability/yearly/leave-one-year-out/overlap/uncertainty
  输出 + 中文报告 + evidence-card（按已冻结计划，不改）。
- **依赖与状态**：**时点更新（R1.5）**——本提案 v1.0 撰写时派发两次失败、
  记"待用户解锁重发"；主控同日复核时已见 `factor_evidence/` 六个模块文件，
  任务已进入实现阶段。文件存在不等于运行、交付或验收完成；后续以该任务
  实际交付为准，本提案不追踪其过程。
- **可并行**：C2 的宽度资格审计、C1 的候选载体资料预核（不同文件，无共享
  写入）。**并行边界（R4）**：真正需要隔离的是共享写入、重复统计问题与
  尝试预算；只读消费同一份冻结观察表不构成天然并行冲突，但同一数据的
  重复统计问题应归入同一研究家族计数，不得借并行重复尝试。
- **另行授权**：无（已授权）。**停止/转向**：按其计划 §4 预算与停止规则。

## 阶段二：C1 双均线状态预先固定方案历史跨载体描述（需授权）

- **用户获得的新判断**：双均线状态的描述差异是不是在多只宽基上都可见
  ——"510300 特有"与"多载体可见但年份不稳"对后续策略信任的含义不同。
  预先固定方案不等于未来未见数据，全部仍是历史描述。
- **最小交付**：2 只预登记宽基的 B1 式描述 + 与 510300 并排对比表 + 各自
  敏感性范围（复用 #5 工具，多载体适配待接口核验）。
- **依赖**：#5 交付并收口；**新载体计算消费者/合同适配方案的设计授权**
  （见草案一；这是本阶段真正的工程前置，不能由提案自批）；每载体数据
  资格预算。**阻断项**：载体证据链不合格，或适配方案未获批准。
- **可并行**：C2 宽度资格审计继续；**波动搭车（C4）不并入本阶段**——
  在 C1 载体/合同上加算波动属新增对象与假设，须独立立项授权；与
  trend.above200 的同日重合率同理另立可选小任务。不可并行：扩到第三只
  载体（等两只结果裁决）。
- **另行授权**：适配方案、载体清单、数据预算、真实运行次数（每载体
  1+1 纠错，沿 #5 预算风格，由合同冻结）。
- **停止/转向**：两载体方向均与 510300 相反 → 停止扩池，交裁决"该状态
  是否降级为 510300 局部描述"（若据此讨论修改状态定义，属另行立项）；
  **达到授权上限即停**（草案不预设任何超额容忍）。

## 阶段三：C2 宽度×双均线信息重叠（需授权）+ 条件触发的工具批次

- **用户获得的新判断**："宽度类候选值不值得投资"的第一份结构证据——
  在指定对象/载体/目标组合上，宽度在双均线之外有无增量描述信息（含
  "极端位格子样本不足"这一诚实结论）。结论不外推为通用淘汰规则。
- **最小交付**：510300 上双均线候选×指定宽度对象（对象与分档方案待批）
  的条件描述全表 + 逐格样本量与年份分布；若同批启动 Alphalens（仅当 C6
  同时获准），交付首个真实 IC 诊断。
- **依赖**：宽度序列研究级资格（覆盖窗口、成分口径、分母/预热——B200
  需 200 个有效收盘，不能默认 B1 预热长度够；科创板修复≠沪深300成员资格
  证明）；计算可复用 C1 载体链（若已建）或独立。**阻断项**：资格审计
  发现序列在可用窗口内不可救 → 如实报"资格不足"收案；**合格起点由资料
  覆盖决定，不可默认改某个年份起点即视为消除成员偏差**。
- **可并行**：Alphalens 隔离适配（不同目录）；C1 若已收口则其工具复用。
- **另行授权**：宽度资格审计范围；宽度分档方案（若用 0.2/0.8 等新阈值，
  属新增分组方案须批准并写清等号边界——已登记 three_tier 阈值为
  0.433/0.567 fraction，不能冒充）；Alphalens 安装与版本固定（0.4.6）。
- **停止/转向**：达到授权上限即停；样本不足判据在冻结时定并注明依据，
  不并年份凑数；重叠与条件差异的结论**只约束宽度类候选**的优先级，
  不据此对波动/量能/排序类候选作通用降级。
