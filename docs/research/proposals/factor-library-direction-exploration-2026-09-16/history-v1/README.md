## 一句话结论（大白话）

我们已经有三样可信的家底：一套登记了 81 个研究对象的定义账本、一条能把
"双均线状态和之后涨跌的关系"在真实历史数据上算清楚并诚实标注边界的流水线
（510300 上已跑完第一次），以及一批生产在用的宽度/情绪环境数据。但三样都
只走到了"描述历史"这一步，没有任何因子被证明有预测能力。下一步最值得做的
不是发明新因子，而是把已有结论的"可信度"补齐（并行任务已授权但尚未启动），
然后用同一套口径把双均线状态复制到第二、第三只宽基 ETF 上验证。宽度、波动、
量能是之后的第二梯队候选；新的情绪测量和外部工具整包接入现在都不值得做。

## 推荐与暂缓（详见 candidate-directions.md 与 roadmap-and-next-prompts.md）

**推荐推进（按顺序）：**

1. **双均线状态的多载体复制**（B1 的延伸）：等"证据可靠性 v1"跑完后，把
   510300 上已算出的"状态成立组之后平均涨得略多"拿到事先指定的另外几只
   宽基 ETF 上，用完全相同的定义和流程复算。定义已有（候选卡）、数据资格
   机制已有（B1 的证据链），是获得"第一份跨标的真实证据"最便宜的路。
2. **宽度与双均线的信息重叠检验**：宽度和双均线可能说的是同一件事的两种
   说法（两者都和市场冷热同步涨跌）。在做任何"第二个因子"投资之前，先用
   已登记的宽度对象回答"它是否在双均线之外提供了额外信息"。防止花钱买到
   重复信息。

**明确暂缓：**

- 新的情绪测量（文本情绪、期权隐含信息、新的调查来源）——情绪线已有丰富
  结论（冰点机会已确认、中间地带择时已被证伪），缺的不是新公式而是把已有
  资产纳入统一研究档案；
- Alphalens 等外部分析工具的安装适配——等出现真实的横截面排序研究问题再
  启动，现在装了没有问题可答；
- Qlib 整包、FactorHub 接入、任何因子收益数据库（Ken French / JKP 等）——
  当前没有收益解释模型需求（登记表 models 为空是有意为之）；
- vectorbt / Backtrader / LEAN 等账户引擎——维持既有"条件触发"待办不变。

3. 宽度对象用于研究前，是否补一次"研究级数据资格"（历史成分变更、早年
   幸存者偏差的窗口限定），需单独授权。
