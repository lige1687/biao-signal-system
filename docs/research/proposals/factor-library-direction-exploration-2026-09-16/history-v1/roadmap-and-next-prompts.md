# 第一部分："发现自己的因子"的轻量流程（任务D）

不是平台，是一条纸面纪律，全部挂在已有物件上（候选卡、研究合同、
experiment-report-template、尝试史记录）：

1. **从问题与机制假设出发**：每个新候选先写一句"它为什么应该有信息"
  （机制），并绑定策略体系的一层（道路/路牌/触发/过滤/环境）。机制说不清
  的公式不立项，防止"先扫公式后编故事"。
2. **候选卡先行，登记表殿后**：定义未冻结前只有候选卡（如双均线 draft-1）；
  公式/窗口/池/时点任一语义变化=新版本。**用途降级是正常出口**：预测不
  成立但描述/风险披露价值可保留，明确写出 uses 与 not_for。
3. **数据资格逐载体**：复用 B1 证据链机制（path+sha256+来源裁定+档位一致）。
  资格不合格的载体宁可剔除，不降标准凑数。
4. **事前冻结**：目标合同（TargetSpec）、对照集合、主指标（只定一个）、
  停止条件、真实运行次数预算。看结果之前写死。
5. **合成小例先于真实数据**：factor_lab 模式——手算期望值对上才碰真实
  输入（这一步防算法错，不防过拟合）。
6. **真实最小证据**：一个载体起步；描述（description）优先于预测；全表
  报告含空格子，不并样本、不删年份。
7. **脆弱性而非选优**：年份留一（leave-one-year-out）、参数邻域（±50%
  阈值同向才稳）、区块长度敏感性（如 #5 的 L=63/126 并排）。邻域结论相反
  = 登记"阈值敏感"，不是换一组邻域参数重跑。
8. **重复度检查**：新候选与既有状态的同日重合率/条件表（C2 模式）。
  公式不同≠新信息；与已有对象相关性极高时，登记降级为"别名/衍生"。
9. **尝试史与已见数据**：同族假设的每次运行（含失败）计数入档；已用于
  看结果/选池/调参的数据永不改叫"未见验证数据"；跨任务不清零。
10. **窗口重叠与时间相关**：相邻观察共享评价区间时（B1 的 21 日窗口），
  如实标注重叠比例（#5 工具），不把观察数当独立样本数。
11. **统计纪律**：重抽范围只表述为"假设条件下的历史敏感性"，不报"因子
  有效的概率"、不承诺任何单一指标能"证明不过拟合"；区间估计不是赢面。
12. **因子通过≠策略采用**：任何候选要进入交易，另需完整账户对照（与
  "不加入它"比）+ 执行成本 + 单独授权——三层状态（历史回测通过/冻结
  观察/生产采用）不可跳。

# 第二部分：三条路线比较与推荐组合（任务E）

| 路线 | 内容 | 现在做的收益 | 现在做的机会成本 |
|---|---|---|---|
| A. 完善现有因子证据可靠性 | #5 可靠性工具 + C1 多载体复制 | 把唯一真实证据（B1）从"单点描述"变成"有敏感性范围的跨载体描述"；所有后续研究共享这套口径 | 推迟新含义维度，但新维度在重复度未测前投资本身就有风险 |
| B. 增加第二类含义的候选 | 宽度条件描述、波动、量能、情绪 | 库的"含义多样性"变好 | 在 C2 重复度检验前投入，可能买到已有信息的第二份拷贝 |
| C. 接入成熟外部工具 | Alphalens 适配等 | 省自建分析引擎 | 当前无真实横截面问题可喂给它；纯工具轮空转，重演"修基础设施无研究产出" |

**推荐：A 先行（其中 #5 已授权未启动）、C2 的资格准备并行、B 的首个候选
（C2 本身）殿后；C 严格触发制。** 依赖关系：C1 依赖 #5 完成（主控 B1 收口
既定顺序）；C2 依赖宽度数据资格授权，可与 C1 载体链复用；C（Alphalens）
依赖 C6 类问题获准——目前没有。

## 阶段一（当前，已授权未执行）：证据可靠性 v1 落地

- **用户获得的新判断**：B1 的全期差异对年份/连续行情有多敏感——
  "510300 上那 0.7 个百分点的组间差"是稳定存在还是被个别年份/一段行情
  拉出来的，附条件性重抽范围。
- **最小交付**：stability/yearly/leave-one-year-out/overlap/uncertainty
  输出 + 中文报告 + evidence-card（按已冻结计划，不改）。
- **依赖与阻断**：派发两次失败（锁屏/剪贴板），**阻断项=用户解锁后重新
  派发**。本提案不触碰其冻结范围。
- **可并行**：C2 的宽度数据资格审计可与 #5 执行并行（不同文件，无共享
  写入）；不可并行：任何消费 B1 观察表的其他分析（避免同数据并行竞争）。
- **另行授权**：无（已授权）。**停止/转向**：按其计划 §4 预算与停止规则。

## 阶段二：C1 多载体复制（需授权）

- **用户获得的新判断**：双均线状态的描述差异是不是宽基普遍现象——
  "510300 特有"与"普遍但年份不稳"对后续策略信任的含义完全不同。
- **最小交付**：2 只预登记宽基（建议 510500+159915，代表大小盘）的 B1 式
  描述 + 与 510300 并排对比表 + 各自敏感性范围（复用 #5 工具）。
- **依赖**：#5 完成；每载体数据资格预算。**阻断项**：载体证据链不合格。
- **可并行**：C4 波动搭车计算（同链近零成本）；不可并行：扩到第三只
  （等两只结果裁决）。
- **另行授权**：载体清单、数据预算、真实运行次数（建议每载体 1+1 纠错，
  沿 #5 预算风格）。
- **停止/转向**：两载体方向均与 510300 相反 → 停止扩池，交裁决"该状态
  是否降级为 510300 局部描述"；证据链成本超预算 2 倍 → 停，先做宽度资格
  （C2）替代。

## 阶段三：C2 宽度×双均线信息重叠（需授权）+ 条件触发的工具批次

- **用户获得的新判断**："第二个因子"值不值得投资的第一份结构证据——
  宽度在双均线之外有无增量信息（含"极端位格子样本不足"这一诚实结论）。
- **最小交付**：510300 上双均线候选×csi300 b200 三档的条件描述全表 +
  空格子样本量 + 年份分布；若同批启动 Alphalens（仅当 C6 同时获准），
  交付首个真实 IC 诊断。
- **依赖**：宽度序列研究级资格（限定窗口+成分口径声明，单独授权）；
  C1 载体链（可复用）。**阻断项**：资格审计发现早年序列不可救（幸存者
  偏差无法窗口规避）→ 降级为"2020 后窗口描述"。
- **可并行**：Alphalens 隔离适配（不同目录）；不可并行：与 C1 抢同一
  观察表写入。
- **另行授权**：宽度资格审计范围；Alphalens 安装与版本固定（0.4.6）。
- **停止/转向**：极端位有效观察 <50 → 判"样本不足"收案，不追加年份；
  宽度与双均线条件重合率 >90% 且条件差异消失 → 后续"第二因子"投资
  （C4/C5 升级）整体降优先级，此为重要负结果。

## 与"证据可靠性 v1"的关系（明示）

已覆盖工作只引用不重做：年份稳定性、留一年、重叠审计、整段重抽——全部
是 #5 的冻结范围。本提案新增项（多载体复制、宽度资格、条件重叠表、
Alphalens 批次）均在该任务范围之外另列，不要求其中途扩项；#5 的预算、
方法、输入身份不因本提案改变。

## 草案一：C1 双均线状态多载体复制（阶段二）

```
【任务性质】受限研究执行：双均线候选状态在两只预登记宽基 ETF 上的
历史描述复制。不做预测声明、不调参、不扩池、不改生产。

【前置条件（不满足即停）】
1. 因子证据可靠性 v1 已完成并经主控收口（其工具可消费观察表）。
2. 本任务合同由主控另行冻结：载体清单（建议 510500、159915）、
   每载体数据资格预算（1 次构建 + 最多 1 次可定位纠错）、
   真实运行次数（每载体 1 + 最多 1 次纠错）。
3. 对象身份固定：candidate:lei.dual_ma.bull_state@draft-1 候选卡
   （不改公式）；目标与 B1 相同（P_vendor(t+22)/P_vendor(t+1)-1，
   供应商调整价，含分红财富资格维持 blocked，不另批）。

【工作内容】
- 逐载体按 B1 同构流程构建 price_basis_evidence 证据链（来源裁定、
  快照哈希、档位/data_mode 一致）；资格不合格即停该载体，不降标准。
- 用 factor_unit 管线（close_state→state_description）计算状态描述；
  用 factor_evidence 工具输出年份稳定性与整段重抽范围（L=63/126）。
- 报告：三载体（含 510300 既有结果）并排全表，绝不合并样本；

【停止条件】两载体方向均与 510300 相反→停，交裁决；证据链预算超限→停。
【边界】不跑策略账户、不做归因、不写 OKR；报告按模板含最小决策卡。
```
