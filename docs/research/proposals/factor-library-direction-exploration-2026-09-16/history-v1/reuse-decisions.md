## 1. 逐项决策

### alphalens-reloaded ——【隔离验证候选】（维持本地短名单第一优先，本轮补查上游版本）

- **能力缺口**：横截面排序研究（IC/分组/排名稳定性）在真实 ETF 数据上的
  正式分析。factor_lab 有合成版 IC，但没有真实数据消费者；自建全套分析
  引擎违反"不为自主而重写通用库"的短名单边界。
- **真实依据**：IC 经 `scipy.stats.spearmanr`（09-10 源码复核）；
  `factor_rank_autocorrelation` 不依赖分组；`filter_zscore` 涉及未来分布。
- **本轮补查（2026-09-16，PyPI）**：最新版 **0.4.6（2025-06-02）**，Apache-2.0，
  Python ≥3.10，依赖 pandas<3.0、numpy、scipy、matplotlib、seaborn、
  statsmodels、**empyrical-reloaded**（依赖链比预期重：我们环境只声明了
  numpy/pandas/requests/pyarrow 等）。发布节奏活跃（0.4.4→0.4.6 一年内三版），
  Production/Stable。
- **输入要求**：date×asset 因子值宽表 + 前向收益；价格/日历由调用方提供，
  工具自推日历不能替代项目合格日历。
- **语义差异（本地审阅已定，继续有效）**：`max_loss` 容忍损失≠质量认证；
  `demeaned=False` 不保证只多不空；小池不机械五分组；先不分组也可以。
- **复用收益**：省掉自建 IC/分组/换手分析引擎；获得社区维护的边界修复。
- **接入成本**：隔离环境+固定 0.4.6；薄适配层（对象 ID/时点/快照语义自己
  写）；独立手算小例（并列/常数/缺失）验收；重依赖链是新增环境负担。
- **决策**：**隔离验证候选**。触发条件=candidate C6（或等价的横截面排序
  问题）被授权；届时"直接参考定义+首次隔离运行"一步完成。

### Qlib / Alpha158 ——【直接参考定义】（已执行完毕，维持现状）

- **能力缺口**：新特征公式的对照来源。已完成：五类公式（ROC/MA/STD/BETA/
  RANK）源码级对照，结论"无一可直接替换本地定义；MA 类与本地距离定义可
  精确换算"。
- **语义差异**：其 BETA=价格斜率/价格，非市场敏感度；ROC 含近月（本地动量
  跳过近月）；PIT 机制限财务数据，不解公司行动到达时间。
- **决策**：**直接参考定义**，作为新候选卡（如 C5 量能类）写公式时的对照
  来源之一；不整包引入、不作底座。无新接入成本。

### FactorHub（factorhub.cn + factorhub-mcp）——【暂缓】（维持 09-14 裁决）

- **能力缺口**：外部供数与逐日逐股因子值。实测证据：scores 返回**汇总
  绩效**而非逐股评分；ETF 行情/分红、历史指数成员均空表或未证；秒级限流。
- **决策**：**暂缓**。不作为数据源接入；待供应商回答 09-14 报告 §5 的
  五个问题后再谈单链资格验收。本轮不新增任何调用。

### statsmodels / arch ——【隔离验证候选（条件触发）】

- **能力缺口**：时间相关下的回归不确定性（cov_hac）；成熟的时间序列重抽
  参考实现。
- **现状**：arch 的循环区块重抽（Circular Block Bootstrap）方法定义已被
  并行任务 #5 采纳为**方法参考**（自写 numpy 索引核心，不装 arch）——
  这是"直接参考定义"等级，正确且不重复。
- **决策**：arch 维持"方法定义参考"；statsmodels 在出现第一个真实归因
  模型（models 非空）时按 `cov_hac` 单点复用评估。此前**暂缓**。

### jqfactor_analyzer ——【暂缓】

- 短名单定位：与 Alphalens 对照阅读、二选一，不双重维护。Alphalens 证据
  更新（0.4.6 活跃维护）后，对照的必要性下降。**暂缓**，不重复维护第二套
  分析实现。

### JQData / RQData 逐股因子值 API ——【不适合当前】

- 无当前需求：本地因子由自有定义计算，外部预计算因子值会复制定义权。
  接口存在（SDK 源码可查）≠账号权限/覆盖/发布时间资格。**不适合当前**。

### OSAP / JKP / French 因子收益库 ——【暂缓】

- 仅当出现真实收益解释问题（登记 model 卡）才评估；美元/月度口径与
  人民币 ETF 日线账户的适配成本高。**暂缓**，models=[] 是有意设计。

### TA-Lib ——【直接参考定义（边界参照）】

- 需要新指标族（如 C5 若扩展到 MACD/ATR 族）时作算子边界参照；EMA 起点/
  预热语义仍按本地口径核对，不整库替换已核函数。

### vectorbt / Backtrader / LEAN / QuantStats ——【不适合现在】

- 维持既有条件触发待办（测出计算瓶颈/订单语义缺口/报告瓶颈之前不评估）。
  本提案的候选没有一项需要它们；任何候选也不得借它们扩参数搜索。
