# 买前关注清单与判断卡 · 冻结计划 v1.0（2026-09-19）

冻结依据：GPT-6 Pro 两轮实质讨论（round1_reply.txt 立场、round2_reply.txt 收敛）
+ 主控仓库核验（生命周期/字段/路由均已实证）。未经用户批准不派发、不实施。

## 总纲（GPT 冻结口径）

把已有判断资产重组为用户决策入口，链路冻结为：
候选出现 → 为什么值得看 → 还缺什么条件 → 什么情况失效 → 用户决定观察/等待/行动。
反对「新闻/因子/评分→综合推荐→买卖建议」路线。消息永远只在解释层，
不影响状态、分组或排序。判定权全部留在 Python 规则层。

## 前段（Stage 1）：关注区块（不动存储层）

- 位置：WorkspacePage 首屏区块，不新增一级路由；升级独立入口须同时满足
  「持续跨日检索/多维筛选/批量管理需求」且「区块经一次局部改进后连续两轮验收
  仍无法 30 秒内定位理解目标候选」，另案报批。
- 内容：复用 /opportunities/scan 的 actionable/waiting/blocked 与
  BuyPointCandidateDTO（state=watch/confirmed/weakened/invalidated）、
  WatchConditionDTO（price/state 型 + as_signal_rule_ids）、SuggestedPlanDTO 预填。
- 纪律：聚合层只做「引用来源或格式化展示」，禁止新增裁决字段；候选 state 与
  扫描 verdict 分别展示（blocked≠invalidated，confirmed≠可交易）；无价位条件
  不编数字；点击只打开既有预填草稿、保存须用户确认、已有计划直达不重复建。
- 消息位：预留状态位但不进消息维度；「消息不可用≠没消息」（S2 反哺原则）。
- 验收（场景式，可打勾）：
  □ 首次打开 5 秒能答「为什么关注它」
  □ 30 秒能答「还缺什么条件、何时不再关注」
  □ state 型条件无价位时无编造数字
  □ 动作闭环：关注→计划草稿预填→用户确认；已有计划直达
  □ 同一 symbol 在机会页与本区块状态可追溯同一来源字段
  □ 未新增任何买卖评分/推荐分/AI判断/消息驱动信号
- 派发建议（GPT 推荐，主控执行选择时记录）：主执行 glm-high；
  契约明确后的机械接线与样式可 flash-high。
- 用户授权点：API 聚合、前端、入口位置。

## 前段前置任务（GPT 指定，主控已核验为真实缺口）

1. **来源映射表**：每个展示字段 → 模块/字段/规则ID/适用标的/数据时点/版本。
   主控核验：scenario_id 锚定 rules/ 各入场模块（first_ma_pullback 等），
   lifecycle_id 经 plans/context.py 派生；rules.v1.yaml 有 provenance 体系
   但无 ETF 适用性标注——映射表须逐项补齐，找不到来源留空或标「未规则化」。
2. **历史状态回查能力证实**：昨日候选及其 state 能否回查。若不能，
   「失效可见」验收阻塞，不准聚合层补判——留待后段快照解决。

## 后段（Stage 2）：每日快照与跨日变化（动存储层，须单独授权）

- 新增最小 `daily_watch_snapshots` 业务表：候选级、每交易日一条、保留 180
  自然日；稳定候选身份（规则锚定身份，不只按证券代码匹配）+ 扫描范围 +
  交易日对齐；约定由收盘完整成功批次生成、同日重跑幂等；保留源字段/来源引用/
  数据时点/口径版本；页面读取不触发写库。
- 验收（场景式）：
  □ 首日显示「建立基线」，不装变化
  □ 次日给出状态/条件/阻断原因的结构化变化（文案变化不算变化）
  □ 日差只比较最近两份成功快照；断档标真实日期；口径变更重建基线
  □ 采集/写入失败不推进成功基线
  □ 候选消失显示「未返回」，不推定失效；上游失效后仍可查原因与时点
  □ 模拟跨日 + 一次真实跨日双验收
- 派发建议：主执行 glm-max（难点=身份/时间/失败与失效留存语义），
  机械迁移 flash-high。
- 用户授权点（缺一不可，代码授权≠迁移/部署授权）：storage 受保护路径改动、
  迁移范围、保留清理与恢复方案。未获批只交前段，不宣称完整 V1。

## ETF 失效语义映射（GPT 冻结清单）

| 类别 | 冻结规则 |
|---|---|
| 结构破坏 | 只映射既有引擎失效规则与结果；WatchCondition 缺失项不反向解释为失效；来源标明观察 ETF 本身还是跟踪指数；指数条件不换写成 ETF 交易价；「结构破坏必有止损价」不进合同 |
| 估值偏离 | 底层资产估值与基金折溢价拆开（后者=市价相对净值偏离）；有既有来源才展示、未实现阈值不裁决；标注「ETF差异」；展示层不得自动升级为候选失效 |
| 宏观条件 | 只引用既有结构化条件及规则结果；新闻/评论/模型推断不得生成失效条件；无来源标「ETF差异，尚未规则化」，不影响技术状态；数据缺失显示未知 |
| 止损价/目标价 | 计划执行参数，只引用既有规则产物或用户输入；未设置/未知分开标注；无止损价≠无失效条件；触目标价≠自动失效；止损触发价≠保证成交价 |

## 验收总原则

用户任务式验收替代测试数量：由非开发试用者复述「为什么看/等什么/何时失效」，
记录成功与耗时；30 秒理解指标 + 信息减负指标（10 个候选不出本区块可答三问）
+ 边界指标（零新增裁决）。
