## 执行顺序与比较纪律

核心优先，按问题依赖与资料就绪程度推进，不按S01—S05编号强制排队。当前主要决定是取得原E真实20/50宽度输入；S03/S05旧问题保持完成。S06—S10标 `SOURCE=extension`，不因某核心受阻自动扩线。

每个问题先区分描述现状、未来涨跌、下跌幅度、下跌概率和波动。连续值先保留；15/85、AAII±25、NAAIM40/100、Equity Put/Call>1记为原始规则参数，不称最佳。固定10个百分点区间用于展示，不从中挑最漂亮组推广交易。

先核问题所需资料与方法是否相配：有效日期、连续极端段、共享未来行情、缺失和可比覆盖不够时，可以完成描述与证据不足结论，不为填表硬做多变量预测。正式实验冻结端点、价格、日期全集、事件规则、费用适用性、参照、参数、预算和停止条件。连续关系与原极端关系分开，模型失败不否定所有尾部用途。

已有价格背景可包括近期涨跌、趋势、当前跌幅和波动，由每个问题选择，不强迫所有样本拟合五个字段。简单历史平均或可比普通时期参照必须保留；加入候选前后同日期、同目标、同训练预算。明确控制和未控制的信息，先报告实际量级，再报告不确定范围与反例；预测误差改善不是投资收益，也不是因果证明。

自算宽度分三种用途：可靠历史重建需要真实历史成员、价格、调整、缺失和版本；历史决策可执行还要输入当时何时能知道；固定后新记录的确认须真正在冻结之后取得。不额外要求自算指标自身首发档案。各窗口独立分母与共同分母都可以是明确的研究定义，须报告合格人数、缺失影响与双极端覆盖；共同分母不是唯一合法算法，既有冻结算法不静默改写。

合格宽度先展示连续关系，再单列原双低≤15%，随后在同一宽度低状态里核AAII确认；不要求宽度先有正结果或各输入分别赚钱。这个确认问题符合原E；普通技术触发与情绪的交互另立问题。日线信息到周末／月底行动的等待、错过机会与完整资金效果仍未覆盖。

本库没有真正新资料验证。旧历史已看过，按年代切分不会使它变成“从未看过”；跨SPY／QQQ也可能共享大部分市场变化。失败、已见历史和参数选择均入账，不能为了正结果改期限、换对手或反复拟合。

完整策略另核全部资金、现金等待、费用、错过上涨和持有／定投参照。资料审阅和信息研究不授予生产采用或交易权限。
