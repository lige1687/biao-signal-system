# 情绪因子报告格式

这是本线对现有 `experiment-report-template.md` 的用途补充，不替代它。正式结案报告落在 `docs/experiments/`，有大白话结论、登记与ARCHIVE；全部未计算／无法计算／不适用分别写清，不填零。

首页次序：一句话结论 → 因子表现表 → 相对已有信息的新增帮助表 → 现在知道什么／不知道什么 → 方向、收益、风险用途 → 完整反例 → 当前决策 → 证据附录。原值、差值、单位、基准、覆盖、范围和不确定性直接可读。

每个实际研究对象必须包含下列决策卡；有多个对象逐项写，不把整族同一判语复制过去：

| 项目 | 必须填写 |
|---|---|
| Signal | 准确ID@版本、连续值／状态、单位、依赖、观测与真实可得时点 |
| Hypothesis | 候选可能提供什么信息，什么结果会削弱它 |
| Prediction target | 方向、反转、涨跌幅、大跌、波动；期限与起止价格，未来最好／最坏变化与账户回撤区别 |
| Baseline | 普通日期本来如何、仅已有信息结果、共同有效日期；不能只报信号后涨多少 |
| Signal result | 全体、条件成立／不成立、连续完整区间的真实成绩和数量 |
| Incremental improvement | 仅基准、仅候选、基准加候选；真实差额与单位，不能用相关性冒充新增帮助 |
| Sample size | 原始日期、有效与排除、极端段、目标成熟、重叠；不要虚构独立机会数 |
| Robustness | 年代、市场状态、跨资产、合理相邻参数、日期连续相关、删单时期影响；哪些未执行 |
| Out-of-sample | 真正没有参与研究的新资料；历史分段防未来值泄漏与新独立确认分开 |
| Main regime | 有证据时才写适用时期，不事后选最好年份推广 |
| Failure regime | 完整反例、方向相反时期、缺资料区间与数据缺陷分别写 |
| Information overlap | 相对价格跌幅、趋势、波动、宽度或其他调查已知后还有多少帮助 |
| Research verdict | 只能用下面七种；限定本次对象、用途、期限、资料与基准 |

七种结论：`Stable predictive information`（稳定预测信息）、`Conditional information`（有条件的信息）、`Tail-risk information`（未来大跌风险信息）、`Volatility information`（未来波动信息）、`Mostly redundant`（主要重复已有信息）、`No meaningful incremental information`（本用途没有值得采用的新增帮助）、`Insufficient evidence`（证据不足）。没有事前有用幅度，不凭一个负数断言所有合理小幅帮助已排除。没有相对基准与新资料证据，不称稳定。

附录绑定来源、规范版本与SHA、原规则阈值、所有试验与失败、实际模型与回退、输入快照、实际命令／退出码、独立数值核验、资料质量和生产权限。方法与策略政策分开：未做账户研究则完整资金、费用、成交表“不适用”，不假造利润。
