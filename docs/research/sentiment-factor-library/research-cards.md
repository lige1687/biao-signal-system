## S01：市场宽度绝对水平

宽度是成员股票中，价格站在各自均线上方的占比。先分清“当前股票普遍很差”与“知道它很差之后，能更准确判断将来”。

| 项目 | 内容 |
|---|---|
| Signal | B20／B50／B200连续比例；独立分母与共同分母分别引用，不能静默拼接 |
| Hypothesis | 低宽度可能提供反弹或风险信息，也可能只是重复已经发生的下跌 |
| Prediction target | 原任务列5／20／60／120／252及多种目标为候选范围；当前有条件下一问仅120报价间隔期末涨跌，尚未冻结或运行，不一次铺开全部期限与目标 |
| Baseline | 下一问拟用同覆盖成熟总体与有限价格分层，具体为63日涨跌方向、20日波动高低；不声称已控制所有价格信息，最终权重及覆盖待实际资料后冻结 |
| Signal result | 美国当前成员回填不能代表历史标普500；中国旧B200的1516日整体排名关系−0.007967只作已有描述 |
| Incremental improvement | 中国旧969日同20日背景风险差范围含零；未做本卡要求的全部市场背景控制 |
| Sample size | 美国数据库11706行、11702日；有效B20/B50/B200为11694/11664/11514行，这些不是同样多独立预测证据；中国冻结2813日、2378有效日 |
| Robustness | 已核来源、分母、覆盖、单位与回填；新年代／市场状态／相邻参数预测核查未执行 |
| Out-of-sample | 无真正未见资料验证；不把历史切分自动称新验证 |
| Main regime | 暂不能归类，不依据缺资格的历史计算“最适用年代” |
| Failure regime | 现有中国旧风险结论有2024反向结果；美国当前成员回填与低覆盖是资料失效，不是市场状态失败 |
| Information overlap | 本身来自价格，需区别指数已跌很多与成员参与程度；不能直接把价格与宽度的共同变化算成情绪贡献 |
| Research verdict | Insufficient evidence（证据不足） |

准确引用：`breadth.csi300.b50.common@1.0.0`、`breadth.csi300.b200.common@1.0.0`及各`legacy_percent@1.0.0`；全A、创业板另有各自卡，不能互相替代。多窗口展示映射为`breadth.production.independent@1.0.0`与`breadth.daily_all_a.independent@1.0.0`；这些引用不自动成为合格历史美国输入。

独立分母指各窗口按自身足够价格记录计算合格人数；共同分母指各窗口使用同一合格成员集。两者都可明确研究，均应列各期人数、缺失原因、对同时极端覆盖的影响。当前历史成员身份缺口不由换成共同分母解决；共同分母也不是唯一合法宽度算法。此前条件计划若采用共同分母，那是该版研究选择，旧定义与冻结结果不静默改写。

`original_LEI_threshold`：美国20＋50同时≤15%或≥85%，200用于增强。它不是最佳阈值；中国旧43.3／56.7也不是原美国阈值。没有合格源，暂不搜索阈值或计算五期限成绩。

S01最新设计：优先真实20/50输入。可靠历史重建核真实成员、含退出者的价格、调整、缺失与版本；声称历史决策能用才另核输入可得时点，不另找自算指标自身首发。固定后后续观察再单列，当前494成员回填仍不能替代历史标普500。连续20/50及固定10个百分点分段先展示，之后单列原双低≤15；一期限120报价间隔，先问将来期末涨跌。简单描述参照为同覆盖成熟总体；条件比较仅预定63日涨跌方向与20日波动高低，分界从此前训练取，不宣称已控制全部价格信息。覆盖、时间、主差值及权重在实际合格资料取得后再正式冻结；目前效果未运行，原E账户未研究。
