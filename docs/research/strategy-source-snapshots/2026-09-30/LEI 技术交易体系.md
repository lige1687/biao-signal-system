## 第一部分 世界观：这套体系的地基
### 1.1 市场是「人性放大器」
金融市场把人性之善和之恶都放大，尤其是恶：贪婪、恐惧、漠视、短视、急功近利，都会被无限放大。

理解这一点要抓住三个机制：

**① 本方有利原则。** 每一笔买卖，买卖双方都认为自己占了便宜——我认为卖出对我有利，你认为买入对你有利，于是才有换手。所以市场反而是相对公平的：价格就是千万人利益博弈的实时结果。

**② 反身性（索罗斯）。** 因为信息本身不完备、每个人的思考不完备、性格不完备，市场上不存在完全真实的信息，所以市场是非理性的。而非理性的结局只有两个：**泡沫，或崩溃**。市场的上涨下跌都需要一个「听上去很有道理的理由」，理由不见得是真的，但只要大家都信，它就真的能推动市场——超级长牛就是靠源源不断的反身性推动的，「你不要跟他讲有没有道理」。

博主的反身性情绪循环链（一轮完整牛熊的人心路径）：

text

```plain
散漫的意见 → 散漫的偏见 → 主流的偏见 → 主流的共识 → 全市场共识（顶）
→ 散漫的反向意见 → 散漫的反向偏见 → 主流的反向偏见 → 主流的反向共识 → 全市场反向共识（底）
```

旁注三个阶段：**看不见 → 看不懂 → 来不及**。

**③ 人性之极 = 最佳交易时机。** 泡沫和崩溃这两个极端合称「人性之极」。恐慌之极的时候你不能恐慌，要思考：现在处于哪个阶段？是不是出现了人性之极？有没有买入机会？全市场疯狂的时候要客观中立。**除了人性之极，绝大多数时间不适合做交易。**

### 1.2 最核心的一条规律：价格围绕市场平均成本上下波动
这是整套体系的物理定律。我们无法精确知道市场的平均成本是多少，但可以用**移动平均线（均线）**取一个近似——「精确的错误不如模糊的正确」。

由此派生出全套体系的定义链：

+ 均线 ≈ 市场平均成本
+ 牛市 = 市场平均成本不断上升的过程；熊市 = 不断下降的过程
+ **趋势的本质 = 市场成本的运动 = 均线的运动方向**
+ 绝大多数人赚的都是趋势的钱

### 1.3 金融市场第一定律
价格波动如果不受外力作用，它将保持原有方向，**并逐渐加速运行**。

和牛顿第一定律的区别就在「加速」：贪婪让上涨惯性自然加速，恐惧让下跌惯性自然加速。（所谓价格惯性，就是常说的趋势。）

由此引出四个选股思维模型（01）：

| 模型 | 一句话 | 实战含义 |
| --- | --- | --- |
| 惯性 | 优秀的企业倾向保持优秀，平庸的持续平庸 | 投经营惯性向上的：收入规模大且稳定增长、运营利润率平稳偏高、现金流随收入同步增长。**价格惯性的变化比基本面惯性更值得重视**——等财报看到惯性变化时，股价早跌完了 |
| 动量 | 动量 = 质量 × 速度，规模越大优势越明显 | 强者恒强、弱者恒弱的马太效应。投细分行业里生意规模大、**生意惯性与价格惯性同时向上**、强于大盘的企业；估值便宜别急着捡——便宜有便宜的道理 |
| 杠杆 | 放大利润也放大亏损（100 万房、20 万首付：涨 10% 回报 50%，跌 10% 亏 50%） | 景气向上的行业选杠杆率高的，景气向下的行业选杠杆率低的（韧性强） |
| 催化剂 | 本身不改变企业素质、也不改变外部环境，只是**突然把二者连接起来**，让价值快速释放 | 七类：换 CEO、企业拆分（PayPal 从 eBay 分拆）、股票回购、并购重组、监管/法律变化（FDA 批准、关税）、产品发布、内部人增持。典型：Meta 元宇宙暴跌 77% → 「绩效年」砍成本重回广告，涨 9 倍；英伟达等来 ChatGPT 一飞冲天。**懂行业，你才知道哪些事可能成为催化剂** |


长期视角：美股百年历史中干扰无数次，但**向上的惯性从未被改变过**。

### 1.4 方法论立场：不预测，只推演
+ **图形分析不是预测，它告诉你已经发生了什么。**立足现实、展望未来，但不预判、不猜、不赌概率性事件。
+ 为什么不用浪形：千人千浪，没人说得清。全部浪形缩减成一个词——**斜率**。
+ 为什么不用趋势线：千人千线，一波行情可以有多个斜率，「跌破趋势线怎么样」不科学。趋势的强度不是直线发展，是缓和的**曲线**变化——均线就是这根曲线。
+ **「模糊正确」**：正确在**方向**，不在某一天的涨跌。谁都不知道明天涨跌，但通过均线、成本分布、抵扣价的规律，可以判断未来一段时间的运行方向。市场运行方向 = 均线运行方向 = 价格的**最小阻力方向**——均线未来往上，每一次下跌都是买点；未来往下，每一次上涨都是逢高卖出的机会。

### 1.5 观察 = 取舍：只看价量时空
市场信息太多，观察系统本质是**取舍系统**，标准是「最真实、最可靠、最直接、最及时」。符合的只有两样：**价格和成交量（额）**。这两样随**时间**变化产生**空间**变化，形成趋势。

价量时空四大要素是全部观察对象——而且 K 线图在世界任何角落、任何软件上打开都一模一样，这是它不可替代的客观性。

## 第二部分 观察系统：用什么工具看市场
### 2.1 抵扣价原理（体系的数学基础）
**推导**（以 MA5 为例）：

text

```plain
今天的 MA5 =（今 + 昨 + 前 + 大前 + 再前）收盘价 ÷ 5
明天的 MA5 =（明 + 今 + 昨 + 前 + 大前）收盘价 ÷ 5
```

两个式子里相同的项（今、昨、前、大前）划掉，立刻得到：

**明天的 MA5 > 今天的 MA5 ⟺ 明天的收盘价 > 4 天前的收盘价。**

这就是「抵扣现象」。一般化：

**MA 均线的方向，由「当前收盘价 vs N 天前的收盘价（抵扣价）」决定：当前价高于抵扣价，均线上行；低于，均线下行。**

**三条重点推论：**

1. 判断一个趋势能否向上，只需找到一根成本线、希望它一直往上走；下降趋势要逆转，必须有一根均线**拐头向上并维持**。
2. **均线什么时候拐头是可以提前算出来的**——把未来 N 天的抵扣价区间框出来（一个「方框/盒子」），找出其中的**最高收盘价**，那就是均线拐头的门槛价。未来股价只要能站上这个位置，均线就开始拐头 → 可以直接在这个价位**设买入提醒**。
3. **下行的抵扣价 + 上行的股价 = 「剪刀差」**，会让均线加速拐头。大行情开始前的「挖坑」（黎明前的黑暗），就是为了在行情逆转之初实现均线快速拐头——快速上行的均线对股价有助推作用。

**实战用法（GE 案例）**：GE 暴跌后想抄底？第一件事是算 20 天均线能不能拐头——框出未来 2～3 周 20 天抵扣价的波动范围，找最高收盘价，把「方盒子」平移到当前价下方；未来只要股价站上那条线，20 均线就开始拐头，在此设价格提醒。注意一定要**动态地看**：想象抵扣价在哪、接下来怎么走、股价要怎么走才能让均线拐上去。

**这不是预测，是预演**：对尚未发生的战局做战术演练、提前做预案，然后**在趋势的「必由之路」上等着**——它要涨要跌都必须经过这些可以算出来的关键位置。不猜不赌，你什么时候来，我就在那儿等着。

### 2.2 双均线系统：MA 做预判，EMA 做确认
两种算法的性格完全不同：

| | MA（简单移动平均） | EMA（指数移动平均） |
| --- | --- | --- |
| 性格 | **迟钝** | **敏感** |
| 拐头判据 | 收盘价 > N 天前的抵扣价（要等价格涨过 N 天前那根 K 线） | **价在线上，线向上；价在线下，线向下**（当前价权重最大） |
| 特点 | 可用抵扣价**提前推算** | 「所见即所得」，破线即拐头 |
| 角色 | **预判** | **确认** |


**组合用法（同周期叠加，如 MA20 + EMA20）**：

+ 两线同时向上 = 牛市；同时向下 = 熊市；**两线不协调、不协同 = 预警**，考虑保护性减仓。
+ 熊市底部的标准演进顺序：**股价先站上 EMA → EMA 稳定上行 → 收盘价涨过抵扣价 → MA 跟着拐头**。底部区域**先拐头的一定是 EMA**。
+ 趋势转折的两个动作——①站上/跌破 EMA，②在 EMA 稳定运行的前提下引导 MA 拐头——**恰好就是两次操作机会**。
+ 一个预判加一个确认，趋势大概率成型；再把 60、120 逐级带上来——**20 往上 → 带 60 往上 → 带 120 往上，三根都向上 = 大趋势**。

**参数**：20 / 60 / 120 三档（月 / 季 / 半年），传导顺序 EMA20 → MA20 → 两根 60 → 两根 120，「这就是一波大牛市」。

### 2.3 双均线的真正精髓：排布次序的合理性（08）
很多人把双均线系统简化成「破线拐头交叉就进出」——**这是误解**，横盘震荡里反复破线拐头会把你折磨死。精髓是：

用两组**同数值、不同算法**的均线，评估**短期、中期、长期市场平均成本的运动方向**，以及**均线排布次序的合理性**。

+ 合理的多头排布 = 短期成本在中期上、中期在长期上（黑线在红线上、红线在蓝线上）。
+ **长得凶的反弹不等于能涨**：如果反弹时红线还在黑线上方（排布不合理），市场会按内在关系重新走下来，直到排布置换合理。要把所有均线理顺成多头排列需要很长时间——这就是为什么高位的成长股暴跌后不一定马上弹回去，**它需要时间去组织**。
+ TSLA 2021 年 1–5 月的完整案例：天量成交后，收盘价跌破上方小平台最低价（= 跌破抵扣价）→ 20 均线拐头向下 → 黑红交叉不可避免 + 下跌放量（黑柱）+ 不能迅速收复 → 之后**所有不能解除双交叉的反弹都是离场机会**；4 月那轮凶猛反弹是「假动作」（短期根本无法形成双交叉）；MA 的红蓝交叉了但 EMA 的红蓝还没交叉、蓝线仍在最上（不合理）→ 反弹上去还是「出」的位置。历史上真正理顺的标志是一根跳空大涨「这样一跳」，使黑在红上、红在蓝上——**这就是重要的标志性动作**。

**推演的两个具体动作**：① 找出未来一段时间的**最高收盘价**——从那一天起 60 抵扣价将开始下移，配合上行的股价就能把 MA60 带起来；② 用矩形工具**数交易日**——例如量出「12 个交易日内，收盘价必须每天都高于相应的抵扣价，灰线才能往上拐」。条件不满足、均线分布不理想，就不买。

**趋势走强的证据**：回调一次比一次浅——第一次跌破所有均线 → 之后只碰红线 → 只碰黑线 → 红线都不碰直接上去 → 趋势越来越强，可能走向 1 点钟。

### 2.4 斜率与时钟方向：怎么描述趋势
**趋势的完整生命周期五段**：转折 → 开始 → 发展 → 极端 → 转折。开始阶段斜率较缓，**发展阶段的斜率才是真实斜率**，极端阶段斜率突然加大。斜率的变化 = **趋势强度的变化**。

**钟表方向五类趋势**（把斜率翻译成人人能懂的语言）：

| 类型 | 时钟方向 | 含义 |
| --- | --- | --- |
| 一 | 1 → 12 点 | 斜率**加速**的上涨（极度乐观、疯狂） |
| 二 | 2:30 → 1 点 | **稳定的上涨**（认可度高、乐观） |
| 三 | 2:30 → 3:30 | **横向整理**（犹豫、怀疑） |
| 四 | 3:30 → 5 点 | **稳定的下跌**（不认可、悲观） |
| 五 | 5 → 6 点 | 斜率**加速**的下跌（极度悲观） |


好处是可以脱离图形纯用语言沟通：「趋势正从 2 点半往 1 点半运行」——一句话同时说出了当前斜率和变化方向（在加速）。

**观察的三条纪律**：

1. **固定时长**：斜率 = 涨跌幅 ÷ 时间，所有品种用相同时间长度才有可比性。习惯用 **5 年**看长期斜率、**1 年**看短期斜率。
2. **对数坐标**：对数轴表达的是比率——1 块涨到 5 块和 100 块涨到 500 块，在 Y 轴上的距离一样；普通坐标会产生严重变形。
3. 趋势的斜率是**弧形曲线**，不要用一根直线去替代。

### 2.5 量：成交量就是市场分歧
+ 某一天不管涨跌，只要放出**巨大的量**，说明这一天多空分歧巨大。**没有分歧的行情不会有量。**
+ **分歧越大，未来行情的确定性越强**（推特案例：涨 30% 后突然爆量、上下巨震，而当前收盘价已让过去一年所有爆量日买入的人全部盈利——这波行情恐怕要往上走）。
+ 只关注**突变和极端**：「大量」是**小草与大树的区别**，必须非常明显。量小 = 没分歧、交投清淡，不用关心。
+ **交投清淡的行情可以走很久很久；放量暴涨暴跌的都不得长久**（持续放量 = 分歧快速化解 = 行情即将转向）。
+ 成交额比成交量更有意义——那是实实在在的金额。

### 2.6 顶底构造：判断顶底的唯一客观判据（09）
**第一原则：只研究一根 K 线的最高价和最低价**，其他信息不看。因为趋势就是被这两个价格推动的：上升趋势 = 不断出现更高的高点（HH）+ 更高的低点（HL）；下降趋势 = LH + LL。

**顶部构造**（上升趋势转向的必经两步）：

1. 建立 **lower high（不再创新高）**
2. 建立 **lower low（跌破前一个低点）**

两步完成，这（最少三根 K 线）的组合体就叫**顶部构造**。底部构造反之：先 **higher low（不再创新低）**，再 **higher high**。

**三种形态**：

+ **简单构造**：三根 K 线。
+ **复杂构造**：多根 K 线组成，lower low 可以在很远的地方才建立。其中若有**包含结构**（一根大 K 线的高低点之间包住了若干根 K 线），被包含的 K 线都**当作不存在**——它们没有破坏高和低，直接拿掉，只看突破包含结构、创立第一个 LL 的那根 K 线。
+ **极端构造**：一根创新高的 K 线直接杀出 lower low（两根 K 线）——**仍需第三根 K 线创新低来确认**。

**两条铁律**：

+ **不出现顶底构造，就见不到顶底。**两步没走完，市场不可能转向——所以涨多了心慌不是信号，跌破那根 lower low 才是。这一条的最大价值是**过滤情绪波动**：不用自己吓自己、提前动作，**路标出现后再动作永远来得及**。
+ 顶部构造完成 ≠ 一定见顶。既然创出了 lower high，就**不能再出现 higher high**——一旦后面突破原有高点，这个顶部结构**被破坏**，重新找下一个。确认趋势走完的完整条件：形成顶部构造 + 之后不再创新高 + 持续保持 LL + 持续保持 LH，直到出现另一个底部构造。

**衍生概念**：

+ **顶 + 底 = 一个波段**（顶部构造最高点连底部构造最低点）。最小波段 = 6 根 K 线（3 + 3，不共用 K 线）。
+ **M 顶 / W 底** = 顶部构造 + 底部构造的循环，跌破/突破颈线确认成形。
+ **2B 与 M 顶的区别**：2B 是创高点 A → 明显回撤到 B → 迅速创新高 C → 迅速跌破前高 A。关键差异：**2B 的 B 点不是底部构造**，A、B 之间不产生新波段（只是原波段的延续）；M 顶的 B 点是一个真正的底部构造。即：**2B 不需要完整的回撤波段，M 顶/W 底一定有**。
+ **趋势线的正确画法**：连接所有底部结构（构造与构造），中间不形成波段的位置全部忽略。
+ 顶底构造只是**路标，不是路，更不是圣杯**——**路就是均线**。路标出现只表示路况可能在变，先观察、减速、做准备，不等于马上动作。

### 2.7 关键性波动：只盯会改变趋势的波动（10）
绝大多数市场波动是**随机波动**，不需要关心。唯一值得盯的：

**可能让 MA20 与 EMA20 同时、或一先一后发生转向的波动 = 关键性波动。**

可操作判据：当某一天价格**既低于 EMA20、又低于 20 日抵扣价**，两条均线都会往下走——关键性波动发生，需要考虑对策了。反之亦然。

配套工具——**黑绿线变色 K 线指标**（11）：

+ 构成：以 20 均线组为主、60 均线组为辅的双均线 + 变色 K 线 + 两个抵扣价；设计原理 = 趋势转折三步骤 + 抵扣价原理 + MACD 强弱。
+ 颜色语义：**绿 = 上涨趋势，黑 = 下跌趋势，灰 = 不明确/可能转向**。上升趋势中没出现灰/黑 K 线之前可以完全不管市场。
+ 使用原则：**多头排列前提下，绿色做多、黑色平仓不做空；空头排列前提下，黑色做空、绿色平仓不做多；灰色不做动作**（多头排列 = 20 均线组在 60 均线组上方）。
+ 操作流程：找多头排列行情 → 找出现黑色 K 线的标的 → 等变绿进多 → 等变黑平仓。
+ 周期：日线看短期、周线看中长线；可做**多周期共振**（日 K 变绿 + 周 K 也变绿时进入，运气好能抓大行情；日内用 60 分 + 日线、15 分 + 60 分）。周期越短，趋势特征越不明显。
+ **明确缺陷**：3 点钟盘整里反复变色、杂音多；12/6 点急速反转来不及反应（算法跟随趋势，反转证据不足时不给信号）。**最适合 2 点钟上涨与 4 点钟下跌——恰好是最容易赚钱的两个方向。**
+ 两条纪律：**Trade what you see**（该进就进、该平就平、不带情绪）；**逻辑一致**（什么原则进就什么原则出）。任何指标都有缺陷，指标不能代替思考。

### 2.8 MACD 正解（17）
**名字拆开就是全部**：MA（移动平均）+ C（Convergence 聚）+ D（Divergence 散）= **两根 EMA 均线之间的聚散关系**，也就是两线距离 = 乖离率。用的是 EMA12 和 EMA26。

三条线的算法：

text

```plain
DIFF = EMA12 − EMA26          （两均线的距离）
DEA  = DIFF 的 9 日 EMA        （距离的均值）
柱   = (DIFF − DEA) × 2        （×2 只是放大显示，无实际意义）
```

零轴含义：快线在慢线上方 → DIFF 在零轴上方。

**核心理念：强度，以及强度的变化。** MACD 能描述均线由**发散向密集**转变的过程，能表达趋势转折五步骤中的后三步（交叉、排列、乖离），但**不表达前两步（破线、均线拐头）**——因为 EMA 破线即拐头，这两件事在 MACD 上显示不出来。

**最重要的观念：强度 ≠ 趋势。** 改变趋势的是破线、拐头、交叉；MACD 从设计原理上就没研究「趋势怎样被改变」。所以：

+ **死叉 = 卖点是错的**——它只表示两均线距离在缩小 = 强度减弱，趋势并没有变；
+ **背离 = 买卖点是错的**——它只表示两个时点两均线的距离不一样 = 强度不一样，不能推出趋势转变。

**两个真正有用的功能**：

1. 研究**均线的扩散与密集状态**——均线密集是厉害的位置，成本统一后会有方向选择；
2. 把差值改造成百分比：**(快线 − 慢线) ÷ 慢线 × 100**，就可以做**全市场、跨品种的趋势强度排行**（哪些标的均线密集、哪些发散、乖离多大）。

## 第三部分 预警系统：什么情况要瞪大眼睛
### 3.1 四项基本原则：大量、缺口、密集、乖离
任何趋势的转折、发展、阶段性变化，在阶段交接处都会出现**标志性动作**。四项基本原则是观察它们的总纲：**大量**（成交突增）、**缺口**（跳空）、**密集**（均线密集）、**乖离**（过度偏离均线）。它们一出现就要想到：这个趋势可能要变了，或我期待的趋势可能要来了。

### 3.2 均线密集：大行情的起点
+ **本质**：均线密集 = 市场短期、中期、长期交易成本**趋于一致** = 大家在这个位置对价格形成了共识。
+ **均线密集之后，往往是一波大行情的开始。**周线级别的均线密集，至少是一个翻倍行情（波音案例：71 → 150 平台 → 130~140 → 200）。
+ 密集区（密集成交区）= 横盘箱体 = 一个**巨大的筹码峰**，通常出现在大涨大跌之后的**斜率修正**。它是大周期趋势的**休息站**：大周期多头结构完好，密集后大概率仍向上；空头结构完好，密集后大概率仍向下。「横过来有多长，竖起来就有多高」——换手越充分，将来行情越大。
+ **判断密集接近尾声的两个量化条件**：① 时间**不少于 6 个月**（之前斜率越大、成本乖离越大，统一成本需要的时间越长）；② 均线**高度密集**——最高一条与最低一条均线的间距 **< 2%**。
+ 之后的路径：均线开始形成逐渐「张嘴」的多头（空头）排列 → 突破密集成交区 → 大概率朝该方向发展。

### 3.3 乖离率：过度偏离必然回归
+ 计算口径：用**最低收盘价**对比 **120 日 EMA**。
+ 人性机制：持有者涨幅远超预期就有卖出需求，人多了股价就会回归。**大幅偏离长期均线（如 50% 以上）的极端行情，很可能迅速转折，因为它必须回归**——什么时候回归不知道。
+ 回归只有两种方式：价格快速跌回来找均线，或者价格横着走等均线上来。
+ 实战（FOSL 案例）：偏离 120 周期成本均线超过 70%，叠加出现 2B 结构——「反弹一触即发」。

### 3.4 两个正式的交易信号（02）
体系里明确的交易信号只有两个：

**① 2B 结构**——只解决**过度偏离后的回归问题**。 有效性用抵扣价推演：股价跌到最深时 20 抵扣价在高位；形成 2B（跌破前低再收回来、突破前低）后股价回升，而此时 20/60 抵扣价正快速下移——**下移的抵扣价 + 上升的股价 = 均线强烈向上拐头**（剪刀差）→ 20 线上穿、60 线拐头 → 斜率反转。这就是大行情前「挖坑」的数学原理。

**② 下一级别的均线密集**——真正的大行情往往发生在均线密集之后。 看周线想要拐头，先要看到**日线级别**出现均线密集：所有均线走下来聚在一起、20 均线开始不跌了；密集区可能出现一个假跌破然后立刻回升。**在均线密集的位置设一个买入价格触发——它要往上走，必须经过这个位置。**

### 3.5 假动作：假突破 / 破底翻
+ 定义（假动作）：该突破的不突破、该跌不跌又涨回去、挖个坑又上去。**破底翻**的完整定义：低点 → 反弹 → 再下来 → 再破掉前一个低点 → 然后再反弹。
+ **真突破给人的感觉是「追不上」**——越追不上越不敢追，越不敢追，趋势可靠性越强。刚突破没走多远就跌回来的，大概率是**诱多**，真实意图可能向下。
+ 密集区末端假突破的**两个确认动作**（不分先后，必须全部满足）：
    1. 最近一个**波峰突破后迅速跌回**；
    2. **跌破 20 均线组，且 20 均线组往下弯曲**。 两者齐备 → 先出局，或反手做空。（向下假跌破反推：跌破波谷后快速收回 + 站上 20 均线组且向上弯 → 空单止损或反手做多。）
+ 铁律：**要走出大多头行情，必须均线多头排列配合；大空头必须空头排列配合。**

### 3.6 人性之极的量化：三个情绪指标（13）
把「别人贪婪我恐惧」变成可操作的图：

| 指标 | 是什么 | 底部信号 | 顶部信号 |
| --- | --- | --- | --- |
| **市场宽度**（主指标） | 标普 500 成分股中收盘价高于 20/50/200 日均线的比例 | 20 天与 50 天宽度**同时 ≤ 15%**（三条同时进极值区更强，可能对应中长期反转） | 同时 **≥ 85%** |
| **AAII 散户情绪** | 每周问卷调查；改造成「看涨 − 総跌 + 20 周均线」 | 极度看空（约 −25%） | 极度看多（约 +25%） |
| **NAAIM 机构仓位** | 每周调查机构风险敞口 | ≈ 40%（低） | ≈ 100%（高） |


用法：**三张图叠加找共同极值区，在极值区做交易**。两个实盘案例：2024-04-17（20 天宽度进入极值区，若 50 天也进 + 一次恐慌性杀跌 = 人性之极后的中期买点，4-19 暴跌当天入场加仓）；2023-10-26（三条宽度同时极低，一周内出现中长期买点）。

三条配套认知：

+ 没有万能指标：有时没到极值区也是人性之极，有时到了极值区也不立即反转——所以要三图**联合判断**；极值区还可能停留一段时间或二次触及。
+ **机构和散户的行为完全一致，都是追涨杀跌**——散户的对手不是机构，是你自己。
+ 作者本人做指数：**只买不卖**——低位极值区买入，高位极值区用**股指期货对冲**而不是卖出（前提：美股长期牛市基础未变；错过上涨的代价远大于回撤）。个股是另一个故事，没有「迟早涨回来」的保证。

### 3.7 宏观仪表盘：20 张图看懂美国经济与市场（14）
这不是每天交易用的，是**背景板**——「我很少关心新闻，我比较重视这些数据」。全部来自 MacroMicro，分四大类，顺序本身就是因果链：

**① 消费（占 GDP 约 70%，看「上个月」——同步/滞后）** 链条：有工作 → 有收入 → 有钱花 → 敢花钱。 五张图：就业（初领失业金=增量、续领=存量、非农年变化=趋势）、个人财务（收入/PCE/储蓄率）、房屋（成屋+新屋销量与房价，产业链最广）、汽车（销量 + Manheim 二手车价）、零售（总额、**Redbook 同店周频最及时**、非实体店）。

**② 供给（看未来 3–12 个月——领先）**

+ 建房许可 → 开工 → 6~12 个月后建成新房；**库存 = 供应 − 销售**，库存升 → 供大于求 → 价格降。
+ 耐用品订单 / PMI：工厂接单 → 采购 → 备货 → 生产约 3~6 个月，**订单与 PMI 下行 = 未来 3–6 个月总供应量下降**。2020 通胀的标准解释：供给断崖式下跌（未来半年缺货）+ 消费快速恢复（当下旺盛）→ 半年后通胀。
+ **WEI 每周经济指数**：GDP 先行指标，进入负值区或连续负值 = 大概率衰退。
+ **铜金比**（铜=工业运行，金=风险对冲 →「隐含风险溢价的工业运行」）：PPI、PMI 的先行指标；**油金比**（油=一切商品成本 →「隐含风险溢价的社会运营成本」）：CPI 的先行指标。两者 + 10 年期国债收益率 + 联邦基金利率放一张图 =「抽象化的宏观经济」——**只许选一张图了解全球经济，就选这张**（这四个都是每天 23 小时交易的大品种，价格里包含全球投资者的共识）。

**③ 利率（一切资产价格的标尺）**

+ 利率的四重身份：**资本成本**（利率降 → 钱便宜 → 杠杆扩大 → 资产价格升）、**机会成本**（5% 无风险收益是所有投资的门槛线）、**货币价值标杆**（高利率 → 货币有吸引力 → 升值）、**风险补偿**（信用差的债要给更高利率）。
+ 政策利率 vs 市场利率互为因果，但方向上：**市场利率引导政策利率；短期利率引导长期利率；3M Libor 是联储利率的先行指标**。利率倒挂（3M > 2Y > 5Y > 10Y）= 不正常的经济环境。
+ **信用利差**（CCC 级以下企业债利率 − 10 年国债收益率）快速扩大 = 违约风险大增；叠加 VIX 与标普 = 系统性风险仪表盘。

**④ 市场（情绪与行为）**

+ AAII ±25%、NAAIM 40%/100%（见 3.6）；**CBOE Put/Call > 1 常对应阶段性底部**（注意：这是真实成交、每天更新，不是问卷）。
+ COT 持仓（CFTC 大型机构期货持仓）：真实但滞后（每周五公布上周二数据）。**轧空机制**：空头持仓巨大 + 市场不跌反涨 → 空头止损平仓 = 买入 → 加速上涨 → 更多空头止损（正反馈）。**创纪录的空头持仓可能对应史诗级的上涨**。
+ 行业相对强度 = 行业 ETF ÷ VTI。**防御三兄弟（必须消费 VDC / 医疗 VHT / 公用事业 VPU）强度提升 = Risk-off 预警**。轮动套利：下跌中空可选消费 VCR、多必须消费 VDC；上涨中多科技 VGT、空公用事业 VPU。

一句话串起来：**供给（未来 3–12 月）→ 消费（上个月）→ 供需错位生通胀 → 通胀定利率 → 利率给一切资产定价 → 定价结果表现为情绪与行为 → 情绪走到极值再反转回来影响供需。**

### 3.8 市场周期、反身性与流动性风险（27/28/29）
这一节是 3.7 仪表盘背后的**理论层**：周期告诉你价格为什么会摆动，反身性告诉你为什么摆动会过头，流动性告诉你崩盘时到底发生了什么。

**① 市场周期：价格是钟摆**（视频 27）

+ 价格永远像钟摆，在「乐观 / 贪婪」与「悲观 / 恐惧」两极之间来回摆动。
+ 四类周期：**经济周期、利润周期、信贷周期、心理周期**——其中**情绪会先于基本面做出方向选择**（这正是 1.3「价格惯性比基本面惯性更值得重视」的周期版表述）。
+ 跟踪工具：FRED 上的 WEI 等高频指标（定义见 3.7 ②）。
+ 思维方式：**模糊正确**（看方向不看每一天，见 1.4）+ **期望值思维**——像「袋子里抽球」那样算：每种结果 × 各自概率再加总，而不是赌某一种结果必然发生。巴菲特「别人恐惧我贪婪」、马克·吐温「历史不会重演，但会押韵」，说的都是判断钟摆摆在哪一端。

**② 反身性原理：完整的正反馈环**（视频 28）

+ 1.1 已讲基本机制（信息不完备 → 非理性 → 泡沫或崩溃）；这里补完整环路：**认知偏误 → 改变基本面 → 基本面的变化反过来强化偏误**，形成正反馈，直到被外力打断。
+ 三个案例：**2023 年硅谷银行（SVB）挤兑**（3 月 10 日 FDIC 接管——「担心它倒闭」本身造成挤兑、坐实倒闭）；**2008 年雷曼**；**2021 年 ARK / Cathie Wood 牛市**（追捧推高业绩，业绩又吸引更多追捧）。
+ 定位：反身性是**理解市场周期与崩盘的理论框架**，与 ① 的心理周期互相印证。

**③ 崩盘的实质：流动性枯竭的连锁反应**（视频 29）

+ 表面是价格急跌，实质是链条：**先知先觉资本撤离 → 卖压出现 → 买盘后撤 → 价差拉大 → 触发 margin call 与强制平仓 → 从高风险资产向优质资产蔓延**（好资产也被抛出去补保证金）。
+ **流动性 = 钱流动的规模与速度 = 资本的动量。**作者亲身经历：2015 年 A 股崩盘、股指期货被限制后被迫卖股清仓。
+ 盘口表现：分时图买卖盘失衡、振幅与换手骤升。
+ 实战含义：低流动性小票是日内交易者的主场，**大资金要回避**（与 4.1「小股票易被操纵」互为印证）。

## 第四部分 交易策略：不同局面怎么打
### 4.1 总原则：基本面定性，技术面交易
+ **基本面不可以用来做交易**——财务数据很好的企业股价可以一直跌。基本面框架解决「值不值得打」（战略），技术面框架解决「怎样打赢」（战术）。生意不值得投的，后面的事根本不用考虑。
+ **趋势是已知信息与未知信息之间的桥梁**：基本面向上、股价反着走 = 有你不知道的事，**不抄底**；要等股价与基本面相互验证（2 点钟方向：两者同步向上）再进——这样的股票有市场共识、拿得住、最容易赚钱。
+ 交易三步清单（03）：**找到靠谱的生意 → 找到两点钟方向的趋势 → 等回撤到重要筹码峰附近买入**。前提：基本面与图形同步向上。
+ **位置 = 筹码峰 = 市场公允价格**：纵向成交量堆积的大峰 = 大量的人在这个价格换手 = 共识所在。上涨中回撤到筹码峰 = 支撑；下跌中反弹到筹码峰 = 阻力。峰越大，共识越大，位置越可靠。
+ 图形不是万能的：小股票流动性差、易被操纵，错误信号多。

### 4.2 大势三层：先定性，再下场（16）
「交易者唯一需要做的，就是评估大势」（利弗莫尔）。大势分三层：

| 层级 | 看什么 | 要回答的问题 |
| --- | --- | --- |
| **时代** | 时代红利：① 大幅提高生产效率的科技 ② 大幅提高生活水准的方向（医疗/生命科学）③ 能源革命与储能 | 下一个时代属于什么 |
| **经济** | 信用周期；MMT 时代「只有扩张没有收缩」，市场被央行主导，经济周期归根结底是**人性的周期** | 当前是扩张期还是紧缩期 |
| **市场** | 图形：价格围绕成本波动 + 趋势五步骤 + 标志性动作/人性之极 + 关键动作确认 | 当前趋势是否完好 |


判断牛市的四要素：A 股版「四轮驱动」（宏观政策积极 / 资金充裕 / 盈利增长 / 图形配合）；美股版 **ELVS**（**E**arnings 盈利 / **L**iquidity 流动性 / **V**aluation 估值 / **S**entiment 情绪——美股 23 小时全球交易，情绪是重要核查指标）。「坏消息不能阻止牛市」——把道指百年走势和历次战争叠加，方向始终是东北。

### 4.3 五类趋势、五种打法（06）
| 局面 | 判别 | 打法 |
| --- | --- | --- |
| **3 点钟横盘**（密集成交区） | 有天花板地板的箱体 + 均线密集 | **本身没有交易价值，摩擦成本极高**。只有两个点可做：① **突破前埋伏**——均线刚形成多头排列时买入，等突破（预期落空、20 组与 60 组要交叉 = 底线，破位止损；「磨磨蹭蹭不走，大概率要出问题」，出局后重新走好可以再进）；② **假突破后的快速反转**（见 3.5） |
| **12/6 点钟急涨急跌**（斜率加速） | 接近垂直 | **无法持久**：大幅偏离平均成本必回归 + 持续放量 = 分歧快速化解。**无仓不参与**（「我喜欢坐轿子，不喜欢给人抬轿子」）；**有仓在出现顶部构造之前不下车**，出现构造后也不急，等**「顶/底构造 + 可能改变均线运行方向的位置」**一起出现才动手——那个位置不一定最完美，但**确定性最高** |
| **2:30–1 点 / 3:30–5 点稳定趋势**（30–60 度） | 多头排列 + 中长期均线几乎平行 | **主战场，真正的大行情**，详见 4.4 |
| **趋势转折点** | 破线、拐头、交叉 | 转折五步骤：**破线、拐头、交叉**（决定性前三步）→ 多头/空头排列 → 大幅乖离 → 再破线拐头交叉 → 进入下一个轮回。转折的两个动作（站上 EMA → 引导 MA 拐头）= 两次操作机会 |
| **全局** | — | **趋势由小到大逐级扩散**——任何大周期的趋势变化都由小周期引起（与传统「大周期决定小周期」相反）。12 点半以上不参与，最后一棒交给别人（多周期操作方法见 4.6） |


### 4.4 主战场详解：在稳定趋势中吃回撤
以多头为例，交易要点三步：

1. **中长期均线多头排列，2 点钟左右方向运行**（短期成本 > 中期成本 > 长期成本——越早进场的人赚越多，结构本身鼓励买入持有）；
2. **价格回撤到中期（60）或长期（120）均线组附近，但不改变 MA 均线的运行方向**——价格经常击穿均线，但只要当前价仍高于相应抵扣价，那条 MA 就还在往上走（用 2.1 的抵扣价判断）；
3. **出现底部构造 + 低一个级别的多头趋势（如小时级别）**，即可进入。

经验法则：**一波趋势刚形成后的「第一次」回撤**——第一次回撤到 20 组、第一次到 60 组、第一次到 120 组附近——都是非常好的入场点（「第一次」要特别重视）。

**结构性加仓**（GOOGL 案例）：日线 2 点钟方向的标的，等**小时/半小时级别完成破线拐头交叉、出现多头排列**再动手加仓。「千载难逢的位置」= 跌下来后蓝线、红线都继续往上。

### 4.5 筹码分布（Volume Profile）：把成交量横过来看（20）
把各价格区间的成交量**横向投影**，就得到一座「横过来的山」：每一座山峰 = 一个密集成交区 = 大量换手形成的市场成本。它与 3.2 的均线密集、4.1 的筹码峰是**同一个东西的三种视角**——时间轴上均线的密集，投影到价格轴上就是筹码的山峰。

最实用的两个判断：

1. **超跌反弹的目标位**：多个山峰在上方汇聚 + 筹码整体已下沉到股价下方 → 反弹的目标就是上方那群山峰（筹码峰 = 阻力与目标位，同 5.2 第 2 步）。
2. **大行情的结构**：偏好做**接近新高 / 连续创新高**的股票——上方没有套牢盘、山峰全在下方 = 一路都是支撑，「下山」的方向轻松。**很少抄底，除非出现恐慌性的极端人性**（人性之极，见 3.6）。

典型：TSLA 财报后的走势——财报造成的筹码位移，直接决定了之后一段行情的支撑与阻力结构。

### 4.6 趋势转折与发展的五个关键步骤 + 多周期传导（18/19）
**五步骤的完整版**（4.3 表中「转折点」的展开）：下降转上升，是沿均线系统按**固定顺序**走完五步，不是一次性翻转：

① 价格站上短期均线（破线）→ ② 短期均线拐头 → ③ 短中均线交叉 → ④ 短中长均线**多头排列** → ⑤ 大幅乖离引发反向。

上升转下降是镜像五步。核心思想是**「先胜而后战」：转折没走完，就不能确认转折**——不要在第二步就宣布反转，也不要等到第五步才恍然大悟。（与 2.8 的对账一致：MACD 恰好只覆盖后三步，前两步要自己看。）

+ **2020 年疫情 QQQ 案例**：空头五步走到一半，被美联储无限 QE 打断——**长期均线向上的引力把行情拽回**，再反向完整走一遍多头五步。教训：大周期长期均线的方向是背景引力，逆着它数步骤要打折扣。
+ 实操建议：把这五步**写成自定义指标**，让图表替自己判断当前走到第几步，避免情绪干扰（与 2.7 黑绿线指标同一思路）。

**多周期交易技术**：「趋势由小到大逐级扩散」落到操作上——

+ 动态观察 **15 分钟 / 60 分钟 / 日线 / 周线**四个级别，**每级只看转折前三步：破线、拐头、交叉**；
+ 15 分钟走好可以先赌（小仓位试），形成多头排列后把视角切到 60 分钟，一级一级往上推；哪一级走不好，就在**原级别**止盈 / 止损；
+ **没有短线长线之分，长短由市场决定**——买入时不必预设持有时长，是持有周期跟着趋势级别走，不是反过来；
+ **周期共振**：小、中、大至少**三个级别在同一时间同步完成标志性动作**（如同日突破密集区 + 同步破线），意义极大，必须**第一时间反应**（以 NQ 纳斯达克迷你期货最易观察；与 2.7 黑绿线的日 + 周共振同一用法）。

### 4.7 选股：不投原则与股票池（15）
**出发点：认知边界**（达克效应四层级：不知道且无自知 → 知道自己不知道 → 知道自己知道 → 不知道自己知道）。**我不懂的事情就不做；安全边际 = 认知边际。**认知边界之外的利润是你注定挣不到的钱，错失就错失。

**三层排除（十条不投）**：

| 层 | 规则 | 说明 |
| --- | --- | --- |
| 认知层 | ① 感知不到产品/服务的不投 ② 2B 企业尽量不投 ③ 五分钟讲不清生意的不投 ④ 医疗/生物个股不投（改投 XLV / XBI / IBB 行业 ETF） | 破例条件也是「能感知」：博主投 Shopify 是因为太太开餐厅真用上了；自己不用但朋友在用（特斯拉）也算感知 |
| 财务层 | ⑤ 营收 < 1 亿美元基本不考虑 ⑥ 现金流太差不投 | 过 1 亿 = 有规模、有护城河、融资能力强（纯梦想型公司如维珍银河例外）；**可以没有净利润，但必须产生正现金流**——现金流是造血能力，最糟的是借钱填补现金流漏洞的企业；同样是负债，要分清是扩大生产还是填窟窿 |
| 政策层 | ⑦ 中小银行（政策影响大）⑧ 在美中概股（退市风险）⑨ 香港企业 ⑩ 俄罗斯企业 | 主观剔除 |


**基本面三层框架**（03，用于筛剩下的）：

+ **商业模式**：做什么生意、赚谁的钱？有无垄断/护城河？能否规模化、有无天花板？伟大产品的四个条件：**无差别的产品 + 最广泛的用户 + 自由定价 + 市场垄断**（典型：Google）。
+ **财务表现**：三类数据（收入规模与增长 / 运营利润率 EBIT margin / 现金流，重自由现金流）+ 四条门槛：**年收入 > 1 亿美元、收入年增 15%~20%、运营利润率行业内偏高、经营现金流为正（自由现金流最好也为正）**。运营利润率**不可跨行业比较**（Google 32% vs 沃尔玛 4% 无优劣，同业比才有意义）。这套筛选刻意排除讲故事阶段的股票——**故事股一旦弱于大盘，果断抛弃**。
+ **市场定价**：估值不是股价高低，是市场预期。估值高有高的道理、低有低的道理，不必与它计较。

**两类标的、两套标准**：

| | 成长股 | 非成长股（垄断龙头） |
| --- | --- | --- |
| 典型 | Shopify、搅局者（PayPal 类） | FedEx / UPS（北美快递双寡头） |
| 要求 | 增速 > 30%（美股「两年三倍三年两倍」上市惯例 → 上市后前 3–5 年仍高速增长）、现金流与收入同步、赛道市值空间大、市值别太大 | 收入 > 100 亿美元、格局已被几家瓜分、现金流/净利润/分红稳定 |
| 逻辑 | 赚成长的钱 | 稳健性投资：赚垄断的利益，「它要是倒了这个行业就不存在了」 |
| 配置 | 少部分钱做高风险 | 相当一部分资本，长期东北方向 |


**股票池 =「你自己的指数」**：每家企业过一遍基本面速查模板，符合且能理解的进池，不达标的剔除；池子长期维护。**平时不找标的，等市场大跌、人性之极、恐慌的时候，只在池子里挑**（用市场宽度、人性之极、相对强度判断时点）。持有方式：**hold and hedge，长期动态持有**。

### 4.8 做空与期权
原则上**不赞成做空**：世界任何地方不太平，钱都往美国跑（换美元、买美股），外加全球最牛大买家美联储；美股跌起来又快又狠、反弹又猛，根本拿不住空单。唯一例外：**大量持仓面临系统性风险、又不值得清仓时，用做空股指期货对冲一部分**。**期权基本不碰。**

## 第五部分 执行系统：从看懂到下单
### 5.1 交易是一门生意
「计划你的交易，交易你的计划」。一笔好的投资，在**投资计划书阶段**就已经决定了——像商业计划书决定生意成败一样。

### 5.2 交易计划五步流水线（04）
**第 1 步：识别趋势**——三个方面：

1. 方向（上行 / 下行 / 平衡）；
2. 强度（角度，越斜越强）；
3. **斜度变化**（经历了几波斜率变化，路径通常是低角度 → 中角度 → 高角度）。

配套纪律：**强趋势盯乖离率，弱趋势盯密集程度**。 可操作区间：**2 点半进 → 走到 2 点 → 1 点半 → 12 点半附近走人**。3 点附近（2:45–3:15）避免或先观察不进；12 点半左右「不要参与，最后一棒交给其他人」。

**第 2 步：识别空间**——空间 = 市场成本在不同时期的落差。下降趋势拐头向上时，**必须迅速找出下降途中曾形成的均线密集区间**：那些是上行路上的阻力 / 目标位。 （HTZ 案例：底部买入后，第一个阻力 = 上方把 20 和 60 汇在一起的位置（中长期偏中期的成本交汇点）；冲过去后，下一个目标 = 20/60/120 全部汇聚的位置。「先征服这一个空间——先拿下阵地，再拿下山头。」）

**第 3 步：识别标志性动作**——大量、缺口、假动作。它们是「介入的参考点」，像大海行船的小岛航标。

**第 4 步：行情推演，算盈亏比**：

+ 进入点（标志性动作 + 破线拐头）→ 假设失败的下部亏损空间 + 假设成功的上部盈利空间；
+ 依据：均线运行方向 + 抵扣价运行方向 + 标志性动作做攻防据点；
+ **盈亏比 = 盈利空间 ÷ 认赔空间。< 3 不参与；≥ 5 才值得做。**下跌转上升的底部若被抓住，盈亏比非常高。
+ （HTZ 算账示范：10.3 买入冲 20 均线拐头而去；失败判据 = 跌回 9.4 以下，亏损不到 10%；上方空间至少 22（两倍），盈亏比约 20 倍；到 22 若中长线完好还不见得走。）

**第 5 步：退出条件**：

+ **止盈**两种：按空间界定（到下一个均线密集区分批兑现一部分，看市场表现决定）；以及「只要赚钱，任何时候止盈都是对的」——能保证 90% 交易赚钱就不用崇拜「会卖的师傅」。长期业绩 = 赚的交易赚得多、亏的交易亏得少。
+ **止损：什么原则进，就什么原则出。**为均线拐头破线而买，拐头失败就止损——止损位可以用抵扣价算出来（跌回抵扣价方框下方 = 均线要往下拐 = 介入逻辑失效）。
+ 五步归结为两件事：**设定预期 + 设定底线** → 三种处置：预期未达标且未破底线 = 拿着；达标 = 出来；破底线 = 出来。

### 5.3 时间：推演必须带「方框」
经典技术分析解决不了时间问题，这套系统用**方框（盒子）**解决：

+ 把「抵扣价走到关键位置需要的交易日数」用矩形量出来、平移到当前价（例如：60 抵扣价还有 12 个交易日到达某位置）。
+ 表述方式永远带时间：**「未来方框这么长时间内，如果股价能站上这个位置，60 线将往上拐头。」**
+ **容差：可以提前，不应该太滞后——必须在时间内拿下山头。**
+ **为什么太早也不行**：60 抵扣价还在上方、60 线还在往下走时就往上攻，股价会因过度偏离 60 线被拽回来；你还是得回到方框的位置解决。最后结局一样——**还是要在方框里解决**。
+ 行情有千百万种变化，**一旦加上时间，推演的可靠性大大提高**：必须知道这段时间内发生什么有利、什么不利。

### 5.4 下单之后的纪律（16）
+ **验证方向的唯一办法是投入资金**（不做模拟盘——没有情绪的练习对心理建设毫无用处；哪怕买一股也要真做）。
+ **做对了的交易会「快且慷慨」地奖赏你**：进去就朝理想方向走、短时间获利巨大（想追又不敢追的感觉）。进去后市场磨磨蹭蹭不奖赏 = 大概率做错了。
+ **心理钱包**：计划分五笔进的仓位，每笔单独记账；某笔没朝理想方向走就撤回那一笔，其余保留——本质是用加仓纪律做资金管理。
+ **对立面思维**：做多的单顺利之后，立即切换到空头视角——空头最佳的进入位置，恰恰是多头最佳的止盈位置。
+ **一致性**：以什么方式进就以什么方式出；看什么东西进来，就看什么东西出去。

### 5.5 交易前只做三件事：简易交易流程表（22）
下单前把三件事定死：**① 定趋势方向；② 定进入价；③ 定退出价（止损 + 止盈）**。核心原则仍是「逻辑一致」（5.4）——用什么原则进，就用什么原则出。

把 5.2 的五步压缩成一张能填空的表：

| 项目 | 符号 | 说明 |
| --- | --- | --- |
| 趋势方向 / 多空 | — | 时钟方向 + 做多或做空 |
| 进入价 | A | 标志性动作 + 破线拐头的位置 |
| 止盈价 | B | 上方均线密集区 / 筹码峰 |
| 止损价 | C | 介入逻辑失效位（跌回抵扣价方框下方） |
| **盈亏比** | **(B − A) ÷ (A − C)** | ≥ 3 才做，目标 5:1 |
| **持仓股数** | **D ÷ (A − C)** | D = 这笔交易可承受的最大亏损（同 6.3 简版算法） |


这张表就是「计划你的交易」的最终形态。**纪律就是反人性**：上涨时人性的极是贪婪（舍不得卖），下跌时人性的极是侥幸（不止损）——表格提前填好，就是为了到时不给情绪留座位。

## 第六部分 安全系统：资金管理（05）
资金 = 兵力，「识众寡之用者胜」。三个层次，**前两条不具备，技巧再多也形同虚设**：

### 6.1 用多少兵（由盈亏比反推）
定好进入点 → 算盈利空间 → 设退出条件 → 得出盈亏比 → 反推投入。例：盈亏比 5:1（潜在盈 50% / 亏 10%），想赚 10 万 → 投约 20 万，同时接受约 2~2.5 万亏损。

### 6.2 能带多少兵（修养问题，不是技巧问题）
+ 「**你的德行和财富不匹配的部分，都会被市场拿走。**」浮亏一两万就手抖的人带不动 20 万大军；没亏过几十万，驾驭不了百万千万。
+ 高杠杆跳楼的不是杠杆问题，是修养驾驭不了超出能力的资金。修养 = 慢慢修、慢慢养。
+ **先靠本职专业赚到第一桶金**（在自己的专业领域都赚不到第一桶金，不可能靠交易赚到）；职业投资者还有第二、三份收入（债券利息、分红）维持长期蛰伏——没有机会就等，等是要消耗资本的。
+ 只用**闲钱**：亏光也不影响生活的钱；标准是**浮亏 30%~50% 不影响心情**。如果浮盈浮亏已经影响心情 = 投多了，**减仓减到舒服**。
+ 在成功的过程中获得自信，让成功成为本能——哪怕一开始只买一股。

### 6.3 怎么用兵（技巧）
**简版**（资金 < 100 万美元、持股 ≤ 20 只时，做到这条就够）：

每笔交易设好退出条件和心理可承受的最大亏损，用最大亏损 ÷ 单股风险 = 股数。 例：1000 元突破买入、跌回 900 止损 = 每股风险 100 元；能承受亏 1 万 → 最多买 100 股。

**海龟量化版**（资金较大、股期通用）：

1. **度量波动**：TR = max（当日高低差, ∣高 − 昨收∣, ∣低 − 昨收∣）；**ATR = TR 的 20 日 EMA**。波动越大的品种，仓位配比越低。
2. **头寸单位 N（风险标准化）**：**N =（账户总资金 × 1%）÷（ATR × 合约乘数）**。合约乘数：期货按品种（纳指迷你 = 20），**股票 = 1**。意义：让市场正常波动造成的账户波动不超过 1%。例：账户 100 万、纳指 ATR ≈ 250 点 → N = 10000 ÷ (250×20) = **2 手**。
3. **持仓硬上限**（不同品种的 N 各自单独算）：

| 类别 | 上限 |
| --- | --- |
| 单一品种 | **4N** |
| 高度关联品种合计（纳指 + 标普） | **6N** |
| 松散关联品种合计（原油 + 铜） | **10N** |
| 单一方向合计（同做多/做空） | **12N** |


4. **降级规则**：账户亏损超过 10% 后，新头寸按当前资金 × 80% 计算 N，依此类推。

**对冲**：碰到系统性风险，拿出一部分资金做**指数期货对冲**；没有对冲手段基本上就是在裸泳。

### 6.4 股指期货：对冲与投机的正规工具（21）
+ **为什么存在**：为对冲一篮子股票的系统性风险而设计；保证金杠杆天然吸引投机。比现货**多交易约 16.5 小时**——期货是全球情绪的出口（这也是 3.7 ②说「这些 23 小时交易的品种价格里包含全球共识」的原因）。
+ **品种**：美股四大股指期货——标普 **ES**、纳指 **NQ**、道指 **YM**、罗素 **RTY**；小资金用微型合约 **MES / MNQ / M2K / MYM**。
+ **期货特有的两个数据**：**持仓量（open interest）= 多空对垒的「总兵力」**；**成交量 = 开战后的「伤亡人数」**。经典模式：**持仓量堆高 → 放量 → 在交割日决出方向**——那个方向往往就是随后的趋势方向（2020 年 3 月交割日见底是标准案例）。
+ **配置打法**（衔接 6.3 的对冲与 4.8 的做空态度）：ETF 出现后，**「大仓位 ETF + 小仓位股指期货」**成为完整配置——现货吃长期趋势，期货做对冲与短线投机。
+ **宏观提醒（SPX / EPS / CPI 三线长期图）**：高通胀 + 高利率的环境下，即使 EPS 上涨，指数也能横盘十年（70 年代 CPI 曾达 14.8%）——估值压缩可以吃掉全部盈利增长（对应 4.2 经济层与 3.7 利率标尺）。

### 6.5 ETF：工具、相关性与组合配置（26）
+ **工具层**：用 etfdb.com 查任何 ETF 的分类、持仓、**资金流（Fund Flow）**、相关性与**重合度**——例如 XLK 与 QQQ 重仓股 47% 重合，两个都买等于在同一批股票上重复下注。
+ **对冲层**：用**负相关 ETF** 做对冲（DRV / REK / SOXS / EPV / SJB / UVXY / SARK / UVIX 等，相关系数约 **−0.69 ~ −0.74**），适合不想碰杠杆期货合约的投资者。
+ **配置层**：用 **Lazy Portfolio**（如全天候组合）+ Portfolio Visualizer 做回测，得到一个不依赖主观判断的底仓。
+ **认知层**：分清**市值加权**（头部权重越涨越大，指数天然越来越集中）与**等权重**的区别，知道自己的 ETF 到底在暴露什么。

## 第七部分 心法：能不能守住系统
### 7.1 初学者 vs 顶尖交易者：六组对照（12）
| 初学者 | 顶尖交易者 |
| --- | --- |
| 短线找感觉、追短期收益 | 长期机会、等了多时的机会 |
| 资本不够就把股市当唯一收入（过度紧张、心态失衡） | 先有第一桶金 + 债券/分红等外部收入支撑蛰伏 |
| 凭感觉、听消息、乱交易 | 成熟理念 + 经市场长期考验的策略 + 懂时机 |
| 只看胜率和相对收益（「今年赚了 50%」） | **看盈亏比和绝对收益**（承担 10% 风险博 50%+；「今年净赚 100 万」） |
| 太急、没耐心、赌行情 | **做假设、做推演**：预想最糟 + 最理想两种场景，Beyond the curve（走在曲线之前） |
| 被别人观点左右、被自己固化的观点束缚 | **靠事实证明、让数据说话、让策略自动运行**；「在这个市场上，最好是没有看法」 |


### 7.2 止损的三行决策表
| 前提（买入假设） | 底线 | 处置 |
| --- | --- | --- |
| 满足 | 未破 | 继续拿着 |
| 不存在了 | 未跌破 | 不妨等一等 |
| 不存在了 | 已跌破 | 认亏出来 |


一句话：**满足前提、不破底线就继续；不满足前提、跌破底线就止损。**绝大多数人的亏损 = 没有底线，或有底线跌破也不认输。

### 7.3 几条用代价换来的铁律
+ **尊重图形**：当图形与自己的预期相反时，尊重图形的方向——「总有一些事情我不知道，而图形里已经包含了这些信息」。（博主十几年前重仓死扛「我没有错，市场错了」，逢低加仓，最终财报证明他错了，惨败出局，至今没涨回割肉位。）
+ **善战者，胜于易胜者也**；知可以战与不可以战者胜——只打容易打赢的仗，像猎人：高手不在枪法，在于**靠得足够近再开枪**。**高手最大最强的素质就是等。**
+ **有预期、有底线、有计划，最重要的是依计行事**——打开财富之门的金钥匙。
+ **不见兔子不撒鹰**：路标（顶底构造、标志性动作）没出现之前，沿原来的路正常行驶，不做多余动作。
+ **完全的胜利不存在：战略必须完整，战术必须能让步。**盈亏比要求 5:1 是战略高标准（为误差留空间），实际拿到 3:1 甚至 2:1 都不算失败。**不要去抓最初和最后 1/8 的利润**——做趋势交易，**掐头去尾吃中间**，给自己容错空间，追求模糊正确。不猜顶（见顶一定有顶部结构），看迹象：大量、缺口、2B 出现，趋势大概要结束（至少斜率要变）。
+ **赚大钱靠大波动中坚定的信念**（利弗莫尔）：纯粹依据图形赚不多也赚得辛苦；真正赚大钱 = **拿一笔亏光不心疼的钱，找一个符合时代红利的好生意，买进去就不管了**——水涨船高。你要能忍受向下的波动，才能获得向上的波动；**不要试图把面条拉直了吃**。

### 7.4 Livermore 启示录：五期拼成完整心法（EP1–EP5）
EP2（视频 16）的「评估大势、用真金白银验证、战略完整战术让步、大波动中的坚定信念」已并入 7.3；这里补齐其余四期：

**EP1 投机的本质（视频 30，系列总纲）**

+ 交易的对象是**亘古不变的人性**；规律来自群体在关键价位的趋利避害——这就是图形为什么有效的根源。
+ **「涨跌总有原因，我 14 岁就从不问为什么，40 岁依然不问」**：先看到事实（异常的涨跌）立即行动，原因事后才知道。对应四词框架：**不闻不问、动态推演、交易计划、想好出现什么情况怎么办**。

**EP3 最小阻力方向（视频 23）**

+ 最小阻力方向 = **均线运行方向**（同 1.4、2.3）。
+ 用计划（推演、预期、底线）把错误框在可控范围内，用图形确认最小阻力方向；**框架被突破时果断转向**，不要跟自己的框架谈恋爱。
+ 方法不难，难在执行——**最终输赢取决于性格**。

**EP4 截断亏损，让利润奔跑（视频 24）**

+ 投机者最大的敌人是**内心的希望与恐惧**；专业者与业余者的差距在**态度**而非技巧——「专业者力求行事正确甚于赚钱」。在华尔街想赚快钱买车买游艇的人无一例外都亏了；**抱希望就是赌博**。
+ 盘面：盯住**领导股转弱**给出的提前量（领导股先见顶，大势随后）。
+ 逃顶只有两个位置：涨幅巨大后的**破线拐头**，以及**回档的第一时间抛出**——绝不在最高点逃顶（对应 7.3「不抓最后 1/8」）。
+ 现实基准：股市 **7 亏 2 平 1 胜**。

**EP5 以事实（而非感觉）为交易依据（视频 25）**

+ 普通投资者没有内幕、没有媒体影响力、没有资金优势，唯一的优势是**只依据事实行动**。
+ 把「事实」拆成两种：**状态变化**与**结构变化**——重点识别**结构性变化**（趋势级别的改变），跟随大概率方向，把感觉沉淀成可重复的交易习惯。
+ **不能把赌注押在毫无根据或意料之外的事情上。**
+ 「火车与铁轨」：跌破底线必须先下车，不要与市场和人性对抗。
+ 金句：**「凡是靠运气赚来的钱，最终都会凭实力输回去。」**

## 第八部分 实盘操作手册
### 8.1 一笔交易的完整流程（SOP）
1. **大势定性**：时代 / 经济 / 市场三层 + ELVS → 决定整体仓位倾向；
2. **选标的**：只从自己的股票池里找（不投原则已筛过；基本面定性 = 好生意 + 2 点钟方向 + 基本面与图形同步向上）；
3. **读趋势**：对数坐标 + 固定时长（5 年/1 年），钟表方向定位；确认处于可交易类型（2 点/4 点，或密集区末期）——3 点横盘主体和 12/6 点加速段不做。多周期对照（15 分 → 60 分 → 日 → 周，每级只看破线拐头交叉），三个级别同步完成标志性动作 = 周期共振，第一时间反应；
4. **等信号**：密集后多头排列的埋伏点 / 2B / 稳定趋势回撤 + 底部构造 + 小时级别多头排列 / 假突破反转；
5. **做推演**：抵扣价框出未来 N 个交易日的区间 → 得到「必由之路」关键价位，设价格提醒；数好「必须守住抵扣价」的交易日数；
6. **算账**：进场依据（标志性动作 + 破线拐头）、止损位（拐头失败 = 跌回抵扣价方框下方）、目标位（上方均线密集区 / 筹码峰）→ 按 5.5 流程表填 A/B/C：**盈亏比 (B−A)/(A−C) ≥ 3 才做，目标 5:1**；
7. **定仓位**：心理最大亏损 ÷ 单股风险 = 股数（大资金用 N 单位法）；检查 4N/6N/10N/12N 上限；
8. **进场**：Trade what you see，不带情绪；进场后时间窗内必须「拿下山头」——市场磨磨蹭蹭不奖赏 ≈ 方向错了；
9. **持有**：满足前提 + 不破底线 = 拿着；到目标 = 分批兑现；前提消失 + 破底线 = 认赔；加仓用心理钱包分笔，每笔独立结算；
10. **离场**：也要等标志性动作（均线拐头 + 回撤不过前高 = 止盈点）；指数仓位在高位极值用期货对冲而非卖出。

### 8.2 全体系量化数字速查表
| 数字 | 含义 |
| --- | --- |
| 20 / 60 / 120 | 双均线参数（MA + EMA 同周期叠加），月/季/半年 |
| 5 年 / 1 年 | 长期 / 短期斜率的固定观察时长 |
| ≥ 6 个月、均线间距 < 2% | 均线密集成立的两个条件 |
| 偏离 120EMA 50%+ | 乖离过大，必有回归（FOSL 偏离 70% = 反弹一触即发） |
| 2:30 → 12:30 | 买入持有的可操作时钟区间；3 点附近与 12 点半之后不做 |
| 盈亏比 < 3 不做、目标 5:1 | 交易门槛；战略 5:1，战术拿到 3:1 也算成功 |
| 85% / 15% | 市场宽度极值区（50 日与 200 日同入 = 中长期反转） |
| ±25% | AAII 看涨 − 看跌极值 |
| 40% / 100% | NAAIM 机构仓位低 / 高 |
| > 1 | CBOE Put/Call 比率的底部信号 |
| 1%、ATR(20)、4N/6N/10N/12N、亏 10% → 按 80% 算 | 海龟式风险量化全家桶 |
| < 100 万美元、≤ 20 只 | 简版资金管理的适用范围 |
| 收入 > 1 亿美元、年增 15–20% | 基本面门槛 |
| 成长股增速 > 30%、非成长股收入 > 100 亿 | 两类标的的标准 |
| 浮亏 30–50% 不影响心情 | 「亏光不心疼」的仓位标准 |
| (B−A) ÷ (A−C) ≥ 3；股数 = D ÷ (A−C) | 简易交易流程表（A 进入、B 止盈、C 止损、D 可承受亏损） |
| 持仓量堆高 → 放量 → 交割日 | 股指期货决出趋势方向的标准模式 |
| 相关系数 ≈ −0.7（−0.69 ~ −0.74） | 负相关 ETF 对冲组合（DRV / SOXS / UVXY 等） |


### 8.3 体系的失效与磨损（必须记住的边界）
+ **3 点钟盘整**：双均线反复交叉、变色指标反复打脸——这段行情本来就该不做，硬做就是被折磨死。
+ **12/6 点急速反转**：指标和信号来不及反应——所以加速段只处理持仓、不开新仓。
+ **极值区不是开关**：市场宽度到 85%/15% 可能停留、可能二次触及；三指标要联合判断。
+ **顶部构造会被新高破坏**：信号是动态的，被破坏就重新找下一个，不要抱着旧信号当圣杯。
+ **个股没有「迟早涨回来」**：只买不卖 + 高位对冲的做法只建立在「美股长期向上」的前提上，个股不适用。
+ **任何指标都有缺陷，指标不能代替思考。**
+ **流动性是隐形前提**：崩盘的实质是流动性枯竭的连锁反应（3.8 ③）——低流动性小票大资金回避；对冲工具（股指期货 / 负相关 ETF）要在风平浪静时备好，别等崩盘了才找。
