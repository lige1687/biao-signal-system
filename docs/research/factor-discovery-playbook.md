# 从金融现象到可验证用途：AI因子发现工作指引

2026-10-18｜适用于新选题、候选扩展和新增用途。旧冻结实验保持原约定。本指引把现行规范落实到开题工作，不另建定义库、实验账本或研究平台；版本仍以[现行规范索引](/Users/yongbiaoli/Desktop/lei-signal-lab/docs/research/current-standards.json)为准。

## 先回答值得研究什么

**先记录一个可核的金融现象，再提出能被削弱或推翻的解释，最后决定用什么指标检验。** 可靠的经验观察、理论预期但尚未观察确认的现象都可以起题，分别标明证据和待检验预测；机制暂不确定就标为假设；不要求先有完美理论，也不能看到漂亮曲线后把故事写成事前理由。

用户已确认本工作顺序：金融现象和竞争解释 → 按具体用途比较收益、风险及其他实际价值 → 根据结果补证据缺口；借鉴RD-Agent将每步的理由、输入、实现、结果和下一步相连。先复用已有研究和原负责人产物；本指引不接管其他对话的任务，也不因流程补充重跑已有实验。

AI先查原件、现有定义、相近实验和负责人。用少量候选比较“为什么值得测”，不按数量交指标。主控在既有授权内决定常规方法、计算和反例；只把无法还原的核心策略含义、新方向授权、必要资料或真实资金风险问题交给用户。

## 一次研究只保留一张开题记录

将以下内容放进本任务已有计划、研究合同附件或raw记录，复用已有文字与链接；不要另开总登记表。学习/审查任务不强行生成实验合同。正式效果计算前采用现有冻结入口；不得向严格JSON合同随意添加不被支持的字段。

| 要写清的内容 | 主控应作出的判断 |
|---|---|
| 现象与出处 | 什么人、资产或制度中出现什么现象？原始资料、日期、对象及反例在哪里？事实与解释分开。 |
| 金融解释与竞争解释 | 可能涉及风险承担、信息消化、行为、交易限制或资金需求；为何在所选期限影响这个决定？至少指出一个替代解释，以及什么可观察结果会削弱主解释。来源不足可先查资料，不直接算收益。 |
| 指标与机制的连接 | 指标测到了解释中的哪个部分，遗漏什么？可预期的方向或条件是什么？原策略、研究近似与独立候选分别标明。 |
| 分类与重复 | 分别填写资料来源、假设机制、决策用途；查相近定义ID@版本、公式依赖、已看历史和既有结果。归为数学等价、同现象另一测量、或待核补充信息；写保留或淘汰理由。 |
| 用途与最有挑战性的简单对手 | 选择下面对应行；同对象、日期、资金和成本口径比较。候选不必单独赚钱。先指定主要用途，不能收益不佳后改口宣称风控成功。 |
| 证据与扩展理由 | 对象、共同日期、不同事件/趋势段、结果成熟及配对对照支持是多少？同日共同变化和连续窗口是否重复？缺什么才扩什么；按当时可知规则选对象。 |
| 检验与停止 | 固定公式、观察/行动时点、资料、方法、期限、基准、权重、成本、尝试历史和预算。没有有依据的最低有用幅度就报告真实差额及不确定性，不事后补及格线。 |
| 结论与恢复 | 输出有帮助、当前未支持、证据不足或资料/定义阻塞；准确限定用途和范围。写为什么关闭，或缺什么可恢复。新任务仍继承相关家族的尝试历史。 |

分类允许一对多：同一资料可以支持不同金融解释；不同资料也可能测量同一个现象。相关性低不证明金融机制独立，相关性高也不自动证明完全无增量。重复表达可以因测量可靠性或模型表达需要保留，但只能声称相应用途的帮助，不变成多份独立证据投票。

复用多份报告前，先核定义ID/版本、公式起算与相等/未知边界、资料资格、信号与成交时点、日期、权重、单位和费用，标为同一对象、依赖它的政策或同家族旁证。同名不代表同一因子；不同日期的财富、费用和风险不能混作准确归因。把差别和可支持结论写进本题原记录，不另建登记表。[20日颜色因子实案](/Users/yongbiaoli/Desktop/lei-signal-lab/.codex/worktrees/personal-audit-coordination-20261018/docs/experiments/dual-ma-factor-worked-case-2026-10-18.md)已发现起算、相等边界和统计日期的实际差别。

## 汇报结果前先说明研究了谁

任何研究结果的首屏或聊天摘要，先写研究对象范围（universe）：股票、ETF、指数或其他对象；名单来源与名单日期；当前固定名单还是历史逐时成员；计划纳入数、实际有资料数及缺失处理；观察期与资金统计期；逐对象结果如何汇总、初始分配和后续调钱/恢复权重规则。用一句话指出外推范围。复用旧结果也必须带上，不能只说“A股/美股”和起止年份，或把几百只股票合计结果讲成一个可管理的个人账户。

本轮仅修正已证实的遗漏：20日颜色案例是2026年当前沪深300名单300只及IVV股票持仓504项的历史回看，有报价300/502；各市场初始同额分配、逐股执行、资金不跨股调配，最后相加。历史成员和退出者未补齐。上述范围不因讨论流程而扩大，原表和旧实验保持。

## 按用途挑对手和评价，不能统一只看收益

| 本轮用途 | 必要的简单对手（按问题取适用者） | 主效果与必须并列的代价 |
|---|---|---|
| 选对象、买入、持有或退出 | 原方法；合适的简单持有或固定投入 | 扣成本后的财富变化、亏损幅度、恢复时间、未参加和没等到的机会、实际参与程度 |
| 提前识别风险 | 历史风险发生频率、已有简单波动或风险信息 | 风险判断是否更准确；漏报与误报、稳定性、提前量；尚未定义行动时不填账户收益 |
| 用信息减少损失 | 原策略；事前固定较低投入或其他适合的简单风险规则 | 少亏多少、少赚多少、恢复与参与程度、现金和交易摩擦；不以几乎空仓的低回撤证明能力 |
| 改善组合 | 原组合；适合问题的简单资金分配 | 同一笔资金的总效果、共同下跌、集中风险和费用；不能把独立账户收益直接相加 |
| 降低操作负担 | 效果相近的简化流程 | 真实交易/人工判断/维护次数和耗时，失败恢复与遗漏代价；未知成本填未知 |

价值不限于上述五类，也可包括判断更一致、依据更清楚、资料缺失时更可靠，以及排除无帮助方向。每项须指定使用者、原办法和可观察差别：例如同一案例的判断分歧、能否定位结论来源、缺资料时是否错误发出判断、是否因此停止一项重复研究。只有报告更长、解释更顺或模型更赞同，不算价值证据；未测价值保留未评价，不能用来补救原主用途的负结果。主观可用性需实际使用者反馈，规则文字和合成演练只证明各自检查范围。

规则减少交易或让持仓更稳定时，另核帮助是否来自新增信息、较少行动、等待或投入变化。没有相应对照，只声称观察到的帮助，不能说成独特机制；只有本题确需辨别且已获授权时，才设计原简单规则加等待/暂不动作的对照，不按降频百分比自动开新实验。

先核“信息有用”和直接核“行动有用”都可以，不强制先预测、再交易的统一顺序。主用途明确后可同时预定辅助用途，但不根据结果挑一个较好用途当原主问题。风险和收益互有取舍时展示交换，不替用户事后发明综合分数或风险偏好。

风险动作应在本来存在可参与机会或持仓风险的场景中，与可执行对照比较。规则实际改变了参与、退出或投入，即可评价避免的损失及放弃的上涨；规则在本批机会中没有改变任何行动时，其保护效果标未评价。事后按全期平均仓位/未来波动配平，只能帮助解释，不能当时可执行基准。不能把最大资金跌幅直接乘全期平均投入比例来伪造风险对照；比例的分母和随时间变化的持仓须按真实资金路径处理。单次最深跌幅受少数路径影响，须配合亏损/恢复分布和具体事件，不只选最漂亮一段。

## 扩样本先说明要补哪一种证据

| 缺口 | 有意义的扩展 | 不成立的替代 |
|---|---|---|
| ETF之间如何选择 | 不同底层风险、流动性与交易条件的合格产品；预先按金融理由分组 | 同指数不同代码凑数量；看完收益才选池 |
| 同一ETF何时持有/减持 | 更长且可比的不同市场阶段、足够的合格事件、规则固定后的未来观察 | 增加同涨同跌的ETF就宣称增加独立周期 |
| 某类交易机会是否有帮助 | 全部合格起点、未触发/未成交及原因；按趋势段和共同市场冲击说明依赖 | 只保留成交或盈利机会，连续20日窗口当独立事件 |
| 股票之间的差异 | 当时可知成员或当时上市/规模/流动性规则，保留退出者和缺失原因 | 用今天的幸存/热门名单代表当时全市场；个股结果直接代替ETF证据 |

报告产品数、日期数、事件支持和依赖结构，不制造一个伪精确“独立样本数”。不存在统一至少8/80只或30笔即可可信的标准。依据问题和支持选择有限估计、完整案例描述或仅资料资格核查；扩大名单也不能修复未定义的原策略。

用户认可的三个扩展方向分别保留：增加可比市场阶段和事件、增加不同底层风险的对象、补当时成员及退出者。新任务按问题选必要方向，在原合同附件写一行“原缺口→新增材料→保持不变的定义和对手→新增可支持范围”。多个方向同时变化时，分别呈现原范围与新增范围结果，不把总行数增长当成效果更可靠。资料身份或规则变化须分版本；本条不重启旧实验，也不要求每题把三个方向全部做完。

## 分开选标的、操作时机和切换因子

选标的在同一日期比较对象，先看排序/分组能否区分后续结果及各期/各对象分布；全池平均资金曲线不替代这项检验。平均分配可以作参照或组内汇总，须说明最初分配还是定期恢复权重；组合最大跌幅不等于单只风险的平均。操作时机固定候选后比较行动；何时切换因子另属一项问题，须先超过固定因子组合，不能事后按好坏年份倒定条件。

先查已有动量、选池、轮动和相对强度实验。选择与操作时机结合时，复用简单持有/仅选择/仅时机/二者结合的已有结果，确认排名是否混入波动过滤、等待与资金调配；只有具体新增信息或资格改善才另冻比较，年化和最大跌幅不线性相加归因。低频选择可先考虑月度，实际节奏由机制、信息到达与成本固定；不为短周期而缩短周期。

金融基本面候选只作独立研究扩展，不据此修改现有技术判定；股票财务指标不直接移植到黄金、债券或混合ETF。RD-Agent式记录沿既有合同串起问题、金融假设、旧家族结果、资料资格、实现、评价和下一步理由；未合格时保留未知，不用自动循环寻找正结果。本次已做的查重、原表和下一题示例见[低频选标的与时机审查](/Users/yongbiaoli/Desktop/lei-signal-lab/.codex/worktrees/personal-audit-coordination-20261018/docs/experiments/lowfreq-selection-and-timing-2026-10-19.md)。

## 发散与固定怎样衔接

1. **看本轮效果前发散。** 根据原始材料比较机制、测量、场景、竞争解释，复用已有结论排除重复，留下一个核心问题及必要对照。原有看过的数据如实登记，不能靠换AI、名称或下载恢复“未知”身份。
2. **冻结后执行固定比较。** 使用现有`--workflow-draft`、合同、合格资料和适配评价器；程序不支持的资金用途走有明确合同的专门账户实现，不把预测器说成具备该能力。不得因为没有程序入口而自动把金融问题改成预测误差。
3. **检查与解释有边界。** 实现错误可纠正并保存前后版本；新机制、期限、资产池、模型或用途进入追加探索记录，保留原主比较。反复用于反馈的历史不能再充当最后未知检验。
4. **让证据改变取舍。** 必要比较及授权内能改变判断的检查完成后，关闭本次有界问题；区分当前未支持、证据不足和已排除有实际意义的改善，不据本次结果关闭未检验用途。没有新增理由，不以追求正结果追加尝试；只有具体新现象、关键前提变化、合格新证据或实质不同问题才重开。无需为了流程完整把所有分支都跑完，也不能用计划/报告数量替代结论。

AI可承担提出候选、检查来源、实现和反驳，但同一个生成模型不能以自己的赞同当独立证据。涉及关键资金或方法歧义时，由另一审查者针对原件和具体数值复核；意见冲突回到证据，不按模型票数决定。外部模型讨论和开源示例均不改变原权限、规则或预算。

RD-Agent按需分步借鉴：优先把假设、准确实现、评价结果和下一步理由连在已有记录中，每轮反馈指向具体证据并决定继续、修错或停止；其次在确有中断需求时复用已核的保存与恢复能力；最后才评估自动提出候选、写代码和循环试验。前两项不依赖安装完整框架。自动循环若以后获准，仍继承累计尝试及请求预算，区分用于修改方案的资料与最终确认资料；不能用循环次数代表发现数量。

借鉴身份：已选读的官方场景及入口源码支持“假设—定义—代码—Qlib评价—反馈”及评价调用、空结果处理、恢复参数；本地旧试跑核实的是通用执行层调用、失败留痕和保存后恢复，模型反馈两次失败。上述优先顺序、金融语义查重与多用途评价是本库设计，不能说成已核实的RD-Agent完整保障。准确阅读范围与失败来源见[既有流程审查](/Users/yongbiaoli/Desktop/lei-signal-lab/.codex/worktrees/personal-audit-coordination-20261018/docs/experiments/ai-factor-discovery-workflow-2026-10-18.md)。
