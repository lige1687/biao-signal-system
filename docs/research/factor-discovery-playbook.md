# 从金融现象到可验证用途：AI因子发现工作指引

2026-10-18｜适用于新选题、候选扩展和新增用途。旧冻结实验保持原约定。本指引把现行规范落实到开题工作，不另建定义库、实验账本或研究平台；版本仍以[现行规范索引](/Users/yongbiaoli/Desktop/lei-signal-lab/docs/research/current-standards.json)为准。

## 低频研究的首要判断

2026-10-19 用户确认：**大规模投入前，由AI先判断预期价值、已有证据和是否值得继续；用户不负责先给出有效因子或研究答案。** 默认服务个人低频交易，宽基与ETF优先，保留个股验证。决策频率、预期持有期限和资料频率分别说明：日线资料不自动代表低频方法，小时资料可以辅助原策略，但研究投入要围绕低频决定的整体价值。固定20/30日结果只回答相应窗口，不能代替整个持有过程。

先作三个判断，再安排实现和规模：

1. **同类是否已回答。** 查同一金融现象、公式依赖和既有用途；均线、双均线、距离、颜色先与已有简单趋势判断比较。价格加工不自动无效，但新名字、参数或图形不能证明新信息。没有新机制、不同用途、前提纠正或合格新证据，不重复追测。
2. **本题改变哪个决定。** 写明选对象、参与、持有、退出、投入或组合中的一个主要用途；给出金融理由、竞争解释、简单对手，以及预期可观察的帮助和代价。可以直接研究行动效果，不强制先证明预测准确；开题预期是可推翻的假设，不是承诺因子必有效。
3. **证据支持投入到哪一步。** 主控在原开题记录中作出“复用即关闭、有限检验、补明确资料缺口、扩大复验、暂停该用途/转向其他候选”的决定及理由。大规模计算、扩样或新开发前，必须指出它准备消除的具体不确定性，以及何种结果会改变当前决定；不能仅以“样本还少”“指标还能发散”继续。

低频研究的五项首要审查，贯穿开题和结果解释：

| 问题 | AI必须核对的内容 |
|---|---|
| 反馈慢却频繁改规则 | 区分正常波动、执行/实现错误和原假设不成立；几笔盈亏不自动触发新条件。研究版本变化与真实执行规则变化分别记录；不设万能最少交易笔数。 |
| 少亏几次却漏掉大行情 | 先固定全部原始合格机会，核已参与、等待、未确认及未成交的结果和原因；并列避免的损失、放弃的收益、买贵与成本，查看盈利集中于少数行情时的取舍。大行情案例解释总体分布，不事后只挑赢家；未定义成交/资金路径时只报机会变化，不称实际少赚金额。 |
| 多承担风险被当成判断进步 | 对照投入比例、持有时长、市场共同涨跌、集中风险和同一笔资金的冲突；适用时比较事前可执行的简单降投入方案。无法分离时保留未知；更高收益不自动是新信息，低回撤也不自动是风控能力。 |
| AI加速试验也加速偶然胜出 | 家族参数、条件、用途、失败和重试都留账；看结果再改仍是探索。同日同涨股票和重叠窗口不能当独立市场经历；未参与挑选的历史或后续新资料单列，跨时期/对象差异不能被总均值掩盖。 |
| 系统建设代替研究回答 | 每项研究开发必须关联一个未决问题，说明完成后哪项比较能做、怎样改变取舍；可复用的结果先复用。图更漂亮、模型接通和检查通过不能代替因子有效，暂不影响判断的功能降低优先级。 |

“足够样本”由AI根据问题、不同市场阶段/事件、对象依赖、缺失与选择偏差、效果幅度及不确定范围留下判断，不按股票数量或固定年限自动通过。必要比较完成且未支持增量，可以暂停该用途；只有不确定范围足以排除事先有依据的有用幅度时，才说“已排除有实际意义的改善”。证据薄时须说明具体缺什么、能否在授权和预算内补到，以及为何补后可能改变决定；补不到可关闭本次证据边界或按真实阻塞/预算状态暂停，不能冒充无效或无限追加。

复现比较先标清三层：**原作者同口径公开组合核算、第三方复现组合核算、本地市场与用途适配**。均值接近不能认证逐股流程，跨层差值不称复现误差；同时核样本、公式、持有、权重、收益单位和缺失处理。程序最少月份标记只控制已实现的输出，不保证统计精度；完整月份法须列出计划→合格→完整结果→费用可核的数量与缺失集中在哪些时期，不能把保留未知权重误解为主均值已消除缺失选择。具体反例见[2026-10-20因子指标与样本审查](../experiments/factor-type-metrics-audit-2026-10-20.md)：119→108→81→64个月、后期50月区间仍宽，风险或组合分散价值也不能只按平均收益增减判定。此例不修改旧合同或设通用月数、IC及格线。

结果交付固定回答：**改善了什么、付出了什么代价、保留/复验/暂停哪个用途、什么证据才重开。** 允许转向更有金融理由且重复更少的候选；这是AI的研究责任，不为换方向重置旧尝试或预算。沿用原权限和负责人，需改变原策略/研究范围或取得新资金权限的事项仍按原约定处理；局部负结果不自动删除原策略条件。

## 先回答值得研究什么

**先记录一个可核的金融现象，再提出能被削弱或推翻的解释，最后决定用什么指标检验。** 可靠的经验观察、理论预期但尚未观察确认的现象都可以起题，分别标明证据和待检验预测；机制暂不确定就标为假设；不要求先有完美理论，也不能看到漂亮曲线后把故事写成事前理由。

用户已确认本工作顺序：金融现象和竞争解释 → 按具体用途比较收益、风险及其他实际价值 → 根据结果补证据缺口；借鉴RD-Agent将每步的理由、输入、实现、结果和下一步相连。先复用已有研究和原负责人产物；本指引不接管其他对话的任务，也不因流程补充重跑已有实验。

AI先查原件、现有定义、相近实验和负责人。用少量候选比较“为什么值得测”，不按数量交指标。主控在既有授权内决定常规方法、计算和反例；只把无法还原的核心策略含义、新方向授权、必要资料或真实资金风险问题交给用户。

将以下内容放进本任务已有计划、研究合同附件或raw记录，复用已有文字与链接；不要另开总登记表。学习/审查任务不强行生成实验合同。正式效果计算前采用现有冻结入口；不得向严格JSON合同随意添加不被支持的字段。

分类允许一对多：同一资料可以支持不同金融解释；不同资料也可能测量同一个现象。相关性低不证明金融机制独立，相关性高也不自动证明完全无增量。重复表达可以因测量可靠性或模型表达需要保留，但只能声称相应用途的帮助，不变成多份独立证据投票。

复用多份报告前，先核定义ID/版本、公式起算与相等/未知边界、资料资格、信号与成交时点、日期、权重、单位和费用，标为同一对象、依赖它的政策或同家族旁证。同名不代表同一因子；不同日期的财富、费用和风险不能混作准确归因。把差别和可支持结论写进本题原记录，不另建登记表。[20日颜色因子实案](/Users/yongbiaoli/Desktop/lei-signal-lab/.codex/worktrees/personal-audit-coordination-20261018/docs/experiments/dual-ma-factor-worked-case-2026-10-18.md)已发现起算、相等边界和统计日期的实际差别。

## 新信息先分用途，再比较它补了什么

新增信息不默认变成“满足才买”的条件；先分候选排序、风险识别、投入、持有退出和组合用途，再选择检验。用于风险识别的信息不必先提高平均收益，预测更准也不能冒充实际调仓获益。

既有对手应保留当时已知且与本题相关的简单信息，例如近期涨幅、总波动、趋势持续时间；不能只用颜色标签人为削弱对手，再把补回标签丢失的信息称为独立优势。控制哪些信息应服务于问题，并在效果计算前写明，不无限追加或看结果后挑选。

核数学依赖及贡献归属：同日同业减去同一个行业收益不改变个股排序；加入个股收益及其相对行业收益可能只是补行业信息。下跌占比仍来自价格，成交量比值不自动是换手率；来源不同不自动独立、价格加工不自动无用。先查定义及同家族不同用途的旧结果，只有具体未决问题才开新检验。

[2026-10-19新增信息建议审阅](../experiments/lowfreq-information-candidate-review-2026-10-19.md)留存金融出处、旧行业反例与条件优先级。这是当次取舍参考，不是永久清单；新任务仍核现状、资料资格、负责人和授权。财务信息沿独立研究扩展，不能据本段修改原LEI技术判定。

## 汇报结果前先说明研究了谁

任何研究结果的首屏或聊天摘要，先写研究对象范围（universe）：股票、ETF、指数或其他对象；名单来源与名单日期；当前固定名单还是历史逐时成员；计划纳入数、实际有资料数及缺失处理；观察期与资金统计期；逐对象结果如何汇总、初始分配和后续调钱/恢复权重规则。用一句话指出外推范围。复用旧结果也必须带上，不能只说“A股/美股”和起止年份，或把几百只股票合计结果讲成一个可管理的个人账户。

时间范围逐项列出预热、指标构造、拟合或选规则、评价和各分段的准确起止日期、月份/事件数及用途；没有拟合就写“不适用”，不人为命名训练集。说明分界在何时、因何理由固定，以及哪些历史已看过或用于提出后续问题。旧历史按年份拆开只支持时期差异描述，不自动成为独立测试；重叠评价窗口须核结果何时成熟。不同报告的“后期”若日期不同，保留各自范围，不能省略年份合并比较。美国公开组合、美国本地逐股和ETF实测分别列示，不能互相代填。

本轮仅修正已证实的遗漏：20日颜色案例是2026年当前沪深300名单300只及IVV股票持仓504项的历史回看，有报价300/502；各市场初始同额分配、逐股执行、资金不跨股调配，最后相加。历史成员和退出者未补齐。上述范围不因讨论流程而扩大，原表和旧实验保持。

## 按用途挑对手和评价，不能统一只看收益

**2026-10-20 用户确认的研究核心：每个因子都要有与其金融含义和具体用途相匹配的评价体系与指标，据此决定保留、复验、暂停和下一步；收益只是价值的一部分。** 评价单位是“因子 × 用途 × 市场/对象 × 期限”。同一因子用于选股、风险提示或减少操作，可以有不同结论；同类用途可复用同一套指标，不为每个因子另造评分。收益没有增加，不能单独成为淘汰理由；某个辅助指标较好，也不能替代原主用途的检验。

开题和委派前，在已有研究记录中绑定：**主用途及金融理由 → 主指标及预期方向 → 简单对手 → 必须并列的代价和辅助指标 → 对象与时间范围 → 哪种证据改变取舍**。主指标回答“准备改善什么”，代价回答“为此放弃什么”；没有资料的用途明确写“未评价”及所缺证据。可以同时预定多个用途，分别下结论，不把全部指标压成一个平均分或事后挑最好的一项。

| 本轮用途 | 必要的简单对手（按问题取适用者） | 主效果与必须并列的代价 |
|---|---|---|
| 股票或ETF之间的排序信息 | 已有涨幅、规模或其他与问题相关的简单信息；同日期同合格对象 | 分数与随后目标的排序关系（Rank IC）、分组差异及是否逐组变化、跨时期稳定性；区分未来收益与未来风险目标，单列覆盖、集中和名单更换；没有账户规则时不称可赚收益 |
| 选对象、买入、持有或退出 | 原方法；合适的简单持有或固定投入 | 扣成本后的财富变化、亏损幅度、恢复时间、未参加和没等到的机会、实际参与程度 |
| 提前识别风险 | 历史风险发生频率、已有简单波动或风险信息 | 风险判断是否更准确；漏报与误报、稳定性、提前量；尚未定义行动时不填账户收益 |
| 用信息减少损失 | 原策略；事前固定较低投入或其他适合的简单风险规则 | 少亏多少、少赚多少、恢复与参与程度、现金和交易摩擦；不以几乎空仓的低回撤证明能力 |
| 改善组合 | 原组合；适合问题的简单资金分配 | 同一笔资金的总效果、共同下跌、集中风险和费用；不能把独立账户收益直接相加 |
| 降低操作负担 | 效果相近的简化流程 | 真实交易/人工判断/维护次数和耗时，失败恢复与遗漏代价；未知成本填未知 |

用于只买入排名靠前的一组时，还要看事前固定的买入组相对同日合格范围和简单选择办法的效果、风险与集中；高低组差主要来自低分组较差，不能据此声称买入高分组有优势，已有分组输出先复用。风险提示须并列报警数量、误报漏报、提前量与代价，按问题核可比报警负担，不能靠多报警取胜或用评价期风险倒选阈值；概率输出沿用现行问题方法规范的校准要求。需要等待、确认或定时查看时，在原机会记录中连接“最早可知→按既定节奏最早可行动→期间价格变化与条件是否失效→行动后结果”，保留未触发、未成交和未知；未定义成交不称账户帮助。这些细化复用[已有建议审阅](../experiments/pro-advice-process-review-2026-10-20.md)，不为验收文字重跑市场实验。

价值不限于上述五类，也可包括判断更一致、依据更清楚、资料缺失时更可靠，以及排除无帮助方向。每项须指定使用者、原办法和可观察差别：例如同一案例的判断分歧、能否定位结论来源、缺资料时是否错误发出判断、是否因此停止一项重复研究。只有报告更长、解释更顺或模型更赞同，不算价值证据；未测价值保留未评价，不能用来补救原主用途的负结果。主观可用性需实际使用者反馈，规则文字和合成演练只证明各自检查范围。

规则减少交易或让持仓更稳定时，另核帮助是否来自新增信息、较少行动、等待或投入变化。没有相应对照，只声称观察到的帮助，不能说成独特机制；只有本题确需辨别且已获授权时，才设计原简单规则加等待/暂不动作的对照，不按降频百分比自动开新实验。

先核“信息有用”和直接核“行动有用”都可以，不强制先预测、再交易的统一顺序。主用途明确后可同时预定辅助用途，但不根据结果挑一个较好用途当原主问题。风险和收益互有取舍时展示交换，不替用户事后发明综合分数或风险偏好。

主控收到结果后，逐用途交付“主要效果、相对简单办法的增量、代价、反例、不确定性、取舍和重开条件”。发现新的用途可以登记为下一项假设；本轮事后发现的线索保留探索身份，不追认成事前成功。不设统一的收益、Rank IC或分组单调性及格线；经典因子原文的数值只能在定义、市场、时期、名单和成本口径可比时作核验参照。

风险动作应在本来存在可参与机会或持仓风险的场景中，与可执行对照比较。规则实际改变了参与、退出或投入，即可评价避免的损失及放弃的上涨；规则在本批机会中没有改变任何行动时，其保护效果标未评价。事后按全期平均仓位/未来波动配平，只能帮助解释，不能当时可执行基准。不能把最大资金跌幅直接乘全期平均投入比例来伪造风险对照；比例的分母和随时间变化的持仓须按真实资金路径处理。单次最深跌幅受少数路径影响，须配合亏损/恢复分布和具体事件，不只选最漂亮一段。

### 横截面因子研究的分层证据（2026-11-03）

适用于新选股、同股合成、过滤及组合研究；单ETF状态、风险概率或纯资料核验只取相关项。不新增统一研究入口或强制实验清单，已有证据先复用，必要比较沿原合同与预算登记。方法依据与缺口审阅见[本次整合报告](../experiments/factor-method-standards-increment-2026-11-03.md)。

**分别交付因子信息、信息合成与资金账户的证据，再核层间联系。** 允许从实际行动问题直接起题，也允许成本和执行约束反馈到信号设计；职责分开不表示三层永远不能交互。主控在原开题与报告中补齐适用行，不用多空组差代替买入端，不用两个独立组合的资金相加证明同股条件协同。

| 证据层 | 要回答的问题 | 必要对照与边界 |
|---|---|---|
| 因子信息 | 哪些股票的什么后续结果不同，差异出现在哪一端、维持多久？ | 原始/预定处理后的信号、共同合格池、相关简单信息；说明分组与IC各自的目标、方向、频率和覆盖。相关不自动证明机制或可赚收益。 |
| 同股合成或过滤 | 新信息在旧信息已知后，改变了哪些选择？ | 适用的强单项、未加新条件的规则、预定合成或过滤；保留过滤前共同池基准、被排除机会和缺失。若还声称胜过资金配置，保留简单资金组合对照。 |
| 完整资金账户 | 相同资金和可执行约束下，净收益、亏损与操作负担是否改善？ | 母指数/被动账户、强简单策略；匹配共同期间和费用口径，列仓位、现金、成交、未成交和机会代价。研究满仓袖套只是一种诊断，不强制真实账户100%持仓。 |

**处理暴露要服务问题。** 去极值、排序/Z分数、行业或市值中性化均须记录理由、顺序、参数、当期分类/市值与缺失处理。若怀疑收益主要来自行业、规模或流动性，用事前限定的分层、匹配或残差化检查，保留处理前后覆盖与暴露。MAD是否含尺度修正要写明；常数、零MAD、稀疏行业和回归共线性不能静默补出正常分数。回归残差只对所用变量、权重和样本满足相应约束，截尾或挑选一部分股票后不保证组合中性，更不等于纯Alpha。研究规模/行业收益时不能机械剥掉目标本身。

财报按真实可得版本和发布时间对齐；TTM、同比是可选定义，不能保证消除季节性。估值所用价格、股本/市值须在决定时已可得，并与分子口径相配；收盘市值不能用于当日更早成交。总波动、特质波动、beta分别绑定模型和窗口；放量下跌仅是可能卖压的候选代理，总成交量不能识别主动卖方，也不能直接命名为非基本面冲击。

**分组曲线用来形成用途假设。** 组数按共同样本、并列值和集中度预定，不强制十组或严格单调。Rank IC衡量排序的单调关联，不是原始数值的线性收益斜率；既有[Rank IC入口](rank-ic-evaluation-contract.md)的ICIR为描述性、不年化，方向和权重沿原协议，其他口径须另行声明且不得混比；不设0.03/0.5通用及格线。报告买入端相对共同基准、坏尾部相对该基准和高低组差；若报告“多头贡献占比”，使用相同期间/权重的算术分解，说明分母接近零或符号抵消时比率不可解释，不能拆分两个CAGR伪造占比。只有坏尾部较差时，比较宽池排除坏尾与集中买入最好组，不预定它只能过滤。

**期限衰减必须连接执行。** 仅当期限选择会改变判断时，事前限定少量有理由的目标期限/行动延迟；区分同一信号预测较远的不重叠未来窗口，与累计持有收益窗口变长。并列信号更新、资料到达、可成交延迟、持有、实际换手与成本；重叠标签不增加独立样本。不能从滞后1—6期IC直接宣布半衰期，未识别时保留未知。

**组合复杂度需要增量证据。** 因子家族是整理相近机制与输入的工具，簇内平均不消除共线性，四类不是固定全集。股票层面等权打分、资金各半、序贯过滤回答不同问题，不预定优胜者；滚动IC/ICIR权重只使用当时已成熟标签，预定估计窗口、收缩/缺失与权重上限，并与固定简单权重比较，24个月不是标准答案。已有评分、持仓、原始收益、主动收益相关和共同亏损检查继续并列；低相关不证明独立收益，高相关也不自动淘汰有增量的候选。

**缓冲和仓位层各自核成本收益。** 买入/留存分位、退出优先级和风险例外须事前固定。缓冲与原规则比较扣费后效果、换手、过时持仓和延迟退出代价，不能承诺“少40%换手且不损Alpha”。选股、择时/仓位、二者结合的旧对照先复用；需要新增交互检验时冻结适用对照及同一资金核算，单层结果不能直接相加。低投入对手必须当时可执行，不能事后按全期平均仓位配平。

新报告沿原性能/增量表，仅补本题适用的“证据层、买入端/坏尾部、处理前后暴露、期限与成本、最强简单对手、未知项”；空缺写未评价及原因，不要求每轮全跑上述检验。主动收益/IR和相对财富回撤的计算口径须声明，累计差、相对财富与回归alpha不混用。

**历史研究、前向观察准备、实盘采用分别下结论。** 前向观察须规则冻结、资料与成交可记录、基准/费用/异常处理明确且取得相应启动授权；可用于学习仍不确定的候选，不以Net IR>1或相关<0.5作为通用准入线。实盘还须独立核净效果及不确定性、容量、风险与操作可靠性和明确资金授权。本段与研究准备提问都是供AI及主控执行的要求，不是自动认证因子、强制阻止所有脚本或自动启动账户的程序门禁。

### AI账户研究：把错误检查与投资判断分开（2026-11-04）

复用既有数据、回测与费用实现，绑定版本、输入和独立期望值。AI新增信号优先只改信号接口；发现底座缺陷时允许按明确范围修复、独立复核并保留旧版，不把未经审计的底座称为“不可变正确”。本段适用于新的账户研究，不改旧冻结协议，也不创建另一套试验账本。实现范围和可运行例子见[账户证据预检报告](../experiments/ai-quant-account-evidence-review-2026-11-04.md)。

| 检查层 | 如何落实 | 不能机械套用的规则 |
|---|---|---|
| 计算与资料错误 | 对照事前完整月历，拒绝重复/越界日期、非法数值及明确核算模型下不平的账目；缺月列出原因和连续片段，不跨缺口拼完整净值、回撤或恢复时间 | 缺月不填零；允许带范围的片段描述，不把可用122个月叫连续十一年 |
| 事前研究约束 | 在原合同写选股名额、资金/行业限制、异常处理及理由；记录每个分支涉及的对象、数量、权重和覆盖，复核其是否违背原目标 | 3%异常、15%换手增幅、20%持仓偏差不是通用金融不变量；小行业全留也不自动证明这些股票全部拖累 |
| 需要解释的变化 | 同时检查绝对风险、基准偏离、暴露、共同损失及交易费用；费前改善费后消失时追查交易量、计费与持仓变化 | 过滤高波后TE上升可以成立；不能由风险指标名字推断必然降低所有风险，也不能直接归因程序错误 |

**费用对账按真实资金时序。** 证券买卖金额以交易前漂移权重或实际成交为依据，现金不再作为收费证券重复计算。逐笔费用、现金、持仓及账户价值须能衔接；双方费用按其自己的交易量处理。只有同起始资产、同持仓/价格路径、期末按比例扣现金费的简化模型，才可校验逐期 `毛收益－净收益＝费用／期初资产`，其中比例费用可由逐笔金额×费率复算。期初扣费、费用影响持仓、最低佣金/税费/冲击及复利年化须按各自模型核算，不能断言年化超额差等于平均换手×费率。

**保留选择历史，稳定性只补充证据。** 复用原试验史和已看区间记录，少量有理由的参数对照须在看结果前登记，全部保留；事后追加仍标探索，不强制每次扫描五档，也不以年度胜率或参数高原替代不确定性和独立验证。DSR依赖尝试数量、相关性与收益分布等假设，不等于“试20次就用t=3”。已见历史不能通过文件切分或权限改名成为未见；真正未见资料与冻结后的前向观察分开登记，锁箱使用规则按原授权执行。

**账户报告沿原模板补适用行。** 共同日历及缺失、费前/费后相对基准表现、TE/IR的定义、相对财富回撤和未恢复期、含漂移换手、实际覆盖年份与主要暴露；并列相对原规则的增量、少亏/少赚及不确定性。参数表仅在有预定参数比较时输出，未测项写未知；风险/信息问题不强塞收益表。有效持仓数使用明确归一化权重并同时报告现金和总暴露，不用现金稀释后的权重冒充股票分散度。

**现有可选程序入口：** `python3 -m lei_signal.research.preparation --root . --practice-only --account-review-file <仓内JSON>`。它检查声明月历、共同毛/净收益覆盖、支持的简化费用恒等式、特殊分支声明和已看样本标记，返回缺口与连续片段；不计算策略收益，不读取行情，不授权运行。不支持的费用模型保留未评价。输入JSON的指纹只绑定本次提交，不能证明原行情/PIT、成交、分支记录完整或未见身份；须再与原产物核对。该入口可复用，未自动接管所有旧脚本；不传参数时不会假称已经执行预检。

### 收益展示与前向环境的固定要求

2026-10-23用户确认：**收益必须展示相对对应母指数或事先指定被动基准的超额，并扣除个人交易费用；牛熊判断只允许在当时资料基础上前向检验。** 本条属于按用途评价的核心，不以收益取代风险、机会代价和操作价值。

- 先固定基准身份、市场/股票池关系、币种、分红再投及价格/总回报口径、完整持有区间和来源。没有天然母指数的组合须事先说明所选市场或被动投资参照及覆盖差异。同池平均、三组平均与母指数分别命名；简单对手仍保留，不能互相冒充，也不能看完收益换基准。
- 主收益展示并列策略扣费后曲线、对应基准曲线和超额。对市场总回报指数比较时，写“策略扣费后相对指数的超额”；对可交易ETF/被动账户比较时，双方都按各自实际行动扣适用交易费，才写“相对被动投资的净超额”。逐期差额为策略净收益减同期间基准收益；累计相对财富为同起点归一后两条财富曲线之比减1。累计收益相减另列百分点；**不能把逐期差额连乘成账户**。
- 个人费用按买卖成交金额、方向和账户费表扣除，记录初始建仓、调仓、终点是否卖出，适用时包含最低佣金、税费、汇兑；价差、滑点另列估计及依据。分红、现金收益和汇率口径一起核。未知费率或缺成交/换手时写“个人净收益/净超额未评价”，不能填零、每月统一扣费或把0.25%单边研究假设冒充个人实际费用。费用假设情景仅以准确标签作为研究参考，不满足个人净超额已验证。
- 当前值、参数、阈值及所用资料版本都只能取判断时点已可用的内容，记录资料截止、公开/可得时间、判定时点和最早执行时点；月末收齐后形成的状态从下一可执行时点生效。后来确认的峰谷、实际涨跌月、全期拟合/平滑状态不得当成当时牛熊。缺资料保留未知或按事前约定等待，不把未知当震荡。
- 前缀不变性检验只证明计算未读未来行，仍要核历史发布时间、供应商版本与修订。既有历史保留已看身份；真正前向观察保存当时输入指纹、状态和后续行动，不事后回填或重写原决定。先固定一种主方法及固定因子/被动持有对手，再评价净超额、少亏/少赚、回撤恢复、换手、现金与覆盖；参数仅在先前训练资料确定，多方法不自动授予泛扫或生产过滤。

现有公开组合未有个人成交与准确基准资料时，允许保留明确标为“未扣个人费用的文献参考”的历史图；默认收益/超额视图须显示缺口，不能把毛收益参考当成满足上述交付要求。已封存数据不覆盖，按有日期的补充记录纠正当前解读。

- **股票池也是金融假设的一部分。** 开题先说明这种现象为什么可能出现在这些对象、何种对象中应更弱或反向，区分待验证解释与已观察事实。反转研究可以提出散户交易、暂时价格压力或流动性补偿等竞争解释；不能由“小市值”直接推出“散户多、定价效率低、反转必然更强”，也不能把历史相关当成机制因果证据。

## 扩样本先说明要补哪一种证据

| 缺口 | 有意义的扩展 | 不成立的替代 |
|---|---|---|
| ETF之间如何选择 | 不同底层风险、流动性与交易条件的合格产品；预先按金融理由分组 | 同指数不同代码凑数量；看完收益才选池 |
| 同一ETF何时持有/减持 | 更长且可比的不同市场阶段、足够的合格事件、规则固定后的未来观察 | 增加同涨同跌的ETF就宣称增加独立周期 |
| 某类交易机会是否有帮助 | 全部合格起点、未触发/未成交及原因；按趋势段和共同市场冲击说明依赖 | 只保留成交或盈利机会，连续20日窗口当独立事件 |
| 股票之间的差异 | 当时可知成员或当时上市/规模/流动性规则，保留退出者和缺失原因 | 用今天的幸存/热门名单代表当时全市场；个股结果直接代替ETF证据 |

报告产品数、日期数、事件支持和依赖结构，不制造一个伪精确“独立样本数”。不存在统一至少8/80只或30笔即可可信的标准。依据问题和支持选择有限估计、完整案例描述或仅资料资格核查；扩大名单也不能修复未定义的原策略。

用户认可的三个扩展方向分别保留：增加可比市场阶段和事件、增加不同底层风险的对象、补当时成员及退出者。新任务按问题选必要方向，在原合同附件写一行“原缺口→新增材料→保持不变的定义和对手→新增可支持范围”。多个方向同时变化时，分别呈现原范围与新增范围结果，不把总行数增长当成效果更可靠。资料身份或规则变化须分版本；本条不重启旧实验，也不要求每题把三个方向全部做完。

## 发散与固定怎样衔接

1. **看本轮效果前发散。** 根据原始材料比较机制、测量、场景、竞争解释，复用已有结论排除重复，留下一个核心问题及必要对照。原有看过的数据如实登记，不能靠换AI、名称或下载恢复“未知”身份。

3. **检查与解释有边界。** 实现错误可纠正并保存前后版本；新机制、期限、资产池、模型或用途进入追加探索记录，保留原主比较。反复用于反馈的历史不能再充当最后未知检验。
4. **让证据改变取舍。** 必要比较及授权内能改变判断的检查完成后，关闭本次有界问题；区分当前未支持、证据不足和已排除有实际意义的改善，不据本次结果关闭未检验用途。没有新增理由，不以追求正结果追加尝试；只有具体新现象、关键前提变化、合格新证据或实质不同问题才重开。无需为了流程完整把所有分支都跑完，也不能用计划/报告数量替代结论。
