# 混合池选强与防守：定义证据盘点

日期：2026-09-09
性质：只读定义盘点；不重跑旧实验，不产生新收益结论，不改生产、旧实验或 OKR。
研究规范：`docs/research/experiment-backtest-principles.md` v1.0。
策略位置：这是组合配置与趋势持仓管理的独立研究扩展；它借用了“道路”中的均线方向，但不是 A/B/C/D 入场模块，也没有把 MACD 当转折或买卖点。

## 一句话结论（大白话）

14 只混合池目前真正执行的是：每月最后一个全池有报价的交易日收盘后，用“252 个有效报价前到 21 个有效报价前”的涨幅排序；先剔除自身近期波动处于历史最高 20% 的产品，再取前三、等分目标金额，下一次全池有报价的开盘执行。均线版本不是“月末先站上 200 日均线才买”，而是月度照常买入，持有后任一有效收盘跌破自身 200 日均线，才在随后可成交的开盘卖出。协议大体记录了这些规则，但小池协议仍保留另一套月末均线过滤定义；“集中度”也不是一个单一数字：现有 70.09% 是前三经济方向净利润占完整账户净利润，不是持仓权重，另有按日持仓市值占账户权益的方向暴露指标。

## 3. 可独立复算的纯函数接口

下面是建议给独立复核者的最小接口。它们只接受表或数组并返回结果，不读写文件、不运行旧 `main()`；精确行为应以上表所列冻结代码为准。

    """每个 YYYY-MM 取全池有效报价日期并集中的最后日期。"""

def mixed_month_decision(index_rows, symbols, decision_date):
    """资格>=273且当日有报价；动量降序/代码升序；RV分位>=.8剔除；取前三；返回1/N目标。"""

def sma200_exit(economic_index, sma200, held_units):
    return held_units > 0 and sma200 is not None and economic_index < sma200

def fast_reentry(economic_index, sma200, in_current_list, held_units, stop_budget):
    return (in_current_list and held_units == 0 and stop_budget > 0

def top_group_profit_share(group_net_pnl, account_final, initial=1_000_000, top_n=3):
    top = sorted(group_net_pnl.values(), reverse=True)[:top_n]
    return sum(top) / (account_final - initial)

def group_account_share(group_market_value, account_equity):
    return group_market_value / account_equity
