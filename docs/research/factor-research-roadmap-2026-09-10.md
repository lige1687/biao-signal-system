## 一句话结论（大白话）

我们要做的不是"多发明几个指标"，而是**给每一类因子绑一个必须回答的问题**——
比如"我们的道路规则，相对 200 日线还多提供了什么"。问题被回答了就算通过，
哪怕答案是"这次没看出增量"。

外部建议的起手式是"先在个股上复现经典动量"。**我们不走这条路**：
一是主战场是宽指和 ETF，二是我们唯一一份历史成分名单只有 B 级资格
（详见 §3），转过去并不能换来更干净的地基。

**第一批只做一件很小的事**（§5 Phase 0）：拿一个已有的 ETF 研究对象，
配一个说清楚的未来观察目标，先用手算例和时间边界测试证明算法没错，
再做一次有限的真实输入诊断。不接利率、不转个股、不搬面板指标、不造多空组合。

## 1. 先说清楚：几个词是什么意思

后面反复出现，第一次统一解释：

| 词 | 大白话 |
|---|---|
| **因子** | 一个能给所有标的打分的规则，比如"过去一年涨了多少"。打完分能排序。 |
| **横截面 / 时间序列** | 横截面 = 同一天，A 和 B 比谁强；时间序列 = 同一个标的，它今天比自己以前强不强。这是两件完全不同的事。 |
| **Rank IC** | "今天的排名"和"之后一段时间实际涨跌排名"的吻合程度，−1 到 1。**不设通用及格线**——多高算有用，取决于池子大小、观察期长短和交易成本，每次实验自己事先声明。 |
| **分组检验** | 按打分从高到低切成几份，看后续收益是不是依次递减。**分几份取决于有效样本量**，样本不够就不分组，不硬切。 |
| **时点（可知性）** | 做某天的决策时，只能用那天真的已经拿得到的数据。用后来才知道的信息叫"偷看未来"。 |
| **幸存者偏差** | 只拿今天还活着 / 还在指数里的标的回看历史，退市和被踢出去的都不在，结果自然好看。 |
| **重叠窗口** | 每天都发信号、每次看未来 20 天，相邻两天的观察期高度重合，样本不独立，会让"这个结果不是巧合"的把握度虚高。**要按实际起止日期检查，换成月频不会自动解决。** |
| **增量检验** | 已经有 A 了，再加 B，B 还能不能多解释一点。多不了只说明**这次没测出增量**，不等于 B 和 A 是一回事。 |
| **归因** | 拆开看这笔钱大致哪来的。注意：拆完剩下的部分**不能直接叫"我们的能力"**，它同时装着没被模型覆盖的风险、运气和口径误差。 |

## 3. 现在的地基：有什么、缺什么

### 已经有的

1. **身份与可复现问题基本已解决**——定义登记表 81 张卡 + 校验器（`src/lei_signal/research/definitions.py`）+ 源文件哈希核验 + 报告模板 + 派发合同。因子库 v0 实测跑通。
   ⚠️ 但注意：**账目误差 4.66e-10 元只证明算术一致，不证明输入资料完整。**
2. **每个指标只有一份公式**（`research/definitions.py`），不会出现两个人算出两个动量。
3. **算账与归因工具**：`factor_diagnostics.py` 能拆资金贡献、分阶段归因、回本等待；`stability.py` 有"去掉最赚的几笔还剩多少"和置信区间。
4. **一个现成的因子面板已在跑**：`market_context/factor_panel.py` 已算 12-1 动量、低波、ADX、残差波动——但只接了 UI 展示。**第一批不直接接它**（理由见 §5 与决策简报 D6）。

### 缺的 / 有限制的

1. **横截面因子检验工具没有**。全仓搜不到 rank-IC、分层分组、因子收益序列、换手与衰减、因子相关矩阵。现有回测引擎是"单标的、事件驱动"的。
2. **`factor_return` 类型只有 2 个对象**：`mixed.asset.total_return@1.0.0`（混合池单产品经济总回报）和 `cash.zero@1.0.0`（现金无息，年化 0）。
   **两者都不是市场收益序列，也不是无风险利率序列。**
   （v0.1 曾写"一个都没有"，是错的。）
3. **无风险利率无落盘数据**。代码有在线抓取能力（`fundamentals/sources.py:331,965`）但只有内存 TTL 缓存。现状 rf=0（`timing_backtest/metrics.py:11`、`cash.zero@1.0.0`）。**第一批不接。**
4. **历史成分名单只有 B 级资格**。`csi300_membership_daily.parquet`（84 万行、2014-12 起、带 version 字段）看起来很完整，但生成方法是 baostock **每 20 个交易日探测一次**，发现变化才二分查找生效日，锚点之间前向填充。
   - 同一 20 日内换出又换回**探测不到**（生成脚本 `prepare_data.py:289` 审计注释自述）
   - `version` 不是官方版本号，是名单 sha256 前 12 位（`prepare_data.py:280`）
   - 补查 40 天已做（`research-breadth-freeze-2026-09-09/historical-membership-supplement/audit.md`），两个换样区间未发现问题，但明确"**不能升级为官方历史完整性**"
   - 原报告 `:193` 定级 **B：有条件重建**，`:202` 重申保留该限制
   → **结论：它不是"干净的时点名单"，不能作为"转去做个股研究"的理由。**
5. **研究池非矩形**：14 只 ETF 中最晚的 562590 只有 654 行（2023-10 起）、513870 只有 643 行（2023-11 起）。早期实际可选标的远少于 14 只。
6. 行情文件只有开高低收量，估值/财务/资金流要另接。

## 4. 既有判负结论（保留，但注意其适用边界）

这些结论**在其原定义与原接法下成立**，不得换个名字重跑推翻；
但它们**也不是对整个概念的永久否定**：

1. **宽度中间地带（20–80）无可靠择时规则，且宽度与价格同步、不领先**
   （`midzone-breadth-timing-2026-09-07`）→ 否定的是**该定义下的择时接法**。
2. **板块级 RS 变化与板块内信号表现既不领先也不同步，不做板块加权**
   （`sector-rs-ARCHIVE-2026-09-02`）。
3. **环境类读数做仓位开关判负**（`huanjing-ARCHIVE-2026-09-01` 等）→ 生产里宽度只保留"只降不升一档"，RS 虹吸豁免。
4. **历史宽度序列是 2026 名单回看，有幸存者偏差**
   （`breadth-source-provenance-audit-2026-09-09`）→ 数据资格问题，不是方法问题。

## 5. 分批路线

### Phase 0 — 第一批（**范围已按上级复核收窄**）

**只做一件事，四个动作：**

1. **选一个已有的 ETF 研究对象**（已登记、已冻结、资格已核过的），不新造。
2. **写清楚一个精确的未来观察目标**：观察什么、看多长、从哪天起算、哪天可知。事先声明，不事后挑。
3. **手算例 + 时间边界测试**：用人工可验算的小例子证明算法本身没错；专门测边界（首日、末日、停牌日、样本不足时的行为）。
4. **一次有限的真实输入诊断**：在已有 ETF 池上跑一次，看排序相关性。**分组数量按有效样本量决定，不足就不分组。**

**这一批明确不做**：不接无风险利率；不转个股；不搬 `factor_panel` 的四个指标；不构造多空收益组合；不宣称风险调整后的独特收益。

**验收**：算法在手算例上逐项对得上；边界行为符合事先声明；诊断结果连同其不确定性一起报告。
（v0.1 曾提"用随机打分跑一遍，IC 应接近 0 且分组不单调"作为验收线——**这条已删除**，随机一次本来就不保证接近 0，不能当通用验收。）

### Phase 1 — Trend 对打

问题：**MA200 / 12 个月绝对动量 / LeiSignal 道路，各自提供什么信息？**
标的：14 只 ETF 全池（已冻结的 `prices.csv`，2019-09 起）。
固定其他条件、每次只改一项。做增量检验，但结论措辞守 §2 的边界。

### Phase 2 — 横截面动量（RS）

复用 `mixed.momentum.raw`。必须写明池子规模与非矩形带来的不确定性。
参考已有的 `cross-sectional-momentum-pool-2026-09-05`（个股上做过，结论 mixed）。

### Phase 3 — Momentum + Trend 组合

相对强度（谁比别人强）+ 绝对趋势（它自己强不强），与单独两者三方比较。
看的重点是**"收益差不多但回撤更小"**，不是收益更高。

### Phase 4 — 把宽度从交易规则重构成因子

经济假设 → 精确定义 → 分组（按有效样本）→ 增量检验 → 才谈仓位。
**前提**：先处理 §3.4 / §4.4 的数据资格问题，否则只出"历史重建"结论。

### Phase 5 — LeiSignal 自有信号的增量检验

道路 / 支撑 / 回踩 / 结构确认，逐个问：它相对 Momentum / Trend 还多提供什么？
措辞守边界：测不出增量 ≠ 等价。

### 不排期
Value / Size / Quality（缺数据）；美股横截面（非主战场，且同样是今天的名单）。

## 6. 每份因子实验报告必须回答的五个问题

沿用 `experiment-report-template.md` 1.1.0，**五项分别填写，不能一个"通过"概括**：

1. 定义清不清楚（能不能追到 `id@version`）
2. 数据有没有资格（时点、名单版本、资格等级 A/B/C）
3. 实现有没有核过（独立算一遍，不是复述执行者的输出）
4. 有效性证据（含不确定性，不只报点估计）
5. 生产授权（**默认没有**。定义通过 ≠ 策略有效 ≠ 可以上生产）

## 7. 一句提醒

经典论文给的不是赚钱公式，是**证明一个因子真有信息的方法**。
要抄的是：定义清楚、当时可知、设好基准、按样本量选检验方法、
说明不确定性、跨时期验证、考虑成本、**允许失败**。

我们自己的两条教训：
**判负的结论要保留，不许换个名字重跑；但也不要把它扩大成永久禁令。**
