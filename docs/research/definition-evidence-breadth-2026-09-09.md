# 宽度定义证据与规范化边界（2026-09-09）

状态：只读定义审计；不修改生产、不重跑冻结收益实验、不更新 OKR。
研究规范：`docs/research/experiment-backtest-principles.md` v1.0。
策略位置：宽度是“市场里有多少股票处于相应均线之上”的环境说明，用来研究资金投入多少；它不是道路、路牌或 A/B/C/D 入场条件，也不能反向改写交易系统。

## 一句话结论（大白话）

仓库里“宽度”至少有三种不同算法：日常全 A 快照、通用市场环境层、以及 2026-09-09 冻结的 ETF 研究。它们在股票范围、B50/B200 是否共用同一批股票、停牌是否沿用旧状态、资料不足时是否仍给数值上不相同，不能混称一条序列。若要复核本次 ETF 研究，应以它自己的冻结纯函数为准；该研究已经否定“等待 B50/B200 20 日转强再投入”，但没有授权改生产规则。

## 1. 建议固定的定义词典

以下是**定义身份**，不是建议上线的新规则。

| 名称 | 精确定义 | 单位与有效性 | 身份标签 |
|---|---|---|---|
| `B_N(d)` | 在日期 `d` 的指定股票池 `U(d)` 中，取合格集合 `E_N(d)`；`B_N(d)=100×Σ[close_i(d)>SMA_N,i(d)]/|E_N(d)|`。严格大于，等于均线不算站上。 | 百分点，范围 0—100；分母为 0 时无值。 | 必须连同 `universe_id / membership_version / denominator_policy / quote_policy / price_adjustment / coverage_policy` 才构成完整定义。 |
| ETF 冻结研究的共同分母 | `E_200(d)={i∈U(d): d 当天有真实收盘且截至 d 已有至少 200 个有效收盘}`；B50 与 B200 都只在 `E_200(d)` 上计算。SMA50/SMA200 各自由该股有效报价序列滚动计算。 | `coverage=|E_200|/|U|`；低于 90% 时 B50、B200 同时无效。 | `etf-confirmation-v1/common-200-real-quote`。 |
| 通用市场环境层独立分母 | 每个 N 各自要求至少 N 根有效数据，故 `E_20/E_50/E_200` 可以不同；宽度即使覆盖率不足仍计算，但整体 `data_status=INCOMPLETE`。 | 宽度为 0—100；覆盖率为 0—1。 | `market-context/independent-denominator`，不可替代上行冻结研究。 |
| 日常全 A 回填 | 每个 N 独立用“当天报价非空且 N 日均线非空”的分母；至少 100 只（旧 33 年脚本为至少 50 只）才给相应值。 | 0—100；历史文件没有逐日成员身份。 | 当前名单/缓存回溯，不得无条件称逐日历史全 A。 |
| `delta20_N(d)` | `B_N(d)-B_N(d-20个真实交易日)`；两端必须是同一完整定义身份下的有效百分数。不是 20 日均值斜率，也不是 20 个自然日变化。 | 单位是“百分点”，不是百分比收益。例如 45→50 为 `+5` 个百分点。 | ETF 冻结研究中 `>0` 才叫该确认条件成立；`=0` 不成立。 |

规范化时不得只保存 `b50/b200`：至少同时保存股票池版本、总数、当天真实报价数、共同合格数、缺报价数、历史不足数、覆盖率、有效标志、价格调整口径和生成代码身份。

## 3. 股票范围与资料状态

### 全 A

旧 33 年成品是用 2026 年缓存名单及可得历史价格向后回看，不含可核验的逐日成员事件表，也不能证明早期退市股票完整。旧生成器的代码证据是：上市前不填；上市后内部缺口只为均线计算向前补前收，但缺少当天原始报价仍不进当天分母；三个周期各用自己的分母。成品可作为“冻结历史文件下的有条件示例”，不可升级称真实逐日全 A。

新 ETF 研究又从现存全 A 面板按每列首个至最后一个有效价格构造每日范围，并改成共同200日分母。因此它与旧 33 年成品、日常快照都不是同一条数值定义。主研究区间全 A 只有 1884/2790 日达到90%覆盖，首个有效日为2018-07-05，资料等级 B。

### 沪深300

每日目标成员数为300；历史日期查询结果用20个交易日间隔探测，有变化时二分定位首个不同交易日。限制是：若一只股票在同一20日探测段内离开又返回，端点集合相同便无法发现。逐股价格仍依赖全 A 历史面板，旧成分缺价会降低覆盖率，故等级 B，而不是完整A级历史成员链。主研究区间 2378/2790 日有效，首个有效日为2015-02-09。

### 创业板指数

协议要求“当时已生效的完整100只指数成分”，不是全创业板股票，也不是ETF部分持仓。反向重建在2017-10-09出现101只，缺少300075后来退出的完整官方链；按事前停止条件记 C 级，`159915 × 创业板自身宽度 × W0—W3` 四条没有运行。当前不存在可用于该冻结研究的创业板自身 B50/B200 历史。

## 4. 原三档仓位与转强条件

1. 每自然周取最后一个**有效** B200：`B200<43.3 → 100%`；`43.3≤B200<56.7 → 50%`；`B200≥56.7 → 0%`。这是低宽度时多投入。
2. 下一自然周第一个可成交开盘才评价/执行。实际持有比例与目标差距 `<5` 个百分点不交易，恰好 `5` 个百分点要交易；两次交易间让价格变化自然改变持有比例。
3. W1 的确认是同定义 B50 的 `delta20>0`；W2 是 B200 的 `delta20>0`。若 t-20 的对应行无效，则不能确认，不得跳到更早的最近有效值。
4. 确认只限制目标上调，包括第一次建仓；目标下降立即按原规则处理。待买期间每天收盘复核，原目标跨档便更新或取消；首次确认后下一可成交开盘下单，之后确认转负不会自动卖出。
5. 一整周没有有效宽度，不产生周信号，并撤销旧待买；不得沿用上一周宽度。

## 5. `delta20` 与既有转强研究的实际状态

- 这不是生产策略“道路转强”，只是市场环境资金实验中的新增投入确认；名称必须写成“B50/B200 20交易日变化为正”，避免和 EMA/SMA 道路、底部结构早期转强混淆。
- 冻结研究已经完成全 A 的510300/159915以及沪深300自身的510300分支；创业板自身分支因资料 C 级未运行。18/22条主路径完成，另有对应18条费用翻倍检查。
- 所有已完成分支中，W1/W2 相对各自未确认的 W0 都明显少赚；简单的ETF收盘高于50日均线确认 W3 均高于 W1/W2。归档结论是：W1/W2 被否定，不进入生产；这不等于所有宽度用途被否定。
- 结果仍受全 A、沪深300均为 B 级数据限制；压力费用只是同一路径的检查，不是第二份独立证据。冻结历史回测、冻结观察和生产采用仍是三个不同状态。

## 6. 给后续复核者的纯函数与冻结小输入路径

### A. 复核 ETF 冻结共同分母（首选）

只导入 `research_engine.py` 的 `breadth_from_close_panel`，不要执行 `prepare_data.py::main`、`run_backtest.py` 或旧 33 年回填入口。最小输入沿 `test_research.py:20-36`：205个工作日，a单调上升、b单调下降、c前199日有值而最后6日缺失；最后一天股票池为(a,b,c)，最低覆盖率临时设0.5。预期：`eligible=2`、`missing=1`、`B50=B200=50.0`。这同时验证共同分母和“缺失不算均线以下”。

建议命令仅运行该边界测试：

```bash
pytest -q docs/experiments/raw/research-etf-breadth-confirmation-2026-09-09/test_research.py::test_b50_b200_share_denominator_and_missing_is_not_weak
```

### B. 复核通用市场环境层（只能证明另一种定义）

纯函数为 `src/lei_signal/market_context/breadth.py::compute_breadth_snapshot`；现有小输入测试 `tests/unit/test_market_breadth.py::TestBreadthSnapshot::test_independent_denominators` 明确要求有55根数据的新股进入B20/B50而不进入B200。它适合证明生产通用层的独立分母，**不能**用来复核 ETF 冻结共同分母。

### C. 复核 `delta20`

纯函数为 `breadth_delta(history,column,as_of,sessions_back=20,current=...)`。冻结小表应有至少21个严格有序交易日；令第1日B50=45、第21日B50=50，预期 `+5.0` 个百分点。把第1日设为缺失应返回 `None`，不可向前或向后寻找替代日。ETF研究实际运行虽按同一数学式判断，但其冻结引擎没有抽出同名 `delta20` 函数；复核时必须先确认传入序列已按共同分母和90%覆盖规则置无效值。

## 7. 必须保留的分歧，不应静默“统一”

1. **共同分母 vs 独立分母：** ETF冻结研究要求B50/B200共同200日分母；生产通用层和日常全A是各周期独立分母。
2. **停牌：** ETF冻结研究当天无真实报价即排除；生产通用层默认最多5个交易日沿用最后状态；旧33年生成器只在均线内部补前收、当天分母仍排除。
3. **覆盖不足：** ETF研究直接把B50/B200设无效；生产通用层仍返回数值但标 `INCOMPLETE`；日常回填按最低合格只数隐藏早段。
4. **股票池：** 沪深300是有条件历史成员；创业板链失败；全A是当前名单/价格列范围回溯。三者不能靠共同字段名互换。
5. **价格调整：** ETF指数成分研究写后复权连续价格，旧33年链写前复权；不同输入版本不可混接成连续 `delta20`。
6. **“转强”语义：** 宽度 `delta20>0` 仅是实验确认条件，不是LEI道路转向，也不是买点。该条件的已有历史研究结论为否定且未获生产授权。

本审计没有联网、没有下载成员或逐股行情、没有执行任何旧主入口，也没有重新计算收益。行号和 SHA256 对应审计时工作区当前字节；工作区已有大量他人未提交修改，因此后续引用应同时校验哈希，不能只凭 Git 提交名。本文只规范“如何准确叫出已有定义和证据”，没有补齐创业板成员链、历史退市股、原始供应商响应或实际成交验证。
