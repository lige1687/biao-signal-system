## 方法论发现（跨三轮稳定）

1. **"在哪定档" >> "怎么分批"**：边界收缩（0-100 → 25/75 → 30/70）贡献 3 个点超额；
   批次比例/节奏贡献 <0.2 个点
2. **A 股逆势、美股顺势**：同一张宽度图，均值回归市场（创业板）逆宽度操作，动量
   市场（美股）顺宽度操作——三窗口稳健检验下方向从不混
3. **波动率目标是美股防守的关键增强**（中位回撤 -39%→-22%），与宽度信号正交
4. 美股宽度顶 ≠ 价格顶：B200≥80 区间占 21% 时间、期间年化 +39.5%——"顶卖"在美股
   是收益毒药、但配闸门/波动率目标后是回撤良药

## 第四轮补充：阶段性顶底（中等宽度水平的波段）

用户提出的直接检验：不等极值，在 30/70、35/65、40/60、45/55 的中等宽度位做反转
波段（含此前从未测过的 B20 快指标），共 1168 组。

- **收益维度全军覆没**：0 组稳健（11 组全窗为正但前后半窗不稳定）；B20/B50 快指标
  阶梯最好仅 +0.1%。结论：宽度只含"大级别"信息，中线顶底信号信噪比太低——
  **想靠阶段性顶底赚波段的钱，此路不通**
- **防守维度反而出新价值**：快指标 + 中等极值 + 小确认(3) + MA200 闸门 = 更快的
  出逃响应：
  - 沪深300：B20 反转 30/70 → 回撤 **-18.4%**（终版 -25%），Calmar 4.75×
  - 标普500：B20 反转 40/60 → 回撤 **-12.9%**（终版 -14%），年化 4.6%
  - 纳指：B50 反转 45/55 → 回撤 **-13.9%**（终版 -16%），年化 6.9%
  - 代价：年化比终版低 1.5-2 个点（更快出逃 = 更多误判踏空）

**阶段性顶底的正确用途：更灵敏的防守档，不是收益工具。**
