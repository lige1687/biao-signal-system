# 美股参数版专项 · 预注册协议（2026-08-28，第 29 轮立项）

## 背景与动机

28 轮结论：LEI 方法论（回调/突破/反转/假突破四件套）出身美股，但 v2 实现的参数
是 A 股校准的；七姐妹实测默认参数负期望，唯宽度低+中区分区过滤后转正
（9 笔 +0.50R/胜率 44%，对照高区 99 笔 -0.75R）。用户批准开美股单独测试专项。

  同步替换（siphon_status 的美股等权基准同受益）。

  `~/.lei_signal_lab/backtest_pool_us/`，不污染 A 股默认全池。

## Phase 1：校准扫参（预注册）

- 样本：美股校准池 = SP500 成分按流动性/历史长度抽样的分层样本（目标 100-150 只，
  覆盖成长/价值/周期/防御四风格，避免七姐妹式单边样本偏差），复权 OHLCV。
- 窗口三窗：全窗 / 前半 / 后半（每只股票按自身历史切分）；外加 2022 熊、
  2020 疫情两个压力窗。
- 待校准参数（只动这四类，防过拟合）：
  1. 盈亏比门槛（A 股默认 3 → 美股网格 {无, 2, 3, 5}）
  2. 止损宽度相关（退出方式四选一：a6_1/a6_2/结构止损/b3_dual）
  3. 入场变体（各模块自带变体）
  4. 宽度分区过滤（关 / 只做低+中区）——28 轮核心发现的前瞻验证
- 固定不动：四模块方法论、形态判定阈值（v2 规则本体）、费用档 standard。
- 通过线（模块级）：三窗期望 R 全 >0，PF ≥1.3，且 2022 熊窗期望 > 全窗期望
  （熊市更能赚）；宽度过滤若稳定提升则入配置。
- 反过拟合纪律：参数网格预注册不开口；分层样本抽取规则预注册（按市值十分位
  各取 10-15 只）；结果只报模块级汇总不挑个股。

## Phase 2：上线（通过后）
