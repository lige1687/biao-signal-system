**半导体失效机制精确定位**：不是“科技周期”——它 B200<30 的黄金坑其实很灵（低宽区未来年化 +51%），失效在于 2019 起有两段**不跟随大盘宽度的独立牛市**（2019-21 国产替代、2023-26 AI），策略在宽度中档区只拿 1/3~2/3 仓，独立行情段仓位不足而踏空。通信虽同为科技，但节奏跟大盘宽度走，实测稳健适用。

**规律**：全A宽度逆势对**经历过深熊的行业**（证券/新能车/白酒/有色/银行）效果
最大——alpha 来自躲开全市场系统性熊市；对**自身独立大牛市**的行业（半导体
2019-2021、中证500）失效。选行业 = 选"会跟大盘一起崩的"。
