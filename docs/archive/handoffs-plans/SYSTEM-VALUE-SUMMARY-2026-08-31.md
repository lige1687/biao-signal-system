## 四、四条元规律（本轮沉淀，复用价值最高）

1. **宽度 = 预算调节器**，不是开关、不是判别器（结构牛/阴跌的补丁都不在
   宽度层内）。
2. **选池靠结构分散**（宽基+缓周期+成长异质混合），不靠与分母同频、
   不靠数量、不靠池内加权（等权即最优）。
3. **空档要空干净**（5 档高位留敞口年化 2.1% 的溃败）。
4. **美股 = 持有资产**（任何闸均证伪），它的作用是与 A 股崩盘错峰。

个股三规律：宽度贡献=指数的1/3+回撤保护可迁移；强周期✓/独立成长✗；
朴素趋势闸=熊市保护器、牛市绞肉机。
