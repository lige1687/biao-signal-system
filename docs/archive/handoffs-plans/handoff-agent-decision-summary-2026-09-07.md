# Agent 决策能力：实验结果、场景定性与增量方向（交接总结）

> 写于 2026-09-07。用途：供总控 Agent 判断下一步增量方向的输入。
> 本文是「Agent 参与交易决策」专题的完整结论快照：全部实验结果、
> 场景定性（适合/不适合）、已落地能力清单、未做方向候选。
> 上游档案：docs/experiments/ai-three-tier-decision-2026-09-06.md（主实验）、
> ambush-dca-exit-2026-09-07.md（定投×Agent）、experience.json（机器可查经验）。

## 一、核心结论（一句话）

**Agent（LLM）在交易系统里的正确位置是「信息层+低频防守型辅助」，
不是「裁决层」——信号放行、逐笔否决、仓位自由裁量三类权力均被实验
证伪；而统计胜率、解释因果、盯梢换挡、发掘机会聚合、标的准入、
定投退出减仓六类角色全部验证有效并已上线。判定权在 Python 规则层
（用户架构红线），数据反复支持这一架构。**

## 二、实验记录与结果（按时间序）

### E1 三档决策实验（2026-09-06，falsified）
- 设计：75 笔核心池信号，GLM 温度 0 逐笔判定（材料：形态/经验/宽度/
  信号参数，全部截至信号日无泄漏），三档对比。
- 结果：纯系统 +174.5R；**AI 否决权砍掉 93% 信号 → -4.6R**；AI 仓位权
  同败。AI 砍掉的 TOP5 全是 +18~+48.5R 大赚单，且每条理由都「正确」。
- 机制：趋势系统 33% 胜率靠少数大赚笔活命，「逐笔求安全」与它结构性
  相克——任何临场裁量者（AI 或人）都会砍掉利润主体。
- 窄规则例外：只砍止损<0.5% 脆皮单在**全池**成立（风险调整比 4.0），
  但在**用户自选池**反噬（利润集中于两笔窄止损大赚单被误砍）——
  规则也要落在实际持仓池验证后才能上（E3 补充证伪）。
- 档案：ai-three-tier-decision-2026-09-06.md（registry: falsified）

### E2 GLM 定投退出（2026-09-07，passed-conditional）
- 设计：定投埋伏持仓，每两月末 GLM 决策 hold/sell_half/clear（材料：
  形态/近90日涨幅/累计收益/宽度），127 次决策存档。
- 结果：**110 hold / 7 sell_half / 0 clear——7 次减仓全部落在浮盈回落
  前**；全部标的回撤改善 4~17pp，收益居中（比规则止盈少踏空、比死拿
  少挨跌）。
- 定性：GLM 的保守性在趋势裁决场景是致命伤（E1），在定投退出场景是
  美德（不折腾、跌前减仓）——**同一性格、两种场景、相反结论**。
- 档案：ambush-dca-exit-2026-09-07.md

### E3 自适应退出（2026-09-07，falsified）
- 「默认筹码止盈、转稳涨自动切趋势止盈」——证伪：价格涨进上方套牢区
  远早于趋势确认（信息时序），自动切换永远来不及。正确姿势 = Agent
  盯形态做**换挡建议**（提醒人切），不是自动切。

### E4 规律发现→规则化（成功范式，多次复现）
- 窄止损脆弱性（0.05% 距离 -16R）、筹码触发（跌穿 VAL×1.02 十分之十
  全胜）、C 模块×下跌型降级（两池同向验证）——**全部由分析（AI 的
  归纳）发现、以确定性规则落地执行**。AI 发现规律有价值，规律执行
  不需要 AI。

## 三、场景定性总表

| 场景 | Agent 适合度 | 证据 | 状态 |
|---|---|---|---|
| 统计胜率/引用历史结果 | ✅ 核心 | winrate 表+经验索引+置信度账本 | 已上线 |
| 解释当下因果（讲人话） | ✅ 核心 | 接地校验+多轮记忆+形态适配 | 已上线 |
| 发掘/聚合机会 | ✅ | scout 三类聚合（零LLM出卡） | 已上线 |
| 标的准入提示 | ✅ | 埋伏前拦「烂标的」、C降级说明 | 已上线 |
| 盯梢换挡建议 | ✅ | 提示词强制项+横幅+清单信号行 | 已上线 |
| 定投退出减仓（低频防守） | ✅ | E2 回撤优化器 | 已验证待接指令 |
| 信号放行/否决 | ❌ | E1 -174R 教训 | 永不 |
| 趋势仓位的自由裁量 | ❌ | E1 | 永不 |
| 逐笔「这单做不做」 | ❌ | E1 机制性相克 | 永不 |
| 自动策略切换 | ❌ | E3 时序证伪 | 永不（人切AI提醒） |

红线（用户定，实验支持）：判定权在 Python 规则层；环境信息（宽度/
情绪/消息/基本面）只做叙事标注与仓位建议，不硬挡信号；AI 引用数字
必带样本量与验证状态，环境不满足=不适用（禁打折引用）。

## 四、已落地能力清单（截至 2026-09-07）

1. 讨论层：多轮记忆（20条）+ 三层标的解析（代码/名/目录别名）+ 形态×
   打法适配（fit）+ 分标的×模块历史胜率（winrate）+ 经验索引（8定案
   报告的条件→结果表）+ 情绪信号纪律 + 重大事件 + 接地校验（数值白
   名单/千分位/单位换算/编造降级）。
2. 推荐流水线：资格门（技术判定）+ 排序（档位/盈亏比/消息小分）+
   情绪/消息/胜率标注 + C模块×下跌型降级。
3. 仓位建议：档位法 + 宽度弱市降档 + RS虹吸豁免（QDII 不适用 A 股
   宽度）。
4. 机会侦察「最近机会」：趋势信号/埋伏位（parquet 直读防 OOM）/情绪
   信号三类聚合出卡。
5. 全局提醒：情绪信号横幅（冰点/热警报激活才出现）+ /ops 信号状态行
   + ops 页左清单右 K 线联动。
6. 闭环其余：报单台账/复盘/每日跑批/速览卡（略，见 plan-agent-
   superentry-v1 执行记录）。

## 六、给总 Agent 的判断提示

1. 本系统用户的实际约束：非量化背景（输出必须说人话）、基金 only
   手动报单、判定权不可下放（红线）、AI 调用要省。
2. 增量判断的关键问句：**该方向把 Agent 放在信息层/防守层（✅做），
   还是让它靠近裁决层（❌不做或改造后再做）？**
3. 所有新规则落地前必须过：①大样本验证 ②用户实际持仓池复核
   （E1 的窄止损教训：全池成立自选池反噬）③用户拍板进规则账本。
