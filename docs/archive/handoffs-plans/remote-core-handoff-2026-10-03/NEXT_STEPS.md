# 接手后的顺序、验收与停止条件

本次交接结束后，本地原执行者停止推进此问题。接手者先核远端版本、manifest输入、当前归属，再做最低复现；不能仅凭complete或报告已完成启动研究。

1. **完成接管检查。** 对照准确远端提交与SHA清单；运行只读smoke和3个单元测试；读取最新阶段记录/分支，核是否已有修复。验收是文件版本一致、实际输入能读、规则能在合成数据上运行，非收益验证。缺文件或SHA不合就停受影响步骤，保存失败和缺口；不覆盖原件。
2. **先处理R1—R8差异，不重做全部。** 若原Opus已有新分支，逐项对照验收清单；否则在自己的返修分支限于报告/工具做允许修正，明确归属。R1/R2收窄结论、R3工具保证、R4读法metadata优先；R5临时目录及复现说明、R6来源、R7采用前资格、R8预算承接按可得材料处理。未知远端任务不假称已暂停；写同输出前必须明确单一写负责人。
3. **将用户技术问题转成一个冻结比较。** 先核其他负责人范围。可优先转黑单开关，或A3日线部分；这些是建议，未预注册。冻结共同机会身份、唯一开关、其余政策、逐日可知构造和缺资料标记；同一机会包含候选未触发，不只看交集。必须复用当前正式研究入口/定义，不能把raw草案导入为正式适配器。现有定义证据闭包缺失则仅准备合同/合成核对，正式效果不准入。
4. **在合格数据和合同下执行最小必要效果比较。** 保留费用、机会分母、未成熟项、依赖分组和简单已有信息基准，报告性能与增量表。日线代理只回答日线部分；固定未来价格描述不等于账户收益。黑色重置影响动作不只是标签，不能把全部开关变化归因给一个条件。不追参数、不重封存；新问题预算执行前冻结并承接旧已看历史。
5. **完整小时/横盘问题按材料资格推进。** 小时缺失时AI给最小试点价值及数据合同，不要求用户猜AND/OR；实际采购须许可/预算。原B参数真实区域不足不放松126日/2%制造样本。数据不足可以得“证据不足”，不能得“策略无效”或“全球没有小时资料”。
6. **结案或暂停。** 报告用大白话首段、准确命令/结果/反例/限制、性能与增量；登记本报告与阶段进度，仅推自己codex分支。候选建议与生产采用分开。预算/核心资料/权限耗尽保存checkpoint和累计尝试，不冒称完成。

停止条件：对该有界问题已回答或当前可得证据到真实边界；关键资料/定义/许可缺失只阻塞依赖部分。没有新证据不反复审查封存。不能为接手续跑新增服务、花钱、改正式策略或改旧账户。
