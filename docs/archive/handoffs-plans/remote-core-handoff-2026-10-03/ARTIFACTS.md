# 运行材料与缺口

每个实际交付文件的用途分组、相对路径、大小、内容指纹、来源提交、必须性和取得方式在manifest.json的files字段；SHA256SUMS可独立检查。已在Git的数据沿用原路径，新增提交不再塞入大数据。旧研究“账户”都是模拟研究输出，不能当私人真实账户资料。

| 材料 | 是否已交付 | 恢复方式/用途 |
|---|---|---|
| 原生产规则/特征与最小测试 | 是，原提交Git文件 | clone本工作分支；不混共享工作区新版源码 |
| 权威策略只读原件、指纹与原任务 | 是 | strategy-source-snapshots与队列目录，SHA绑定 |
| T2—T10草案、脚本与保存产物 | 是 | remote-astra raw/proposals；本轮不重跑旧研究 |
| 独立验收日志/反例/完整逐日摘要 | 是 | remote-astra-core-acceptance raw；原报告验证SHA不改 |
| 两ETF名义日线/行动、四产品母体输入、候选压缩JSON、冻结账户输出/源码锁 | 是，沿用已有Git | 两个宽基冻结目录及twelfth accepted，逐文件列manifest；不是新上传数据包 |
| 字段与时间范围 | 是 | data-fields.json含关键CSV列/行/日期；T8 data-contract.json补数据资格要求 |
| 当前项目政策及研究技能 | 是，只读快照 | sources/source-index；不是其他任务未提交工具的正式发布 |
| 新版工作流/登记表及56条证据闭包 | 未完整移交 | definition-gaps.json逐项列；取得原负责人正式分支及准确证据版本后核sha，不能复制Air所有raw来填洞 |
| 六ETF现行名义日线/行动/真实日历资格包 | 未取得任务正式完整包 | T8 D1—D3只草案；不能用旧两ETF/四产品历史冒充六ETF现行资料 |
| 小时历史行情与当时可知时间 | 未取得，大小未知 | 无已授权接收位置/供应商采购；不能以日线代理冒充小时确认 |
| 第二篇指定发表前PDF原件/逐页核验 | 未交付，大小/完整SHA未核实 | source-followup和T7方法卡有链接/已知范围；接手者有访问后核原件，不能说页码已核 |
| 按日确认构造完整列表 | 未保存 | 原审计只留下摘要；新比较确有需要时在新合同内重建，非本次交接重跑 |
| 完整远端对话、任务ID、费用和24小时预算余额 | 无可访问原件 | task-state仅自报约数；保留unknown，等实际负责人证据 |
| 离线依赖wheel/另一系统验证 | 未提供/未验证 | 公共包索引恢复最低环境；无Air依赖但需接收端网络 |
| 权重、tokenizer、模型/向量索引 | 不适用 | 本任务无训练或模型服务 |
| 活跃数据库、私人账户、密钥/SSH/cookie/登录态 | 不交付、不需要 | 最小检查只读Git文件；后续额外权限须由用户安全提供 |

原锁有历史Air绝对路径和LF/CRLF差异，本包原样保留预期指纹；received SHA是实际Git字节，与historical_expected_sha并列，不能为了路径适配改旧成绩。外部来源许可/到达时间仍unknown的保留unknown。旧Git存在文件不是许可/当时可知资格的证明；不得把商业原件再次上传公开库。

新的大文件没有被装进普通Git；若后续确需缺失材料，先生成精确大小/指纹与最小所需清单，用户指定获准存储，接收端验指纹。当前未知大小必须写未知，不能捏造。
