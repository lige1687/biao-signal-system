# 有限适配协议（统计前固定）

问题：两个通用时序表达是否能以明确输入接成可调用的小工具，以及相对既有20日涨跌和波动的数学区别。服务研究计算层，不改LEI规则，不新增正式因子ID，不预测未来结果。

固定tsfresh 0.21.2的mean_abs_change和autocorrelation原函数，去除装饰器、保留正文和MIT许可。第一项输入21个连续计划交易日的100*log(经济价格)，表示20次相邻涨跌幅度的平均值，单位为对数变化百分点。第二项输入这20个相邻对数收益，lag=1，采用全20项的均值/方差，沿用上游近零方差返回未知的约定。这不是两个错位子序列的普通相关系数，不强行截到[-1,1]。

固定窗口20只用于对齐已有ret20/vol20表达，不选择最优窗口。近零标准保留上游np.isclose(var,0)，输入百分点使单位明确；常数/近零不填0。引用20日既有简单涨跌、年化对数波动为比较列，不修改原定义。

接口要求明确as_of、完整有序唯一的计划日历、明确资产列表、原资料说明和模式。逐资产、按声明日历推进，缺行/停牌/供应商缺价/行动未知中断连续片段，需要重新积累21个有效价格；不压缩缺失日期。只用截至as_of的资料。日历和来源声明不由本工具独立认证，所有输出均为候选计算预览。

本地试用仅固定四ETF原panel的末日2026-06-30，完整原日历与已核SHA的原panel，0新行情、0目标/模型拟合；保留历史到达和行动时间未知限制，不扩作收益结论。

最多4批验证：第1批为有限人工算术/日期/缺口/无未来/换单位/资产隔离/真实只读预览；失败保留后才修复运行下一批。源码逐函数AST与上游一致是维护检查，不另开研究实验。独立审阅只读不运行测试。

数学区别例固定为4项人工对数收益（百分点）：A=[1,-1,1,-1]、B=[1,1,-1,-1]的总涨跌、方差与绝对变化均相同，但相邻联系不同；C=[sqrt(2),-sqrt(2),0,0]与A的总变化和方差相同，但绝对变化均值不同。4项仅用于手算公式，不伪装为20日真实研究结果。结论仅相对该指定参照，不称新增原始信息、独立alpha或预测改善。
