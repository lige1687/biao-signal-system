## 先抓住这条思路

先说明研究的问题和信息来源，了解数据与可能混淆结论的背景，再安排公平对照。分清观察到的差异、相对已有信息的额外帮助，以及未参与选择的新资料上的验证。实验允许得出没有稳定改善或证据不足；保留失败和限制，让别人能继续核对。

## 怎样理解他们的分类

华泰报告第5页按信息主题回顾12类风格。下面的短解释是本库的大白话整理，不是逐字引用；分类名称来自原文，具体公式未在本轮逐类核验。

|原文类别|大白话理解|
|---|---|
|估值|价格相对利润、资产等的高低|
|成长|企业经营规模或盈利增长|
|财务质量|盈利与财务状况的质量|
|杠杆|债务和融资负担|
|规模|公司大小|
|动量|过去价格表现|
|波动率|价格涨跌幅度的变化|
|换手率|成交相对可交易规模的活跃程度|
|改进的动量|原文单列的动量改进方法；具体公式本轮未逐项核对|
|分析师情绪|分析师预期及其变化|
|股东|股东相关信息；具体公式本轮未逐项核对|
|技术|价格与成交等技术信息；具体公式本轮未逐项核对|

这与资料库的四类对象不同：特征定义是怎么算，因子组合收益与模型是怎样构成收益参照，方法文献是怎样研究，验证案例是哪些条件下检查过。也与策略的道路、路牌、触发条件、过滤纪律不同。三者各有用途，不能用分类名称代替有效性或生产授权。财务和消息在本系统仍只作叙事标注，不参与生产技术判断和硬过滤。

## 原文的实验次序与需要审查的条件

波动率报告第5—6页的次序是：先看行业与公司规模中的分布，再按信息高低分组比较，之后用控制背景的比较和排序关系检查，最后综合方向、稳定性及优缺点。合成报告第11页将复杂组合与原始单项及平均分配权重比较。

这些研究主要比较同一日期不同股票；我们的主战场是宽基与ETF，常见问题是某只ETF随时间的变化。可以借鉴先了解数据、保留简单对照、多角度检查的思路；评价方法、窗口、费用和阈值必须按本地问题选择。

原文也有需要审查的条件：标准化后把缺失特征设为零，不等于可以把缺失行情或未来收益填零；剔除下一交易日停牌股票，需要检查是否使用了当时不知道的信息；统计关系不能直接写成因果关系。不能因报告知名就省略这些检查。

## 七条学习内容（与前端使用同一份内容）

### 1. 先分清信息类别，再确定研究对象

**要学会回答：** 作者为什么先按信息来源分组，而不是把全部指标一起筛选？

**来源研究内容或本库整理：** 报告第5页回顾12类风格：估值、成长、财务质量、杠杆、规模、动量、波动率、换手率、改进的动量、分析师情绪、股东、技术；再列出波动率类的具体定义。它们是股票研究的分类，详细机制并未在本轮逐类核对。

**我们从中学什么：** 分类先帮助说明一项信息描述什么、需要什么数据，再决定检验什么。它不同于资料库的四类对象：特征定义、因子组合收益与模型、方法文献、验证案例。分类本身不证明有效，也不代表已经接入。

**例子（教学假设，不是真实回测）：** 过去涨幅描述方向，波动率描述涨跌的幅度。两者都来自价格，却回答不同问题；不能只因都算出了一个数字，就用同一个门槛判断好坏。

**应用步骤：**

1. 写清信息属于价格、成交、财务或外部预期，并保留作者原分类名称
2. 说明研究的是同日股票间比较，还是某只ETF随时间的变化
3. 写出这一项想帮助判断涨幅、上涨机会还是下跌风险
4. 再检查我们是否具备当时可用的数据

**可以怎样检查（本库整理）：**

- 作者原类别与我们自己的归类是否分开
- 股票财务或外部预期是否仍只作叙事和研究参考
- 是否把资料已登记误说为公式已实现

**适用边界：** 12类名称来自原文；不是LeiSignal新增12个技术判定维度。财务和消息资料不能因此进入生产技术判断或硬过滤。

**自测：** 把一个指标归入经典类别，能否说明它已接入或有效？

**答案提示：** 不能。类别描述信息来源；还要分别检查定义、数据、计算和本地证据。

### 2. 先看分布，找出可能混淆结论的背景

**要学会回答：** 低波动组看起来更好，是波动率的作用，还是它恰好集中在不同公司和行业？

**来源研究内容或本库整理：** 第5—6页先观察波动率在行业和公司规模之间的差异，再决定检验时怎样考虑这些背景，之后才做分组和控制比较。

**我们从中学什么：** 先了解信息值在哪里高、在哪里低、缺失在哪里，以及哪些输入表达相似内容。发现相关只是提示该怎么比较，不能单凭高相关否定价值，或凭低相关宣称有额外帮助。

**例子（教学假设，不是真实回测）：** 一组主要是银行，另一组主要是科技公司。两组表现不同，可能来自行业背景，不能立即归功于波动率。

**应用步骤：**

1. 画出或汇总不同对象、时期的数值和缺失分布
2. 查清极端值、相似输入和组别大小
3. 预先选出可能影响结果的背景信息
4. 保存原始比较，再做适配的背景控制；不只展示控制后结果

**可以怎样检查（本库整理）：**

- 比较组是否其实换了行业、对象或市场时期
- 新增条件是不是已有信息的另一种表达
- 处理缺失或极端值是否改变了参与比较的对象

**适用边界：** 华泰研究同日股票间差异；我们的少量ETF研究先在每只ETF内部比较，再检查共享行情，不强制套股票行业处理。

**自测：** 看到两个指标高度相关，能否立即删掉其中一个？

**答案提示：** 不能。先辨认它们描述什么，再检验在已有信息下新增一项是否改善指定问题。

### 3. 从多个角度检验单项，检查方向和稳定性

**要学会回答：** 一个总体数字好看，怎样判断它是否只在少数行情里有效？

**来源研究内容或本库整理：** 第5—6页的四步顺序是观察分布、分组比较、用控制比较和排序关系检查、综合优缺点；第10—11页写明股票池、日期、月末观察、后续收益和评价条件。

**我们从中学什么：** 分组查看高低值对应什么结果；排序检查当时靠前的对象后来是否更强；控制比较检查背景信息能否解释现象。这些是不同角度，同一批数据上的多个角度不等于几次独立验证。

**例子（教学假设，不是真实回测）：** 一个方法总平均不错，但主要优势来自某一年；其余年份方向反复。只展示总平均会隐藏这种不稳定。

**应用步骤：**

1. 先保存单项原值和明确的未来结果
2. 按问题选择分组、排序或控制比较；不要求每次把所有方法都跑一遍
3. 同时报告组别数量、连续事件数量、时期差异和不确定范围
4. 记录支持结果、反例和样本太少的地方

**可以怎样检查（本库整理）：**

- 是否只展示最好组或最好年份
- 持续几十天的同一状态是否被当成几十次独立机会
- 历史分组上涨比例是否被误写成未来个体的预测概率

**适用边界：** 同日股票排序和ETF跨日期预测是不同问题。原文统计门槛不自动适配本系统；重复窗口和共享行情必须保留在不确定性解释中。

**自测：** 分组、排序和控制比较都用了同一批历史，算三次独立验证吗？

**答案提示：** 不算。它们是同一批证据的不同角度；独立新资料必须没有参与规则和参数的选择。

### 4. 先验证单项，再让组合方法与简单办法比较

**要学会回答：** 复杂地合成几个指标，是否比原始单项和平均分配权重更有用？

**来源研究内容或本库整理：** 报告第5页说明合成可整理相似信息或代表一类信息；第11页明确比较合成结果、平均分配权重的结果和原始单项。研究采用月频股票数据，使用12个月历史窗口估计部分方法所需的信息。

**我们从中学什么：** 组合应有明确目的和简单对手。把多个输入变成一个组合值可能帮助受限模型，但不会凭空产生新的原始资料。看过成绩后才改权重，会增加挑中偶然好结果的风险。

**例子（教学假设，不是真实回测）：** 三个指标平均分配权重已经表现不错；复杂权重必须在相同日期和目标下超过它，才有理由承担额外复杂度。

**应用步骤：**

1. 先理解并核对每个输入；不先堆成一个总分
2. 保留原始单项和平均分配权重的简单对手
3. 只用当时已经知道的历史信息确定权重
4. 固定目标、日期和计算预算，比较改善及不确定范围
5. 把表现退步、方向不稳和复杂度一起报告

**可以怎样检查（本库整理）：**

- 是否用后来结果决定过去的权重
- 是否把同一信息的组合写成新增原始信息
- 是否为了复杂办法换了更容易的对手或样本

**适用边界：** 原报告的合成公式、12个月窗口和股票结果本轮未移植；双均线组合只检验指定预测方法是否受益，不证明交易更好。

**自测：** 组合用了两个指标，就等于获得两份独立信息吗？

**答案提示：** 不等于。两项可能都来自同一段价格；组合价值要相对原始输入和简单对手检验。

### 5. 把实验放回当时：防止偷看后来行情

**要学会回答：** 研究使用的信息，在作出判断的那一刻真的已经知道吗？

**来源研究内容或本库整理：** 这是本库的时点检查整理。华泰原文描述月末信息对应后来收益，但也采用标准化后将缺失特征设为零、剔除下一交易日停牌股票等条件。我们记录这些条件，不能直接照搬为ETF事前预测规则。

**我们从中学什么：** 学习研究步骤，还要审查原处理的适用条件。未来收益缺失不能填零；今天修订的数据不能假装当时已知；跨日期学习的权重和标准化参数只能用较早资料，训练段的未来结果不能跨入验证段。

**例子（教学假设，不是真实回测）：** 一份财报在4月公布，不能把它当成3月底已经知道的资料。只因现在能下载到完整历史，也不能证明过去当时可见。

**应用步骤：**

1. 列出观察日、信息发布时间、可使用时刻和结果区间
2. 按时间安排学习与检查资料；同一天的ETF保持一起处理
3. 排除跨越时间边界的未来结果，保留原因
4. 分别记录未知、缺失和真实的零；不拿零掩盖缺行情
5. 声明哪些历史以前已经看过，哪些新资料确实未参与选择

**可以怎样检查（本库整理）：**

- 训练资料是否含验证期的后来涨幅
- 当月因子组合收益是否被当成月初已知输入
- 是否因明天停牌而事后改变今天参与研究的对象

**适用边界：** 这是本库依据项目规范作的审查，不是声称外部作者已完成全部防未来检验。原文缺失处理是特定特征处理，不是缺失收益可以填零的许可。

**自测：** 下载了一份完整历史文件，就能称它是过去当时可用的数据吗？

**答案提示：** 不能。下载时间、历史发布时间和后来修订是不同概念；无法确认的地方必须明确保留限制。

### 6. 用双均线案例走完一次：问题、对照、结果

**要学会回答：** 已有一条均线和简单价格信息后，另一条均线究竟多提供了什么？

**来源研究内容或本库整理：** 这是本库整理的真实试点，不是华泰原作者的实验。2026-09-28报告用六只国内宽基ETF、20日均线和21个交易间隔的后续涨幅，分别检验已有SMA再加EMA及反向问题。

**我们从中学什么：** 先冻结问题与定义，再比较只用已有信息、只用新增信息、两者一起用。用同样对象、日期和结果，分别展示原始分组与额外改善。计算通过和有用证据必须分开。

**例子（本地真实实验：已看过历史，属于探索）：** SMA再加EMA时，预测误差由87.7552变为87.9670；误差越小越好，单位是预测涨幅偏差的平方平均（百分点的平方）。改善为−0.2118，95%探索范围为−0.5474至+0.1160。范围包含零，当前没有稳定改善证据；这不是账户收益或未来收益保证。

**应用步骤：**

1. 写问题：在已有SMA下增加EMA，是否改善后续固定涨幅预测
2. 固定六只ETF、20日定义、21个交易间隔的目标及原数据快照；不按结果挑周期
3. 先用手算和独立实现核对定义、单位、缺失和边界
4. 让三种输入在相同日期、目标和简单预测方法下比较
5. 读表一的组别差异，再读表二的额外改善及不确定范围
6. 保留证据不足结论，并注明没有独立新资料验证

**可以怎样检查（本库整理）：**

- 是否把原始分组差异冒充新增信息的贡献
- 反向问题是否同样记录
- 误差单位、改善正负和研究结果与交易收益是否说明

**适用边界：** 仅限报告列出的数据、对手和简单线性预测方法；不能推出双均线在所有期限、风险目标或完整交易中都无用，也不能直接上线。

**自测：** 双均线组的平均上涨更多，为什么还要看第二张表？

**答案提示：** 第一张表只描述组别不同；第二张才检查在已有简单信息下是否额外改善，仍受模型、历史与不确定性限制。

### 7. 把失败和未完成项留下，让下一位能接着核对

**要学会回答：** 下一位AI怎样知道哪些已经验证，哪些仍只是参考，哪些结果可能是挑出来的？

**来源研究内容或本库整理：** 这是本库的交付整理。既有试点保存了来源原件、配置和代码身份、失败及修订记录、逐行预测和复核报告；外部官方收益接入、证券级重建和本地预测有效性分别说明。

**我们从中学什么：** 一份可接续的研究应让读者知道问题、对手、尝试、证据和边界。分清原作者结果、本地重算及工程检查；无改善或证据不足也能回答问题，不用不断换参数直到出现正数。

**例子（本地真实实验：过程记录）：** 本次三套官方收益已能读取，四种本地对照已能计算；证券级外部复现和独立新资料验证仍未完成。试点保留首次缺日和边界处理失败，修复后重跑并未成为新的行情证据。

**应用步骤：**

1. 登记主要问题、期限和判断指标；保存所有尝试，不只留最好一次
2. 给出原始来源、数据版本、输入与代码指纹、执行入口和结果路径
3. 写清工程是否正确、作者计算复现到哪层、本地问题支持什么
4. 提供两张主要表、反例、限制和下一步会改变判断的必要检查
5. 问题已回答或现有证据到达边界时收尾；未授权的新实验另行界定

**可以怎样检查（本库整理）：**

- 失败与修订是否可以追溯
- 是否把重跑相同历史称为独立新证据
- 没有改善时是否仍准确交付，而非隐藏或扫参

**适用边界：** 保存记录不自动证明统计可靠；本学习路线不启动新研究、自动任务或生产部署。后续研究仍按授权和现行research-closure及项目规范推进。

**自测：** 工程测试全部通过，但研究没有稳定改善，这次工作算失败吗？

**答案提示：** 不能混为一谈。工程证明计算按约定运行；研究可以得到没有稳定改善或证据不足的结论，仍然有价值。

## 看结果时，依次问这三个问题

1. 条件成立与不成立的组别有什么原始差异？先看数量、平均涨幅、上涨比例和指定下跌事件。这些只是描述。
2. 在同样对象、日期和目标下，它相对已有简单信息增加了什么？同时比较只用已有信息、只用新增信息、两者一起用，解释改善幅度及不确定范围。
3. 没有参与选择规则、参数和指标的新资料上，结论还成立吗？重跑旧历史、换执行者或改文件名都不产生新资料。

三类证据的具体要求沿用[研究问题与方法规范](../research/research-question-method-standard.md)；本学习稿不重新制定统一统计门槛。因子信息与完整交易结果分开：一个信息有帮助，不等于扣费后账户更好。
