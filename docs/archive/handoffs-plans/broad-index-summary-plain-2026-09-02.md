## 一、八个宽基/相关标的，测过的结论一览

| 标的 | 测没测 | 结论（人话） |
|---|---|---|
| 创业板（399006/159915） | 测过，最扎实 | 有一套"大盘整体热度高就减仓、冷就加仓"的规则，历史上表现最好、验证最严格（16年历史，多个时间段分别检验都成立）。但有个已知的代价：遇到像2015年、2024年那种科技股单边猛涨的行情，这套规则会因为提前减仓而少赚不少。这不是bug，是这套规则本来的取舍。 |
| 沪深300（000300/510300） | 测过 | 这套规则用在沪深300上"多赚钱"这件事不成立（历史上跑输不动的持有）。但它有另一个作用——当作**防守工具**：遇到大跌能明显减少亏损（历史最大回撤从-59%降到-26%），代价是平时会少赚一点。定位是"保险"，不是"增值"。 |
| 科创50（588000） | 测过，但证据弱 | 早期数据看起来不错，但历史数据只有5.8年，切成两段分别看，后一段表现是亏的。样本太短，靠更多测试也解决不了这个问题，先不用。 |
| 科创100（000698） | 这次专门补测了 | 结论是不建议用。原因和科创50类似——数据只有6.6年，而且2023年后AI概念这段独立行情完全没跟上大盘的节奏，用"看大盘热度"这套逻辑管科创100会错过该赚的钱。 |
| 中证1000（512100） | 测过 | 可以用，历史表现稳健（多段验证都是正的）。但有个重要提醒：这只ETF的历史价格数据里发现过一次不可能出现的单日暴涨(176%，A股10%涨跌停限制下不可能发生)，是数据本身有问题（复权计算错误），已经排除这个假数据点重新验证过，结论没变，但引用"历史年化收益"这类具体数字时要用修正后的版本。 |
| 恒生科技（^HSTECH/513180） | 这次专门补测了 | 不建议用。系统里没有恒生科技成分股的详细数据，只能用简化版规则（跌破200日均线就减仓），测出来效果经不起统计检验（有5%以上的概率是纯粹运气好），而且如果用真实能买到的那只ETF去测，效果直接消失。目前定位只是"看看行情"，不是"照着买卖"。 |
| 标普500 / SPY | 测过 | 这套规则用在标普上不能帮你多赚钱，只能当"保险"——大跌时少跌很多（40年里任何年代最大回撤能压到-15%到-23%之间，不用这套规则的话是-57%到-78%），代价是每年少赚4-8个百分点。适合已经打算长期拿着又怕跌太狠的人。 |
| 纳指 / QQQ | 测过 | 和标普同性质的保险工具，且是这类保险里"性价比"最高的一个（因为纳指本身波动最大，防守效果最明显）。 |

## 二、几个宽基指数能不能搭配着买、分散风险？

**结论：A股几个宽基指数（创业板、中证1000、沪深300等）之间，本身涨跌高度
同步，靠"多买几个不同的宽基"分散不了风险。**

这次专门查证过：之前有份报告说创业板和中证1000关联度很低（意味着可以分散），
但那个数据是错的——是上面提到的同一批"数据断裂"问题造成的假象。用干净数据
重新算，两者关联度高达0.85（满分1，几乎是同涨同跌），过去十年逐年看都是
高度同步，没有例外的年份。

**真正能分散风险的只有三条路，而且都已经在用**：
1. **A股配美股**——两者关联度只有0.11，几乎互不影响，是目前最有效的分散方式
2. **配黄金**——和股票关联度也很低
3. **多个不同行业指数轮着买**（比如证券、白酒、有色、银行这些行业指数
   一起等权持有）——这条路已经验证过效果不错（历史上跑赢单纯持有超额12.2%），
   靠的是行业之间此起彼伏，不是"宽基之间"分散

恒生科技本来被期待能当"第三个市场"来分散风险，但查证后发现它和沪深300的
关联度（0.61）反而比A股配美股（0.11）高得多，分散效果不如直接配美股，
所以目前不建议把恒生科技当分散工具用。

## 三、目前已验证、可以直接参考的组合搭配方式

现有测过的几个组合搭配，各有不同的风险/收益取向，没有发现比这些更好的新组合：

| 搭配方式 | 历史表现 | 特点 |
|---|---|---|
| **两只版**（创业板用规则买卖 + 纳指一直拿着不动） | 年化15.9%，最大回撤-25.6% | 目前测过的里数字最好看的一个，但这是"事后挑出最好的结果"，需要打折，更现实的预期是年化11-12% |
| **八个指数轮换篮子**（1个宽基+7个不同行业指数等权持有，各自用规则买卖） | 年化12.2%，最大回撤-36%（vs 一直持有的年化2.6%/回撤-46%） | 分散效果扎实，验证方法更严格，数字打折更少 |
| **沪深300防守型**（正常持有，跌破关键线才减仓） | 年化跑输持有，但最大回撤从-59%压到-26% | 定位纯防守，不追求多赚 |
| **美股防守型**（QQQ/SPY，跌破关键线减仓） | 每年少赚4-8个百分点，换回撤减半以上 | 适合已经持有、想上一道保险的资金 |

**这次专门检查过还有没有更好的新组合方式，结论是没有找到**——几个可能的
新想法（比如把A股几个纯宽基凑成一个篮子、把恒生科技加进组合）背后的假设
都已经被证明不成立，不建议再往这个方向投入精力。

## 四、系统里的"技术判断工具"，在宽基指数上用得怎么样？

系统里有两大类判断工具：一类是"看大盘整体冷热"（比如现在多少比例的股票在
上涨这种统计），另一类是"看单个股票的买卖点形态"（比如某只股票是否符合
特定的技术图形）。

**结论很清楚：宽基指数上真正验证有效的，全部是"看大盘整体冷热"这一类工具**
——包括前面说的减仓加仓规则、防守闸门、底部预警信号等。

**"看单个股票买卖点形态"这一类工具，从来没有人在宽基指数本身上单独测试过**
——这类工具设计的时候针对的是个股和行业ETF的波动特点，直接搬到宽基指数上
是否管用，目前没有证据支持，也不能假设它管用。这不是测出来"不管用"，是
"压根没测过"，需要如实说清楚这个边界。

## 五、这次过程中查出的一个数据质量问题（重要，影响部分历史结论的可信度）

系统缓存的A股ETF历史价格数据里，发现了**13次不该出现的单日暴涨暴跌**
（比如中证1000ETF某天单日暴涨176%，这在A股10%涨跌停限制下不可能真实发生）。
查出来是数据源在处理分红、拆分这类事件时计算出错，不是市场真的这样波动过。

**这批假数据影响了几个结论，逐一说明**：
- 一个关于**通信行业ETF**表现的结论被直接推翻——原来算出来是跑赢+9.4%，
  排除假数据后变成跑输-7.6%，方向完全反过来了。如果你之前看到过"通信板块
  这套规则表现不错"的说法，那个结论现在不成立了。
- 一个关于**中证500ETF**"这套规则不适合它"的结论，排除假数据后从"明显不
  适合"变成"基本打平"——原来判断它不行的理由是错的，但也没有直接证明它
  现在就是可用的，需要重新认真测一遍才能下结论。
- 前面提到中证1000、沪深300等已经在用的规则，超额收益的结论本身没有受影响，
  但"历史年化收益具体数字"有一定程度虚高（差距在1-11个百分点不等），
  引用具体数字时要用修正后的版本。
- 已经在用的核心组合（两只版、八指数篮子等）全部使用的是"指数"数据而不是
  出问题的"ETF"数据，没有被这批假数据污染。

这批数据本身还没有被修复（正确修复需要真实的分红拆分记录，目前只是"排除
掉这几个异常点"的临时处理方式），是否要安排彻底修复，需要你决定。

## 六、总结：现在能给的最实用建议

1. **进攻方向**：创业板 + 中证1000（两个都不加防守闸），是目前验证最扎实
   的收益候选。
2. **防守方向**：沪深300（用于减少大跌时的损失，不追求多赚）。
3. **组合层面**：两只版或八指数篮子二选一，取决于你更看重"数字好看但要打
   折"还是"数字稳健验证更严格"。
4. **美股部分**：如果持有QQQ/SPY这类美股宽基ETF，防守型规则可以帮你在大跌
   时少亏，但代价是平时少赚，本质是买保险不是增值工具。
5. **不建议投入的方向**：科创50/科创100（数据太短、跟不上独立行情）、
   恒生科技（缺数据、测出来的效果站不住）、A股几个宽基互相搭配分散风险
   （关联度太高分散不了）。
6. **下一步真正的新证据来源**：不是继续回测，是系统从8月底开始实时运行
   一批配置产生的真实观察记录，9月底会出第一份月度总结——这是唯一不受
   "历史数据里挑好看结果"这个问题影响的新证据。
