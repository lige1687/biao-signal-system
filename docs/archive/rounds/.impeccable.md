# Impeccable Design Context — LEI 技术信号研究系统

## Target Audience
- 上海 A 股交易者（彪哥），每日盘中使用
- 需要**快速**识别趋势方向、关键价位、结构状态
- 不需要后端技术细节，需要人话判断 + 可操作参考

## Use Cases
1. 输入代码 → 看摘要栏（价格+涨跌+多周期共振）→ 判断大方向
2. 看 K 线图 → hover 信号标记 → 理解当前结构（C/颈线/B1）
3. 看今日判断卡片 → 获取操作参考（条件化行动框架）
4. 导出图片 → 发给其他人查看

## Brand Personality
- **专业金融终端**，不是花哨的 SaaS 仪表盘
- 紧凑、高信息密度、精确
- 参考：同花顺、东方财富、TradingView 的专业感
- 数据驱动：数字用等宽字体、涨红跌绿、状态徽章
- 克制：不滥用毛玻璃/渐变/圆角；细线边框、精确间距

## Design Constraints
- 框架：Streamlit（Python），通过 `st.markdown(unsafe_allow_html=True)` 注入 CSS
- 图表：ECharts（已嵌入）
- 配色：A 股惯例——涨红(#e33d47) 跌绿(#0b9b64)
- 字体：正文 PingFang SC，数字用 SF Mono / JetBrains Mono
- 布局：右侧输入栏 + 主区域看盘

## Differentiation
- 不是通用仪表盘，是 **LEI 方法论专用看盘器**
- 信号标记（◆底部确认 / ◆顶部确认 / ×失效）是核心视觉语言
- 多周期共振（日/周/月三色）一眼可读
