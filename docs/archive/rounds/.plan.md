# Plan: MACD 指标 + 强度解读 + 盲区补齐 + 前端副图 + agent skill

## 背景 & 设计原则（内化用户的 MACD 解读框架）
系统目前缺 MACD 指标及其解读。按用户原则实现：

- **定义**：MACD 研究均线的扩散和密集状态，本质是**乖离率**，表示的是**强度**，不是转折趋势节点。
- **趋势转折 5 步骤，MACD 能/不能表达**：
  1. 破线（close 破均线）— MACD **不能**表达 → 由系统既有 LEI 颜色（close vs EMA20 vs close_lag20）补齐
  2. 均线拐头 — MACD **不能**表达 → 由系统既有均线斜率（ema20_slope / sma slopes）补齐
  3. 交叉 — MACD **能**表达（DIF/DEA 金叉死叉）
  4. 多头排列和乖离率 — MACD **能**表达（DIF 在 0 轴方向 = 排列强度；hist 幅度 = 乖离扩散/收敛）
- **结论**：补齐 MACD 看不到的「破线 + 均线拐头」（系统已有），即可用 MACD 观察趋势强度。
- **红线**：MACD 是强度非转折 → **不产生买卖事件、不构成买点**；金叉/死叉只作强度描述，绝不当入场触发。provenance = research_proxy，界面标「研究代理」。

参数决策（已确认）：标准 MACD(12,26,9)。范围（已确认）：后端 + agent skill + **前端 MACD 副图**。

## Phase 2: MACD 强度解读（解读层）

### 2.1 解读模块 `src/lei_signal/rules/macd_strength.py`（新）
- `@dataclass MacdStrengthReading`：`status`（多头扩散/多头收敛/空头扩散/空头收敛/交叉中）、`dif`/`dea`/`hist`/`prev_hist`、`cross`（金叉/死叉/无）、`dimension_value`（支持/冲突/中性）、`label_cn`、`detail_cn`、`blind_spot_cn`。
- `read_macd_strength(row, prev_row) -> MacdStrengthReading | None`：
  - 交叉：DIF 与 DEA 上下穿 → 金叉/死叉（MACD 能表达的「交叉」）。
  - 扩散/密集：hist 同号且 |hist| 放大 → 扩散（多头=支持 / 空头=冲突）；|hist| 收缩 → 收敛（中性）。
  - 0 轴方向：DIF>0 = 多头排列乖离方向；DIF<0 = 空头。
  - `blind_spot_cn` 固定文案：「MACD 仅表达交叉与多头排列乖离（强度）；破线见 LEI 颜色，均线拐头见均线斜率」。
  - MACD 列缺失/NaN → 返回 None（不崩）。

### 2.2 接入解释器 `src/lei_signal/compose/interpreter.py`
- `build_assessment`：取 `row` + 前一日 row，调 `read_macd_strength`。结果转 `Factor`（dimension="强度(MACD)"，rule_id="macd_strength"，provenance=get_rule(...).provenance，values 带 dif/dea/hist），按 `dimension_value` 进 supports 或 conflicts。
- `_build_dimensions` 加 `"强度(MACD)"`：扩散=支持 / 收敛=中性 / 空头扩散=冲突。
- 维度与 Factor 经既有 `AssessmentDTO`（`symbols.py:1289`）自动透出 API 与前端 `AssessmentPanel`，无需额外接线。

### 2.3 解释文案 `src/lei_signal/api/explanations.py`
- 加 `macd_strength` 条目：definition（强度/乖离，非转折）+ 5 步骤能/不能表 + 盲区补齐映射 + 用法（看强度不看拐点）。供前端 `ExplanationPanel` 与 agent 接地查询。
