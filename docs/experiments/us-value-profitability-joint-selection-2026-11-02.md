# 因子组合下一步：便宜与盈利联合选股的实际检验（2026-11-02）

## 一句话结论（大白话）

**本轮实际测了“便宜且盈利高”的联合选股，目前应降低这条具体规则的优先级。** 初始极端交集过于集中；补做一次固定分散度对照后，2015—2024年较大规模组年化6.61%，低于同池仅盈利的10.73%，月末最大回撤也更深。较小规模组同样落后。已有研究里，盈利×低资产扩张仍更值得优先复验，A股动量×经营现金流保留有限线索；都尚未成为个人净收益已经验证的策略。

**本报告是公开历史股票组的毛收益比较，未扣真实费用，不提供可执行个股名单。** 数据为French当前202609重建版本，预定截止2026-08；原始历史名单、财报首次可见时点、逐股权重/成交、行业风险及个人成本没有补齐。广义美股市场是市场参照，16格是同源同规模对照，均不冒充这些自定义组的可投资母指数。近期及早期历史都是探索性证据。

## 2. 金融含义、Universe和规则

“便宜”准确指账面权益/市值较高；“盈利”指收入减销售成本、销售管理费用和利息后，除以账面权益。它们不是所有价值或质量指标的总称。原始方法见[French规模×账面市值比×经营盈利32组说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/32_ports_me_beme_op.html)。

来源在每年6月底，以NYSE市值中位数分大小组，再在各规模内按NYSE四分位分别划分价值、盈利，两者交叉得到每规模16格。覆盖其合格NYSE/AMEX/NASDAQ股票，包含金融和公用事业；不是标普500、罗素2000，也不等于A股大小盘。使用此前财年账面与经营数据和前一年12月市值，来源重建时点并不证明原始披露时点已经本地核准。

假说是：便宜股票中的经营支撑能补充单纯便宜或单纯盈利。竞争解释包括市场/行业风险、周期性困境、财务口径、集中度及单独盈利。不能指定一个没有证据的“亏钱对手方”；收益也可能是承担风险的补偿。账面市值比乘经营盈利比率，在相同账面分母下近似化为经营利润/市值；因此两指标并不自动代表两份独立优势。联合排名阈值也不等同于直接按该乘积排序。

| 项目 | 本轮冻结规则 |
| --- | --- |
| 初始候选 | 每规模BM最高四分位且OP最高四分位，单一公开交叉格 |
| 初始对手 | 同32格的最高价值行、最高盈利列、两者各半、全部16格参考 |
| 补充候选 | 两项均在上半区，4格各25%资金；仅这一项事后分散度诊断 |
| 补充对手 | 同32格上半价值8格、上半盈利8格、两者各半、全部16格参考 |
| 资金 | 每段从100美元开始，无外加资金；跨格按月重置权重，内部按来源收益；无杠杆或做空 |
| 费用 | 全部毛收益；跨格重置及组内交易成本未测，不虚构固定扣费为个人净回报 |
| 日期与未知 | 1963-07—2014-12：618月；2015—2024：120月；2025-01—2026-08：20月。全部32格、计数和市场月数完整；不填零/选择性删月 |

主要十年中，较大规模联合格的公司数只有2—16家，中位5家；较小规模20—40家，中位26家。数量不是有效分散程度，市值权重还可能更集中。原始文件中大规模联合格2016-02单月−44.5960%，小规模联合格2020-03为−43.9373%；这些尾部没有被删掉。

已从同一官方源取得TXT版本核对：759月×32格与CSV均在TXT两位小数的0.005个百分点舍入范围内。首次误用逐值精确相等失败的记录保留。该核对验证格式和读数，不是独立供应商或逐股原件认证。

这一发现促成唯一补充诊断。上半区联合的公司数量扩大为较大规模70—132家（中位90），较小规模208—458家（中位289）。集中度问题有所缓解，但主要十年的收益/回撤仍不如同池盈利或简单混合，因此不能只归咎于“股票太少”，也没有理由继续试第三个阈值。
