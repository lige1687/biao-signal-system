# 连续讨论二轮补修：ATR 继续讨论可达 + 用户事实语义与精确归属

## 一句话结论（大白话）

主控二轮复验发现的两个循环/误记问题已修好：点「继续讨论（不做数值比较）」现在真的能继续聊——概念类问题（「ATR止损是什么意思」）正常讨论，明确要求比较/换用 ATR 的仍然老实说「这项比较暂未支持」，而且问这些问题时聊天对象不会再被「ATR」三个字母拐到一只同名美股上；聊天记录也不会再把「如果我有一万」「朋友有一万」「手里有一万闲钱」当成你的真实预算或持仓——记忆只认绑定到具体问题和具体标的的声明，你改口（「我已经不持有了」「不是一万，是五千」）会立即生效且不前后矛盾。

## 1. 收口一：ATR 拦截后的继续讨论必须真实可达

- **概念与执行分开**（`web/src/utils/agentUx.ts`）：检测到 ATR 退出词后，若消息明确是概念解释/思路讨论（是什么意思/解释/聊聊/讨论/只讨论/不要求回测/不做数值比较等）则放行正常讨论；否则保持「暂未支持」拦截。比较/换用请求（换成ATR…胜率变化/用ATR补测效果）仍被诚实拒绝。不是只改一条草稿规避正则——放行靠的是问题语义，草稿只是恰好属于思路讨论。
- **对象不被指标词截走**（`api/routes/agent.py`）：「ATR」被 `_symbol_candidates_from_message` 当美股代码探测（纯字母 token 语法合法即收）。新增指标词守卫表：ATR 与止损/止盈/缓冲/距离/指标/真实波幅等共现时跳过证券认领；「看看ATR这只股票」「ATR现在怎么看」仍按证券身份解析（不全局禁用代码）。目录层同名守卫同样补上（双保险）。
- **拦截轮显示名**：拦截轮没有依据卡，两入口标题/上下文条曾短暂显示「名称待核实」——标签查找改为取最近一条**带名称**的同对象轮（对象身份从未丢失，纯显示问题）。
- **两入口浏览器链实测**（真实 Chrome + 真实构建）：515880 上下文 → 比较问法被拦截且上下文保持通信ETF → 点「继续讨论」发送 → 获得讨论回复（非拦截复读），补测任务数为零 → 概念问法正常讨论回复。工作台 5/5、控制台 4/4 全过（r2-atr-chain-notes.json + 3 张截图）。概念/继续讨论/显式比较三种输入的函数级回归进 `run-agent-ux-regression.mjs`（`npm run test:agent-ux` 通过）。

## 2. 收口二：用户事实先核语义与归属，再进记忆

- **语义守卫**（`copilot/resolve.py`，五例全修并保留正例）：
  - 「如果我有一万元」假设句、「朋友有一万元闲钱」第三人 → 不写成预算；
  - 「我手里有一万元闲钱」现金不是证券 → 不识别为持仓；「朋友持有这个」第三人 → 不识别；
  - 「我已经不持有了」等正常否定表达进撤销词表（清除旧持仓背景）；
  - 「不是一万，是五千」先清后立：旧值清除与新值 5000 在同一条消息内顺序一致，`user_budget` 与 `user_background` 不矛盾。
- **精确归属**（`api/routes/agent.py::_user_background` 重写）：改用现成的 `message_id`（用户问题）↔ `question_id`（assistant 回答）绑定认领事实——无 message_id 或尚无绑定回答的声明标未知、不可继承；不再按「后面最近一条 assistant」跨下一条 user 猜归属；中断后重试/同一问题多个回答共享 question_id 天然按同一问题处理；symbol 未知（全局）不收集任何背景。
- **成本措辞**：降级直出不再固定说「你没给成本」，改为「成本信息这段系统直出未核实（系统目前没有成本提取能力），不编造」。
- **固定矩阵**（全部有测试，路由级用临时库真实 message_id/question_id）：五例反例 + 持有/预算用途继承正例 + 不同对象不串 + 声明无回答不继承 + 本条更正金额 + 明确撤销后清除。
- 路由链补充实测（隔离服务真实缓存）：c7/c7b 资金分支记住 10000 元与闲钱、不重复追问；c8 同对象比较口径不变（cfix-chain-probe.json 为 C-fix 轮证据，本轮身份绑定改动不影响该链结论——路由级测试已覆盖身份绑定）。
