## 为什么值得补这一项

原600只历史A股的价格资料中，招商积余001914在2013-01-04至2019-06-05的1560行返回了与请求不同的价格口径。此前再次请求当前代码仍未解决；这使同池比较的132个月中有63个月无法直接使用。供应商返回“成功”不足以证明价格可比。

[2019年12月16日更名更码公告](https://static.cninfo.com.cn/finalpage/2019-12-16/1207164397.PDF)提供000043与001914的身份联系。此前取得的是官方检索正文，未冒称读取了全文。代码更改日与2019-06-06的价格断点不同，不能只靠名字关联解释价格断点；本轮实际取得旧代码的报价与公司行动记录加以核对。

本轮只回答这一家公司的历史价格链，不扩股票池，不计算新的收益，也不代表600只股票的年度价值分母全部齐备。
