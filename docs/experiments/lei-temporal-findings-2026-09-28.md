# 黑绿因子按时间推进：过去的偏强，后来保持了吗？

## 一句话结论（大白话）

**没有看到全期的绿色上涨优势稳定延续到后续各半年段。** 固定19、20、21、22、30日参数后，5日绿色上涨比例高于当期平常水平的段数分别为2、3、3、2、2段（共7段）；黑色5日亏损比例偏高，各参数都只有1段。不能因此反过来认定黑色是买点。这次是已看历史的时间推进检查，真正未见资料的验证尚未发生。

## 1. 这次跟以前有什么不同？

此前把2022年至2026上半年合在一起看；本轮用2022年起的资料作过去参考，然后依次检查2023上半年至2026上半年七段。每段只使用当时已经完整结束的过去结果作参考；新段的未来观察窗口也必须在该段内结束。跨分界结果不混用，不把未来标签提前算进过去。

参数、期限和ETF都固定，没有选冠军、拟合模型或滚动调参。因此准确说是“固定因子的时间推进稳定性检查”，不是训练模型的walk-forward。**所有这些历史此前已被看过，所以绝不称为真正未见样本外验证。**

仍是道路层原生颜色：绿色为价格高于同周期指数均线及N日前价格，黑色相反，相等为灰、缺价为未知。分析每日状态，不限首次变色；未来5/10/20/30日均从信号次日收盘起算。每段基准是同ETF全部有效日期，含绿黑灰，不能当独立组。先各ETF统计，再六只各占六分之一，不是组合收益。
