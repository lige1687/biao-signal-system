# EMA120负乖离：标的范围、牛熊分组与增量验证（2026-09-28）

研究状态：探索性的时间顺序历史重演，限定批次已完成并独立复核。没有真正新资料验证或生产授权。

## 一句话结论（大白话）

价格明显低于120日指数均线后，反弹线索主要出现在偏熊环境；但把近期涨跌幅、波动和市场状态已有的信息扣除后，增加乖离程度使整体预测误差反而增加约0.98%。本轮没有支持它提供稳定的通用新增信息，也不能据此判断所有乖离研究方向无效。

## 1. 决策问题与停止条件

本轮服务策略规格§4.7的路牌研究：评估乖离能否增加判断信息，不形成入场、退出或仓位规则。研究对象为负乖离时未来20个交易间隔的价格涨跌；没有完整账户、费用或收益承诺。预算固定一批、两个模型各三个年份、三个阈值描述检查；禁止根据结果换标的、模型、期限或挑选参数。

## 3. 公平对照与时间隔离

基础模型使用20日及60日涨跌幅、20日波动、ETF身份和统一市场状态；另一个模型仅增加连续的负乖离程度。两者使用完全相同的日期与ETF记录。固定岭回归，含义是限制系数过大以降低对历史细节的迎合；惩罚强度固定1，不搜索参数。目标函数依据[官方岭回归说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)，实际计算由NumPy完成。

各输入的缩放只在训练资料上计算，之后应用到后续年份；符合[官方数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)中的训练与检验分离原则。训练标签终点必须早于下一年开始，预测年末跨界标签排除。2024、2025、2026上半年分别用之前已经到期的资料拟合，模型在预测时期内固定。

主要比较各ETF的平均平方预测误差，再将六只ETF等份平均，使记录较多的产品不会自动占更大权重。改善为正表示误差下降，为负表示变差，**不是账户收益率或亏损率**。

## 6. 过拟合检查与反例

过拟合指规则过于迎合已经看过的历史，换时期后失效。本轮固定以下检查并保留不利结果：

- 时间顺序推进、清除跨年未来标签、仅训练期缩放；两模型严格同记录比较。
- 不搜索模型或惩罚强度，完整报告三个年份、六只ETF和三种市场状态。
- 将连续60个交易日一起重复抽取，并让同一天的六只ETF一起变化，避免把重叠的未来涨跌和共同市场冲击误当成独立证据。2000次中2000次有效；误差改善的95%重复抽取范围为**−63.82%至+5.22%**，既包含好转也包含恶化。它只描述固定模型下的历史不确定性，不包括重新训练和研究选择的影响，不是因子有效概率。
- 负乖离8%、10%、12%三个相邻切点全部报告。偏熊环境下，极端负乖离组相对中度组平均后续涨幅分别高4.76、3.92、4.30个百分点；共同合格ETF数分别6、6、5，不能直接选最高者。偏牛三种切点均没有符合每组至少10条记录的共同ETF；过渡仅8%切点有3只合格。未见10%单点特别突出的结果，不代表已经排除过拟合。

所有历史已被此前研究看过，本轮是时间顺序历史重演，**真正新资料验证尚未执行**。首批极端负乖离仍出现超过20%的后续下跌，反弹不是保证。前期失败和更改历史保留在首批报告及尝试账；本轮不因不利结果追加模型。
