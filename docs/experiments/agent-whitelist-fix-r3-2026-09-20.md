# Agent 数值白名单误拦修复 R3：身份标记准入（2026-09-20）

## 一句话结论（大白话）

上一轮修复后，聊天助手引用你之前说过的基金代码（如 510300）时仍可能被
"防编数字"保护误拦。这一轮再加一道关卡：只有你原话里**明确说"这是在指
某个代码"**（比如"我要讨论的标的代码是 510300"）时，这个数字才会被当成
代码放进可信名单；像"账户金额是 510300 元""成交价 510300.25 元"这种
长得一样但其实是钱数的，一律不放进来。防编数字的保护没有被削弱：助手
自己编的代码、你当前消息里编的代码，照样被拦。

## 背景与前情

- R1（1eb0d61b）：会话历史标的代码入白名单，解决 S4-2 好答案被误换成
  降级模板的问题。
- R2（6246eea6）：收紧为"恰好 6 位 + 前后无相邻数字 + 交易所前缀合法 +
  仅用户消息"。被 GPT ITERATION:20 BLOCK，反例：
  - "账户金额是 510300 元"——6 位、无相邻数字、51 前缀、来自用户，但它是金额；
  - "成交价是 510300.25 元"——小数点不算相邻数字，整数部分仍命中。
- 结论：**形状过滤不充分**。GPT 最小要求：用户文本中的数字须有明确标的
  身份依据才可入补集；无法区分时不加入，保留既有降级。不得用继续枚举
  前缀或排除特定数值代替身份判别。

## 本轮改动（R3 身份标记准入）

实现：`src/lei_signal/api/routes/agent.py::_history_symbol_numbers`

1. **身份标记模式集**（`_HISTORY_CODE_IDENTITY_MARKERS`，注释即文档）：
   6 位数字必须紧邻明确标的指向语境才入补集——
   - `代码 / 标的代码 / 证券代码 / 股票代码 / 基金代码 / 指数代码 / ETF 代码`，
     后可接 `是 / 为 / ： / : / =`；
   - `标的（是 / 为 / ：…）`——"讨论的标的是 510300""标的 510300"。
   - 「标的」分支要求其后只允许 是/为/冒号/空白再接数字，
     "标的成本 510300 元"不命中。
2. **形态护栏**（`_HISTORY_CODE_TOKEN`，防御纵深，非身份判别的替代）：
   - 拒绝小数整数段（`510300.25` 的 510300 不算代码）；
   - 拒绝紧跟计量单位（含间隔空白）：`元/股/份/手/张/%`——
     "510300 元""510300 股"是金额/数量。
3. **无标记→不加入**：该句数值不进补集，回复由既有 chat_fallback 降级
   模板承接（不关闭防护）。
4. **R2 边界保持**：前缀合法（沪 60/68/51/56/58；深 00/30/15/16/18）、
   仅扫 `role == "user"` 消息。
5. **表述口径**：前缀集合是**本补集支持范围**，不是证券存在性证明。

## 绕过排查（主控复核点）

- "代码忘了，账户 510300"——窗口需以 `代码(是/为/冒号)?` **结尾**，
  "代码忘了，账户 "不命中 → 不入。
- "这个标的成本 510300 元"——「标的」后夹了"成本" → 标记不命中；
  且"元"单位护栏兜底 → 不入。
- "标的 510300 股"——单位护栏（股）→ 不入。
- 已知残余面：用户在明确标的语境后接数量单位以外的量词（如"510300 份"
  已拦，罕见自定义量词不拦）——属自然语言固有歧义，保留降级兜底即可。
