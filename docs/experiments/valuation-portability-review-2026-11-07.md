# ERP框架跨行业与个股：可以复用计算，不能直接复用仓位结论

**赔率适配器值得保留，现有建议和代码不能直接成为全品种交易引擎。** 本轮已实现研究用参考计算并完成确定性验证：统一估值方向、正确滚动MAD、缺失/预热处理、明确的MA20条件、仅使用此前带宽的分位参照。未把沪深300仓位表迁移到行业、未新增交易指令。

当前数据回答：**行业行情及ETF—指数关联已有；在已检查的权威数据目录和当前基本面服务中，尚未建立行业PB/PS/股息率/预测PE的可回测历史链。** 有当前快照或行情接口，不等于已有过去每个时点可得的估值。不能据此计算行业轮动收益，更不能把缺失估值换成价格指标后继续标注ERP。

## 1. 哪些建议保留，哪些需要改

| 建议 | 复核判断 | 工程处理 |
|---|---|---|
| 将估值拆成适配器，统一“越大越便宜” | 保留；统一的是方向和量纲，未统一未来回报或风险 | 显式选择指标，输出原值、中心、尺度、有效观察数与Z值 |
| 周期行业一律用PB、科技一律用PS | 过度概括；PB也受资产减值与盈利能力影响，PS不处理利润率变化 | PB/PS作为候选，保持原始财务口径与适用性说明，不按行业名自动采用 |
| `1/PB - Rf` | 不成立：账面价值/市值不是年度盈利收益率，不能解释成股债收益差 | 不实现该公式；负PB或负PS可形成自身历史相对估值指标 |
| 高PE板块的ERP对国债利率“极不敏感” | 算术不成立：在PE固定时，`d(100/PE−Rf)/dRf = −1` | 删除该理由；历史ERP为负也不能单独证明指标无用或资产应卖出 |
| 均线“100%原样复用” | 计算公式可复用；有效参数、复权、停牌、交易成本与收益结论不能保证相同 | 复用特征计算，不直接复制仓位上限 |
| 拥挤度防止价值陷阱和顶部踏空 | 属于待检验假设；成交额分母、天量与滞涨期限尚未定义 | 示例的`turnover`根本未参与计算，不能宣称已经有拥挤风控 |
| 稳健龙头“盈利没有暴雷风险”、股息差更精准 | 没有证据支持这种保证；分红和盈利都可能改变 | 不采用此表述，也不据此许可个股重仓 |
| 价格与长期均值回归平替ERP | 可以另做价格位置观察，但不再是估值或盈利信息 | 明确命名为价格位置；必须对纯趋势检验增量，不能改名冒充估值 |

PB与ROE、PS与利润率等基本面共同决定相对估值，不能只看历史低分位。[Damodaran估值教材](https://pages.stern.nyu.edu/~adamodar/pdfiles/uValue/uValuebook.pdf)给出这些关系；其[相对估值讲义](https://people.stern.nyu.edu/adamodar/pdfiles/eqnotes/relintro.pdf)也列举周期制造业使用正常化盈利的做法。这里据此作出的工程判断是：按行业一刀切换因子不充分，尚需经营质量与口径资格，资料并未证明某个择时仓位表有效。

`100/PE−Rf`本身也是盈利收益率差的观察代理，不是完整的前瞻预期风险溢价模型。股息率差同样不包含全部资本利得、分红持续性和权益风险。

## 2. 示例代码中的明确问题与反例

### MAD用了不同的中位数

正确MAD是在**同一窗口里**，对所有值减去**该窗口同一个中位数**后取绝对偏差中位数。原代码先逐日减各日自己的滚动中位数，再对残差滚动取中位数，计算对象变了。[SciPy官方定义](https://cache-docs.scipy.org/doc/scipy/reference/generated/scipy.stats.median_abs_deviation.html)也明确这一点。

固定序列1至10、窗口5，最后窗口是`[6,7,8,9,10]`：

| 算法 | 中心 | MAD | 最后一个值的稳健Z |
|---|---:|---:|---:|
| 示例两次rolling | 8 | 2 | 0.67449 |
| 同窗口MAD | 8 | 1 | 1.34898 |

这是可复现的数值偏差，并非风格区别。参考实现使用1.4826022185的正态一致性缩放；稳健Z并不等于正态分布概率，也不能把其±2直接当作标准差带完全相同的触发频率。MAD为零时返回缺失，不除零、不给无穷大的“极度便宜”。

### 一分或两分不等于站上MA20

用120天价格构造的反例：前60天80、随后40天95、再19天100、最后一天99。此时收盘99、MA20=99.95、MA60≈96.65、MA120≈88.325，计分为2，**价格仍在MA20下方**。

- 若左侧限制要求“重新站上MA20”，必须直接检查`close > ma20`，不能用`trend_score >= 1`代替。
- 原示例把“2分且站上MA60”也归为多头；这个反例会被归多头，已经改变此前“仅3分为多头”的定义。
- 严格大于的三个条件全为假，也可能是价格与均线相等；0分不总是严格的`P < MA20 < MA60 < MA120`。参考层将其注明为“空头或平坦”，避免等号被错误解释。

### 预热、参照时间与缺失值

| 检查 | 原代码风险 | 已验证的参考处理 |
|---|---|---|
| MA120未满 | NaN比较为False，会过早得到0分；min/max默认跳过NaN又会得到假带宽 | 全部均线有效前，分数、状态和带宽均为缺失 |
| 750行但`min_periods=250` | 不代表每次都用了三年；两次滚动的示例MAD在第499行才首次有效 | 默认完整750个有效观察；若显式缩短预热，记录实际有效样本数 |
| 750个此前带宽值 | 还需要MA120预热 | 连续完整价格的第870行才有完整“此前750个带宽值”的阈值 |
| 当前带宽进入自身分位 | 不符合“自身过去历史”参照约定；并非只因含当前值就叫前视 | 阈值使用`spread.shift(1)`后滚动，方向和压缩状态分别输出 |
| 负PE、非正PB/PS、无限值 | 可能制造假便宜；缺失财报或稀疏日期被当作日频 | 无效值保留缺失；不自动补成0或替代为另一个因子 |
| 日期与交易时间 | 排序、缺交易日、晚披露或修订数据可能造成错位 | 拒绝乱序/重复日期；调用方仍须提供完整交易日索引和决策时已知的数据 |

使用当前完整收盘计算当前状态是允许的，但不能假设以更早的同日价格成交。当前参考计算不自动认证财报公开时点，也不解决历史修订；这些限制写在接口说明和结果属性里。

固定验证还覆盖：已知极端样本MAD、股息率为0及负利率、改变未来数据不影响过去输出、截断后过去输出不变、一个缺价使其依赖的120个趋势窗口失效。10组确定性检查通过；这只验证数学与计算边界，不是市场胜率验证。

## 3. 现有数据究竟到哪一步

本轮读取并核过本项目`acquired-data-catalog.json`、当前基本面服务、基金行业映射、机会来源配置；外盘行业资料包及两张价格表SHA与登记一致，实际读取行数与登记一致。没有扫描整个私人磁盘，结论限定为这些权威入口。

| 对象 | 已有、已核内容 | 对本方案的缺口 |
|---|---|---|
| 沪深300 | 已有同口径PE/ERP观察链与本日已完成研究 | 周频观察、滚动3个日历年，不是这份示例的日频750行；历史版本不能自动视为当时已知 |
| 通信ETF 515880、半导体ETF 512480 | 已有对应中证通信设备、全指半导体指数的业务参考关系 | 关系表不是PE/PB/PS历史；还需历史跟踪关系与估值定义 |
| 沪深300十行业指数 | 2024-03-12至2026-11-02，640日×10列价格，已核SHA和行列 | 无估值列；也不足完整750行估值窗或870行带宽预热，不代表申万31行业 |
| 美国11只Sector SPDR | 2024-11-04至2026-10-30，499日×11列价格，已核SHA和行列 | 是拆分调整价格，不能当分红总收益；没有配套同口径历史PS/PB/预测PE |
| 机会来源与行业快照 | 有单日估值、当前行业快照等参考材料 | 单日值不能造三年序列；TTM与Forward PE不可直接拼接 |

另发现当前行业快照处理器将注释为动态PE的`f9`映射到名为`pe_ttm`的字段。**本次未将该字段作为TTM历史输入，也未据此改变原服务。** 接入行业估值前必须核实供应商字段含义及所有消费者，不能只因字段名看起来匹配就使用。当前检查没有证明各数据供应商无法提供行业历史，只说明本系统尚无可直接用于所述回测的合格链路。

也核了已连接长桥工具：`valuation_history`声明只提供PE历史，`industry_valuation`声明为行业同类个股比较及其历史，均不承诺ETF底层指数的PB/PS序列。实际两次查询中，中际旭创`300308.SZ`的行业估值返回空列表，半导体ETF`512480.SH`的PE历史也为空。两份原返回保存于[接口核验](raw/valuation-portability-review-2026-11-07/connected-source-probes.json)。这只证明这次两个对象没有返回可用历史，不能推断所有股票或供应商都无法提供；同业个股比较也不能冒充指数估值。

外盘资料位置与源代码指纹、实际列名见[资料核验记录](raw/valuation-portability-review-2026-11-07/data-readiness.json)。没有新增付费购买、批量下载或跨项目取数。

| 新内容相对什么比较 | 可确认的增量 | 不能据此得到的结论 |
|---|---|---|
| 正确MAD对示例双rolling | 固定反例尺度由2纠正为1，Z由0.67449纠正为1.34898 | 不等于收益提高或更早抓底 |
| 动态带宽对固定阈值 | 变为相对自身历史的压缩程度，并明确此前参照 | 不自动保证更稳、更少交易或最优25%阈值 |

原沪深300反例仍成立：2020年计分连续收益1.42%，固定50%为13.00%；2024年9月指定急涨段连续版14.86%，持有22.05%。指数不退市并不能证明左侧70%仓位合理，尤其不能移植到单一行业或个股。

## 5. 已落地的边界与后续入口

参考实现位于[reference.py](raw/valuation-portability-review-2026-11-07/reference.py)：`OddsNormalizer`支持盈利收益率差、负PB、负PS、股息率差及MAD/标准差两种尺度；`trend_features`输出严格计分、显式站上MA20、独立带宽和压缩状态。没有内置仓位矩阵、板块自动分类、实际下单、拥挤度或止盈，也没有在估值缺失时暗换价格代理。

前端若接此观察层，足够显示：**指标名称/原值及日期、历史相对位置、趋势0—3分、是否站上MA20、带宽分位、数据是否齐备**。估值缺失直接显示缺失；未验证前不展示“建议满仓”“保证胜率”或用统一Z横比各行业的预期回报。保留原观察板，本轮没有给它塞入一套尚无数据的新卡片。

后续能改变采用判断的条件已明确：先取得同口径且有可得时间记录的行业估值及可交易收益链；冻结ETF名单/历史跟踪变化、拥挤度分母和时间窗、建仓/减仓/再入场与组合约束，再对纯趋势、固定配置及估值单因子作同资金、同费用比较。阶梯和连续函数也要固定插值锚点；“相差10%才调仓”必须定义为权益仓位百分点，明确含价格漂移的实际仓位。缺失估值时保留缺失，是本轮证据边界，未启动这些额外研究。
