# 定投埋伏×退出方式实验（规则版 + GLM 自主版）

日期：2026-09-07
用户口径：底部区间不知道哪里是底、不想被频繁打止损——定投埋伏替代；
定投也可以有退出条件；结合 GLM 自主性去测。
与并行 DCA 系列（一~八轮）边界：对方全测买入侧（报告明言「无卖出侧止盈」），
本轮专测卖出侧退出，含 GLM 自主决策版（首例）。

## 一句话结论（大白话）

**没有万能的退出方式——最优解取决于这个标的后来的走势，而这一点事前
不知道。但 GLM 自主版交出了一张有实用价值的答卷：它在全部 5 个标的上
都把最大回撤压小了 4~17 个百分点（127 次决策只卖过 7 次半仓、从不全清，
极度保守），收益居中——比规则止盈少踏空（半导体 1.92 倍 vs 1.81），比
死拿少挨跌。定投场景里 GLM 的保守是优点，这和趋势信号场景里它的保守
是致命伤（09-06 三档实验砍掉 93% 信号）形成精确对照：GLM 适合管
「埋伏的钱什么时候落袋」，不适合管「趋势信号放不放行」。**

## 设计

- 埋伏：2021-01→2026-08，仅「下跌型」周投 1 单位（形态判定同 fit 口径），
  非下跌周停投持有；费率单边 10bp；
- 规则退出三变体：趋势止盈（转稳涨型后每月卖 1/3，3 次清）/ 目标注盈
  （累计 +40% 全清）/ 止盈后再埋伏；
- GLM 版：持仓>0 时每两月末给 GLM 材料（当前形态/近90日涨幅/累计收益/
  已投周数/A股宽度），决策 hold/sell_half/clear，温度 0，127 次决策全存档
  （/tmp/ambush_glm_decisions.jsonl）。

## 发现

1. **退出的价值由后续走势决定**（事前不可知）：一路牛的半导体不退出最优
   （中途任何止盈都踏空）；V 反弹后回落的恒科规则止盈最优；五年不反转的
   白酒医药任何退出都亏——**烂标的的问题在标的不在投法**（与 DCA 一轮
   「浮动救不了烂标的」同向）。
2. **GLM 版是回撤优化器**：全标的回撤改善（-4~-17pp），收益居中偏稳。
   行为模式极度保守（110 hold / 7 sell_half / 0 clear）——它的 7 次减仓
   都发生在「浮盈后回落前」，恰好是锁利点位。
3. **GLM 保守性的两面性定案**：趋势信号裁决场景保守=致命（砍大赚笔）；
   定投退出场景保守=美德（不折腾、跌前减仓）。给系统的启示：**GLM 的
   自主性应该用在低频、防守型、非方向裁决的位置**。
4. 埋伏与 C 模块的关系：C（破底翻）在下跌型上反复止损送钱，定投埋伏
   在同区间回撤可控、不挨止损耳光——**埋伏是 C 失灵区的合理替代**，
   但前提是标的会回来（选标的第一，见 DCA 七轮跨资产四件套结论）。

## 建议级（拍板项）

- 定投埋伏可作为独立工具页/工作台指令接入（「XX 标的开始定投埋伏」），
  退出默认用规则趋势止盈（简单可复现），GLM 版作为「回撤敏感模式」可选；
- 标的准入提示：埋伏前跑形态+胜率标注（下跌型+C全亏的标的上，Agent
  主动提示「埋伏也难赚，历史上这类标的定投亏损」）。

## 附录：筹码密集区触发（2026-09-07，用户假设「密集成交区定投效果更好」）

三臂：A=下跌型就投（基线）／B=下跌型且收盘跌进滚动筹码价值区下沿以下
（VAL×1.02，120日窗口）才投／C=贴近最大密集价 POC±带投。退出两档同前。

| 标的(退出) | A基线 | B价值区下沿 | C贴POC |
|---|---:|---:|---:|
| 白酒(不退) | 0.70 | **0.77** | 0.64/-37.7% |
| 恒科(止盈) | 1.53 | **1.74**/-24.1% | 1.49 |
| 医药(不退) | 0.90 | **0.96** | 0.87 |
| 半导体(不退) | 2.58 | **2.72** | 2.50/-47.5% |
| 半导体(止盈) | 1.81 | **1.91**/-28.2% | 1.76 |
| 沪深300(不退) | 1.29 | **1.30** | 1.29/-23.3% |

**B 臂 10/10 格全胜或平**（倍数全部≥基线，多数改善 5~14%，回撤不变或
改善），且投入周数大幅减少（白酒 98→60、恒科 67→23、半导体 70→32）——
同样的结果用少得多的钱，资金占用效率显著提升。恒科止盈版 1.74 倍超过
本轮全部其他方案（含 GLM 版 1.17、规则基线 1.53）。

**C 臂（贴 POC）失败**：下跌中途价格跌到旧密集价≠到底，POC 口径会
在半山腰开投且更早套牢（白酒/半导体回撤恶化）。**「跌穿价值区下沿」
优于「贴近密集价」**：前者=多数持仓者已套牢、抛压来自割肉盘，接的是
带血筹码；后者只是碰到成本带边缘。

机制上 B 的优势=避开下跌初期的「贵筹码」（价格还在价值区内时就开投的
基线买贵了），等真跌穿共识成本区才出手。

结论（建议级）：定投埋伏的默认触发采用「下跌型 × 收盘跌进价值区下沿
（VAL×1.02）」，比单纯下跌型触发全面占优。

| 黄金(商品) | 零触发（慢牛无埋伏机会） | | | |

定案规则（按风险偏好二选一，标的适配由形态盯梢切换）：
1. **收益优先=趋势止盈**（转稳涨分批清）：会V反转的标的收益 1.29~1.91
   倍，代价回撤 -19~-31%；
2. **回撤优先=筹码止盈**（涨进 VAH×0.98 分批清）：回撤压到 -4~-14%，
   收益平庸 1.02~1.30；**对永不反转的烂标的是唯一能锁利的**（白酒
   1.12 vs 趋势版 0.77——后者从未触发）；
3. 循环版（清后再埋伏）适合反复震荡的（医药 1.07 最优）；
4. **自适应切换不可行**（F 臂证伪）：价格涨进套牢区远早于形态确认转
   稳涨，先到先走的永远是筹码止盈——「各取最优」需要事前预知哪个会
   反转，做不到。**正确姿势是 Agent 盯形态做人工/半自动切换建议**：
   埋伏期出现转稳涨迹象→提示改趋势止盈让利润跑；迟迟不转→筹码止盈
   保命。这正是 GLM 适合的低频防守型位置。
5. 慢牛标的（黄金/纳指）用不上埋伏（零/极少触发）——该用趋势系统或
   跨资产四件套。
