## 一句话结论（大白话）

**判定：证据不足（按跑前写死的判定线）。**"长短期分层"用人话讲就是：月度的大气候信号
说"这个月可以动手"，但不动手，等日频的恐慌信号出现的那一天再动手，赌它能挑到更便宜的
入场价。在创业板 14 年历史上 22 个"大气候允许"的窗口里实测：等恐慌信号确实能挑到明显
更好的入场点（在等得到的 9 个窗口里，比月初机械动手平均好 7.7 个百分点，9 个里赢了 8 个）；
**但 22 个窗口里有 13 个（59%）等到窗口关门也没等到恐慌信号，整个错过——而错过的恰恰是
行情直接复苏的好窗口（平均 +5.2%）**。两项几乎精确抵消：净改善每窗只有 +0.07 个百分点，
把持有期拉长到 120 天，净差还变成 -3.4 个百分点。对用户的意义：这套"一层分层"在创业板
上不挣钱也不怎么亏钱，纯属多一层复杂度换不来东西——按总纲的警告，不值得为它搭多层框架；
分层这个想法在"等更深恐慌"这个具体形态上已被证明是纸上谈兵。

> 词汇表（第一次出现先解释）：**宽度（B200）**= 全市场个股里收盘价站在自己 200 日均价
> 上方的比例（0-100），低=大多数股票在深跌（恐慌），高=大多数股票在涨（热度）；
> **B50** = 同口径换成 50 日均价，反应更快；**双极值警报（双≤20）**= B50 和 B200 同一天
> 都跌破 20，即短期和长期看都在极端恐慌，系统里叫"定心丸"警报；**窗口**= 长周期信号
> 连续允许动作的一段月份；**事件研究**= 不做完整回测，只把历史上同类事件挑出来，
> 对比两种做法在事后的收益好坏；**百分点（pp）**= 百分数之差的单位，+2pp 即多赚 2%。

## 1. 背景

总纲 `docs/next-steps-master-plan-2026-09-02.md` 语义五：现有系统把"要不要做"和"具体
哪天做"合并成一个信号，设想拆开——长周期（月度宽度状态）决定这个月要不要在创业板上
动作，短周期（双极值警报）决定具体哪天执行。总纲原话警告这类设计容易滑向过度设计，
要求先做简单历史事件研究验证价值。本任务即该验证，**一层结构为限**：单标的、不嵌套、
无权重设计、无参数网格。

## 2. 一层结构定义（全部复用已验证口径，跑前写死于脚本 docstring）

| 层 | 定义 | 来源 |
|---|---|---|
| 长周期（月度状态） | 每月最后交易日收盘的 B200 < 43.3333（冠军三档的满仓档下界；档位线 43.3/56.7 由边界 30/70 三等分而来）→ 下月"允许做"；B200 为 NaN（2010-2012 成分 eligible 不足段）→ 不允许，不造数据 | `src/lei_signal/timing_backtest/presets.py::cyb_b200_ladder3_final`；归档 `docs/experiments/kuandu-quanzhan-ARCHIVE-2026-09-01.md`；档位线用源码原函数 `_fixed_edges(3,30,70)` 计算 |
| 短周期（日频触发） | 双≤20：同日 B50 ≤ 20 且 B200 ≤ 20（只用低位侧；高位侧双≥85/90 是热度警报，与入场挑时点无关） | `src/lei_signal/timing_backtest/service.py::alert_state`；同上归档"双极值警报"行（双≤20 后 120 日 13/13 标的正） |
| 标的 | 创业板指 399006（冠军证据最全口径），唯一标的 | 同上归档"冠军三档"行 |
| 执行口径 | T 日收盘信号 → T+1 开盘成交（与 `timing_backtest/engine.py` 一致，无未来函数） | 仓库引擎统一口径 |

- **允许窗口** = 连续允许月份的最大连段；窗口起 = 第一个允许月第一个交易日，窗口止 =
  最后一个允许月最后一个交易日。
- **机械版**：上月末已知允许 → 窗口第一个交易日开盘入场。
- **分层版**：窗口内（含首尾日）第一个双≤20 日的次一交易日开盘入场；全窗口无信号 = 错过。
- **进行中窗口**（数据结束时允许状态仍在延续）：不计入错过率分母；已入场且收益可算则
  计入统计；未入场则整窗剔除（状态未定，不得记 0）。
- **入场质量**：入场日开盘成交，N 日前瞻收益 = 入场后第 N 个交易日收盘 / 入场日开盘 - 1；
  主口径 N=60（约一季度），N=20/120 仅描述性参考。数据末端算不出的记"删失"并剔除。

## 3. 预注册判定线（跑第一遍之前写死，跑后未动）

设 n = 已完结窗口数，miss_rate = 已完结窗口错过占比，diff60 = 全窗口逐窗差均值
（分层版 60 日收益、**错过记 0%**，减机械版 60 日收益），matched_diff60 = 两版都实际
入场的窗口里（短信号 - 机械）逐窗差均值。判定树按顺序：

1. n < 8 → **证据不足**（样本太少）
2. miss_rate ≥ 2/3 → **无价值**（十窗七等不到，时机精度沦为抽签——任务书原话场景）
3. diff60 ≥ +2.0pp 且 matched_diff60 > 0 → **有价值**
4. diff60 < 0 → **无价值**
5. 其余（0 ≤ diff60 < +2.0pp）→ **证据不足**（改善太薄撑不起分层复杂度）

费用说明：两版每个实际入场窗口各付一次单边 10bp 费用，费用差为零；分层版错过窗口不
付费（微小优势已含在 diff60 内）。+2.0pp 的价值线远超费用量级（双边 20bp），也低于
冠军规则本身 +4.4%/年的超额水平——分层作为附加层至少要值这个钱。

## 5. 机制解读（为什么抵消得这么干净）

1. **时机精度是真的**：匹配窗里双≤20 挑到的入场点，60 日后平均比月初机械入场好
   7.68pp、逐窗胜率 89%——恐慌日买入确实更便宜，这与归档"双≤20 后 120 日 13/13 正"
   的既有证据同向。
2. **但"等更深的恐慌"这个形态自带选择偏差**：满仓档的门很宽（B200<43.3），双≤20 的
   坑很深（要求 B200 再跌进 ≤20）。只有"窗口内市场继续恶化"才等得到；**"不回头直接
   复苏"的窗口全部错过**——而那正是 60 日弹性最大的窗口（错过的 13 窗机械均值
   +5.2%，高于全样本均值 +4.0%；拉到 120 日 +10.7%，净差转负）。2013-05（+26.7%）、
   2013-07（+30.8%）、2020-04（+29.3%）三个最好的窗口全部错过。
3. **算术上两项几乎精确抵消**：[9×(+7.68pp) + 13×(-5.20pp)] / 22 ≈ +0.07pp。等待
   挣的钱和错过的钱基本一样多——这一层复杂度目前不产生净值。
4. 错过率 59.1% 虽未触预注册的 2/3 封杀线，但对应任务书"十个窗口六个等不到"的场景，
   "时机精度"的可用性已大打折扣。

## 6. 判定（三选一）

**证据不足**——按预注册判定树第 5 条：全窗 60 日净差 +0.07pp，落在 [0, +2.0pp) 区间。
严格说不是"无价值"（净差没有为负、匹配窗改善真实且显著），但也远达不到"有价值"的
+2.0pp 线；更关键的是 N=120 净差 -3.40pp 提示这一形态在更长持有期上是净损害。

**对语义五的具体含义**：
- 本任务验证的这个具体形态（满仓档月度许可 + 等双≤20 执行）在创业板上净价值 ≈ 0，
  不应进入多层框架设计——总纲警告的过度设计防线起作用了。
- 拆解显示的教训是结构性的：**用"更深的恐慌"做执行触发，等于把直接复苏的窗口全部
  让渡出去，而这正是低宽区最有价值的窗口**。若语义五要继续，方向应是"更浅或回升确认
  型"的执行触发（等恐慌缓和而不是等恐慌加深），但那超出本任务"只用已验证信号"的红线，
  需另立预注册实验，且按本研究的抵消量级，预期收益不高。
