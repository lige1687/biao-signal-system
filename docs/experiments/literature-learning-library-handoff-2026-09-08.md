## 2. 选择什么页面组织方式

考虑过三种方式：纯论文书架容易找到文章，但学到什么不够突出；纯方法卡片易读，但出处容易丢失；**推荐论文目录为主、每篇下挂学习条目，并提供主题筛选**，同时满足按文献追溯和按问题学习。

独立入口命名“文献学习库”，建议路由 `/learning`，放在现有“资料与研究”导航附近，与“实验报告库”“系统待升级”并列。不要替换 `/library` 或 `/upgrades`。名称、路由是交接设计建议，开发时先检查当前路由是否被并行任务使用；冲突则记录调整，不覆盖他人页面。

三个页面分别回答：

| 页面 | 用户的问题 |
|---|---|
| 文献学习库 | 这篇文章有什么值得学，怎么理解，什么时候适用？ |
| 实验报告库 | 我们实际测过什么，得到了什么结果？ |
| 系统待升级 | 准备推进什么，做到哪一步，由谁验收？ |

## 3. 第一版的阅读流程

### 目录

页面标题下显示一句用途说明：“从文献中学习研究方法与投资思考。”显示18篇文献、20条内容这类**从数据算出的实际数量**，不能写死。

首先展示3条学习路线：“先学会看懂一个好结果”“怎样设计值得相信的实验”“把方法放回自己的资金需求”。这只是编辑建议的阅读顺序，不表示其他文献无价值。

提供一个搜索框，可搜中文条目题名、问题、作者、英文论文题名和学习正文。主题筛选固定为：实验方法、判断标准、经典理论、投资启示。论文阅读情况与内容类别分开筛选；全部结果必须可访问，低优先条目不能被默认隐藏到找不到。

主要列表以论文分组。每篇展示作者、年份、原题名、选入理由、阅读情况、学习条目数与中文学习标题；不要将英文长题名作为最醒目的唯一信息。按推荐顺序默认展示，提供年份排序；推荐值来自编辑字段priority，不随收益排序。

### 一篇文献的详情

建议深链接 `/learning?paper=lo2000`，条目可定位为 `/learning?paper=lo2000&entry=lo2000-lesson-1`。刷新、复制链接、浏览器返回应保留定位与筛选。

先显示“这篇值得学什么”，接着论文信息与阅读情况，之后逐条展开：

1. 要学会回答的问题。
2. 作者研究了什么——仅摘要转述或已核实原文。
3. 我们从中学什么——明确标本库理解。
4. 一个好懂的例子——必须标“教学假设”，不能用回测式配色假装实测。
5. 可以怎样检查——注明是作者原方法还是本库整理的检查建议。
6. 适用条件与不能推出的结论。
7. 原文、Zotero、相关论文及本地实验链接。
8. 一个自测问题及可展开的参考回答。

同篇可以有多个条目，不复制多份论文书目。相关论文允许跨主题，比如Moreira 2017与Cederburg 2020互相链接；限制性证据必须和支持性证据一样可见。

### 与系统的关系

学习条目可以链接相关实验和OKR，但“方法已在某次研究采用”不等于“策略已被验证有效”。第一版不提供一键采用参数、修改交易规则或启动实验的按钮。

系统解释仍以 `docs/trading-spec-v1.md` 为依据。本功能服务于学习与研究说明层，不参与道路、路牌、技术入场或过滤判定。MACD只解释强度；基本面、消息和情绪不能从学习卡变成技术硬过滤。

## 4. 内容质量：什么值得收录

收录至少满足一项：与系统高度相关的经典研究；可迁移的实验或验证方法；能够澄清常见误解的理论；有出处、有条件的投资启示；对已有结论有实质限制或反证。年代久不自动成为经典，文章新也不自动优先。

“普适投资心得”在页面统一称为“投资启示”：可以广泛帮助思考，但不得写成所有市场、资金需求和风险偏好下都成立的投资指令。若启示是我们根据论文延伸的，必须标本库理解，不包装为作者名言。

每项判断标准区分四件事：是否像巧合、实际多得多少、实施是否做得到、用户是否愿意承担代价。只有核实具体原文后才能记作者的数值门槛，并写清该门槛针对的统计对象和条件。当前20条**没有填作者数值通过线**；任何空值都显示“本条未提取已核实的数值标准”，不得默认为0、通过、或统一套用70%/30条等门槛。

阅读情况按篇标：书目/摘要/部分正文/重点章节/全文精读/作者计算复现，不能由一个标签推断下一层。首批12篇旧记录未逐篇细分正文阅读范围，因此保守保留原说明；不补作全文精读。工作论文、机构报告与期刊论文分开。经典、权威、同行评审均不等于“本系统已验证”。

不同版本分别记录。Anarkulova所读是2025年3月版，不能拼接7月版数字。Kang 2026只读摘要与方法片段，不得扩写未知效果。The Three Types of Backtests原文的三类是按时间推进检验、重新抽取历史片段、依假设模拟情景；不得把本库教学分层冒充原文分类。[作者机构说明](https://www.adialab.ae/research-series/the-three-types-of-backtests)。

## 5. 数据与Zotero分工

Zotero继续保存文献书目及原有笔记；本地内容文件保存学习条目、中文教学例子、引用定位与学习路线。以稳定paper.id关联entry.paper_id；以核实的zotero_item_key跳转原条目，不能把论文题名当唯一键。

首批18篇已逐项匹配本地Zotero。第一版页面使用随项目提供的内容数据，不依赖用户当前开着Zotero，不在网页加载时调用模型生成解释或抓取全文。Zotero链接无法打开时，仍保留论文题名、标识和HTTPS原文入口；网页不能因此崩溃。

本次 `learning-library-draft/1` 是学习内容包的草案格式，**不是另一套研究证据公共协议**。如果展示实际实验数字，应引用原有EvidenceRef/MarketDataRef/RuleRef及对应报告，不把学习条目转成交易结论。结构化文件里的空值有明确意义，不由前端补猜。

第一版只读浏览，不增加登录、学习进度存储、收藏、用户编辑或自动同步。以后若用户需要可另列目标；不要因此扩大本次范围。

## 7. 页面验收：用户应该实际能做到什么

这张表是本次页面开发的验收条件，不是投资实验通过标准。

| 操作或检查 | 应有结果 |
|---|---|
| 打开独立入口 | 显示实际18篇、20条；原报告库与升级页保持可用 |
| 搜“幸运赢家”或“Sullivan” | 能定位相关文献与学习条目；搜索含正文与题名 |
| 筛选“投资启示” | 显示对应条目及其论文归属，不丢出处 |
| 打开Lo论文的一条笔记、刷新、返回 | 定位不丢，浏览器返回可回目录 |
| 从Moreira打开限制性研究 | 能到Cederburg，两个方向都有可见关联 |
| 看Kang或Anarkulova | 前者显示全文未完整获得，后者显示所读版本；不虚增证据等级 |
| 关闭Zotero后打开页面 | 本地中文内容仍可读；原文入口仍在 |
| 缺数字门槛/缺全文 | 明确显示未提取/未取得，不显示0或已通过 |
| 区分例子与实验 | 假设例子有明显文字标注，本地实验有真实报告链接 |
| 键盘和窄屏使用 | 搜索、筛选、展开和链接可访问；中英文长题名不遮挡操作 |
| 数据错误与未知ID | 给明确可恢复提示，不静默展示另一篇 |
| 检查修改范围 | 无冻结UI、交易规则、预计算、模型调用或调度改动 |

开发者运行与改动相关的类型检查、构建及必要功能核查；对来源映射、未知ID、缺字段和错误内容等真实失误点做检查。不要只验证快照数量。提交改动说明、验证记录与未完成项，再交用户验收；本稿的完成不算页面已验收。
