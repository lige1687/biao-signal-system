# 宽度能否多提醒一点风险：相同20日背景下的补充检验

## 一句话结论（大白话）

**目前不能把“高宽度”统一理解成更安全，也不能统一理解成更危险。** 相同20日确认背景下，高低宽度的下跌差异仍很不稳定；两种背景的不确定范围都包含零。尤其全期看似“高宽度少跌”的那组，在唯一高低组都达到旧数量要求的2024年反而是高宽度跌得更深，说明年份构成可能影响全期印象，而不是已找到可靠的仓位信号。

宽度在这里指沪深300合格成员中，价格站上各自200日简单均线的比例。只研究随后价格路径，不研究账户赚多少钱；“窗口最深下跌”是相对于未来观察起点的最深收盘跌幅，不是账户最大回撤。

## 本轮究竟新增加了什么

旧报告已给出这两个差值，但没有适配日期相关性的不确定范围。本轮固定60交易日连续块、2000次重抽，同一日期抽样同时用于两个Q20背景，不按高低组各自打散；有效次数分别1999、2000，超过本批90%可报告约定。两范围都包含零。

**新增的是对已有差异可靠性的认识，不是新行情或新因子。** 不改原969日期、43.3/56.7分组、21段目标、价格来源与旧状态；未重新跑账户。60日块不是万能长度，状态持续、市场变化和此前选分点仍会影响判断。

原45段互不重叠日期比较仍不足每侧10个，保留旧不足；不调整起点补样本。原文“没有区间”的旧合同不覆盖，本轮用独立追加合同授权区间补算。

## 尝试背景、来源限制与结论取舍

至少已知宽度收益、原始风险、同Q20风险三类问题；高/中/低分点源于此前策略探索，逐年和不重叠资料都看过。历史总尝试数未知；记账不等于多重检验校正。

本输入为 `breadth.csi300.b200.legacy_percent@1.0.0`：旧成分名单以约20交易日探测，可能漏掉段内变动；历史资料何时实际取得未知。经济价格用于事后研究，不能冒充可执行成交价。补区间不会自动升级这些数据资格。

保留旧“关系随20日背景改变”的描述；降低任何将−1.055个百分点当成已证实保护作用的解释。当前也不能因两区间包含零，就证明宽度对所有风险目标无用。没有概率模型，不宣称风险概率预测改善；账户减少多少回撤、仓位如何调整尚未研究，不能从本表推导。
