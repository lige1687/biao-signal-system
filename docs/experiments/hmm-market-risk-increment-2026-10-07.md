# HMM市场状态对8只ETF未来收盘下探风险的新增帮助

2026-10-07，Asia/Shanghai。采用 `research-closure` 与项目当前研究规范。用户授权：“继续看看效果哈，对我们系统有帮助的”。本轮是已见历史上的风险信息探索；原视频评估及方法试验见[原报告§12](douyin-system-increment-2026-10-07.md#12-继续检验是否帮助etf风险判断)。

## 一句话结论（大白话）

**原338日正式比较只改善0.0083个百分点，仍不能确认稳定帮助；用户要求再试后，追加16日局部核对，加入HMM反而使误差增加0.0308个百分点。当前没有形成继续投入这个固定版本的新依据，按用户要求收尾，不接入系统判定或仓位。** 追加窗口很短、结果区间高度重叠，且没有通过原研究入口的新时期完整验收，只是描述性附件；不能据此证明HMM长期无效。原正式研究及冻结产物保留，完整LEI账户收益未评价。最新附件见§10。

## 1. 最关键结果表

问题：只用当天及以前资料计算的市场状态概率，能否帮助判断每只ETF未来约一个月的收盘下探幅度？HMM即隐马尔可夫模型，用已经发生的收益与波动推断看不见的状态；这里的编号没有命名为上涨、震荡、下跌，也不是交易胜率。

预测日期实际为 **2025-01-02至2026-05-29**，未来结果观察到2026-06-30。共8只ETF、338个日期、2704条共同评价记录；相邻目标区间重叠，同日ETF相关，2704条不等于2704次独立市场验证。

平方预测误差（MSE）是每次“预测风险减实际风险”的平方再平均，越小越好；开方误差（RMSE）是其平方根，单位恢复为百分点，它不是平均绝对误差。例如预测下探5%、实际3%，差2个百分点，这次平方误差为4。

| 方法 | 平方预测误差（百分点²） | 开方误差（百分点） |
|---|---:|---:|
| 所有ETF共同的此前平均风险 | 16.848621 | 4.104707 |
| 每只ETF各自的此前平均风险 | 15.916461 | 3.989544 |
| 每只ETF最近120个已成熟结果的平均风险 | 16.439817 | 4.054604 |
| 仅区分ETF身份的固定模型 | 16.147508 | 4.018396 |
| 区分ETF身份＋HMM概率 | 16.086033 | 4.010740 |
| 已有价格背景和ETF身份（28项） | 16.152061 | 4.018963 |
| 已有28项＋HMM概率（主比较） | 16.085779 | 4.010708 |

已有28项包括21项价格/市场背景和7项ETF身份；它是本库已有研究模型的固定参照，**不是完整LEI策略或所有现有系统信息**。两种HMM比较均使用固定惩罚强度的线性预测模型，不搜索参数。

## 2. 现在知道什么

- 在本轮固定设置下，HMM对已有28项模型有很小的误差改善；两个预定比较都不能确认稳定帮助。
- 2025年平方误差改善约0.5853%，2026年1月至5月预测仅约0.0607%；不能把整体点估计说成跨时期效果已被确认。
- 8只ETF中7只点估计略改善，512800略恶化；从汇总中去掉任意一只ETF后，主比较仍为小幅改善约0.3653%至0.4604%。这只检查结果是否集中，不是排除该ETF重新训练的验证。
- 每只ETF各自的训练期历史均值，本轮误差低于HMM加价格模型。只和全ETF共同均值比会高估新增帮助，因为ETF之间原本就有风险差别；这个更细均值本身也未被确认稳定优于HMM。
- 接入正式研究入口、按时剔除尚未成熟的训练结果、保存真实预测和独立复算均完成；这些工程检查与效果判断分开。

## 3. 现在不知道什么

- 新取得且未用于选方法的历史或今后行情能否重复这一差额：没有新资料确认。
- 真实历史供应商到达时间、修订版本、当年的可取得性：当前快照未提供证明。
- 其他状态数、编码、模型、重新训练方式或ETF池的效果：未试。当前结论绑定p0/p1、固定标准化和惩罚强度1。
- 当前概率是否可以增加收益、降低完整账户最大跌幅，或改善入场/退出/资金复用：未检验，不适用账户绩效表，不能填0。
- 第一条视频展示的全部方法和第二条的真实逐笔成交方案是否有效：本轮没有复现，视频也没有提供可独立重建的完整资料。

目标以次日收盘价为起点，观察从次日到之后20个日收益区间共21个收盘点，取相对起点的最大下探百分比。代码目标kind为 `mae`（最大不利幅度），不是平均绝对误差，不是从途中最高点到最低点的回撤；不含当日到次日的损失，不含盘中最低价。观测在日收盘后计算，不设计交易执行。
