# 四类因子资金曲线、股票池与环境分层（2026-10-22）

## 一句话结论（大白话）

已把20/60/120日动量、双均线距离/PPO、残差动量、下行风险及简单对照接成固定研究页面。这批历史报价比较没有支持增加“涨得最强就优先买”的条件；残差动量没有超过简单的波动缩放动量，下行风险也没有稳定超过普通低波动。低波动的少亏线索可以保留，但同时少赚上涨、付出换手费用；目前不据此改实际交易。

权威方法借鉴及边界：

- [Pagan与Sossounov的牛熊研究](https://onlinelibrary.wiley.com/doi/10.1002/jae.664)通过前后价格寻找峰谷；其后续窗口说明这种阶段适合历史复盘，不能当成当时已知买卖条件。本轮没有实现该完整峰谷算法。
- [Hamilton的作者说明（2005）](https://econweb.ucsd.edu/~jhamilto/palgrav1.pdf)区分只用当时信息估计状态和利用后来信息重判过去。即使只输出前者，参数也必须按当时时点估计；本轮没有另拟合状态模型，未冒充读过1989原论文。
- 本地10个月规则是先固定的透明约定，不宣称唯一权威牛熊，也不是Faber完整策略复现。本轮SSRN原入口403未读正文，失败留账；另一个负责人已核作者公开复盘，直接复用其[范围审查](factor-universe-regime-audit-2026-10-22.md)，不重跑旧84曲线。

沪深300、中证500、标普500、纳斯达克100分别保留历史成员资料状态。当前300来源股不能改个名称就变成这些池；纳斯达克100也不能与纳斯达克综合指数混称。历史成员、退市退出与当时可得资料没衔接好之前，只显示缺口，不伪造完整指数结果。

## 5. 为什么这些图还不能证明实际交易有效

1. **估值不确定。** 缺价持仓沿最后已知报价，来源断裂后仍暴露未知；没有解决真实退出权利与清算收入。部分G5最高未知比例超过三成，平滑曲线可能掩盖损失，不是可靠下限。
2. **成交时点有限。** 原报价账户使用完整当日日线判断部分不能成交情况，开盘时不可能已经知道全日高低；分数份额、分红、拆股和退市财富也未完成真实账户验证。
3. **已看历史与特定股票池。** 名单在2014年底固定，后续新上市公司不进入；没有市场全量、ETF、美股的同题独立证据。
4. **复杂残差资料的时间缺口。** 中国三因子历史发布时间与修订未知；保存的回归分数适合本次历史描述，不能称当时一定能够照做。
5. **不是完整策略。** 月底选五分之一、下一月再分组并不包含原策略完整入场、目标、失效、仓位和退出规则。负结果只暂停这里的具体排序用法，不等于原LEI体系被证伪。
