# 08：AI解释练习材料与评分依据

## 一句话结论（大白话）

已准备8份固定练习材料，每份都有来源、应该说清的内容和不能说的结论，可用于之后比较普通事实表与AI解释。当前没有运行模型或让用户评分，因此不能说AI解释已经更好。

本轮服务于规则解释和证据引用，不涉及买卖判断。承接[两份未来验证方案](ai-future-validation-protocol-2026-09-08.md)。

| 练习 | 重点检查 |
|---|---|
| MACD金叉 | 会不会把强度变化说成可以买；会不会指出缺少颜色与均线斜率 |
| 收盘才确定条件 | 会不会假定能提前在同一收盘成交 |
| 极端乖离 | 会不会只凭偏离程度承诺反转 |
| 分红尚未到账 | 能否区分财富中的应收款、可用现金和用户新存钱 |
| 前复权价格比值 | 能否解释本次与现金持有计量的差异，不冒充策略改善 |
| 旧四区间结果 | 能否识别实际代码只测两个条件，且记录并非交易 |
| 条件缺历史资料 | 能否保留未知，不把未知判成失败 |
| 资料取得与发布时间 | 能否区分文件未改变和当年已经知道这些数据 |

每份材料保留事实表作为普通解释对照、问题、必要说明、禁止的误导结论和来源文件校验值。AI回答、用户理解和评分全部为空，明确标记“准备材料，尚未评价”。[8份完整材料](raw/research-third-2026-09-08/08/explanation-cases.json)

使用时应先固定模型与提示词、保存所有尝试和原回答，再按事先写好的事实答案逐项记录正确、错误、未表达；用户理解和用时必须由实际参与者产生。不能把材料数当通过数，也不能让生成答案的同一模型独自决定自己表现是否良好。

这些练习是错误类型覆盖，不是代表真实市场问题比例的随机样本。后续还需要正常无异常问题，避免只在容易犯错的题目上评价；8份材料也不能证明所有场景都可靠。

退出效果的主要偏好、最低值得改善幅度、收益/风险代价和观察量仍未定。它们不影响准备解释材料，但必须在正式退出效果试验前确定。本轮未付费调用、未自动采集未来决策、未启动用户试验。
