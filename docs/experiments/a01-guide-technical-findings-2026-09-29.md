# A01 均线距离技术信息研究 — 2026-09-29

## 一句话结论（大白话）

在这次固定宽基ETF历史里，“靠近双均线更好”没有形成统一规律；已知道近期涨跌、波动、均线方向和结构位置后，加入距离没有稳定改善判断。**裁决：本实验范围内未发现实际增量。** 不据此删除LEI原规则，也不把本结果说成所有市场中距离无用。

主呈现是60日双均线、每周收盘判断、随后20交易日。20/60/120日均线和周/月两种安排全部保留，五个未来期限全部计算。这里的收益是固定期限价格变化，风险是期间价格路径；没有优化买卖策略或模拟完整资金账户。

**先说明限制：** 六只预定ETF中，创业板因预热缺价没有合格观测，中证1000只有2022年前段少量观测；后来评价实际为四只ETF。2022—2026H1资料以前已看过，后续日期评价（通常称样本外）只表示每次模型使用更早数据训练，**不是真正从未见过的新资料**。严格原A模块只移除距离、其他规则完全不变的候选机会，目前无法从原代码独立构造，因此原A部署增量未完成，不能由下表代替。

## 2. 现在知道什么、还不知道什么

- 组内33次平均+1.55%，轻微跌破42次平均−2.01%，但深度跌破平均+0.57%、上方靠近−0.42%，不存在简单的“离均线越近越好”顺序；早期与后来时期的大小和方向也变化。
- 相对本轮已有技术信息，主60日/每周距离没有提高20日收益、方向或下跌风险的预测；60日结果同样没有改善。20日/每月的局部改善保留，但未稳定覆盖周期、年份和用途。
- 不能认定距离与所有已有信息在数学上完全等价，也不能认定所有模型都无法利用它。本轮只评价事先固定的预测方法和B1/B2技术字段，未覆盖全部主观形态或真实完整A规则。
- 没有新资料、真实成交和完整账户证据；不能将过程下跌较小解释成已降低策略最大回撤，更不能从本轮推断应新增、删除或修改技术原文。

² 典型偏差是平方预测误差开平方：先把每次预测差平方，再按ETF平均，最后开平方；收益和过程下跌的单位是百分点，上涨概率乘100后也是百分点，越小越准确。概率采用固定简易线性模型后限定0—1，未声称概率校准或真实胜率。

简单对照也保留：只用距离与资产身份相对训练平均值，对60日收益的误差曾减少13.90%、对60日过程下跌减少22.43%；加入近期涨跌、波动等B1后，这两项分别增加2.29%、1.90%，再加入B2分别增加3.40%、3.66%。这说明单独看起来有区分力，不能直接理解为对现有判断增加信息；同时不同基准模型整体准确度并不理想，结果不能推广成已找到最优预测器。
