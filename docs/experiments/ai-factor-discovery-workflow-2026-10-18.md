# AI因子发现流程：先金融现象，再分类、用途与检验

资料核对：2026-10-18。范围：现有流程、样本覆盖、开源实践及可执行工作指引；无新增因子回测。

## 一句话结论（大白话）

**把金融解释、重复关系和实际用途放到开题前面，再按所缺证据设计检验。** 本项目已有冻结、来源、时间和预测对照检查，薄弱处是这些检查不能替AI判断一个问题为什么值得研究。此次补成后续AI可读取的工作指引；收益、避险、组合及操作成本分别选简单对手，并保留合理探索。文档入口不等于程序已经强制执行。

8只ETF只是量价研究的一条固定范围。已有实际可比296只A股、499只美国股票的研究，以及变色事件和简化纸面账户；真正的限制还包括当前名单回看历史、共同市场阶段少、相邻日期重复和完整策略定义缺失。不能只把8变成80就认为证据问题解决。

## 2. 固定部分与发散部分怎样配合

**金融现象/理论预期 → 可能解释及反例 → 分类查重 → 选定用途与简单对手 → 核资料和有效机会 → 冻结检验 → 按结果决定继续或关闭。**

前半段允许AI根据可靠材料发散，解释可以待证；发散的交付是少量值得检验的问题和淘汰理由。后半段固定对象、资料、时点、目标、对照、成本与预算。看到效果以后提出的新用途、新窗口和新名单保留为追加探索，不抹去旧失败，不重新获得“从未见过”的身份。

现象还未被观察确认也可研究，前提是清楚标为理论预测。金融含义清晰提高了研究理由，不证明市场尚未反映这份信息，更不保证能赚钱。同源价格可以研究不同机制；低相关也不能证明机制独立。

具体工作步骤和可复制开题记录见[AI因子发现工作指引](../research/factor-discovery-playbook.md)。它复用现有规范与登记，只在新选题/用途扩展时触发，不对旧冻结实验补填要求。

## 3. 相对简单方法，收益以外怎样判断价值

| 主要用途 | 对照 | 有帮助应体现在哪里 | 不能遗漏的代价 |
|---|---|---|---|
| 收益或进入/退出 | 原办法、适合资金用途的简单持有/固定投入 | 同条件扣成本后多留下多少财富 | 更大亏损、集中风险、错过机会 |
| 风险识别 | 历史发生频率、已有简单风险信息 | 提前判断是否更准，少漏报/误报 | 报警过多、滞后、不同阶段不稳定 |
| 回撤与风险动作 | 原策略、事前固定较少投入等简单办法 | 实际少亏多少、恢复是否改善 | 少赚多少、退出后何时重新参与、现金与摩擦 |
| 组合 | 原组合和适合的简单分配 | 同一笔资金是否更稳、共同下跌是否减少 | 权重变化、成本、资金冲突与真实集中 |
| 操作成本 | 效果相近的简化办法 | 更少人工判断、交易和维护 | 漏掉机会与失败恢复；未知费用不编造 |

例如一个事前以避险为目的的方案，收益稍低但损失和恢复明显改善，且超过简单少投入办法，可以有风险价值。应交付真实收益与风险交换，不能事后改名，也不能替用户编造风险偏好。预防性不参与同样可以评价；必须比较本来可执行的机会和放弃上涨，而不是必须先真实亏损才能研究。

此次是方法研究，没有新增因子性能或资金效果。此前价格范围联合预测对旧模型改善0.854%、对简单均值差9.309%的结论，仅限原预测用途；**本次没有检验它是否另有风险行动价值，不能用这张误差表替代该问题。**[原比较审查](factor-research-gap-review-2026-10-18.md)

## 6. 后续AI如何实际使用

本次仅在项目`AGENTS.md`追加短入口，并把同一工作指引放到本机项目及独立成果分支。后续读取项目指令的AI会看到：新因子选题、扩展或新增用途先读本文指向的工作指引，填写本题机制/重复/用途/样本理由，再进入现有执行链。未改策略、正式定义、旧合同、生产或交易。

主控依据指引演练五种情况：重复颜色/投票不能计三份证据；收益失败不能改口风控成功；真实风险改善允许在成本和机会代价比较后获有限支持；同指数产品或当前热门股不能制造独立历史；反复调窗口不能改名成为未知检验。演练还纠正了两处过严表述，避免不支持就永久关闭用途，以及必须实际亏损才能评价避险。演练是阅读规则后的方法裁决，不是自动测试器或市场验证。

接入以后仍有两个不同状态：**AI有明确阅读与交付要求，已经落实；程序自动识别经济解释与样本充分性，尚未实现。** 后续如需加强程序，最小改造是准备阶段核来源、竞争解释、重复引用、用途评价入口和样本支持的明确缺漏，再用失败案例验证；不要开发“自动保证因子有金融含义”的伪检查器。本轮未修改这些程序。
