# 现有情绪资料能否成为因子：可行性与有限历史诊断

## 一句话结论（大白话）

能把现有情绪资料做成可计算的研究候选，但还不能当作可靠买卖依据：在假设资料七天后可得、只比较价格背景的固定20日检验中，加入美国散户看法和中国融资变化，估计误差分别增加约0.96%和0.45%；机构资料有时点缺口，板块资料存在口径混用与重复，暂不合成情绪总分。美国指数原体系的情绪配置模块 E 尚未被本次验证或否定。

本报告封存的是最初“现有资料能否因子化”的有限问题。用户随后给出的 **LEI Sentiment Factor Library** 任务另行推进，优先从 S01 宽度开始；本报告只是 S03 的已有有限证据和中国融资扩展资料，不代表整条研究线完成。

## 2. 现在知道什么

**“情绪”至少要拆成五类。** AAII测美国个人投资者的看法；NAAIM测美国主动管理人的自报股票风险敞口；融资余额测借款存量变化；板块资金测按订单大小分类的金额；宽度测成员中有多少股票站在均线上方。不同来源不等于互相独立，也不自动意味着预测有帮助。

原始连续值、极端状态、组合条件和配置政策分别记身份。先研究连续值，再检验少数极端区间，最后才考虑组合；不把全部原值加成一个总分。NAAIM不是全部机构实仓，小单不等于真实散户、大单不等于全部机构。

AAII原始缓存xls中的“Reported Date”与清理CSV逐行对应，2038条三种占比全部一致，最大数值误差约5.6×10⁻¹⁷；看多减看空重新计算一致。可以制作候选值，但这不证明1987年以来每条首次发表的时刻和数值修订历史。

2014—2026年6月的651次AAII调查中，≤−25个百分点有41次、分成22段连续极端；≥25有41次、25段。同期NAAIM651条中，≤40有50次、20段；≥100有38次、21段。**连续段不是独立投资机会，更不是模块E触发数。** 原体系的宽度条件尚未合并，不改阈值、不挑较好阈值。

## 3. 现在不知道什么

- 本次线性20日检查没有检验“仅极端悲观时有帮助”、5/60/120/252日结果、反转概率、未来大跌概率或未来波动；不能用负结果否定这些用途。
- NAAIM官方当前公开页面说明延迟三个月，答复可为−200%到200%。现有自动脚本把数值贴到最近周并限制在0到100之间，不能作为及时历史资料证明。长史42次大于100，不能裁掉。这里只记录缺陷，没有改生产抓取。[NAAIM官方说明](https://naaim.org/programs/naaim-exposure-index/)
- AAII调查是未来六个月的看法，每周发布；本次20日检查不是检验其半年问卷是否“答对”。首次发表与修订版本未知，七日延迟不能修复错标日期或后来的修订。[AAII调查说明](https://www.aaii.com/sentimentsurvey)
- 在本批已绑定的美国历史资料中没有20/50日宽度；B200也没有合格的当时成员与逐行到达证据。这是本批输入范围的结论，不宣称整个仓库从未有其他宽度材料。新S01任务正在复用已有登记与最新报告另行核查。
- 融资CSV有额外字段而旧提取脚本输出字段不同，因此提取脚本不能单独证明现存CSV的完整来源。余额可以按当前缓存计算；正式当时可用研究还缺来源版本和发布时间。

## 6. 板块资料的真实缺口

当前页面NAAIM129周、AAII86周不是长研究史；另有1047／2038周缓存。板块价格历史有261个日期、458个板块、100173行，价格和B50各99358行非空，B20／B200均没有值，阶段只有3507行。

腾讯资金流为138板块、75611行、561个日期；东财为496板块、61251行、129个日期。两源共同日期与板块15034行，其中13227行小单相差超过0.01亿元，最大57.85亿元。差异不能自动认定某个供应商错误，但不能无标记拼成一份原始资料。

腾讯的主力、中单、小单合计每行约为零，最大舍入差0.01亿元；因此两种分类金额的“分歧”可能包含算术约束，不能叫两个独立心理测量。一二级板块可能含同一股票，板块合计不能冒称整个市场净额。

生产中至少有三种不同对象：历史调查排名标签；小单20日平均相对过去120个平均的偏离；以及“小单−超大单／流通市值”的20日平均再按层级排序。完整冰点还包含市场环境、板块60日跌幅与宽度，不能把价格贡献全部记为情绪贡献。缺日要记缺失，不能压缩成相邻日。

旧“154条冰点”共享19个日期，旧“多年四事件”是简化条件，不是完整四条件得到的独立证据。旧定投20/20失败、VIX三个主触发失败都保留；这些不能替代原始因子增量研究，更不能直接证明最新模块E失败。
