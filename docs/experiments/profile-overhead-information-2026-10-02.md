# 上方成交量分布是否增加信息 — 2026-10-02

## 一句话结论（大白话）

**证据不足。** 本轮用日线粗估过去120日的成交量在不同价格上的分布，检验“股价上方成交量越少，未来上涨越轻松”。四只国内宽基ETF中，把这个占比加入已有价格、均线距离和前高距离后，较晚历史的预测平方误差改善2.2391%，但改善的合理范围仍包含变差，而且完整方法仍比只用较早平均涨跌幅的简单方法差20.2053%。两只ETF改善、两只变差。没有证据支持把该占比作为通用入场硬过滤。

这是粗估分布：每根日K成交量均匀分摊到其最低价和最高价间的价格箱，**不是真实逐笔成交分布，也不是当前持有人成本**。历史资料已被其他研究使用；此轮没有交易、参数优化或改策略原文。

先用较早历史建立固定预测关系，再预测2025与2026上半年的20日涨跌幅。下表的典型预测偏差先把每次预测差平方，再求平均并开平方，所以较大的错误受到较大权重；它不是每次绝对差的简单平均。偏差越小越好，单位是涨跌幅的百分点，不是账户回报。三种方法评价相同874个观察日、291个日期，四产品各占四分之一。
