## 外部资源准入要求

统一接口和验收标准，不把所有对象统一成一种用途。特征数值、状态条件、因子收益、风险指标、基准和完整政策继续分开登记；收益解释不能自动获得交易用途。

后续获准接入时依次保留：原始出处与许可 → 只读输入快照 → 薄适配层 → 精确对象 ID 与语义版本 → 小例和旧定义差异 → 隔离研究。另记作者/供应商、论文或编制日期、代码版本、下载时间、数据截止、修订政策及已知限制；代码许可与数据使用许可分别核对。不得为了引入工具重建现有账户引擎。

上一轮仅做过官方资料抽查，以下是执行者复核入口，不是实际数据采购或质量合格证明：

- [MSCI 动量编制文件（2025年4月版）](https://www.msci.com/indexes/documents/methodology/2_MSCI_Momentum_Indexes_Methodology_20250417.pdf)：借鉴需逐项比较窗口、波动尺度及组合方法，不能把现有动量除以20日波动就冠以相同名称。
- [Qlib 官方计算定义](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)：变量名不等于经济含义，例如价格斜率不能因为命名为 BETA 就当成市场收益敏感度。正式引用须固定代码版本。
- [Stambaugh 作者资料页](https://finance.wharton.upenn.edu/~stambaug/)：具体下载序列的频率、覆盖截止与更新情况须分别确认，不能因网站有更新就推断所有文件都更新。
- [RiceQuant 指数接口说明](https://www.ricequant.com/doc/rqdata/python/indices-mod)：历史查询、数据入库时间和当时市场可知时间要分别验证；供应商推算的权重不能冒充编制方每日原始权重。

### 初评的保留结论与修正

保留“不为本轮数据基础引入大型框架、不下载整包、不重建账户”的结论。但不采纳“Alphalens 只能作第二个算盘”“Qlib 唯一价值是日历”的限制，也不沿用未经隔离实测的兼容性判断。

- **Alphalens 可以承担合格后的正式研究分析，不必先自建同一套分析引擎。** 优先评估 `alphalens-reloaded`，采用薄适配与手算期望值验收。其相关性指标 IC（打分排序与后续收益排序的吻合程度）调用 `scipy.stats.spearmanr`；自写 SciPy 包装与它比对只能部分检查对齐，不能算独立数值核心。`factor_rank_autocorrelation` 检查前后日期的名次稳定性，不依赖分组；它也不是账户实际换手。`demeaned=False` 不保证只买不卖空：原始负分仍可产生负权重；IC 函数本身没有这个参数。不同函数的“去均值”不可一概等同于多空构造。[官方计算源码](https://github.com/stefan-jansen/alphalens-reloaded/blob/main/src/alphalens/performance.py)
- **清洗与分组需要逐函数设定。** 小池不能机械分五组，但不因此禁止所有分组观察；并列值可能造成重复边界，不是14只必然报错。先不分组也可以。清洗的 `max_loss` 容许损失不是质量认证；应先单列预热、缺失及后续收益尚未观察完整的末端样本，再控制剩余损失，保存原因。源码有损失摘要，不能一律称为静默。前向收益过滤 `filter_zscore` 涉及未来分布；初次验证显式关闭。工具推断的日历不能替代项目合格日历。[官方清洗源码](https://github.com/stefan-jansen/alphalens-reloaded/blob/main/src/alphalens/utils.py)
- **Qlib 并非没有历史可知时间设计。** 它有按历史发布时间选择数据版本的 PIT 机制，官方范围主要是季度、年度财务数据；不代表已解决本系统公司行动的原始到达时间。缺失的来源证据仍不能由框架补造。[官方 PIT 文档](https://qlib.readthedocs.io/en/latest/advanced/PIT.html) 数据导入和提供器也可自定义，不能把预置整包下载当成唯一用法。[官方数据组件说明](https://qlib.readthedocs.io/en/latest/component/data.html)
- **版本与兼容性重新核验。** 本次查看的是上游 `main` / `latest`，不作为固定发布版执行合同。初评中的旧 issue、第三方活跃度标签、未发新版时长，不能单独证明当前版本不可用。安装前固定发布版本或提交、核对许可证与依赖锁定，在隔离环境运行最小测试；尚未完成这些步骤。

### Alpha158：值得看定义，不是一次接入158个因子

Alpha158 是一组价格、成交量等特征的默认配置，不是158项已经证明有效的交易方法，也不是158条因子收益。下一步候选工作仅为“与现有对象的公式差异对照”，有独立授权后才执行计算或新增登记。

例如，上游 `ROC` 是过去收盘价除以当前价，不是本系统跳过近月的涨幅；`MA` 是均线除以当前价，不是当前价相对均线的距离；`STD` 是价格标准差除以当前价，不等于收益波动；`BETA` 是价格斜率除以当前价，不是市场收益敏感度。默认滚动窗口为5、10、20、30、60；名称相近不得直接替换已有定义。[Qlib Alpha158 官方公式](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)

对照时先看与已有对象重合的少量公式，记录所需输入、窗口/缺失语义、价格与成交量单位、分红拆分口径；训练用标准化和待预测收益另行区分。引用已登记对象必须解析实际 ID@版本，不在此猜造；未匹配项保持候选。资料不够即停止，不为凑齐158项补数据，不以择优回测成绩作为选型标准。
