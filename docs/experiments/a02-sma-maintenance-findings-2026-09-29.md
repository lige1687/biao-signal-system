# A02 回调期间SMA方向保持研究 — 2026-09-29

## 一句话结论（大白话）

“回调时均线一路保持向上”单看历史有些分组差别，但在已知道距离、近期涨跌、波动、回调深度和当前方向后，20日收益和下跌判断的改善只有0.273%和0.099%，且随产品和年份变方向。**结论：证据不足，尚不能确认稳定增量。** “今天均线向上”本身只是过去同周期价格变化的另一种写法；本轮未证明整段回调的历史完全重复，也未据此删除LEI规则。

主结果为60日SMA、每周收盘判断、随后20交易日。收益是固定期限价格变化；风险是期间最差收盘价相对起点的下跌，通常叫MAE，可能低估盘中下跌。不是完整资金账户或交易策略优化。

**先说明限制：** 预定六ETF中创业板没有合格指标，中证1000仅2022年前段少量状态；后来评价实际四ETF。所有2022—2026H1历史已被研究看过；按更早日期训练、后来日期评价（通常叫样本外）不是真正未见的新证据。本轮峰值和回调是明确的研究代理，不是完整原A模块机会，不支持真实买卖、生产采用或修改技术原文。

## 2. 现在知道什么、现在不知道什么

- 今天SMA向上与`C(t)>C(t-N)`在数学上相同；不能和同周期涨跌算成两套独立确认。已有B2六方向中已经含这条事实。
- “每一天都保持上行”和“过程中离失去上行还有多远”才是本轮新增历史。主要后来评价中收益、风险误差略减，方向误差略增，没有稳定用途证据。
- 原始收益差受到产品与时期组成影响。中证1000非全向上组只有1条、跌7.921%，却和每只ETF一样占组的五分之一；其全向上组7条。四个完整产品里，上证50/沪深300全向上平均收益高，中证500/科创50反而低。不能用组均值编市场故事。
