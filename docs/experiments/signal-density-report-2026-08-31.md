## 一句话结论

**C 模块（破底翻）信号密度与市场阶段有清晰的机制耦合：月密度
脉冲（池内 ≥10% 标的当月出破底翻信号）共 9 次，全部落在阶段性
大底附近（2018-09/11 双脉冲 = 2018 大底，2022-03/05 = 4·26 大底，
2022-11 = 防疫放开底）；密度枯竭（连续数月为零）对应阴跌深水区；
月密度三分位的沪深300 未来 1 月收益单调（−1.15% / +1.08% /
+1.16%），IC +0.164。但样本仅 83 个月、脉冲事件 9 次——不足以
支撑任何门控规则，定位为「观察指标候选」，建议进 2026-09 打分卡
观察名单积累样本。**

## 核心证据

1. **脉冲=底**（9 次脉冲事件全表见 raw）：

| 脉冲月 | 密度 | 对应市场事件 |
|---|---:|---|
| 2018-09 / 2018-11 | 0.208 / 0.358 | 2018 熊市大底（2440 点区） |
| 2022-03 / 2022-05 | 0.113 / 0.358 | 4·26 大底（2863 点区） |
| 2022-11 | 0.113 | 防疫放开底 |
| 2023-06 / 2024-03 / 2024-07 | 0.113 / 0.170 / 0.132 | 阶段底部区域 |

   机制：破底翻 = 跌破前低后快速收复 = 下方有主动承接。密度高
   = 承接普遍 = 筑底特征。**这是宽度之外的一个独立「底确认」信息。**

2. **与 B200 的关系**：同期相关 −0.412——C 密度高时宽度低（弱势
   市才有破底），二者互补而非冗余：宽度低告诉「市场弱」，密度
   脉冲告诉「弱中有承接」。
3. **三分位单调**（未来 1 月沪深300 收益）：C 密度低 −1.15% /
   中 +1.08% / 高 +1.16%；A 密度不单调（−0.09 / +0.87 / +0.30），
   IC −0.085——A 流（门禁后）无前瞻信息，不入选。
4. **反例（为什么不能做空仓开关）**：2024-09 后 V 型反转牛市中
   C 密度也长期为零（没有破底就没有破底翻）——「密度枯竭」混合了
   「阴跌无承接」与「牛市无破底」两种状态，单独使用必然错杀
   牛市起点。

## 定位声明（必须随结论引用）

- 后验探索、非预注册；83 个月 / 9 次事件的样本量不支持门控规则，
  任何「密度门」回测在此样本上都是用 9 个事件拟合规则——过拟合
  必然，不做；
- 信号池为门禁/过滤后的流（非全量信号），密度绝对水平受过滤参数
  影响，只有「时序形态」（脉冲 vs 枯竭）有信息；
- **唯一建议动作**：把「C 模块月度信号密度」作为观察指标加入
  2026-09 打分卡（记录但不下单），积累 2-3 年样本后再评估是否
  有门控价值；
- 若未来要做正式检验，正确路径 = 全量（未门禁）信号流 + 预注册
  密度阈值 + walk-forward，而非本实验的过滤流。
