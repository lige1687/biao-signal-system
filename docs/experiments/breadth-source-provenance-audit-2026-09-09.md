# 宽度历史依据核查：已有收益能支持到哪里

日期：2026-09-09。范围：追查已使用的 A 股 200 日均线上方股票比例，不新增收益测试。

## 一句话结论（大白话）

现存代码和生成日志高度支持这样一条来源：用2026年取得的股票名单及旧价格缓存回看历史，而没有保存每个历史日期当时的完整股票范围。原始价格面板随后又被刷新，无法逐字节还原当时计算。因此，宽度方法在两只ETF上的历史优势仍是值得保留的线索，但目前不能据此直接认定真实决策已有可靠增益；再增加ETF数量，也不能解决这一共同数据问题。

## 查到什么，对决策有什么影响

这里的“宽度”指纳入计算的股票中，收盘价高于各自200日均线的比例。本研究用它决定投入多少，属于市场环境研究，不改写A/B/C/D的买卖条件。

| 问题 | 证据 | 影响 |
|---|---|---|
| 已用数据是哪份？ | 归档、本机结果、同步仓副本字节相同，共8109个日期；200日指标从1993-12-21有值 | 能确认研究使用的数值文件身份，三个副本不是三个独立来源 |
| 股票范围如何取得？ | 现存程序读取当前股票名单；对应日志读取5543只名单，使用已有5207只价格面板 | 没有逐日历史成员表，无法证明早年退市股票齐全 |
| 能否还原生成？ | 日志为8707日×5207只，现存面板已是8714日×5211只；日志没有输入、代码或输出哈希 | 日志与成品日期、行数高度吻合，但没有完整的生成绑定证据 |
| 缺失股票有没有影响？ | 当夜336只补拉全部失败，主要涉及920代码；现存名单与价格列也有缺口 | 不能声称覆盖完整市场；本轮未量化对收益的影响 |
| 价格如何调整？ | 代码使用前复权价格，没有保存因子及版本 | 不能完整复核历史价格版本；这本身不等于宽度信号必然错误，统一倍数调整通常不改变价格与均线的大小关系 |

现存程序还表明：上市前不填价格；上市后内部缺口用前收计算均线，但缺少当日原始价格的股票不进当天比例分母。以上属于现存代码证据，不能冒充已确认的当夜执行字节。

## 对旧结果的处理

旧资金计算和收益文件保留，未发现依据本轮审计应直接改写金额的证据。引用时统一称为“冻结历史宽度文件下的有条件结果”，同时披露2026年股票范围回溯及来源缺口。不能再把它描述为已逐日还原的历史全A股宽度；目前没有哪个年代能免除该限制。

宽度的沪深300、创业板比较，以及H1减少操作、H2增加趋势参与，都共用这项基础限制。阈值又来自已经看过的历史，因此固定规则重跑不能被称为完全未知行情的考试。独立核对现金只能证明资金运算，不能补足股票范围的历史真实性。

本轮继续完成分红再投入的持有参照，用来回答原差额有多少只是分红使用方式不同。技术退出的单条件比较继续推进，它使用ETF自身价格及公司行动，不依赖这一宽度序列。宽度方向暂不通过增加产品或扫描阈值来强化结论。

## 真正需要补的增量

后续若继续提升宽度证据，先确认是否存在原面板备份；不存在则如实记录，不反复找同一批缺失脚本。更关键的是取得可核查的上市、退市及市场变更历史，说明退市股票价格覆盖，并逐日保存实际参与计算的股票数量。新版运行须同时保存名单、价格、程序、依赖版本和调整方式；这样才能检验幸存股票遗漏是否改变信号和收益。

这些是下一阶段的数据研究要求，本报告没有下载全市场数据，也没有改生产计算。若历史覆盖无法补齐，应保留限定名称，并研究可在今后按日保存的真实可得序列，而非把缺口隐藏在更漂亮的收益表中。
