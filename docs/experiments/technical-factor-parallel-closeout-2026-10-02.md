# LEI技术因子：双跌破、上方成交量分布与剩余用途 — 2026-10-02

## 一句话结论（大白话）

本轮完成了两项真实历史效果研究。**双跌破在本实验范围内未发现实际增量；上方成交量分布代理证据不足。** 双跌破后的风险没有比价格背景相近的普通日更高，加入已有信息的预测反而略差。上方成交量占比让一个较弱的价格模型略准，但完整方法仍不如只用较早历史平均数。不能凭这些结果新增硬过滤，也不能据此删掉LEI原文规则。

我们研究的仍是“LEI已有判断是否提供额外信息”，不是挑选最赚钱参数。两个有边界的问题已完成，完整入场、持有、退出和多周期体系尚未被这两个代理回答。另查出旧35次A机会的资格问题，以及历史均线密集区目标的实现空白。

## 增量表：已有信息之后还增加什么

典型预测偏差先把预测差平方、求平均再开平方，所以大错误受到更大权重；单位是价格涨跌的百分点。它不是每次绝对差的简单平均。K01主报告表头的“平均预测误差”实际采用此算法，本表澄清名称，数值没有更正。

先用较早资料固定预测关系，再预测较晚资料。每项的三种方法都使用相同874个观察、291个日期，但两项预测目标不同，不能横向比较误差大小。
