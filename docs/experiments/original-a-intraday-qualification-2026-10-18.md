# 连续小时资料与确认等待：这次真正测到了什么

2026-10-18。历史资料截至2026-06-30；当前下载版本的回顾性研究。新问题只补小时确认带来的等待，不重跑旧颜色、底部收益或旧A账户实验。

## 一句话结论（大白话）

6只个股的连续小时资料已经取得，并完成一次固定比较：底部出现后，393次后来等到小时确认，等待的中位数为21个交易小时，确认时观察价格的中位数比起点高2.39%；另291次在确认前先跌破底部。等待确实改变了参与时机，既可能暂时避开继续走弱，也可能让价格变贵，但这还不能证明完整原策略赚得更多。ETF这次没有足够合格的连续小时前史，不能拿个股结果代替它。

中位数表示一半记录高于这个数、一半低于这个数。21个交易小时约为5个交易日的盘中时间，不包括午休、夜间和休市。这里的底部及均线排列是明确登记的研究表达，还没有涵盖完整A的环境、位置、目标和对应失效。

## 1. 这次拿什么和什么比

金融含义是：多等一个短周期趋势条件，可能减少过早参与，也可能付出时间、价格和不参与的代价。方向不预设为正，不找更赚钱的参数。

共同起点是按既有定义第一次看见某个日线底部的当日收盘。简单参照是不加小时条件，观察起点价格；新增条件是小时SMA20、60、120依次排列，同时EMA20、60、120也依次排列。SMA是等权平均价，EMA对近期价格更敏感。两组必须同时成立，不能用“任一成立”代替。

底部识别复用既有逐时点的包含合并和复杂等待算法；每次只使用当时及之前资料，冻结原低点。后来图形变了，不回头删除旧事实。“首次”指这个底部第一次被看到，不等于一段趋势的第一次回撤。

日线至少有252个连续合格交易日。小时均线使用现行程序的初始算法：先用前N个价格的平均数启动EMA，再递推；120根以后才发布完整排列，记录实际前史长度。满120根只说明这个有限历史表达能计算，不代表已经完整还原老师的主观趋势判断。

本轮不模拟买卖，也不把收盘价当成交价。原始买入持有、单均线、双均线和旧A账户结果沿用[已有报告](/library?report=docs%2Fexperiments%2Fmodule-a-rule-audit-2026-10-18.md)，没有重跑。这里的同机会零等待参照，专门回答新增小时条件的代价。

## 3. 相对简单参照，新增了什么、尚未证明什么

| 比较内容 | 不额外等小时条件 | 增加小时条件 | 本轮判断 |
|---|---|---|---|
| 确认者等待 | 起点为0 | 中位21个交易小时；范围1—230 | 等待时间已量化 |
| 确认者观察价格 | 同一起点为0 | 中位+2.39%；90次反而更低 | 有价格代价，也有反例 |
| 确认前结构破坏 | 起点不知道后面会不会破坏 | 291次等待期间先破底 | 描述了筛除；没有证明净收益改善 |
| 本来能赚却没参与 | 需要固定目标、退出和可成交机会 | 本轮未模拟 | 不能把上涨幅度当错过利润 |

“等到多头后价格常更高”本来就可能来自确认条件自身，不是发现了预测未来上涨的证据。真正的收益增量还要比较：少亏的金额是否超过买贵、漏掉上涨、闲置资金和交易成本。当前这张表把已量化和未量化的部分分开。

## 5. 连续资料到手了，但哪些能用必须分清

固定8只ETF、6只代表股，申请2019-09-01至2026-06-30的15分钟、60分钟、原始日线、后复权日线、复权因子及产品身份；另取交易日历。后复权用于把分红拆分前后价格放到同一比较尺度，不等同真实账户含现金分红的收益。

| 资料 | 实际取得 | 资格结论 |
|---|---|---|
| 6只个股小时与15分钟 | 2020-01-02至2026-06-30；5只各1,571日，中兴1,570日 | 同源因子与日线价格运算可核；只在合格连续段研究收盘状态 |
| 8只ETF小时与15分钟 | 均为2026-01-05至2026-06-30，116日 | 不能声称有2019年起的小时资料 |
| 15分钟合成小时 | 除茅台一根收盘差0.0001外，价格全部一致 | 是同一供应商内部核对，不是两个独立来源证明 |
| 小时合成日线 | 开高低、收盘及量额存在差异 | 不覆盖原件，不增加容差；不能据此模拟盘中止损或成交 |
| 科创50、半导体、银行、医疗ETF复权 | 因子表空；请求后复权却返回原始价标记 | 不把空因子当1，不称后复权已取得 |
| 其他4只ETF的日线底部 | 709次满足日线前史，其中2026上半年131次 | 起点均没有合格的完整小时前史；无法评价小时等待 |

ETF日末收盘存在制度差异：在本研究截至2026年6月底的区间，上交所基金收盘价按最后一分钟成交量加权，未必等于最后一笔成交；2026年7月6日才实施新规则。这可以解释一部分收盘差异的可能来源，**解释不了所有高低价或开盘差异**，不能据此宣布数据完全对齐。[上交所2023规则及附件4.1.3](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/c_20250612_10824490.shtml)、[2026规则实施日期](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。

因此本次只研究小时收盘状态：每一天必须有完整15/60分钟记录、内部价格一致、日末小时收盘与日线收盘一致，且日线与小时使用该日已经生效的同一调整因子。任一天不满足，小时历史重新累计。高低价不拿来猜盘中顺序；如果日线显示破底且同日出现小时确认，直接保留“先后不明”。茅台大量事件因此未进入小时比较，不能把其少样本解释为策略特色。

按规则读取截至当日最近生效的因子，不使用未来因子；“同一日口径”不要求每天发生一次分红。[BaoStock复权方法原文](https://www.baostock.com/helpdocs/pdf/BaoStock%E5%A4%8D%E6%9D%83%E5%9B%A0%E5%AD%90%E7%AE%80%E4%BB%8B.pdf)。下载时间已记录，但当年供应商何时发布、后来是否修订仍未知；小时结束标签由交易时段及15→60分组合对应作研究解释，未当作实时到达证明。

旧日线与新资料在若干分红日也有差异，ETF日变化最大差约0.0302个百分点、个股约0.000192个百分点。因此没有直接把旧7条放行机会或旧信号拼入新价格，而是保留旧实验，按本次明确口径做新增等待描述。

没有停在第一个供应商：按[AKShare的ETF原始实现](https://github.com/akfamily/akshare/blob/master/akshare/fund/fund_etf_em.py#L314-L403)，另试了东方财富中证500ETF匿名60分钟后复权接口。实际连接被对端关闭，没有收到行情；未自动重试、购买或把近期资料伪装成历史。原始实现也是先取服务端当前保留的分钟资料再按日期截取，不能仅凭可填写开始日期就断言能回溯多年。长桥资料能力文档不能证明本账户当前有历史权限，本轮也没有可调用的对应连接。因此ETF合格历史仍是实质缺口，不能把“已找到接口”写成“已拿到资料”。

## 6. 目标和失效位：原文核清了哪些

| 原文内容 | 核查后的处理 |
|---|---|
| 底部与小周期趋势 | 两者同时成立；不能由收复EMA20单独代替 |
| 小周期 | 小时是原文允许的分支；没有擅加15分钟和60分钟同时确认 |
| 首次回撤 | 原文强调特别重视，没有禁止所有后续回撤；不能用首次硬筛选代替完整A |
| 20/60密集区，再20/60/120密集区 | 对应HTZ跌转涨案例；不能当成所有稳定上升趋势A的唯一目标算法 |
| 初始失效 | 必须对应买入理由：底部低点、支撑区域下沿或均线抵扣推演区域，不能统一用触碰后最低价代替 |
| 密集目标区域怎么选 | 历史锚点、区间边界、时间范围仍未有可逐笔复核的统一原义规则；不得自行挑最有利目标 |

依据为《LEI技术交易体系》§2.6、§4.4及HTZ案例，与《LEI技术实现》§4.5、§7、§10。最高语义来源要求同时确认；实现文档的“任一成立”不能反过来改写它。完整策略目标和对应失效仍未核齐，**这次没有把等待研究包装成完整原策略收益回测**。

## 8. 这项研究的边界和接续

已回答的是：新增小时条件会带来怎样的等待、观察价差和结构破坏筛除。原完整A是否胜过简单方法、等待是否减少真实亏损、错过的净利润及费用、仓位和组合风险，仍未评价。

下一项真正需要补的是合格ETF连续资料，以及逐机会可核的首目标与对应失效。选择了哪一区域、为什么当时能知道、失效对应哪条理由，都要先固定，才能与相同机会下的简单方法比较资金结果。不会为了多出交易而放宽条件，也不会把图画漂亮当作有效因子。
