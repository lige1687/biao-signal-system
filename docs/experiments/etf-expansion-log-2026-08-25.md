## Round 4 — B 在半导体/通信/AI 集群（任务四）

**复核上轮「B cb=40/cl=5% 是 IGV 单边投影」**的判断：国内行业 ETF 集群是否也有 IGV 那种"密集区突破"形态？

**7 个集群 × 3 组 B 参数** = 21 个 run：

| 集群 | 标的 | cb=40/cl=5% | cb=40/cl=3% | cb=126/cl=2% |
|---|---|---:|---:|---:|
| 5G 通信 | 515050 | 0 信号 | 0 信号 | 0 信号 |
| 人工智能 | 159819 | 0 信号 | 0 信号 | 0 信号 |
| 半导体（华夏）| 512760 | 0 信号 | 0 信号 | 0 信号 |
| 半导体（国联安）| 512480 | 0 信号 | 0 信号 | 0 信号 |
| 半导体（深证）| 159995 | **N=3, −0.23R** (IS −1.03/2, OOS +1.37/1) | N=2, −1.19R | 0 信号 |
| 通信 | 515880 | 0 信号 | 0 信号 | 0 信号 |
| 半导体组合（6 个）| — | N=3, −0.23R | N=2, −1.19R | 0 信号 |
| 半导体组合去 IGV | — | N=3, −0.23R | N=2, −1.19R | 0 信号 |

**结论**：

1. **B 在国内行业 ETF 集群样本稀缺**：21 个 run 里 15 个 0 信号，有信号的 6 个里全部是 半导体深证 159995.SZ 一家的。
2. **没有"投影"**：cb=40/cl=5% 上轮在 IGV 上能稳定投影（每轮都有信号），搬到国内半导体深证只有 3 笔且负期望。半导体组合和半导体去 IGV 结果完全相同，**证实国内行业 ETF 没有 IGV 那种 dense breakout 形态**。
3. **沿用上轮结论**：B 不切档，cb=40/cl=5% 仅在 IGV 单标的有偶然投影。
