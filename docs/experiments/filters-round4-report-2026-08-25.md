## 2. 各块要点

### 量能（任务一）
「信号日放量才做」选出的是**最差**子集：放量组 expR -1.1 ~ -1.9，无放量组 +0.6 ~ +1.9。模块 A 是回调买入，放量回调=抛压未衰竭。**手册的放量确认适用于突破模块，不适用于回调模块**；反向用法（排除放量日信号）是明确的候选线索，未擅自实验，待拍板。

### 筹码（任务二）
- vacuum（overhead_supply_ratio ≤ 0.30）：A股ETF expR +1.585 -> +1.810、OOS +2.337 -> +2.727；全池 +0.516 -> +0.560、OOS -0.045 -> -0.010。剔除者两池胜率均 21%、合计 -22.0R/-35.6R。**通过全部检验，但幅度小**（expR +0.04~+0.23），建议以观察档进 A（开关键已在工作台，默认关）。
- poc_support 逻辑反直觉但归因清楚：下方 1×ATR 内有 POC = 入场点下方拥堵，趋势回调要的是下方干净。不采纳。

### 五步状态机（任务三）
分组即结论：**stage_1（仅破线）全池 -0.531 expR、-128.6R；stage_4 +0.692、+1000.4R**。2/3/5 无样本（过渡态太短 / 与回调互斥）。门控 stage≥2 是本轮 totalR 增量最大的候选。周线逆向组 0 笔：A 已硬门控周线多头，引力折扣不可测（门控生效本身即验证）。

### 缺口（任务四）
- 动能过滤：保留组更差 + 样本损耗 86-88%，不进。
- 目标档：**救回 0 笔**。非 bug：上方有缺口的信号仅 15/289 且全部已回补（触沿即回补口径下 94.5% 缺口被回补）。代码与账本（gap_events 2.0.0）保留，供 API/未来更宽回补口径复验。
