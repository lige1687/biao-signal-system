# 小时确认值不值得等：同一底部、同一终点的增量比较

2026-10-19｜历史截止2026-06-30｜本题结案 ARCHIVE｜完整LEI策略仍未验证。

## 一句话结论（大白话）

**现有证据不支持把小时确认设成所有底部机会的强制条件。** 六只代表股的1124次可比较机会中，等小时确认后，到共同20交易日终点的平均价格机会分数从1.26%降至1.03%，少0.23个百分点；观察期间的收盘下探也少了2.01个百分点，但同时减少参与，不能称为相同投入下判断更准。预先划定的“中长期排列与简单均线方向向上”背景有正向线索，较晚时期却不稳定，值得扩大验证，暂不足以认定有效或接入强制交易规则。

“上涨中回调”可以先作为理念分解研究。完整策略的目标、失效位没有唯一核清，只阻断依赖这些定义的资金回测，不再阻断独立信息的比较。本次复用旧底部和小时状态，新增的是共同终点的效果与代价；没有重跑旧颜色、账户或等待描述实验。

## 1. 怎么测，数字代表什么

固定原来保存的六只代表股：贵州茅台、宁德时代、比亚迪、美的集团、中国平安、中兴通讯。日线第一次识别同一底部的收盘为起点，第20个交易日的收盘为共同终点，30日只作预先约定的辅助检查。

比较三种观察办法：起点立即观察；等首次小时多头确认再观察；不看小时、固定等5个交易日且底部原低点未被跌破再观察。小时办法沿用原条件：小时SMA20＞60＞120且EMA20＞60＞120；没有改周期或重新生成旧信号。

**价格机会分数**是从各自观察价格到共同终点的涨跌幅；已知没有参与的机会按闲置本金、无利息记0，资料未知的机会保持未知。实际不能承诺按信号收盘成交，所以这些数值不叫策略净收益。复权价格也不等于已经核全现金分红的账户财富。

**收盘下探**是观察价格至随后最低日收盘的最大跌幅，未参与记0；它不是整个账户的最大回撤，也不含盘中最坏价格。先分别平均每只股票的机会，再把六只股票的结果平均，防止事件多的股票主导；它不代表一份可投资的组合资金。

## 4. 代价来自哪里

20日全部机会，小时办法相对立即办法的−0.23点，可以逐项核回：

| 来源 | 对平均价格机会分数的贡献 |
|---|---:|
| 已知不参与，而终点下跌的机会 | +1.31点 |
| 参与后，等待改变观察价格的代价 | −1.14点 |
| 已知不参与，而终点上涨的机会 | −0.41点 |
| 三项相加 | **−0.23点** |

这是同一批机会的价格算术，不是已经实际避开的亏损。1124次中289次不参与，70次后来上涨、219次后来下跌；后来确认的372次，中位等待19个交易小时，确认价相对起点中位高2.37%。交易小时不能直接当成19个自然小时。

少下探既可能来自略过坏机会，也来自参与更少、开始更晚；本题尚未固定相同风险或投入的真实账户。因此不能把下探少2.01点全部归功于新增预测能力。手续费、价差、跳空、现金占用和并发机会没有完整核算，不随意减一个费用数字假装净收益。

## 最小决策卡

**现在值不值得用？** 不支持把小时确认升级为所有机会的强制筛选。预定向上背景保留为候选，优先用合格ETF及更广个股、较晚历史或后续新资料验证；先核等待和错过是否反复抵消收益，再进入相同投入与风险下的账户检验。完整目标、仓位、风控、选标的和共同资金属于随后策略验证，当前没有宣称组合有效，也没有修改生产或交易规则。
