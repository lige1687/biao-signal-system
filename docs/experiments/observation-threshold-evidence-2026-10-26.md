# 市场观察阈值依据与展示修正 · 2026-10-26

现有证据不支持把本页统一的20%／80%分位、VIX15／20／30、信用利差3／4.5／6／8%，直接称作市场“机会、风险、阶段顶底”。本轮撤回这类线、色带和标签，保留原始曲线、日期和定义明确的参照。Baker保留为月度情绪背景，不作为阶段顶底提示。结论是这些展示用途缺乏依据，并不是证明相关指标在所有用途上都无效。

## 问题与完成边界

用户要看阶段顶底，同时明确“没有权威机构或数据支持就不要硬套”。对手是只显示原始数值、日期和价格对照；只有额外分区有支持其**具体用途**的证据，才应增加。权威数据源只保证对象和定义，不能自动证明买卖线。此次依据审查和显示纠正完成，未新做金融效果实验，未提高任何因子的采用等级。

本轮使用 research-closure 和项目 lei-lowfreq-research：复用冻结结论、核原始定义、修正实际页面。未寻找更好看的参数，未把同一历史反复优化成正结果。两份策略源SHA及6次明确外部查询账见 [合同与来源账](raw/observation-threshold-evidence-2026-10-26/contract-and-source-ledger.json)。策略技术层、交易规则、原始金融资料不变。

## 每项到底能看什么

| 指标 | 原始依据支持什么 | 本轮处置 |
|---|---|---|
| VIX | 标普500期权隐含的未来约30天波动幅度；幅度不等于涨跌方向 | 保留日线，不画固定机会／风险线。S&P2017的12／20示例是波动分区，并非买卖线 |
| 高收益债OAS | 低于投资级企业债相对国债的额外收益率，反映市场要求的风险补偿 | 保留日线，撤掉6%警戒等未经验证的页面阈值。它不是违约率 |
| Baker–Wurgler | 作者月度、可修订的情绪水平；原论文主要研究不同股票的后续相对表现 | 删除全历史20／80冷热线和色带，明示月度背景。不能通过插值制造日频信息，不用相邻月差衡量情绪变化 |
| PE、CAPE、股债收益差、利率、两融 | 各自估值、贴现或融资背景 | 撤回固定机会／危险区。保留股债差0的算术含义，保留带窗口的历史分位文字，分位不叫机会线 |
| 宽度 | 一批股票中站上均线的比例；50%表示半数 | 旧六项数值查询不变，默认关闭色带；按钮显示实际数值，不再叫阶段／反转顶底或牛熊确认 |
| AAII、NAAIM | 受访者意见或管理人自报敞口 | 新统一对照图撤掉20／80分位线；AAII净值0仅表示看涨看跌比例相等。旧散点分箱仍明确仅为事后展示，不是阈值验证 |
| PMI、OFR、NFCI | PMI50为扩张／收缩定义；OFR／NFCI0为各自标准化基准 | 定义线可保留并标来源、含义，绝不标成股票机会／风险线 |

## 数据为什么少

本机API与实际图已分别核对：

| 序列 | 有效点数 | 实际可用历史 |
|---|---:|---|
| VIX | 5029 | 2006-10-31—2026-10-26 |
| 高收益债OAS | 786 | 2023-10-24—2026-10-22 |
| 标普500价格 | 2512 | 2016-10-24—2026-10-21 |
| 纳斯达克综合价格 | 14048 | 1971-02-05—2026-10-23 |

风险双图原先默认截取365日，现默认5年，可选3个月／1／3／5／10年／全部；同时标“显示范围”和“可用范围”。VIX“全部”已实页显示约20年。OAS的限制来自FRED2026年4月起只保留三年，更早历史须另向原始供应商取得，本轮未补齐。切到更长窗口不会伪造资料。价格对照只画价格与指标共同覆盖期；标普500本身约10年限制不等于VIX只有10年。

Baker原表726个月（1965-07—2025-12），宏观调整列有效725个月；2025-10空值保持空，不插补。历史修订值不证明当时已经公布。库中已有1990年起Cboe原件，但本轮未接成新的在线数据源。
