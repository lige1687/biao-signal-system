# 冰点焦点股动量：独立版本效果、相关研究与中美观察用途

日期：2026-10-25（Asia/Shanghai）。研究状态：有限历史检验与文献比较已完成；未复现作者原式，未验证全市场、美股或账户效果。研究ID：`focus-stock-momentum-evaluation-20261025`。

## 一句话结论（大白话）

实际跑完一个事前固定的A股独立版本后，没有发现“跌破零就更容易迎来宽基反弹”的稳定证据，加入它也未改善下一交易月的预测；可把它保留为热门股状态的观察线，与市场宽度和成交集中度一起看，但不把零线当作已经验证的抄底线。

这不等于证明量化舵未公开的原模型无效。本次检验的是明确写下的一种算法、一个历史300股样本和20交易日目标，不能替原作者所有可能的参数下结论。

## 1. 实际测了什么，覆盖到哪里

原始身份沿用已核的[量化舵原视频](https://www.douyin.com/video/7699879945107016969)与[来源报告](focus-stock-momentum-source-review-2026-10-24.md)。作者没有公开完整选股比例、活跃窗口、涨跌窗口和权重；图中用成交额，评论又用成交量措辞。因此明确另立独立定义，不猜参数去重画他的线。

独立版本：每天收盘后，在合格股票中按**过去20交易日平均成交额**排序，取前5%（向上取整），对它们的**过去20交易日复权价格涨跌**等权平均。低于零即负值，没有另行调阈值。成交额在相同人民币单位内比较；它描述交易活跃程度，不预设入选者都是行业龙头。

| 项目 | 实际范围与边界 |
| --- | --- |
| 股票范围 | 从供应商2014-12-31历史名单中，沿此前固定哈希规则抽取300股，保留后来退出者；抽样实际发生在2026年，排除了旧研究600股。不是沪深300成员，不是全A股，遗漏2014年后新上市公司 |

| 实际每日覆盖 | 2015-01-05—2025-12-31，2,674个有效日；每日124—290股合格，焦点组7—15股 |
| 周观察及成熟标签 | 两指数共同560周，2015-01-09—2025-12-12；完整日历止于2026-01-15，末端未成熟20日标签剔除 |
| 年度预测评价 | 2020-01-03—2025-12-12，每目标305周；2020—2022为154周，2023—2025为151周 |

| 目标与风险 | 信号日收盘至20个交易日后收盘的指数涨跌；另记未来20日最低收盘相对信号日的涨跌。后者不是账户最大回撤 |
| 原件 | 300股各一份行情和复权资料，共600份SHA核验；两指数在绑定日历内各3,166个收盘；资料清单见inputs.json |

股价采用已存在的 `foreAdjustFactor` 适配器及断点检查；这是供应商复权研究价格，不冒充逐笔可成交的含分红持仓收益。各股票只有当日及之前的价格和成交额用于计算。周末日期先由完整交易日历确定，再筛区间，不用“本周最后一个有行情的日子”替代。

## 3. 是否比已有信息更有用：增量表

基础对照B使用三个当时可知量：对应指数过去20日涨跌、日收益波动、同池全部合格股的平均20日涨跌。新增信息每次只加一个，另保留“只预测历史平均收益”和“只用焦点动量”两个简单参照。

每年以2015年以来且20日结果已经成熟的资料拟合一次线性回归，预测下一年；2020—2025年训练样本分别251、302、355、405、455、506周。训练集内标准化，未使用当年结果拟合；不搜索窗口或阈值。本段是已见历史资料上的按时间留出检验，不能称未来新增样本。

误差MAE为预测涨跌与实际涨跌差的绝对值平均，越小越好；RMSE更重罚大错。下表误差单位为**收益率百分点**，例如MAE=4表示平均相差4个百分点。方向正确率不能直接转换成可交易胜率。

| 只用历史平均收益 | 3.9488 | 5.4908 | 50.2% | 5.2166 | 7.2270 | 53.8% |
| 基础对照 B | 4.0332 | 5.5025 | 49.5% | 5.0012 | 7.1270 | 63.3% |
| 只用焦点动量 | 3.9558 | 5.5093 | 49.2% | 5.2240 | 7.2568 | 48.5% |

| B＋上涨股票比例 | 4.0965 | 5.5389 | 46.9% | 5.1495 | 7.1862 | 58.7% |

主检验是“B＋是否低于零”。沪深300误差4.0372，基础对照4.0332，加入后反而略大；中证1000也由5.0012增至5.1084。尤其沪深300，简单历史均值的点估误差3.9488更小，复杂的基础模型本身也没有确立优势，不能只挑一个弱对手报喜。

## 5. 已有研究和这个模型的关系

本轮新增6次有边界的资料请求，实际核两篇全文、一篇出版方摘要及一份官方指标说明；没有找到能直接验证量化舵这套未公开算法的学术证据。以下研究支持某些组成概念，不能把论文的收益率挪给这个模型。

| 资料 | 研究内容与发现 | 对本题的适用范围 |
| --- | --- | --- |
| Lee与Swaminathan（2000），[Price Momentum and Trading Volume](https://www.lsvasset.com/pdf/research-papers/Price-Momentum-Trad-Vol-2000.pdf)，全文 | 美国个股过去收益与换手活跃度的交互；成交活跃度影响动量持续及较长时期反转，高活跃赢家反转更快 | 个股横截面、多月到多年；并非“大成交额股票平均涨跌跌破零→大盘反弹” |
| Gervais、Kaniel、Mingelgrin（2001），[The High-Volume Return Premium](https://rodneywhitecenter.wharton.upenn.edu/wp-content/uploads/2014/04/9901.pdf)，作者工作论文全文 | 股票相对自身历史出现异常高成交量后，约20日尺度存在相对收益线索；论文也讨论忽略佣金和冲击对盈利判断的限制 | **相对异常量**不同于绝对成交额排名；大公司日常成交额高，不等于出现异常关注 |
| [Herding for profits: Market breadth and the cross-section of global equity returns](https://www.sciencedirect.com/science/article/pii/S0264999319312982)（2021），出版方摘要 | 1973—2018年64国资料，摘要报告较高市场宽度对应较强后续回报，频繁再平衡成本需考虑 | 可为观察上涨参与面提供研究背景；未核全文数值，其宽度定义不能直接等同本轮20日上涨比例 |
| [Cboe VIX官方说明](https://www.cboe.com/tradable_products/cboe_minis/vix_mini_vix/) | VIX反映期权价格隐含的未来约30日美国市场波动预期 | 可补观察风险定价，表示预期波动幅度，不直接给出上涨/下跌方向；本轮未实测其增量 |

对这个想法最关键的区分是：成交**金额排名**、成交**换手率**、相对自身历史的**异常量**，是三种不同的量。论文发现不能仅凭都带“成交量”三个字就合并。

## 6. 还能配哪些观察线

| 观察项 | 能回答什么 | 本轮证据与使用边界 |
| --- | --- | --- |
| 焦点股动量＋同池平均动量 | 热门部分与大多数股票是否同向 | 已实算；差异可描述结构，预测增量未建立 |
| 市场宽度：同池20日上涨股票比例 | 恢复是否扩散，还是仅少数股票在涨 | 已实算并比较；本设定未改善预测，但仍可解释参与面 |
| 焦点组成交额占比＋最大单股贡献 | 交易关注是否集中、曲线是否被少数股影响 | 已实算；集中度高不等于净流入，也不自动表示见顶/见底 |
| 相对异常成交量/换手率 | 活跃来自长期规模，还是本身交易突然升温 | 有相关个股研究，本轮未另起模型，效果不能填为已通过 |
| 美股VIX | 期权市场是否正在为更大波动定价 | 官方定义已核；美股辅助背景，本轮未比较，不能跨市场照搬阈值 |

观察时可以这样读：焦点转强而上涨家数仍少，说明恢复较集中；焦点与宽度一起改善，说明参与面扩大；焦点与宽度一起弱，说明热门部分也没有明显支撑。它们是对**正在发生的状态**的解释，不附带“下一步必然反弹”的推断。没有必要把这些线拼成一个新分数来掩盖各自含义。

## 7. A股与美股的universe怎么落地

以下是后续正式观察的范围设计；这次固定300股试验不冒充已经把两个全市场建好。

| 层次 | A股 | 美股 |
| --- | --- | --- |
| 主观察池 | 当时上市的沪深普通A股，含创业板、科创板；北交所单列 | NYSE、Nasdaq、NYSE American上市的本土普通股；ADR与境外发行人单列 |
| 不混用的对象 | ETF、可转债等分开；新股历史不足、ST与停牌有明确资格/覆盖标记 | ETF、基金、优先股、权证分开；多类股份先定一公司还是一证券的口径 |
| 焦点组 | 池内按人民币成交额选活跃比例，报告实际数量和占比 | 池内按美元成交额选活跃比例，另报数量、行业结构和集中度 |
| 与持有宽基对照 | 沪深300、中证1000分别按当时有效成员做各自版本 | 标普500、罗素2000分别做；纳指100是特定指数版本，不能代表全美股 |
| 历史要求 | 保留退市、上市日期、停牌和行动资料，不回填今天名单 | 同样需要历史成员及退出股票资料，不能只留今天存活的巨头 |

可以先采用相同选取比例便于结构比较，但中国和美国应分别校准分布，**不能共用“低于零就稀有”的假设**。哪怕采用同一20日窗口，也只是一个待核定义。正式产品若目前只有当前股票名单，可以说明“今天的观察”，不能因此宣称具备十年效果验证。
