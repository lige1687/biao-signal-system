# 行业情绪叠加EMA20：条件收紧EMA10实测（2026-11-03）

## 一句话结论（大白话）

**按Gemini这次明确的规则测完，周频主样本有小幅收益和回撤改善，但换成每日或其他周频排期就不稳定；现有证据不足以把热度升级为自动仓位规则。** 这次不能说“完全无用”：原周频叠加多赚累计1.60个百分点、年化约0.40个百分点，回撤少0.68个百分点。不过五种周频排期只有两种多赚，原主排期的年度改善集中在2026年，且原有强热很少真正改变仓位。保留有限风险观察，不重建SCI；不修改生产仓位控制。

**范围和未知：** 20条行业指数共同完整信号期为2023-02-10—2026-08-24；观察与次日成交后，周频计收益855日、每日857日。输入是已查看过的历史和指数价格，缺合格ETF分红/执行链；旧强热另用当前成分回填的一级/二级代理，只有2022、2026两个短有效段。结果不是全A、红利指数或实盘收益验证。

## 1. 真正比较了什么

- 基准：收盘价≥EMA20满仓，否则空仓。
- 叠加：先满足EMA20；仅当成交活跃≥88，或对应面板旧强热触发时，再要求收盘价≥EMA10。低于EMA20时，即使EMA10更低，也必须空仓。
- 对手：始终持有、始终使用EMA10。每5个交易日观察是低频主检，每日是预先规定的执行频率敏感性；不是盘中触线止损。
- 所有方案观察t日收盘、t+1日收盘成交；每行业初始等额资金、现金收益0、独立现金/份额子账，行业之间不每日调款。单边10bp主检、20bp压力测试，含首次建仓及末日清算。
- 热状态解除就恢复EMA20；满足条件在下一观察点回补，未加“触发后锁定若干天”。这是本次明确的临时收紧版本。跌破均线不保证熊市无损失，执行等待和跳空仍在。

这是对风险执行的独立研究扩展，不是把LEI原策略改成单均线系统。原指标不因本次局部结果被删除。

## 6. 对Gemini质疑的纠正及保留意见

1. 上轮完整报告§4已经列过“高活跃时改用EMA10”：年化9.72%、回撤25.48%；但当时是半仓/满仓。本轮是满仓/空仓并加EMA20硬底线，确实值得另测。上轮摘要遗漏了收紧那一行，容易使人误以为未测；本报告补清，保留旧结果。
2. 新特征加入后预测误差变差，不能单凭这一点认定“严重共线性导致失败”；价格变换与已有信息重复是合理竞争解释，但具体原因也可能来自模型形式、估计噪声或有限样本。量能有风险线索，不代表它已被证明与价格正交；旧强热还包含价格宽度，不能全称纯量能。
3. 12/20行业方向相同，不证明科技和红利两种基因截然相反。本轮资金效果的具名反例已经说明不能按这个故事直接分行业操作。

本轮未重复查文献、重训预测模型、补行情或构建SCI。机构方法的已核原文与其不支持统一88/15阈值的边界，复用[上一轮报告](/Users/yongbiaoli/Desktop/lei-signal-lab/docs/experiments/sector-sentiment-comparative-evaluation-2026-11-02.md)；方法声望不能替代本地增量。
