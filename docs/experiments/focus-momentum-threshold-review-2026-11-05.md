## 3. 本次采用的阈值与标记决定

| 展示 | 依据／作用 | 当前决定 |
|---|---|---|
| 0%虚线 | 20日平均涨跌的数学零点 | 保留“涨跌分界”；上穿看修复、下穿看降温 |
| 小卡高低虚线 | 每日仅取此前756个有效观察日，线性插值计算15%／85%分位；缺资料不算 | 保留本地历史位置参照，明确标出15%／85%；无“机构认可机会线”说法，不改变原分位算法 |
| 约5%极端时间思路 | 富达旧版ROC阅读方式，未给本模型完整算法 | 留作有出处的阅读参考；不把它偷偷替换现有分位或新增买卖线，预测增量未评价 |
| 每一次原始穿零 | 当日收盘可确认的正负转换 | 全历史上下两图都标出；方向筛选只用于读图，不依据未来收益选点 |
| 大圆环及竖虚线 | 用户当前选中的日期 | 图例写“选中日期”，可点任一图的三角定位，不赋予预测成功含义 |

本轮增量是让已有状态可以看清、让阈值出处可以分辨，未增加一种独立金融信息。单纯把全部点改成“机会点”会夸大已有证据；按未来底部挑少数点又会引入事后信息。现有资料已能回答本轮阈值适用性问题，不重复旧实验或换参数寻找好结果。
