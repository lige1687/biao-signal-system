# 低频怎样选标的，再与操作时机结合

2026-10-19｜有界文献与本库证据审查；复用旧结果，0新行情、0新回测。适用方向为个人低频、宽基与ETF优先，股票选股单独说明。

## 一句话结论（大白话）

**值得补强“同一天选谁”的研究层，先用月度选择、较慢变化的金融信息，再独立核操作时机；不用先做短周期选股，更不宜一开始同时预测何时切换因子。** 本库已有动量选池和ETF选强加退出研究，结果有正有反；缺的是形成可复用的排序效果、适用范围及相对简单方法的完整证据，不能说从零开始，也不能说搭配已经普遍有效。

当前名单回看、少量行业、部分时期贡献集中，以及原LEI完整语义仍待原负责人处理，限制本地结论。本轮只回答方法与优先级，未实施基本面筛选、部署RD-Agent或改变生产规则。

## 1. 三个不同问题，分别检验

| 层次 | 大白话问题 | 必要证据 |
|---|---|---|
| 同时选标的（横截面） | 同一个月末，哪些股票或ETF更值得优先研究？ | 同日排名是否区分随后表现；高/中/低组、各期差额、对象贡献与成本 |
| 单标的操作时机 | 选中的产品什么时候进入、退出或减持？ | 在固定候选和资金规则下，动作相对简单持有改善什么、付出什么 |
| 切换因子 | 什么时候偏重动量、质量或价值？ | 先有固定组合，再核切换条件当时能否知道、相对固定组合是否有新增帮助 |

平均分配并非错误，它可以做简单对照或组内汇总；但全名单一条资金曲线不检验“排序能否把好坏区分开”。选股因子应先看同日期的排序及分组差异，保留每期/每只的分布；按日或月汇总，不能把所有股票日期混成独立机会。全部标的都跌时，排名第一仍可能亏损；相对强与自身趋势向上并不相同。合计账户的最大跌幅也不是单只股票跌幅的平均。

## 2. 低频并不要求短周期选股

Kenneth French的月度动量口径按此前第2至12个月表现构造组合，每月重建；其价值、盈利能力和投资特征组合也使用滞后财务信息与年度成员形成安排。它们证明这些研究可以以月度/较慢信息组织，不证明某个频率对我们最优，更不证明境外多空差额能成为本地只做多净收益。[月度动量方法](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_mom_factor.html) · [五因子构造](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/f-f_5_factors_2x3.html)

本库研究建议：初始以月末统一比较作为低频选标的框架，质量/价值在实际财报公开后再更新；允许观察日价格但不要求每天换名单。回看多久、预计影响多久、多久更新名单、多久交易是四个不同选择。月份与1—3个月观察窗口仅是待固定的问题尺度，不启动多窗口搜索，也不根据某段曲线选择最优周期。卖出与风险规则可以比选股更新更快，仍由原策略研究负责，不强迫所有决定锁到月末。

股票里的公司盈利质量不能直接套到黄金或债券ETF；ETF选择须先分底层风险、跟踪对象、币种与交易条件，同指数不同产品不能当成独立金融证据。跨股票的因子证据与跨ETF的选品证据分别保留。

## 3. 从金融解释找候选，怎样排优先级

以下是候选机制与本库建议，不是已经证实的本地收益来源。每题先固定一个可测变量和竞争解释，避免把所有指标同时扔给模型。

| 候选 | 为什么值得研究；可能失败在哪里 | 本库优先用途与资料条件 |
|---|---|---|
| 中期相对动量 | 可能反映信息逐步被市场消化和趋势延续；也可能只是行业同涨，反转时失灵 | 先作为已有参照，复用12-1定义/排序和负结果；不能再把旧动量包装成新发现。ETF用不同风险对象，股票需历史成员 |
| 盈利能力/质量 | 持续经营能力或对风险的不同定价可能影响长期表现；好公司也可能买得过贵 | 股票的下一类独立信息候选。先核行业内可比盈利指标、公开日期、修订和退出者；“质量”不是一个已经统一定义的分数 |
| 价值 | 相对账面、盈利或现金流的价格可能包含风险补偿或过度悲观；便宜也可能是经营恶化 | 后于质量资料资格，允许与动量做互补假设；不同会计/行业/负分母处理须先固定，不把低估值直接写成买点 |
| 低风险/防御特征 | 观察价格起伏、市场敏感程度或经营稳健性；低波动不保证高收益，也可能错过上涨 | 先作为风险与分散用途的候选，评价少亏和少赚；不一开始并成额外选股硬条件 |

AQR对动量的原文介绍明确区分相对赢家与输家；French定义库提供价值、盈利能力与投资特征的可复用研究构造。这些支持选题和对照，不使本表机制自动成立。[动量原作者说明](https://www.aqr.com/Insights/Research/Journal-Article/Fact-Fiction-and-Momentum-Investing) · [French数据方法入口](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)

优先次序是“旧动量作参照 → 检查独立信息候选的数据资格 → 单项增量 → 固定的少量组合 → 必要时才研究因子切换”。这不等于宣布质量胜过动量；当前尚无足够本地证据给这些候选排收益名次。

## 4. 我们的策略有哪些基础，缺在哪里

《LEI技术交易体系》1.3有经营惯性和强于大盘的思路，4.1谈先选择可理解的生意再处理技术交易，4.7含盈利、现金流与股票池原则，且强调利润率不宜跨行业简单比较。因此原思想中有选股内容，不能说策略完全没有选股。

但《LEI技术实现》开头明确仅覆盖单标的技术分析、入场、失效、止盈和持仓状态，不含基本面选股、组合配置和仓位数量计算。项目还有板块相对强度研究代理，使用当前成员回看，不能当成已验证选股模型。**真正缺口是将选股思想转为时点合格的指标、横向比较和可复用效果证据。**

本轮学习和独立候选提案不把基本面改成现有技术判定的硬过滤，不改两份策略原文。技术研究和系统UI仍归现有两位负责人；本任务不接管原A、小时确认或共同资金实验。原文SHA与已确认值一致，见raw来源清单。

## 6. 怎样借RD-Agent推进，具体落在哪一步

微软官方金融场景把假设、因子定义/实现、Qlib评价和反馈串起来；示例是CSI300、Alpha158加新因子和LGBModel，不能直接当本库低频ETF的验证框架。[官方金融场景](https://github.com/microsoft/RD-Agent/blob/main/docs/scens/data_agent_fin.rst)

本轮已在同一报告/raw记录中完成一次资料研究循环：用户问题 → 原策略与论文 → 旧实验查重 → 原表复核 → 发现“已有组合但效果依赖范围” → 调整优先级。下一步应复用现有合同、定义和尝试账本，不另建研究平台。最小候选卡如下，仍是提案，不是已冻结或已运行实验：

| 项目 | 已落下的内容 |
|---|---|
| 核心问题 | 同一选择日，在已有中期动量之后，行业内盈利能力是否提供不同的信息，或减少不稳健候选？ |
| 候选身份 | 股票独立选股扩展；尚无本轮新定义ID。ETF主线不直接照抄公司指标 |
| 金融假设/反例 | 盈利持续性可能未被价格完全反映；若已被估值/动量吸收或只是行业差异，增量可能消失 |
| 已有参照 | 准确动量定义与历史阴性、原策略文字、旧四组组合结果；不重命名成新发现 |
| 第一项必要工作 | 先清点已获准的历史财报公开日期/版本、行业和退出者；不可用则记录缺口，不拿今天财务值填历史，也不立即买数或批量下载 |
| 后续评价 | 先同日排序和分组分布，再看相对动量增量；合格才进入同资金的选择与时机组合。主收益或风险用途须事前固定 |
| 反馈和停止 | 缺核心资料停在资格；无增量保留负结果；只有具体新证据改变判断才继续。不得为得到正结果循环换窗口 |

这张卡把下一题做得可检查，但不能代替数据资格和准确公式合同。本轮未安装、调用或试跑RD-Agent；其通用执行层的旧成功与模型反馈失败直接复用。自动迭代用过的资料不能又作为最后未知检验；费用、失败、候选家族及尝试次数要累计。

对“什么时候用哪个因子”，优先检验固定的少量不同信息组合。AQR对估值驱动的因子切换研究发现，可能只是重复增加已有价值倾向且损失分散，因此不能预设动态切换更优；这不证明所有切换方法永远无效。[原作者研究简介](https://www.aqr.com/insights/research/journal-article/contrarian-factor-timing-is-deceptively-difficult)
