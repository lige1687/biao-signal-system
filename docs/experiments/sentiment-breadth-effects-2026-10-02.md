# 宽度水平与恢复：有没有价格之外的帮助（2026-10-02，ARCHIVE）

## 一句话结论（大白话）

这轮已经把免费短历史的实际效果算完：加入宽度水平后，SPY随后约一个月涨跌的典型估计误差从4.262降到4.149个百分点，再加入宽度变化降到4.022。但去掉用于学习的2025年4月特殊行情后，两项帮助都反转为更差。**当前只能保留有限线索，不能确认稳定帮助，也不能据此加仓。** 这里的宽度是供应商记录的“站在均线上方的股票比例”；成员名单、计算与调整方式尚未核实，本轮不是原LEI情绪交易规则的验证。

## 4. 输入、定义与范围

旧、新供应商快照186个共同日期中，B20改动185日，最大1.90个百分点；B50/B200每天都变。原因未确定，不能直接说是成员变化，也不能把今天数值当历史当时已知。完整依据见[版本审计](sentiment-breadth-version-audit-2026-10-02.md)。这些未知阻断原E和历史可交易解释，却不阻断“这份固定版本数值与之后价格如何相关”这一限定问题。
