# AAII散户看法：极端程度与中长期新增信息

## 一句话结论（大白话）

AAII在中长期留下弱线索，但还不能说它稳定增加了预测能力：加入看多减看空这个连续数值，120／252日涨幅的估计误差相对本轮价格背景减少约2.55%／9.54%；再额外强调原±25以外的极端强度，反而比连续值用法更差。所有中长期改善范围仍容纳恶化；多项价格背景模型还不如只用过去平均涨幅，不能把超过较弱对手包装成可靠增量。

本轮实际完成SPY单市场、五个固定期限、六种对照的历史检查与简单对手挑战。只限假设调查七天后可用的已见历史；真实发布时间、历史修订和价格复权版本仍未证实，没有新资料确认，也不是账户收益或完整模块E验证。整个情绪库S01—S10仍未完成，S01成员资料阻塞没有消失。

## 3. 更简单的对手会改变判断

核心六种对照已含只用历史均值的I。看到结果后增加的诊断仅重用原预测和原抽取误差，未新拟合、未新生成标签、未改期限；不把这个后加检查伪装成结果前已指定的主比较。

- 120日，B误差9.0886，加入连续值为8.9720、加入极端为9.0195，而只用均值是8.7776。加入两种AAII用法仍不如更简单的对手。
- 252日，B误差13.6235、BXE为13.1787，而均值是13.1290；“改善6.42%”不能直接当成实用价值。
- 只用连续AAII的X，120／252日相对均值改善1.50%／5.25%，但范围分别为恶化6.02%到改善6.82%、恶化4.04%到改善11.12%。也不能确认。
- 背景加连续AAII的BX在252日相对均值改善2.60%，范围恶化21.95%到改善19.75%，估计很不确定。复杂度和背景本身的弱点不能都算作情绪贡献。

因此，保留连续AAII的中长期线索，当前不增加极端强度规则，不将模型比较升级为可靠预测或策略。

每个期限成熟极悲观44日期、极乐观60日期，分别属于25／39个连续调查段；这些段也可能共享未来行情，不当作25／39份独立成功。极悲观44日期中20个在2022年，该年的120日随后平均仅涨0.84%，整体10.05%并非每次都能得到。252日极悲观随后平均涨19.71%、非极端15.04%，但上涨比例88.6%反而低于非极端89.6%；更多平均涨幅不能改称更高胜率。

## 5. 现在知道什么与仍不知道什么

本轮削弱了“上轮20日简单用法不改善，所以AAII所有期限都无用”的外推，也未支持“越极端就越应该加强信号”。连续值有中长期点估计线索，但误差范围与简单对手都不足以确认稳定新增信息。

最终研究枚举：`Insufficient evidence`（证据不足）。这适用于本轮可计算的已见历史；具体结论是短期当前未支持增量、连续值中长期保留线索、加入极端强度当前未支持额外帮助。并非认定整个调查家族无效，也不宣布稳定、可靠或独特收益。

仍未检验：情绪恢复／持续周数／20周平均线、未来风险与波动、其他市场、AAII同宽度或NAAIM组合、完整E与真实资金。原宽度仍为E主输入，本轮调查不是独立买卖触发；普通技术研究未扩项，价格变量只是预先指定对照。

## 6. 定义、来源、时间与权限

原值实际由调查中的Bullish和Bearish比例计算，不把问卷当持仓：`candidate:sentiment.aaii-spread@draft-1 = 100*(Bullish−Bearish)`。本地新增`local:sentiment.aaii-low-excess@1.0.0 = max(−25−x,0)`、`local:sentiment.aaii-high-excess@1.0.0 = max(x−25,0)`，即超过原界限的悲观／乐观强度。等于±25时额外强度为0，分组包含界限；缺失值不当0；原数值不截断、不翻方向。`original_LEI_threshold`仍为±25，不称最佳。

标签`local:sentiment.forward-h@1.0.0`是C(t+1+h)/C(t+1)−1：h段收益、h+1个收盘点。观察t是源日期加7自然日当地23:59以后第一个实际报价收盘，最早结果起于下一报价；真实历史首次发布时间未知，该假设不回写原available_at。训练标签终点严格早于评价年1月1日。

原源文件只读，静态副本在raw/inputs。2038调查1987-07-24—2026-08-27，8456报价1993-01-29—2026-09-02；范围外资料仅作输入身份核查与历史预热，评价标签不得越2026-06-30。调查值已在上轮与官方缓存逐值核一致，本轮100×多空差独立复算零差。价格是旧调整收盘缓存，逐公司行动与历史调整版本未验，不能当实际成交价。输入、协议、代码及两份最高策略原文实际SHA都绑定清单；桌面原文SHA与用户确认值吻合。

拟合为带截距线性最小二乘，训练均值和标准差仅用成熟旧行；每年一次、没有参数搜索或结果截断。实际504次拟合（五期限×六模型，252日2026无评价而少六次），一个真实核心批次。预算为本轮新有界问题最多四次尝试、一个核心加最多三个必要跟进；旧可行性四次含失败保留，完整家族探索总数未知。本轮另一次保存误差挑战，无新拟合或新市场标签；没有把换任务当独立数据。Pro／网络／付费本轮均0；生产、交易、OKR与仓库外写入均未执行。
