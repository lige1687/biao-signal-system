## 一句话结论（大白话）

免费资料已经拿到：这次又直接下载了约516 MB的公开股价档案，并在Investing.com核到了2008—2025年的20日、50日宽度页面。后者可能省去逐只补退市股票的工作。免费登录现已恢复，但点击下载尚未收到完成确认，完整文件和计算口径仍待核。逐只重建仍没补齐：2008-09-12找到连续50个交易日价格的同名候选为384/496，排除已发现的公司身份冲突后最多383个，其余身份仍未验证。因此本宽度输入阶段有资料进展，宽度效果尚未评价。再次续查另取得官方131周NAAIM并完成限定效果检验，见末尾追加及独立报告。

宽度是“成员股票中，有多少站上各自20日或50日平均价格”的占比。本轮服务原LEI模块E的美国宽基指数信息研究，不改原15%/85%判断、生产或交易规则。今天的成员回填旧价格不能代替当年成员。

## 1. 问题、范围与方法

用户明确要求自行取得开源、免费或有免费额度的数据，不要求联系供应商；需要登录时可由用户操作。沿用五个预定核验日期：2008-09-12、2008-09-15、2009-03-09、2020-03-23、2025-12-31。

执行两条路线：公开历史成员加股票价格，及直接提供历史宽度的页面。前者核实际连续报价、证券身份和版本，后者先核历史存在性、下载条件和口径。资料错误会改变研究对象，增加预测计算不能修复它。本轮未得到完整合格输入，不生成未来结果或拟合效果；五个日期只是来源检查点，不是五次独立投资机会，也不保证中间全部日期合格。

连续50日报价是本次完整窗口的可得性标准，不等于宣布所有宽度算法必须使用共同分母。先核输入、再另冻单一效果问题；技术因子、其他市场、S06—S10不自动扩项。

## 4. 反例和旧解释纠正

**AGN有旧价格，但公司不对。** 2008-08-29的iShares同时有Watson（WPI）和原Allergan（AG4），证券身份编号不同。持仓市值除股数所得单价分别是30.31和55.87美元；FNSPID的AGN当日未调整收盘30.309999美元，吻合Watson而非原Allergan。fja旧日名单列AGN、不列WPI/ACT，旧别名链可能还影响名单中的公司数量。本轮没有完成全部公司沿革，不作更强断言。

前阶段把AGN作为“已取得旧价格”的例子，文件事实保留，但其用途需纠正：不能证明补齐原Allergan。Boris的AGN调整价也不能只凭相似性认定身份。[身份反例实证](raw/sentiment-open-source-input-2026-09-30/security-identity-counterexamples.json)保存原字段、计算和指纹。
