# 低频趋势研究：新增信息建议的吸收与取舍

2026-10-19｜本轮为资料审阅与研究方向取舍，没有新增收益计算。适用个人低频研究，宽基与ETF优先，同时保留股票；市场、产品和用途分别判断。

## 一句话结论（大白话）

这份建议值得吸收：保留双均线描述趋势，让行业信息帮助选对象、风险信息帮助判断持有过程、成交与盈利信息提供待验证的补充。当前最值得补的是“在已有趋势信息之外，是否增加了判断”，而非把每条信息都变成买入条件。行业排序和下跌结构进入优先核查，盈利意外先核历史资料，成交参与随后；这不是已发现有效因子，也不是全清单开跑。

## 1. 本次实际吸收什么

1. **先指定信息负责的决定。** 排序、风险识别、仓位、持有退出、组合分别评价；一个指标可以有多个用途，但本轮主用途在看结果前写定。风险信息有用，不要求它单独赚钱；风险预测较好，也不自动证明减仓后更好。
2. **比较起点要保留本来知道的信息。** 若已有近期涨幅、总波动和趋势持续时间，不能把它们删掉，只用绿黑标签当对手，再把补回这些内容称为独立优势。按本题选择相关的简单信息，不无理由无限堆控制变量。
3. **先核数学关系和旧证据，再决定扩样。** 来自不同数据不自动独立；同样来自价格也不自动无用。行业环境与个股相对行业表现有数学联系，应说明到底补充了谁的信息。
4. **大趋势的代价继续放在核心位置。** 少跌多少，与少赚、等待、买贵、未参与的大行情、成本一起呈现。宽基、行业ETF、股票分别下结论；不能靠增加同涨股票数制造更多独立经历。

上述前三项已接入[AI因子发现工作指引](../research/factor-discovery-playbook.md)；现有 `lei-lowfreq-research` 技能按原入口读取，不再增加一套流程或指标库。

## 4. 真正冻结新研究前，必须补齐的定义

- **行业信息：** 使用当时可知的行业归属、成员与权重；说明个股是否参与其行业指标，防止“自己涨导致行业涨”被夸成外部确认。同一天同一行业，减相同的行业收益不会改变股票排序；已有股票收益再加“股票减行业收益”，主要是在补行业收益。要区分挑行业与挑行业内股票，不能重复记作两份贡献。共同日期/行业的观察彼此相关，不能当成独立样本；条件比较仍不等于证明因果机制。
- **下跌结构：** 可供定义讨论的一个版本是 `sum(min(r, 0)^2) / sum(r^2)`，即下跌日收益平方占全部收益平方的比例。它是价格衍生信息，且不等同于下行标准差除总标准差。收益类型、是否以零为参照、窗口、复权、零分母和缺价都尚未冻结；本轮不新增对象ID、不试多个公式挑赢家。它可能反映压力，也可能反映短期反弹条件，需留下竞争解释。日收盘指标不能直接描述日内最深下跌；评价时点和未来路径数据须匹配。
- **成交参与：** 若叫换手率，要有当时流通股数或明确的供应商分母；若只有成交量相对自身历史，只能称相对成交量。ETF份额变化、成交活跃与成分股交易分别定义。单日大波动、规模和流动性可能解释差异，不能先称“主力进入”。
- **盈利意外：** 实际盈利相对公告前分析师预期，与基于过去财报估计的盈利意外是两种版本；两者均不能用最新修订值冒充当时版本。同比增长可另作候选，但不改名为意外。本轮未取得合格历史预测资料，数据可用性保持未知。
- **行动与组合：** 若信息有效，比较只改排序、只改仓位、二者结合与原方案；既定主问题优先，非要求穷举。用当时能执行的简单风险方案检查收益和跌幅；事后拿全期波动配平只作解释。没有成交、现金和再入规则时，不报告账户改善。

当前登记可复用 `mixed.rv20@1.0.0`、`mixed.rv_percentile@1.0.0`、`research.risk.vol_instability20@1.0.0`、`research.volume.abnormal20@1.0.0`、`research.space.prior_upper_pivot@1.0.0`。它们不是上述新候选的替代ID。当前定义库1.6.14中未发现可直接绑定这几个提议的同名完整定义；正式效果研究须先登记准确对象及代码。
