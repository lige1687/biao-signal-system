# 开盘前共享资金下单计算：限定工程核验（2026-10-08）

## 一句话结论（大白话）

人工研究输入现在能在开盘前算出每只产品分多少钱、买多少整手以及最高能接受什么价格。初版发现的三个问题已修复并通过独立复核：不再把已经花掉的钱拿来重复安排，不同资金回执能对应不同订单，已知公司行动不会在后续安排中被漏掉。这让后续研究的下单计算更可信，但还没有接入成交账本，也没有证明调整持仓值得多付费用。

沿用2026-10-04共享账户规范v0.2，比较方向仍是“只用新钱补较少的一只”与“达到固定差距后允许调整旧持仓”。每周250元、两只产品各半、5个百分点均是旧研究情景，不是用户真实资金或风险配置。本轮没有运行两种方法的历史收益比较。

## 实际算出的边界

下面费用仅为明确命名的人工假设：相应案例分别给佣金比例、最低收费及滑点，不能当成用户真实收费。

| 检查的问题 | 固定输入与结果 | 对后续研究的意义 |
|---|---|---|
| 买不起一手怎么办 | 参考价2元、佣金0.1%、最低5元、滑点0.1%；100份共需205.20元。预算205元为0份，205.20元才可买100份 | 不借钱凑整手，0份不收最低费 |
| 看到开盘后能否改数量 | 预算205.25元、固定100份，最高价向下取到2.000；2.001需205.3001元，拒绝 | 不用已知开盘倒改过去的计划 |
| 比例费用和价位边界 | 预算500元、参考价2元、佣金1%、最低1元、滑点0.5%，买200份，参考成本406；限价2.463成本499.989，下一档成本500.192 | 两种收费分支和向下取价位均有独立金额核算 |
| 应收的钱能否拿来买 | 持仓价值200/400、自由现金300、应收100，总资产1000；不足金额300/100，预算分成300/0 | 应收计入资产，但没有支付前不能花；当次未用预算不倒给同一开盘另一单 |
| 原200元已经花掉 | 当前实际可用174.82元且已含卖款，只安排100份，参考成本105.10，剩69.72元 | 不再把旧200元重复使用。当前现金0且明确不含卖款时，加这笔174.82元得到同样结果 |
| 原合法现金仍在 | 当前200元明确不含卖款，加实际净卖款174.82元，共374.82元，安排300份 | 修复没有禁止本来可行的安排 |

数量、限价与顺序在开盘前固定。缺少资格、开盘越限、试图改数量或把别的计划订单混入时拒绝。这里检查的是人工报价是否符合约束，没有证明真实市场一定能按该价格和数量成交。
