# 趋势条件下的低贝塔、资产增长与净股份发行：定义复用与证据审查

## 一句话结论（大白话）

这三个方向都可以作为“已经出现同样趋势机会后，再选哪些对象”的研究问题，其中低贝塔最贴近当前“少亏、又少丢上涨”的需求。Open Source Asset Pricing适合提供出处、具体公式和复现参照；它的美国组合结果不能直接证明我们的趋势交易会改善。现有资产扩张研究并没有超过简单方法的清楚证据，也没有研究转绿条件；低贝塔和净发行在同样趋势内的效果仍未评价。此次完成了源码/定义对应和关键算式核验，**尚未完成三个条件策略的效果研究**。

## 1. 三个金融问题及反例

| 方向 | 金融理由与指标含义 | 与趋势条件结合要问什么 | 必须尝试推翻的解释 |
|---|---|---|---|
| 低贝塔 | 贝塔衡量相对于选定市场的共同涨跌敏感度；估计为股票与市场收益的共同变化除以市场收益的变化程度 | 同样合格的上涨机会里，偏向较低贝塔，是否少亏且保留足够上涨？ | 可能只是少承担市场风险，效果不如原选择少投入一些资金；牛市反弹可能明显落后 |
| 较低资产增长 | 同口径总资产同比变化；扩张可能意味着投资回报变薄、估值偏高或过度扩张，也可能是有价值的建设期 | 同样趋势内，扩张速度是否有额外区分力；增长快但经营支撑强是否不同？ | 并购/合并范围或会计变化制造指标；行业结构、盈利、估值解释了表面差异；新产能尚未贡献盈利 |
| 较低净股份发行 | 实际股数经拆并股等调整后的净增加；反映股权融资及现有股东权益比例的变化 | 同样上涨机会里，发行多是否更容易后劲不足或上涨失败？ | 员工股权激励、换股并购、优质融资也增加股份；减少股份不一定便宜或经营健康 |

低贝塔不等于低波动：股票可以不跟随大盘，却因自身事件剧烈波动。贝塔随市场参照、估计期限和时期变化；它不是下一次上涨幅度或最大亏损保证。融资约束导致投资者偏好高敏感度资产，是BAB研究提出的机制之一，不能视为所有市场的唯一原因。[Frazzini–Pedersen / AQR](https://www.aqr.com/Insights/Research/Journal-Article/Betting-Against-Beta)

CMA是“投资保守组合减投资激进组合”的收益，不能直接把这一条组合历史收益当成每家公司的已知因子分数。我们要先测的是公司层面的资产增长，再考察它和趋势的条件关系；不能直接使用后来实现的CMA收益去决定此前选股。现有年度资产增长研究已引用French投资定义，但其A股范围、行业规则与毛利条件是本地适配，不是完整CMA复现。

## 2. Open Source Asset Pricing实际能复用什么

准确名称为 **Open Source Asset Pricing（OSAP）**，主要代码仓库为`OpenSourceAP/CrossSection`，作者Andrew Y. Chen与Tom Zimmermann。它将公司特征计算和组合构建分开，提供公司层面特征及多种组合实现的下载入口。源码运行涉及WRDS等数据来源，开源代码不代表底层授权数据全部免费或已在我们本地。[官方仓库](https://github.com/OpenSourceAP/CrossSection)

本库10月8日已有固定版本`8db892442c2c3a3779b0f1eac4370d3655be15a1`的资料表和部分源码；本轮核对了原保存指纹，直接复用，没有重新建因子目录。

| 对应对象 | 实际核到的口径 | 对本任务的提醒 |
|---|---|---|
| `Beta` | 已存Python用月度超额收益对等权市场超额收益作带截距回归，60个观察窗口、至少20个观察 | 它是Fama–MacBeth口径，不是BAB完整构造；观察行数与连续月份需核，市场参照不可随便换 |
| `BetaFP` | 固定资料表有Frazzini–Pedersen条目，组合复现标为`3_distant`，说明常规十分组和原BAB的权重/风险尺度不同 | 不能用普通高低组差额冒称原BAB；本轮最初猜测文件名404，旧目录索引实际是`ZZ2_BetaFP.py`，尚未取得该文件正文，不假装已完成源码核验 |
| `AssetGrowth` | 当前Python读取月度财报中间表，用总资产较12行前的比例变化 | 必须验证上游已经形成完整逐月表，12行不总等于12个月；财报何时可知也在上游处理，单看因子脚本不能证明无未来资料 |
| `ShareIss1Y` | 当前Python按实际月份配对t−6和t−18的调整股数，再算相对增长 | 是留出6个月间隔的一年变化，不是今天比去年；不能把原作者滞后处理自动当A股公告可得证明 |
| `ShareIss5Y` | 固定资料表有五年股份变化条目，原文与股息/复合发行衡量存在差别说明 | 不能与一年变化随意互换；未取到本轮实现正文，不声称已复现 |
| `NetEquityFinance` | 资料表定义为发行股票收到的资金减回购支出，再除以平均总资产 | 现金融资指标和净股份数量是两个对象；不能用回购公告、加权平均每股收益股数代替 |

发现一个需要先解决的具体差异：旧资料表写调整股数用`shrout/cfacshr`，当前ShareIss1Y代码用`shrout*cfacshr`。版本及调整因子定义尚未完整核对，因此不宣布上游代码错误，也不静默选一个。已做明确约定的拆股例子：纯1拆2时，100股变200股，若旧调整因子2、新因子1表示统一到新股单位，乘法得到净增加0，除法却得到300%。这说明**拆股本身不能被误认成净发行**，必须按实际供应商因子含义检验。算例不证明A股历史股份资料合格。

同样已实算缺一个月份的例子：12行滞后跨了13个月。复用范围应包括上游的证券身份、完整月份、时点、缺失和公司行动处理，而不只复制最终一行公式。

## 4. 低贝塔优先比较什么

主要假设：在同一批、同一时间已出现的趋势机会中，低贝塔选择能以较小的上涨牺牲减少损失，并有一部分帮助不能由简单减少投入解释。这仍是待证假设，不能预先承诺“不丢上涨”。

必要对照保持同一资料资格与原机会分母：原趋势方法；趋势机会内低贝塔；原趋势方法减少投入；同样机会内低波动/已有动量的简单选择。现金比例只能使用决策前的风险估计，不能用后来实现的风险倒算最优仓位；未授权杠杆或做空。如果低贝塔只获得与少投入一样的风险/收益变化，保留风险标签或仓位用途，不必新增选股规则。

收益和代价应并列：上涨月份保留多少、强行情漏掉多少，下跌月份少亏多少，最差损失、恢复等待、集中行业、交易及维护成本。贝塔估计不稳、停牌导致同日收益错配、市场参照不同、风险降低来自行业偏向，都可能削弱结论。净发行和资产扩张还应看与规模、盈利、估值的重复，而不是简单把所有分数相加。

“处于绿色”“刚转为绿色”“满足原策略完整买入条件”须分别绑定。原语义还有20/60多头排列、观察黑转绿等背景，单纯颜色事件不能冒称完整策略。现存价格式绿条件`C>EMA20且C>C[t-20]`，在相同EMA递推和完整日历下，与SMA20及EMA20同时上升在数学上等价；27个有相等边界的合成例子已核同，**没有证据把两种文字写法判成规则冲突**。但状态与转变事件、预热与缺报处理仍然不能混用。

## 最小决策卡

- 改善什么：不从名称猜算法，避免把低贝塔、BAB、上下行跟随差或三个融资指标混成同一对象；认清“趋势内选择”尚未被旧研究回答。
- 代价：需要合格市场参照、历史股份和时点维护；低贝塔可能丢强行情，资产/发行条件可能排除优质扩张。
- 保留：低贝塔×趋势作为下一优先资格问题；净发行是不同信息方向，先补股份事件；资产增长先复用旧资格，不重复原年度条件。
- 暂停：宣称三个条件策略有效或直接改为硬过滤；旧年度资产增长追加试法保持暂停。
- 恢复条件：同一机会集合与市场锚点/股份数据资格实际通过，再事前冻结一个具体比较并运行，必须同时交收益、风险和上行代价。
