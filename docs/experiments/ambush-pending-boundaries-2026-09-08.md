# 05：完整资金研究的未成交与取消记录

## 一句话结论（大白话）

在新研究副本中补上了“安排了但没有成交”的原因记录；8类人为构造的边界检查通过，64个旧账户的原有五项输出完全不变。真实历史新增732条记录，全部是买够52次后取消后续安排。这改善了可核查性，没有创造新的策略收益。

服务层：资金安排及持有退出的研究记录；原252个报价日建仓、52次买入、30%目标退出和756日最终期限均未改动。只读前轮封存数据，未改生产程序。

## 本轮检查了什么

| 情形 | 明确记录的结果 |
|---|---|
| 建仓期末缺开盘价，未能买入 | 建仓期过后取消，不在以后补买 |
| 研究截止时仍缺开盘价 | 保留未成交买入或卖出安排 |
| 退出已触发，但当天缺开盘价 | 等第一次有效开盘再执行 |
| 期限到了但从未持有 | 记现金计划到期；旧五项输出中的零金额动作仍保留以便比较 |
| 最后一日收盘才形成决定 | 本段数据内无后续成交，不假造买卖 |
| 已买满52次 | 后续安排按达到次数上限取消，与当天能否获得开盘价无关 |

用完整账户摘要、每日资金、计划表、事件表、成交动作五项逐项比较，共64个账户，均与旧版本一致。独立复核还对照了原封存摘要。合成边界用于构造明确答案，不能当成新增历史机会。

## 独立复核发现与修正

初版新增日志在买够52次后仍依赖有效开盘价来取消，导致后续缺开盘的安排误记“截止时没成交”。复核者给出55条每周报价、最后两条缺开盘的反例；已修复并严格核对两条取消日期。复核和最终结果见[独立记录](raw/research-05-08-next-2026-09-08/05/independent-review.md)、[8类检查与64账户结果](raw/research-05-08-next-2026-09-08/05/results.json)。首次建仓期末反例没有实际覆盖到一个周安排，已扩大人工缺数区间至确实跨过周安排；测试设计调整不涉及历史参数。

仍未声称解决所有问题：历史报价日期不是完整交易所日历；缺收盘价的账户估值仍拒绝计算，未自行补值；零金额旧卖出动作只在新诊断中解释；原数据和交易逻辑本身不因“输出没变”而获得有效性证明。其他异常情形只通过合成检查，真实732条日志全部属于次数上限取消。
