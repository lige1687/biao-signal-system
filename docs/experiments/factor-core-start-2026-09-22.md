## 3. 标准流程与每一步交付

1. **问题、定义和范围**：固定因子公式、单位、方向、研究哪些产品、观察多久、与谁比较，以及准备接受哪些代价。登记完整尝试史；已看过的历史不能重新包装成未见资料。
2. **数据与时间检查**：核价格、分红、交易日期、缺失和信息何时可知；只补该问题真正需要的资料。实际输入和代码留指纹。原始价格与调整后研究价格各司其职。
3. **单因子信息检验**：检查分数与之后表现的关系。IC指原始数值的相关性，Rank IC指名次的相关性；逐期保存对象数、并列和排除原因，并看分组表现与不同观察跨度。共同市场状态、二元趋势状态和风险指标采用各自合适的检验，不强行套排名相关。
4. **可靠性检查**：分时期、分产品，检查结果是否集中在少数行情；处理重叠观察期和反复尝试造成的偏差。需要拟合的步骤只用当时已经可得的资料；固定规则不伪造训练过程。允许结论是无增量或证据不足。
5. **策略与组合比较**：在同一资金、产品池、费用和成交约束下，从简单方法开始逐项加入趋势、风险组件。保留不加入该组件的参照，不能靠少投入资金就宣称预测更准。完整记录现金、份额、分红、费用、未成交与每日账户。
6. **判断与展示**：回答是否值得保留、依赖什么条件、付出了什么代价、什么反例会推翻判断。报告同时给出净收益、最大跌幅、恢复等待、换手和费用；不以计算测试通过替代有效性。

上述是执行顺序，不是已经跑完的成绩。每个实际批次还须在看新结果前固定目标端点、价格/收益口径、日历、费用、交易规则、资源预算和停止条件。普通动量先行；趋势与风险不与它一次性混算成一个新信号。此前高点位置方案的“多赢几年/跌幅差若干百分点”只是待审取舍，不能作为所有因子的统一通过标准。
