## 2. 得到什么研究判断

1. **20日主问题没有支持普遍增加双确认。** 双线对简单单线在多数产品上多赚，但没有同时满足相对两种单线及持有的减跌要求。不能只找一个弱对手来证明有用。
2. **60日双线只有中证1000这个局部候选。** 基础费用下，相对简单单线，扣费年化约多1.71个百分点、最大跌幅少5.39个百分点。初始10万元的期末金额多约8993元，同时累计费用多约204元；这组优势不能全解释成“少付手续费”。但仍不能据此证明未来有效。
3. **120日双线在这六只产品、两档费用下均比同周期简单单线少赚。** 是否值得牺牲收益要看少跌多少，而本组没有达到固定减跌要求。
4. **仓位影响必须保留。** 沪深300的20日双线，在较高费用下被固定半仓方案同时超过收益和最大跌幅。相近的平均持仓也不代表每天风险相同，因此不能直接把全部少跌归给第二条均线。

这些是对已有数据的解释，不是新市场证据；与现有研究的核心判断一致，不将重复读出结论计为新增因子发现。

**只给结果，不给研究进度，会产生重复工作建议。** GPT建议补中证1000的年度对照，但项目在9月27日已经做了年度利润拆分与时期依赖解释，见[已有研究报告](factor-ma-money-findings-2026-09-27.md)及其中年份依赖材料。它建议中的逐年恢复时间等更细字段不等于全部已经完成，但需要先核现有材料缺口，不能整批重做。

这是本轮刻意限制输入产生的局限，不能据此断言GPT无法读取或理解研究历史。实际研究任务的输入应同时包含：当前问题、冻结规则、已有成果和反例、尚未解决的问题、允许的下一步。

它还提出“任一完整年份同一单线同时多赚少跌，就停止推进普遍改善候选”的条件。这是新的建议，不是原冻结标准；不能直接回填到旧实验或据此淘汰局部候选。
