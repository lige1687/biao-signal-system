# Agent 本人事实与讨论意图统一

## 一句话结论（大白话）
这次把“听到一句话就猜成你的情况”改为保守记忆：朋友、假设、疑问和未来预算不能改掉你已声明的持仓与资金背景；本人明确更正仍能更新。回答、历史恢复与问题存档共用同一处理，避免撤销的预算又被旧快照带回来。概念解释也不再因为提到“回测”就进入补测流程。只改善可靠性，不代表收益或真实模型回答质量提高。

## 本次做法与用户能感受到的变化
- “朋友昨天操作了，已经清仓”：朋友的主语延续到后半句，不会抹掉你的持仓。
- “如果以后有钱，每月定投”：可以讨论这个情形，不记成你已有的资金用途。
- “我有五千预算？”／“我是不是有五千预算”：不覆盖原预算；“我下个月会有五千预算”不当作现在可用的五千。
- “朋友还持有，但我已清仓”：明确的本人更正生效；“不是一万，是五千”在已有预算时更新，没有已有预算时不凭空建立。
- “解释一下ATR止损回测是什么意思，不要求你执行”：正常进入讨论；明确要求采用或补测不支持的ATR退出方式仍给诚实提示。否定一个动作不会取消另一个明确动作。

策略归属为讨论解释层；道路、路牌、A/B/C/D触发、盈亏比与资金纪律不变，基本面与因子边界不变。用户2026-09-17“可以的，开干”授权主控设计并执行；没有重启旧ZCode第四轮。旧任务仍保留未接受结论。

## 实际限制与采用
这是有限、保守的中文规则，不承诺理解所有口语。无明确本人的独立“十万闲钱”等可以作本轮问题参数，但不会自动长期继承；需要明确“我有……”才能建立背景。会话记忆沿用现有最近消息读取范围，不是跨会话长期记忆。没有重新测真实模型质量，也没有本轮浏览器整页复拍；前端为共用函数测试与构建、后端为真实路由临时库验证。

本轮不修改运行目录、因子代码、模型配置、交易计划或成交库，不部署或重启服务。验收后按用户既有授权把开发分支集中合入本地main；运行目录有并行因子改动，实际采用仍须定向核对，不能用整目录覆盖。
