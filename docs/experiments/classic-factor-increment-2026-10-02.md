# 经典因子给LeiSignal增加了什么：比较基准、重复信息与同期解释（2026-10-02）

## 一句话结论（大白话）

经典因子目前最有用的地方，是给新想法一个简单比较对手，以及帮助解释ETF为何一起涨跌。本轮六ETF历史中，过去涨幅和波动一起加入旧双均线模型后，预测误差没有稳定改善，原模型本身也不如始终预测涨幅为0的简单参照；中国三因子把同期解释误差平方降低21.21%，但约85%的净改善来自科创50，不能据此说能提前判断行情或让完整LEI多赚钱。

## 现在知道什么

1. **有了可执行的研究参照，但没有13套已验证交易策略。** 既有13个对象是4个本地价格特征和9条官方月度组合收益。28条来源记录还包括模型说明、公式候选和未满足资料条件的对象。本轮首次补齐国内CH3的有限同期解释计算；完整库存见[逐项盘点](../archive/handoffs-plans/classic-factor-increment-2026-10-02/inventory.md)。该盘点保留计算前状态，本报告记录新增结果。
2. **部分经典名称与现有信息重合。** 当价格为正时，20日涨幅正负与SMA20当日升降方向相同，因为 `SMA20[t]-SMA20[t-1]=(C[t]-C[t-20])/20`。涨幅大小仍是不同表达，不能直接说它没有任何用途。T03已有过去20日涨幅和简单日涨幅波动；再加入完全相同的一列不会增加信息。另一些研究用对数涨幅和年化波动，必须核公式，不能混为同一因子。
3. **解释工具出现了有限帮助。** 市场因素已解释掉很多共同变化；加入规模和价值后整体误差继续下降。这里“规模”指小公司与大公司组合的收益差，“价值”指按盈利与价格关系划分的组合收益差。它们帮助辨别产品共同特征，尚不能衡量LEI交易能力。

## 现在不知道什么

- 未估计过去涨幅与波动各自独立的帮助；旧产物没有仅这两个特征的预测，故该组为未估计，不能填0。本轮比较是两者一起加入旧两个状态。
- 未比较完整LEI已有信息，更没有完整买卖、现金、分红到账、费用和资金占用。没有年化收益、最大跌幅或可交易的独特收益结论。
- 六只相关ETF和30个月不等于180份互相独立的新证据。它们共享市场，产品池事后固定，历史已经多次看过；正的整体范围不能证明其余五只ETF也稳定改善。
- 中国三因子使用当月完整因子收益，月初不知道。作者原始研究年代和股票板块不包括我们的科创50ETF；当前发布序列是否包含科创股票未独立核清，不能把两件事混为一谈。

CH3原文为Liu、Stambaugh、Yuan的中国规模与价值研究；本轮复核已保存正文的构造方法，核心包括剔除最小30%股票和使用盈利价格比。作者原始股票检验与本轮ETF月变化不是同一实验。原件与来源定位在[库存JSON](../archive/handoffs-plans/classic-factor-increment-2026-10-02/inventory.json)和[9月28日来源快照](raw/classic-benchmarks-2026-09-28/sources/snapshots.json)。没有重新构建股票组合、复制原文检验或使用事后股票因子作交易输入。

本轮选择线性同期解释，因为问题是这些共同特征能否解释已发生的ETF变化。先用2022—2023年每ETF24个月确定关系，固定不变后解释2024—2026年6月。每ETF设常数/市场/规模价值/三因子4种方法，参数数为1/2/3/4，共18次线性估计和6个均值；不扫参数、不换时期、不按结果筛ETF。这个方法不能回答因果或未来预测。没有事前有依据的最低有用幅度，故不事后设置通过线。

旧双20比较直接读取9月28日预测文件，0次重新估计。S与E是旧试点的具体状态，不是当前全部MA/EMA策略语义；两者加历史涨幅和波动的比较是本轮事后追加，不能改写旧报告或称当初预先提出。完整LEI采用MA预判、EMA确认等现行定义，旧状态名称不替代桌面权威源。
