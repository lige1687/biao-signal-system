## 一句话结论（大白话）

**两种研究方式都提供了有用的新细节，QuantaAlpha 的修订和融合组件也实际接通了，但这批没有证明它能比直接 GPT 多提供可靠信息。** 两组各提出并评价八个候选，合计十六个版本，在本批资料上实际对应十一种分组比较。新认识主要是“额外均线确认的作用依赖什么背景”和“哪些问题缺少公平对照”；继续融合条件并没有自动解决资料不足，部分候选只是同一比较的另一面。

## 2. 先说明数字是什么意思

A 的 X 是已有事件中的“SMA20向上”；M 的 X 是 S60，即价格在60日简单均线上、且该线向上。E20/E120分别表示20/120日指数均线满足相应条件；S20/S120为简单均线。候选只是按这些背景分组研究，未被采用为交易过滤条件。

两题均沿用观察日之后 **t+1收盘至t+21收盘、20个交易间隔**的经济价格标签。A 主指标是 X 成立组减不成立组的上涨比例；M 主指标是两组平均涨幅差，单位均为百分点。它们不是账户利润。

在同一 ETF、同一均线周期（A）或同一年（M）内作比较，A 两边至少各2条、M 各10条有效观察才纳入。辅助检查分别给予每轮趋势相同总权重、或沿原日历选取互不重叠窗口。后一检查每边至少2条。门槛在看本轮结果前固定；这些日数不是独立证据数量。

“背景差异”要求背景成立与不成立时，**相同的ETF/周期或ETF/年份，两边都有可比较的X正反观察**。不同资料覆盖下的两项汇总不能直接相减。以下“不足”表示无法按预定方式比较，不等于作用为零。

## 3. 真正增加了什么认识

### 3.1 回调类型：继续细分，先遇到的是反例不足

重复触碰的53次机会中，52次 X 已成立，只有1次不成立。于是这批资料无法公平回答“重复触碰时再要求 SMA20向上有没有帮助”。

首次触碰、底部构造来源及二者结合，在各自部分资料内可算出0、20、0个百分点的上涨比例差；但分别只覆盖10、13、5次可比机会，且没有足够的共同分组来比较类型强弱。底部构造的20个百分点在每轮趋势总权重相同时变为10个百分点，也不足以选它作为更好的类型。

**改变研究取舍：暂停在这95次事件内继续叠加类型条件。下一份资料应先检查每种类型有没有足够的X正反机会。** 两组最后都提出“重复触碰且来自底部构造”；其无法比较已能从父资料推出，不计为新的市场发现。

### 3.2 60日确认：短期背景提供了进一步区分，但并非统一有利

直接 GPT 提出的“S20已确认会削弱S60信息”受到本批主比较反驳：在两种背景都可比较的7组ETF年份中，S20成立背景的额外S60信息比另一背景高 **4.31个百分点**，覆盖1193条加总观察，主要集中于2025年。

QuantaAlpha 组预期“E20尚未确认时，额外S60确认的信息更弱”，主比较与这一预期同向：4组共同ETF年份中，该背景的差异低 **3.09个百分点**，覆盖734条加总观察。条件侧互不重叠检查只剩4条可比观察，方向与条件侧主比较不同，不能据此称预期已稳健成立。

这两项把以前“整体负差”的认识进一步定位到短期状态。**它们支持继续区分背景，尚不支持某个新增确认条件稳定有效。** 辅助检查的覆盖不同，不能用变号或两侧差值来宣称稳健。

### 3.3 修订和融合：有局部新事实，也有重复和无法比较

直接 GPT 的“E20成立、S20不成立”组合，在创业板与中证1000的2025年共同资料中，背景差异为 **−5.19个百分点**，加总覆盖364条；不能扩大到其他年份。

QuantaAlpha 融合出的“E120成立、S120不成立”，在中证500与中证1000的2022年共同资料中，背景差异为 **+3.10个百分点**，加总覆盖183条；条件侧的互不重叠窗口检查没有合格分组。这反驳了该候选原先偏弱的预期，仍只是局部历史事实。

长期S120的两种背景各自有不少可比日期，却没有同时合格的共同ETF年份。**总日期多，不代表足以判断背景的影响。** 继续加条件也可能把比较资料耗尽：直接组最后的“S20与S120均未确认”已有251个观察日，却没有合格的主比较。

## 5. 对 QuantaAlpha 的实际判断

十六个版本在本批资料上合并为十一种分组比较：两组共有五种，各自独有三种。“独有比较”不自动等于“独有有效因子”。两种方式都产出反证和资料缺口，均有局部新事实，当前没有充分理由宣布哪种方式更强。

**可复用的能力：** 原生修订、融合提示能接收本地真实反馈，并产生可追踪的后续候选；四次真实回答都经过原生解析，再由同一本地程序评价。

**下一步值得补的能力：** 本轮协议固定要求完成修订和融合，所以实际产物仍包含父资料已经能推出的不可比情况；互补条件也形成了新版本。这里没有检验框架能否自主提前停止，不能把继续生成全归因于软件。候选进入评价前应先检查“是否只是已有比较的另一面”和“是否还有足够的正反机会”。这比单纯加大生成数量更值得优先做。

本地接入有实际人工成本：传输过程曾因保存时改变字段顺序而使原提示核对失败，修复后逐字确认提示未变，再复用原真实回答；没有新增模型候选。首次工程检查产生的三个字节码缓存已精确恢复。未取得完整文本单位和费用数据，也没有无人值守的完整原生运行，因此不宣称已经省钱或省工。
