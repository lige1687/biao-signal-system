# 原生20日黑绿风险线索：证据不足到底卡在哪里？

## 一句话结论（大白话）

**两条风险线索仍值得保留；上一轮“无法估计”同时来自稀少分歧和过细的联合要求，不能作为因子无用的证据。** 在已可比的资料里，绿色30日过程下跌平均少0.59个百分点、黑色10日平均多0.38个百分点；删除单个连续分歧时段，能够计算的总体方向都保留。但不同ETF有反例，很多小组只有1—3个对照日期，仍不足以认定可靠风险增量。

本轮限定问题是“当前风险对照为什么无法估计、点值是否被单段撑起”，不是宣告整个双均线研究完成。保持20日、六ETF、原生定义和此前两条探索线索；2023—2026上半年都是已研究历史。

## 3. 我们现在知道什么

- 绿色43个可比小组中16组只有1—3个分歧日期，黑色51组中也有16组如此。细分背景后，对照过少是真实问题。
- 原估计要求六ETF全部小组同时存在，属于苛刻的联合条件，不能把其失败率等同于全部数据无信息。
- 改用每年内部保持连续日期的抽样，绿色可计算次数由2提高至21/2000，黑色由18提高至68/2000，仍远低于原约定的90%；没有以选较好的方法宣布通过。
- 删除一个连续分歧时段，在所有可计算检查中，两条总体点估计方向都没有翻转。不是由一个时段独力撑起，但联合删多个时段、改变市场背景的结果未验证。
- 两条线索各有两只ETF给出相反或近零方向，不能说对每只ETF都有用。

## 4. 我们现在不知道什么

- 在资料连续性和多个ETF相关性得到合理处理后，两条条件差值的可靠范围有多宽；本设计没有给出答案。
- 少数日期的背景小组是否能代表未来相同场景，不能从已可比66%/82%推广到其他日期。
- 新资料能否重复，以及将信号用于仓位或退出是否有价值；未检验。

## 7. 下一步的明确问题

P0：为稀疏背景对照选择一个能处理资料相关性、且不要求每次抽样所有小组都完整的方法。判断标准是能否得到解释清楚、可复核的估计，而不是把区间改到正向。任何方法变更必须保留旧版、事先固定、同时报告覆盖和敏感性；不得自动删小组或调阈值。

P1：只有P0能合理衡量风险差值，再按同定义收集未参与选择的新日期，观察是否补足分歧。新资料不足时不冒充验证完成。

本轮已实际完成两种日期设计对照和影响度检查。下一步是新的有限方法研究，不继续循环旧失败估计；当前诊断问题已回答，风险因子的最终有效性没有回答。
