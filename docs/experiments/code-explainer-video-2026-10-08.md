# 代码科普视频：四条教程学习、趋势流派短片与skill · 2026-10-08

## 一句话结论（大白话）

这类视频的效果来自具体分镜、清晰素材、能解释知识的动作，以及与声音共用的时间表。框架负责生成画面，skill负责组织工作，模型仍需做设计。已取得四条教程的完整本地转写并检查抽帧，将方法整理成项目skill；新片按用户最新要求讲道氏思想、利弗莫尔、唐奇安、海龟实验与今天的分支，暂停真实行情案例和旁白。主观观感仍待用户验收；没有得到原作者可安装的skill，也没有确认原片BGM名称。

## 本轮问题与授权变化

用户先要求学习Winhao六步科普教程，多看相关教学视频，并可以沉淀skill。随后补充乔同学原理视频，并明确“不要做真实案例了，就讲趋势交易的流派发展就行，包括利弗莫尔”。因此已停止ETF案例小样计划，改做60秒历史科普。上一版实际成片保留，只补磁盘满时缺失的验收与额度记录。

这不是交易收益实验，不改策略、规则、账户或系统计算。无旁白，无声音平台接入、付费、发布、删除或仓外配置变更。
