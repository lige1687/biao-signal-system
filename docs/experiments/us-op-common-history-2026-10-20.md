# 美股经营盈利：历史名单、财报时点及相邻动量选择的实际增量

资料与计算日期：2026-10-20（Asia/Shanghai）。研究期2015-01—2024-12。Luna执行，主控定义问题并独立核数，Astra审阅会计含义与科学结论。本轮已完成固定的历史诊断；完整市场、账户和ETF用途分别保留边界。

## 一句话结论（大白话）

**在历史标普500成员中、能核清这项财务口径的42家公司上，经营盈利尚未证明能让“动量排序相邻”的选择多赚或更抗跌；它使目标名单变动较少，但这种便利是否胜过简单保留持仓，还没有证明。** 实际比较覆盖十年120个月、1,967条公司月份、953对选择；相对每对动量较高者，月均可核差额仅+0.026个百分点，估计范围跨过零。保留财务资料与名单稳定性线索，暂缓把本次指标用于逐月收益或防守强化。

## 1. 本轮具体回答什么

问题是：当价格趋势已经提供一层排序后，年度经营盈利是否还能改善选择对象、减少亏损、保留上涨机会或减少操作负担？三个方法在同一日期、同一合格股票集合、同一配对和相同目标权重下比较，只改变每对选哪只股票。

金融理由：公司经营所产生的盈利相对股东投入，可能包含价格趋势尚未反映的经营信息。竞争解释包括行业和资本结构、小额账面权益、一次性利润、回购、好盈利已经被市场计价，以及资料差错造成的假效果。我们没有做行业中性化，也不能把剩余差额直接归为独有预测能力。

本轮是**独立的年度财务研究**。没有把基本面加入LEI技术信号或硬过滤；另一对话的季度EPS、原LEI因子实现、低换手/前向服务、宽度仓位与ETF工作保持其原负责人。

## 3. 财务指标是什么，以及为什么资格损失这么多

准确对象：`research.fundamental.annual_operating_profitability_after_da@1.0.0`，名称为**扣折旧及利息后的经营盈利相对普通权益**。

计算为：**（合并经营利润－单独列示的经营外利息费用）÷含少数股东权益的永久普通权益**。要求同一年度申报、同一期间、合并美元口径；分母为正，有明确的优先股总额为零，并用资产、负债、权益及少数股东权益的关系核对。缺失不填零。经营利润中已扣除的研发不重复扣除。

这保留折旧摊销成本，**不是French当前口径的严格复现**；也没有剔除原报表中的全部一次性项目或权益法收益，因此不能叫纯现金盈利或纯经常性利润。French方法更新涉及少数股东权益、费用及折旧口径；其公开组合只作为研究动机。[French方法说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)

| 资料处理阶段 | 实际留下什么 |
| --- | ---: |
| 年度申报候选 | 8,247份 |
| 第一轮金额、展示位置和权益结构检查 | 293份通过；这仍不是最终财务含义许可 |

| 最终准入 | 1,967条、42家、185份报告；4条后续结果未知仍保留 |

**第一轮字段检查曾误放净利息和混合财务费用，已经纠正。** 首次效果运行在输入检查处停止，尚未连接任何后续收益。随后逐份核对实际同一利润表上的展示行：排除12份净额/混合项目；保留13份仅扣除资本化利息的当期费用，以及5份明确独立列示的债务利息。原始文件、失败代码、合同和日志全部保留，未为跑通而扩大定义。[逐报告裁决](raw/us-op-common-history-2026-10-20/interest-line-adjudication.json)

覆盖窄主要卡在权益与费用能否准确解释。8,247份申报中，5,903份未通过本轮严格资产负债权益关系检查，5,308份不能证明所要求的优先股总额为零，4,102份未找到符合要求的利息结构；原因会重叠。这里很多情况是没有采用本轮限定字段或表达形式，**不能据此说这些公司的财报有错**。所有原因见[资格覆盖记录](raw/us-op-common-history-2026-10-20/qualification-coverage-gap.json)。当前最大缺口是扩大可核、相容的财务表达类别，而非继续叠加价格公式。

## 4. 同动量问题实际检验到哪一步

每月按动量排序，把相邻两只组成一对；每对分别选经营盈利较高、动量较高、动量较低者。奇数月份按看结果前固定的日历规则省去一只，61条省略记录保留；并列值按固定代码顺序或动量规则处理，后续结果不参与配对。

**这里只做到排序相邻，尚未做到数值严格相近。** 953对的11个月动量差中位数3.78个百分点，90%分位14.75，95%分位26.09，最大110.47。个别配对差距很大；结果不应称为控制了相同动量后的独立作用。没有看结果后删除“大距离”配对来美化结论。

盈利选择在953对中有475次不同于较高动量者。另加入较低动量者，是检查差异是否只是偏向较低价格动量就能得到；不能只挑有利的一个对手。

## 6. 相对已有信息的实际增量

本表在**完整120个月**逐月计算能确定的配对差额，再平均。两者选同一股票时，即使该股结果未知，差额仍恒为零；各自是否亏损仍未知。不同股票必须双方结果都可核才计算。对两个对手各有2对差额未知；因此这里是可确定部分，不能冒充完整池的真实平均收益。

## 7. 退出、价格与未完成证据

最终保留未知的4条：EMC／2016-09、St. Jude Medical／2017-01、Varian／2017-01及2021-04。其中EMC、St. Jude和2021年的Varian属于退出事件，其现金、换股、股息权利与目标月价值还未完整定价；2017年Varian是分拆调整。它们仍在当时形成集合中，不按未来是否存活筛选，不填零，不沿用最后报价。

已经取得EMC的Dell官方并购条款、St. Jude完成公告、Varian宣布与完成公告；HAR现金收购资料也保留，但该公司最终因原财务含义不合格退出共同池，**不是根据其后续收益剔除**。知道现金价格或换股比例还不等于重建了全部持有人权利。[Dell原始申报](https://investors.delltechnologies.com/sec-filings/all-sec-filings/content/0001571996-16-000021/delltechnologiesq3fy1710q.htm)、[Abbott完成公告](https://abbott.mediaroom.com/2017-01-04-Abbott-Completes-the-Acquisition-of-St-Jude-Medical)、[Varian完成公告](https://www.siemens-healthineers.com/press/releases/varian-closing)

此前两套价格源的616,628个重叠日变化中查到18个超过1个百分点的差异，原因包括代码复用造成的错误分红、分拆与分红调整约定。这18个事件与本次会计候选没有期间交集；另行审查的人工调整依赖则使90条原候选动量窗口不准入。原因可以重叠，不能把不同检查数相加为独立问题数。

原件保留，但当前价格是公开来源的后来历史重建；没有全面证明每项公司行动及每个当日可成交情况。行业、杠杆、小账面权益、财务披露类别和特定公司的依赖仍未充分拆开。这里只看下一月，不代表年度持有、入场退出、仓位控制或ETF使用价值。

## 8. 结论、取舍与下一步条件

| 用途 | 本轮取舍 | 依据和代价 |
| --- | --- | --- |
| 提高逐月选股收益 | 暂缓本次规则作为增强条件 | 对较高动量的差额很小且不确定，对较低动量也未证明胜出；新增财报维护成本 |
| 减少亏损、改善尾部 | 暂缓本次规则作为防守条件 | 没有胜过较高动量；相对较低动量少亏线索伴随更多少赚，方向仍不确定 |

| 财务解释与研究输入 | 保留 | 形成可定位的原始年度版本、身份、权益、利息语义和未知退出记录；资料质量价值与赚钱价值分开 |
