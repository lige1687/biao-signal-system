## 大白话（先说结论）

**判定（预注册三选一）：证据不足（费率敏感带内）。** 既够不上"值得进一步验证"，也够不上"维持判负"——这个结论本身这次是**收口的**，理由如下。

上一轮复核（Y 报告债务三）留下的问题是：把同一套规则、同一段修平后的数据，按"每次调仓收多少手续费"这两个不同假设各算一遍，结论的正负号居然会翻——按 1bp（约等于只收最低佣金）算，三个时间段全部小胜持有不动；按 10bp（佣金加点差的保守上限）算，前半段就变成小输。也就是说，之前的判断不是被证据左右的，是被一个**手续费假设**左右的。

本次的做法：不再猜两个点，而是把手续费从 0 到 15bp（万分之一到千分之1.5）每隔一档算一遍，画出完整曲线，再算出"打平费率"——费率高于它策略就输给持有不动，低于它就赢。结果：

- **全期（13 年）打平费率 ≈ 14.4bp**：高于 10bp 这个现实保守上限——意味着在**任何实际能做得到的费率下，全期都不输**给持有不动。这一头可以收口：全期口径下"判负"不成立。
- **但前半段（2013-2019）打平费率 ≈ 2.8bp**：正好落在现实费率带（约 1-10bp）**正中间**。佣金谈得下来（≤2.8bp）就小赢，谈不下来就小输。这段的结论被费率假设左右的状态**没有被消除，而是被精确定位了**：它就是一条悬在零线上、随费率翻转的敏感带。
- 按 5bp（现实带偏保守的代表值）算：全期 +1.05pp、前半 **-0.26pp**、后半 +2.38pp——预注册的"值得进一步验证"要求三个时段全正且全期至少 +1pp，前半段那 -0.26pp 卡住了，不达标；"维持判负"要求全期在任何现实费率下都输，也不成立。所以落进预注册的中间档。

**为什么费率对它这么致命**：这套规则在 510500 上平均每年要做约 20 次调仓、年化单边换手约 10.3 倍，每多收 1bp 手续费，年化超额就被吃掉约 0.11 个百分点。前半段费率敏感度还更高（约 0.117pp/bp）。

**对用户实际意味着什么**：中证500 维持现状（不在执行清单内），但归档理由可以更精确了——不是"跑不赢基准"，而是"全期在任何现实费率下都不输，但优势薄到完全被前半段 2013-2015 疯牛拖进费率敏感带"。前半段最拖后腿的是 2014 年（单年落后约 24pp），和 Y 报告滚动窗结论（两个负窗都在 2013-2015 起点）互相印证。这不构成"该不该进池"的建议——本报告只呈现费率曲线和判定。

技术名词速查：
- **bp（基点）**：万分之一。1bp = 0.01%。下文"单边费率"指每成交一次按成交金额收的比率。
- **修平**：把缓存里两处假跳变（2015-04-15、2022-08-29）从跳变日起把后面所有价格同除跳变比抹平，这是审计定的"下界"修法，不是正确复权。
- **三窗 / 三档 / 30/70**：全期、前半、后半各算一次，要求方向一致；三档=按"宽度"指标把仓位分成三档，宽度 30/70 为档位边界；逆势=宽度越极端越减仓。
- **超额**：策略年化收益减去同期"买入持有不动"年化收益，单位 pp（百分点）。
- **打平费率（盈亏平衡费率）**：使超额恰好等于 0 的单边费率。

## 1. 预注册判定框架（跑前写死，全文照录脚本 docstring 要点）

- **复用**：import Y 的 `run_pollution_recheck_csi500.py`（修平法、宽度对齐 cn_all、第十四轮 BASE：ladder/b200/3bands/fixed/30-70/contrarian/gamma1/min_trade0.05、无闸、行数中点三窗、target 全历史热启动），唯一改动 `fee_bps` 由写死 10.0 参数化。不调参、不换规则。
- **费率网格**：{0, 0.5, 1, 2, 5, 10, 15} bp 单边。
- **现实费率带论证**：510500 场内，主流券商 ETF 佣金约 0.5-2.5bp（免五后），价格约 6-7 元、1 tick≈0.15bp、半点差约 1bp、小资金冲击忽略保守计 1-3bp → 现实区间约 **1-10bp**；1bp=最乐观可实现（最低佣金+零点差），10bp=保守上限，5bp=现实上限代表值；0bp 仅理论下界，15bp 超带披露用。
- **盈亏平衡方法**：三窗各自对 excess(fee)=0 二分法数值求根，区间 [0,60]bp、容差 0.01bp；单调性（excess 随 fee 递减）用网格数值验证，非线性费用复利效应由数值法自然涵盖。
- **判定线（三选一）**：
  - 「值得进一步验证」：fee=5bp 三窗全正 且 全窗超额 ≥ +1.0pp。门槛依据：Y 明示"打平不等于值得入选，翻案门槛要明显高于打平"，+1.0pp 为最小有意义幅度（10bp 口径全窗 +0.5pp 只算打平噪声带）。
  - 「维持判负」：全窗打平费率 < 1bp（任何现实费率下全窗皆负）；或 1bp 口径全窗 ≤0 且任一半窗 ≤ -2pp。
  - 「证据不足（费率敏感带内）」：其余中间情形；或实现校验未过。
  - 最高只判「值得进一步验证」，不下入选结论。
- **实现校验**：fee=10bp 修平·无闸三窗须复现 Y 归档 +0.0049/-0.0084/+0.0185（±0.001）——**通过**（本次算得 +0.49%/-0.84%/+1.85%）。

## 3. 附加稳健性（不影响主判定，如实呈现）

**换手与费率敏感度**（全窗，fee=0 口径的成交记录）：
- 13.0 年共 262 次调仓（年均约 20 次），累计单边换手 134.0 倍，**年化单边换手 ≈ 10.3 倍**；
- 费率敏感斜率（fee=0 与 fee=10 两点差分）：全窗 **≈0.112pp/bp**、前半 ≈0.117pp/bp——每 1bp 费率吃掉约 0.11 个百分点年化超额，与"年化换手 × 1bp"的量纲直觉一致（10.3 × 1bp ≈ 0.103pp，复利效应略放大）。后半换手低、敏感度低，故其打平费率高达 27.6bp。

**拖后腿窗与单年主导**（全窗运行的逐年超额，前半≈2013-2019）：
- 前半最拖后腿年份：**2014（-23.9pp @1bp / -25.5pp @10bp）**，其次 2015（-13.5pp）——前半窗的负号几乎由 2013-2015 疯牛段主导，与 Y 报告"两个负滚动窗都在 2013-2015 起点"互相印证；
- 后半的负年份是 2025（-22.3pp @1bp）与 2021（-1.3pp）、2026 年初（-4.0pp），但后半总量被 2019/2020/2022/2024 的正年份盖过；
- 费率口径差异（同一年 1bp vs 10bp）约 1-2pp/年，量级远小于年份本身正负——**年份结构主导，费率决定的是前半段在零线附近的翻转**。

## 4. 判定

**证据不足（费率敏感带内）**——预注册三条线核对：
- 「值得进一步验证」：fee=5bp 前半 -0.26% ≤ 0 → **不满足**（全窗 +1.05% 达到 +1pp 线，但三窗全正被前半卡死）；
- 「维持判负」：全窗打平费率 14.37bp ≥ 1bp，且 1bp 口径全窗 +1.49% > 0 → **不触发**；
- 落入预注册中间档。实现校验通过，判定有效。

收口的实质：全期口径"判负不成立"这一头已经钉死（打平费率在现实带外上方）；剩余的不确定性被精确定位为**前半窗打平费率 2.82bp 落在现实带内**——前半段的正负取决于实际能拿到多低的佣金+点差，这不是继续调参能解决的事，与 Y 报告"最有信息量的新证据是等非牛市场景或正确复权数据"的结论一致。

## 6. 局限（如实声明）

1. 修平法是"无断裂下界"，非正确复权（审计 §7 欠账原样有效）；打平费率是在修平数据上定义的，若未来换正确复权数据需整条曲线重算。
2. 现实费率带 1-10bp 是跑前论证写死的静态区间，未建模大资金冲击成本随时间的变化；510500 流动性在 2013 年远差于现在，早年实际点差可能高于带内假设——这会进一步压低前半段表现，方向上不利于翻案。
3. 费率只按单边线性计费（引擎口径），未含滑点不对称、折溢价套利成本等；引擎中基准也扣一次买入费，与策略同口径（对结论影响 <0.1bp 量级）。
4. 本判定只收口"费率敏感性"这一个维度；Y 报告的另两条不达标（邻域正占比 56%<2/3、邻域中位 ≈0）不在本任务范围，但翻案时须一并满足，故本报告任何档位都不构成入池结论。
