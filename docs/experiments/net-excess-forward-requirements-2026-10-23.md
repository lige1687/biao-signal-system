# 净超额收益、前向市场状态与股票池资格核查（2026-10-23）

## 一句话结论（大白话）

收益要看扣除个人交易费用后，相对对应指数或事先指定的被动投资多赚多少；股票池也要随着金融解释一起定义。这两条和“只用当时资料判断市场状态”已补入研究指引与用户要求的持久记忆。美股参考页已把个人净超额明确改为未评价，原公开毛收益仍可展开。现有反转样本不是中证1000，不能证明小盘反转更强；新的前向实际效果尚未测出。存储本轮先失败、后来实测已恢复，当前缺口是资料时点、历史成员与个人费用，不能再把旧空间不足当作理由。

## 1. 本轮到底回答什么

本轮检查三个相连的问题：当前曲线有没有回答“比适合的简单投资多获得什么”；市场状态能否在行动前知道；股票池是否支持因子的金融解释。复用既有报告、输入和另一负责人的历史成员资格工作，不重跑原反转、French组合、RankIC或账户结果。研究服务个人月度选择与参与判断，不更改生产交易规则。

原French范围为美国公开股票组合：价值、经营盈利、动量，大小规模分开；1963-07—2014-12为较早背景、2015-01—2024-12为主要比较期、2025-01—2026-08为补充。它们全是已看历史。原A股300/600样本是2014年末历史名单中的固定抽样，不是沪深300或中证1000的逐时成分。股票、指数、ETF及个人可执行账户四种对象不互相代替。

## 2. 收益怎样才算比较清楚

默认同时展示策略扣费后累计收益、对应基准及两者差额；有两种不同比较：

- 策略扣费后减同期间市场总回报指数，叫“策略扣费后相对指数的超额”。指数是参考，不能声称可直接买入或已扣相同账户费用。
- 策略与可交易ETF/被动持有账户，都按各自买卖扣适用费用，叫“相对被动投资的净超额”。起始资金、币种、持有区间、分红、现金及期末是否卖出一起固定。

逐月差额是策略该月净收益减基准该月收益。累计收益差是两条从同日起算的累计收益相减，单位是百分点；相对财富是同起点累计财富之比减1。逐月差额直接连乘不能代表账户。

个人费用按实际模拟买卖金额、方向与适用费表计算；最低佣金、税费、汇兑若适用也计入，价差和滑点分别披露。缺费表或成交/换手，写未评价，不能每月随意扣一个常数。旧A股单边0.25%属于研究假设，不能叫个人实际费用。

French的B只是每月给低、中、高三组各分三分之一资金，不是母指数。公开月收益没有本人的逐次成交、换手和费用资料，不能仅改标题或扣固定月费“恢复净收益”。本轮只修正展示资格，旧数字、分红处理、数据JSON、PNG和原封存结果保持原样。

| 必须给出的性能 | 当前状态 | 具体原因 |
|---|---|---|
| 个人扣费后收益及风险 | 未评价 | 无个人费表、成交金额/换手及完整执行资料 |
| 相对对应母指数/被动账户的净超额 | 未评价 | 尚未绑定适用基准，个人成本也不齐 |
| 已有公开低中高组毛收益曲线 | 可作历史参考 | 原结果可核，不能代替前两项 |

| 相对简单办法的增量 | 当前判断 | 下一项真正会改变判断的证据 |
|---|---|---|
| 盈利/动量组合优于对应被动投资 | 未确认 | 同期适用基准、净成交成本与共同支持 |
| 加市场状态减少损失且不过多漏涨 | 未评价 | 当时可用的状态、下一可执行行动与完整资金路径 |
| 小盘反转强于大盘且优于低波动 | 未确认 | 逐时成分/历史市值、流动性对照及各池扣费比较 |

## 3. 股票池须和金融解释一起定义

“散户交易或暂时价格压力，使部分价格变化随后回归”值得检验；“小盘股必然散户多、定价效率低，所以反转一定强”尚不是我们的结论。规模、流动性、行业、价格限制和成本可能共同变化；只在难成交股票中出现的毛收益还可能消失于价差和换手。

中证官方2023年12月V1.1编制方案说明，中证1000在中证800以外选规模偏小、流动性较好的股票，还设置成交额过滤和定期/临时调整。它不等于全部小盘、微盘或最不活跃股票；本轮取得的是该版规则，不宣称它是所有历史阶段或最新版本。[中证1000编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/20231208175402-000852_Index_Methodology_cn.pdf)

大股票也不能预先判“没有反转”。Da、Liu、Schaumburg的美国研究，将过去收益中与基本面消息相关的部分分开后，在较大且较活跃的股票中仍找到反转；这是一种不同的反转定义，不能拿来证明A股原始上月收益取负的因子在大盘或小盘必然有效。已选读其摘要、引言、定义和异质性部分，没有复现全篇。文中部分收益解释用全期平均风险溢价，也不能照搬为本轮前向输入。[作者论文](https://econen.sufe.edu.cn/_upload/article/files/d3/34/c6aa75294353b29e32728df8b04e/01c74230-970a-454a-8483-265efa7c6ba1.pdf)

本地证据的范围是：

| 要核什么 | 现有资料/结果 | 仍缺什么 |
|---|---|---|
| 中证1000与大盘反转差异 | 未找到对应当期成员的反转实测；固定300/600不能代替 | 生效与公布日期完整的历史成员、退出链 |
| 大小市值差异 | 原300行情缺历史股本/市值 | 形成日前历史市值；不可用今日市值倒填 |
| 是否只是低波动帮助 | 同池反转对低波动已有比较，未证明稳定胜出 | 规模/流动性/行业下的可比增量 |
| 是否只是流动性或难成交 | 历史成交额可复用，已有执行限制 | 形成日前窗口的流动性匹配、价差/换手及成交敏感性 |
| 散户或定价效率机制 | 当前仅为机制假设 | 可用历史持有/交易者或事件资料；没有则只说相关差异 |

复用[反转方法检验](reversal-method-replication-2026-10-21.md)：按过去月收益取负计算的排序相关仍有正关联，但未控制规模、行业与换手；沪深相对低波动的收益比较不一致，误差范围含零。[环境/股票池审查](factor-universe-regime-audit-2026-10-22.md#7-能否进一步扩大股票池)已核字段缺口。不能用这些结果确认中证1000优势。

后续有界主问题固定为：**同一上月反转定义、同一形成/持有日期、相同权重与成本，在逐时中证1000和沪深300各自相对其对应基准有没有帮助；相近流动性时是否仍然存在。** 中证500可作中间层，不因加入它就搜索所有组合。各池分别给排序关系、分组顺序、净超额、风险、少赚机会、未知权重和换手，不用跨池平均盖住差异。名单公布与实际生效分开，后来退出者保留；看结果后更换池记追加探索。当前没有新建这些指数成分账户。

## 4. 前向市场状态：固定方法，不用后来走势命名

先固定10个月均线这一种主方法：完成月末收盘价高于截至当月的10个连续月末均价，记偏强；低于或相等记偏弱。缺资料记未知。它是可观察的长期趋势状态，不能当“未来一定是牛熊”的预测；三态时钟仅为未测试候选，后验峰谷不进入本次行动。

时间顺序必须是：实际月末收盘完成 → 所需版本已发布且本研究已取得 → 作判断 → 下一实际可交易开盘才行动。晚取得的旧资料不能将可用时间回填成原发布日期。真实新观察需保存当时原件/指纹、判断和动作，不事后用修订版重写。已有历史分期仍叫历史复核。

[本轮设计附件](raw/net-excess-forward-requirements-2026-10-23/forward-contract.json)固定了主方法、被动持有对手及收益/风险/现金/换手/错过上涨的指标。它是设计附件，**不是已登记适配器或已获准运行的原生统计合同**。基准、成本及输入资格尚未齐；不能拿本附件绕过现有研究入口。

12个人造案例已通过可用时间筛选、后来数据追加、后来版本修订、缺月、相等、未知、非法价格和冲突版本检查。这只证明传入字段满足假设时，该小函数不读后续记录；没有证明字段真实、每月准确交易收盘、供应商历史版本或下一开盘成交。审查发现并明确了这几个能力边界，没有把它报作真实前向效果。

## ARCHIVE 与最小决策卡

本轮持久化、展示纠正与资料资格审查完成；科学效果为证据不足，归档判定mixed，前向实测仍受输入/成本资格阻塞。保留“在合格不同规模池内复验反转”和“SMA10固定前向状态”两个待验证用途，不采用自动切换，不宣布中证1000反转有效。

唯一接续先核原负责人的历史成分与退出资格成果，复用合格资料；把对应基准、实际成本、形成月末、版本可得时间和下一执行时点补齐到原生合同，再启动有边界的真实比较。若只能取得当前回溯版本，则明确降为历史模拟用途，不能补造严格前向认证。任何来源、费用或执行假设变化须保留选择历史；不重开封存结果或重置旧研究预算。
