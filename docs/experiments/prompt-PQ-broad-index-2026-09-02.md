## 背景

（最主要的是**行业权重结构**——标普科技权重明显低于纳指，纳指集中在科技），

# Prompt Q：少数纯宽基 vs 现有8指数行业分散篮子——对现有假设的复核

你在 `biao-signal-system` 仓库工作（当前分支 `recovery/lei-round2`）。只读研究
任务，**不改 `src/` 下任何生产代码，不 push，不删任何现有文件**。

## 背景：这不是加新标的，是复核一个可能被误读的现有结论

`docs/timing-sweep/execution_playbook_20260827.md`"第十九轮补充"一节的
"8 sleeve 等权"实验，构成是：**创业板/证券/新能车/白酒/有色/银行/通信/沪深300**
——仔细看，这里只有沪深300一个是真正的宽基指数，其余7个全部是行业/主题指数。
该实验的假设是"篮子稀释单标的特异性风险"，用行业分散来降低波动，共同窗口
（2015-06→2026-08）+12.2%/-36%，认证等级很高（三窗一致+分段复核）。

**该报告自己在结论第1条指出一个重要警告**："全窗的冠军组合跑输是组成效应"——
早期只有沪深300这一个sleeve存活，沪深300自己的宽度择时超额是**负的**（-3.4%，
跑输持有）。这意味着现有8指数篮子的良好表现，很大程度依赖后期7个行业指数
陆续"上线"分散风险，而不是"宽基本身"的贡献。

本任务要验证的假设：**如果只用少数几个流动性最好、覆盖年限最长的纯宽基指数
（创业板+沪深300+纳指+标普）做equal weight，而不引入7个行业指数，效果相对
现有8指数篮子是更好还是更差**——这不是要否定现有8指数篮子的结论，是搞清楚
"行业分散"这个机制本身对结果的贡献有多大，一个复核性质的对照实验。

## 任务

1. 构建新篮子：创业板 + 沪深300 + 纳指 + 标普500，四个纯宽基指数equal weight
   （每个25%权重），用与8指数篮子完全相同的宽度择时框架（同一套三档宽度信号
   判断买不买）套用在每个sleeve上，组合日收益=存活sleeve等权平均（逐字复用
   "第十九轮补充"的口径定义）。
2. **在同一个共同窗口下对比**：8指数篮子的共同窗口是2015-06→2026-08（8个
   sleeve全存续起点），四指数篮子的共同窗口需要重新确定（纳指/标普历史更长，
   瓶颈应该是创业板或沪深300的起点，需要查证并在报告里写清楚具体日期）。
   如果两个共同窗口不一致，必须同时报告"各自共同窗口"和"强制对齐到较短窗口"
   两个版本的数字，不能只挑一个说事。
3. 判定标准先写死：不是简单比年化/回撤谁大，需要拆解**组成效应**——参照
   execution_playbook的诚实做法，把"早期只有部分sleeve存活"这个偏差在四指数
   版本里也检查一遍（虽然只有4个sleeve，仍然可能存在启动时间不同步的问题）。
4. 双跑哈希核对（PYTHONHASHSEED=0/42）。
5. 至少一个阴性对照：如果条件允许，测一下"只用创业板+沪深300两个A股宽基"
   （不含美股）作为对照组，帮助区分"美股腿的贡献"和"减少行业数量本身的贡献"
   两个不同的效应来源。

## 输出

`docs/experiments/broad-index-basket-compare-ARCHIVE-2026-09-XX.md`，格式对齐
现有ARCHIVE。

冲突发现一节必须明确回答：
1. 本任务结果是否推翻或修正"8 sleeve篮子稀释单标的风险"这个原始假设——如果
   四指数篮子表现更好，说明"减少到宽基"可能比"分散到行业"更有效；如果更差，
   说明现有8指数篮子的行业分散确实有增量，不是组成效应的错觉。两种结果都要
   如实报告，不要预设倾向。
2. 与Prompt P（标普替代纳指）如果同时产出，两者数据是否可以互相复用（Prompt P
   的"标普持有"腿数据和本任务的"标普sleeve"数据理论上应该是同一份，检查口径
   是否一致，避免重复计算却产生不一致的数字）。

## 明确不做

- 不产生"哪个篮子应该采纳"的最终建议——这是资产配置层面的决策，需要用户看
