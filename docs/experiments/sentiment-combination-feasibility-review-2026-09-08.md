# 情绪条件与既有进入方法：能否研究新增价值

日期：2026-09-08。任务07；可行性审计，mixed。没有新跑收益筛选。

## 一句话结论（大白话）

现有“四次冰点验证”的脚本实际只检查了简化条件，不能证明完整四条件都成立，更不能据此推导完整买卖有优势。先补齐当时的数据与准确日期，再判断它是否给既有方法带来不同的机会；本轮没有为寻找好结果再开参数搜索。

## 与现有系统的关系

服务于市场环境的独立分组研究和叙事说明。情绪、基本面及消息不变成道路方向、技术入场放行或硬过滤条件。宽度是某类价格条件成立的股票占比；原完整冰点定义包括全市场“三票偏冷”、板块60日下跌、散户资金异常和短期宽度低于30%，其各项历史数据必须在当时可得。

## 旧研究实际做了什么

冻结的icepoint脚本用4个指定时间窗口表示冰点环境，再检查板块60日跌幅不高于-10%、散户资金强度绝对异常达到阈值。它没有逐日重建完整四条件；板块价格使用所取成分的平均值，还需核对历史成分。完整来源见[source-manifest](raw/research-unified-2026-09-08/other-lines/source-manifest.json)及icepoint-study.py。

| 旧窗口 | 起止日期 | 当前可以支持的描述 |
|---|---|---|
| 2022-A | 2022-03-01—06-15 | 指定窗口内简化条件观察 |
| 2022-B | 2022-09-15—11-15 | 同上 |
| 2026-A | 2026-03-20—04-30 | 同上 |
| 2026-B | 2026-07-10—08-04 | 同上 |

未来15日收盘价变化，是触发后的价格观察；没有完整退出、现金、成本、占资拒绝和未完成持仓，不是实际交易胜率。现有账本的4/4说法应收窄为其原研究覆盖的简化条件观察，不能借给完整四条件或技术信号组合。

## 本轮做了什么可重复核查

先固定[只比较日期与状态的方案](raw/research-unified-2026-09-08/other-lines/overlap-protocol.json)，将4个旧窗口分别与E01的8个对象、深超跌/底部区域2种状态对照，共64行。没有计算后续收益，没有把指数状态冒充板块信号，没有把窗口里同时出现状态叫做完整四条件的交集。

## 旧失败研究必须保留

源项目《overnight-gate2-increment-2026-09-03》已考察2021-06-16至2026-09-02的1185天。在把A股开盘跳空因素一并考虑后，没有给出美国隔夜信息的新增正面支持，原裁定为证据不足，细分后有效格子很少。[冻结旧结论](raw/research-unified-2026-09-08/other-lines/overnight-prior.md)。不能原样重启广义“美股预示A股”研究，再换几个阈值找赢家；也不能由这项不足宣称所有行业对应关系都不可能有用。

## 唯一保留的候选问题与停止条件

若能取得完整四条件当时可用的日度记录，下一次只问：**在已有深超跌或底部区域进入机会中，完整冰点条件是否提供额外分组信息？** 对同一进入机会分别记录四条件成立、不成立、未知；未知不补成不成立。先统计重叠日期、独有日期、完整持有区间重叠及缺失来源，再决定是否有足够独立信息值得做完整资金对照。

这是研究候选，不是新硬过滤。收益实验尚未固定也未执行；需要的数据包括全市场三票历史、当时板块成分、资金流原始系列、宽度及发布时间。只要缺关键项，就停止组合有效性判断。即使数据齐全，也不得采用“20个日期就够”之类未经依据的门槛；共享一段行情的多对象需一起考虑。
