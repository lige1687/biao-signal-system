# 出场组归档摘要：a6_3 纯结构止损复活尝试——补止盈机制（2026-09-01）

> 任务来源：新方向探索 Prompt G（2026-09-01 拆分）。脚本：
> `scripts/run_exit_revival_a64.py`（判定标准预注册于 docstring）。raw：
> `raw/exit_revival_a64/`（结果 JSON + 环境重建复现清单 README）。

## 0. 一句话结论

**复活失败。** 给 a6_3 补独立止盈（ATR 倍数档 / 结构目标位档共 5 臂、
3 模块全测、预注册邻域全扫）确实把 a6_3 从「全灾难」（expR −1.30～−2.17、
PF≤0.02）止血到接近盈亏平衡乃至小幅转正（最优臂 A 模块 3×ATR：
expR +0.498 / PF 1.37），证明确有「止盈缺失」这一病灶；但**没有任何一臂
在任何模块达到预注册的「不劣于默认 a6_1」线**（J2 判定 0/3×5 臂全灭，
最优臂期望仅为 a6_1 的 42%）。机制诊断：a6_1 的优势来自「早断亏损
（均亏 −0.5～−1.8R）+ 放足盈利（A 模块均盈 +7.9R）」的非对称结构，
固定止盈只能恢复胜率、同时截断右尾，亏损侧却仍按结构止损全跑满——
补一个止盈救不了这台缺两个零件的机器。归档为证伪清单第二轮。

## 一、机制假设：这次为什么不同（Prompt G 开工条款）

原 prompt 要求先写清「这次为什么不同」再跑。本实验的两个具体假设：

1. **H1（部件补全假设）**：exit-matrix 报告对 a6_3 的诊断是「缺止盈机制，
   盈利单全部回吐到初始止损位才离场（PF≈0）」。若诊断成立，保留 a6_3
   止损 + 补一条独立止盈（a6_4），应能把回吐的盈利单截住，PF 从 ≈0 恢复
   到 >1，expR 转正——「补全已诊断出的缺陷部件，不是重跑已判负配置」。
2. **H2（可恢复性假设）**：恢复到「不劣于默认 a6_1（抵扣价出场）」即算
   复活成功，判定结构止损思路在系统里是否有位置。

**事后逐一回答**：H1 **部分成立**——止血确实发生（PF 0.02→1.37@A最优臂，
胜率 2%→40-51%），止盈确实是缺失部件；H2 **不成立**——离 a6_1 还有整整个
数量级的期望差距，且诊断书只写了半个病名：a6_3 不止缺止盈，还缺
「早断亏损」（详见第五节证伪清单机制行与第七节数据）。

## 五、证伪清单（新增）

| 实验 | 假设 | 关键参数 | 证伪证据 | 验证强度 |
|---|---|---|---|---|

**机制层证伪（为什么补止盈救不回来）**——三模块分解数据（standard 档）：

| 模块 | a6_1 均盈/均亏 | a6_4 最优臂均盈/均亏 | a6_1 持仓 | a6_4 持仓 |
|---|---|---|---|---|
| A | +7.90R / −1.75R | +4.63R / −2.28R（ATR3） | 16.6 根 | 11.6 根 |
| B | +2.94R / −0.93R | +1.71R / −1.68R（ATR3） | 17.3 根 | 16.4 根 |
| C | +1.46R / −0.49R | +1.21R / −1.28R（ATR3） | 16.9 根 | 23.6 根 |

（均盈/均亏/持仓为 standard 档全量已平仓口径，取各模块 expR 最优臂。）
a6_1 的期望来自两端：盈利端不封顶（A 模块均盈 7.9R）、亏损端早断
（B/C 模块均亏仅 −0.9R/−0.5R——C 模块 224 笔里只有 2 笔真正走到结构
止损，抵扣价条件在结构位触发前就把弱势单清掉了）。a6_4 只补了盈利端，
且是「封顶式」的补法：A 模块均盈 7.90→4.63R，而亏损端恶化
（−1.75→−2.28R，无早断、还有跳空穿越）。**「早断亏损」这半个零件
止盈规则补不上，它的功能在 a6_1 里由抵扣价条件兼任。**

## 六、通过清单

**无。** 没有任何臂在任何模块过 J2。

## 七、观察中

- **A 模块 ATR 族的「止血幅度」本身值得记录**：a6_3 −2.174 → a6_4a/ATR3
  +0.498，恢复量 2.67R。它与 a6_2（顶构造+关键波，+1.302）在 A 模块
  同向（都让利润比 a6_1 拿得久/稳），但幅度差一个量级。若未来有人想
  做「结构止损 + 止盈 + 早断亏损」三件套，a6_4a 的止盈部件数据可复用。
- **ATR 档对目标档的一致优势**：5 臂里 ATR 档全面优于结构目标档
  （B 目标档全模块最差）。解释：目标价 B 本身是「纸面赔率」输入
  （rr 过滤用），不是出场位设计；到 B 即走等于把入场过滤器参数误用为
  出场参数。此观察与规格第 10 节 B 的定位一致，不构成新发现，仅记录。
- **止盈触发率与退化笔**：A 模块 ATR3 臂 1469 笔中 TP 触发 576 笔、
  结构止损 893 笔——即使 3×ATR 这么宽的止盈，仍有 61% 的单先触止损；
  B 缺失退化笔（纯 a6_3 行为）A 模块 83/1521（5.4%）。

## 八、下一步方向（≤3）

1. **不建议再做「纯补件」路线的 a6_3 复活**。若仍想测结构止损思路，
   唯一没试过的组合是「结构止损 + ATR 止盈 + 抵扣价式早断」三件套，
   但第三件一加就趋近于重造 a6_1——预期增量极小，性价比存疑，需用户
   拍板才开。
2. **环境欠账（移交汇总方）**：stash `a816485f`（v2 检测器 + rules.v2.yaml）
   是当前主树跑不了 8-31 口径回测的直接原因。若要保留工作台历史 run 的
   可复现性，需把该 stash 的 v2 状态合入分支或至少归档账本；否则
   8-31 及之前所有走 overrides 的 run 在主树均不可复现（本报告的重建
   配方在 raw/exit_revival_a64/README.md）。
3. 本报告不产生任何「应切换默认出场」的建议；a6_1 默认地位反而获得
   一侧新证据（任何固定止盈都劣于它）。

## 九、冲突发现

1. **与 heiti-ARCHIVE「右尾长持单」结论同向复现（非新发现）**：合体组
   发现卫星腿 41+ 天长持单占总利润 164%；本实验在出场层独立复现同一
   规律——A 模块均盈 7.9R 靠不封顶的右尾，3×ATR 封顶后均盈掉到 4.63R，
   期望只剩 42%。**封顶式止盈与右尾驱动结构相克**，这是同一枚硬币在
   入场层（砍信号=砍右尾）和出场层（封盈利=截右尾）的两次显现。
2. **与 exit-matrix 原报告诊断的半冲突**：原报告称 a6_3 失败是「缺止盈
   机制」。本轮证明该诊断不完整：补止盈后仍远离 a6_1，缺失部件还有
   「早断亏损」（a6_1 的抵扣价条件兼任）。建议汇总方在引用 8-31 报告
   「解读」第 3 条时附带本修正。
3. **与 b3 双条件判负的机制分野**（澄清，非冲突）：b3 败于「出场滞后
   （多重确认）」，a6_4 败于「出场过早（封顶）+ 亏损端无早断」——
   出场侧现在两端都试过了，中间地带只剩 a6_1/a6_2 一族。

## 十、局限（解读必读）

- 全样本单段口径、无 IS/OOS 切分（与 8-31 矩阵同限；本轮主结论是
  维持默认的阴性结论，过拟合风险低，但 A 模块 ATR 族的「止血」幅度
  若要引用需注明未做样本外确认）。
- 止盈执行采用「收盘确认、次日开盘」的保守口径，未测盘中触价即走
  （限价单口径）；盘中口径会略抬高 TP 臂成交价，但按 a6_4 与 a6_1 的
  差距量级（0.68R@A 最优臂），不认为能翻转 J2 判定——此为推断，
  未验证。
- a6_4b 的 B 缺失退化笔分布不均（A 5.4% / B 1.8% / C 0），三模块间
  目标档的可比性略弱于 ATR 档。
- 判定线（J2 严格无容差）为事前预注册；即使放 5% 容差，0/15 的格局
  不变（最强臂差距 58%）。
