# Jev 系统库存新闻30条验证

## 一句话结论（大白话）

Jev在系统真实新闻中表现出不错的理解能力：21条有结果的新闻里19条符合事先标签，而且没有把未来预测误说成已经发生；但免费Playground有9条不返回结果，完成率只有70%，当前既不能当稳定服务，也不能据这批陈旧且未经第二人复核的新闻直接开发接入。

## 为什么继续测

上一轮8条人工筛选的真实新闻摘要中，Jev有7条符合预设。用户回复“可以啊”，同意继续从系统实际新闻中抽更大一批。本轮不再挑适合模型的案例，而是从系统新闻库按固定办法抽30条。

本研究仍只服务于消息叙事层：区分新闻是在说已发生、预期、条件、评论还是多种内容并存。它不参与双均线道路、路牌、A/B/C/D触发、失效位、盈亏比或无交易纪律。

## 新闻库先暴露了一个问题

系统 `news_items` 表共有321条，但最新发布时间是2026-09-05；验证当天是2026-09-22。也就是说，这是真实库存新闻，却已经停更约17天。本轮可以评价文字理解，不能代表当前新闻流，也不能证明现有新闻链路健康。

这个发现与Jev能力是两件事：模型分类得好，不会自动解决新闻没有更新的问题。

## 抽样和标签

排除B站长字幕后，对东方财富、新浪和Google News三种来源分别按固定种子生成的哈希排序，各取标题不重复的前10条，共30条。原始数据库行、选择哈希与来源链接保存在 `docs/experiments/raw/jev-system-news-30-2026-09-22/source_snapshot.json`。

有摘要时把原摘要送入Playground，没有摘要时使用原标题；不改写、不翻译、不补背景。中文20条、英文标题10条。预设标签和理由在首次提交前冻结，见 `labels.json` 和 `input-manifest.json`。

标签只由当前Codex制定，没有第二位人工独立复核。因此下文只能说“符合预设标签”，不能把比例包装成真实准确率。样本中也没有资料不足类，类别覆盖并不完整。

| 页面提交 | 30条，每条一次，无重试 |
| 返回可见结果 | 21条 |
| 页面无结果 | 9条 |
| 可读结果中符合预设 | 19/21，约90.5% |

| 精确模型版本、用量、账单 | 页面未提供 |

按来源看：东方财富返回9/10，其中8条符合预设；新浪返回7/10，7条都符合；Google News英文标题返回5/10，其中4条符合。英文看起来没有明显理解崩溃，但只返回一半，无法区分语言差异与免费页面后半段不稳定。

页面无结果时没有显示明确错误、额度提示或拒绝，浏览器错误日志也为空。本轮只能记录“结果缺失，原因未知”；不能擅自断言一定是限流。缺失在后半段增多，生产可靠性风险已经足够明确。

## 两个分歧

1. Solidigm融资传闻加公司“尚未确定”的澄清，预设为“传闻预测＋事实澄清”的混合内容；Jev只判为预测，概率79%，混合16%。它漏掉了澄清作为独立内容。
2. “就业报告可能影响美联储利率决定”的英文标题，预设为条件关系；Jev判为预测，概率50%，条件45%。这是接近五五开的边界分歧，标签本身也需要第二人复核。

其余可读结果中，市场价格、已经发布的政策、评论、未来预测、明确的if条件和多句混合内容均符合预设。

## 与简单规则的比较

上一轮冻结的简单关键词规则不作任何补词，在30条中只符合3条；对Jev有结果的同21条也只符合3条。原因很直接：真实快讯常用“若、据悉、必须、当前报价”等大量不同表达，旧小规则没有覆盖，英文标题则几乎全部落到“资料不足”。

这个差距说明语义模型比那套小规则更适合处理开放表达，但小规则只是本实验的简陋对照，不是生产新闻模型。因此不能据19比3宣称Jev已经超越生产系统。

## 决定

结论比前两轮更清楚：Jev的语义判断能力值得保留，尤其没有出现最危险的“把预测当成已发生”；速度也够快。但免费Playground的70%完成率不具备接入条件，且库存新闻停更、标签未独立复核、样本类别失衡。

当前决定仍是“不接入生产”。若继续，顺序应为：

1. 先查清系统新闻为何停在9月5日；
2. 由用户或另一位人工只复核本轮30条标签，不给其看Jev答案；
3. 取得稳定API后复测相同冻结样本，单独计算服务成功率；
4. 三项都通过后，再设计只读的影子运行，不改变排序、推送和交易判断。

## 证据和复现边界

原始库存快照、标签、协议、输入指纹、逐条结果和输出指纹都在 `docs/experiments/raw/jev-system-news-30-2026-09-22/`。逐条概率与耗时是从当前任务的Playground可见页面人工转录，不是供应商原始响应。没有重试缺失项，没有付费、充值、安装依赖或修改生产代码。

## 最小决策卡

- 测什么：系统实际库存新闻，而非人工编写句子。
- 得到什么：有结果时19/21符合预设，预测误作事实为0；但9/30没有结果。
- 用户意义：模型理解有潜力，免费网页不稳定，当前接入会造成新闻随机漏标。
- 下一步：先修新闻停更和独立复核标签，再谈稳定API与影子运行。
