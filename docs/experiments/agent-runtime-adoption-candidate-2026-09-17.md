# Agent 运行采用候选：隔离整合与采用包验证（S2）

## 一句话结论（大白话）

把上一阶段审出的 24 个文件改动，在一个隔离副本里装成了完整候选：先把运行系统里没提交的在制工作（基金成交防重复记账、因子工具、页面样式）原样保存为基线，再叠上已验收的 agent 改进（提问失败可重试、断开不丢答案、别人/假设的话不再被记成你的事、名称板块语义修正、每问省约 12 秒计算）。全部相关后端测试 301 项通过、前端构建与 6 个确定性回归通过、真实服务冒烟可用；唯一失败的 1 项测试经在基线上复跑证实是改动前就有的老问题，按要求不修。做好的"一键采用/一键回退"包在另一份副本上实测四幕：能装上、任何一个文件变了就拒装且一个字节都不提前写、能完整退回、采用后再被人改过的文件回退时会拒绝碰它。**这仍是候选，未上线**：真实大模型的回答质量没有测过（全程用桩和无模型模式），浏览器整页检查因本会话浏览器不可用未做；最后是否采用由主控决定。

## 3. 采用包与演练（G3）

包位置：`docs/experiments/raw/agent-runtime-adoption-candidate-2026-09-17/adoption-package/`
- `manifest.tsv`：24 行，逐项 `before_sha256`（=2026-09-17 11:44 运行实态捕获，**不是运行 HEAD 提交**，含当时未提交层）/`after_sha256`（候选）；
- `after/`：24 个候选文件；`before/`：14 个被替换文件的运行实态原样捕获（回退依据）；
- `apply.sh`：全目标预校验（14 个 replace 逐字节等于 before + 10 个 add 不存在）→ 任一不符拒绝且**零写入**；写入走 .tmp+内容校验+原子改名；
- `revert.sh`：先校验所有目标仍==after 才回退——采用后被人改过的文件一律拒绝碰。

**四幕演练**（/private/tmp 独立副本，与真实工作区同构，演练后清理；日志在 raw/rehearsal/）：

3. 回退：14 个逐字节恢复 before、10 个精确删除；
4. 采用后追加本地改动再回退：拒绝，改动原样保留。

**采用/回退操作**（供主控）：在运行工作区根目录执行 `sh <包路径>/apply.sh`（或 `revert.sh`）；脚本从任意位置调用均可。应用前如遇 PRECHECK-FAIL，说明运行目录已再漂移，按冻结任务书处理，不要强行覆盖。
