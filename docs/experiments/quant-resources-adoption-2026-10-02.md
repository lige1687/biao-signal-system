## 一句话结论（大白话）

可以接入，而且已经补了一个能实际调用的项目技能：复用 statsmodels 的数值核心，检查平均差额有多不稳定；借用 exchange_calendars 的2026年上交所休市清单，并与官方通知核对。27项检查通过。更大的因子分析、智能研究和学术资源继续按具体问题使用已有评估；本轮没有证明提高收益或减少开发时间。

## 本次实际交付

新增 `.agents/skills/lei-quant-tools/`，可明确调用 `$lei-quant-tools`。

### 1. 平均差额误差计算

直接复用 statsmodels 0.15.0 的 `weights_bartlett` 和 `S_hac_simple` 原函数，
只改变模块包装。完整BSD许可与版权通知保留。
适配程序负责完整日期、有限数字、明确单位和观察频率，以及显式的相邻间隔数。
运行使用项目已有 NumPy 2.1.1，没有新增依赖；没有安装完整 statsmodels。

“误差”在这里是给定平均差额受波动和相邻日期联系影响的不稳定程度，
不是策略有效的概率。多个ETF须先按本轮固定口径汇总为每日期一条资料；
声明的日历仍须经过已有资格检查，程序不能验证调用者有没有漏报整个日期。
已经看过资料、反复挑方案及过短序列的问题也不会被这两个函数自动解决。

真实调用入口：

```bash
python3 .agents/skills/lei-quant-tools/scripts/quant_tools.py mean-hac INPUT.json
```

### 2. 上交所2026年度日期核对

从 exchange_calendars 4.13.2 源文件提取19个非周末休市日期，
与[上交所2026年度通知](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)
的七组日期逐日比较。快照与Apache-2.0许可保留。
输出年度安排中的 `scheduled_open` / `scheduled_closed`，超出2026年返回未知。

通知发布日期为2025年12月22日，日内发布及供应商到达时刻未知。
这是年度计划核对，不证明后来没有临时调整、单个产品能够成交，
也不是整个日历库或其他交易所的验收。已有官方日历没有被替换。

```bash
python3 .agents/skills/lei-quant-tools/scripts/quant_tools.py xshg-date 2026-10-02
```

## 小型验证与相对参照

一批固定模拟核验，共27项，包含实际程序调用与完整年度日期比较。
未测真实市场表现，不以这些数字替代因子收益表。

| 检查对象 | 简单参照 | 借用组件后的结果 | 判断 |
|---|---:|---:|---|
| 六条正负值各连续三条，平均值0，相邻间隔数2 | 按日期互不相关算误差0.408248 | 误差0.527046 | 此例中的联系让误差增大 |
| 六条值正负交替，平均值0，相邻间隔数2 | 按日期互不相关算误差0.408248 | 误差0.235702 | 此例中的联系让误差减小，不能一律说普通方法低估 |
| 2026年只排除周末 | 261个工作日 | 年度安排242个开市日 | 多识别19个工作日休市；全年365日期均与年度通知对应 |
| 缺一个原计划日期、重复日期、缺值或无限值 | 简单删行会改变相邻关系 | 实际拒绝 | 不自动填补或压缩时间轴 |
| 固定相同数值 | 所算误差为0 | 保留“不能证明现实确定性”的提示 | 不给现实研究下确定结论 |
| 2027年查询 | 未核资料 | 返回未知 | 不回退为普通工作日 |

独立算术：第一组残差平方和6、一期间隔乘积和3、两期间隔乘积和0，
加权后平均值方差为10/36；第二组对应为6、−5、4，方差为2/36。
没有调用借用函数产生这些期望值。
逐函数语法树比较确认两段原函数未改；实际命令行输出保存到原始证据目录。
