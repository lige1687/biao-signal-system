# 08：AI解释与退出的两份未来验证方案

## 一句话结论（大白话）

已经把“解释是否清楚可靠”和“退出是否实际有帮助”拆成两份能逐项记录的方案；目前没有新的AI投资成绩。解释方案可以先核事实和理解，退出方案还需确定你最重视少回吐还是少卖早，以及愿意为此付出多大代价。

服务层：技术规则的解释与持有退出研究。模型不改变道路、路牌、触发条件和失效位，不接实盘。前一轮发现历史缓存缺完整输入及版本，因此130条旧动作不作为未来有效性的证据。

## A：解释价值

问题：同一份已知材料，加上AI解释，能否减少误读并帮助用户找出下一步观察条件？

对照：A0为规则事实表及固定文字解释；A1为同一事实表加AI解释。两者展示同一时点、同一材料，模型不能得到A0没有的未来价格。先建立固定练习材料，再按预先安排的顺序展示；参与者若只一人，分不同材料分次看，记录熟悉效应，不能推广成普遍用户研究。

评分在看模型回答前写好答案依据。每份材料均检查：阶段、路牌、触发条件、失效位是否忠于原规则；能否说出还缺什么信息；MACD是否被误说成买卖点。逐项记正确、错误、不确定，并记录理解耗时、用户信心和引用能否打开。回答流畅、篇幅长或用户喜欢不等于事实正确。

记录所有生成失败、拒答、缺引用和重试，不从多次回答中挑最好的一次。来源、规则版本及引用错误由独立检查者对照原文核实，不能只让生成答案的同一模型给自己打分。用户理解结果由用户的实际回答产生，研究AI不代填。

验收：任何新增虚构来源、提前使用未来材料、擅改规则，都使该版本的正确性要求未满足；保留错误个案。零错误的有限观察只说明这批材料未发现错误，不证明永不出错。理解提升与耗时分别报告，尚未预设“提升多少才值得常用”。

## B：退出价值

固定三组：B0按原冻结退出规则；B1采用冻结AI版本的持有、减半、退出或无法判断建议；B2使用事先写明的简单机械退出条件。B2必须在结果前选择，不能从历史最优条件挑选后当公平基准。B2具体规则与费用预算目前仍待冻结。

三组同时获得相同日期、相同金额的外部入金；卖出的现金一直计入账户。起始资金、持仓、费用、成交延迟、再进入规则、分红和份额变动处理完全一致。不能因为某组退出就停止给它存款，不能把“少投本金”算成风险降低。

每次判断先封存输入、生成时间、模型及提示词版本、完整原回答，再等下一次确实能成交的价格；缺价格则保留待执行状态。看过之后行情再生成的答案只能用于解释研究。重复调用每次都登记，版本改变后另立观察批次。

每组报告期末现金加持仓价值、费用、排除新增存款影响后的最深下跌、离历史高点的最长时间，以及卖后继续涨或跌的结果。这里的“排除新增存款”是把存钱带来的账户增长拿掉，单看投资本身涨跌。卖后观察固定20、60个可交易日，不随结果改窗口；这是描述性附表，主评价仍是持续完整账户。

若主要目的为减少盈利回吐，主评价是完整账户的投资下跌是否减轻，同时列出少赚多少钱；若主要目的为保留趋势，主评价是期末总财富，同时列出多承受多少下跌；若只需解释，则B暂不启动。这三个选择不能在结果出来后轮流挑一个宣布成功。

同一次行情中多个建议、多个基金同时触发，按共同事件归组；不能把每日提醒当成几十次独立成功。连续账户是主记录，事件表解释差异来源，不把它们混成一个成功率。

## 观察量与启动条件

不凭空规定“做满30次就通过”。先确定最小值得改善的幅度、可接受的收益或风险代价，再使用一批不参与正式评价的先导记录估计事件之间的差异大小，据此确定正式观察数量、终止日和中途查看安排。若独立事件太少，或推算所需事件在可用时间内不可获得，应明确判为证据不足，不能降低标准凑通过。

当前未确定的内容：用户主要偏好、最低值得改善幅度、可接受代价、B2规则、模型和费用上限、正式观察数量。因此本文件是可执行结构，**不是已经完全冻结并启动的未来投资试验**。已发偏好问题；未答部分保留为空，不代用户选择。

历史数据可用于账目程序检查，不能代替未来模型输入日志。正式观察需要真实发生的新材料和新行情；当前没有安排自动运行、没有付费调用、没有发交易建议。

## 每条记录的最低字段（供后续实现）

| 内容 | 要保留什么 |
|---|---|
| 身份 | 研究、事件、对象、对照组、版本、唯一记录号 |
| 信息时间 | 材料原始发布时间、取得时间、决策时间、最早允许成交时间及其时区 |
| 原材料 | 原文件位置与校验值、规则版本、数据缺口，不能只存摘要 |
| 模型 | 模型名称、完整提示词及校验值、设置、每次尝试、费用、完整原回答 |
| 结果 | 持有/减半/退出/无法判断/生成失败，理由与来源；不能只记成功动作 |
| 执行 | 待执行、成交、取消、截至日未成交及原因，成交价、费用、现金与持仓 |
| 评价 | 预先固定的事实答案、用户理解结果、完整资金结果、偏离方案说明 |

空白记录模板见 [JSON模板](raw/research-05-08-next-2026-09-08/08/record-template.json)。空值是尚未发生或尚未决定，不能显示成零错误或零费用。文件校验只能证明保存后没变，不能单独证明材料在过去某时刻已经可得。
