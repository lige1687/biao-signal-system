# 已投入资金指标独立复核协议

日期：2026-09-08。只读取两个已封存实验的8条R1路径，不运行新策略，不改旧结果。

协议中的单位资金曲线定义在数学上成立：每笔交易先除以该笔买入金额和买入费，结束后把净回报因子接到上一笔之后；空仓日保持不变。完整研究期年化保留等待机会的时间，累计持有日年化只描述持仓期间的收益速度，两者必须分开命名。账户收益除以平均投入比例没有这种数学含义，不能替代上述曲线。

独立计算从每账户的 `daily.csv`、`trades.csv`、`events.json` 和 `roundtrips.json` 出发。持仓日价值使用该笔当日份额乘有效收盘价，加该笔截至当日已经取得的分红权利；分红到账不重复增加。卖出日使用卖出金额减卖出费，加累计取得的分红权利。未结束交易在期末用收盘市值加累计分红，不虚构卖出费。

曲线在买入前保留上一值，并把该值作为新交易的起始高点，所以入场日收盘低于买入成本时会计入下降。卖出日不计为持仓日；入场日和持仓跨越的周末计入。逐笔最大下降也从买入时的1开始，以日线收盘和退出开盘净所得为观察点，不声称覆盖盘中极值。

核查8条路径的曲线末值、完整日期年化、累计持有日年化、连续最大下降、逐笔最大下降和年度变化；另配对同产品、同费用的R1与R1-risk1，核候选、买卖日期、买卖价和每笔单位投入净回报。若数量导致实际交易身份不同则列差异，不强行配对。
