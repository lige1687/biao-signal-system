# 手算小例记录（源码/数学审阅，非市场证据，非 Qlib 数值一致性测试）

日期：2026-09-13；2026-09-13 按主控审核同步修订（见主报告 §10）。
用 Python 标准库算术＋pandas 依赖行为核验（pandas 2.3.3）；未安装、未运行 Qlib。
对照输入：收盘价序列 C = [10, 11, 12, 13, 14]，取 t 为最末一根（含当日）。

**身份声明（F4 修订）：以下是通用 N=5（另加 N=2）教学小例，演示公式形状与换算关系；
不是 trend.distance50@1.0.0、mixed.rv20@1.0.0 等任何本地登记对象的执行结果或逐值对齐。
登记对象还要求对齐含当日规则、有效观察集合、预热、缺失处理、价格与公司行动口径，
仅有相同数量的行不保证这些条件都满足。**

## ROC（Qlib Alpha158: Ref($close,d)/$close）

- 输入：C，d=2。推导：Ref 即向前移 2 根 → C[t-2]=12；ROC2 = 12/14。
- 结果：0.8571428571428571。
- 语义：过去价/当前价，价格上涨时数值 <1，方向与涨幅相反；分母含当日。
- 与本地 mixed.momentum.raw@1.0.0（I(t-21)/I(t-252)-1，跳过最近 21 条；
  分子是 t-21 条处的经济价格指数，不是当前价）：
  公式方向相反（同一对端点下反向单调）、端点不同、含当日语义不同，不能等同；
  端点窗口不同，不宣称两者实际排序一定相反。

## MA（Qlib: Mean($close,d)/$close）

- 输入：C，d=5。SMA = 60/5 = 12；MA5 = 12/14 = 0.8571428571428571。
- 通用距离写法 D5 = P/SMA − 1 = 14/12 − 1 = 0.166666666666667
  （与 trend.distance50@1.0.0 同一公式形状，但此处 N=5 是教学值，非该对象执行结果）。
- 换算验证：1/(1+D5) = 1/1.166666… = 0.8571428571428571 = MA5。成立。
- 成立条件：同一 N、同一组合法价格观察、当前价与均值非零有限、均线含当日、
  同一价格与公司行动口径、满窗口。若 Qlib 用 min_periods=1 的部分窗口前段，
  或有效观察集合/预热/缺失处理/价格口径不同，则不成立。

## STD（Qlib: Std($close,d)/$close，pandas rolling.std 默认 ddof=1）

- 输入：C，d=5。价格水平样本标准差 = sqrt(((−2)²+(−1)²+0²+1²+2²)/4) = sqrt(2.5) ≈ 1.5811388300841898。
- STD5 = 1.5811…/14 ≈ 0.11293848786315641。
- 缺失行为（F1 修订，pandas 2.3.3 实际执行）：[10,NaN,12] 窗口 3、min_periods=1
  → std=√2≈1.4142135623730951，÷12≈0.11785113019775793（**不是**窗口有 NaN 就全缺失）；
  仅剩一个有效值 [10,NaN,NaN] → NaN；常数 [12,12,12] → 0。
  这是 pandas 依赖行为核验，没有运行 Qlib 表达式引擎。
- 本地 mixed.rv20@1.0.0 是收益率的样本标准差 ×√252（窗口 20）。
  用 C 的 4 个日收益（缩微小例）r=[0.100000, 0.090909, 0.083333, 0.076923]：
  样本 std ≈ 0.009945932426055933，×√252 ≈ 0.15788678253598387。
- 两者都消除了货币单位、以小数表达；差异在输入（价格水平 vs 收益）、统计含义
  （价格分散程度 vs 收益波动）、时间尺度处理（无年化 vs 年化）。不能互换。

## BETA（Qlib: Slope($close,d)/$close，Cython rolling_slope）

- 输入：C，d=5，自变量 x=[1,2,3,4,5]。x̄=3，Ȳ=12；
  Σ(x−x̄)(y−Ȳ)=10，Σ(x−x̄)²=10，slope = 1.0（每根涨 1）。
- BETA5 = 1/14 ≈ 0.07142857142857142（教学期望值，非 Cython 编译模块运行结果）。
- 边界：常数序列 slope=0 → BETA=0；窗口内仅剩 1 个非 NaN 点时
  源码分母 N·Σx²−(Σx)²=0、无显式保护（cdivision=True）——这是源码阅读发现的风险，
  具体 NaN/inf 输出未实测。
- 语义：价格对时间序号的回归斜率，与市场收益敏感度（CAPM 意义上的 beta）无关。
  本地登记表无对应对象。

## RANK（Qlib: Rank($close,d)，pandas rolling.rank(pct=True)，并列 average）

- 例1 [10,14,12,13,11]，当前值 11：小于 11 的 1 个，等于的 1 个 →
  (1+(1+1)/2)/5 = 2/5 = 0.4。
- 例2 并列 [10,11,11,13,11]，当前值 11：三个 11 并列名次的平均
  (2+3+4)/3=3 → 3/5 = 0.6（scipy percentileofscore kind='rank' 同值）。
- 例3 常数序列 [12]×5：平均名次 (1+…+5)/5=3 → 0.6（不缺失）。
- 上述三例已于 2026-09-13 用 pandas 2.3.3 的 rolling(5, min_periods=1).rank(pct=True)
  实际执行确认（0.4/0.6/0.6）；这不是 pandas/scipy 两条 Qlib 路径的兼容性测试。
- 与本地 mixed.rv_percentile@1.0.0（ties=average、含当前、除以非缺失数）：
  并列算法与含当日语义同族；但本地排名对象是 RV20、窗口 756、最少 252 条，
  Qlib RANK 排名对象是收盘价、窗口 5–60、min_periods=1。对象与窗口均不同。
- 与本地 mixed.momentum.rank@1.0.0：那是同日产品间横截面排序
  （ordered_symbol_list，精确相等后按代码升序），与 Qlib RANK 的
  单产品历史分位完全是两种东西。
