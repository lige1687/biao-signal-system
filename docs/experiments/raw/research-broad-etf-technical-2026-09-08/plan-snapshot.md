# 宽基与ETF主战场专项研究计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. 本文是研究总计划；各批代码实现及收益试验按对应冻结协议执行，不把未冻结阶段当成已可运行程序。

**Goal:** 回答宽基与行业ETF各适合怎样投资或交易，并验证论文方法能否改善完整资金结果。

**Architecture:** 保留原宽度投资、ETF长期投资与LEI技术交易三条研究线，按同产品、同资金、同日期比较。先用可追溯的旧结果建立参照，再扩产品与完整交易，最后只选少量论文候选；个股结果仅作方法参考。

**Tech Stack:** 本地Python研究副本、已有名义行情与公司行动、独立资金核算、Markdown/JSON报告及既有OKR；生产接口与UI不在本计划执行范围。

## 一句话结论（大白话）

现在把宽基和ETF列为后续研究主线，计划覆盖六只国内宽基ETF、四只行业ETF，黄金与海外ETF另作对照。首先推进宽度择时与持续持有的完整比较，再检验技术交易适用性和少量论文改进。旧研究继续作为起点；计划写好不等于新收益已经算完。

## 4. 阶段二：宽基ETF到底适合持有、宽度择时还是简单趋势

**问题：** 同一只ETF、同一份钱，宽度择时多带来什么，付出多少错过上涨和操作成本？

首批执行设计固定为510300与159915，各自独立账户。比较三个方法：

1. **持续持有：** 第一个允许的开盘买入，此后不因技术信号卖出，期末仍持有单列估值。
2. **既有宽度三档：** 43.3/56.7三档和5个百分点调整条件继承源版本；自然周结束后使用本周已知的最后宽度观察，随后可用开盘调整。与原九指数“下一共同日收盘”成交分开命名，不能说完全相同。
3. **简单60日报价区间突破：** 收盘高于此前60根最高收盘后进入，收盘低于此前60根最低收盘后退出，下一可用开盘执行；期间卖出资金保留现金，等新触发再进入。60根来自已有简单突破/退出基准，不借论文声称最优。它不附加LEI的目标筛选，否则不再是同一个简单参照。

首批只用一种明确研究资金：开始时每个账户有10万元，之后无外部追加；这是方便比较的金额，不是用户实际预算。三个方法都最多投入可用资金、不借款。名义价、100份整数买入、已知行动和停复牌约束沿已核资料；现金零息。买卖单边费用各0.1%，另完整保留0.2%情景，不把研究费率当实际渠道费率。

**首批上限12账户：2产品×3方法×2费用。** 主区间2015-01-01—2026-06-30；此前资料只作预热。首个可成交日及宽度空缺处理必须由冻结的数据资格表给出，不凭今天的日历猜测。缺宽度不新增调整动作并标资料未知，不能填零；已有持仓按原份额保留，不假装这是正常“保持档位”信号。

产品资料与资金实现核准后，在新目录保存运行配置、事件排序与缺价例再开跑，输出 `daily.csv / trades.csv / signals.json / rejected.json / summary.json`。完整月份、年份和危机区间只从这些路径汇总，不另选参数。首12账户已执行并独立核对，见 `docs/experiments/broad-etf-first12-account-comparison-2026-09-08.md`；尾部未完成周候选另有记录资格更正，不影响资金。生产或数据资格改变须留版本差异。
