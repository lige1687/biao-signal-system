# 美国 CFTC 股指期货分类持仓：数据资格核查

核对时间：2026-10-20（北京时间）。范围仅为 CFTC TFF 期货独立表中 CME E-mini S&P 500，合约代码 `13874A`。未计算收益、反向效果或选阈值。

## 一句话结论（大白话）

这条公开数据足以看今天能查到的单一标普股指期货分类持仓历史，但**不能把 2006 年起的整条序列当作当时每周已知的信息**。分类报告到 2010 年才开始发布，更早行由后来资料回填；停摆、网络事件和纠错还改变了部分周的实际可用日。若要评估交易时能否使用，必须逐周核实际公布日和当时版本；本轮只完成资料资格，不证明因子有效。

## 下载与字段

- 官方数据集：[TFF - Futures Only](https://publicreporting.cftc.gov/w/gpe5-46if/default)，通过该数据集的过滤 CSV API 取得。原样返回的 318,128 字节 CSV 在外盘 `source-manifest.json` 所列路径，SHA-256 为 `7e58691af996974cc7620a09523aceef6e1b0ddc0e1e2c9a443202b8406d2f1e`。它是 2026-10-20 下载时的当前版本快照，不是每周首发版本档案。
- 选取代码 `13874A`，字段含报告日期、周序、合约代码和名称、总未平仓量、交易商、资产管理人/机构、杠杆基金、其他可报告交易者的多/空/跨期对冲头寸，以及可报告和未报告总量。资产管理人与杠杆基金保持分列。单位是**期货合约张数**，不是美元、市值或股票持股比例；`futures only` 不含期权。
- 原始数据 1,062 行，报告日 2006-06-13 至 2026-10-13，每个报告日与 ID 各唯一；1,048 个星期二、13 个星期一、1 个星期三，按日期差没有超过 8 天的空档。所核七个核心数值列均无空值、负值，总未平仓量均大于零。合约名称有两个写法，代码始终相同。
- 最新行 2026-10-13：总未平仓 1,931,607 张；资产管理人多头 1,110,384、空头 194,549、跨期对冲 96,043；杠杆基金多头 121,404、空头 530,130、跨期对冲 46,956。示例净头寸分别为 915,835 和 -408,726 张；除以当周总未平仓量分别约 47.41% 和 -21.16%。这是字段计算核对，不是市场信号。跨期对冲不再加进多减空；CFTC 解释它是相互抵消的头寸。[TFF 解释说明](https://www.cftc.gov/idc/groups/public/@commitmentsoftraders/documents/file/tfmexplanatorynotes.pdf)
- 每行核对了 `(四类单向多头之和 + 四类跨期对冲之和) = 可报告多头`、相同的空头等式，以及 `可报告头寸 + 未报告头寸 = 总未平仓量`，1,062 行均为精确相等。接口聚合查询独立返回同样的 1,062 行和首末日期；首行数值与官方数据集网页可见行相符。

## 何时能知道，何处不能倒填

- CFTC 的通常安排是周二收盘资料、同周周五美国东部时间 15:30 公布；节假日可延迟。**报告日期只是持仓快照日，不是公开日**。[CFTC 常见问题](https://www.cftc.gov/es/node/128971)、[公布日程](https://www.cftc.gov/MarketReports/CommitmentsofTraders/ReleaseSchedule/index.htm)
- TFF 报告在 2010-07-22 宣布开始发布；CFTC 于 2010-12-03 才公开“回溯到 2006 年 6 月”的历史资料。[启动公告](https://www.cftc.gov/PressRoom/PressReleases/5857-10)、[历史特别公告](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalSpecialAnnouncements/index.htm)。CSV 中截至 2010-07-13 的 214 行不可能在当周取得 TFF 分类数据。2010-07-20 快照可能赶上首次发布，不能仅凭公告确认；从该周至 2010-11-30 共 20 行处于报告已开办、历史包尚未发布的过渡期，也不能仅凭现存 API 判断每行首发内容是否与今版相同。
- 官方解释明确：2006 年起的回填期没有保留当年的交易者分类历史，使用较近期的分类倒推，越往前准确性越弱。[TFF 解释说明，第 3 页](https://www.cftc.gov/idc/groups/public/@commitmentsoftraders/documents/file/tfmexplanatorynotes.pdf)。这使早期数据既有**公布时间**问题，也有**历史类别含义**问题。
- 官方称不提供完整历史逐周公布日列表；网页只保留近期约 13 个月的日期。因此，不可将每周机械标为报告日后三天 15:30，也不可把今版 API 的修改时间倒填成逐周原始版本时间。[CFTC 常见问题](https://www.cftc.gov/es/node/128971)。当前接口响应 `Last-Modified: Fri, 16 Oct 2026 19:30:08 GMT`，与 2026-10-13 行的当周预定公布时间接近，但它只证明本次接口版本的响应时间信息，不能证明所有旧行首次发布时间。
- 已核公告例外：2013 年停摆，原拟 2013-10-04 的报告推至 2013-10-25；2018-19 停摆，2018-12-24 快照原拟 12-28，预计 2019-02-01 恢复首份；2023 ION 事件，原拟 2 月至 3 月中数份报告分批补发；2025 停摆，官方 2025-12-09 更新了 13 份报告的**拟定**补发日；2017-03-28 的 `13874A` 行在 2017-04-04 因申报错误公布了修正版。详见 `release-evidence.json`，不能以初版预告取代后来日程，更不能把“拟定”冒充逐行实际到达。

## 用途边界与下一步输入

CFTC 将资产管理人/机构与杠杆基金按交易者主要业务分类，个人或机构也可能用期货对冲现货；期货净头寸不是这些主体的完整股票仓位。合约 `13874A` 也不等于全部 S&P 500 股指期货：CFTC 另有标准合约与合并报告；2023-05 起合并报告还纳入微型合约，本次未混入这些不同口径。[TFF 解释说明](https://www.cftc.gov/idc/groups/public/@commitmentsoftraders/documents/file/tfmexplanatorynotes.pdf)、[2010 合并合约说明](https://www.cftc.gov/MarketReports/CommitmentsofTraders/HistoricalSpecialAnnouncements/index.htm)。

本数据可用于**带明示时点限制的回顾性描述**。若主控需要可交易时点的效果检验，须先固定可核的近期段、逐周公开日和纠错时点；当前全历史首发版本未齐，不能直接评估 2006 年以来的实时反向策略。对宽基 ETF 的具体期限、对手和风险效果均未评价。
