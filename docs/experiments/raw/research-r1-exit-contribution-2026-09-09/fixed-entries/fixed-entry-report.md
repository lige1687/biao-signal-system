# R1道路退出贡献：固定原买入比较报告

## 一句话结论（大白话）

只保留初始失效保护，会让少数长期持有到期末的交易赚得很多，但大多数原买入反而变差，而且持有时间从约两周拉长到数月甚至数年；这些路径互相重叠，不能当作一个真实账户的收益。

## 固定范围与核对

本批锁定旧R1四账户的330笔实际买入，两种退出各算一次，共660条单独计算的路径。两档费用下实际是同一批165条原持仓记录的重复费用情景，不能把330笔称作330次独立证据。

原“道路或结构退出”版本的330条路径全部对上旧账户的退出日期、退出原因、净收益和净回报；最大净收益差低于0.00001元，最大净回报差低于1×10⁻¹⁰。逐自然日处理分红登记、应收、支付、失效位调整、交易限制和期末估值。

## 两种退出的变化

按330组费用路径计，结构退出改善80笔、变差244笔、相同6笔；去掉费用重复后对应40、122、3条原持仓记录；这些记录仍不构成相互独立的市场考验。

沪深300每档83笔：改善15笔、变差66笔、相同2笔。原版平均持有26.45天、中间一笔14天；只等结构失效后平均566.34天、中间一笔112天。结构版本67笔已退出、16笔到期末仍持有。已退出路径相对原版每笔平均少约7.15个百分点；期末仍持有路径平均多约39.5个百分点。

创业板每档82笔：改善25笔、变差56笔、相同1笔。原版平均持有25.54天、中间一笔12.5天；结构版本平均522.23天、中间一笔159天。结构版本57笔已退出、25笔到期末仍持有。已退出路径相对原版每笔平均少约14.45个百分点；期末仍持有路径平均多约111.2个百分点。

主费用0.1%下，沪深300每笔平均净回报由0.72%升至2.55%，但中间一笔由约-0.88%降至-5.69%；创业板平均由3.03%升至26.87%，中间一笔由约-1.33%降至-7.38%。平均数变好主要来自少数长期开放路径的期末浮盈，并非多数交易改善。每个产品贡献最多的5笔差额全部来自期末仍持有的路径，已经包含截至2026-06-30的分红权益和收盘估值，没有假设卖出。

这些固定路径会互相重叠，不能把净收益金额相加，也不能代替允许后续重新进入的完整账户结果。

## 文件与验证

接受结果在`attempt-02/`：`paired-comparison.csv`为逐笔对照，`path-daily.csv.gz`为逐日路径，`path-events.jsonl.gz`保留行动、退出信号和每次开盘尝试，`comparison-statistics.json`记录改善/变差、持有时间、已退出/未退出贡献和前5笔。

12个测试覆盖严格小于、同日结构优先、道路与结构版本分离、买入后次日才能卖、受限延期、登记后卖出仍收款、入场除息日不重复调整和两档费用。运行锁中的21个协议、输入和代码文件在运行后未变。

首轮所有输出完整保存在`attempt-01/`。其退出、金额和逐日路径正确，但汇总对每组最后一笔未结束持仓少计期末当天1天；第二次尝试只修正这个持有日统计并补充风险与贡献指标。

## 限制

持有中下降只使用每日有效收盘与实际退出开盘，不含盘中最低价。公司行动和交易限制只代表冻结输入的覆盖范围。结构版本大量路径长期重叠且许多没有退出，因此平均收益对期末日期和少数大涨路径很敏感。
