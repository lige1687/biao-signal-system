## 3. 01D事实、推断与数据恢复决定

### 3.1 本轮重新核实

读取 `~/Library/LaunchAgents/com.lei.timing.daily.plist`，ProgramArguments为 `/bin/bash` 与桌面仓库的timing_daily.sh，计划是周一至周五17:30（并非自动识别交易所节假日）。stdout文件0字节；stderr有7行相同的`Operation not permitted`，无逐行时间戳。launchctl返回LastExitStatus=32256，为编码后的126退出状态。列出的4个脚本两仓SHA256一致。

这些事实足够把故障定位在脚本内容执行前的读取权限阶段。TCC/桌面保护是合理解释；单凭这些信息不能确认具体是哪条隐私授权、也不能证明python已获特定授权。当前不改隐私设置、不尝试扩大bash访问权限。

### 3.2 修正一处交易日期说明

01D把9月7日美股没有新日线解释为“当日交易尚未结束”。实际2026年9月7日是美国劳动节休市，9月4日为此前最近交易日。已查官方[NYSE 2026—2028日历公告](https://ir.theice.com/press/news-details/2025/NYSE-Group-Announces-2026-2027-and-2028-Holiday-and-Early-Closings-Calendar/)。这不否定价格源到9月4日的观察，但理由须更正，不能把工作日近似当完整交易日历。

### 3.3 总控决定

1. 01D只读排查到此结案，报告注明哪些是本机证据、哪些是推断；不再把它当完整日历交付。01R当前无可信日历/发布策略时unknown、02R严格评价暂不ready的限制可接受，不要求双方继续互等。
2. 将来修自动链时用桌面外的确定部署副本与运行目录，输入/输出/日志路径明确；不通过扩大整个bash的隐私权限解决。仓库同步、回补校验、运行测试和启用调度是单独运维实施，不在本次验收自动执行。
3. 先在临时副本生成A股/美股宽度候选文件，核对成分池、复权、有效值分母与重叠日期结果，再决定真实替换。保留01D的零网络回补方案，但本轮没有重跑该大文件计算，不能替其临时验证升级成正式回补完成。
4. 维持历史证据与当前状态分开，当前数据未知不阻断已有回测的解释，但不能借历史状态称今天出现机会。
