## 事实核查一：第13轮摘要能对上，但成交与资金约束不完整

来源：`scripts/dca_complete_trades_study.py` 与对应原始结果。全部20组摘要重算的最大差为0；730条是**146个“入场类型＋标的＋日期”机会各配五种退出**，不应称730次互相独立的经历。去掉入场类型后只有142个不同的“标的＋日期”。

### 1. 当日收盘决定卖出，却用当日开盘成交

代码125行用 `closes[j]` 计算收益，135行检查+30%，147行按 `opens[exit_j]` 卖出。该日收盘信息在开盘时尚不存在，违背规格§3.2。

沪深300归档21笔目标止盈全部用当前快照原函数复现成功；只把触发用价改为前一天收盘，10笔退出日期发生变化。一个清楚的真实例子：

| 项目 | 值 |
|---|---:|
| 入场触发日期 | 2012-02-07 |
| 原记录退出 | 2014-12-08开盘 |
| 2014-12-05收盘时浮盈 | 27.5807%，尚未达30% |
| 2014-12-08收盘时浮盈 | 32.8065%，此时才达标 |
| 原假设成交开盘价 | 3108.272 |
| 只修正信息先后后的退出 | 2014-12-09开盘 |
| 原净收益 / 修正后净收益 | 26.7756% / 31.8667% |

该小组修正后平均收益反而增加1.7632个百分点。这说明**修正程序错误不等于收益必然下降**，也不能据此宣称修正策略更强；当前只核实机会时序。21笔逐一保存在 `round13_000300_target_paired.csv`，没有按盈利挑样本。

### 2. 所谓12个月等待，实际约6个月；所谓周查，实际逐日查

133行是 `j > acc_end + ACCUM // 2`，ACCUM=252，意味着建仓后第127根记录退出，全部时间退出的平均持有期均为18.0476个“21根记录月”。报告文字说建仓12个月后再等12个月，按文字应约24个月。124行循环逐条日线检查，并没有限制每周检查。

因此，“随机入场后到期退出中位亏5.2%”不仅把固定月末对照说成随机，还对应实现的约18个月总持有期，不能当作文字版24个月的成绩。固定月末对照见78—87行，并无随机抽取。

### 3. 同一资金不能把重叠计划都当能执行

178行统一占位504根记录，但有些退出要等到756根。原始逐笔记录中，**相同入场类型、退出规则、标的的相邻计划有128处日期重叠**。例如深证成指的深跌入场、等年线上方30%退出，一笔2015-08-26开始、2018-10-08结束，下一笔已在2018-08-06开始。

五种退出本来就共享机会，比较时可以保留这种配对；问题在于不能同时声称同一方法的计划都不重叠、同一预算没有重复占用。已留 `round13_overlapping_plans.csv`。尚未重新建立全账户资金竞争与再次进入规则。

### 4. 中位数较好不等于总资金更赚

归档原数中，固定月末入场的时间退出平均收益24.7607%，目标止盈平均19.3457%；后者中位数25.1264%，前者中位数-5.1747%。两者回答的是“常见一笔怎样”和“平均一笔怎样”，不能只选对止盈有利的一个数就断言出场绝对更重要。这些仍是有上述时序问题的旧数，仅用于解释旧摘要为何不能直接给出优先级。

## 事实核查二：第18轮完整组合，终值对上了，但收益/风险口径应分清

以下保持原买卖、费用和价格完全不动，先复现原引擎，再独立记账：

|---|---:|---:|
| 原终值，预算1单位 | 1.5697011216242525 | 2.31764528602191 |
| 本次独立账本与原终值差 | 0 | 0 |

原引擎143行把“买入时花的钱”当外部投入；期末最后一笔现金没有买入，却包含在终值，所以年化计算漏了一笔自己的本金。恒价、零费用、260个工作日的合成例中，账户始终不赚钱，原程序却报年化+4.0286%；按外部全部投入记账后约为0。见 `flat_price_daily_ledger.csv`。

原157行直接对含持续投入的余额计算最大跌幅。这个数可以描述“账户表面余额跌了多少”，却不能独自证明组合风险较低。例如100元资产跌成80元，再存100元，账户余额变180元，并不是投资上涨80%。本次严格按原程序顺序把隔夜涨跌、开盘外部入金、日内交易和涨跌拆开，给出排除入金影响的投资价值曲线；不改变旧资金购买路径。该指标也不是某个用户实际曾经拥有的同一笔本金损失，应与账户金额、累计投入、实际亏损金额并列，而不能互相替代。

会计恒等式“总资产＝现金＋持有资产市值”的最大误差≤1.12×10^-16。两个时段逐日存款、买入、现金、费用、总资产、剔除入金后的价值全部保存在 `round18_*_daily_ledger.csv`。

方法记录：初算曾按期末入金作近似；检查到少数周只有一天，原程序会同日入金并买入，遂改为严格按原程序开盘入金拆分。此处仅校正计量时点，未根据收益选择参数。最终数字以本报告和 `results.json` 为准。

## 尚不能回答的真实空白

1. **固定期限与取钱阶段。** 第13轮时间退出是交易规则，不能代表某年必须支付学费、购房或退休逐月支出。第18轮仍是持有资产估值，不含长期取款顺序。
2. **暂停后的生活现金安排。** 第16轮已有两种策略恢复方式，所以不能说从未研究恢复；但未来收入中断、必须保留现金、恢复时补投与否没有完整比较。
3. **退出后的资金复用。** 第13轮每笔独立了结，不含全账户现金等待、并行预算和再次出现机会。第16轮覆盖内部恢复但不是篮子外独立机会。
4. **可买产品。** 沪深300/创业板/纳指综合均是指数，不能直接代表可购基金；人民币/美元转换、汇率、净值更新时间、跨市场休市、分红和跟踪误差尚未完全对齐。数据加载器对ETF写“可能复权，失败退不复权”，旧报告统称价格口径不能替代逐文件来源核验。也不能预先保证补分红后排名不变。
5. **独立经历与事后选择。** 第18轮所有起点共用2026年终点、相邻方案高度重叠；1月起点8个也共享行情。资产选择经历多轮筛选，这些旧数据不能再当作完全未参与选择的证明。更长代理历史也不能冒充实际产品可投资历史。

## 唯一优先实验候选：先固定合法成交与完整资金账的定投基准

这是准确性修复研究，不预设哪种退出收益更高。它对用户的价值是：后续问“多赚了多少、最坏亏多少、这笔钱到期能否拿回”时，不再混用不同账法。

| 方案要素 | 固定建议 |
|---|---|
| 对应条款 | 规格§3.2次日执行、§3.3成本；任务书§7信息与成交时间、定投资金、比较口径 |
| 与旧实验差别 | 不找新阈值；明确旧实现、修正时序实现、文字原方案三者差别；剔除资金重复使用和错误外部现金流 |
| 对象 | 第13轮原146个入场类型/标的/日期机会，保留五种退出配对；第18轮现成四资产固定基准作为持续收入账本对照。不额外选择近期赢家 |
| 三个有限对照 | A原归档实现仅作对账；B只将收盘触发推进至下一可用开盘、其余保留；C按原书面方案恢复每周检查与建仓后252根记录时间退出。每种修正分开展示，不能一次改完后把全部差异归功单一因素 |
| 时间与缺数 | 用真实日期而非删行后“第n根”冒充月数；缺实际交易日历或报价时该计划标不可核验；跨市场指数价格仅可作为解释性代理，不能给实际产品成交承诺 |
| 完整资金约束 | 每个标的固定1单位起始闲钱、不同退出方案各有独立但相同预算；上一计划未结束时后续机会记“资金占用未执行”，结束后现金留在账上、等待下一个原定义事件；不同标的比较先各自独立，不擅自拼成全账户配置 |
| 期末处理 | 记录所有已有机会与未执行理由，不丢掉未结束计划；必须到期取钱的场景另立研究。主研究期末以可用最后估值标仍持有，同时列净变现假设与成本，不虚构已成交 |
| 主要验收 | 配对机会和资金记录齐全；外部投入与内部买卖严格分开；恒价零费收益约0；资金恒等式误差<10^-10；原始对照可追溯；每个成交使用的信息均早于实际执行 |
