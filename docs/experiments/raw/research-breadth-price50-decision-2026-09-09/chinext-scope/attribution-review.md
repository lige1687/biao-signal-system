# 宽度与价格持有差异的独立核账

规范：`experiment-backtest-principles.md` v1.0；`definition-standard.md` v1.0.0。

## 一句话结论（大白话）

12组宽度方案与简单价格方案的资金差额全部对平，分红、拆分和除息没有重复计账；但“只有价格方案持有”的金额有时代表宽度避开下跌，有时代表宽度错过上涨，必须看正负金额，不能把这一组统一称为防守收益。

## 独立复核方法

没有导入`controller/relative_and_attribution.py`。复核器从每个账户的每日份额、现金、应收、累计分红、真实成交和名义开收盘重新计算：成交前份额承担隔夜价格变化，成交后份额承担当日开盘至收盘变化；应收增加与到账增加合并为分红权益；费用单列扣除。

每个账户逐日满足“隔夜价格变化＋日内价格变化＋分红权益－费用＝账户资产变化”，最大残差低于`1e-6`元。再按双方成交前、成交后是否持有分为双方持有、只有宽度持有、只有价格方案持有、双方现金。12组对照的每日明细、全期汇总和2025年至2026年上半年汇总均与发布文件一致，差额小于`1e-8`元。

分红权益日也单独检查了上述恒等式。拆分通过账户份额和真实名义价格自然进入隔夜计算，没有再把拆分倍数当利润；除息价格变化与应收分红一减一加，因此没有把分红重复算两次。

## 如何读“只有价格方案持有”

这一组的`difference`等于宽度账户的0减价格账户当日价格损益。若为正，表示价格方案当时亏损而宽度持有现金，宽度避开了这部分损失；若为负，表示价格方案当时上涨而宽度持有现金，宽度错过了上涨。

以0.1%费用、全期相对200日价格方案为例：

- `159915 all-A W3`的“只有价格方案持有”为-6.34万元，净效果是错过上涨，不是避免损失；完整账户差额为+61.02万元，主要金额来自“只有宽度持有”期间的+45.44万元及双方持有期间的+23.93万元，费用和分红差额合计拖累2.01万元。
- `510300 all-A W3`的“只有价格方案持有”为+4.45万元，表现为避免损失；完整账户差额为+15.02万元。
- `510300 CSI300 W0`的“只有价格方案持有”为+28.54万元，表现为避免损失；但“只有宽度持有”期间为-1.35万元，完整账户差额为+22.33万元。

2025年至2026年上半年，以上三组相对价格方案的完整资金差额分别为-74.97万元、-24.24万元和-3.90万元。这说明全期优势不能概括为最近阶段也持续有效。

## 边界

这些金额是实际持仓路径的会计拆分，不是严格的单动作因果收益，也不是独特能力证明。宽度和价格规则会改变后续份额、现金及成交，不能把各时期年化或不同持仓组简单相加成独立贡献。结果仍来自已看过的历史区间，没有生产授权。

机器核验见`attribution-review.json`，每组误差见`attribution-checks.csv`，全期与2025年至2026年上半年金额见`attribution-phase-checks.csv`。复现命令：

```bash
python3 docs/experiments/raw/research-breadth-price50-decision-2026-09-09/chinext-scope/verify_attribution.py
```

## 新增50日价格方案的分次复核

前述12组是第一轮对200日和持有参照的复核。本次只新增复核6组相对50日价格方案的对照，没有重复运行原12组。6组各2,918个交易日至日历日记录的相对净值和相对下跌逐行一致，最大差异`4.5e-16`；最长相对恢复和期末仍未恢复天数也一致。

0.1%费用下，全期相对50日方案的资金差额为：`159915 all-A W3`多102.41万元、`510300 CSI300 W0`多66.94万元、`510300 all-A W3`多59.63万元。2025年至2026年上半年则分别为少53.59万元、多10.54万元、少9.80万元。全期领先仍不能推出最近阶段普遍领先。

本轮机器文件`attribution-review.json`、`attribution-checks.csv`、`relative-checks.csv`及`attribution-phase-checks.csv`只包含这6组新增对照；原12组通过记录保留在上一轮生成的报告文字中，未被本轮重复计算冒充新复核。
