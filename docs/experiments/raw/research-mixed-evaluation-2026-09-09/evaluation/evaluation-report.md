# 11只混合池既有账户评价补全

规范版本：`experiment-backtest-principles.md` v1.0  
冻结协议：`research-mixed-evaluation-2026-09-09/protocol.json`  
性质：只评价已经封存的8个账户，没有运行新策略，也没有改变历史交易。

## 一句话结论（大白话）

四种方法的大部分利润都来自2025年至2026年6月，快速回补虽然把全期最大下跌压到约23%—25%，但交易明显更多、费用更高，而且账户从历史高点恢复最长仍需三年多；这些数字支持继续观察，不能说明它已适合真实资金。

## 主要发现

- 每边0.1%费用下，快速回补在2020年12月至2024年底赚34.28万元，2025年至2026年6月再赚154.73万元；后段收益建立在2024年底实际134.28万元权益上，没有把资金重置为100万元。
- 同期满额不退出前段赚25.61万元：快速回补前段累计收益高8.66个百分点且最大下跌更浅。后段满额赚151.15万元；以各自2024年底实际权益为基点，快速回补累计115.23%，低于满额的120.33%，两者期内最大下跌均约20.07%，几乎相同。四种方法后段都很强，这只说明利润集中在哪段历史，不能叫独特能力或运气占比。
- 快速回补主费用全期买卖成交额合计约为平均账户权益的94.25倍，总费用12.46万元；满额不退出分别为54.73倍、6.90万元。较浅的全期下跌伴随更高的交易成本和操作负担。
- 普通平均配置主费用全期年化12.52%、最大下跌22.69%，交易额约为平均权益的4.86倍。它的收益较低，但交易负担远小于三种选强方法。
- 快速回补主费用最长一次从前高到恢复用了1130个自然日；双倍费用用了1255日。期末两条路径都从2026-06-25的前高回落，至截止日仍有5日未恢复；满额和75%版本为36日，普通平均配置已恢复。

## 资金归因核对

按每次真实买卖重建移动平均持仓成本。拆分只调整份额和每份成本，不改变总成本；分红在形成应收权益时计入。每个账户均满足：

`已卖出价格损益 + 期末持仓价格损益 + 已取得分红 - 费用 = 期末权益 - 100万元`

8个账户最大核对差异为0.000000001元以内。明细见`profit-attribution.csv`。这项是资金核算，不解释利润来自哪种可持续能力。

## 输出口径

- `phase-metrics.csv`：early、late、full三段累计收益、日历年化、阶段内最大下跌、平均/期末仓位、双边成交额、换手、费用。
- `annual-metrics.csv`：逐年收益、平均及年末仓位、成交额、换手、费用。
- `recovery.csv`：全期最长已恢复区间，以及截止日仍未恢复的区间。
- `profit-attribution.csv`：移动平均成本下的已卖出、期末浮动、分红和费用归因。

阶段最大下跌把阶段开始前的实际权益作为基点。晚期从2024-12-31实际权益继续，收益率不能与前段收益率直接相加。换手为该段买卖成交额合计除以该段每日平均权益，因此是整段累计交易强度，并非年化数字。

## 限制

这是已看过历史结果后的评价补全，不是新行情验证。统一费用没有覆盖真实开盘价差、成交偏差和容量；产品池仍有历史选择偏差。结论只说明这8条封存账户在固定历史数据上的收益、风险与成本，不授权生产或真实交易。
