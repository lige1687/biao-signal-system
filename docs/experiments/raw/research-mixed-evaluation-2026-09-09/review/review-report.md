# 11只ETF池完整评价独立复核

规范版本：`experiment-backtest-principles.md` v1.0

冻结协议：`docs/experiments/raw/research-mixed-evaluation-2026-09-09/protocol.json`

复核性质：独立公式重算与逐账户资金归因核对；没有导入评价程序

## 一句话结论（大白话）

8个账户的分期、逐年、下跌恢复和利润拆分全部对平；图表中的16,304个下跌幅度也与每日账户重算一致。这个通过只证明已有历史结果算得一致，不代表策略已通过新行情或真实交易检验。

## 覆盖与结果

独立复核了24组早期、后期和全期指标，以及56组逐年指标。起始和期末资产、累计及日历年化收益、区间内最大跌幅、平均与期末仓位、成交金额、费用和成交笔数均无差异。

全期恢复重新逐日扫描，并把初始100万元作为第一个高点。两个平均配置账户期末没有尚未恢复的下跌；两个不退出100%账户和两个75%账户均在期末仍有36天未恢复；两个快速回补账户均为5天。最长已恢复区间的高点日、恢复日和自然日数也全部一致。

图表数据共16,304行。每条曲线均以当时历史最高账户资产计算下跌幅度，逐行差异不超过`1e-12`；各曲线最小值与全期最大跌幅一致。

## 利润恒等式

复核按移动平均成本独立处理每笔买卖：卖出产生的价格损益，加上期末市值减剩余成本形成的未卖出涨跌，再加已取得分红、减全部费用，必须等于期末资产减初始100万元。8个账户全部通过，允许误差`1e-6`元；期末成本和份额也与每日账户记录一致。

这个拆分回答钱在已卖出部分、期末持仓、分红和费用之间如何组成。它没有把市场、行业、动量或回补解释成互不重叠的独立收益来源。

## 限制与复现

本次只复核已经看过结果的11只存续ETF历史账户，没有新增策略收益、参数搜索、真实成交容量或未见行情观察。生产与真实交易仍未授权。
