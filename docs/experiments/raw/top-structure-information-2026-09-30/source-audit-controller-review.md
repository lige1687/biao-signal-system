# T01 原文子集与去重主控决定（统计前）

Luna机械审查已核：三根高低价严格逐根下降是§2.6/实现§7.1—7.3的窄子集，旧宽度高侧事件、完整账户退出及消费方修复没有回答本信息问题。接受去重结果，非因看到效果选题。

针对审查提出的三个定义问题，原protocol已有明确限定，在这里给出理由并保持不变：

1. 观察日期固定候选第三根收盘。这个问题观察每一个连续三根简单图形，而非完整检测器最早顶部发生日、首次顶部或整个顶部状态。每个三根片段第一至第二根已经LH，第三根低点再低于第二根LL，所以在第三根形成这个片段；后续同样片段仍计每日观察但必须记录连续段、不得当独立事件。即使更早另有顶部，也不回填新片段日期。不得把本状态称为原文所有顶部的首次确认。
2. 高低价严格逐根下降自动不包含相邻K线。相等、包含合并、极端外包、隔多根确认是未覆盖原用途；这是明确子集，不是把原文要求修改成两次严格下降。没有新增生产确认或退出规则，也不否定未覆盖形式。公式是当前strict源码在最简单非包含三根输入上的可核对例子，不调用全段有后视的旧事件。
3. 环境仅SMA60(t)>SMA60(t-5)，沿本项目V01背景计算；称“SMA60近期上行背景”，不能称已满足完整LEI上升趋势/阶段/持仓。精确公式写入研究卡和合同，不冒用不存在的完整趋势定义。它只是预定研究范围，未来结论仅在这个范围成立。

因此无需替用户更改技术原文含义；可以在明确标记的研究子集上继续资格与效果检验。若执行发现该三根模式连原简单构造子集都不满足，或数据因果时点无法核定，停止受影响分支。原文指纹、规则及复杂构造/同日退出歧义保持只读，本决定不批准改变它们。可比机会160/299，只是无未来数值的支持事实，不代表效果可靠。
