## 保存日账 CSV

六份 CSV 的列相同；每份1642自然日，2022-01-01至2026-06-30。本次仅检查新方法必要的2025-09-25至2026-06-30，共279自然日，包含每个风险观察日的前一自然日。

| 字段 | 含义与单位 | 使用注意 |
|---|---|---|
| `date` | 北京时间自然日，ISO日期 | 唯一且升序；不能把休市行删掉后取“上一行”作为交易日分母 |
| `cash` | 已入账、可使用现金，元 | 应收分红不在这里；不能借用后续付款 |
| `receivable` | 已确认但未付的分红应收，元 | 计入完整资产，不能直接拿来买入 |
| `units` | 当日持有的ETF份数 | 保存原整数份额；不是金额或交易手数 |
| `raw_close` | 当日原名义收盘，每份元 | 非交易日可为空；不是信号使用的经济指数 |
| `mark` | 当日每份估值价格，元 | 有收盘用原名义价；休市用原账保存的上一价格 |
| `mark_basis` / `stale_age` | 估值来源及该价格延用的自然日数 | 不能把非交易日价格延用称作新增行情 |
| `wealth` | 完整资产，元 | 已核 `cash + receivable + units × mark`；不得仅用现金或持仓市值 |
| `invested_pct` | 持仓估值占完整资产的百分数 | 这是0至100的百分数，不能误作0至1比例；不替代风险检查 |
| `is_trading_day` | CSV字符串 `True` / `False` | 与原冻结日历比对；不要用字符串本身的真假判断 |
| `missing_reason` | 原非交易日或缺价原因 | 原解释保留；空值不代表已证明实际可成交 |
| `reconciliation` | JSON字符串，保存累计费用/买卖额/分红及资金核对差额 | 先解析JSON；本期费用读取期末 `fees_cny` 减2025年末同字段，不能使用2022年起累计数 |

所有金额字符串按十进制数读取。保存账的四项核对差额是 `cash_residual_cny`、`receivable_residual_cny`、`unit_residual`、`wealth_residual_cny`；本次必要日期均为0。

B的日收益分子是当日完整资产，分母是**前一自然日**完整资产；数据准备已验证日期和正金额存在，没有计算收益值。原统计使用分母为观察数减1的标准差，意思是按这批日收益估计起伏幅度；实际计算、零波动检查属于B。

## 原价格、日历及月末截止

原价格CSV列为 `date, open, close, high, low, volume`。只有原 `open` 用于开盘价格、`close` 用于收盘估值；不能用经济指数、复权指数、同日最高/最低/收盘价来保证开盘成交。当前原价全文件3273行，2013-01-04至2026-06-30；本次所需交易日与原日历、限制参考一致。

`original_calendar` 是深交所官方保存日历。510300在上交所交易，旧合同接受这一有限历史对照口径；资料里没有独立上交所逐日官方日历证明，也没有更早公布时间的完整证明。`original_input_calendar_manifest.complete_month_last_trading_dates` 可作原资料对照，实际截止表见本目录资格说明。

只需要六次截止：2025年末及2026年1月至5月末，供次月使用。2026-06-30是半年结束估值，不增加7月目标或下一批资料。月末为休市时，截止仍是自然月末，最后一项观察来自不晚于它的最后交易日。不得因某个最新日期缺账而删掉该日、往前多找一日凑63个。

## 公司行动与到账

原行动事实中的 `symbol`、`type`、`event_id` 固定产品、类型和事件身份。`record_date` 决定权益份数；`ex_date` 在开盘前进入应收；`payment_date` 的支付阶段是 `after_close_research_assumption`。原映射将 `payment_date` 记作 `pay_date`，将 `cash_cny_per_unit` 记作 `cash_per_unit`，金额是**每份**元，不能再除以10。

原B0持有19800份，保存分红账分别记录权益、应收、付款，金额2435.4000元；这是旧账户资料，不是新对照的分红金额。新对照的权益取决于B实际运行中的登记日份数，A没有计算。

## 交易限制与保存成交账

逐日参考字段：`date`、`reason`、`restriction`、`prior_nominal_close`、`lower_limit`、`upper_limit`、`event_ids`、`next_quote_recovery_candidate`。`restriction=null` 只表示原模拟未禁止此开盘；`blocked` 要等待。不能把它解释成交易所或券商成交保证。

2026-01-19原记录为 `reference_unknown` / `blocked`，除息开盘的官方参考价不明；01-20是下一有报价候选，是否成交由B沿原条件处理。原规则是100份买入整手、每份0.001元报价单位、一般10%涨跌限制，零头卖出按原规则；未发现停牌清单不等于证明从无停牌。

保存成交账 `fills` 里的 `date`、`decision_at`、`units_delta`、`price`、`fee` 分别是成交日、决策时点、份数变化、成交每份元和费用元；`orders`、`rejections` 保留原订单与拒绝。`action_ledger` 保存三阶段分红。`full` 是原2022年以来全时期汇总，不能冒充半年指标；`annual` 的2026行也不替代准确日账检查。
