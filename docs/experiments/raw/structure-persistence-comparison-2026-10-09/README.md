## 一句话结论（大白话）
本轮把用户批准的两种解释写成了可实现的研究规则：第一种遇到去包含后的短反弹就中断；第二种必须先看到后续构造的高点和确认低点再次下降，之后允许尚未形成新底部的短反弹。现有四只宽基 ETF 固定资料可支持有限的历史比较准备。这里没有计算新状态或未来结果，不能说哪种更有用。

## 为什么第二种不等于“一直没破原高”
根顶部刚确认时，第二种记为等待，值为 0。后续再确认一个顶部，只有其冻结参考高点和确认低点都比前一个顶部对应值低，才转为成立，值为 1。此后尚未产生新确认构造的短反弹可以维持；新顶部比较不通过便永久中断，新底部或突破最初高点则终止整个观察段。低点是顶部确认时的 LL 低点，**不是独立确认的底部谷点**；真正新底部一旦确认，按原句已经该终止。它是明确的窄研究近似，不冒称完整波段语法。

两种共同从首次确认顶部之后观察，不按各自成功片段选样本。中断之后的日期、等待推进的日期、反弹日期和终止日仍留在同一分母。包含K只按当时已见资料合并，后来的扩展不能改写已发布的历史结论。同日突破原高与新底确认同时保存，二者都令状态终止；不从日线猜盘中先后。
