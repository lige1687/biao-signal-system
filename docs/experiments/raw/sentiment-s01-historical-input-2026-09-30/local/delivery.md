# Local repository evidence: S&P 500 historical breadth

**Finding:** Within the files inspected under the local-agent contract, no genuine historical S&P 500 20-day or 50-day breadth series qualifies for the planned study. The repository contains working code that can calculate those percentages, and it contains a current constituent snapshot plus recent daily prices, but it does not contain a verified historical member list and matching prices for companies that later left the index. The existing backfill route itself labels its old-period output as using today's membership retroactively and warns that this makes the readings too high.

The fixture `tests/fixtures/market_context/universes/SP500.parquet` has 503 symbols and fields `effective_from`, `effective_until`, `source`, `source_version`, and `source_kind`; the sampled rows are all marked `wikipedia_sp500`, version/effective date `2026-08-04`, and `research_proxy`. `tests/fixtures/market_context/indices/SP500.parquet` covers 2024-08-16 to 2026-08-14. The inspected AAPL component file has the same 500-session date span and OHLCV fields. The manifest explicitly says the constituent set is current-only with no historical point-in-time rebalance.

`src/lei_signal/market_context/breadth.py::compute_breadth_snapshot` can produce 20/50/200 readings, each using its own eligible denominator. `src/lei_signal/market_context/us_breadth.py::compute_sp500_breadth` can also compute those horizons from a close-price matrix and returns percentage values. Neither calculation creates missing historical membership or source timing. The latter reads its main price matrix from the cache or a user-supplied path outside this inspection contract. `scripts/backfill_sp500_breadth.py` documents a backdated mode that assigns the current members to the earliest available price date and labels them `wikipedia_sp500_backdated`; strict no-backdate mode starts only at the fixture's 2026-08-04 effective date. Thus neither route qualifies as a long-run historical S&P 500 series.

The older `docs/experiments/raw/breadth_overlay/A_us_indices.json` is a Module A trading run on `^GSPC` and `^IXIC`, not a breadth dataset. The prior local inventory likewise says no independently registered US S&P 500 breadth object was found. The separate US audit lists database B20/B50/B200 numeric columns but explicitly leaves historical membership and historical publication time unproven; that database was outside this executor's scope and remains for controller review.

**What is established:** no qualifying series was located among the inspected local paths; the current fixture membership begins 2026-08-04; recent index/component prices reach back to 2024-08-16; the available producers either use current membership or retroactively backdate it; and no historical publication/availability times are evidenced here.

**What is not established:** this was not a whole-repository absence proof. No broad scan was performed, and no external cache or database was read. No historical S&P 500 B20/B50 outcome or return analysis was run.
