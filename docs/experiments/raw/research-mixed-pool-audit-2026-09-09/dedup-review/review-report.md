# 11只代表ETF池独立资金复核

## 一句话结论（大白话）

本次11只ETF对照的8条完整资金路径均通过独立复核：被排除的3只从未进入名单或持仓，月末排名、波动过滤、75%资金目标、快速回补预算以及每日现金和持仓全部对平。结果只能说明固定缩减后的这11只存续ETF，不能证明它们代表了历史上所有可买ETF。

## 独立核验范围

复核器没有导入执行器，直接从冻结价格和公司行动重建连续价格指数、200日均线、跳过最近21个交易日的252日强弱、20日波动率在过去756日中的位置，以及至少273条真实报价的入池资格。逐月核了536个账户决策，池内严格为协议列出的11只；`515130`、`515050`、`159652`从未入选或成交。

四种方法、两档费用合计8个账户均从100万元重放。16,304行每日账逐行核了现金、应收分红、拆分后份额、市值和总资产，误差阈值`1e-7`元且没有差异。另核134组75%资金目标、402组全额目标、174次止损预算建立、96次回补信号和96次真实回补；回补买入金额和买入费没有超过对应止损净到账资金。
