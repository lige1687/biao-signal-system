# 验证器修订说明

首版验证器保留为`failed-attempt-01-incomplete-assertions.py`。它虽然报告通过，但75%目标金额的差异判断误缩进到循环外，只实际判断最后一组；预算检查遇到缺失预算或没有恢复报价时也会跳过，因此不足以支撑通过结论。

最终版逐一判断134组75%目标，并要求每组恰有一个月度信号。快速回补改为按月度信号的真实`eligible_date`重建预算生命周期：174次预算都必须对应同日真实止损卖出及其净到账，96次触发都必须已有预算，96次买入都必须已有触发且不超预算；月度执行日先核76次取消再清空旧预算。恢复条件允许在实际止损成交日收盘成立，且不会把前一日止损信号日期误当成交日期。修订后全部检查通过，金融输出未改。
