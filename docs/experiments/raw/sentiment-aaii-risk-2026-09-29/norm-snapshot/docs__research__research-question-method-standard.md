# 研究问题与方法匹配补充规范

版本 1.1.0，2026-09-29；新增Universe与依赖口径，旧1.0.0冻结实验不变。本文件供本次双均线逐日研究及明确选择采用它的后续工作参考，不修改旧冻结合同、已登记因子定义、交易规则或 `docs/research/experiment-backtest-principles.md`。`question_contract.py` 是可选研究问题附加块的局部结构校验器；它不是全系统已接入的强制检查。通过不代表计算正确或因子有用。

## 1. 用问题类型选择方法：五类对照表

| 研究问题 | 常见抽样 | 适用方法示例 | 必须明确的对手/主结果 | 容易误读的地方 |
|---|---|---|---|---|
| 计算或定义核对 | 固定输入、边界样本 | 独立逐例重算、边界用例、字段/来源一致性核验 | 被核对的定义或结果、允许误差、失败样例 | 核对通过只说明实现与约定相符，不说明对象有预测信息 |
| 单市场随时间预测 | 每交易日或预先定义的事件 | 固定期限分组差、秩相关、按日期连续分块重抽 | 简单状态/无条件基线、时间范围、目标端点和主指标 | 相邻日和持有期可能重复，日期数不能当作独立样本数 |
| 同日多资产比较 | 同一交易日的完整资产截面 | 同日排序比较、分组差或截面回归（仅在问题需要时） | 同日候选池、资产覆盖规则、主比较 | 不应把多个资产日期打散随机分组；资产可能共享市场冲击 |
| 状态或事件条件比较 | 每日状态，或严格定义的事件起点 | 状态内固定期限分层、匹配同日简单状态、事件后固定窗口比较 | 条件成立/不成立的完整分母、同一目标期限 | 条件组大小、窗口重叠和事后选事件会改变解释；到状态终止的期限不能冒充固定期限 |
| 买卖/仓位政策比较 | 完整机会或完整账户路径 | 同一机会、同一资金、费用和持有规则下比较完整策略 | 不加入该政策的简单策略、账户资产与风险指标 | 资金路径不是单一因子的预测标签；账户优势不能自动证明因子有额外信息 |

“同一市场随时间”“同日资产比较”可以在同一个面板问题中共同出现；这类问题必须写出 `comparison="joint"` 和 `joint_structure`，说明哪些日期与资产一起保留。不能为了套用某种统计量，改变问题原本的时间或资产单位。

## 2. 三类证据分别记账

结果块中的 A、B、C 是证据类别，不是自动升级顺序：

- **A：原始分组差异。** 记录新增条件组和对照组各自样本、方向与数值。它只说明观察到分组不同，不能排除时间趋势、资产构成或其他共同变化。
- **B：相对简单基线的增量。** 在同一标的池、日期/事件、目标期限和缺失规则下，检验新增条件相对明确的简单基线多提供了什么信息。只有 B 已完成，结果标签才允许写“增量获得支持”；验证器不会替作者判定是否支持。
- **C：新资料验证证据。** 在没有参与选择规则、参数、标的或指标的资料上，验证同一个问题与基线。处于探索阶段的问题不能把 C 记为完成。旧资料换文件名、重算、重新划段，都不会自动变成新资料。

策略或决策层结果另设 `layer=decision_policy`，单独保存与展示；绝不能填入因子信息研究的 C。主控复核修正：初稿误将 C 写成策略结果，本段纠正该文字错误，已有本批配置和结果均将 C 记为未计算，未因此改动市场数值。

某类不适用、没算、样本不足要分别记 `not_applicable`、`not_computed`、`insufficient`；不能填零代替缺失，也不能把 A 的好看差值自动升成 B，或把 B 自动升成 C。

## 3. 分组概率不等于概率预测模型

按因子高低报告未来上涨比例，只是历史分组中的经验比例。它没有自动学出新日期的概率，也不保证概率经过校准。应同时写出完整分母、有效标签数、观察期、收益幅度和预先指定的下行结果；条件组与全体常常重叠，不得当作两批独立样本。若没有训练、校准与真正后续时期检验，不称“概率模型”，也不把历史上涨率解释为未来个体或组合的确定概率。

## 4. 日期切分、标签成熟与边界

当研究使用日期划分探索资料与后续检验资料时，应按日期整体切分，而非随机拆散同一天的ETF。每个结果标签的起止日必须完整落在所属区间内；凡标签终点越过切分边界、资料末端或价格缺失的行，应按冻结规则排除或单独列出，不能从边界外借未来资料。

本次双均线研究计划约定从信号日后第一个收盘开始，到第二十二个收盘结束（固定21段日收益）。在后续窗口不完整时，不产生完整目标值。固定期限结果与“等到道路转弱或资料结束”的变长结果分开记录。计划的日期切分与标签边界规则只表示执行约定，不代表已经产生任何新市场结果。

## 5. 不统一强制一个统计门槛

计数核验看逐行匹配；单序列状态看目标与时间依赖；横截面排序看同日资产集合；条件事件看组内样本与窗口重叠；策略政策看完整现金、成本和风险路径。不能要求所有问题都报告相关系数、回归、显著性、收益或同一个最低样本数。方法、最低关注幅度和是否给不确定范围，应在看结果前按具体问题说明；数量太少、重抽有效次数不足或来源不可核时，保留“证据不足”，不降低门槛追求结论。

同一市场、同一目标的重复计算或修改实现，仍属同一研究家族的尝试历史。应保留失败、放弃和更改缘由；换执行者、换文件名或重复运行不产生新的市场样本。历史资料的取得时间不清楚时，不能把它重新称为未见检验资料。

## 6. 本次适用范围

本规范和 `question_contract.py` 只为研究问题附加块提供结构校验，不会运行行情计算、改旧协议、写定义登记、登记到报告库、调整规则或生成交易建议。双均线正式研究的分析入口按本批冻结计划调用该校验；这不意味着旧研究协议或其他模块被强制改造。本次交付本身不含新的市场结果，也不声称这套校验经过生产接入。

## 7. 三个独立维度与适用前提

因子定义引用说明怎么算；研究问题说明拿它判断什么；方法说明如何检验；决策规则说明如何据此行动。同一因子允许多个问题，每条结果挂 `question_id`，不设置整个因子的有效标签。

| 维度 | 内容 | 本批选择 |
|---|---|---|
| 比较方式 | 横截面、时间序列、明确结构的联合分析 | 多资产联合，但每个ETF内部跨日期比较；不是跨ETF排序 |
| 取样方式 | 每日、定期、事件、其他明确单位 | 每个交易日；不限制为已开仓日期 |
| 预测目标 | 相对收益、收益水平/分布、涨跌概率、波动/下行风险、其他 | 主要比较21段日收益的均值；概率和下行结果只作辅助 |

| 具体用途 | 方法、所需数据和选择理由 | 局限与不可跨越的结论 |
|---|---|---|
| 同日资产排序 | 每日期完整候选集合内排名相关（Rank IC）及少量分组；需要同日可得因子和同期限未来标签 | 资产少或值重复不硬分十组；正相关不代表绝对上涨或扣费盈利；行业/规模控制需说明实际混杂理由 |
| 单资产状态 | 完整观察日期的状态分组或简单预测基线比较；相关系数亦可，但须明确对象与期限 | 连续日期相关；简单状态差异不是排除所有其他解释；本批采用有明确基线的条件组差 |
| 回调/突破机会 | 完整事件全集、触发时点、重复触发和结果窗口预先固定；比较满足/不满足条件 | 不只看已交易事件；无额外识别设计只能说关联，不能说因果 |
| 未来风险 | 预定义大跌标签、下侧分位数、误报漏报；若输出实际概率，比较同一验证集的概率评分 | 历史组上涨比例不是预测概率；Brier分数（概率误差平方均值）或Log loss（概率对数损失）改善不等于校准改善；校准需另看预测概率与实际频率 |
| 退出/仓位 | 信号后结果恶化属于因子信息问题；按它行动的资金结果属于决策问题，分别对照 | 不用账户最大回撤代替窗口下行风险，也不用账户优势证明因子信息增量 |

结果除来源外须写局限；不适用、未计算、无法可靠计算分别说明，不填0。不确定范围采用适配日期与跨资产相关结构的方法；重抽的块数不是独立观察数。现有校验只检查必填项和少量明显冲突，不能读懂方法理由、发现所有泄漏或自动判定有效。

## 8. 方法依据（不替代本系统实测）

- [Alphalens官方文档](https://quantopian.github.io/alphalens/alphalens.html)：逐日期排序信息系数及事件后结果工具支持对应问题的方法选择，不支持把全体日期混成一个截面相关。
- [arch时间序列重抽样文档](https://bashtage.github.io/arch/doc/bootstrap/timeseries-bootstraps.html)：连续日期分块保留部分时间相关性。本批固定60交易日不是文献规定的万能长度；长期状态、非平稳市场及多次选择仍有限制。
- [scikit-learn概率校准说明](https://scikit-learn.org/1.8/modules/calibration.html)：概率损失同时受校准与区分能力等影响，不能仅用评分下降断言校准改善。
- [TimeSeriesSplit官方说明](https://scikit-learn.org/1.4/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)：按时间组织资料及留间隔是工具能力；仍须按实际未来标签窗口处理跨边界，不因使用工具便认为没有泄漏。

## 10. 新合同的研究对象与推断范围

每个问题固定主用途、主Universe、主频率、主目标、基准、模型预算、最低关注幅度与依据。周期bar数、决策频率、未来结果跨度分开，60日不能改称60周。附加期限/风险用途不得事后变主目标；至少保留一个简单对手，不为正结果搜索模型，预算内至多一个预定非线性检查。

Universe合同写：精确标的或动态入池规则、市场/类别、选择理由和时间、目标决策对象、成员来源/历史可用日期、实际逐资产区间、入退池、预热、缺失/停牌/退市/合并/改名、行动复权、完整日历、预设少量分层、主权重、验证身份和已有数据使用史。计算输入集合 `source/input universe` 与评价对象集合 `target/evaluation universe` 分开。资产身份与指数/ETF跟踪映射保留；相关代理不能当独立复现。

逐项列 `hypothesized_scope/tested_scope/supported_scope`。执行是否完成、效果是否获支持、覆盖是否回答是独立维度，复用既有状态枚举；覆盖事实写合同/报告，不强迫旧schema接受自造状态。没有证据支持的应用范围不标validated。

个股池优先可靠历史成分；或按当时上市状态与当时可知的规模/流动性动态选池，并承认不是指数成分。不能拿今天幸存/热门股票回看，上市/成立前不补价，退市收益缺失不填零或删身份。只有低频探测成员时须披露漏短暂变化风险，无法确认时暂停依赖该成员的检验。指数发布前回溯与发布后区间分列，价格/全收益/ETF经济价格不混称；筹码/量价不能拿无意义的指数成交字段代替。

先做 raw可用→指标可用→机会可用→标签成熟→共同模型可评价 的逐标的流水账，时间边界及每层排除不能省。已看过历史重新下载、换AI/文件名/相关资产不成为未见验证；预先冻结跨资产仅提供有限外推，不抹掉共同市场暴露。未来新观测可登记冻结起点，不把等未来资料当本轮不能结案。

主权重看结果前选定。同日资产等权再跨日平均、每资产日期平均再资产等权、逐行等权不是同一个答案。另报逐资产/共同支持，说明原组均值因组成不同不能拼回总体。日期整体切分，训练标签须在预测时成熟；跨边界清除、同日相关、单资产重叠、指数ETF关联均记录。推断用完整日历同步分块或适配的多维相关方法；块长顾及结果跨度，有限敏感性，不报伪精确独立样本数。

当前SMA方向等于当前价与N日前价的符号；标准EMA变化符号等于当前价与上一根EMA的关系，亦可推导当前价相对当前EMA。必须按实际种子/缺失公式核验，不靠名字猜。加入等价字段的改善可能只是模型表达优势，不是新增原始市场信息；无改善只限定所测基准和方法。

结论按问题×Universe×时期×基准×方法下达。支持、条件线索、当前未支持、证据不足、数据/定义阻塞均可关闭有界问题。只有范围精度足以排除预先关注的改善，才说本范围没有实际意义增量；不显著不证明无效。所有新资产/分层/目标/模型进入同一家族尝试账本，保留失败与旧历史；账本并不等于已自动校正多重挑选。

方法依据：跨资产和时间相关须共同处理，见[Petersen作者页](https://www.kellogg.northwestern.edu/faculty/petersen/htm/papers/standarderror.html)；全部已尝试技术规则的挑选偏差不能只看胜者，见[CEPR DP1976摘要](https://cepr.org/publications/dp1976)。本次仅核对官方摘要/方法提示，不声称完整复现论文统计过程或LEI有效。美国数据字段参考[当前CRSP官方入口](https://indexes.morningstar.com/research-data-products/crsp-us-stock-databases)，含在市与退出市场身份、行动/终止信息；没有购买、订阅或取受限数据授权。

本节仅新合同显式采用，question_contract.py等旧验证器未自动接入这些自然语言要求；需要人工复核与输入清单指纹。旧规范实际快照见`../experiments/raw/universe-scope-correction-2026-09-29/before/`。
