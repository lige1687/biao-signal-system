## 一句话结论（大白话）

把情绪页的两个信号——**情绪强度 b50**（板块内站上自身 50 日均线的股票占比，
≤20 机会位 / ≥80 压力位）和**散户净流入**（板块小单资金净流入，信号化成
20 日和的历史分位）——接进定投的买和卖，在半导体 ETF（512480）和有色 ETF
（512400）上实测（2023-07→2026-08，约 3.2 年）。四条判定、一条口径教训：

1. **"b50 机会位加码"看着赢实际没肉**：信号周投 2 倍，期末总钱多 21~22%——
   但这几乎全是"多投了本金"给的；按每一块钱算的年化只高 0.2~0.8 个点
   （和第六轮估值加码 +0~0.9% 一个量级）。而且本窗恰好是"2023-24 熊市触发
   在底部 + 右端 2024-09 大反弹"——第一轮行业 ETF 短样本伪象的同款结构，
   长窗翻案风险高。**读法：方向为正、幅度趋零、不采用。**
2. **"b50 压力位清仓"明确有害（判负扎实）**：b50≥80 清仓、b50≤50 买回，
   期末总钱少 30%~49%——牛市中段下车、反弹后追高买回，双向挨打，与第八/十三
   轮"宽度热出场砍牛腿"完全同构。**情绪页的压力位标签不适合当卖出指令。**
3. **散户净流入两个方向都不行**：加码方向（散户割肉时接）触发太少实测不足
   （扩展分位 P10 在窗内只出现 9 天，0/4 判负更多是数据覆盖问题——腾讯源
   约一半交易日缺数）；清仓方向（散户追高时跑）期末总钱少 18%~30%。
4. **门控式触发投（b50≤20 才开始投 12 个月）没翻案也没加分**（混合）——
   第十二轮"门控只新增现金闲置"的结论在本窗维持。
5. **口径教训（重要，登记给后续轮次）**：本轮预注册用"每一块钱的年化"
   （XIRR）当主指标，但这个指标对"清仓落袋+现金闲置"型策略会系统性虚高
   （本轮出现过年化 141% 的格子，期末总钱其实更少）——按预注册线"散户沸点
   清仓 3/4 成立"，按期末总钱 0/4 全输，两者矛盾时以口径缺陷解释，**最终
   读法=不采用**。后续同类实验应预注册"比入场用 XIRR（本金不同）、比出场
   用期末总钱（本金相同）"。

（b50=板块内收盘高于自身 50 日均线的成分股占比；机会位≤20/压力位≥80 为
情绪页阈值；散户净流入=板块小单净流入的 20 日滚动和；XIRR=资金加权年化，
即按每一块钱实际在场时间算的年化。）

## 1. 背景与问题

用户看到情绪页的「半导体/有色 · 价格×情绪对照」（b50 折线+散户净流入柱+
机会位/压力位阈值线），问能否结合定投制定买卖。此前定投线（一~十六轮）已
证伪全市场粒度的宽度/情绪/估值加减码与总开关，但**行业粒度+行业自有情绪
信号**未测过。本轮补测。信号口径以代码为准（`sector_trend.compute_breadth_
series`：b50=50 日均线宽度；`market_mood.py`：≤20 机会位 / ≥80 压力位；
散户流=`tx_sector_flow_pilot.json` 小单净流入）。

## 2. 口径

- 标的与信号：512480（BK1036 半导体，186 只成分）/ 512400（BK0478 有色，
  145 只）。半导体散户流 2022-09-09 即断（154 点）→ 不测流臂；有色流
  2021-08→2026-09（561 点，约半数交易日缺数→20 日和取稀疏口径 min_periods=10）。
- 价格=ETF 真实行情（backtest_pool，无合成前视）；b50=逐股日K+当前成分
  回溯合成（**含前视偏差**，模块自身声明口径，如实沿用）。
- 主窗=b50 首个可用日（实测 2023-07-05/07-12，成分回溯数据起点晚于名义窗）
  →2026-08-24，约 3.2 年。引擎沿十六轮骨架（周投、信号收盘判定次日开盘
  执行、费 10bp 双边、现金 0 收益）。
- 入场四臂：E0 平投 / E1 b50≤20 当周 2 倍 / E2（仅有色）20 日和≤扩展 P10
  当周 2 倍 / E3 b50≤20 触发后 252 根内周投（门控版）。出场四臂：X0 不退 /
  X1 +50% 止盈清仓+126 根回场（循环）/ X2 b50≥80 清仓+≤50 回场 / X3（仅有色）
  20 日和≥P90 清仓+≤P50 回场。
- 判定线（跑前写死）：赢=XIRR 更高且回撤不深于基准 2pp；格子赢率 ≥70% 成立 /
  ≤30% 判负 / 其余混合（占比制，半导体缺流臂如实计数）。
- 过程修复（判定标准未动，沿七/十六轮 bug 规程如实登记）：①信号映射 bug——
  b50 索引为 date 对象与行情 datetime 不匹配导致全部信号臂首轮空转，修复后
  重跑；②散户流原始 20 日和在稀疏数据上永不触发，改稀疏口径（min_periods=10
  + nanquantile）后才有有效信号。

## 4. 细读

1. **V1a 的"成立"要拆开看**：加码臂多花的钱 ≈ 触发周数×1 倍周额（半导体约
   +13% 本金），期末 +22% 里绝大部分是本金、小部分才是时机；同钱口径
   （XIRR）+0.25pp（半导体）/+0.83pp（有色）——第六轮估值加码的同款"方向
   正、幅度趋零"。叠加短窗结构（触发集中在 2023-24 熊市底部、右端恰是
   2024-09 起反弹），第一轮行业 ETF 伪象的教训直接适用，不采用、待长窗。
2. **V2b 是本轮最扎实的判负**：b50≥80 清仓把 2024-09 后的行业主升段切成
   "下车—追高—再下车"，终值近乎腰斩；唯一收获是回撤浅 15~19pp——又一例
   "拿收益买安心"，且代价（−30%~−49%）远大于第八轮总开关。情绪页压力位
   标签的正确用途是**叙事提示**（追高风险），不是卖出指令。
3. **XIRR 对清仓型臂失真**（本轮方法论教训）：X1/X2/X3 都含"清仓落袋+现金
   0 收益闲置"，资金加权口径把早期落袋的收益放大（141% 的格子即此），期末
   总钱口径才是"定投者期末财富"。两口径矛盾时后者为准；后续轮次预注册应
   分维选指标（入场臂本金不同→XIRR；出场臂本金相同→终值）。
4. **散户流信号在本数据上不可判**：加码方向触发太少（9 天），清仓方向触发
   够（85 天）但效果为大负。加上半导体流 2022-09 断供，"散户净流入"目前
   不具备接进定投的证据基础；它作为情绪页叙事层继续用没问题。
