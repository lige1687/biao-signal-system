# E01 独立复核：真实冻结路径闭合，缺价等待行为需补齐

日期：2026-09-08。范围仅为 E01 研究复核，不是生产验收，不包含 E02 或其他新增研究。原方案、澄清、源码、结果均保留；本复核只写 `review/`。

## 一句话结论（大白话）

原146个机会都能对上，时间修正后58个机会的退出发生变化，平均收益差为增加1.62394个百分点；64条同预算账户路径也能从每笔钱重新算出来。这个结论在冻结历史和报价假设内成立，不代表之后一定更赚钱。另发现缺开盘报价时买卖安排会丢失，当前真实输入没有这种缺价，因此保留现有路径；以后处理缺价前必须补好等待执行，并重新检查。

## 1. 核查方法与版本

- 主复核 `independent_check.py` **未导入、未调用**原研究引擎：重新读行情和旧归档，以独立算术计算份额、退出条件、费用，再逐动作重建全部账户现金和持仓。
- `events_check.py` 使用明确的向后200/500行窗口与自然月末日期，独立重建触发记录；没有读取评价日之后的价格来计算该日条件。
- `missing_open_probe.py` 只抽取冻结函数做合成缺开盘反例，不调用主流程或落盘函数。这部分是针对原函数的最小行为验证，与前述独立算术区分。
- 核查版本 `run_e01.py` SHA256：`ba95b58cfbefae8b0c4162d0f3a038dda203f3d428c77c59ae73f6e31b5f61d8`。全部被读输入及原结果摘要在 `independent-results.json.source_sha256`；核查前后原文件未变。
- 结果文件为 `independent-results.json`、`independent-paired.csv`、`events-check-results.json`、`missing-open-results.json`。最后两项缺价检查不覆盖随后修订版本。

## 2. 146个旧机会和修正差异

独立计算在原10bp费用（每次买卖按金额收0.1%的研究情景）下，146个旧Xtarget记录的退出日期、净收益、是否到最大期限退出、持有长度**全部对账**。不是只复算汇总，也不只用原作者同一函数跑两遍。

独立核查两个费用情景共292对；与原交付配对CSV的收益最大差为 `8.88e-16`，日期完全一致。

原10bp的时间修正结果：

| 项目 | 独立核查 |
|---|---:|
| 配对机会数 | 146 |
| 退出日期改变 | 58 |
| 全部146个机会的平均净收益差 | +0.016239395708984854，即+1.6239395709个百分点 |
| 配对差异中位数 | 0 |
| 增加／减少／不变 | 58／0／88 |

可以说“修正该批历史记录的成交信息顺序后，平均数发生了上述变化”。不能说“新策略未来增加1.62个百分点收益”，也不能说58次变化是58次独立市场试验。这里仍保留原方案的历史价格对齐方式和按未来可见周数平分独立计划预算，只为定位时间差；原历史已被看过，并非未参与研究选择的新时期。

## 3. 64个账户的预算、现金和时间

从各账户独立的1单位现金开始，按交付动作与冻结价格逐项重建，核对：

- 64账户均只有最初1单位外部入金，无追加外部资金或把卖出款当入金；所有方法在相同对象内使用相同起止日。
- 新计划预算等于可用现金；每笔不超过计划预算的1/52，最多52次；同日合并执行多个此前周日排程，也逐笔计数，没有多给预算。
- 同对象同方法计划不重叠；占资期间事件拒绝，退出之前形成的新事件没有被事后排队补入。
- 买入安排晚于计划触发，来自此前周日23:59；实际购买落在第1至252个报价日内的后续首个报价日。当前输入每个开盘均有效。
- 所有目标卖出在第253个报价日起，用前日收盘验证30%条件，再按当日开盘执行；到期退出不早于第756个报价日。
- 逐笔费用、份额、现金、每日资产和期末总资产闭合，无负现金。全部账户的最大累计数值误差为 `1.1962e-11`，小于冻结的 `1e-10` 限度。
- 32组对象×进入方法共580条占资过滤前事件，独立用向后窗口与自然日时间表重建，**32组全部与冻结事件一致**；两个费用情景复用事件，不把1160条重复计数当独立机会。

支持的结论是：**这份实际无缺开收盘的冻结资料下，没有发现资金重复使用或计算条件时读取未来价格的问题。** 这不证明历史宽度当时已经公开、当前成分回算没有偏差，也不证明报价日期等于完整交易所日历。这些来源条件尚未核实，不能省略“历史报价代理”的限制。

本复核首先是核账与信息顺序检查；没有把64条不同方法/费用路径拼成用户组合，也没有将其财富与第一阶段独立计划平均数当同一指标比较。

## 4. 两个必要修正：缺价不应让已安排动作消失

复例共同输入：900个工作日，2020-01-01起，开收盘均为1，最初事件 e=0，费用0；其余参数不变。

### 已安排购买遇到空开盘

只将2020-01-06开盘设为空。2020-01-05周日23:59已经排程，2020-01-07有有效开盘。

- 冻结方案预期：保留这次排程，1月7日执行，仍遵守52次与第252日报价期限。
- v1实际：1月6日跳过，排程消失，首次购买直到下一周1月13日。

需要保存未执行的周排程；只在下一有效开盘执行，超过建仓期限或计划已结束则明确取消并留痕。不能为了补单越过预算和52次上限。

### 已触发目标卖出遇到空开盘

第252行（2020-12-18）收盘设为2，已达到目标；第253行（12月21日）开盘为空，12月22日开盘恢复1，其余收盘恢复1。

- 冻结方案预期：目标已经在12月18日收盘成立，保留待卖安排，12月22日首个有效开盘卖出。
- v1实际：12月21日不能卖；之后重新计算时目标已不满足，原安排被遗忘，直到2022-11-24最大期限才卖。

需要固定触发时点与理由，之后等待有效开盘；不得因为等待期间价格变了就悄悄撤销原退出决定。修正后应同时检验排程取消、到期冲突、数据截止仍未执行的留痕。

**当前真实八份报价预检均无缺开收盘，上述是合成边界，不能将64条实际路径判为因此失效。** 建议保留v1全部数字，另存修订；缺价反例通过并确认原64路径不变后，再扩大“能处理缺价”的说法。

## 5. 三种结论强度要分开

1. **可重复：** 本复核独立算术支持原146条对账、两费用292对、64账户现金链和32组事件，达到限定范围的重复与核账要求。
2. **方法正确：** 实际无缺价路径的信息和资金顺序得到支持；已证明两个缺开盘场景不符合固定方案，修订前只接受当前无缺价输入范围。指标解释、完整来源时间、真实产品约束仍不能靠数值对账证明。
3. **实盘适用：** 未成立。本轮仍是既有历史的准确性审计，没有真实基金/指数代理映射、分红复权与费用、停牌涨跌停等成交条件的完整验证，也没有随后新行情的证据；没有同预算旧方案对照来证明资金版本带来收益增量。

首轮审计可收窄旧引用、指出须补测之处；不得自动改变生产证据状态或真实交易规则。待修订复核另记，不覆盖本报告的v1结论。
