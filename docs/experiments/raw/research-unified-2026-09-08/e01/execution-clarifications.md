# E01执行前细节固定

2026-09-08，尚未查看本次全对象修正或资金路径结果。沿用首轮冻结v1，不扩参数。以下解决实现歧义，不追认历史为新验证。

1. 八对象公共截止取各自价格与宽度实际可用末日较早者；起点取该对象MA200、近500条最高价（最少100条）及宽度首次同时可计算日，保留前面数据预热，所有方法在该对象用同一起止日。来源为报价日代理，无真实交易所日历确认。
2. 第二阶段在完整价格索引上左接宽度。deep20只需有效价格/MA200；bottom需有效价格/MA200/最高价/宽度；lowtier只需有效宽度。状态未知后首次真值不触发，必须前一相邻报价日为已知假。base于自然月末23:59起算，按当时最后已知报价索引执行126条冷却。其他条件在收盘16:00形成。各条件冷却都按全部触发记录计算，包括占资被拒绝者。
3. 周日23:59安排，买入在之后第一个有效开盘；安排必须晚于计划触发。每笔预算1/52，最多52笔，只在(e,e+252]内买，余款留现金。从e+253开始可退出，最长e+756。退出目标分母是实际买入支出含买费，未投入现金另计。数据末尾只估值。
4. 新触发在开盘执行动作之前按触发时的持仓状态接受/拒绝；已有计划即拒绝，即便卖出已安排也不排队。单个对象单个方法一份预算，完全退出后下一新触发可用当前全部现金开始新计划。不同对象不同方法不拼组合。
5. 第一阶段原146机会只比较旧Xtarget与滞后一日信息的Xtarget，10/20bp两个成本情景。原10bp先对账，任何不一致先停止该对象解释，不跨数据版本混算收益；若缺原日期就保留不可核验。
6. 主要目的仍为准确性；不加入统计成立阈值。第二阶段各方法的账户财富不拿来和旧逐笔平均数当同一指标。没有原同预算基准就不宣称方法提高收益。报告均值/中位/严重亏损/持有和恢复/现金占用/已完成与末尾，波动同期性未知不称独立证据。
