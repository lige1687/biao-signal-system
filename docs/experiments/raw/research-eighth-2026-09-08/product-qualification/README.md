# 第八批四基金资料与执行限制核对 · 2026-09-08

## 一句话结论（大白话）

现有资料足以在2015年1月1日至2026年6月30日做明确标注近似条件的四基金模拟：分红、已知拆分和两次确定停复牌都有出处，原报价没有发现未解释的明显越界。仍不能叫完整交易还原：部分年份没有逐年核完拆分，交易日历与日内暂停没有完整覆盖，成交量的绝对单位也未最终确认。遇到这些边界要按下面的限制处理，不能把未知写成没有。

本项服务交易规格§3.2的当时可知与价格一致性，以及§3.3的停牌和成交处理。没有产生候选信号、仓位或策略收益；没有修改正式规格、旧封存、生产或目标台账。

## 公司行动覆盖到底到哪

三只无现金分红基金的正式报告已逐段接到2026-06-30，没有现金覆盖空缺。510300的完整性依据是两个公开分红列表相互对应、每条均有原公告，并由名义价与供应商复权差异交叉检查；它不同于交易所出具的连续“无其他事件”证明。2020不另造现金事件，2025分红发生在6月，不能搬到1月。

各份年报“过去三年未分红”只支持现金分红，不支持三年没有拆分。仍缺逐年拆分原段的期间为：

| 产品 | 尚未得到逐年正式拆分覆盖的研究年份 |
|---|---|
| 510300 | 2015—2025及2026上半年 |
| 159915 | 2015、2017、2019、2021、2023—2024 |
| 518880 | 2015、2017—2018、2020—2021、2023—2024 |
| 513100 | 2015、2017—2018、2020—2021、2023—2024 |

`action-coverage.json`保留这些确切未知区间，没有将它们补成零。普通基金申购赎回造成总份额变化，不是每个持有人都自动变更份额，不能据总份额变化臆造拆分。

为判断是否能先做有限研究，本次独立对照已有名义OHLC和供应商旧复权OHLC，共51,496个价格字段。已知分红/拆分能解释二者差异：510300、159915、518880最大误差为0；513100为0.0004元，低于报价0.001元的半个最小变动单位。此交叉检查支持使用已知事件的研究近似，**不能证明供应商没有和我们一起漏掉某个事件**。旧供应商现金复权是加法，不能当成本轮比例法；这份旧复权价仅作为资料核对，不用于候选生成。

## 必须执行的日历与报价限制

| 产品/日期 | 有据可查的事实或明确缺口 | 本轮模拟处理 |
|---|---|---|
| 159915，2021-02-08 | 实际暂停，原行情无报价 | 不买不卖；保留日期和旧估值 |
| 159915，2021-02-09 | 官方公告说明10:30才恢复 | 不模拟当天开盘买卖；实际收盘可估值 |
| 513100，2022-01-13 | 拆分日暂停，原行情无报价 | 当天持份乘5、旧估值价格除5；不交易、不造K线 |
| 513100，2022-01-14 | 有真实恢复报价；交易所当天限价参考未核准 | 整日跳过模拟买卖，实际收盘可估值；不是说现实当天停牌 |
| 513100，2025-04-07 | 完整日线只有1.272一个价格 | 只作收盘后诊断，不能反推开盘已知“一整天一价” |

前四项已写入`blocked_dates`，研究负责人已在候选结果之前接受1月14日的保守限制。

拆分后1月14日必须区分三个数字：此前市场收盘5.192除5为1.0384，用于持份和旧估值换单位；年报列出的拆分后基金净值是1.009；当天市场开盘是1.010。不能把市场价、基金净值和交易所规定的限价参考当同一个数字。未核到后者，就不靠猜测安排这一天成交。

513100的2025-04-07开盘1.272，按此前已知收盘1.413及普通10%限制、四舍五入到0.001元，恰好在跌停参考价。因此开盘方向检查拒绝模拟卖出；该判断无需读取当日最高、最低或收盘。买入侧只说未被这个价格条件挡住，不保证订单深度或足量成交。

四基金观察日期合起来只有上述两条产品缺报价。这个“观察日期集合”不是正式完整交易日历；全市场共同缺失的日期，以及当天有价格但中途暂停的情况，不能用此方法排除。缺报价不能压缩掉日期后擅自提前下次成交。

## 哪些能先做，哪些必须停止

**可以先做的有限模拟**：仅这四产品、这个窗口；现金只按已核事件，按登记持份确认权益；拆分按已核生效日改变持份；价格使用冻结比例转换；执行采用指定停复牌限制、当日开盘与此前参考价；缺价只保留估值，不造成交；成交量只做比率；标注“已知事件、日线成交近似、完整事件资料尚未覆盖”。

**必须停止的情况**：指纹变动；基金代码或报价单位不一致；新增无法解释的价格/份额行动；现金覆盖越过2026-06-30；要在未知限价参考日期成交；读取当天完整OHLC来决定开盘行动；需要绝对量决定成交但单位仍未知；重复/冲突行动、分红参照价陈旧；将此包称为完整可实际执行服务。价格转换器自身仍按第七批检查拒绝其已知坏输入。

如要求全期正式公司行动完整，就需补表中明确年份的份额变动原段或正式完整行动源，不能凭已知行情没有大跳变豁免。若只做本轮已接受的有限模拟，不再无限搜索多年公告；保留未知区间及上面的降级表述即可。是否通过新的技术账户会计检查，由账户研究另外验证，本包不替它放行。
