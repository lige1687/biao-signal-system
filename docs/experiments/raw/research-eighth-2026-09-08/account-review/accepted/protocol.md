# 第八批：修正研究执行差异后的有限技术账户比较

日期：2026-09-08。当前用户授权原话：“那继续”。本文件在查看本批候选数量和收益之前固定；实际源码、输入与参数另在执行前保存指纹。沿用第六批草案的8个配置上限，任何变更另留记录，不覆盖已封存批次。

## 要回答的问题和规则依据

在固定四只基金与相同模拟收入下，均线密集突破的研究实现，相比普通突破及简单方向判断，实际能参与多少机会、账户有什么变化？先修复第七批定位的三项执行差异，再比较；不带着已知错误给收益排名。

依据策略规格§2.3进出同一逻辑、§3当时数据和一致复权、§9 B、§10/§13目标风险纪律、§16统计。MACD不作买卖点，基本面和消息不参与过滤。本轮仅研究副本，不改正式规则、网页、账本、通知或OKR；目标进度仍须先向用户提出具体更新范围。

## 明确降低的主张范围

本轮名称为“修正后的B研究代理与简单办法的有限账户比较”。九条无交易纪律仍有缺项，不能冠名完整B已实现。修复突破版误用埋伏退出、实际开盘风险比复核、初始无效预热计龄；不自行补造缺失纪律，也不调126根/2%等现有阈值。

历史公司行为、正式交易日历及个人实际费用未全覆盖。使用已核现金分红、已知拆分及停复牌例外，输出带日线成交近似的模拟。资格检查如发现无法解释的价格跳变或行动金额冲突，则停止运行，不把未知补成零。已核现金覆盖与第三方价格调整交叉核对，不等于全部公司行为原始公告全集。

## 固定研究选择

- 产品：510300、159915、518880、513100，人民币；2015-01-01至2026-06-30。早前已有日线只作预热。既往已看过这些历史，整段均为历史描述，不宣称全新数据检验。
- 每周一各产品新到账250元；产品间不借钱。每次买入取100份的整数倍，卖出全部当前份额；现金零利息，单边成本为成交额0.1%，无最低收费。这是研究情景，不是用户真实资金或费率。
- 技术价格采用第七批 `cash_proportional_v1`：现金除息按前名义收盘缩放，拆分按比例换单位。理由是在同一已知历史段内保留原规则的百分比关系，未依据收益选择。只用当时公告且生效事件；保存每个历史决策日期的版本，不把终点复权价当早年名义成交价。
- 技术结构和目标均在信号日保存为该日名义单位，之后仅随已生效公司行动换单位；这不是亏损后移动失效理由。账户独立记真实名义金额、现金、持份和应收，不能从技术价格收益再加一次股息。
- 全部技术配置在信号收盘和指定开盘各检查潜在盈利/预设亏损至少3；目标缺失则拒绝并保留。目标使用冻结现有优先级：已确认高点、成交量分布代理、之前60根高点；可选缺口档沿默认关闭，上方密集区档未实现。保留来源和确认时间，不临时挑更高目标。
- B显式使用 `entry_variant=breakout`，当前规则账本2.1.0，密集规则2.0.0及原126根/2%。不使用未指定变体时的埋伏默认，不拿旧较宽阈值替换零信号结果。

## 八个配置（一个资金情景，禁止参数搜索）

| 配置 | 入场原始候选 | 初始失效与退出 |
|---|---|---|
| P0 | 收盘严格高于之前60根收盘最高值 | 前60根最低收盘为失效；否则收盘同时低于EMA20及20根前收盘退出 |
| P1 | P0且收盘高于EMA20及20根前收盘 | 同P0 |
| P2 | 修正后B突破候选 | 用P0统一研究失效位与退出，只比较入场部件 |
| P3 | 同P2原始候选 | 改用B结构失效位，其余同P2 |
| P4 | 同P2原始候选 | B结构失效；否则跌回锁定突破上沿且EMA20、SMA20都下弯才退出 |
| P5 | 收盘高于EMA20及20根前收盘，从不满足变为满足 | 同P0 |
| P6 | 被动参照，有现金且可成交则继续买入 | 不技术退出，末尾保留持仓 |
| P7 | 同P4 | 仅投入量改变：前一有效收盘该产品净值的1%作为计划亏损金额，并受现金与整手约束 |

所有技术配置至少有120根完成报价才能形成候选，缺失均线/目标有明确空值。P0严格突破可连续多日出现，持仓期间全部留下“已有持仓”记录，不重复持有；P5只在状态新转入时产生候选。P2与P1机会不相同，不能把它们的差额都说成相同入场下的改善。

## 日期和执行状态

取四产品报价日期的并集作为本次指定开盘日期参照，它是数据近似而非正式交易日历。信号只在当日收盘后可用，下一个参照日只尝试一次买入；该产品无价、已知禁止开盘、开盘受限或资金不足则作废，不挪到更晚好价格。退出保持待卖状态，直到可交易开盘；期间不取消退出或新买。若最后一天无下个参照日，保存末尾待处理。

日内顺序：公司行动与支付→周一到账→此前退出/买入委托→当日收盘估值和退出决定→登记日持份锁权。全体技术配置采取保守次日卖出约定，买入日收盘可决定退出，最早次日开盘卖；同日卖出后不能再买同产品。结构退出统一为收盘低于失效位优先，下一可开盘卖；不新增独立盘中低价或开盘硬止损。达到目标只用于入场空间检查，不作为固定止盈。

价格限制近似沿第五批（159915在2020-08-24前10%、后20%，其余10%；开盘距前参考到限制附近双向保守拒绝），已知159915 2021-02-08/09及513100 2022-01-13禁止模拟开盘成交；待资料核验附确切来源。无价日只保留单位调整后的旧估值，标记陈旧，不能制造一根可成交价格。

分红按登记日持份确定权益，除息记应收，支付转现金；支付日开盘前可用是研究假设。拆分即使无价也更改持份和水平线；在缺价日不交易。新到账现金、应收、尚持资产全部进入财富，入金独立记账，计算投资损失时排除入金抬高账户的影响。

## 先检查，再运行

先保留原B反例失败、修正后通过；再测技术账户关键分支：缺目标、跳空、重复候选、当日买卖限制、退出延期、分红权益、无价拆分、尾部、到账日休市、整手和风险预算。价格日期截断在既定行动边界及每个年份首个报价日复查：只给截至当天的资料，应得到相同的已知特征和候选。

输出全候选并集、各配置接受/拒绝原因、订单、成交、持份与逐日资金记录。主程序逐日检查会计恒等式；根独立重建每个配置的名义买卖现金、持份、分红、全部日终财富，不只重复运行同一引擎。任何错误先保留失败、修正实现并说明，不因成绩改变规则。

最多8个完整历史路径，每路径4只产品；三段2015—2019/2020—2022/2023—2026H1和年度仅汇总已有路径，不重新调参或再建账户。共同市场日期与时期依赖保留；本轮不重复月份抽样，不输出显著性或未来获胜概率。

## 结果和采用边界

主结果：P4相对P0/P5的同投入期末财富差额，同时报告投资净值从高点最大跌幅、未恢复时间、低于累计入金额最差值、费用、操作次数、资金占用及现金。部件对应另外列P1−P0、P3−P2、P4−P3、P7−P4，明确路径和资金差异。

已完成交易报扣费并含有权红利的净收益金额、平均/中位、最差笔数和持有时间；未结束持仓单列，不计交易胜率。若没有交易就报告零，不放宽阈值。不能仅由没有合格机会判定B在所有市场无效，也不能用P6的长持收益反证不同风险用途没有价值。

用户尚未选择值得交换的收益、跌幅和操作成本，所以没有自动“采用”通过线。本批只交有限研究及独立核对，正式规则、全部A/C/D、真实个人费用与未来观察仍未完成。
