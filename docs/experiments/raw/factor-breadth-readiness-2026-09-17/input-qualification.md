# input-qualification — 沪深300宽度历史输入资格盘点（只读）

日期：2026-09-17。执行：GLM-5.3-Flash（ZCode 委派 round 1）。本轮只做本地读取与结构统计，
未重算任何宽度/状态/目标/收益，未联网。

## 一句话结论（大白话）

「宽度」= 一个指数的成分股里，有多少比例的股票价格站在自己的均线之上。本轮查清：
沪深300宽度存在一条由**历史时点名单（构建方式为每 20 个交易日探测+变化区间二分，
再填充出每日名单；272 次查询不等于 2,813 天逐日核验）**生成的冻结序列，2015-02-09 到
2026-06-30 之间有 2,378 个有效日（该 valid 计数是旧实现字段，不构成新用途授权）。
它属于**候选材料**：做历史描述仍受来源、成员与覆盖三重限制，下一次分析尚未批准；
而"历史上每一天当时就能拿到数据"没有任何证据——所以「当时可知的预测研究」资格
**未核验**，不能直接开算。旧实验自评的 B 档只说明旧实验当时的用途限定，不是本轮
或后续研究的使用许可。

## 2. 成员名单资格（csi300 链）

- **来源与构建方式**：`prepare_data.py:231-291`。对 baostock
  `query_hs300_stocks` 按**每 20 个交易日一格探测、变化区间二分定位首个生效日**，
  再用探测到的名单段**填充**出逐日成员表；全程 272 次查询。**272 次查询不等于
  2,813 天逐日核验**；未探测日与区间内的名单状态是填充结果，非逐日查询结果。
- **产物**：`csi300_membership_daily.parquet` = 843,900 行 = 2,813 个交易日 × 300 只整
  （每天恰好 300 只），2014-12-01 → 2026-06-30，累计 **682 个不同代码**，31 个名单
  版本，无重复 (date,symbol) 键、无空值。682>300 证明名单**不恒定**；它不能证明
  每一天名单正确，也不能证明当时可得。
- **生效时间**：探测到 30 个名单变更日（**供应商查询结果**；其中含 2015-01-26、
  2017-02-20、2023-03-20、2025-09-08 等非半年调整窗日期，出现原因本轮不解释、
  不补理由；全表见 probe audit）。变更在探测到的首个交易日整体切换。名单内**不保存
  公告日**；协议要求「公告日与生效日分别保存」，csi300 链只落实了生效日；
  与指数公告的逐条核对**未做**。`prepared/sources/` 的 33 份公告原件属创业板链证据，
  与 csi300 生效日未建立逐条对应。
- **已知盲区（audit 文件自带）**：若成分在同一个 20 日探测区间内"离开又回来"，
  端点比较检测不到——盲区存在但规模未知。
- **未知（保持未知）**：baostock 该接口返回的是"查询当日视角的名单"还是"事后修订
  过的名单"，无供应商认证；本轮未联网验证。填充产生的名单在未被探测日上与真实
  历史名单是否一致，同样未知。

## 4. 价格数据资格（本轮最重要的发现）

**冻结的沪深300宽度序列的价格底表是「当前存续个股」回填缓存；已见一条前复权（qfq）
生成路径；协议/登记 profile 的「后复权」声明与已见代码路径矛盾，实际逐列复权口径
未经追溯证实。**证据链：

1. `prepare_data.py` main()（L341-351）：`panel = pd.read_parquet(ALL_A_PANEL)`，
   注释原话 "Reuse the already-audited long-history panel. **It is a current-list
   backfill**, so missing old constituents lower coverage and keep the result at
   grade B"；随后 `breadth_from_close_panel(panel…, csi300_membership)`。
2. `ALL_A_PANEL = ~/.lei_signal_lab/cache/a_share_klines_full.parquet`（L32）。
3. **已见一条 qfq 生成路径**：`scripts/backfill_breadth_full.py` 的 `_fetch_cn_close`
   请求 `ak.stock_zh_a_daily(adjust="qfq")`（L88）；`_fetch_all` 会读取旧缓存并
   **跳过已有代码**（续传）。因此：该路径存在且请求 qfq，但**不能单凭它证明缓存中
   所有列都由该路径产生、来自同一抓取日期或同一复权锚**——缓存是多次增量写成的，
   列级来源未追溯。
4. `fetch_constituent_prices`（baostock 后复权）在 `prepare_data.py`（L294-305）中
   **未被 main() 调用**——死代码，不构成"实现使用了后复权"的证据。
5. 结论：协议/`profiles.breadth.price_basis`（"指数成分为冻结后复权连续价"）与
   已见实现路径**存在来源声明矛盾**；矛盾成立，但"实际就是 qfq"只对已见路径成立，
   逐列证实需要追溯（本轮无此预算，也不追加计算解决）。

**影响分层（如实区分，不夸大也不掩盖）**：

- 条件性数学事实：**若**满足"有限正价、同一日历、同一成员规范"这些前提，同一序列乘
  正常数不改变"P 是否高于均线"。主控确认的是这一**有前提的公式关系**本身，
  并未对真实底表逐列确认这些前提成立——前提在真实输入上是否满足，仍是未核项。
  且该数学事实**不能**证明供应商 qfq 与 hfq 实际逐值等价、**不能**证明复权修订
  无影响、也**不能**推出"差异影响有限"。
- 真实缺陷一（成员×价格错配）：底表是当前存续回填，历史退出成员可能整列缺失 →
  计入当日名单总数（pool_total）却无法合格 → 压低覆盖率、缩小 E200。名单是探测
  填充的历史名单，价格是存续回填缓存——**分子分母的股票集合并不是同一套数据底表**。
  早年覆盖率最低 0.64；**逐产品的原因未核实**，可能机制包括退市成员缺价、
  新股不足 200 日等，本轮不归因具体占比。
- 真实缺陷二（底表与当时价格的一致性未证明）：底表逐列口径未追溯，
  **无法证明**其绝对价位与历史当时价格一致；影响取决于实际口径与用途——若未来
  复用该底表做价格类因子，须先补齐口径证据。抓取日期分布未逐列记录，锚点时点未知。
- protocol/profile 声明与实现的矛盾**本轮不改代码、不改登记表**，提请主控裁定：
  是追溯列级口径后修正声明，还是补数据重建，或维持矛盾记录并限制用途。

## 5. 缺失、停牌、退市、公司行动

- 引擎层（`research_engine.py:16-62` + `_valid_quote_sma`）：缺失=显式 NaN，不前向
  填充；停牌日若无报价行即当日不合格；SMA 只用有效报价滚动（跳过 NaN，不补）；
  新股不足 200 个有效收盘不合格；当日合格集 E200 为空或覆盖 <0.90 → 当日宽度为
  缺失值并带原因（绝不把缺失当 0 或当弱）。
- 数据层：停牌日面板里到底是"缺行"还是"带标记行"未逐日核验。已见 qfq 生成路径
  与死代码里的 tradestatus 字段都**没有**落进实际底表的证据链；实际底表（候选路径
  akshare 新浪）的停牌呈现未知。
- 公司行动：若底表确为复权价则经复权吸收（口径见 §4，逐列未追溯）；分红造成的
  价格跳跃对"是否高于均线"的影响预期被复权平滑，但供应商复权实现本身未独立复核。

## 6. 时间证据（观测/抓取/当时可得）

- **观测时间**：日收盘（profile.breadth.time：t 收盘观测，Asia/Shanghai）。
- **抓取时间**：文件 mtime 显示 2026-09-09 18:00-18:16，probe audit 记录 272 次查询
  发生在一轮运行内；但 **mtime 不是抓取行为的证明**，运行的具体时刻无原始记录。
  运行日期 2026-09-09 由实验命名、冻结声明与 mtime 共同间接指向，无独立原始命令
  输出留存（原始输出未归档，不能补造）。
- **当时可得时间（available_at）**：**无任何证据**。verify 脚本生成的 manifest
  明文 `historical_available_at: "unknown: sources do not certify vendor arrival
  timestamps"`。历史每一天的名单/价格当时何时可得，供应商不认证，本轮也不伪造。
- 结论：该序列自带的资格证据只支持"2026-09-09 前后用供应商查询+探测填充重建"，
  不支持"历史上当时可知"；即便未来双源核对一致，也只证明内容一致，
  仍不构成历史可得时点证据。
