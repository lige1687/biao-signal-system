# 技术单环节实验准备

范围：只复用已封存两ETF的候选、订单和持仓，不重新生成信号。按产品及配置列原确认候选、信号日拒绝、后续持仓/开盘拒绝、成交及期末等待；两费用分列，不重复计为独立机会。零候选只能说该固定识别版本没有确认入场，不能从中计算所有原始形态的缺失比例。

已有内容检查后拟选一个问题：简单道路参照R1的“收盘同时低于EMA20和20根前收盘就退出”相对只保留初始失效保护的贡献。选R1因总控要求拆分其效果、实际机会比A充分，原A退出已在四基金持续入金下做过，不重复把它当新问题。本问题是研究参照的机制检查，不取消正式纪律、不冒称整个A/B/C/D或新的正式系统。

根负责人先查看旧阶段数量用于选题；不能把随后保存的细分汇总说成未见数据的预先检验。单环节新收益须另冻结协议后运行。当前目录只存来源指纹、数量分解和选题依据，后续新收益另目录。
