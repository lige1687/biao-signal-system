## 执行顺序与比较纪律

S01宽度绝对水平 → S02变化／恢复 → S03AAII → S04NAAIM → S05Put/Call → 单独因子对照 → 两两新增帮助 → 原LEI组合。S06—S10只作扩展候选，标`SOURCE=extension`，核心尚未完成时不启动。

每个新问题先写明：它描述现在，还是研究将来的方向、涨跌幅、大跌或波动；连续值先保留，15/85、AAII±25、NAAIM40/100、Equity Put/Call>1只记`original_LEI_threshold`，不宣称最佳。10个百分点区间是关系展示，不从十组中挑最漂亮组推广交易。

资料合格后才冻结实际实验：各期限的起止端点、价格口径、日期全集、事件去重、费用是否适用、已有基线、参数版本、预算、失败条件。极端状态同时报告普通时期本来如何，并保留事件行、日期、连续极端段及目标重叠。连续关系与极端关系分别研究，线性结果失败不能否定只在尾部有用的情况。

相对已有信息的检查至少区分近期1／3个月涨跌、趋势、从既有高点跌了多少、近期波动。控制哪些、没控制哪些都明示；同期差异不称独立预测，预测结果不称因果。加入候选后与仅基线比较严格同日期，先报告真实差值及其单位，再报告不确定范围与反例。

本库没有真正新资料验证。旧历史曾看过，不能把按年代切开的已见资料重新命名为“从未看过”。参数、市场或期限更新另记版本；跨SPY／QQQ也可能共享大量行情，不能当完全独立证据。稳定结论须同时有年代、市场状态与合理相邻参数核查，不为了负结果搜参数。

只有信息价值得到相应证据后再讨论策略。完整策略另核全部资金、费用、等待和错过上涨，至少对照持有、定投、原LEI规则、研究新规则。本库不下单、不改生产、不把资料审计当策略准入。
