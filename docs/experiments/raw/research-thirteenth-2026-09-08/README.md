## 一句话结论（大白话）

六种A各比两种退出已经计算与独立复核。A20新增道路退出后，最大投资跌幅约10.9%降至5.7%，但每组期末少18.46万元；其余四组无差异。要把少跌与少赚一起看，不能直接宣布升级成功。

主报告：`../../a-road-exit-account-comparison-2026-09-08.md`。

- `protocol.md`、`configurations.json`、`initial-lock.json`：新结果出现前固定范围与指纹；已知旧历史，不冒称未来检验。
- `source-audit.md`：策略A6①、结构保护、20报价根、EMA种子、下一开盘的来源。
- `paper-methods/`：Kaminski/Lo 2014正式PDF、文本、原文方法核读、只读Zotero对应项；不是全文精读或作者复现。
- `execution/account-results/{S,T}/`：每方法六账户的候选、全部订单/拒绝、成交、日账、行动、持仓及年度/基金贡献。S纯结构，T结构加道路退出。
- `execution/fixed-17-paths.json`、`fixed-17-comparison.csv`：固定原17买入日期、价格、数量的两条路径；卖后零息现金，不再次买入。
- `independent-review/`：独立EMA/抵扣价、日账、订单、最早退出、汇总、固定数量路径。所有接受副本与首次检查失败均保留。
- `pre-run-review.md`、`supplemental-tests/`：运行前草稿问题、修正要求与额外分红到账反例；负责人7项测试通过。
- `evidence-cards.json`：沿既有证据契约给出的两条有限研究结论。
- `root-verification.json`、`final-manifest.json`：最终核对与文件封存；共享registry/INDEX、实时OKR不在不可变清单。

执行者在独立接受快照之后改名一份旧失败日志、移除两份编译缓存；独立快照仍完整保留原字节，经济与代码来源不变。原路径变化必须按独立完整性记录披露，不把它写成无保留的“全部路径未变”。旧完整运行因补测试后指纹变化而重跑也保留，不将重复运行视作额外独立研究。

本批未修改生产、实际交易或OKR；Spark短窗额度用尽，Sol执行/来源审计，主模型研究取舍与独立复核。没有重置或购买额度。
