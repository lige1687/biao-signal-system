# 第十三批独立核查

## 一句话结论（大白话）

本目录核查“增加道路走弱退出后，何时能卖、卖后钱是否算对”。道路、12账户资金/订单和原17笔两种退出路径已经全量核对一致；结果与边界见 `review-2026-09-08.md`，机器摘要见 `summary.json`。

## 范围和独立性

- 服务规格 §3.2/§3.3、A5/A6①及③、§14/§20：使用当日已知价格和公司行动，收盘出现条件后最早下一可用开盘执行。
- `verify_observations.py` 是本批新写的独立递推：40位十进制定点计算、最初20根收盘平均数起算、之后权重2/21。行动生效时，只调整此前均线状态和过去20根报价；不读取未来价格来判断当前道路，不导入原价格帮助器、指标、目标或信号算法。
- `verify_accounts.py`、`verify_orders.py`、`verify_summaries.py` 复用第十二批 `independent-review/precision-addendum/` 已验核查器。资金核查仍由十进制资金簿依据原行情、行动及实际成交单独重建，**不导入或执行账户引擎**。本批改动是六配置×S/T目录和T退出条件。
- `verify_orders.py` 用独立重建的道路布尔值，核持有期最早收盘触发；结构失效与道路退出同日满足时优先结构。买入当天收盘可触发，次日开始逐个日历日核不可成交原因，买单只尝试一次。
- `verify_sources.py` 本批收窄为保留检查：修正后的原504条A候选及全部嵌套来源、目标、纪律数据逐字段不变，订单元数据一致。**原信号检测与目标选择的核查复用既有结果，本批不冒称独立重写。** 同时核S六账户全部30张表与第十二批完全一致。
- `verify_fixed_paths.py` 是本批新写：固定原17笔实际买入的日期、价格和数量，以原买入支出作为起始资金；按日历日核拆分、登记日权益、除息日应收与实际到账，卖后现金继续零利息持有至末日。S须先与原17笔完整结果对齐，再比较执行者S/T全部路径。
- 所有修改仅在本批 `independent-review/`；不改正式策略、规则账本、资金系统或界面。

## 已知失败保留

`observation-first-attempt.json` 记录核查器首稿假设行动当天有报价，在2022-01-13已知无报价拆分处停止；修正为下次报价前应用已生效行动后，全量核查通过。此处是核查器遗漏，不能归为账户执行错误。

`detected-draft-review.json` 和 `detected-draft-fixed-path.txt` 保留执行者首稿固定路径的问题：只遍历报价日会漏停牌日拆分；分红必须按登记权益、应收及到账日处理；卖出后仍需处理已有分红权益。发现时尚未锁定最终执行结果，已通知负责人及执行者修正。负责人也独立发现同样问题。

## 运行方式

复现时先等执行者完成、确认文件停止改动，再以 `python3 -B` 运行 `freeze_evidence.py` 创建一次性 `accepted/` 副本和SHA256清单。之后分别以 `EXIT_VARIANT=S` 与 `EXIT_VARIANT=T` 运行资金、订单、来源和汇总核查器；最后运行固定路径核查。接受副本不覆盖，失败保留。

最终检查发现一份日志改名且字节不变、两份编译缓存源被清理；接受副本和锁保留原状，详见最终独立报告及完整性差异表。
