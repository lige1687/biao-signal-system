# 513100 分红与拆分正式报告核查

2026-09-08；本目录为主研究的资料交付，不是收益实验。新增下载5份PDF，复用已封存2份；不改生产数据、不计算收益。

## 一句话结论（大白话）

基金正式报告已连续覆盖2013年成立至2026年6月末，这段时间明确没有向基金份额持有人分配现金红利。2022年确有“一份变五份”，年报也确认实际完成。现金分红这项资料已补齐；但少数年份的“没有拆分”尚未逐年核实，不能把一份报告的当年情况推成整个历史都一样。

## 拆分与边界

[2022年报](https://static.cninfo.com.cn/finalpage/2023-03-30/1216285962.PDF)第45页确认2022-01-13实际拆分：713,622,120份变成3,568,110,600份，5.045元的单位净值变成1.009元，每旧份变5份。第32页给出2022-01-12登记日。第76页本期拆分增加2,854,488,480份，与上面前后差额一致。

复用[基金公司第二次提示公告](https://st.gtfund.com/report/2022/01/国泰基金管理有限公司关于纳斯达克100交易型开放式指数证券投资基金实施基金份额拆分及相关业务安排的第二次提示性公告.pdf)第1—2页：拆分日1月13日、当日停牌、1月14日恢复。公告与后续年报分别提供原定安排及已完成确认。研究账户应增加份数，不应把单位价格缩成五分之一算成亏损或新存钱。

本次选取年报的利润分配段覆盖三年，但“基金拆分变动份额”一行**只覆盖本报告期间**。核到破折号的期间为2013年成立后（第55页）、2016年（第61页）、2019年（第67页）、2025年（第64页）、2026上半年（第50页）。2014、2015、2017、2018、2020、2021、2023、2024尚未逐年以本字段核实。因此本目录能确认已知2022事件，不能单独证明全历史拆分事件表完整。

## 取证与文件

- `sources.json`：每份PDF的原URL、最终URL、取回时间、PDF及文本SHA-256；复用材料标原本地来源。
- `events-and-coverage.json`：分红零事件的连续覆盖段、原句、段落与页码，已确认拆分事件及尚未覆盖的拆分期间。
- `513100-*.pdf`：正式原件；`513100-*.txt`：逐页提取文本，非改写报告。
- `manifest.json`：本目录交付文件大小与SHA-256，清单自身不纳入。
