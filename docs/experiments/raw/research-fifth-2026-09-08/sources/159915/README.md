# 159915 正式报告现金事件覆盖核查 · 2026-09-08

## 一句话结论（大白话）

创业板基金159915的正式年报及中期报告已经连续覆盖2013年7月29日至2026年6月30日的分红记录，均明确未分红；这解决了“是否漏记现金红利”的资料问题。份额拆分只能确认已读报告对应的单个年度或半年，其他年份仍有资料空缺，不能因此宣布整段历史没有拆分。

## 本次实际取得

新增5份巨潮正式年报：2013、2016、2018、2020、2022；复用并核指纹的2份原件：2025年报、2026中期报告。没有超过“最多新增6份PDF”的范围，没有运行收益计算或修改旧文件。

2019年报的证监会目录入口超时，尝试同名基金公司文件返回404，因此没有声称取回2019原文。用2018与2020年报的过去三年分红说明重叠覆盖该年，保留替换理由。搜索中出现的110026联接基金报告没有拿来替代159915本体。

每份PDF附全文提取文本。`sources.json`保存来源URL、原始取回时间及SHA-256；复用原件另外保存旧目录来源与复制时间。`coverage.json`保存原句、章节、PDF页码、正文页码、确切覆盖区间和未覆盖区间。

## 份额变化与拆分边界

“份额拆分”是每一份变成多份；普通申购和赎回则是投资者向基金申购或赎回造成基金总份额变化，不是每个持有人都自动增加或减少持有份额。不能把报告中的巨大申购赎回数量当成拆分。

各报告“开放式基金份额变动”表中，“本报告期基金拆分变动份额”均为横线，分别支持以下**单个报告期**未发生拆分变动：

| 报告期 | PDF页码 | 正文页码 |
|---|---:|---:|
| 2013年 | 48 | 47 |
| 2016年 | 53 | 53 |
| 2018年 | 55 | 55 |
| 2020年 | 62 | 62 |
| 2022年 | 235 | 235 |
| 2025年 | 65 | 65 |
| 2026上半年 | 48 | 48 |

**尚未由这些份额变动表直接覆盖的年份：2014—2015、2017、2019、2021、2023—2024。** 这些是拆分资料空缺，不是现金分红空缺。年报三年分红说明不能扩张成三年拆分说明。没有新增任何拆分事件，也没有将未知日期或比例填成确定的零。

本次覆盖截至2026年6月30日，对7月至9月未作零事件承诺。研究收益所需的行情、停牌及交易限制资料仍由主研究分别检查。
