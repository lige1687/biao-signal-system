# 连续月份组成敏感性：补充方案

日期：2026-09-08。在读取任何本项重抽样结果前固定。属于已看第六批结果后的诊断。

主检查仍为实际年度贡献及逐次去掉一年；本项只回答：若固定历史中的连续月份被重复抽取，累计预算差异有多大变化。不是新交易历史、不是未来分布，也不是参数显著性或完整Reality Check。

资料为calendar-monthly.csv中A/B/C、相同预算/相同计划风险、原结构/半个ATR两路径。每模块每月的候选减基准预算变化，固定除以原模块N（1521/563/225）；所有模块合计可固定除以2309。抽到的月份有多少新入场都不改变分母。

原窗1983-11至2026-08，首尾为部分月照原样保留。T为完整年月索引长度，零贡献月份必须保留。每次抽T个月；所有模块、视角共享同一组月份索引，不能各自抽出有利行情。

只用固定连续块长6/12/24个月各5000次，随机种子20260908加块长。块起点在0到T-L间均匀抽取，块内顺序保持，块不能绕回首月；拼足T后截短末块。这样避免把2026与1983当真实相邻月，但中间月份可被更多块包含、原窗边界月权重不同，明确属于组成扰动，不声称无偏置信区间。5000是数值计算次数，绝不表示有5000次独立市场经历。

只输出中间90%范围（5%与95%分位）及中位值，全部块长都显示，不挑某档作为通过证据。不输出p值、显著性标签、获胜频率或未来赚钱概率。各时期产品/机会密度不同，长期关联会在块边界断开；不能通过此诊断修复非平稳、历史选品或历次调参造成的选择偏差。

实现必须确认：月贡献和日贡献/第六批终点守恒、12月内的已知序列顺序正确、所有方法用同索引、每次恰T个月、恒零差异仍为0、固定输入与种子可复算。不重新运行交易规则、不复利、不改变正式门槛。

论文对应详见paper-methods/METHODS.md：Sullivan等讨论稿附录C采用随机长度的连续交易日抽样与整个候选集合校正；本项固定月份块既不是该原法，也没有补全旧历史所有尝试。Cederburg等的仅用过去资料逐月推进原则适用于将来的新账户验证，不可倒过来把已看历史命名为未来验证。
