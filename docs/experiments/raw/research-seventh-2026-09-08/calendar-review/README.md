# 第七批日历记账与连续月份诊断：独立复核

日期：2026-09-08。仅写本目录，没有改动已封存的论文方法目录、原实验、正式规则或目标台账。

## 一句话结论（大白话）
已独立重算全部日账、各期汇总和月份抽样，结果一致，未发现剩余计算错误。这个检查能确认钱的变化被记在正确日期、各方法共同经历的月份没有被拆开；它仍然不能证明未来收益。非循环月份抽样对历史中间和两端的权重明显不同，输出只能用于观察历史组成变化的影响，不能叫置信区间或未来获胜概率。

## 独立检查的范围

`verify.py` 没有导入或调用主研究脚本，也没有调用 Spark 的抽样函数。使用第六批冻结的价格文件与既定机会明细，另行按价格变化和实际费用计算每日财富；读取原始文件前检查冻结指纹。

本复核重建了全部164808条日账，不仅抽查少数交易。2309个机会 × 原/缓冲 × 两种资金用法，共9236行终点全部对齐。它不重新决定第六批的信号、入场或退出，退出定义和0.5倍ATR的独立核对见第六批 `atr-review/`；本项核对的是既定交易在正确日期产生的现金及持仓价值变化。

逐条计算方法：第一日以实际入场开盘为起点，计入买入费用和到当日收盘的价格变化；持有日只计相邻已知收盘之间的变化；退出日只计到卖出开盘的变化并扣卖出费用。没有使用卖出后的当日收盘来增加或减少收益。

## 月份抽样的实际核验

完整索引为1983-11至2026-08，共514个月，包括零贡献月份。独立按种子20260908加块长生成原始块起点，对6、12、24个月三种长度逐元素重建各5000×514个索引，全部一致。每个完整块和末尾截短块均连续，不越过历史末端，不绕回1983年。

所有六列（A/B/C × 两种资金方式）使用同一个索引矩阵，每次恰抽514个月。独立直接逐次相加被选月份，未使用主脚本的次数矩阵乘法，重算90000个结果；全部一致，最大差异2.51×10⁻¹⁵。18组第5百分位、中位及第95百分位与原值均对齐；恒为零的序列仍为零。

主负责人采用的是已固定的5000次、非循环块，和论文方法附件提出的10000次、循环块建议不同。这属于明确记录的本地选择，没有冒充原论文算法；本复核按最终锁定方案验收。

## 结论使用边界

主结论应来自原始年度贡献和逐次去掉一年的敏感性，抽样结果只放附表。所有方法同步取月能保住共同月度冲击和块内时间关系，不能保住跨块长期关系；既往选品、调参、产品池随年代变化及早期稀疏暴露均未消除。

5000次是计算次数，不是5000次独立行情经历。中间90%范围是这套组成扰动生成数字的范围，不能叫统计置信区间，不能解释为未来有90%概率落入该范围。月贡献不重新生成信号或入场，也没有建立共享有限资金的账户；不能把抽样结果复利成真实可执行收益。各记录终点来自既定可用资料，未结束后的未知市场结果仍未知。
