# 论文方法核对与第七批可执行建议

日期：2026-09-08。面向研究负责人及后续接手者。本附件仅查方法、提方案，未运行新增效果检验，未修改既有报告、正式规则或目标台账。

## 一句话结论（大白话）
可以进一步检查“多赚或少亏是否过分依赖某些年份”，但不能把已经看过的历史再抽几遍，就说成未来获胜概率。两篇论文的全文已取得，相关方法段落已核读；此前学习库只有摘要记录，先前计算没有实施它们的完整统计方法。下一步建议先列年度贡献，再把同一日历月份里各方法的资金变化一起重抽，作为有明确边界的历史稳定性诊断。

## 从原文能确认的具体方法

**Sullivan 等：应同时评价整个被尝试的方法集合。** §I公式(1)–(4)用各方法相对基准的日收益差组成向量，检验其中最好的方法是否仍不优于基准。附录B公式(B5)将重抽样均值减原均值后，在所有候选中取最大值；附录C所有候选共用同一时间索引，按几何随机长度取连续片段，平均长度为1/q，主设q=0.1，即10个交易日，并检查2、100日。它依赖时间序列分布稳定、远隔观测关联减弱等条件。[原文印刷页5–6、33–36](https://www.fmg.ac.uk/sites/default/files/2020-11/dp303.pdf#page=9)

**Cederburg 等：直接比较、事后最佳组合与当时可做的组合是三种问题。** §2.2按上月方差调整月度持仓；用全期数据定的缩放常数当时未知，但部分比率对其不变，不能把所有结果简单称作未来数据错误。§4.3.1先用120个月估计，此后每月只用之前历史重新求缩放与权重，在同一后续月份比较；§4.3.3检查参数关系随年代变化。§3另有特定无风险收益预测关系假设下的重抽样，并非我们的月份资金变化法。[原文页98、101、105–107、112](https://www.lehigh.edu/~xuy219/research/COWY.pdf#page=4)

以上是作者方法事实。下面全部是针对本系统的适配建议，作者没有为“半个ATR”“6/12/24个月块”或本系统通过标准背书。

## 与第六批的关联及差异

这次服务策略规格§2.3进出同逻辑、§3数据和执行、§9结构失效、§10盈亏比纪律的研究评估层，不更改正式信号。第六批研究对象是固定2309个旧机会、0.5倍日常波动幅度的结构缓冲，以及资金用量的变化。它既不是论文中的道指日度交易规则全集，也不是103个长期因子组合。

可直接借用的是：同一行情下保留参照和配对差值；各方法共同抽取同一时间段；保留所有尝试；只用当时可得信息计算可执行版本；对时期变化保持敏感。不能移植作者的盈利结论、统计阈值、风险偏好或杠杆设置。

第六批24个视图是4方法×3费用×2资金口径，共用行情。它们不是24次独立实验，更不覆盖系统历来全部参数与选样尝试。新增统计发生在第六批结果已知之后，必须标作事后诊断；此时固定新协议可以防止继续随结果调整，却不能追溯变成预先登记的验证。

## 建议先做的主检查：按真实发生年份看贡献

限定 amount_5bp 费用情景，只比较 buffer 与 base；same_budget、same_planned_risk 两种资金方式均保留。先隔离失效价及其引起的资金量变化，不再叠加 RR 筛选。固定原2309身份，模块分别仍按原模块身份数计；不删除未成交和未结束记录。

1. 重建每个机会的每日财富：入场前预算为1；入场后为未用现金加持仓价值；买卖费用只在发生时计入；退出后财富保持为现金；未结束只到原有末次有效估值。不要把累计费用在现金和财富中各扣一次。
2. 每笔逐日财富变化相加必须等于第六批该行的终点预算变化；两个方法的差同样必须严格对齐。先完成这个检查，再运行任何重抽样。
3. 以实际价格日期归属日历月、日历年，不以信号月或退出月承包整笔利润。跨市场按原数据当地日期对齐，不虚构精确同时成交。休市日没有新的估值变化不等于把缺失成交价补成可交易价；发生缺价的特殊记录须单独保留说明。
4. 主表报告每年的贡献、当年机会数、实际持有预算暴露，并逐次去掉一个年份看剩余贡献方向。这里去掉的是该年已发生的资金变化，不是删除该年入场交易，也不重跑信号。

固定定义：令 `d[i,v,t]` 为机会 i、视角 v、日期 t 的“缓冲方法财富变化 − 原方法财富变化”。`D[v,m] = sum_i sum_t_in_m d[i,v,t]`。完整历史的配对平均预算变化必须等于 `sum_m D[v,m] / N`，其中全体 N=2309，模块报告使用原模块N。去掉一年时分母继续固定N，称“去掉该年贡献后的历史总差额 / 原始预算数”；不能把它叫新时期每笔平均收益。

只读覆盖提示：第六批上述两条方法最早入场1983-11-22，最晚估值2026-08-27，最长持有172根价格记录。早晚可用标的和机会密度不同，特别需要展示暴露变化。不能看过效果后截去稀疏早期来改善区间。

## 可选附加：同步连续月份重抽样

大白话解释：把原历史中的连续几个月整段选出来，允许某段重复出现，观察结论对“哪些历史阶段占比更大”是否敏感。它没有产生新的行情或可执行交易过程。

建议锁定固定长度6、12、24个月，各10,000次，随机种子20260908；三种长度全部展示，不按结果选最好。它们是本地敏感性设置，不是论文原参数。采用循环固定长度块：每次从全部T个月中等概率选起点，连续取L个月，到尾部从头接；重复取块并截到T个月。保存所有索引或索引矩阵指纹。循环首尾相接会创造不存在的年代连接，应在结果里明说；采用此约定仅为让每个原月份被等概率选中。

所有模块、所有方法和两种资金视角，在同一次重复中共用同一组月份索引。每次计算 `sum_selected D[v,m] / N`，N仍为原始身份数；不按抽到的信号数量改变分母，不把已完成的单笔再当独立样本抽取。按同一实际月份汇总，保留了同时持有机会共同遭遇的市场变化；连续块保留块内的时间关系，但边界外的长期关联仍会被切断。

输出原值、重抽样结果中间90%的范围（第5和95百分位）及各长度之间的变化即可。此处90%只是所生成数字的覆盖比例，不是“真实效果有90%概率落在其中”。不要标置信区间、严格显著性、未来获胜概率或上线通过线；不要把正值比例解释成未来胜率。区间跨零或不跨零都不能独立决定是否采用。

统计对象是固定预算的历史资金变化贡献。月度持仓暴露随年代改变，已有选样、不同市场和不稳定关系没有被消除；因此这个重抽样范围不能被当作一个稳定总体的精确推断。更不能将抽出的月度贡献复利连接成真实账户财富，因为块的持仓初态来自原历史，边界处并未重新建仓或重新生成信号。

若无法让每日记账与原终点逐条对齐，或出现未解释的持仓期缺价，停止重抽样并保留缺口；可以先交年度贡献。若无法避免对区间的误读，直接只交年度及逐次去掉一年诊断，不输出区间。

## 为什么不叫 Reality Check 或 Cederburg 复现

- 没有重建系统曾经尝试过的所有候选及选中0.5倍的完整过程；后补两方法比较不能校正所有历史寻找偏差。
- 本建议不取所有候选中最大的、经中心化后的统计量，也不计算相应原假设概率；只是同步时间块的敏感性计算。
- 固定月份长度不同于Sullivan原法的几何日数长度；资金变化贡献也不同于其日收益差向量。日历共同索引思想得到保留，其他条件没有冒称相同。
- Cederburg 的事后最优权重、逐月估计组合、专用原假设重抽样及结构断点检验没有在此实施。展示年度差异也不等于已经完成其结构断点检验。
- 新的未看历史、真实价格与公司行为、可交易限制及有限共享资金约束仍未完成。统计计算不能补齐这些数据与执行缺口。
