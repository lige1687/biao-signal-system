## 要比较什么

## 双方共用的机会身份

研究先生成同一母体，再各自运行状态；不能分别生成母体后只留交易交集。

1. 研究共同趋势条件为SMA20 > SMA60 > SMA120且close >= SMA120。在已观察到共同趋势破坏之后，等待双方共用的模块A环境首次成立（历史代理：时钟二类、SMA/EMA多头、周线多头），以该日为共同起点。不使用black开关、最早入场日、未来收益或后来构造确定起点。
2. 共同段开启后只由SMA排列破坏或close < SMA120结束；时钟/周线/EMA临时变化不自动重开共同段。black仅影响各自内部状态，不进入共同段结束规则。每日触碰仍按两边相同基准条件，段存在不等于每日可入场。
3. 暖启动、研究窗口左端或缺数据之后，无法证明原始趋势起点就标“未知/被资料打断”。数据恢复只产生数据段ID，不能直接记已知的新趋势/首次；重新观察到一次共同趋势破坏并随后共同环境成立，才恢复已知起点。该未知处理尚须共同基准正式接受。
4. 父记录是产品×共同起点（未知时用明确数据段ID），20/60/120均线组是子记录。产品×起点×均线组可做行主键，但三个组共享同一行情，不当作三份独立样本。未来才完整知道的段长/段尾只能用于汇总，不用于当天资格选择。

完整输入要求包括当日已完成OHLC、已合格经济价格/行动、SMA/EMA及抵扣价、时钟、周线环境、所需ATR。旧raw.NEED没有clock/weekly，不能照抄为完整资格表。缺字段、未完成K线、未知首次或未知时点不能补零、False或“非黑”。具体字段缺失是否停止状态、如何恢复，需要正式共同基准；这里不预写实现已验证。

## 输出、反例与未来执行验收

阶段一保存全部共同父段/均线组、资格原因、逐次触碰/取消/早期/确认、black日与内部重开日、首次是否确定、结构ID及可用/失效时点；两边都不触发、仅一边触发、日期/原因不同、资料未知和窗口截断必须留。价格结果栏标未评估，不填0冒充同收益。

对账要求：全部父段=完整可评估段+不足/未知段；每项动作引用共同parent_id和touch_id，差异类别互斥且完整；两个版本不能双计触碰。内部episode_id允许不同，不能用它当共同母体。输入/选项/代码SHA除唯一开关外一致，未来结果不能进入资格、身份或信号。

必须保留反例：
- black后SMA大趋势仍在：内部首次可能变化而共同段不变，是待研究差异，不能先判哪种好。
- black当日也SMA失效：共同条件已结束，不能归因black开关；原因要分主次不双计。
- close等于EMA20或抵扣价：不算black；未知颜色也不算已知非black。
- 窗口左端和缺价后恢复：不能假装确定首次或删除这些段来提高通过率。

未来执行器必须做追加未来行情不改旧动作、未知不转已知首次、等号边界、black仅取消true内部状态、共同失效两边一致、无信号/未知全保留、选项唯一差异和旧证据不改等数值检查。本轮只是明确验收条件，没有执行定义实现、数值边界测试或效果计算。
