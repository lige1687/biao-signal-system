# 宽基ETF论文增量候选筛选

日期：2026-09-08  
状态：只读筛选完成；未运行收益，候选尚未成为正式策略规则。

## 一句话结论（大白话）

建议首轮只测两件事：一是把已有的二元宽度加缓冲候选放进真实ETF账户，回答它能否取代现役三档；二是宽度三档减少投入但ETF仍继续上涨时，如果ETF自身的60日上涨趋势仍在，就保留较高投入，看看能否补上2025年那类踏空。两项都必须把下一次进入、现金、分红和费用算到同一账户里；论文没有替本地阈值背书。月末才检查60日区间的方法定义清楚，但决策紧迫性低于已有待采用候选，留作未运行备选。

## 核查范围与来源

- 主计划第6节限定：最多两项进入首轮，每项最多两产品×原办法/新办法×两费用；不得照搬期货做空、风险缩放或论文参数。
- 本地学习记录和既有实验显示：510300、159915已经完成持续持有、周度宽度三档和每日检查的简单60日突破完整账户；月末才检查的同一60日规则尚未完成ETF资金账户。宽度与趋势曾分别研究，也做过“长周期允许窗口加短期择时”的事件预检，但未发现本候选这种 `max(宽度档位, ETF趋势持有状态)` 的完整ETF资金账户。
- Sepp、Lucic（2026）把趋势方法统一分类，并指出较长观察跨度更依赖低频持续性，交易成本会改变合适的检查跨度。这里仅借“固定信号、比较频率和费用”的问题设计，不采用其连续合约、波动标准化、做空、风险缩放或由历史优化出的跨度。[arXiv原文](https://arxiv.org/abs/2607.19497)
- Jeon、Masturzo（2025）明确把退出价和重新进入价视为同一套安排，并在实证中计入交易成本和延迟成交；其趋势组合是71个期货/外汇合约、252日动量、波动配权，且扫描多组止损与重新进入倍数。这里仅借“退出、再进入、费用和风险要一起算”的验收方法，不采用5%止损、0.5%再次进入、波动倍数、252日阈值或次日收盘成交。[机构原文PDF](https://media.researchaffiliates.com/1099_stop_the_losses_e389db6127.pdf)

外部原文只用了上述两项官方来源，没有泛搜，也没有把作者的历史收益当作本地ETF证据。

## 入选 H1：二元宽度加2个百分点缓冲

**要回答的问题。** 这项规则已经在旧指数代理和旧ETF面板中研究过，并列在系统台账的待采用候选；但还没有进入首12使用的名义价格、分红、100份整数和两档费用完整账户。它补齐一个真实资金决策，不把旧代理成绩再算一次新成功。

**固定定义。**

1. 每只ETF独立、只做多、初始现金100000元；主区间、名义价格、公司行动、100份整数、费用、限制日、分红和期末估值全部沿用首12账户冻结协议。
2. 沿用完整自然周最后一个非空B200观察和下一周开盘的节奏。二元状态初始为0；状态0且 `3×B200 <= 130` 时目标变为100%；状态1且 `3×B200 > 136` 时目标变为0%；两条线之间保持原状态。这样精确表示进入线130/3、退出线136/3，不用四舍五入数参与计算。
3. 只让 `eligible_date >= 2015-01-01` 的完整周更新状态。周内没有有效宽度时不制造信号；旧未成交订单跨入新周时按首12规则取消。研究末尾未完整结束的周只记候选观察，不执行。
4. 下一自然周首个可成交开盘评价一次，仍使用5个百分点最小差额、开盘前净资产、应收不可花、100份整数和限制顺延。目标只有0或100%，不借款也不增加到100%以上。
5. 禁止重跑旧参数网格后重新选择。

**唯一基准。** 同产品、同费用的现役 `breadth_three_tier`。两只产品×两费率形成4个H1新增账户，原宽度4账户直接引用且核指纹；不得把旧代理或基准账算成新增账户。

**准入理由与边界。** 这是“退出后何时重新进入”的周度状态机：低宽度再次到达进入线才重新参与。旧研究固定参数仅胜5/11个历史段，必须与有利证据一起披露。两篇论文都没有提供这两条宽度线；论文只支持把卖出、再进入、费用和下跌风险放在同一资金路径中评价。

## 未入选备选 I1：完整月末检查的60日报价区间趋势

**要回答的问题。** 原简单60日趋势每天检查；本候选只减少检查频率，不同时改观察窗，因而能单独回答“少操作是否值得”。这是研究用的简单趋势参照，不冒充LEI模块B。

**固定定义。**

1. 每只ETF独立、只做多、初始现金100000元；主区间、名义价格、公司行动、100份整数、费用、限制日、分红和期末估值全部沿用首12账户冻结协议。
2. 60根均指ETF的有效收盘报价，当前收盘不进入前60根。比较前按信号当时已经生效且已知的公司行动换成同一价格单位。
3. 只有一个自然月已经结束后，才使用该月最后一根有效ETF收盘检查一次。空仓且 `close > 前60根有效收盘最高值` 时计划进入；持仓且 `close < 前60根有效收盘最低值` 时计划退出；相等不触发。
4. 信号在下一可成交开盘执行。受限或缺开盘时按首12协议顺延；在新月末出现相反状态前，月中不重新判断区间，也不因月中突破下单。
5. 主区间以前的报价只预热60根，不继承虚拟持仓。卖出后现金等待以后某个完整月末再次满足进入条件。

**唯一基准。** 同产品、同费用的原每日检查 `simple_60_close_breakout`。候选和基准各用0.1%、0.2%两档费用；先只做510300与159915，共8账户。不得再加30/90/120/252日或周频/月中版本。

**暂缓理由。** 这一定义尚未在两只ETF完整现金账户中重复；旧月度动量和月度宽度研究改变了指标或资金问题，不等于本候选。但它是本轮新造的频率变化，当前更需要补齐已有二元缓冲候选的采用证据，所以本轮不运行、不占第三候选。若以后启用，以上定义须重新在收益运行前冻结，不能用H1/H2结果决定是否启用。

## 入选 H2：宽度三档加ETF自身趋势续接

**要回答的问题。** 现有宽度三档在2025年明显少参与上涨。本候选只检验一个事先知道的缺口：宽度要求少投时，ETF自身仍处于60日上涨趋势，是否应保留较高投入。它可能补上踏空，也可能在下跌初段投入更多，两面都要报告。

**固定定义。**

1. 先逐日维护原 `simple_60_close_breakout` 的二元状态：空仓状态遇 `close > 前60根最高收盘` 变为1；状态1遇 `close < 前60根最低收盘` 变为0；严格不等式、公司行动比较口径和预热规则均不变。这里的状态只是周度目标输入，月内或日内变化本身不下单。
2. 只处理已经完整结束的自然周。原宽度目标仍为：周内最后一个非空B200低于43.3%取1，43.3%（含）至56.7%（不含）取0.5，56.7%（含）以上取0。
3. 完整周的决策时点为下一执行周之前的周日；宽度来源日独立记录。趋势状态只使用不晚于该决策时点的ETF有效收盘，合成目标为 `target=max(breadth_target, trend_state)`。因此趋势状态为1时目标为100%；趋势状态为0时完全回到原宽度三档。不能因宽度来源较早就把ETF状态也截在来源日。
4. 周内没有有效宽度时，沿用原协议：该周不制造目标，取消跨入新周的旧未成交订单；不得只凭ETF趋势补造宽度目标。研究期末尚未结束的自然周只记候选观察，不得称为确认信号或执行。
5. 合成目标只在下一自然周首个可成交开盘评价一次，仍用5个百分点条件、开盘前净资产、100份整数、应收分红不可花、受限顺延和新周替换规则。不得把趋势触发改为次日执行，否则同时改变了执行频率。
6. 主区间首周可使用区间前已经完整结束且当时已知的周观察；60日状态从主区间首个有效收盘开始为空仓状态生成，不继承2014年的虚拟持仓。

**唯一基准。** 同产品、同费用的原 `breadth_three_tier`。两只产品×两费率形成4个H2新增账户；复用原宽度4账户时必须核输入与指纹一致，不能再次把旧结果当新实验成功次数。H1与H2合计8个新增账户，另引用首12全部既有账户作共同背景。

**准入理由与身份边界。** 旧研究已经说明“宽度与价格趋势分工”，也做过其他长短信号组合；现有盘点未发现这个固定最大值规则的ETF完整资金账，因此有增量。但它源于已经看见的2025踏空，是回顾历史后提出的扩展，不能把同一段上的改善叫新验证，也不能把它写成论文参数或现役宽度规则。它属于市场环境资金比例的研究扩展；ETF趋势是简单研究参照，不改写A/B/C/D技术触发。

## 两项共同验收

- 收益运行前冻结协议、输入、程序和完整尝试清单；不看结果调阈值或追加版本。
- 每日重建现金、应收分红、份额、权益和回撤；逐笔核目标、下单、受限顺延、成交数量与费用；保留未成交与期末观察。
- 同时报告期末金额、最深下跌、逐年结果、空仓/低投入时间、买卖次数和费用。I2另列所有 `trend_state > breadth_target` 的周及其随后实际增持，尤其分开2018和2025。
- 独立复核者按原始输入重建账户，不导入执行者模拟器证明其自身。两只ETF共享同一市场宽度，不算两次完全独立的成功。

## 未入选内容
