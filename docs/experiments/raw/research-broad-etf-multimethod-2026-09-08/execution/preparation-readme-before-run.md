# 宽基ETF有界增量实验执行骨架

## 一句话结论（大白话）

这里先把“一个已经定义好的买卖目标，怎样变成真实现金和ETF份额”的共同记账骨架准备好；候选方法的具体规则还没有冻结，所以现在不能运行或汇报任何新增收益。

## 策略边界

- 这是资金安排扩展实验，不修改LEI的道路、路牌、A/B/C/D触发或失效规则。
- 候选信号必须由后续冻结协议单独定义并标为研究代理，不能宣称是论文作者原始规则。
- 固定两只产品：510300、159915；每账户初始10万元、无追加；日期、单边0.1%/0.2%费用、名义开盘成交、100份整数和公司行动口径继承首12账户。
- 最多两个候选，每个候选2产品×2费用，共最多8个新增账户。持有、宽度三档和简单60日突破旧基准直接引用，不重复计入新增账户。

## 当前状态

- `protocol-gate.json` 明确为未锁定；`run_candidate_accounts.py` 会在协议门槛未满足时拒绝运行。
- `account_adapter.py` 只接收通用目标份额信号，并复用首12冻结资金函数。
- 未完成的研究尾周会标成候选，不能进入账户；官方停牌、延迟开盘和仅因资料不足而设置的研究限制分开分类。
