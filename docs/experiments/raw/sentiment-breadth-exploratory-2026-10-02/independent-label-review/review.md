# 独立标签核算

## 一句话结论（大白话）
按冻结协议从两份原始数据独立复算，三个指定日期的过去涨跌、宽度变化、后续收益和最大回落均可重现；404条宽度记录分组得到343个共同成熟日期，其中训练175、评价147、跨年剔除21，与协议一致。

## 口径
报价日期 t 是宽度记录的原日期。过去20个报价间隔的涨跌用 t−20 至 t 收盘价计算；B20 使用保存的20日均线之上股票比例；delta20 是 t 与 t−20 两个同日记录的比例差，单位为百分点。未来20个报价间隔收益使用 t+1 至 t+21 的收盘价。未来最大峰谷回落是 t+1 到 t+21 区间内，从此前区间最高收盘价到之后最低收盘价的最大跌幅；它是价格波动描述，不是账户实际亏损。

SPY序列含8,456行报价。逐行检查确认所有收盘价均为正且有限。原始输入 SHA-256 与冻结协议相符：宽度文件 `613fa152ee6cf2820df59f5566eb4601bda2f1c71747b7bda96d8128282011c7`；SPY报价文件 `952f397be0ccc5745185b91cce6acc781737c0f30a7a34aa8a230ae892ed5e45`。
