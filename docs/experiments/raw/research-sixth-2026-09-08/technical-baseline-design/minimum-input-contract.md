# 最小输入契约与执行前检查

日期：2026-09-08。状态：执行前待数据检查。本文是后续研究执行者的数据交接，不是生产接口改造。

## 一句话结论（大白话）

有成交日期与赚赔倍数还不够。要比较同样的钱下复杂规则和简单办法，需要知道当时可见的信号依据、实际基金价格、每笔钱何时到账、交易是否可做，以及每天还剩多少现金和持份。缺哪一项就明确停在哪一步，不用旧收益填空。

## 每次运行必须产出的表

- 候选对应表：每种办法是否接受、拒绝原因、成交/未成交/仍持有等状态，保留输入身份和原始字段。
- 委托与成交表：决定时间、实际尝试时间、数量、名义价、费用、限制、撤销或持续待执行状态；计划风险比与开盘复核值都留。
- 逐日账户表：累计到账、提现、可用现金、各产品数量/名义市值、应收分红、陈旧估值标记、总财富、剔除入金影响后的投资净值、费用和已实现/未实现盈亏。
- 事件对账表：持份变动、拆分前后数量、分红锁权/应收/付款、每日会计恒等式差值。
- 全部配置摘要与差异表：不隐藏零信号、未完成、被资金限制拒绝和数据缺口；至少同报财富、损失、恢复、操作负担。
- 数据/代码/参数/来源指纹，独立复核报告，以及累计已尝试配置清单。
