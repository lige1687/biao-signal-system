# 原16笔默认退出：两套价格文件独立核验

日期：2026-09-08。源项目 `/Users/yongbiaoli/lei-signal-sync`；仅本专属研究目录写入。已读源AGENTS及策略规格、规则账本、MACD口径、板块方案；本轮服务于规格§3.2“股票拆分、合并、分红等必须使用一致复权方式”和§2.3结构失效退出的证据核验，不改变策略。

## 一句话结论（大白话）

**原先对不上的3笔已经找到能逐项对上的旧价格文件。** 使用8月25日快照后，固定的16笔全部复现原记录；9月2日重建价格里，泸州老窖整段价格都比旧版本低4.417元，但此前记录的失效价没一起换，造成3笔结果失配。其中一笔还因这种价格平移被简化跌停规则多延迟一天卖出。这证明要把价格和结构价成套保存；它没有证明某个退出方法变好，也没有确认哪套价格最接近真实可交易的价格。

## 固定范围与方法

原先选定16笔不变，未按本轮结果另挑案例：

- A：`raw/lifecycle_combo/T2_A_ETF_cm05_shrink.json` 中159611.SZ的12笔。
- B：`raw/lifecycle_combo/T1_Bp_a61.json` 中000596.SZ的1笔。
- C：`raw/lifecycle_combo/T2_C_stocks_v3_b15.json` 中000568.SZ的3笔。

逐笔信号日期、失效价、目标价等全部来自原JSON，不重新生成入场。两套资料统一截至2026-08-25。沿用原默认“结构失效或收盘同时低于EMA20和20根前收盘，下一开盘退出”，沿用原简化涨跌停和旧费用：单边max(5bp,0.005/价格)。费用的市场适用性尚未认可；这里保持原样是为查明历史记录。

`audit.py` 从冻结文本中仅抽取原`seeded_ema`、交易数据类、费用类和`simulate_trade`，不加载应用服务、不执行旧脚本的主程序，也没有联网。默认退出需要的条件直接按原公式提供，顶部列表为空而该退出分支不使用顶部。资料与源代码冻结在`inputs/`，完整路径、SHA见`input-manifest.json`。

### 两套行情的确切差别

截至共同截止日，159611.SZ两池均1122日，每根开高低收相同。000596.SZ共同2427日的开高低收也相同；重建池额外多2016-08-24一日，不影响这次B的退出。

000568.SZ快照2427日，起于2016-08-25；重建池2387日，起于2016-10-26。**共同2387日、全部四个价格字段，快照减重建都是4.417元**（最大浮点误差约3×10⁻¹⁴）。不是只在三次入场日偶然相差同一个数。

| C信号日 | 原失效价 | 快照中对应低点日期 | 快照低价 | 同日重建低价 |
|---|---:|---|---:|---:|
| 2018-09-21 | 14.212 | 2018-09-14 | 14.212 | 9.795 |
| 2018-11-21 | 9.682 | 2018-10-29 | 9.682 | 5.265 |
| 2021-09-01 | 140.353 | 2021-08-23 | 140.353 | 135.936 |

这三个旧失效价都恰好等于快照中信号前30根最低价，而不等于重建池同日低价。它提供了“原交易结构价与快照成套”的直接证据，不是仅根据文件名推断。

### 第一笔为何连卖出日期都变了

2018-10-10收盘，快照价16.332，高于原失效价14.212，但已经同时低于EMA20和20根前收盘，所以原记录是趋势退出。重建池价11.915，低于仍被沿用的14.212，优先触发结构失效。两套资料均在同一天提出退出，理由却不同。

次日10月11日开盘，快照价14.862相对前收16.332下跌约**9.0007%**，未达到原简化规则9.5%的禁卖条件；重建价10.445相对前收11.915下跌约**12.3374%**，于是被当成不能卖出，顺延10月12日开盘11.365。

价格统一减一个常数不会保持百分比涨跌不变。因此即便日线走势形状相似，在复权后的价格上直接判断涨跌停也会受版本影响。本次没有取得2018年相应名义报价或官方涨跌停价格，**不判断现实中10月11日究竟能否卖出**。逐日数值见`c-daily-diagnostics.csv`。

另外两笔退出日不变，但原失效价未调整使风险距离变小，从而把同一绝对价格损失换算成更大的“计划风险倍数”。这不是多亏出的实际现金证明。

## 能解决什么、还不能解决什么

- 原16笔默认退出的**历史复现缺口已闭合**：找到一套与原记录一致的现存价格快照，保留其价格和原结构价一起复现。
- 不能据16笔就说整个价格池正确或全池都能复现，也没有重生成A/B/C入场，未计算899笔重复分支，避免与主研究重叠。
- 两个000568元数据文件都写`provider=tencent`，抓取时间分别是2026-08-26T06:46:54Z和2026-09-02T04:37:10Z。旧`run_exit_three_piece.py:50–52`及归档称东财与腾讯调整差异，本次文件本身**不能独立支持该供应商归因**。
- 本轮未取得供应商原响应、调整因子历史或000568分红公告，不能确认4.417具体对应哪项公司行为，也不指定哪套为经济意义上唯一正确的行情。研究不把“能复现旧数”当作“已经还原真实资金收益”。
- 不建议手动给重建价全部加4.417或只减失效价来冒充修复；百分比规则、历史数据起点和原始公司行为仍需成套规定。后续使用快照是为了固定历史版本，不是宣布重建池所有用途作废。
