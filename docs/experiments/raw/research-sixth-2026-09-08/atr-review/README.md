# 固定半个日常波动幅度缓冲：独立复核

日期：2026-09-08。范围：本批有限机会比较；未修改正式规则、生产数据或目标台账。

## 一句话结论（大白话）
这次复核确认了计算本身：2309 个旧机会全部保留，55416 行比较没有遗漏，资金、筛选和全部发生变化的退出路径均能独立核对。把失效价放远会改变买入数量、筛选数量和部分退出；这些是所选历史机会上的结果，不能当成一个真实账户的收益，更不能据此认定策略将来更好。

## 复核如何独立完成

本目录的 `verify.py` 没有导入主研究的 `prepare`、`exit_path`、`account`，也没有执行主研究脚本。它读取已经冻结的 3 份原始机会文件和 165 份价格文件，先核对全部文件指纹，再自行计算以下内容：

- 从原始记录顺序重建 2309 个身份，包含模块、原行号、标的及信号日。每个身份必须恰有 4 条方法路径 × 3 种费用情景 × 2 种资金用法；相同标的、同一天的原始不同记录不会被擅自合并。
- 对全部 2309 个机会，逐日计算信号日及以前 20 天的真实波幅平均值（ATR），重新求原失效价、缓冲失效价和潜在盈利与预设亏损的比例。
- 从明细中识别 415 个退出日或退出原因发生变化的机会；另加 1 个尚未结束的 MSFT 机会。独立逐日重建两种失效价下共 832 条路径，自己计算 20 日指数均线、结构优先判断、收盘确认后下一开盘执行及不能成交时的等待。832 条全部匹配。
- 对全部 55416 行重新计算数量、买入后现金、持仓金额、计划损失、费用、期末预算变化，以及持有期间最低收盘价格对应的预算变化。重新核对 72 组统计。

未改变退出的其他机会，本复核重建 ATR、筛选和资金，但没有另写一轮逐日退出复现；其旧退出由同批 `full-baseline-review/` 的完整旧基准复核支撑。不要把本项范围说成独立重建了所有机会的全部退出路径。

| --- | --- |
| 原机会身份 / 记账行数 | 2309 / 55416，覆盖和唯一性通过 |

| 资金重新计算的最大绝对差 | 数量小于 2×10⁻¹⁴；预算变化小于 2×10⁻¹⁵，属浮点舍入 |

## 方法边界与已经修正的问题

本次实现与固定方案的主要处理一致：只试 0.5 倍、只用信号日及此前 ATR；所有市场均在确认之后寻找下一开盘，不读取成交日收盘判断能否开盘成交。停用缓冲或筛选的路径没有复活原来无法入场的机会。

初审发现 `applied_buffer` 展示标记把一些已被筛掉的记录仍标为应用了缓冲。主研究已将它限定为实际准许进入的缓冲记录，并重新生成明细。最终文件中，未入场却标为应用缓冲的行数为 0。该问题不影响此前的资金或退出计算；本复核封存的是修正后的版本。

以下限制依然成立：

- 固定的旧机会列表和标的集合已经被研究过程选择过，不能视作从未看过的新历史；没有 D 模块输入。
- 使用复权价格代理和旧中国市场 9.5% 的简化成交限制，没有验证每个产品的真实涨跌停、整手或当天实际可成交情况。
- 三种费用均是指定情景。旧费用按入场价格算双边费用只为历史兼容；其他两种按实际买卖金额。尚未证明它们就是这些产品和账户真实发生的费用。
- 计划损失设为预算 1% 的资金视角只按入场价到失效价的距离控制仓位，不把费用计入这 1%；它也不能保证跳空后的实际总损失不超过 1%。
- 持有期间最低值按收盘价格计算，包含入场费用与实际终点费用，没有模拟每天立即卖出，也不是盘中最差损失或一个共同账户的最大回撤。
- 每个机会有独立预算，现金收益为零；没有共享有限资金下的并发、币种、分红、整手、再次入场等约束。机会平均预算变化不可冒充组合收益、年化收益或实盘回报。只确认计算与限定条件，未证明策略有效。
