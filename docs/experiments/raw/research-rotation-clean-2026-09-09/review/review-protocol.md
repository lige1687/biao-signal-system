# 独立核验约定

独立程序只读取冻结的 `data/prices.csv`、`data/actions.json` 和根目录协议，不导入执行者代码。它从名义开收盘重新连接只使用当时已发生分红与拆分的连续价格，再独立生成月末强弱排序、200 日均线状态、次日订单和日账。

核验覆盖八个账户：四种配置方法乘两档单边费用。逐项比较月末名单与权重、每日均线退出、100 份整数买入、先卖后买、费用不足时同比例缩小买量、实际漂移份额、登记日分红权益、除息应收、支付现金、期末未平仓估值、年度收益、从初始本金开始计算的最大下跌和产品贡献。没有有效开盘、零成交量、已知停牌或延迟开盘时不得成交；自然日发生的拆分必须先累计，等下一有效报价再接价格。

审查结论会把资金与交易是否一致、只用过去数据是否一致、指标是否一致分开写。四产品是事先固定的小名单，结果不能外推成全市场轮动结论。
