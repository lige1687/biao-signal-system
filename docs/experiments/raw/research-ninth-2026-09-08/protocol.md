# 第九批：入场纪律的有限诊断与 B 区间定义核查

日期：2026-09-08。本协议在本批两组诊断账户运行、查看收益之前固定。已知第八批 P0 零成交、P5 两次买入；本批属于针对已知结果的历史诊断，不能包装成全新历史的独立考试。

## 要解决什么

最高依据仍为交易规格 §4.6、§9 B、§10、§13、§16，规则账本 2.1.0。服务于入场触发和过滤纪律两层：分清普通突破本身与叠加目标空间纪律的作用，核对 B 的横盘时间与实际价格区间是否被混作一回事。正式规则不变，不新增投资建议或自动交易。

## 仅两组新账户

- R0：完全复用第八批 P0 的 1082 个原始候选。
- R1：完全复用第八批 P5 的 660 个原始候选。
- 唯一实验变化：取消“必须有已知历史目标、潜在盈利至少为初始计划亏损三倍”这一组合条件在信号收盘和指定开盘的检查。
- 原始 `signal_accepted`、`signal_reject_reason`、目标及其来源全部保留，增加原候选 ID/配置以及 `diagnostic_reference_only=true`。只允许绕过原拒绝原因 `target_unavailable`、`signal_reward_risk_below_3`。其他拒绝原因仍拒绝；没有明确理由的拒绝也不能绕过。
- 信号参考价必须高于正失效价；指定开盘必须高于当时的正失效价。不得因取消目标检查而允许零风险、负风险或缺失失效位。
- 其他规则、资金、四只基金、日期、公司行动、价格调整方式、每周收入、费用、整手、下一日成交和退出优先级均保持第八批。达到历史目标仍不是退出条件。
- 初始失效依然为之前 60 根最低收盘，之后收盘低于初始失效或同时低于 EMA20 和 20 根前收盘则下一可开盘卖出。
- 两组都是诊断参照，违背现行目标空间纪律的交易不得展示为正式可买信号。也不称为完整经典突破策略复现，因为退出、投入方式仍采用本研究约定。

不添加第三组，不试其他周期、不调整纪律阈值、不按成绩追加更有利版本。R0 与 P0、R1 与 P5 成对报告；同时列第八批被动持有作为背景。不同持仓和后续资金路径造成的差额不能说成逐笔因果效果。

## B 区间核查范围

对原有六个 B 事件列出横盘计龄起点、watch 起点、价格区间天数、原上沿/下沿/目标。只机械计算一种替代：取完整横盘计龄段的已知最高/最低价，说明与原定义差多少。不得重新搜索更多 B 事件、重算该替代的收益或选最赚钱区间。原文未指定的细节明确记为定义缺项，不能擅称确定的实现错误。

## 检查与判断标准

保留 Spark 原始修改及失败记录；根和审查 agent 核对修改只影响两组诊断。原 P0–P7 合成用例通过，并对 P0/P5/P6 原真实账户逐表一致性检查。新账户记录全部候选、拒绝、订单、成交、逐日资金及未结束持仓。独立复算全部新账户现金、持份、分红和财富；检查成交只用当时开盘、原失效位仍有效、最早退出条件未漏。

主输出是能实际买入多少次、扣费后期末财富及投资净值从高点最大跌幅；同时列成本、持有资产比例、结束与未结束交易。禁止输出未来获胜概率、采用排名或据此放宽正式纪律。现金/费用/历史行动不完整等第八批限制原样继承。
