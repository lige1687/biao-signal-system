# B结构定义溯源：横盘126根，为何止损区间只有1根

日期：2026-09-08。范围：6个已存在的518880事件；无新信号或收益运行。

## 一句话结论（大白话）

原因是代码把“横盘多久”和“这次观察区间有多长”分开了：横盘够久只赋予观察资格，新区间的上下沿却从观察当天重新累计。6个事件中3个只用1根行情决定失效位。手册确实讲的是横盘箱体，但没有明确给出区间起点算法，所以目前应判为**研究定义缺项和既定代理边界**，不能直接断言已违反一条明确公式、然后悄悄改生产。若采用完整横盘段的上下沿，这6个原日期都没有突破更大箱体的上沿，改变的不只是止损宽窄。

## 两套状态为何会分开

第一套是横盘状态寿命：首次有效横盘开始计龄，允许最长20根短暂离开，超过才清零。它由全历史时钟类别独立计算，不因一次突破失败就重新开始。到126根、且当日六条均线足够密集，系统才有资格发出watch，即“开始观察这个区间”。

第二套是一次具体观察区间：创建watch时，上沿直接设为当天high，下沿直接设为当天low；以后每天先用昨日为止的上下沿检查突破，再更新区间。突破失败或密集条件持续消散会结束这一轮观察，但第一套横盘寿命可能还在。因此下一次watch可以马上开启，不必重新等待六个月；其价格区间又从新watch当天开始。

这意味着“横盘已持续341根”和“当前突破参考只来自最近1根”可以同时发生。第八批修复的是首次有效横盘前的错误计龄，没有把这两套状态合并，也没有改这项区间定义。

## 原文说了什么，没有说什么

现行最高规格v1 §4.6要求整理约不少于6个月、六条均线接近；§9B说等待密集区突破，跌回密集区且20组走弱时失效；§10要求目标在当时已存在。它没有给出箱体从哪一天开始、结束后怎样继承边界的算法，也没有明确规定B的初始固定止损必须是整段横盘最低价。

两工作区引用的`docs/handbook-30-videos.md`都已不在当前文件树，普通git历史路径查询也未找到。根据已有coverage-sync报告的对象线索，从旧git对象`1a321ce60e29ef5c11b735c73b5e593b749aed34`取回手册和旧v2规格，全文及SHA已保存在sources。手册是30期视频整理稿，其中17期完整笔记、13期补充摘要，不冒充本次逐段核对过的视频原声。

手册3.2将密集区解释成横盘箱体，要求时间与均线密集程度同时达标；旧v2 §9B把突破版写为超过区间最高价。这些支持“价格边界应代表所谈的横盘结构”的原则，但两份材料仍没有规定该结构起点如何机械识别。旧v2 §4.6的`bars_in_zone`命名也没有补上边界重置算法，不能单凭变量名认定现有代码应回溯哪一天。

当前两个repo的B、横盘、时钟、风险比条目一致。整个v2 YAML指纹不同，是其他4条情绪/定投规则差异，未混入本诊断。当前v2账本写“密集区下沿/整个密集区”，却没有明确说明区间只从watch开始；这是应当消除的解释歧义。项目本次最高依据仍按用户给的AGENTS指定v1，旧手册自身的“最高依据”标注只作为历史背景，不覆盖本次约束。

## 最小具体例子：2018-11-22

此前横盘状态从2017-07-03开始，watch当天已有341根寿命。新watch却在2018-11-21才建立，所以上沿只有2.723、失效位2.720。第二天收盘2.728，确实超过新watch上沿；与固定目标2.767相比，目标收益为原风险的4.875倍，因为预设风险距离只有0.008。

若所谓密集区指整个相关横盘寿命段，上沿为2.798、下沿2.595。这天2.728仍在大箱体里。此时问题首先是“这是不是我们所说的突破”，而不是保留同一个买点后把止损调得更宽。完整原数值和中间状态见minimal-existing-counterexample.json。

## 工程与研究建议

1. **可以直接补清楚的记录与表述**：同时保存横盘段起点、watch起点、寿命、有效横盘根数、价格区间根数；把现有stop描述为“本次watch观察区间下沿”。不得描述为“126根完整箱体的下沿”。这些建议本次未写入生产。
2. **需要补明的原则**：B是突破整个持续横盘箱体，还是在横盘环境合格之后，允许一次重开的局部小区间突破？用2018-11-22即可说明选择的含义，不需要用户选择统计方法。若按手册的整段箱体理解设计后续研究，应让用于入场的上沿与用于失效的下沿来自同一段明确区间。
3. **如批准整段箱体研究定义**：先写明起点是“使watch合格的横盘寿命段起点”、20根暂离如何保留、横盘结束后何时丢弃边界，固定后再运行独立研究。上沿与下沿一起改变，旧日期不会被强行保留，不从收益结果倒推更好窗口。原watch代理仍留作历史对照。
4. **当前判定**：不是已经证实的行情/算术bug；是研究定义尚未充分说明且与“完整箱体突破”名称存在明显偏差。补明语义前继续标研究代理，不能用第八批的少量成绩证明完整B有效或无效。
