## A/C/D到底缺什么

本次只读了当前规则与对应测试，不运行新候选，不把“有测试”写成“本轮测试全过”。

- **A回调**：已有价格、均线、方向状态、首次触碰生命周期与结构处理。需要给这次完整账户明确采用哪个触碰距离、结构确认版本和退出版本，并检查当时可知的多周期结构是否有对应资料。
- **C破底翻**：代码以已确认低点和限时收复等规则形成研究代理，已有版本及追加未来资料不改旧事件的测试；最高策略原文仍标精确2B结构未提供。不能把代码中的选择当作作者原定义。
- **D假突破**：已有区间、收复及生命周期规则，日线基础列可以从现有行情衍生。正式边界与四模块账户接入未验证；原文空头对称规则缺少定义，四基金做多研究不能顺手补造做空能力。
- **共同缺项**：同一机会归属、同时触发时的优先级、完整九条纪律、统一入场/退出/仓位归因，以及缺资料时到底拒绝还是标未知。最高规格已有冲突顺序未定义的标注。

因此，不应笼统说三模块“完全缺行情”；日线行情可复用。真正先要做的是一次有边界的定义与输入核对。多周期或历史成分等缺口若成立，应明确停点，而非靠新代理默默替代。
