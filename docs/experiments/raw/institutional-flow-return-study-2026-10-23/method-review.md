## 2. 先固定用途，再决定是否值得投资料成本

**主问题：** 每季作一次低频观察时，已公开的基金赎回与其此前持股，能否在已知股票近期涨跌之后，进一步区分这些股票未来一季度的总回报？这个用途保留在股票范围，尚不对应ETF买卖规则。

金融理由是资金需求可能引起出售，而共同持仓可能传递影响。竞争解释至少包括此前差业绩引发赎回、共同风格暴露、投资者预判、基金经理调仓及现金缓冲。由于公布已经滞后，出售造成的压力可能早已被价格吸收；公布后的延续、反弹或无关系均可能发生。因此先报告带正负号的关系和量级，不看到负数就改做反向、看到正数就改为追涨，也不预设“高持仓必反向”。

**投入决定：** 先补能同时产生可比净流入/净流出、不同年份及不同管理机构的资料。不必等到全市场无一缺项才做限定研究；可以用在看收益前固定的、历史身份可核的子集，但明确选择方式、漏失与外推边界。不能为追求样本行数，把同一基金的多个份额、同管理人的近似基金或更多相同股票当成独立经历。

## 3. 股票问题的最小可执行定义

### 3.1 观察量和样本

采用连续完整报告区间q及前一期q−1。对基金f：

`net_flow[f,q] = sum_months(sales - redemptions) / net_assets[f,q-1]`

`redemption_exposure[f,q] = max(-net_flow[f,q], 0)`

再投资单列，不混进主净流量；期初净资产须为正，字段缺失不补零。经济区间须连续，不按文件所在季度代替报告期，也不跨缺报硬连。异常大额先查合并、清算和单位，不能看效果后裁剪极值。

若没有可靠股票市值/成交量的历史口径，最小版本可固定：

`X[stock,q] = sum_f(holding_value[f,stock,q-1] * redemption_exposure[f,q]) / sum_f(holding_value[f,stock,q-1])`

这表示“样本基金持有该股的资金中，所对应的净赎回程度”，是**持有人资金压力暴露**。分母包括合格的净流入和零净流量基金持仓，不只保留流出者。它不等于卖出金额占全市场成交量、不等于机构持股比例，也不能称真实卖压。若主控取得可靠期初股票规模/流动性数据并采用另一分母，须在效果前另定公式和金融含义，不能边看结果边换分母。

期初持仓用于避免把当期已经卖过的持仓反过来当压力来源。股票总体以期初合格持仓决定，不能要求股票在期末仍被持有才进入。对每股保存基金数、管理机构数、持仓金额、最大基金贡献和单一管理机构贡献。未进入样本的基金不是零流量；总分母只是已覆盖基金，覆盖变化必须可见。

最小主体仍可限定当年原件确认的美国主动开放式股票基金、美元普通股及可核的证券身份；不要把“发行人注册地美国”改称“全部美国上市股票”。基金及股票成员按当时资料进入，不能只取今天仍存续者。无法核退出价格的股票保留为未知结果，说明缺失占比及集中位置，不以完整未来价格倒筛起始总体。

### 3.2 公开日期、决策日和收益起点

推荐使用**共同的季度末观察日**，每个观察日只使用此前确已公开的完整申报；随后评价下一季度，避免不同基金的不同申报日被当作同日排序。对每基金选择最近一份可用报告，记录经济结束日、公开日、距观察日天数；无连续前期或超过预定正常披露周期的旧资料不无限沿用。最大可接受陈旧期由实际制度和覆盖在效果前固定；不能根据回报挑。

1. 先核 `FILING_DATE` 对应首次公开的NPORT-P版本。法定60日期限只是制度期限，不证明每份记录在该日已公开，也不证明今天镜像里的修订当时可用。
2. 已确认首次公开但只有日期时，可保守使用**申报日期之后的下一个美国交易日**作为最早可用日，并在该日或之后的收盘决定；不要求为所有记录补不可得的分秒。假期、时区、文件日期均留表。
3. 若只能取得一次性批量发布日期，按真实批次可用日研究；不能回填为更早申报日并声称可执行。若完全没有可验证公开日期，可做另标的历史关联描述，不能进入“当时已知资料”的主结果。
4. 修订必须保留首次值和可用日期；首次版本缺失时相关记录不能冒充当时可知版本。目标期收益使用后来的最终结果资料合理，输入特征不能这样回填。
5. 股票主标签用共同观察日之后可执行价格起算至下一季度对应端点的含分红总回报，确切交易日、开盘/收盘、拆股与退市处理在合同冻结。若用观察日收盘作标签起点，则所有信号须在该收盘前已可用；不要同时写成第二天买入后的已实现收益。
6. 结果所用季度的申报可晚于结果月份，这是事后标签可观测，不是特征可提前使用。重叠、尚未成熟与缺失标签逐项列出。

因为信号已经落后实际压力一段时间，这个检验回答的是**公开后还有没有信息**。它不能证明压力发生当时有没有价格影响；公开后无增量亦不能否定当期机制。

### 3.3 必不可少、但可以有边界的价格/身份核对

CUSIP到证券及价格序列的映射必须带有效时期；今天ticker相同不足以证明历史同股。只覆盖可核子集可以接受，但名单和排除在看收益前固定。优先核分红、拆股、改名/合并及退出；不从股票数量比推断未经调整的真实买卖。主定义用期初持仓金额可减少跨期股数变更需求，但无法免除未来收益证券身份和公司行动处理。不能因为资料不完整，就只选今天熟悉的大赢家再外推全市场。

## 4. 基金级补充：可以做，但必须单列问题

有条件值得做的问题是：“基金的已公开净流量，在已知该基金过去收益后，能否区分未来一季度该基金收益？”这能初步看资金流是否还有排序信息，不需要假造股票价格，也能暴露‘只是追逐过去业绩’的竞争解释。它既不能识别持仓股票的冲击，也不能当作原股票问题已完成。

最小要求如下：

- 对象计数单位为SERIES_ID；同基金多个CLASS_ID共享组合和净流量，不能扩充为多只独立基金。
- 收益需要预定份额规则。优先采用首次合格时已存在、身份可核的一个代表份额并固定；选择依据为当时可见的份额属性与明确确定性规则，不能挑回报最高、今天最长历史或最低成本的存续类别。不具备可投资门槛证据时只称研究代表份额。
- 不将多份额简单平均称基金资产加权收益；若无期初份额资产权重，基金层真实加权回报未知。代表份额费用差异可影响横向比较，应保留并说明。
- `MONTHLY_TOTAL_RETURN1/2/3` 要从原表/实例确认月份顺序和百分数单位；三个月收益相乘得到季度收益，不能直接相加。相同series/class/month的重复或修订逐项解决。
- 共同季度末观察，未来三个完整自然月作结果，可以避免用月收益表虚构某个申报日之后的日收益。若观察日信号未在该月末净值决定前可用，则推到下一个合格观察日。实际申购截止、费用和投资者可买的份额未知时，只是前向净值结果，不能叫可实施交易收益。
- 简单对手用**观察时已经公开可知**的前期累计收益。若仅有N-PORT已披露、已经陈旧的月收益，须明确这是“滞后公开收益对手”；它弱于当时通常能观察的最新基金净值动量，正的增量不能宣称超越最新价格信息。优先取得代表份额的历史可见净值，使基准截至相同观察日。
- 流出前差业绩、赎回与后续收益可共同受风格影响。控制已知过去收益只能减少一种解释，不能写成因果。ETF、指数、债券、货币、基金中基金等不混为一组。

只有旧四基金三季度可用时，停止新的收益拟合；不是认定因子无效，而是原样本没有足够不同状态的对照。较长且类型明确的四基金可以做这四只的时间描述，但仍不能用每期4个点的相关系数或加入过去收益后的极少剩余信息，宣称稳定横向排序能力。扩大样本的理由应是增加不同机构和正负流量对照，不能只说“凑更多数据”。

## 5. 收益与IC怎样比较才不偷换“增量”

IC在这里指：**同一观察日，把对象按指标从低到高排列，再看这个次序与后来收益次序有多一致**。每个观察日单独计算Spearman排序相关，然后按日期同权汇总均值、中位数、正负比例与分布；不把全部股票×日期混在一起算一个相关数。每期对象太少、指标没有差别、缺失过多时列不可估，不填0。

主简单对手B建议为观察日前12个月、扣除最近1个月的含分红收益（常见中期趋势），而不是只用与陈旧报告同一季度的回报。主控可因确实可用的数据预先改为一项明确的简单过去收益对手，但必须说明所回答范围，不以数据方便削弱对手而不披露。固定一个主期限，不比较多个期限选最好。

最低三列：

| 比较 | 应输出 | 解释边界 |
|---|---|---|
| 只看已有价格信息B | B与未来收益的逐日IC；固定分组的未来收益差 | 简单对手本身能区分多少 |
| 只看资金压力/流量X | X与未来收益的逐日IC；固定低中高组收益、数量与覆盖 | 原始关系，可能由价格、风格或时期解释 |
| 已知B后再看X | 同日将X及未来收益的排序分别去除与B排序的线性关系，再计算剩余部分相关；同时按预定B组内比较X组未来收益 | 这是“控制这一价格信息后还剩多少关联”，不是自动得到可交易预测组合；组格不足时明确不能估计 |

第三列的相关数应叫“控制已知价格后的相关”，不可把它与第二列直接相减后说增加了多少投资收益。若主控选择预测模型，才另做B-only、X-only、B+X同样本同训练流程比较；参数只能用目标已成熟的过去时期拟合，且不得随机打散同一日期或把未来标签跨入训练。模型在当期数据上拟合提高解释程度，不构成未来预测增量。少数据时优先无训练的上述条件关联，不强造复杂模型。

固定分组（例如三组）按指标原始方向报告高减低，不按结果翻转方向。大量零压力产生并列名次时保留并列和单列零组，不把同值随机拆开制造梯度；若零组占比导致预定三组不可分，报告不可分及非零覆盖，不能结果后换阈值追正。条件组数在资料资格检查后、读结果前固定。

如用户希望看到策略收益，需要另有明确选择方向、持仓权重、再平衡、等待和交易规则；本轮信息检验不把分组收益差称账户年化。股票含分红收益、基金报表总回报（费用涵盖范围待核）、扣除投资者交易成本后的净收益分开；缺买卖费、冲击、价差、申购赎回费用和周转时，净收益写未评价，不能默认0成本净盈利。

## 6. 最少的反证和不确定性检查

1. 保存逐季度结果；先看总量与逐期能否对上，再做前后时期和最大贡献期剔除的固定诊断。某一行情贡献大时直接展示，不能只报平均。
2. 日期整组保留所有对象，用时间区块重新抽取计算不确定范围；这样允许同一时期股票共同涨跌及相邻期压力延续。区块长度及使用理由先定，少季度时如实说明无法给可靠精度，不拿几十万持仓行当几十万独立事件。无须同时堆多套统计方法寻找显著。
3. 以基金管理机构为单位检查集中影响。只剩四基金且两只同机构时必须直说；可做逐一去掉最大贡献机构的固定诊断，不靠它挑最佳基金池。
4. 对原始差额与控制B后差额同时列反方向时期。零/净流入、净流出各自覆盖；基金期数、股票数、管理机构数、共同观察日期数和可成熟结果数分开。
5. 如未来要作过滤用途，完整列出被排除对象中少亏的机会及错过的大涨机会；当前没有交易路径时只报机会收益差，不叫实际账户少赚或避损。

不先设没有金融依据的“IC必须大于0.02”“至少几百只/多少年才有效”。应根据日期跨度、依赖、幅度和不确定范围判断能支持到哪里。无最小有用幅度的先验依据时只报告量级和范围；不能因不显著就宣布排除有价值的改善。

## 7. 执行顺序与停止条件

1. 主控先收齐资格表：来源固定版本、公开时间规则、历史基金类型、连续流量/期初净资产、份额/证券身份、结果价格、共同观察日及覆盖分布。做若干手算含边界/修订/缺失例子，尚不看收益关联。
2. 若股票分支关键身份与价格合格，冻结一个公式、一个期限、一个主基准及上述反证后，运行一次核心比较。股价资料可通过限定子集解决时先做该子集，不要求全市场无缺陷。
3. 股票分支确实卡住时，保留原问题blocked/未评价，并由主控在原合同附件明确基金级补充问题及其预算；用户已有广义流量信息收益授权时无需仅因常规实现选择再次问，但不得覆盖其股票用途或把另一个问题当交付完成。
4. 必要比较完成且增量未得到支持，可以关闭这个**具体用途**；若范围仍包含有用改善，写证据不足，不开参数网格。净收益、因果、ETF及其他用途仍未评价。
5. 真正阻塞项：无法核输入公开时间、合格历史对象、连续流量/净资产、证券或份额身份、成熟结果；没有可比基准亦阻塞“增量”结论。无可执行权限或本轮真实预算不足时保存状态，不把暂停写无效。

### 9.1 有成交量时，优先选这个主分数

`F[f,q] = max(sum_months(redemptions - sales), 0) / NAV[f,q-1]`

`L[i,q-1] = sum_last_63_trading_days_before_flow_interval(raw_close[i,d] * raw_volume[i,d])`

`X[i,q] = sum_f(H_USD[f,i,q-1] * F[f,q]) / L[i,q-1]`

此处H为期初美元持仓金额。X的单位是相对前期一季度股票成交金额的比例，其大白话名称为：**若按原持仓比例处理净赎回，估计涉及的金额相对该股票平时成交金额有多大。** 不把比例假设写成真实卖出、被迫出售或基金清空仓位。现金、其他资产、实物安排和主动调整都会使实际出售不同。

这个分母比第3节的持有人平均净流量更接近可能的价格压力规模；成交字段与历史身份合格时，建议在效果前选它为唯一主版本，而不是两者跑完择优。63交易日仅为近似一季度流动性尺度，不代表已找到最佳参数。主控若改用准确前一完整自然季度成交额，也须先固定且不按效果选择。

**主公式不减再投资。** 旧试点区分外部申购与再投资；再投资涉及分配与再投入，不能在没有完整现金会计依据时直接当外部新增资金，从净赎回减去。保留再投资供核对，但不无声改变净流量定义。分母用同时期未调整价格乘匹配的原始成交股数；复权价格乘未作相应调整的股数会把拆股前后金额弄错。成交量为零/缺失、异常单位或分母不全的记录单列，不用无穷大或零代替。

分母截至流量区间开始前，避免以后发生的流动性变化反过来决定当时压力规模。季度末公开后预测时可以另观察最新流动性，但那是控制信息，不回写主压力定义。四只基金的财务季度若一致便按同一经济区间算；若不一致，要先规定最新可用区间与年龄的组合，不把不相同月份直接称同季压力。

### 9.2 四基金特别容易出现的机械关系

令 `D[i,q]=sum_f(H[f,i,q-1])/L[i,q-1]`，`alpha[f,i,q]=H[f,i,q-1]/sum_f(H[f,i,q-1])`，则：

`X[i,q] = D[i,q] * sum_f(alpha[f,i,q] * F[f,q])`。

原平均流量分数是去掉D后的版本。每个季度只有四个基金流量数，股票间的差异来自持有者构成和成交规模。把同一期各基金暴露 `H[f,i]/L[i]` 全部纳入可自由变化的控制系数时，X完全在这些变量的线性组合内；不应再要求它有“剔除全部这些信息后的独立冲击”。对原平均分数，控制完整alpha也有同样问题；对排序转换后的残差出现非零，并不创造新的独立原始信息。

这不意味着研究毫无意义。未决问题可以是：**知道原持仓构成后，加入各基金随时间变化的实际净流量，能否改善后来收益的预测？** 它是资金流与原持仓共同形成的、随时期变化的预测信息；因果机制仍未识别。

### 9.3 不借行业和市值资料，也能执行的最小控制方案

全部特征仅用观察时已知资料，在效果前固定：

1. 观察日前12个月扣除最近1个月的总回报，以及最近1个月总回报：分别照顾中期趋势和短期反弹这两个价格解释。
2. `log(L)`：前期股票成交规模；它不是公司市值，不能说已完整控制大小公司差异。
3. `D`：四基金总持仓相对成交规模，避免只是重仓、交易不活跃的股票不同。
4. 三个独立alpha，固定以第四基金作参照；四者和为1，不把四列加截距造成确定重复。这个检查处理可观察的基金持有者构成；仍不能消除所有行业、风格或经理私人信息。

建议作为同一必要比较的B，随后比较B、X、B+X。若实际覆盖/可估性不支持完整版本，保留价格+流动性+持仓强度作为较弱B，并将持有者构成影响“未剥离”放到结论旁；不能删除alpha检验后仍宣称已排除基金风格。无必要为了本题先搭全行业/市值历史库。

B+X需跨日期共享估计规则，才能评价当期新流量的作用。可用简单线性模型、只用过去已成熟结果的扩展训练，每日期总权重相同，防后期股票多的日期支配。选择训练预热期只作为拟合可执行条件，不把它当科学有效性门槛；精确起止期在知道覆盖、未看效果时冻结。原始有符号X的逐期IC与回报分组仍单列，模型自动学到的方向不能反过来改原始假设。

模型比较须同一股票×日期评价集、同样价格信息与预处理。各期横向排序或缩放只用该期可知特征；训练目标必须在预测日前成熟，不随机拆行。不要求同日额外回归掉X的全部原始构成，也不在同一期用后来收益估计系数再称预测。公开后长历史的回看仍是历史探索，时间顺序正确不自动等于从未看过的新验证。

### 9.4 身份连接与缺失的可用边界

同报告日其他基金给出的ticker可以帮助解决映射，但唯一字符串不等于证券身份最终证明。至少核CUSIP/ISIN、币种、普通股类别、报告日与ticker有效区间；连接所用申报必须在观察日前公开。未来记录可用于事后核身份真伪，不可据未来价格可得性筛历史买入对象。价格面板ticker的后续重用、改名和退出仍需核对，不能因NPORT有ticker就宣布整个链合格。

四只便利选择基金的持仓子集可以构成一个有价值的**范围有限的试验**；主要结果就叫“四基金已覆盖美国普通股”，不叫全机构或ETF。只要按原持仓总体保留价格缺失清单、按金额/数量披露覆盖及退出，且缺失集中对结论的影响说清楚，不必等到全市场完美恢复才算限定样本。但若连关键大额持仓或退出者的结果都系统性缺失，真实总体收益无法判断；可以报告可观察子集的条件关联，不补零、不以赢家存续子集代替总体效应。

本补充建议的投入选择：先完成四基金更长历史、类型适用期、同日历史证券连接与成交字段资格，做一份已公开后季度预测检验；基金级收益问题留为独立备选，不作为价格映射已有可行路线时的替代交付。

## 10. 对正式冻结前设计的复核（仅追加，未计算效果）

审查对象：`design-before-effects.json`，`fixed_at=2026-10-23T17:58:08.157914+08:00`，本地定义 `local:us-four-fund-holder-redemption-pressure@1.0.0`。本节取代前文涉及候选模型和候选分母的建议，作为这份具体设计的审查；不要求运行前文其他版本。

**结论：这份有界设计可以冻结执行，没有必要另开参数或分母比较。** 成交股数和价格单位未核合格，因而在效果前固定持仓加权净赎回比例，是合理的范围收缩；结论只涉及四基金持有者的资金流，不涉及股票总交易压力。以下是必须落实的实现条件与结论边界。

1. **总体与未知结果不能混淆。** 按期初持仓与当时可知特征形成总体；未来缺价格、公司行动或ticker歧义只令对应结果未知。设计末尾的“歧义排除”须解释为不计入可测收益，不从原形成总体删去这批股票。只做exact ticker与点/横线格式处理可作为有界选择，但不证明不存在ticker重用；无法核的仍保留未知。过去特征本身身份不明可以使预测不可得，理由与未来结果未知分列。每股若某个有正期初持仓的基金缺流量/净资产，不能把它当零或从分母删除后重新归一化；该股信号未知。共同四基金日期缺一只报告的情况同理。
2. **固定权重与目标函数。** ridge是给大系数加惩罚、避免少量资料过度拟合的简单线性拟合。设计应按 `sum_dates[(1/n_t)*sum_observed_training_rows((demeaned_y - normalized_X @ beta)^2)] + 1*sum(beta^2)` 实现；此处n_t为该训练日实际合格且有成熟结果的行数，每日期总权重1。若软件还把整个损失除以日期数，惩罚也必须作对应换算，否则不再是固定λ=1。三模型同一训练日期、同一共同合格训练行、同一目标处理；不要X模型因缺少B要求而用额外资料却称同样本对照。特征在完整当期特征合格总体按均值/总体标准差处理，常量置零；有结果子集与全体均值可能不同，故“无截距”是本设计的估计选择，不称已经做了精确日期固定效应控制。
3. **训练与时点合理。** `target_exit < current_decision` 排除紧邻上一期尚未成熟的标签是正确的；因为其卖出价发生在当前季末之后，不能提前用于当前预测。8个成熟季度只是拟合开始条件，不是有效性标准。先前季度中已知的四基金构成与当期新增流量结合，可以在跨期同一拟合规则下检验预测改善；不能声称X在同日独立于完整基金构成。固定原始X正向反弹假设可以保留，报告有符号结果且不事后翻向。拟合X的方向与原始X方向属于不同预先登记输出，不能取较好者代替另一者。
4. **分组规则保留并列，不能补组。** 在完整特征合格形成总体计算平均名次，再用 `(rank-1)/(n-1)` 与1/3、2/3分组，符合不拆散同值的要求。常量无上下组；非恒定值也可能因大量并列而没有下组或组内仅少数对象，均如实保留。n=1不得除零。未来结果缺失后不重新排名、不补股票、不强凑三等份；某组无可测结果则组收益未知。逐期至少10对象是IC计算筛选，不保证可靠性，须同时报实际对象数、不同分数个数和组大小。
5. **比较必须成对且不隐藏缺失。** B和B+X在同形成总体产生分组，在共同可测结果行算同日IC；四种选择情况由原始上组选取关系定义，不受结果可得性重分。组收益只称“该组可观察结果的均值”，旁列全形成数量/持仓金额及未知结果比例。某日比较缺一边时不补0，配对日期数与被遗漏日期列出。区块抽取使用两边共同日期，保留原季度顺序；不能把删除后的不连续季度当成相邻连续季度而不披露。已计划的四季度区块、时期对照和去掉最大影响季度可以执行，不再扩一组窗口寻找稳定结果。
6. **成本是情景，不能叫上下界。** 0.20与0.50个百分点只能是明确假设的完整往返成本情景，没有成交资料时不是实际费用、净收益或成本边界。对同样假设每季度完整买卖一次的两种选股方法，都扣相同费用，其收益差保持不变；不能只扣B+X或把差额再单扣20基点。上组与全体同样假设时差额也相同。真正周转、未成交、冲击和连续持仓费用未计算；未知结果导致总体收益本就不能确认。可以给可观察子集的扣费算术，不能以此补成账户净回报。

执行冻结仍依赖主控的输入资格：确切原始/修订申报截至观察日可用、四只基金所覆盖年份的类型适用期、相邻完整三月流量和期初净资产、历史证券身份及价格标签核查。不同类型/缺失输入不可由此方法审查代签。上述资格若完成，允许本轮既定历史探索；没有要求等到全市场历史身份完美、取得行业/市值全库或扩大基金名单。

## 11. 效果运行前代码复核：具体实现问题

审查范围仅 `us-effects/run.py`、`design-before-effects.json`、`us-price-qualification/events.json`；不读效果、不联网、不另开实验。审查期间执行者正在修改代码，以下区分已读回修复与待执行者核销事项。中途记录的代码指纹为 `90cb60dc99d128281ff767e6660da78c9dec895f386eac66d0cc2ccd747c4221`，设计 `8b0fc999965a82477eb50d21337782eae3c26ac78efc384041ec271d8c1c9c41`，事件表 `55ddf20348cb12ed68f340436fa0a5cf2c83db0372f941e8d157b2b0385d2ce3`；最终执行须另绑定修复后的代码指纹，不能把本中途指纹当最终代码。

**已核符合：** `weighted_pressure`用全部已覆盖期初持仓金额为分母；有正持仓而缺基金流量时不填零。全部模型使用相同特征合格股票，未来未知结果不改变分组；训练仅用 `exit_date < decision_date` 的已成熟标签、每训练日期总权重1，ridge精确为日期均方误差之和加λ=1惩罚。B、X、B+X训练行一致，拟合账保存日期、行数、最晚目标退出日与系数。平均名次分组保留并列；未知结果留在原形成行；两种假设成本对上组与全体同额扣减。没有发现主比较中随机混合日期训练或用未来标签拟合当期的问题。

必须核销的具体问题：

1. **历史动量跨退出断点（已见代码修复，未替执行者运行测试）。** 初版 `price_features` 只核252日端点和最近63日逐日资料；若SBNY/SIVB退出断点在较早月份，端点都有效时仍可能把未核清的退出前后价格拼接成动量。已读回新增 `crosses_exit_gap`、`history_exit_rights_unverified` 和“断点在最近63日以前”的合成断言。最终应由执行者跑合成检查并保留结果；不删除形成行。
2. **季度日历来自现存行，会吞掉整期缺失。** `effects` 用 `sorted(formation.decision_date.unique())` 作为`summarize`和区块抽取的时间轴。某整季度没有形成行时，虽然bootstrap函数注释称保留完整季度，实际已经把这个季度压掉。给汇总/抽取使用设计start/end构造的完整季度网格，缺期补NaN；或在执行前明确断言形成日期等于完整预定季度网格，失败则保留缺失而不执行错误抽取。不能仅因每期内部保留NaN就宣称季度间隔已保留。
3. **缺失价格来源会被负下标变成有效来源。** `PriceSeries`的`pd.Categorical`把缺失来源编码为−1；`self.sources[self.source_codes[ix]]`会取最后一个真实类别，若是yahoo/tiingo/crsp，资格检查可能错误放行。必须对负编码返回缺失/无效来源；若整个类别表为空还会触发索引错误。添加一个价格为正、volume为正但source缺失的合成例子，确认不能被`price_usable`接受。即使当前原表恰好无缺失，这条身份核验也不能依赖负索引误行为。
4. **覆盖基金字段被defaultdict读取污染。** `prepare`为计算三项alpha读取 `holdings[FUNDS[0..2]]` 时，会插入原本没有持仓的基金零值；随后 `covered_funds`把它们列为真实持有者。使用 `.get(fund, 0.0)`，覆盖名单只列正持仓基金。此项不改变此前已经计算的X，但会错误扩大覆盖解释和后续核算的基金数。
5. **波动基准的定义与实现未完全对齐。** 设计写63日“日总回报标准差”，代码为`diff(log(adj_close))`。前者通常应对应`adj_close[1:]/adj_close[:-1]-1`；二者数值不同。效果前落实普通日总回报标准差，或明确在冻结定义中记录对数收益口径并给理由；不能运行后选择较好的口径。仅是定义一致性修正，不授权比较两版效果。

两项输出解释注意，不要求额外方案：Fidelity敏感性会使只有Fidelity持仓的股票分数未知，因此其IC不能直接减全原样本raw_X IC并称“去掉Fidelity的贡献”；应单列覆盖差异，若做差则须共同股票×日期。逐模型最有影响季度已输出；主增量的集中程度若在主控汇总阶段核算，直接从已保存同日期差额核对即可，不另拟合或选择时期。
