# 美国四只固定基金的历史类型与公开时点核查（2026-10-23）

## 结论与使用范围

这四只事先选定的基金都有 2019 年末的同系列申报，且跨年资料支持其“主要投资股票、由经理选择证券”的类型。补充核查后，Parnassus 的 **2019-05-01 SEC 完整提交文件**直接证实该策略；Contrafund 的 **2019-08-27 波士顿大学退休计划资料**也描述同类策略，但它不是基金招募书，其最早读到的 SEC 策略原件仍为 2021-03-01。**这些是若干历史锚点，不是 2019—2026 每次策略修订的逐份核对**。可以据此提出一个有条件、方便抽查的历史候选组，不能把四只推广为美国主动基金整体，也不能把按基金知名度挑出的存活样本说成无偏总体。历史年份逐年类型严格锁定、停业基金覆盖和与指数基金比较仍未完成。

四只和日期来自既有 [2024/2025 资格底稿](../../institutional-flow-holdings-pilot-2026-10-21/fund-type-sources/sources.md)及下列 SEC 原始文件。本文件只核基金类型与信息公开时点；没有读取收益、按收益换基金或做效果统计。

## N-PORT 的当时可知时间

[SEC 2019 规则说明](https://www.sec.gov/rules-regulations/2019/02/amendments-timing-requirements-filing-reports-form-n-port)说明：基金每个财季三个月的报告均须在财季末后 60 天内申报，其中**第三个月的报告在提交时公开**，第一、二个月不公开（特定保密项目除外）。[SEC 2025 延期规则](https://www.sec.gov/rules-regulations/2025/04/s7-26-22)把 2024 新的逐月公开制度推迟到 2027/2028 执行，因此本研究截至 2026 的时间判断仍按前述季度公开制度；[2026 年再改回季度的文件](https://www.sec.gov/rules-regulations/2026/02/s7-2026-05)是提案，不是已经生效的规则。[SEC 数据集页](https://www.sec.gov/data-research/sec-markets-data/form-n-port-data-sets)只收已公开申报，但数据集发布时间不能代替逐份 EDGAR 申报的公开时间。

## 可恢复的证据边界

要把“这四只在所有历史季度都保持该类型”从推断升级为逐季确认，需复查各季度有效招募书和补充文件，尤其 Contrafund 2019/2020 SEC 原件以及份额类别新增日期。已核验的 2019 NPORT-P 官方例子支持以“第三个月原始提交日加保守等待”为探索性时点规则；若使用批量镜像，还须确认其表型、报告期和日期列含义，抽查源申报与修订，不能声称所有行均已逐份官方核对。这项进一步核对不应被误写成必须人工打开每一行才准做有界探索。若这些证据取得前运行数值研究，应标作**事先固定的四只基金小组的探索**，并把历史分类缺口和幸存者选择写在结果旁。任何统计只能回答该组内部的机制问题，不能推断主动基金整体优势或实际可交易性。
