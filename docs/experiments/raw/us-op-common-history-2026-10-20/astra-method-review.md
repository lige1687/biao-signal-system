# 年度经营盈利与动量同池比较：独立方法审阅

审阅日期：2026-10-20（Asia/Shanghai）。模式：只读方法审阅；未联网、未计算盈利因子或收益、未扩大取数或执行预算。主控负责采纳与最终判断。

## 一句话结论（大白话）

目前可以继续核实资料，但还不能计算“盈利信息在相近动量下能多帮多少”：历史名单与公司身份尚未完全对应，退市和停牌后的损失尚未纳入完整路径，年度报表字段也还没有组成同一口径的盈利比率。应先完成下述有限核查；大量下载成功、月末报价齐全或程序测试通过，都不能替代这些条件。

## 已核证据及其边界

- `membership-execution-receipt.json` 与外盘 `membership-price-qualification/summary.json`：120个月、60,510个月份—代码记录，60,480条有符合当前检查的正数报价，218次指数成员离开事件。**离开指数不等于证券退市；月末有价不等于整段持有可以退出。**
- 同一名单来源衍生的 FJA 对照不能作为独立确认；改名映射后仍有3,923条月度差异。2014年末两表共同435项、各自独有67与64项；不能凭后期吻合较高忽略早期差异。
- 已读 lawcal README：CIK存在人工回填；历史日期有用网页修订时间近似的情况；不具有完整证券改名模型。它是身份候选来源，不能把后继公司的CIK倒填前身。
- 已读 johnbrick README：价格混合来源；`close`是否已处理拆股随来源变化；`adj_close`旨在统一分红拆股口径，但仍需对本次固定文件核查。README明确存在沿用旧价的停牌记录，并指出 SIVB、SBNY 的延迟成交损失；这些是来源自述，不能当作本轮已核终值。
- 已读 `renames.csv`：既有名称更换，也有并购、拆分或重组候选，如 UTX→RTX、PX→LIN、ARNC→HWM。通用字符串替换不能证明证券经济权利或发行人连续。
- `fsds-development-receipt.json` 与2014Q1资格摘要：4,781份年度申报、601,959条保留事实，正确保留不同 accession、可比年份及缺失；尚未证明字段经济含义、年度归属、权益分母或可用时间。已读的 `identity-daily-receipt.json` 仍是两次失败且未产生结果文件的历史状态；不代表当前其他执行者的后续运行状态。
- 既有 French 报告的“盈利高组优于平均、未明确优于中组、近期反转”可作为研究理由，不能代替本次逐股增量证据。本轮历史已经被研究选择使用，不是全新验证。

## 先达到什么条件，才允许进入一次效果统计

| 必需条件 | 可执行核查及拒绝条件 |
|---|---|
| 历史证券身份 | 每条成员区间绑定研究内部证券ID、该时段代码、该时段发行人CIK、证据及生效日期；多股权类别分开。相同CIK不自动合并两类股票，不同CIK不自动断开同一经济投资。重点核 Google/Alphabet、ACT/AGN、IR/TT、CB/ACE 与所有多候选/改名链。无法唯一对应的月份保留为未知，禁止按现在名称择一。 |
| 名单资格 | 解释2014锚点及逐月差异的类别：日期错位、代码别名、重组、实际遗漏。对会改变某次形成名单的未决差异，给出两种名单下覆盖范围；不静默取两表交集当完整历史指数。无法确认时可报告明确受限的历史大盘股子集，不能声称复原完整S&P500。 |
| 严格盈利字段 | 每个计算值记录 accession、tag+version、单位、期间、原始金额、采用/拒绝原因。收入、成本、销售管理费用、利息须同一合并范围、同一年度；不能相加主表合计及子项，不能把展示用 `negating` 再次当经济符号处理。缺失与明确零分开；零只来自原始明确零或足以证明该项为零的文件。 |
| 不以近似公式冒充原目标 | `OperatingIncomeLoss` 可能额外扣了研发或其他费用；净利息不等于利息费用；金融公司的利息可能已进入收入/成本。不得无差别代换、重复扣减或把不存在适用标签当零。主表缺字段先查是否在现有原件附注；若当前抽取只保留 IS/BS 导致缺失，应定位到原件，而不是继续增加公司数。 |
| 权益分母 | 在效果统计前冻结目标版本的 book equity：普通股权益、优先股、少数股东权益、递延税等具体如何处理，何种标签可等价、负值/零如何处理。现有 brief 只写 BE，尚不足以声称严格复现某一 French 版本。不能直接把 `StockholdersEquity` 或“资产减负债”当所有公司的合格替代。分母非正或范围不符拒绝评分，单列覆盖；接近零造成极端值优先用排序减少幅度影响，不事后截断找好结果。 |
| 当时可知 | `accepted`先核时区，再统一时间；月末截点只能用此前已接受文件。推荐一律从接受后下一个完整交易日视为研究可用，不能用 `filed` 或财年结束日替代。保存初报与修订：修订只能在其接受后生效；10-K/A没有完整字段时不与旧表随意拼接。历史数可来自当时已公开的可比列，但不能来自观察时点之后的申报。 |
| 年度期间 | `qtrs=4`只证明约四季，不能单独证明当前财年；`sub.period`可能是月末近似，不能机械要求与实际 `ddate`相等。按原件年度表头、财年与实际年度截止日核52/53周、比较列、改年结及过渡期。同一观察月使用哪一“先前年度”须冻结；每月采用最新可见年度属于本地适配，与French固定年度形成分开标识。 |
| 完整后续结果 | 每个形成时已入组证券都追踪到目标期末，包含离开指数、并购、停牌和清算。真实现金/换股权利与生效时间有证据才折算；未解决终值保持未知，不能最后报价续填、零收益填补或删除后把剩余权重重新分配。停牌时不能模拟卖出，指数删除日不能冒充卖出日。 |

**最小实际样例复核**：选取实际映射机制各一例，覆盖正常年度、53周/非月末年结、重复收入标签、利息缺失或净额、负权益、优先股/少数权益、10-K/A与前期比较列，再加上述身份/停牌事件。选择按失败机制而不是事后收益。每种机制只要仍会静默生成错误数值，就修正其规则后再运行受影响资格检查；不要求无理由重跑全部历史。

## 最小同动量比较：先做信息评价

本 brief 的用途是月度观察与名单排序，因此最小主检验可用随后一个完整月的收益和损失分布，解释为“下次月度复核前的信息帮助”；它不回答一年持有效果。若主控实际要回答年度持有，须在看结果前将主期限改为12个月并补齐离开指数后的完整价格，不能先看两种期限再挑好结果。

1. **时点冻结**：月末收盘形成信息，下一交易日的合格价格作为结果起点；期末用下一次月度复核的相同价格约定。动量为第12至第2个完整月的总收益；把具体起止日期例子写进合同，避免相差一个月。起点晚于信息截点；用收盘价作为研究结果起点不等于证明真实订单可以成交。
2. **共同资格**：先按当时可知的名单、身份、动量、财报字段建形成名单；再连接未来结果。未来缺价只能标成结果缺失，不能倒过来删除形成机会。基准、盈利分组和加入盈利后的比较共用同一已知资格集合；并另报“只要求动量”的更大集合，以显示财报缺失造成的范围缩小。
3. **最小分组**：每月将动量分成五组，再在各动量组内将盈利分低、中、高三组；分组方案在效果前固定，不寻找最优组数。比较高−中、高−低，以及去掉低盈利后相对原集合的变化。每个月各动量组使用相同固定权重，各公司同等权重；有多类股份时避免同一发行人被额外加权，规则预先冻结。展示15格的数量和结果，不能只给总平均。
4. **“动量相近”不能只靠分箱名称**：并列每格的动量实际分布。预先补一个更严格的核查：在同月、同动量组中按动量最近原则将高/中/低盈利公司配成不重复三元组，不根据未来收益择配；报告未匹配数量和剩余动量距离。只在共同动量范围内解释配对结果。若结论随这一必要核查反转或仍明显失衡，应写“尚不能区别盈利与残余动量的帮助”，不继续改分组寻找稳定正值。
5. **分别评价用途**：排序看之后收益排序与高、中、低差额；风险看损失概率、损失尾部和下跌月份差额；选择用途并列少亏、少赚及大涨机会。风险提醒比较同样数量的提示对象，不能靠多报风险取得更多命中。操作用途看每月名单变化、资料更新/拒绝次数。没有完整资金、成交和成本规则，不填策略年化收益、组合最大回撤或“降低账户风险”。
6. **一次必要反证**：按2015—2019/2020—2024、年份、价格来源、会计可映射范围和行业展示贡献；行业只能用已确认当时可知分类。缺历史行业则不能以今日行业消除行业解释。报告结果是否由少数公司/危机月份决定；这些为解释检查，不作为删掉难看时期的理由。
7. **不夸大样本**：每月先汇总差额，再按整段月份保留共同涨跌与时间关联来估计不确定范围；同一年度财报反复使用、同公司多月与多类股份不能算独立证据。十年只有有限市场阶段，不能把60,510条记录当同等数量独立试验。方法与时间段在计算前绑定，不用逐股独立抽样制造狭窄范围。

五组、三组是可复现的比较设计，不是统计合格线；稀疏或不可比的格子按事实报告。没有事先有依据的“多少改善才值得维护”，就报告量级、范围和维护成本，不补造及格线或声称已排除实际价值。

## 覆盖选择风险与停止规则

**必须先交覆盖漏斗**：所有历史成员月份→身份已核→动量可算→当时年度申报可用→分子齐全→分母合格→未来结果已知。按年、来源、加入/离开事件以及动量组给出数量和拒绝原因；能获得其他条件时进一步看行业。不要把“其中覆盖率高”写成没有选择偏差。

对形成时已评分但之后结果缺失的公司，损失概率可给透明上下界：未知项分别全部亏损、全部不亏损。普通股票总收益的上涨没有有限自然上界，未知退出/换股价值不能随意造一个对称收益区间。如果未知结果足以改变结论，就不能给完整池的确定增量；可报已知结果子集描述，但明显注明会遗漏困境公司。缺少OP的公司连分组身份也未知，不能仅靠对已评分股票的上下界推断全池效果。

**可以继续且会改变判断的工作**：完成已授权批量提取；核真实标签/分母覆盖和所有身份冲突类别；验证成员之间缺价、源切换和关键公司行动；确认SIVB/SBNY等形成持仓的完整损失路径；按当时版本做上述小量人工算例。它们回答的是“是否能成立公平比较”，有实际价值。

**不能靠继续抓更多相同资料解决的事情**：CIK不是证券ID、改名链混入重组、`qtrs=4`不指定目标年度、主表没有附注字段、无明确权益口径、退出资产权利未确认、财报缺失集中在特定行业。增加ZIP或更多存续公司不会消除这些缺陷。需要对应的身份/公司行动原件、期间/会计证据或明确缩小研究定义；缩小后必须更名并报告丢失范围，不冒充原任务完成。

**本轮状态建议**：`qualification_in_progress / effect_not_evaluated`。必要资格核查完成后：

- 存在可解释的共同覆盖、完整结果和清楚定义：冻结一次主检验，完成上述对照后按用途给“保留候选 / 未发现增量 / 仍无法区分”。
- 无法获得关键身份、字段或退出证据：停止受影响的效果分支，结案资格研究并明确原增量问题未完成；仅允许对明示受限范围作描述，不宣称完整S&P500/美股规律。
- 已获准、可执行的关键核查仍未做：不得以“证据边界”替代执行。实际预算或运行中断则保存剩余项并标暂停，不判因子无效。

恢复条件必须指向缺失的具体证据或已登记的必要动作；不以“再多一些股票/再多几年”作为自动扩样理由。股票信息价值也不能直接转成宽基ETF买点或生产技术过滤。
