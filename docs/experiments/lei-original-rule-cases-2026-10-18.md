# 研究怎么分工：先核原策略，再扩大样本

2026-10-18。当前交付：研究分工、原始出处核对、固定历史截面案例及输入资格；完整策略收益仍未评价。

## 一句话结论（大白话）

**每项研究都应先讲清金融含义、要帮助哪个决定、与谁比较、什么结果算没帮助。你负责判断方向是否符合实际需要，我负责查资料、设计检验、写程序、核数据与结果。** 已确认的范围继续做；只有原策略含义确实无法从资料确定、需要新增花费或要改变真实操作时，再给你具体选项。本轮已经把“原规则不清”推进到原作者的时间戳、三个真实历史案例和可复核的计数，仍未发现可宣布有效的新因子。

## 1. 每次开题，你只需看这六件事

| 开题内容 | 必须说清什么 | 谁负责 |
|---|---|---|
| 金融含义 | 为什么可能有用、在哪些情形会失灵；先写假设，不能见到好成绩才编解释 | 我提出并找反例，你看是否符合交易直觉 |
| 实际用途 | 帮助选机会、等确认、退出还是控制投入；可以先检验信息，不强行编成买卖规则 | 我具体化，你决定实际目标 |
| 简单对手 | 相同对象和时间下，已有价格信息、单均线、简单持有或固定较低投入 | 我选择并说明理由 |
| 增量和代价 | 多赚/少跌多少，等待多久，错过多少上涨，增加多少操作和费用 | 我同时计算，不能只报胜率 |
| 数据与检验 | 当时能知道什么，哪些历史已看过，缺失/历史名单/相关机会怎样处理 | 我负责，你不用选统计工具 |
| 结束条件 | 没帮助、效果不稳定、资料不足分别怎样结案；不换参数追正结果 | 我预先写清并保留失败 |

开题说明先给你看。沿用已确定方向的常规补测、实现修复和复核，我自主完成。新方向或会改变策略含义的定义先确认；不会每次运行脚本都问一遍。只有能改变判断的差异才追加实验，不把报告数量当进展。

“金融含义”是能够被推翻的解释。例如：短期回调缓和、较慢趋势仍在，等待底部与小周期确认可能减少过早进入；反面是确认太晚、买得更贵且漏掉好机会。这个解释值得检验，**不能据此认定均线就是投资者真实持仓成本，也不能提前认定两项确认有效。**

## 2. 本轮优先问题与直接查清的规则

本轮先问：**完整模块A的目标、首次身份和小周期输入，够不够准确，能不能直接扩大样本？**比较对象是两份已确认原文与现有近似实现，不是比较哪种解释回测更赚钱。

| 项目 | 已可从原文确定 | 当前行动 |
|---|---|---|
| 入场确认 | 《体系》§4.4要求底部构造和低一级多头同时成立；《实现》A3“至少一种”属于另一版本 | 保留完整与简化版本的区别，不拿简化成绩判原策略 |
| 首次身份 | 首次到20、60、120组分别识别；不是整段趋势只许一个首次 | 逐均线保留身份，不能为增加交易重置第一次 |
| 历史上方目标 | 《体系》§5.2和作者总纲示例先看20/60交汇，再看更高的20/60/120汇聚 | 不能把目标候选一律缩成六线同时汇聚 |
| 六个月整理 | 《体系》§3.2、《实现》§4.6要求整理时间与当前密集程度；没有明确要求126日每天都窄于2% | 排除这一未经原文支持的强加条件；整理起点仍需客观定义 |
| 目标价与失效价 | 原文要求事前存在的目标及对应结构失效，无法确定应标未知 | 不用更远目标凑够比例，也不把触碰低点自动当完整结构失效 |

这次没有修改两份原文、正式规则或已封存结果。上表是含义审查，不证明已有程序采用了所有这些误读，更不证明它们就是交易少的全部原因。

## 3. 把尚未确定的含义讲具体

以下是**人工边界例子**，用来讨论定义，不是市场成绩。

**例一：整理130日，其中最近30日六线宽度1.5%，此前4%。**原文没有说必须连续126日都低于2%，所以不能据此自动排除。但“这130日从哪天开始算整理”仍未被定义，不能反过来宣布它一定合格。

**例二：拟进入价100、失效价97；近处目标区108—110，远处118—122。**若已知近处就是首个历史成本交汇区，就不能为了得到更大空间直接跳去远处。

| 近处目标取价 | 可赚空间÷计划风险 | 对3倍要求的影响 |
|---|---:|---|
| 下沿108 | 2.67倍 | 不足 |
| 中间109 | 3.00倍 | 恰好达到 |
| 上沿110 | 3.33倍 | 达到 |

**可见，目标区域算得出来，还不等于目标价已经唯一确定。**取下沿可作为保守研究约定，但原文没明确指定，不能擅自称“原汁原味”。需先核原图/笔记，再确认必要的定义。

**例三：昨天趋势尚未成立，今天最低99、收盘104，收盘才第一次满足趋势条件，触碰区域为100—101。**一天的开高低收无法证明“先有趋势，再发生首次回撤”。程序可以保存这个边界情形；不能仅因后来没有成交，便把下次重新叫第一次。已有近似规则继续留作对照。
