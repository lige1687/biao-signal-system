- 纪律：不改 `configs/ src/ web/`；纯实验脚本；判定标准事前写死（见脚本 docstring）；结论只到「建议」级

## 0. 一句话结论

1. **美股：宽度调仓不成立（事前双杠全失，E5 判负）**。1986-2026 四十年，基准档 S2（B50 五档，低位重仓/高位轻仓）年化 5.7% vs 买入持有 9.1%（只剩 63%，<85% 线），最大回撤 −44.9% vs −56.8%（只降 21%，<25% 线）；**终值 942 万 vs 周定投 2697 万——跑不赢 DCA，择时无增量，如实报告**。激进档能把回撤压到 −38.3%（降 32.5%）但年化只剩 4.4%，双杠互斥与资金层结论同构。
2. **A 股：档位式调仓「有效」判定成立，但同样跑不赢 DCA**。短样本（2021-06→2026-08）S2 回撤 −26.0% vs S0 −39.8%（改善 34.9%≥30% ✓）且终值 102.7 万 ≥ 0.9×89.4 万 ✓；但 S2 终值仍低于周定投 110.9 万。**唯一跑赢 DCA 的是 S3 纯择时（B50≤40 全仓否则空仓，终值 126.4 万）——A 股牛熊分明，binary 择时有增量；美股同款 S3 年化仅 2.7%，惨败**。宽度调仓的价值在 A 股是双向的、在美股是负的，与核心假设一致。
3. **错过上涨的钱在美股是结构性的**：S2/S0 相对净值 1986-11 见顶后再未收复，四十年终端落后 73%；落后最重年份全是强趋势年（1995 −20.5pp、2013 −14.4pp、1997/2021 −14pp 档）——这正是手册 3.6 第 3 条「美股只买不卖、高位用对冲而非卖出、错过上涨代价远大于回撤」的量化印证。**手册作者的定性判断被四十年数据完整支持。**
4. **2026 背离市考场：调仓反应及时**。B50 从 1 月 84.4% 崩到 7 月 10.6%，周频档位 3 月即加到 0.8、7 月满仓（逆向买恐慌），S2 全年权益 102.5→102.7 万 vs S0 92.2→89.4 万——宽度崩没有伤到调仓组合，反而按 3.6 极值法则提供了买点。2021-06→2024-02 阴跌段（半覆盖）S0 回撤 −39.5% 被压到 −26.0%（S3：−22.5%）。

## 2. 任务一：美股四十年（1986-03→2026-08，周频 B50）

| 策略 | 年化 | 最大回撤 | 夏普(rf=0) | 终值（初始 100 万） | 换手 |
|---|---:|---:|---:|---:|---:|
| S0 买入持有 | **9.07%** | −56.8% | 0.584 | **3338.8 万** | — |
| S1 周定投（260 份） | 8.49% | −56.8% | 0.576 | 2696.8 万 | 100 万 |
| S2 V1 基准档 | 5.70% | −44.9% | 0.507 | 941.6 万 | 5.5 亿 / 1969 次 |
| S2 V2 激进档 | 4.40% | **−38.3%** | 0.444 | 570.3 万 | 4.6 亿 |
| S2 V3 温和档 | 6.89% | −49.2% | 0.544 | 1475.7 万 | 5.5 亿 |
| S3 纯择时 | 2.73% | −35.8% | 0.288 | 297.6 万 | 3.8 亿 |

- **判定：不成立**（V1 回撤降 21%<25%，年化比 63%<85%）；**E5：941.6 万 < 2696.8 万，跑不赢 DCA**。
- 月频对照（防过拟合检查）方向相同且更差：V1 月频年化 5.31%、回撤 −51.5%（信号更钝，躲跌更慢）——**结论对频率不敏感，周频已是较优执行**。
- 分年代（V1 CAGR / S0 CAGR / 回撤差）：1986s 6.9% vs 10.4%；1996s 5.7% vs 7.7%；2006s 2.3% vs 3.9%（唯一回撤改善明显段：−42.8% vs −56.8%）；2016s 8.2% vs 13.0%。**没有哪个年代 S2 年化占优**——降回撤的钱全部来自少赚。
- 错过上涨专项（S2−S0 年度收益差最差十个年）：1995 −20.5pp、2013 −14.4、1997 −14.3、2021 −14.2、2003 −13.0、1989 −12.5、1998 −11.9、1991 −11.2、2019 −11.2、2017 −10.9——**清一色强趋势年，S2 的档位表在这些年份只有 20-40% 仓位**。S2/S0 相对净值 1986-11-18 见顶后单边走低四十年（终端 −73%）。
- 机制：档位表是「低宽度重仓」的逆向结构。美股宽度 <40% 的时点大多在深度回撤中段——加仓加在刀落途中，回撤只降 21%；而宽度 >60% 的长期牛市常态让仓位长期只有 20-60%，复利被结构性截断。**手册 3.6 的原意是「极值区做交易」（≤15% 附近买），不是全程按宽度缩放仓位——按后者实现，四十年数据判负。**

## 4. 建议（均为建议级，下一轮预登记项）

1. **美股不引入全程宽度缩放仓位**（四十年判负 + E5 判负）。若要在美股用宽度，只按手册 3.6 原意做「极值区事件」（B20/B50/B200 同时 ≤15% 附近的中长期买点），不做常态档位——这是下一轮可预登记的对照实验。
2. **A 股可用 B200 档位定调总仓位**（短样本内 V2@B200 与 S3@B200 双改善，且 2021-2024 阴跌段、2026 背离段两个考场都过关）；但「跑不赢 DCA」必须如实告知：档位式在 A 股也输给定投，只有 binary 择时赢——**A 股下一轮应直接对照 S3 型（B200≤40 全仓否则空仓/低仓）与档位式，样本拉长后再拍板**。
3. 宽度层与资金层互补：资金层管「单笔风险与爆发段削减」，宽度层管「三年阴跌与背离市的总敞口」——两者叠加的联合回测（宽度 cap × risk_pct 降级）是接口落地后的验证项。

## 5. 局限与打折声明

- 美股指数为 yfinance auto_adjust 序列（分红再投资口径），与回测池 2016-2026 段拼接未做交叉校验（重叠段 2016-08→2026-08 与池数据同源 yfinance，风险低）。
- DCA 闲置现金按 0 收益计，对 S1 略不利——即便如此美股 S1 仍大胜 S2，结论稳健。
- A 股宽度全 A 口径 vs 基准沪深 300（口径错配）；样本 5.2 年且错过 2021-02 峰；A 股结论全部按「短样本 + 多重比较」双重打折。
- 宽度档位含未来样本内选择（手册 15/85 推导的档位），未做样本外切分。

## 附录：任务三——宽度仓位曲线与信号层/资金层的接口约定（只设计不实现）

**目标**：`src/lei_signal/backtest/portfolio.py` 的 `risk_pct`/`N_max` 之上加一层市场总敞口上限，由宽度档位曲线驱动，周频刷新，独立于信号判定（规格 4.2：市场层在交易层之前）。

**接口约定**：

```
# 新模块 src/lei_signal/market_context/position_cap.py（下一轮实现）
def position_cap(as_of: date, market: str) -> float:
    """返回 [0.2, 1.0] 的总敞口上限。
    - 输入：宽度 B50/B200（读 lab.db SP500 / a_share json，含 1 个交易日延迟防前视）
    - 档位表：与账本 rules.v2.yaml 同源配置（不硬编码），A 股默认 B200 版 V2 档
    - 刷新：周频（每周最后交易日收盘后），日内/日间不重算
    - 降级兜底：宽度数据缺失/过期 >10 个交易日 → 返回 1.0（缺数据不挡交易，
      与基本面「叙事层不硬过滤」同一纪律）
    """
```

**接到 portfolio.py（伪代码）**：

```
cap = position_cap(signal_date, market)          # 周频缓存值
effective_risk_pct = risk_pct * cap              # 单笔预算按总敞口等比缩
effective_n_max    = max(1, ceil(N_max * cap))   # 并发上限同步缩（档位 0.2 → N10→2）
# 回撤降级系数照旧叠乘：budget = equity × effective_risk_pct × drawdown_factor
```

**要点**：
1. cap 只缩「新头寸」，不平旧仓（与宽度调仓周频执行一致，避免日内抖动）；
2. cap 作用于风险预算而非名义市值，与 portfolio.py 现有 R 口径无缝；
3. 生效顺序：信号门禁（信号层）→ cap × risk_pct × 降级（资金层）→ 入场；宽度层永不直接否决单笔信号，只调预算——保留「市场层定调、交易层执行」的分层；
4. 回测侧同一函数复用（宽度历史序列已在 lab.db/json，无新增数据依赖）；
5. 验收实验（预登记）：a61 口径十年流 + cap(A股B200_V2) vs 无 cap，判定沿用本轮双杠（回撤改善≥30% 且终值≥0.9×）。
