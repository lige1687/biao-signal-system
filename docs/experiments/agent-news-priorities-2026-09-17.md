# Agent超级入口：消息可靠性与买前准备的优先级

## 一句话结论（大白话）

先确保Agent拿到的是最新、可核对的资料，并能明确告诉用户哪里断更；再把技术条件、相关事件和下一步串成买前准备。消息面确实停更，但宏观消息早已接入Agent，缺的是可靠更新、来源和事件状态。建议按“资料可靠与既有入口稳定 → 买前卡和相关事件 → 按需联网解释 → ETF产品比较”推进，历史事件收益数据库暂缓。本轮只核对和排优先级，未修复、部署或发通知。

## 3. 值得立即安排的优先级

### 第一优先：资料可靠与已修入口的实际采用

- 接续现有运行采用任务，核对已验收代码与运行版的差异，不重开另一套连续讨论改造。
- 核清新闻任务当前未加载的原因、实际数据库路径、来源可用性，再恢复既有抓取；本轮未执行恢复。
- 将最后一次抓取、最新消息时间、评分和简报生成分别说明。代码目前`_score_all`批失败主要记日志，而最终`status`依据采集错误计算，因此单个`ok`不足以代表整条流程健康。
- 抓取、未评分原文和模型讲解分开处理，模型失效仍保留可靠原始信息。现有`--no-llm`能力可复用，不必重建采集模块。
- Agent和清单必须区别：正常更新但没有相关消息、资料过期、采集失败、已采集尚未评分。现有`major_events_brief.available`主要表示有没有符合条件的条目；`_major_events_block`没有条目就省略，未传递完整更新状态。
- 现有20:30每日计划不能保证国内开盘前获得北京时间凌晨的新决议。后续按使用时点补定向更新与事件日安排，不扩成全天高频全网扫描。内部页面提示优先，外部投递按原渠道和授权范围单独验证。

完成标准：真实运行可核对时间和阶段；模拟一个来源/模型失败，入口仍能显示已知事实及缺口；不能用“没有重大消息”替代“没更新”。

### 第二优先：把买前卡与相关事件放到同一段讨论

`/ops`回答今天先看什么，`/agent`回答为什么、等什么、下一步怎么看；`/detail`保留完整图表核对。不是新增第四个总览页面。

买前答复先给技术状态、未满足条件和失效依据，再列与当前ETF有关的少量事件。事件需有原文来源、发布时间、事件时间、取得时间，以及“预期/正式结果/评论”身份。相同事件报道合并但保留来源，新决议出现后不能继续让旧概率报道占据首位。

宏观事件关联到ETF时写明理由，如跟踪海外股票、涉及汇率或持有特定行业；关联不等于已经证明价格变化由该事件造成。价格表现只描述事实，不说成单一消息的因果结果。

当前重大事件输出及讨论压缩没有保留完整原文链接和绝对发布时间，需补齐可追溯材料。“利空”“重要度”是模型解释，不冒充新闻事实，不统一推导所有ETF都会下跌。

完成标准：从“今天看什么”点进一只ETF后，在同一对话能回答为何关注、还等什么、哪里失效，以及相关事件是新事实还是旧预期；无新资料时明确说无新资料。

### 第三优先：按需联网解释，并把出处留在系统里

同意用现成检索和模型能力回答开放问题，但“GPT能联网”不等于当前网站内Agent已经联网。已检查的Agent材料路径是本地查询，模型请求主要传入messages；未见通用联网检索工具接入，不能直接承诺已有。

可增加“核对最新结果/查官方原文/找历史背景”动作。只在用户追问或材料明确缺失时查询，给次数与费用上限；复用按需结果和来源，后续同一问题不必重新查。引用结论至少绑定原文、发布时间、核对时间和适用对象，不能只粘贴一段模型总结。外部页面不获得执行权限。

“不参与技术判定”不等于历史背景没价值。小规模事件档案与官方日历有价值；暂缓的是维护成本高、尚无明确用途的全市场历史收益数据库。若要精确回答“过去加息25基点后通常涨跌多少”，必须统一资产、时点和比较方法，不能凭聊天记忆报胜率。该统计属于另行研究。

### 第四优先：ETF产品比较与资金重复提醒

沿用昨日建议：比较跟踪对象、成交便利程度、费用、价格相对净值偏离，以及新增基金和原持仓的重复。场内与场外分别解释，黄金和海外ETF单列。此项待前两项能稳定支持买前阅读后再扩，不把全部资料一次塞进首屏。

## 4. 第一批建议范围与不应扩大的内容

第一批建议只包含新闻可靠更新及状态传递、官方重大事件的来源与阶段、在现有Agent买前答复中展示；与已有入口运行采用协调。可以先验证“9月4日预期→9月17日正式结果”这一完整例子。

不将新因子、自动消息择时、全网资讯平台、历史事件收益库、每次提问自动联网或新综合推荐分数并入首批。消息始终解释背景，不新增技术过滤。

实用性验收：用户能看懂资料是否新、事件是否已发生、与关注对象有什么关系、技术上还等什么。稳定抓取与页面通过不能宣传为收益提升。

## 5. 交付与边界

报告及事实快照归档；已对既有买前目标和Agent方向追加本轮结论，消息可靠更新作为具体待规划目标登记，不冒充授权开发或完成。未调用真实模型、触发新闻抓取、修改launchd、部署、推送、记账或重置额度。当前主控直接完成判断，无子agent派发。
