# 研究首轮交付：逐环节证据、论文方法与完整交易核查

日期：2026-09-08。首轮成果待用户验收；研究结论为 **mixed：部分计算得到复现，部分证据必须收窄，尚未证明任何新增交易方法有效**。

## 一句话结论（大白话）

论文中最值得先吸收的是“怎样公平比较、怎样避免把好看的数字看错”。三路研究发现，我们已有不少退出和定投实验，也已有 ATR 结构缓冲；当前更急的是校准成交时间、资金记账、费用和版本。旧定投中一段历史的账户余额最大下跌约9.67%，排除不断存入新钱的影响后，投资价值最大下跌约23.38%，买卖和期末资产完全相同。两个数字回答不同问题，不能只用前者说明投资风险低。此次没有新增生产规则，也没有认定所有旧方法无效。

## 3. 本轮真正运行了什么

### 3.1 退出基准：16个机会，小范围计算一致，历史价格不全一致

事前按每份参考文件中代码排序的第一个对象选择A的159611.SZ、B的000596.SZ、C的000568.SZ，保留全部16机会。日期升序、重复、缺价和高低价格合法性检查通过；当前默认退出与独立简单循环 **16/16一致**。与旧归档 **13/16一致**，C的3笔价格口径不一致。

C旧入场价与新资料相差同一绝对数4.417，但仍保留旧结构价，导致一笔退出理由也改变。这只能证明价格口径没有闭合；本轮未独立重建分红复权，不能断言差额原因已查清。更不能把新旧收益差当规则改善。[逐笔结果](raw/research-first-round-2026-09-08/exits/reproduction_results.json)

另两项最小核查：

- 当前费用函数把 `max(单边0.05%, 0.005/入场价格)` 统一用于所有对象。本轮12笔低价ETF实际单边约 **0.422%–0.486%**。每股收费下限来自美股参数，不能无条件称适合A股ETF。主 agent 独立抽取费用类验证了公式，未擅自改费率。
- 普通“持有N日仍无进展”旧脚本某分支将同一机会加入平均数两次、加入误差估计一次。真实518850.SS、2023-07-20机会已复现此现象；四个条件型方案没有该重复添加分支，不能扩大为全表全部无效。[最小反例](raw/research-first-round-2026-09-08/exits/duplicate_diagnostic.json)

### 3.2 定投时间：21笔原结果复现，10笔合法退出日期不同

第13轮20组730条记录的原摘要全部对账。730是多个配置的结果行，不是730次独立市场经历。相同进入类型、退出规则、对象的相邻计划有128处重叠；这是方法内重叠次数，不能把这些计划都当同一预算可同时执行。

沪深300目标收益退出21笔原函数全部复现；只把当天收盘触发改为前一天已知收盘，**10笔退出日期改变**。例如2014-12-08开盘前尚未达到30%目标，当天收盘才达到，旧程序却在当天开盘卖出。修正后该例收益反而提高，说明修复时间错误不保证收益下降，也不能据此宣称策略更强。[逐笔配对](raw/research-first-round-2026-09-08/dca/round13_000300_target_paired.csv)

第14/15轮也有该收益触发问题；第16轮已取前日收盘，不能一概归罪。时间退出另有文字约24个月、代码约18个月，以及文字周查、代码日查的差异，需要逐条核准。

### 3.3 定投资金：原终值完全复现，风险与入金必须分开

第18轮对象为沪深300指数、创业板指数、黄金ETF、纳斯达克综合指数，**最后一个不是纳斯达克100**。原跨市场价格共同日期的实际终点是2026-08-26。以下使用原买卖、原费用、原价格，保持交易和期末总资产不变：

| 量度 | 2020-11-16起，约5.8年 | 2013-07-29起，约13.1年 |
|---|---:|---:|
| 总投入1单位后的期末资产 | 1.569701 | 2.317645 |
| 独立资金表与原终值差 | 0 | 0 |
| 原含持续入金的账户余额最大下跌 | 9.67% | 23.79% |
| 排除入金影响后的投资价值最大下跌 | **23.38%** | **30.01%** |
| 原考虑投入时间的年化收益 | 15.8802% | 12.1405% |
| 把全部外部入金记全后的年化收益 | 15.7553% | 12.1170% |

“排除入金”是把后来自己存的钱从投资涨跌中分开，**不是说用户实际持有的同一笔本金曾亏掉23.38%**。应同时看账户金额、累计投入、现金和投资风险，不能拿一种指标冒充另一种。

原年化算法按买入金额记录入金，漏掉末尾尚未购买的现金，却把这笔现金算进终值。在价格不变、零费用的最小例中，旧算法报年化+4.03%，完整外部入金记账后约为0。独立 agent 用另一套份额算法复核了两条风险曲线及不变终值。[结果与反例](raw/research-first-round-2026-09-08/dca/results.json)

原96起点五方案摘要也已重算一致，但**没有修正并重跑全部96起点**。旧材料把中间八成范围当最好最差、把请求终点当真实最后数据日的问题已记录。不得把本表两个时段的改正推广成全网格新成绩。

### 3.4 问答证据：两个修复复例通过，一处旧表行为仍不稳

胜率构建先按同日同对象去重，合成A/B记录交换顺序会丢掉不同模块，已复现。讨论读取还缺进入/退出版本、费用、历史窗口与来源运行编号，不能凭旧表回答换方法后的精确胜率。

缺价不挤压200日窗口、过期参考日期在周末/开盘前保守降级，本次复例通过。观察记录代码正在被另一工作修改，三个旧探针在中间态运行异常，未到达语义检查；**既不记通过，也不作为当前生产仍有旧缺陷的证据**。[检查记录](raw/research-first-round-2026-09-08/evidence/probe-results.json)
