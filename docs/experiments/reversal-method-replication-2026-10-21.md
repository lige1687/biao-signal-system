# 月度短期反转：论文方法、300只历史股票检验与 TRAE 委派试跑

资料与计算日期：2026-10-21。本题为已授权的独立研究，主控设计与复核、Luna 执行；不接管“因子实现”的条件选股/账户，也不接管策略组合负责人的行业内反转方向。

## 一句话结论（大白话）

过去一个月跌得多的股票，下一月的相对排序确实有反弹线索；但在这批300只历史A股中，直接挑最差的一成买入，没有证明比简单低波动选择更有用，持有中途的下跌还更深、换股更多。隔一个月后，排序线索明显减弱。保留反转作为研究和数据体检对象，暂不把“跌得多就买”加入系统。此次覆盖131个形成月份，但未来报价不全，使完整组合的共同月份明显减少，不能称完整11年账户验证或原论文全市场复现。

TRAE 独立命令已安装，但桌面登录没有完成 CLI 认证；编辑器入口也未确认有效答复。委派技能已保存并验证前提检查，不宣称自动派发—回调已打通。

## 1. 问题、金融解释与可能失败的原因

要回答的决定是：个人月度选股时，近期跌得多的股票是否值得优先，以及这个信息能保留多久。简单对手是同一时期的全部合格股票和同数量低波动股票；上涨最多组用于识别相对现象，不能把它的表现差直接记成买跌组合的盈利。

合理的候选解释是：短期卖压、流动性需求或过度反应把价格暂时压低，卖压消退后价格修复；提供资金的人可能因此得到补偿。失败解释同样重要：下跌反映真实坏消息，报价不连续产生假反弹，或看似收益其实来自小股票、行业、交易活跃程度及更多风险。当前价格资料能检验现象与时间衰减，不能辨认这些原因谁占主导；没有持仓流量、事件和完整历史行业/市值，不能声称已证明强迫卖出或过度反应。

## 2. 这次究竟复现哪种方法

新核读 [Shi、Jiang、Zhou（2015）原文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0137892)，公开 CC BY，原件及指纹保存在本题 raw。原文使用 RESSET 沪深全部A股月度复权收益，实证1997—2012，上海、深圳分别研究，删除上市首月；用过去J个月排序、持有K个月，各股票同等金额，研究近期最差组与最好组的收益差。本次只取 J=K=1，不搜索整张参数表。

**需要补充上一份报告的范围：月度调仓本身有经典依据。** 先前核过的 Liu/Stambaugh/Yuan 是过去20日信号、分批持有5日，不能拿那篇直接证明月度交易；本次这篇确实研究一个月形成、一个月持有。[French 短期反转说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_st_rev_factor.html)也采用上月收益，但美国市场、市值分层和金额权重不同，不能混作本次的算法。

| 项目 | 原论文 | 本次实际做法与差异 |
|---|---|---|
| 股票池 | 当期沪深全部A股，交易所分别计算 | 2014年末历史名单固定抽取300只，沪116、深184；不补后来上市股票；不是全市场动态名单 |
| 年限 | 1997—2012 | 2014-12—2025-10形成，共131个月；无跳月结果2015-01首个交易日—2025-12首个交易日，跳月结果2015-02—2026-01首个交易日 |
| 准入 | 明示去掉上市首月 | 沿既有12个干净历史月、形成日交易/非ST、动量与60日波动可计算等资格；仅去掉“必须转绿”要求；比原文更严格 |
| 分组与权重 | 十分/五分/三分，组内每只同等金额 | 固定十分组，至少30只合格；取向上取整的10%，并列按代码；同数量低波动及全部合格股作对手 |
| 收益 | 月度复权收益及年化算术平均，包含最差减最好组差额 | 月末信号后下月首日开盘买、再下月首日开盘卖；复权报价比较，非完整股东总回报 |
| 跳月 | 形成和持有之间空一个月 | 同一形成名单原样延后一个月，不重新按未来可交易情况挑选 |
| 未知与退出 | 正文未充分规定每一种历史退出、并列和成交处理 | 无法核实的未来原权重保留未知；不补0、不用末价代替、不删除后重新分配 |
| 交易实现 | 组合差额不等于可实做空收益 | 无融券、订单容量、排队、真实成交或账户资金模拟；费用仅买入方案间的近似比较 |

完整可执行步骤：先按形成日前资料审查资格；沪深分开计算过去自然月复权收盘收益；先保存全部选择与权重，再连接两种持有期的未来报价；统计同月完整差额、未知权重和统计误差范围；比较收益、下跌、上涨机会、换股和费用；最后按用途取舍。每个实际名单/权重/日期已保存，不能凭未来结果重选。

本次研究价格、原件、代码与两份策略文档实际 SHA 均绑定在 [design.json](raw/reversal-method-replication-2026-10-21/design.json)。直接复用既有定义 `research.selection.short_reversal.month_return@1.0.0`、`research.selection.short_reversal.momentum@1.0.0`、`research.selection.short_reversal.vol60@1.0.0` 及已审报价适配器，新增的仅是论文分组和跳月对照，未修改策略或生产定义。原600股诊断、转绿条件选择与10/20只账户旧结果保留，见[前次范围审查](a-share-reversal-applicability-review-2026-10-20.md)。

## 3. 样本、时间划分与数据缺口

共35,765个合格“股票—月份”、71,530个两期限结果。3只股票合计5个历史价格中断日继续隔离。未来未知1,432条：1,417条买卖端没有可交易报价、12条日历行缺失、3条未来复权断点。它们没有变成亏损0或被悄悄剔除。

每月合格沪股95—112只，选择10—12只；深股141—180只，选择15—18只。无跳月最差组完整结果沪118个月、深100个月；与全部合格股比较仅剩64/62个月，因为全部组合中任一原始权重结果未知就不能给完整收益。沪/深全部组平均未知权重1.18%/1.74%，单月最大8.00%/13.19%；最差组最大18.18%/23.53%。小的平均缺口也可能集中在异常时期。

预先分为2014-12—2019-11（60个形成月）和2019-12—2025-10（71个形成月），没有用结果选分界。**都是看过的历史资料，不称新的未见验证。** 最差组对全部组在较早段只有沪12/深9个完整月，较晚段52/53个月；对低波动则为沪46/67、深28/64个月。没有“11年每个月完整账户”的证据，也不能把这些幸存的可算月份当成随机缺失。

金额权重、市值分层、行业、历史价格/流动性门槛、退市现金处置仍不齐；本题未把它们伪装成已完成的底层过滤器。形成日前的资格决定与未来无法成交的处理分开；不能因为后来停牌就回到形成日删股票。

## 7. 为什么隔一个月会变弱，和论文是否一致

用两种期限、最差与最好四组均完整的**相同形成月份**比较：沪83个月，即刻差额比跳月差额多1.222个百分点（−0.365～+2.809）；深71个月多0.820（−1.397～+3.037）。方向上减弱，但组合差额变化仍不能排除随机波动。

拆开以后原因并不完全一样：沪最差组延后收益下降约1.000个百分点，最好组延后改善0.223；深最差组延后也改善0.951，但最好组改善更多、达到1.771。不能把两地都写成“跌后反弹只在第一个月发生”。这是固定名单不同月份的对照，仍混有市场时序影响。

论文沪市十分组最差减最好年化均值12.8%跳月后10.8%，不能与本题不完整月份、开盘端点和不同股票池直接比数值。论文认为跳月后仍显著即可排除测量误差，这个推断偏强：它最多排除部分极短暂报价效应，不能证明不存在任何数据错误，也不能证明因果机制。

反例也明确：本题沪最差对全部在2023、2024、2025形成月的可算部分分别为−1.011、−0.786、−0.924个百分点（月数9/9/5）；深较早段+1.625只有9个月，较晚段−0.156有53个月。它不在所有年份同样有效。原论文牛/熊分段也是回头定义，不能直接变成当时可执行的市场状态选择器。
