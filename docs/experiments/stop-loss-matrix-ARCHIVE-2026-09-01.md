# 止损方式归档摘要：ATR/时间/追踪止损跨模块统一矩阵（2026-09-01）

- 脚本：`scripts/run_stop_loss_matrix.py`（判定标准固化于 docstring，跑前写死）
- 原始数据：`docs/experiments/raw/stop_loss_matrix/`（结果 JSON + 双跑哈希
  `hash.json`，seed0=seed42=`e571dee6509d021d40798cd3d6b55c8f` + pre-revert
  检测器快照 `pre_revert_modules/`）
- 口径：与 exit-matrix-2026-08-31 完全同源——全池 175 标的（工作台默认池；
  08-31 报告误写 53，实际 run JSON 为 175，以 run JSON 为准）、数据截至
  2026-08-28（与基准 run 同窗）、rr_min=None、fee=standard（单边 5bp）、
  limit_guard=True、净 R 口径。模块冻结配置：A=early+shrink+clock_mult0.5；
  B'=breakout+cb30/cl3%；C=v3+深乖离-0.15；D=默认单版本（无历史冻结配置）。
- 实验设计：候选止损 = 在默认出场（初始结构止损 C + A6① 抵扣价）之上
  **叠加**一个附加退出触发（先触发先出，收盘确认次根开盘执行）——隔离
  的正是「止损方式」这个维度本身；不重测 a6_3「止损替代全部出场」机制
  （exit-matrix 已判负，诊断=缺止盈）。参数网格：ATR k∈{1.5,2.0,2.5}、
  时间 N∈{10,20,40}（「无进展」=入场以来最高收盘≤入场价）、追踪
  p∈{0.5,0.7,0.9}（锁定峰值浮盈比例）。
- 判定标准（事前固化）：「不劣于」=ΔexpR≥−0.10 且 ΔPF≥−0.10；「显著
  改善」=逐笔配对 bootstrap（10000 次，固定种子）95% CI 下界>0；「跨模块
  普适候选」=某参数点 ≥3/4 模块不劣于且 ≥1 模块显著；有效性前提=A/B/C
  基准与工作台 08-31 run 逐笔锚定零失配（exit_date/exit_reason/r_net）。

## 一句话结论

**默认出场（结构止损 C + 抵扣价）经 4 模块 × 9 止损参数全矩阵压力测试
再次站住：ATR 与时间止损在个别参数点机械通过预注册普适门槛，但最大
增量 ≤0.014R（B 模块 +4%，其余 ≈0），无经济意义；追踪止损在 A/B 显著
有毁坏性（−0.3~−1.1R，触发 60%+ 交易=系统性截断右尾），实质证伪。
「止损方式」这个维度不存在跨模块的免费增量——风险控制已内化在默认
出场结构里。**

全池）量级一致，右尾集中事实**跨口径复现**。

时间止损误伤量化（prompt 点名义务）：「无进展」定义下，N=10 全模块仅
砍 16 笔（其中 41+ 天单仅 B 的 1 笔，代价 −0.18R）；N=20 砍 3 笔（41+
单 1 笔，−0.03R）；N=40 砍 0 笔。**担心的右尾截断没有兑现**——41+ 天
长持单全部在早期出现过收盘浮盈（否则早就被默认出场打掉），对
「无进展」型时间止损天然免疫；代价是这类止损的收益也趋近于零。
真正砍右尾的是追踪止损（不等无进展、浮盈回撤即出），其 A/B 毁伤
正是这个机制。

## 冲突发现

1. **与 exit-matrix-report（2026-08-31）的关系是同向加固，不是重复**：
   exit-matrix 测的是**替换整套出场**（a6_2/a6_3/b3），本实验测的是
   **在默认出场上叠加保护层**——机制不同、结论同向：a6_1 默认地位
   双重确认。a6_3「止盈不可省」从反面获得补证：默认出场内嵌的趋势
   跟随退出已经承担了利润兑现，额外保护层（ATR/时间）无可保护的风险
   （增量≈0），更紧的层（追踪）反而吃掉利润兑现空间。
2. **与 heiti-ARCHIVE 右尾事实（41+ 天=164% 利润）**：正向复现并扩展。
   复现：本口径 123%~220%。扩展：「砍信号=砍右尾」从入场侧推广到
   出场侧——追踪止损砍的是同一个右尾（60%+ 触发率）。边界说明：
   时间止损不砍右尾是「无进展」定义的数学结果（右尾单早期必有浮盈），
   若改用「持仓超 N 日无条件离场」型时间止损将直接命中右尾，本实验
   未测该变体且**不建议测**（先验机制已表明是自杀式配置）。
3. **与 Prompt G（a6_4 结构止损+补止盈）互补不冲突**：G 给 a6_3 补
   止盈、本实验给 a6_1 加止损，是出场部件两个方向的修补测试；两者
   合并后的默认结论仍是原装组合（C+抵扣价）。若 G 也判负，出场侧
   可整体结案。
