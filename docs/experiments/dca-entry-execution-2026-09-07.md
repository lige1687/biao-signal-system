## 一句话结论（大白话）

系统出买点之后，**一次性买入就是最优执行**。在模块 A（趋势回调）4368 笔、
模块 B（密集突破）552 笔真实系统买点上，四种分批/定投窗口方案（分 3 批/分
5 批/信号后 20 天日投/8 周周投）**全部显著降低每笔收益**——平均每笔少赚
0.4~1.4 个百分点，且统计上都不是巧合（置信区间上界全部小于零）。原因有两个：
①系统买点之后行情平均往上走，晚买的批次更贵（分批建仓均价比一次性贵
0.8~2.9 个百分点）；②趋势系统的利润集中在信号后不久的快速段，仓位还没建满
行情就走了——三到六成的批次还没轮到买入就被出场信号作废（和宽度引擎实验
"十次分批七次被信号叫停"的老发现同构）。分批唯一的好处照旧是**亏钱时亏得浅**
：亏钱单平均少亏 1~2 个百分点；但赢钱单平均少赚 2~9 个百分点——趋势系统
靠少数大赚笔活命，稀释大赚笔是结构性代价，两相抵消净值为负。这与 AE（宽度
引擎分批）、AM（极端底部分批）两次归档方向完全一致：**"信号触发后分批/定投
式建仓"在系统买点层面第三次判负**。

（VWAP = 分批各笔成交的加权平均买价；pp = 百分点；pp 里说的"每笔少赚"是按
每笔投入金额算的收益率差，不是 R。）

## 1. 背景与问题

用户问：系统出一个买点之后，用定投或分批的方式买入行不行？这是总规划语义九
（"信号决定要不要买，分批决定怎么落地"）在**系统入场模块**上的直接落地——
但此前从未测过：

- AE（2026-09-03）：宽度**引擎**升满仓信号后分批 → 证据不足、方向偏无增量；
- AM（2026-09-03）：**极端底部**信号后分批 → 语义九买入侧关闭；
- AV（2026-09-04）：极端底部**价格阶梯**（越跌越买） → 交换结构（另一个机制，
  本轮不重复）；
- 本轮：**模块 A/B 的普通买点**后的一次性 vs 分批 vs 定投窗口，首次直测。

## 2. 口径

- 样本：回测深池（175 标的：A 股 140 + 指数/美股 35）全池；模块 A 引擎 4503 笔
  （有效平仓 4369，剔除无风险退化笔 124、重放跳过 1，**分析 4368 笔**）、
  模块 B 引擎 563 笔（分析 552 笔）。样本窗以引擎输出为准（A 股深池 2020-09
  起约 5.5 年；池内美股指数更长，混合统计）。
- 五臂（每笔预算 1.0，每批买入 5bp + 出场卖出 5bp，含涨停约束）：
  one_shot（入场日开盘全买，基线）/ staged_3x5（3 批×间隔 5 根 K）/ staged_5x10
  （5 批×10 根）/ dca_20d（20 批×每根，信号后日投窗口）/ dca_8w（8 批×5 根，
  周投窗口）。
- 批次规则（预注册）：第 k 批在入场位置+k×间隔的开盘成交；已到出场位置的批次
  作废（出场优先），其现金 0 收益计入期末财富；A 股当日开盘较昨收涨幅 ≥9.5%
  视为涨停该批作废（引擎简化规则）。
- 设计前提（登记）：出场信号 a6_1/结构止损 C 纯价格驱动，与建仓方式无关，故
  五臂共用同一 exit_date/exit_price——执行方式的差异全部来自买入侧。
- 度量：逐笔 ΔPnL%（vs 同笔 one_shot 重算臂，含双边费）、VWAP 差、完成率、
  建仓期缓冲（评估窗=入场→最后一批成交日，分批组合含现金的最深权益 −
  一次性组合最深权益）。
- 判定线（预注册）：E1 逐笔 ΔPnL% 均值配对 bootstrap 95% CI（B=10000，种子
  20260907）下界>0=增量成立 / 上界<0=负增量 / 跨零=无显著差异；E2 VWAP 差
  CI 同法；E3/E4 只登记；E5 跨模块方向一致性。

## 3. 判定结果

| 判定 | 结果 |
|---|---|
| E1 收益增量 | **8/8 臂（A×4 + B×4）全部「负增量」**，CI 上界均 < 0 |
| E2 成本方向 | **8/8 臂「分批更贵」**，VWAP 差 +0.77~+2.91pp，CI 下界均 > 0 |
| E3 完成率 | A：3批67% / 5批41% / 日投52% / 周投41%；B 几乎相同——**三至六成批次被出场作废** |
| E4 建仓期缓冲 | 均值 +0.04~+0.84pp、中位数 0（多数建仓窗无回撤）；dca_20d 最大（中位 +0.56pp、60% 笔有正缓冲）——量级远小于 AE 的 1~3pp |
| E5 跨模块 | A 与 B 方向**完全一致**（负增量+更贵+完成率同型） |

## 5. 细读：分批的账是怎么算输的

**描述性盈亏切分（跑后补充、不设判定线）**——把每笔按 one_shot 盈亏分组：

| 臂 | 赢钱单 Δ（A，1368 笔） | 亏钱单 Δ（A，3000 笔） |
|---|---|---|
| staged_3x5 | −4.25pp | **+1.21pp** |
| staged_5x10 | −9.44pp | +2.31pp |
| dca_20d | −7.01pp | +1.89pp |
| dca_8w | −9.31pp | +2.35pp |

（模块 B 同型：赢钱单 −2.4~−5.6pp、亏钱单 +0.8~+1.7pp。）

机制读法：
1. **亏钱单上分批确实有用**——少亏 1~2pp（现金缓冲 + 仓位没建满），这是分批
   唯一真实的收益；
2. **赢钱单上分批的代价大一个量级**——少赚 2~9pp：系统买点确认后的盈利段
   平均快速上行，晚到的批次买得更贵（VWAP +0.8~2.9pp），且低完成率意味着
   行情启动时仓位只有六成、四成甚至两成；
3. 趋势系统 31%/36% 胜率、利润右偏（少数大赚笔养活全部），**任何系统性稀释
   大赚笔的动作，代价都超过在亏损单上的节省**——与 AI 否决权实验
   （ai-three-tier-decision-2026-09-06）的教训同构；
4. **完成率是"分批 vs 系统"的内在冲突**：a6_1/止损 C 的中位持仓很短，批次
   还没铺完出场就来了（41%~67% 完成），与 AE 在宽度引擎上"十次分批七次被
   信号叫停"完全同构——这不是参数没调好，是两个节奏机制天然打架。

## 6. 五轮定投系列总结（截至 2026-09-07）

| 轮次 | 问题 | 判定 |
|---|---|---|
| 一（09-06） | 定投方式×频率×浮动 | 宽基/美股平投；行业 ETF 短样本浮动 10/10（后被四轮推翻）；频率无关 |
| 二（09-06） | 情绪冰点信号浮动 | 空心臂+微弱增量 → 证伪 |
| 三（09-06） | 时间跨度 31 年/分年代 | 宽基平投、美股平投、频率无关全部维持 |
| 四（09-07） | 行业指数长窗口 | 一轮行业结论推翻（短样本伪象）→ 定投择时整体证伪 |
| **五（本轮）** | **系统买点后的分批/定投执行** | **8/8 臂负增量、8/8 更贵 → 一次性买入最优；语义九第三次判负** |

执行层的完整答案：**不管钱是新现金流（定投）还是系统信号（买点执行），
"分批/摊开买"在收益上都没有增量，唯一功能是降低过程波动（回撤浅、亏钱单
亏得少）——那是拿期望收益买心理舒适度，属于风险偏好选择，不是收益优化。**

## 7. 局限与诚实登记

1. 深池 A 股 2020-09 起（约 5.5 年）：含 2021-2024 熊市与 2024-09 起反弹，无
   2015/2018 型完整熊市；池内美股/指数标的更长（最早 1986），混合统计。
2. 出场冻结 a6_1_costbasis：换出场变体改变持仓时长会改变完成率与 VWAP 机制
   的相对权重，但"信号后价格平均上行 → 晚买更贵"的方向机制不依赖出场选择。
3. 费用 5bp 单边、无滑点/价差；批次腿沿用引擎简化涨停规则。
4. 引擎事件检测器为当前提交版（与历史归档的检测器漂移风险沿止损矩阵披露；
   本实验各臂共用同一交易清单，信号质量差异不影响执行层对比）。
5. 运行日志（如实）：初跑①全部交易被日期键 bug 跳过（输出全 NaN、零判定）；
   修复后初跑②产出完整判定（哈希 d4988e…）；为报告叙述补描述性盈亏切分
   （明确标注不设判定线）后定稿重跑双跑（哈希 fe72a2…）。E1~E5 判定标准
   自预注册起未改动。
6. 中途除上述实现修复与描述性补充外无修改；双跑哈希一致。
