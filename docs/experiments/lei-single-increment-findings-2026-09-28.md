# 原生20日黑绿：第二条线究竟增加什么？

## 一句话结论（大白话）

**暂不支持把第二条线当成已经可靠的5日方向预测增强。** 绿色相比单线的上涨比例只增加约0.72—0.77个百分点；把年份构成对齐后，共同确认与分歧组的上涨差缩至0.18—1.12个百分点。黑色相比单线的5日期末亏损比例基本不变。当前决定：暂停追加参数和策略升级，保留原生颜色作为趋势状态描述；这不等于证明它对所有期限、所有风险用途无效。

研究问题：已知道一条均线方向后，另一条确认能否进一步区分未来5日上涨、亏损、平均涨跌和过程下跌？固定20日、六ETF、2022—2026上半年完整每日记录，未来从信号次日收盘到其后第5个交易日收盘。历史已看过，本轮是新增单线条件对照，不是真正新资料验证。

## 3. 我们现在知道什么

- 第二条线会排除部分单线日期，但“筛得更少”不自动代表判断更好。绿色共同2496个资产日期，对比SMA单线2952、EMA单线3093，分别排除15.45%、19.30%。
- 绿色共同与分歧组的原始上涨差为4.78、3.95个百分点；这一比较不同于上表共同与全部单线差0.72、0.77，不能混写。
- 共同与分歧组采用相同年份权重后，上涨差为0.18、1.12个百分点，年份构成解释了原差异的重要部分，不是证明因果。
- 黑色5日期末亏损比例没有增加；过程平均下跌相对单线只增加约0.01—0.03个百分点，不足以作为已可靠的风险增强结论。

## 4. 我们现在不知道什么

- 没有预先最小有用幅度，不能声称已统计证明“值得关注的所有增量都不存在”。
- 未验证其他期限、其他市场或真正未参与选择的新资料；不把本次5日结果推广到全部用途。
- 没有检验加入连续近期收益和波动率后的模型预测误差；当前有限单线对照不叫排除所有背景。
