# 月末股债再平衡：能否用于低频策略｜2026-10-20

## 一句话结论（大白话）

**机制优先的研究路径值得采用；月末股债再平衡这版“一月看一次”的规则，暂不加入我们的买卖条件。** 美国股票与国债ETF的285个月历史中存在符合预期的价格关联，但最近9个月有8个月方向相反；对简单价格反转的改善很小，也没有证明月底的额外作用足够稳定。本轮已完成这项适用性检验，保留历史线索，实际账户净收益和中国ETF用途未评价。

## 1. 对我们的决定有什么帮助

本题要回答：已经有低频持仓或调整计划时，是否值得继续投入研究，利用月末的机构调整改变执行日期。可以采用的研究顺序是：观察现象，解释谁受到什么约束，再提出可推翻的预期，检查数据，最后检验实际决定和代价。

本轮决定是**保留候选和可复算实现，暂不采用本版执行日期规则，也不据此过滤原LEI信号**。这个结论限定于本次月度观察方式；没有否定所有再平衡机制，也没有检验原论文每日更新的完整期货方法。

数据对象为美元计价的标普500ETF（SPY）与iShares 7—10年期美国国债ETF（IEF）。本轮没有中国ETF、汇率、基金溢价或真实账户证据。

## 2. 先看实际结果

为统一理解数字：如果月内股票相对债券涨得多，机制预期月底股票表现较弱；反之预期股票较强。下面把未来5天的股债收益差按这个预期方向记正负，**正数表示方向吻合，负数表示方向相反；这些数字不是账户收益率**。

| 观察时期 | 完整月份 | 方向对应的平均股债收益差 | 从下一开盘才开始观察 | 方向吻合 / 相反 |
|---|---:|---:|---:|---:|
| 2003年1月—2023年2月 | 242 | +0.581个百分点/次 | +0.533个百分点/次 | 139 / 103 |
| 2023年3月—2025年12月 | 34 | +0.278个百分点/次 | +0.109个百分点/次 | 21 / 13 |
| 2026年1—9月 | 9 | **−0.733个百分点/次** | **−0.621个百分点/次** | **1 / 8** |
| 全部历史 | 285 | +0.503个百分点/次 | +0.446个百分点/次 | 161 / 124 |

全期平均值的95%估计范围为 **+0.262至+0.785个百分点/次**；下一开盘观察为 **+0.234至+0.682**。计算时将连续12个月一起反复取样，保留相邻月份的联系。它描述这段历史平均值的不确定性，不表示未来收益保证。2026年仅9个月，不报告这种区间，也不足以单独否定整个机制。

正面证据不能忽略：同时去掉2008和2020年，仍有261个月，平均方向差为 **+0.364个百分点/次**；采用供应商调整价重新计算，285次方向全部一致。因此，不能把历史关联简单归为两个危机年份或分红处理错误。

## 3. 比简单办法多提供了什么

### 月底是否比其他日期更特殊

预先固定一个对照：每月把观察窗口提前10个交易日，保持相同的过去观察长度和未来5天。

- 全期月底方向差比月中多 **0.411个百分点/次**，估计范围 **+0.047至+0.790**。
- 2023年3月—2025年12月，这个差额变为 **−0.080个百分点/次**；2026年1—9月为 **−0.311**。
- 上面的简单差额还可能受到两个窗口涨跌方向比例不同的影响。进一步同时分开“月底平均涨跌”“一般短期反转”和“月底反转是否额外增强”，额外作用的估计范围仍跨过零：系数 **−0.1433，范围[−0.2749，+0.0341]**。因此，不能确认这里识别出了稳定的机构月末价格压力。

技术记录：同月月底与月中两条记录配对，估计 `y ~ 1 + EOM + relative_log + EOM*relative_log`；取样时整月两条一起保留。系数单位是未来收益小数对过去相对对数涨幅的变化，并非资金收益。

### 配置偏离是否比普通股债强弱更有用

使用已经结束的过去月份训练，再预测下一次观察；先留60个月，实际共同比较225个月。没有用全期结果拟合后冒充提前预测。

“平均平方误差”就是把每次预测错多少平方后求平均，越小越好。

| 同一225个月上的方法 | 平均平方误差（百分点²） | 误差的平方根（百分点） |
|---|---:|---:|
| 只用过去平均结果 | 7.4005 | 2.7204 |
| 只看股票月内涨幅 | 6.5935 | 2.5678 |
| 看股票相对债券的月内涨幅 | 6.2670 | 2.5034 |
| 用60比40配置偏离表达 | 6.2360 | 2.4972 |

| 增量比较 | 平均误差减少（百分点²） | 95%估计范围（百分点²） | 能支持什么 |
|---|---:|---:|---|
| 配置偏离相对普通股债强弱 | +0.0311 | [+0.0039，+0.0786] | 全期误差少约 **0.50%**；有限的表达改善 |
| 股债强弱相对只看股票 | +0.3265 | [−0.1081，+0.8435] | 全期改善仍有不确定性 |
| 配置偏离相对过去平均结果 | +1.1645 | [−0.4811，+3.9596] | 平均改善不能视为稳定优势 |

2026年9个月，配置偏离的误差为 **2.7489百分点²**，过去平均结果仅 **1.1804百分点²**，简单方法更好。

配置偏离本身是股债相对涨幅的确定变换。设股债月内累计增长倍数分别为 `Gs`、`Gb`，则：

`股票权重偏离 = 0.6×Gs / (0.6×Gs + 0.4×Gb) − 0.6`

全部285个月中，它与股债相对涨幅的方向完全相同。因此，上述0.50%属于同一价格信息换一种表达后的改善，不能算一份新的独立信息。误差平方根只少约 **0.0062个百分点**，也不能直接换算为多赚多少钱。

## 4. 失败机会和代价一起看

| 当时情况 | 后来情况 | 月数 | 按机制方向计算的平均收益差 |
|---|---|---:|---:|
| 股票配置偏高，预期股票较弱 | 股票确实较弱 | 99 | +1.528个百分点 |
| 股票配置偏高，预期股票较弱 | 股票继续较强 | 85 | −1.129个百分点 |
| 股票配置偏低，预期股票较强 | 股票确实较强 | 62 | +2.587个百分点 |
| 股票配置偏低，预期股票较强 | 股票继续较弱 | 39 | −1.850个百分点 |

最差例子为2010年6月，方向差 **−6.869个百分点**；最强正例为2008年11月，**+18.753个百分点**。2010年6月这类失败说明，照此提前或推迟原定操作可能继续承受损失；2009年5月、2020年4月则显示，股票配置偏高后仍可能继续上涨，提前降低股票投入会少赚。

本轮预先记录的每笔调整金额0.05%、0.10%、0.20%费用，只是未来执行研究的比较尺度。未建立资金账户，不能把表中收益差简单减去这些费用，便称净收益。真实手续费、价差、税费、分红到账等待、闲置现金和调整次数均未计入账户。

## 5. 机制、原论文和本轮改造

机构如果有固定股债目标比例，股票相对上涨会让股票权重超标，恢复比例可能需要卖股票、买债券。这一约束给出了方向、日期和可推翻的预期。但不同机构可能按季度、偏离幅度或现金流调整；60比40也不是所有机构的目标。

[《The Unintended Consequences of Rebalancing》2025年12月15日版本](https://afajof.org/management/viewp.php?n=144452)使用股票指数与国债期货，主要信号每日更新、预测下一天；作者比较不同月底窗口后选择末5日。本轮改为每月一次、提前固定信号，并使用两只现金ETF，属于低频用途适配，不是原文完整复现。没有机构交易资料，本地价格检验不能确认因果。

| 项目 | 本轮固定口径 |
|---|---|
| 观察 | 每月倒数第6个交易日收盘；此前从上月末累计股债回报 |
| 主要结果 | 此后5个交易日，到本月末收盘的股债总回报差 |
| 可执行时点检查 | 下一真实开盘到月末收盘；买入日不享有当天除息权益 |
| 分红 | 原价加现金分红，假设除息日收盘再投资；实际到账等待未建模 |
| 时间范围 | 2003年1月—2026年9月，285个完整月；2026年10月未完成而排除 |
| 预测比较 | 过去已成熟60个月起，每次只用当前观察前已结束的结果 |
| 其他固定检查 | 同长度月中窗口、同时去掉2008/2020、供应商调整价、三个时间段 |
| 新资料身份 | 2026年是论文此版本之后的回顾检查；不是本轮冻结之后的真实前瞻观察 |
| 是否改过参数追结果 | 没有 |

## 6. 数据资格和适用范围

2026年10月20日从Yahoo公开行情端取得原始OHLC、调整收盘、除息现金和拆股字段：SPY 6,114行、IEF 6,094行；共同日期为2002年7月30日至2026年10月16日，共6,094行。没有单边缺日、空值、非正OHLC或重复日期；两产品在取得范围内拆股记录为零。

IEF最近10笔分红与[发行方产品页](https://www.ishares.com/us/products/239456/ishares-7-10-year-treasury-bond-etf)按供应商三位小数精度一致；2021—2025年自行重建的年度回报与发行方市场价格回报最大相差 **0.005个百分点**。SPY产品身份由[发行方资料](https://www.ssga.com/us/en/institutional/etfs/state-street-spdr-sp-500-etf-trust-spy)核对。上述检查提高资料可信度，不等于每一天的价格及全部历史公司行动均经独立认证。

当前资料没有当年每条记录的首次到达时间和完整修订历史；共同交易日期没有另外逐日对照完整交易所日历。采用当前仍存续的两只ETF，也不构成所有股债产品的代表性检验。IEF是持有7—10年剩余期限国债的基金，与原论文国债期货的持仓、费用和连续合约处理不同。

原研究指引已经包含金融理由、简单对手、用途和代价；本轮把这些要求落实到一个真实候选的定义、冻结设计、数据检查、统计对照、反例和停止决定。

**现有单资产技术信息工作流尚不支持这类双资产日历事件，不能声称已通过那个原生入口或全系统已经固定这一流程。** 本轮使用独立的、有输入和代码指纹的研究合同，并明确采用现行研究规范。旧工作流、预算、定义和冻结实验均未迁移。

另有一个具体接入问题：共享工作区定义表的三项French来源包含不被现有校验器接受的额外字段及绝对路径，全表严格读取失败。本轮未改这些他人记录，也未放宽校验器；使用本任务已发布分支的有效规范登记表，仅追加本对象并严格解析。执行快照与基线见 `definition-binding.json`；**本对象尚未合入共享主表，也未合入main或生产**。
