# EMA120乖离扩大到四行业ETF：信息增量研究（2026-09-28）

## 一句话结论（大白话）

在半导体、有色、银行、医疗四只ETF的这段历史中，已知道近期涨跌、波动、产品身份和统一市场状态后，再加入价格偏离EMA120的大小，整体预测反而更差：负乖离误差增加3.57%，正乖离增加5.83%。偏熊时较深负乖离后反弹较多是原始现象，不能据此把乖离升级为普遍买卖依据。

限定范围：四只事先选定的存续行业ETF，评价2022-01-04至2026-06-30；仍是已使用历史的探索，新日期验证未做。统一沪深300状态不等于每个行业自身牛熊；历史资料到达时间未知。
