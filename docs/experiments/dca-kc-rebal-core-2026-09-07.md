## 一句话结论（大白话）

三个问题都有了答案：

**① 科创腿值得进组合，"换"比"加"好。** 把跨资产四件套里的创业板**换成**
科创50：年化 15.8%→**17.1%**（多 1.3 个点），代价是最大回撤 −9.8%→−12.6%
（多 3 个点）；改成五腿（创业板+科创50 都留）介于两者（16.4%/−12.6%）；
七腿全景（再加中证500/1000）16.1%/−14.8%，性价比反而降——腿多了、A 股腿
之间相关性高，稀释了跨资产的好处。**科创100 在它仅有的 4.3 年短窗里与科创50
年化几乎一样（22.9% vs 23.0%）、回撤还浅 1 个点**（−10.9% vs −12.0%）——
方向参考，短样本不足为凭。

**② 再平衡方式：季度完胜月度（4/4），阈值版判负，年度别用。** 季度再平衡
（每三个月一次、共 23 次交易）比月度（69 次）终值还略高、交易省三分之二；
**±5% 阈值触发版反而全面更差**——高波动腿 5% 的带宽太窄，触发比月度还频繁
（74~90 次）白交摩擦；**年度版不稳定**（本轮两个组合都不如不再平衡，与
第七轮篮子结果相反——频率太慢时单次再平衡的时点运气支配结果）。结论：
**季度或月度，季度更省更优；别用窄阈值，别用年度。**

**③ 纳指长持不参与再平衡：确实多赚，代价是回撤，教科书级的收益换回撤。**
50% 纳指"只买不卖"长持 + 50% 其余腿月度再平衡：年化 16.4%→16.8%（+0.5 个
点）、回撤 −12.6%→−14.4%；100% 纯纳指定投：年化 18.5%、回撤 −22.0%。每多
一分"不卖强者"，收益升、回撤也升——没有免费午餐，按自己扛不扛得住回撤选。
按"年化÷回撤"性价比排序仍是：全再平衡（1.30）> 半长持（1.17）> 纯纳指
（0.84）。

（XIRR = 资金加权年化；再平衡 = 定期把各腿市值拉回等权；pp = 百分点。）

## 4. 细读

1. **科创腿的贡献是真实的但不大**：换科创50 年化 +1.3pp——科创50 这五年的
   高波动（含 2024-09 起大反弹）被再平衡持续收割；但回撤同步加深 3pp，
   性价比（1.36）仍低于基准 A0（1.61）。**要收益选 A2、要稳选 A0**，这是
   风险偏好菜单，不是谁对谁错。
2. **再平衡频率存在"够用区间"**：季度 ≈ 月度（略优）> 年度（不稳）；
   阈值触发在窄带宽下退化为"更贵的月度"。机制：再平衡的增量来自腿间
   波动差，季度检查已足够捕捉，频率再高只是多交摩擦；频率太低（年度）
   单次时点运气支配结果、不稳。
3. **纳指长持 = 收益换回撤的旋钮**：与八轮总开关、估值分位等"择时旋钮"
   不同，它是**配置旋钮**（改变风险敞口而非择时），所以才允许"多赚"——
   代价表已列，交给用户自选。
