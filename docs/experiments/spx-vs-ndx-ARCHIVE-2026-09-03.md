## 〇、大白话总结（非量化读者先读这段）

已有的两个候选方案里，"美股那一半"全都用的**纳指**，从没测过换成**标普500**。这次没有设计任何新东西：把现成的两套框架原封不动搬来，只把美股腿的标的从纳指换成标普500，其他一字不改（创业板那半的规则、费用、时间窗全部不动），然后如实对比两边数字。

先解释几个词：**年化**是每年平均复合收益率；**最大回撤**是从最高点跌下来的最大跌幅，衡量"最疼的时候有多疼"；**收益回撤性价比（Calmar）**=年化÷回撤绝对值，越高说明每承受一份疼换来越多收益。

结果一句话：

1. **两只版**（创业板择时 + 美股满仓持有，16.2 年）：换成标普后**年化少约 1.9 个百分点**（15.89%→13.99%），**回撤浅约 1.7 个百分点**（-25.6%→-24.0%），性价比略降（0.62→0.58）。两个版本日涨跌高度相似（相关 0.978）。
2. **防守版**（美股指数长持+回撤闸，40 年同窗）：两档防守后回撤都被压到 **-19%~-20%** 一线；标普档年化比纳指档低约 2 个百分点（5.1% vs 7.1%），各自相对"纯持有"的年化代价几乎一样（约 4.2pp/年）。
3. 差异来源清楚：纳指科技股占比高——涨的时候更猛（2020、2023 年两只版差距最大的年份），跌的时候更深；标普行业更分散，弹性小、也更稳。**本报告只出对比数据，不构成"该用标普还是纳指"的建议，资产决策留给用户。**

## 四、机制归因（差异从哪来）

- **P1（|Δ年化|=1.90pp）**：方向与美腿持有差（-3.53pp）一致，等权一半≈-1.77pp，剩余来自再平衡交互与费用 → **美腿收益差主导**（符合冻结归因规则第一条）。年度表定位：差距集中在纳指科技牛年份（2020/2023/2013/2019/2015），反向只出现在纳指深跌年（2022）。这与"纳指科技权重高、标普行业分散"的行业结构叙述方向一致，但本实验未直接检验行业暴露，只能记"与行业结构一致"而非"由行业结构证明"。
- **P2（|Δ策略年化|=2.02pp，触发归因阈值）**：持有腿差 ann -2.13pp / 回撤浅 21.2pp；策略差 ann -2.02pp / 回撤 -1.6pp。策略年化差与持有差方向一致、量级接近 → **指数本身差异主导**。回撤侧：防守闸把两条深浅悬殊的持有腿（-57% vs -78%）都压到 -19~-20% 一线，纳指档"削减空间"天然更大，所以保险性价比（13.8 vs 8.7）的差距主要来自分母端（持有回撤深浅），不是闸门效率本身。
- **P1 与 P2 的表面不一致**（P1 标普版回撤浅 1.7pp；P2 标普档回撤反而略深 1.6pp）：不矛盾，机制不同——P1 美腿是裸持有，标普持有回撤浅直接传导；P2 防守后回撤差异被闸门抹平，剩下的是收益弹性差。两处数据都如实保留。

## 五、冲突发现

1. **归档标签"纳指 20/80·5档"与生成代码不符（文档类欠账，已解决）**：`us_defense.json` 标签与《宽度全栈组归档》均写"5 档"，但生成代码（`render_kuandu_archive.py` jrun）两档都是 `n_bands=3`（本脚本 G3 逐位复现 3 档口径，max |Δ|=0.0，证实归档数字出自 3 档）。真"5 档+底仓 30%"的生产终版预设（`presets.py nq_b200_defense_final`）在共同窗为 7.76%/-18.2%，与 3 档方向一致、量级差 <1pp。**结论：标签笔误不影响结论方向，但引用防守版纳指数字时应以"3 档 20/80（档位线 40/60）"为准。**（验证强度：强，逐位复现+补充臂）
2. **纳指档的信号宽度用的是 SP500 成分宽度**（生成代码 `breadth="sp500"` 两档同源）：即纳指防守版的信号输入不是纳指自身成分的宽度。这是原认证口径的既有组成细节，不是错误，但对"纳指防守版"的解读有影响——它的信号是美股整体宽度而非纳指内部宽度。如实披露，未重测。（验证强度：强，代码级确认）
3. **ixic_close.parquet 的原始抓取脚本在当前树中找不到**（9-1 事故遗留，`legacy_recovery/README.md` 记录了三脚本丢失事件，该数据文件幸存）：文件为认证基线的输入，本任务原样使用未动；无法从当前代码追溯其抓取方式。属**数据工程欠账（溯源类）**，因 G1 已逐位复现认证值，该欠账不影响本对比的有效性。（验证强度：中，复现通过但溯源断链）
4. **两美腿均为不含股息的价格指数**：^GSPC 与 ^IXIC 同为 Yahoo 族价格指数（股息不计入），口径对称——这是 P1 选 ^GSPC 而非 SPY 的原因（SPY 复权含息，实测同窗 14.91% vs ^GSPC 12.93%，股息差≈1.98pp/年）。若实盘用 ETF，两条腿各多约 2pp/年，相对结论不变，绝对数字会整体上移。属**如实声明的口径边界**，非欠账。（验证强度：强，实测量化）
5. **行业权重结构解释的边界**：本实验证明了"差异存在、由美腿传导、集中在科技牛/科技跌年份"，与行业结构叙述一致；但**没有直接检验行业暴露**，不能声称"差异完全由行业权重解释"。剩余可能混杂因素（数据工程面）：两指数数据同源同窗同口径（已排除窗口/复权/费用差异），无其他已识别欠账。（验证强度：中，描述性归因）
