# AI如何研究有金融依据的策略：收益来源、适用股票池与验证流程

日期：2026-10-31。范围：公开原始资料调研＋本项目流程只读审计。没有新增收益回测、因子挖掘、参数搜索或前向策略。本文是方法研究，不证明任何候选已经有效。

## 一句话结论（大白话）

**值得把“这笔收益为什么存在”放在研究入口。现有工具已经能查因子、做检验和记录尝试，主要缺口是把金融解释变成一条可以被证据推翻的链：收益来源 → 参与者需求与约束 → 指标所测环节 → 适用股票池与期限 → 竞争解释 → 区分它们的检验。**

本轮查到可借鉴的AI研究框架与学术实践，但没有证据表明某个开源工具能自动认证金融规律。合理解释使研究值得开始；可重复的预测、反例检查、合格的新资料和可执行账户结果，决定它能走多远。也允许从可靠现象出发再提出解释，不能要求研究开始前已证明全部因果。

“赚谁的钱”需要先分清绝对收益和相对优势：持有企业权益的回报不要求有一名亏损卖家；流动性服务可能由急于成交者承担成本；讨论相对同一市场的主动超额时，需要进一步核对其他资金的相对得失。收益高不等于超额高，超额高也不自动等于技能或独特信息。

本轮结论：**复用已有研究平台，补收益来源与机制附件；不安装新平台，不重建因子库。** 外部方法只做有选择的借鉴，现有旧研究及预算保持原样。下面的两张研究卡是拟议设计，不是新实验或旧实验的事前理由。

## 1. 把“收益来源”问准确

下表是本库研究分类，不是互斥、可直接相加的收益归因公式。同一策略可以包含多种来源；具体占比必须另做有条件的实证分析。

| 可能的来源 | 钱或补偿从哪里来 | 我们付出什么 | 研究中必须区分什么 |
| --- | --- | --- | --- |
| 企业现金流与权益持有回报 | 企业经营产生可分配现金，市场重新定价未来现金流 | 资本占用、经营和市场风险 | 好公司是否已太贵；企业增长不自动变成超额收益；与可投资的同类基准相比如何 |
| 风险补偿 | 投资者要求在不利状态下承担风险获得补偿，反映在买入价格和预期收益中 | 坏时期亏损、融资或流动性压力 | 高收益是否仅因更多市场、行业、规模或尾部风险；相近风险的简单方法是否做到同样效果 |
| 流动性与保险等服务 | 对手方为立即成交、转移风险或满足现金需求承担成本 | 库存、逆向选择、尾部风险和执行成本 | 对手方可能是理性付费者，不能直接叫“韭菜”；价格让步能否覆盖我们的成本 |
| 信息消化或行为偏差修正 | 某些信息没有及时或充分反映在价格中 | 判断错误、修正时间不确定、拥挤和竞争 | 信息何时公开、谁受限、为什么专业投资者未消除差价；收益是否其实是风险补偿 |
| 制度约束与非收益目标 | 指数规则、资金赎回、投资范围、负债或考核形成交易需求 | 提前交易的判断风险、规则变更与拥挤 | 是否确有被约束的参与者及可核日期；事件后涨跌不能单独证明强制交易是原因 |

持有期总回报首先核对价格变动与现金分配：`(期末价格 − 期初价格 + 期间分配) / 期初价格`，多次分配再投资、拆并股和外部入金需相应账本处理。价格上涨既可能来自预期现金流改善，也可能来自估值或要求回报变化，不能统称“市场增长”。

Sharpe的主动管理算术要求先定义同一市场与被动组合：在相应假设下，主动资金整体的成本前平均回报等于该市场回报，较高成本降低成本后平均回报。它不要求每笔赢家交易都对应一个绝对亏损者，也不排除部分人跑赢。[作者原文](https://web.stanford.edu/~wfsharpe/art/active/active.htm)

因此一张策略卡要分别写：**赚到的总回报、相对事前可投资基准的差额、可能的风险补偿、仍未解释的部分。** 未解释残差不能直接命名为金融规律、运气或独特alpha；长期持有的正收益也不能直接算选股功劳。

## 2. 本轮找到的框架及取舍

这是一组有明确用途的参照，未声称穷尽行业，也未发现能够替代研究者科学判断的统一认证标准。

| 来源或方法 | 本轮实际核到什么 | 对我们的用途 | 不能据此宣称什么 |
| --- | --- | --- | --- |
| Microsoft RD-Agent Finance Data Copilot | 官方文档串联报告假说、因子定义与实现、Qlib回测、反馈修订；示例绑定CSI300及时间切分 | 借鉴每一步保留理由、输入和反馈的组织方式 | 演示框架不证明机制正确；示例股票池不适合所有策略；被反复反馈的数据不再是独立测试 |
| Open Source Asset Pricing / CrossSection | 作者仓库区分Signals、Portfolios与数据发布；提供定义目录和对照信号，完整重建涉及WRDS等来源 | 因子溯源、定义核对、复现参考和反例检索；复用本库已接目录 | 目录项数不是有效策略数；开源代码不代表全部底层数据免费，也不代替本地股票池资格 |
| Harvey–Liu–Zhu的多重检验研究 | 作者摘要说明大量因子搜索使普通单次显著性门槛不足 | AI生成的全部公式、池、期限、模型及失败均留账；按依赖关系评价选择偏差 | 不能机械把某个t值当所有用途的通行证；统计筛选不证明金融机制 |
| Nagel的流动性供给研究 | 作者摘要将短期反转与流动性供给联系，并指出回报随市场压力变化 | 为反转提供一个可竞争、可反驳的机制起点 | 海外文献不能证明本地A股月度反转有效；代理变量关系也不直接识别实际卖方 |
| 本项目已有技能与入口 | 已有机制、用途、universe、强对手、冻结、尝试、资料和账户检查 | 沿既有合同附机制证据，不建立第二个研究控制器 | 非空解释、文件SHA和程序通过都不认证经济解释 |

来源：[RD-Agent官方场景文档](https://github.com/microsoft/RD-Agent/blob/main/docs/scens/data_copilot_fin.rst?plain=true)、[OSAP作者仓库](https://github.com/OpenSourceAP/CrossSection)、[多重检验研究摘要](https://www.nber.org/papers/w20592)、[流动性研究摘要](https://www.nber.org/papers/w17653)。本轮未运行这些项目，也未验证它们宣传的投资业绩。

## 3. 建议采用的研究顺序

这是对本项目现有流程的具体化，不是另建平台。每一步写入同一研究的已有开题、附件、合同、尝试账本与报告。

| 步骤 | 必须留下的可核内容 | 什么情况不能升级 |
| --- | --- | --- |
| 1 现象与用途 | 观察到了什么、来源和当时可知时间；要改善选择、持有、退出、风险还是组合 | 单个赚钱图形、仅有名字或抽象“更聪明” |
| 2 收益来源与竞争解释 | 相关参与者及需求/约束、我们提供的服务或承担的风险、优势为何可能持续；至少一个竞争解释 | 用“散户傻”“机构接盘”替代证据；故事随收益结果改变 |
| 3 可区分的预测 | 主解释与替代解释分别预期什么；在哪些对象、时期、期限应减弱、消失或反向 | 所有涨跌都能被同一故事解释；只有价格涨了这一项观测 |
| 4 机制导出的universe | 决策时真实可选的名单、行业/规模/流动性/会计口径、上市与退出、交易约束；少量事前主池及反例池 | 从今天的幸存者回推；看到效果差就换池直至好看；把A股/美股标签当完整定义 |
| 5 因子测量与资料资格 | 指标对应机制哪一环，代理误差是什么；准确公式、披露时间、修订版本、公司行动、缺失 | 公式可算就当机制可见；后公布信息提前使用；缺价变零收益 |
| 6 冻结最小检验 | 主要问题、强简单对手、同池基准、母指数/市场参照、费用与容量、样本和全部尝试历史 | 同时挑公式、股票池、窗口、模型和基准却只报告赢家 |
| 7 机制证据与行动效果分别核验 | 核方向、条件差异与反例、共同暴露；账户用途另核完整成交、现金、退出和扣费曲线。先后由主要用途决定，也可以直接检验行动差额 | 相关性当因果；IC当利润；样本行数当独立机会；收益差额重复归因 |
| 8 独立验证与组合 | 固定版本测试未用于修订的新证据，再核评分、持仓、收益、共同下跌和同一资金下的组合增量 | 重复看过的历史称样本外；仅凭低相关或好故事进前向 |

**机制检验不必一开始就做到完美因果识别。** 可以依次标为“合理猜想”“有区分力的证据与机制相符”“有较强识别支持”，并始终保留替代解释。交易效果另列“未评价/有限证据/独立验证范围内支持”，不能合成一个总分。

金融理由应在投入前说清，但不把“因果完全证明”设为所有行动效果检验的前置条件；直接比较行动也可以，只是结果不能自动反证或证明所讲的机制。

若存在合适的制度变化或外生冲击，可以考虑事件比较、匹配或其他识别设计；必须检查其假设，例如同期变化和选择偏差。没有这类证据，就报告条件关联，不能因为做了回归而声称因果已证。

允许两条入口汇合：一条从经济机制推导预测；另一条从可复核的经验现象提出候选机制。第二条产生的解释及新检验要带时间戳，不能倒填为第一次发现时已知。AI训练中接触过的论文与历史范围未知，也不能称模型完全未见历史；真正独立的后续观察需另行标明。

## 4. 可直接放进既有合同附件的机制记录

不随意给严格JSON合同增加字段。沿已有`claim_mapping`、`sample_fit`及Markdown附件，填写以下问题并引用准确证据：

1. 现象和拟改善的决定是什么？我们已经看过哪些历史？
2. 收益属于哪些来源，绝对回报与相对基准优势如何分开？
3. 涉及什么参与者，他们为何交易、受什么约束；哪些只是猜测？
4. 我们承担什么别人不愿承担的风险，或提供什么服务？
5. 竞争与套利为什么可能尚未完全消除机会？容量与失效条件是什么？
6. 因子测到链条的哪一段，测不到什么？
7. 哪些股票池、时间尺度和市场条件适合检验，反例对象是什么？
8. 主解释与竞争解释有哪些不同预测，什么结果会削弱主解释？
9. 最强简单对手、同池基准与对应母指数是什么，交易代价如何比较？
10. 当前证据强度、缺件、全部尝试记录与唯一下一项可改变判断的证据是什么？

AI可协助找原文、提竞争解释、推导预测、核公式、写测试、核账和生成审阅材料。主控需检查引用是否支持论断、指标是否测到机制、对照是否公平。多个AI意见一致属于审阅过程，不是新的市场证据。

## 5. 示例一：短期反转，先研究暂时卖压

**状态：本库拟议机制卡；未新增实测。** 文献给出流动性供给这一解释，但不能直接搬成A股月频规则。

| 项目 | 填写示例 |
| --- | --- |
| 问题 | 在可交易、历史资格清楚的股票中，近期相对下跌是否包含会消退的价格压力，且足以覆盖成本？ |
| 收益来源与参与者 | 假说是卖方因现金或仓位约束急于成交，提供承接的一方获得价格让步；不是认定卖方无知或亏损 |
| 承担的风险与持续原因 | 承接后继续跌、坏消息造成永久损失、资金占用；约束、风险和交易成本可能限制套利，均待证 |
| 竞争解释 | 基本面恶化、行业共同冲击、买卖报价反弹、停牌/缺价处理造成假反转 |
| 因子对应环节 | 近期跌幅只是价格压力的代理，不能识别资金需求；成交异常也不等于实际净卖盘。可信申赎或规则事件才能补相应证据 |
| 事前适用池 | A股与美股分别设计；在历史可选名单内按形成日前规模、行业和流动性比较；保留可成交、交易单位、价格限制、退市和成本要求，不先指定小盘必胜 |
| 有区分力的预测 | 暂时压力解释预期压力缓解后有相应修复，且和可测压力强弱有关；若主要出现在基本面持续恶化或不可成交对象，需改判。共同宏观风险仍可能混淆 |
| 期限 | 由压力形成与缓解速度确定；若现象只持续几天，不为服务低频系统而擅自改成月度；若维护成本过高，可不采用该用途 |
| 简单对手与反例 | 普通反转、同池不筛选、已有低波/趋势方法；关键暴露相近的低压力组；比较少亏与错过收益，不只挑修复赢家 |
| 否定或降级条件 | 换成可执行价格/成本后差额消失；压力代理不能区分预测；控制共同暴露后不稳。资料不够则是无法区分解释，不能宣称机制不存在 |
| 旧证据边界 | 原CN固定2014年末300股、US当前IVV回溯池，加趋势过滤与退出，只回答那些版本在那些样本的结果，不否定全部A股反转；同样不证明“换池后必好” |

文献依据仅支持这项机制候选，具体条件与检验是本库拟议延伸，未复制作者组合或宣称复现。[Nagel，Evaporating Liquidity](https://www.nber.org/papers/w17653)

## 6. 示例二：盈利能力＋投资扩张，区分好企业与好价格

**状态：用本库已有组合问题展示方法；无新收益结论，也不倒改旧实验解释。** 原证据保持在[盈利与资产增长组合报告](profitability-investment-combinations-2026-10-24.md)。

| 项目 | 填写示例 |
| --- | --- |
| 问题 | 在行业和财务口径可比的企业中，高盈利＋较慢总资产增长的联合条件，是否比单看盈利、单看资产增长或简单资金分配提供更多有用信息？慢增长不直接等于投资优质 |
| 收益来源 | 持有回报可能来自企业未来现金流；相对优势还需要有利买入价格、风险补偿或市场未充分反映信息。不能由“高盈利”直接推出超额 |
| 参与者与竞争解释 | 候选解释是市场对扩张回报或盈利持续性预期有偏差；风险、行业结构、会计差异与简单价值暴露均可能解释结果。谁错估、为何错估目前未知 |
| 因子与机制 | 当前候选测量高盈利与较慢总资产扩张；盈利、现金流及资产增长测不同经营环节，低资产增长本身不识别资本配置效率。毛利/资产、ROE等不是同义替代；金融企业、无形资产密集企业可能不可按同一比例横比 |
| 事前适用池 | 首先在会计和行业可比、披露版本与退出完整的普通企业中检验；金融企业需另定义。A股/美股各自绑定财报可得时点、历史资格与对应基准 |
| 有区分力的预测 | 若主张市场错估未来盈利或投资回报，需要可得的事前市场预期与事后兑现差别证据；仅经营较好不能证明错误定价。缺预期资料时保留机制未知。未来兑现只用于验证，不回填成当时信号；若低估值、行业或规模已解释结果，新增解释需降级 |
| 组合检验 | 先固定盈利与投资强弱的少量条件分组，比较联合条件和两个单项/简单资本组合；对相同样本、资金、风险、成本比较，不靠低评分相关认定增量 |
| 否定或降级条件 | 经营链不支持假说、效果集中于少数行业/年代、扣成本无差额或强单项已解释全部；只削弱对应解释或用途，不判整类因子无效。长期增长过慢也可能是经营衰退，不能把“越慢越好”当规律 |
| 当前取舍 | 复用旧证据及其缺口，先补有区分力的经济记录；仅有价格收益与相关性还不能确定赚钱机制。需合格资料后才设计新的有界问题 |

上述基本面研究是独立研究用途，不改LEI原技术策略的判定或硬过滤。

## 7. 因子怎样有金融理由地组合

| 组合目的 | 合理的候选逻辑 | 必须做的比较 |
| --- | --- | --- |
| 联合选股 | 一项度量预期回报来源，另一项识别其兑现条件，例如经营能力与扩张质量 | 联合条件对各单项、简单混合、共同暴露；避免只是筛掉更多股票 |
| 策略资金配置 | 收益来源、亏损情景或持有周期可能不同 | 同一资金、现金和风险约束下的净收益；持仓重合、共同下跌、压力时期与回撤持续时间 |
| 执行或风险改善 | 一项选机会，另一项降低无法成交、过度集中或资金占用 | 原策略加简单执行/风险规则的对手，核避免损失与错失行情；不能仅凭低仓位称预测改善 |
| 按环境调配 | 机制依赖可事前观察的条件，且改变策略的成本可承受 | 固定配置与简单调配；环境指标可得时间、误判和频繁切换成本；事后牛熊标签只作描述 |

**低相关可以提示分散可能性，但不能单独说明收益来源独立，也不能成为采用条件。** 同一机制可能在样本中表现低相关，不同机制也可能在危机中同跌。股票池、期限、风险暴露、成本和共同亏损都要放在解释旁边。不能承诺任何组合穿越所有牛熊。
