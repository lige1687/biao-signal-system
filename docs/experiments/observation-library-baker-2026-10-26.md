# 市场观察库与 Baker 情绪历史：展示交付

## 一句话结论（大白话）

首页和基本面宽度区域已接入默认收起的观察库，24类候选去重为33个市场/指数项目；15项有可显示读数，18项明确待补资料。用户可把已有读数放到首页、再收回，选择保存在当前浏览器。Baker已取作者原表，最新所属月为2025年12月，只作历史情绪水平观察，未证明顶底预测或账户改善。

## 用户问题、用途和本轮边界

用户授权把此前发现的指标和模型整理为按优先级阅读的列表，先收起来，自选首页展示，并明确不要重复；估值应绑定所观察的大盘指数。本轮解决“如何一起看、看哪一个值、如何管理首页”这一展示问题，服务策略的基本面/消息面叙事层。

基准是原来分散的观察入口与首页固定焦点卡。本轮复用已有API、历史文件和图表，不重算同族因子，不改变技术信号、过滤、仓位或交易执行。原焦点卡改由观察库选择显示。列表顺序表示日常阅读优先级，并非预测能力排名。

复用[24类候选研究](breadth-companion-observation-discovery-2026-10-26.md)、[焦点顶底检验](focus-momentum-turning-points-2026-10-25.md)、[金融压力用途核查](financial-stress-operating-feasibility-2026-10-25.md)，不重跑已回答的收益问题。

## Baker 原表：是什么，怎样看

本轮实际读取[作者主页](https://pages.stern.nyu.edu/~jwurgler/main.htm)及其链接的[官方工作簿](https://pages.stern.nyu.edu/~jwurgler/data/SENTIMENT.xlsx)，原件和HTTP回执保存在本报告raw目录。工作簿README标记2026年3月更新。

当前维护版用五项美国市场情绪代理的主成分形成综合水平；原论文六项版中的NYSE换手已被移除。SENT是未作宏观调整的综合水平；SENT_ORTH先处理宏观变量影响，再合成，且宏观处理于2026年修订。它观察市场热情的共同成分，不是主观“市场今天几分”，也不是A股自身情绪。

展示默认SENT_ORTH，可切换SENT。原表816个月份标签中，1958-01至1965-06的90个月两列均无值；有效SENT为1965-07至2025-12共726月。SENT_ORTH有725个值，2025-10缺值保留断线。主控以标准库XML独立回算全部日期和值，与导出完全一致。

作者明确提醒不能把相邻月指数差值当作情绪变化，因此页面不显示Baker环比，不把零线上穿解释为情绪回暖或底部信号。历史首次发布时间和当时版本未知，不能把这份2026年修订表直接当成当年可交易信息。
