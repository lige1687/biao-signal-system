## 1. 预注册协议（跑前写死，跑后未改）

### 1.1 判定线及依据

| 线 | 值 | 含义 |
|---|---|---|
| 高相关主判定 | Pearson ≥ **0.75** 且 Spearman ≥ **0.70** | 可复用该标的已验证规则作为参考 |
| 中相关 | 0.55 ≤ Pearson < 0.75 | 仅方向参考，档位输出误差可能大 |
| 不可复用 | Pearson < 0.55 | — |
| 最少重叠 | 全窗共同交易日 ≥ 120 | 不足则「样本不足，不下判定」 |
| 年窗稳定 | 全部日历年窗 ≥ 0.50 且中位数 ≥ 0.70 | 任一年窗 < 0.30 → 判「不稳定」，即使过主线也降级表述 |
| 灵敏度面 | 阈值在 {0.60,0.65,0.70,0.75,0.80,0.85} 逐档重判 | 展示结论对阈值的敏感度，不用于事后选阈值 |

**0.75 的独立依据（非照搬 Prompt T 的 0.80）**：
1. R²≈0.56：持仓约 56% 方差与参考标的共动。宽度档位规则管的是市场
   beta 部分，移植语义要求共动部分过半。
2. 结构参照：ETF 对自身跟踪指数典型 >0.95；A股跨行业指数对典型
   0.5–0.8；主动行业基金对行业指数典型 0.6–0.85。0.75 位于「主动基金
   可达到的上沿区域」。不用 0.80 是因为本任务对象是主动基金/QDII，
   净值噪声天然更大，且用途是「参考规则」而非「数据代理」。
3. 0.55 下限：R²≈0.30；A股任意两个宽基日收益相关性常达 0.5+，低于
   0.55 无区分度（黄金对照的区分意义也在此）。

### 1.2 QDII 滞后条款（跑前写死）

QDII 基金 T 日净值反映美东 T-1 收盘。QDII×美股配对 lag0（同日）与
lag1（美股 T-1 对基金 T）双算，**有效相关 = 两档 Pearson 较高者，两档
数字均披露**（§4 各表括注 lag1，双档明细见 §4.1/§4.2）。实测全部
QDII×美股配对 lag1 ≫ lag0（如 100055×SMH：lag1=0.600 vs lag0=0.112），
滞后条款有效。

### 2.1 数据修复痕（诚实披露）

首跑出现过一次系统性数据 bug：天天基金 pingzhongdata 的净值时间戳
`x` 是**北京午夜对应的 UTC 毫秒值**，直接按 UTC 解析会全部早一天
（诊断线索：基金净值出现 512 个「周日」条目）。当时症状是 QDII×QQQ
相关性仅 0.07、A股基金×A股指数 ≈ −0.07（错位一天后随机水平）。修复
（解析 `+8h`）后重写 `{code}_nav.parquet` 并重跑全部计算，本报告所有
数字均来自修复后数据。原始 `*_pingzhong.js` 与修复后 parquet 均存于
raw 目录可复核。
