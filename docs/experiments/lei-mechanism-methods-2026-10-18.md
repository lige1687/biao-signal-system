# 原策略怎样收敛：候选金融含义、科学方法与原始依据

2026-10-18。本轮完成候选去重、定义边界与方法审查；新收益实验未运行，完整LEI效果仍未验证。

## 一句话结论（大白话）

**先保留三个需要回答的决定：何时确认入场、怎样退出并重新参与、同一机会投入多少以及如何共用资金。** 其中退出已有明确的少跌与少赚对照，直接复用；入场和仓位仍须补原文含义与资料。其他均线先作少量比较对象，不能靠换名字、改周期把旧负结果变成新发现。文献给研究理由和方法，不证明我们的参数与组合有效。

本对话负责原LEI、原因子、原模块与组合；另一研究对话独立寻找新低频方案；系统实现对话负责Web和判断行动链。本文不重复独立方案研究，不改原文、生产规则或真实账目。

## 1. 收敛后的三项候选

这里的“因子”是一条在当时能够计算的信息；“策略组合”还规定怎样行动和使用资金。金融含义是可检验的解释，不是金融定律。

| 优先项 | 金融含义与可观察定义 | 新增帮助要问什么 | 什么会削弱它 |
|---|---|---|---|
| 1 原趋势中的确认入场 | 较慢趋势仍在、短期卖压开始缓和时，确认可能减少过早参与。保留原20/60/120组方向与排列、回调身份、底部构造及已收完低一级周期多头状态。原体系主步骤是60/120组；20组来自“首次回撤”经验条款，来源分开。 | 在同一批尚未知确认结果的回调机会中，等待某项确认，是否比已有简单信息多帮助？先明确是检验低周期确认，还是底部与低周期的共同作用。 | 只剩更少机会、买得更贵；扣费后改善不稳定；结果被少数标的或时期解释。多周期都源于价格，不能当两名独立证人。 |
| 2 原入场理由对应的退出与再参与 | 趋势中短暂回撤和持续破坏不同；退出可能减亏，也可能反复卖低买高。保留原结构失效保护，按原文分别标识抵扣价退出、顶部构造后反向关键波动、仅结构失效。卖后只按定义允许的后续新机会再入。 | 同一笔原买入改变退出有何差额？允许后续重新参与后，整个账户还剩什么差额？ | 少跌主要因为长期空仓，错过上涨大于避开损失，或费用与等待吃掉改善。9月8日已测“加道路退出＋新原机会再入”，直接复用。 |
| 3 原风险数量与共同资金组合 | 同样金额在不同失效距离、价格波动和关联品种上承担的风险不同。分别核原简版风险数量、原ATR数量体系，以及多个模块是否重复使用资金或重复承担风险。 | 在同一组入退机会下，是否以更可接受的亏损、恢复时间和参与代价取得相近收益？组合后是否仍有帮助？ | 与预先固定少投入的简单办法相近；风控根本未触发；风险下降伴随过多上涨损失；同日资金冲突或跳空使纸面保护失效。 |

这三项是待检验决策，不登记成三个“已有效因子”。仓位约束不必预测涨跌才有用途，但不能在亏钱后临时把主目标改成省心。

## 2. 定义清楚到哪一步，缺在哪里

已确定部分可写成准确计算，仍有歧义的部分保留未知，不能为了开测擅自补条件。

- **均线方向**：同一价格口径下，SMA在第t日相对前日的变化等于`(C_t-C_(t-N))/N`。因此上涨方向用严格`C_t>C_(t-N)`判断。EMA按既有正式定义判断方向；保留N=20/60/120的状态向量，不把它们加成没有依据的总分。收盘信号不能提前按同一收盘成交。
- **完整A确认**：原体系§4.4要求底部构造和低一级多头同时成立。技术实现A3的“至少一种”和日线代理属于另一版本，不能替代。若起点已要求底部构造，则后续只是在检验低周期确认；要检验两个条件的共同作用，必须另定义共同起点。首次底部确认不等于趋势后的首次回撤。
- **原简版数量**：`数量=事前能承受的亏损金额÷(预计进入价-事前失效价)`，只在分母为正且资料合格时计算，再受可用现金、可交易数量单位等约束。实际跳空和费用可使损失超过预算，不能称保证止损。
- **原ATR数量**：`N单位=(账户资金×1%)/(ATR×合约乘数)`，原文ATR为TR的20日EMA，股票乘数为1。这与止损距离分母不同。原N体系还有品种/关联/方向上限，以及亏损后降低新投入；只核数量公式不能称完成整个体系。多品种须各按自己的N单位换算，不能直接相加股数。
- **原组合账户**：原实现§12允许多个模块分别记录信号，没有给出同日现金不足时的全序分配。现金、数量取整、成交先后、重复持仓和资金不足处理必须明确；没有这些规则就只能交付单项数量比较，不能拼成所谓完整组合收益。

完整效果目前仍缺：历史均线密集目标区间的准确选择、趋势成立同日触碰的首次身份、合格小时资料与收盘对应、完整N及共享资金的未明确细节。先核原出处和遮住后来行情的边界案例；原文不能唯一决定的部分列为需确认含义，不自行改成最赚钱的一版。已有9月结果仍保留历史来源和资料限制。

## 4. 科学方法怎样落实

| 环节 | 本轮采用的研究约束 | 为什么这样做 |
|---|---|---|
| 先有机制，再看成绩 | 预先写作用对象、可能有用的原因、简单对手和否定条件；机制只是待检验解释 | 防止看到漂亮曲线再补故事 |
| 信息和行动分别检验 | 信息问题比较“简单背景”与“简单背景加候选”；行动问题比较同起点机会及连续资金。非排序状态不强套股票排名统计 | 预测误差下降不等于交易赚钱，少跌也不证明预测更准 |
| 强简单对手 | 同口径历史平均/近期涨幅波动/单SMA或EMA，按用途选；账户保留简单持有、原策略和事前固定较低投入 | 候选必须说明超过已有信息多少，不能只赢一个较弱复杂模型 |
| 当时只能知道过去 | 按日期整体安排前段开发、中段检查、最后保留检验；估计值和权重只用过去资料。跨边界尚未走完的未来结果不能用于前段选择 | 本项目已反复看过的历史只作回顾核查，重新切分也不会变成未知检验 |
| 相关机会不虚增数量 | 同日资产共同变化、连续行情和20/30日窗口重叠保留；对保存的逐日配对差额按连续日期段估计范围 | 不能把几百只同涨股票或相邻30天当几百次独立验证。少数事件就保留宽范围和证据不足 |
| 真正算钱与机会 | 同资金、日期、现金去向、费率、成交规则，记录未等到、失效、缺资料、跳空取消、已有持仓和资金不足 | 只看成交者会漏掉等待与错过的代价；缺值不能填零 |
| 少量组合拆解 | 必要时比较都不加、只加甲、只加乙、一起加；计算组合总差及不能由两单项相加解释的部分 | 这是固定规则的历史共同作用，不是市场因果证明；不遍历全部排列找冠军 |
| 尝试历史和否定结果全部留存 | 每个对象/用途/参数变化登记；保留失败、负值和未知；真正新增问题才开新合同 | 多试自然更容易撞到漂亮结果，不能重置预算或隐去失败 |

日期分块的具体长度、主结果和可接受的实际改善量，须在对应运行合同中根据机会窗口与用途确定；本方法报告不硬塞一个通用数字。不会把随机拼接价格后重新生成的账户当成原历史重复证明；若需不确定性分析，分别针对固定起点路径差与连续账户日收益差，并保留状态依赖的限制。

因子评价看信息差额与覆盖；策略评价同时看扣费财富、亏损幅度、恢复时间、参与程度、错过上涨和操作负担。胜率只是其中一项。没有实质改善标准时报告量级与不确定性，不在看到结果后造及格线；没有统计上清晰的改善，也不等于已经证明所有用途都无效。

## 5. 具体借鉴了谁、借鉴什么
