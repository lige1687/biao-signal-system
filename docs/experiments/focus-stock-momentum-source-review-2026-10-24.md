# 冰点：焦点股动量模型的来源、中美股票范围与观察用途

日期：2026-10-24（Asia/Shanghai）。状态：来源与用途调研结案；原模型未完整复现，预测效果未评价。

## 一句话结论（大白话）

找到了量化舵的原视频：每天挑出交易最活跃的一小批股票，看它们近期的平均涨跌，低于零被作者称为“冰点”。它有助于描述热门股是否也在走弱；视频没有公开完整公式，历史底部圆圈又是事后选出的最低日，所以尚不能认定它能提前预测反弹。中美都可研究这种观察方法，但应分别确定股票范围、分开核零线是否罕见，并与简单的市场涨跌比较。

## 1. 原始来源与已核事实

- 原视频：[量化舵《一分钟宏观模型：冰点——焦点股动量模型》](https://www.douyin.com/video/7699879945107016969)。页面显示发布时间 **2026-10-23 23:06**，本地取得的视频长111.27秒。核查日为2026-10-24。
- 已实际读取原视频、完整自动语音转录、20张抽帧和页面作者评论；关键结论以画面文字交叉核对，语音识别把“量化舵”“零轴”等识别错的文字不作为引用。
- 视频约36—49秒说明：从全市场中每天重选最活跃的一小批股票，观察它们近期的平均涨跌。图示按**成交额**排除不活跃股票，脚注写明成员每天变化。没有说明必须是行业龙头、大市值股票或固定几家公司。
- 作者在评论中建议自行设置阈值找交易靠前的股票，使用了“成交量”一词；另对索要公式和参数的评论表示只分享思路。**股数还是金额的文字口径仍有不一致；不能把我们的选法说成他的完整原公式。**
- 未披露：入选数量/比例、成交活跃统计天数、涨跌计算天数、简单平均还是加权、复权与分红处理、ST/新股/停牌边界、具体市场名单。因此不足以准确重画视频的线。

可确认的结构是：当天选出的焦点股票集合 → 这些股票过去某段时间的平均涨跌。当天成交额与收盘价用于收盘后描述状态，本身不算偷看未来；若拿这一天的完整资料解释当日开盘前的决策，就混入了后来才知道的信息。

## 2. 视频数字与性能证据表

下表是原作者在画面上的统计，**本轮只核实其确实展示过，没有取得逐日底表独立复算**。

| 原片内容 | 数字或方法 | 实际能说明什么 |
|---|---|---|
| 指标分布期间 | 2016-02至2026-10，2,602个交易日 | 是作者展示的历史范围，原始底表不可得 |
| 指标均值 | +12.0% | 所选股票的过去涨跌分布偏正；不是策略年收益 |
| 负值出现比例 | 8% | 作者定义下，负值较少；不是未来反弹成功率 |
| 高于同期沪深300 | 98%的交易日 | 是所选股票过去表现的同期比较；不是98%胜率，也不是可交易超额收益 |
| 历史图中的底部圆圈 | 每段负值区间内，指标最低的那一天 | 要看完整段才知道，不是当天可实时识别的最低点 |
| 预测性能 | 未提供全部事件、固定未来期限、失败事件和误差范围 | 无法判断提前多久、上涨概率提高多少或还能跌多少 |
| 账户收益、回撤和费用 | 无持仓/买卖规则，也无交易费用记录 | 未评价；未建立账户，更没有净收益或相对母指数净超额 |

作者把负值称为冰点有自己的逻辑：成交活跃的股票通常已经涨过，若连这一组近期平均也在跌，市场热门部分也转弱了。但“通常先涨才活跃”是作者的解释，放量下跌同样会让股票入选。每日换成员还可能让指标变化包含换名单的影响。

**最重要的反例在原片中已经存在：**约90秒附近展示跌破零后继续跌到更低负值，作者也说明会有更冷的冰点。因此“已经冷”与“最低点已到”必须分开。不能把每段事后最低日之后的反弹当作第一次跌破零后的预测表现。连续多天负值也不能全当作互不相关的多次成功。

## 3. A股与美股股票范围建议

以下是服务我们宽基/ETF低频复盘的**新研究设计建议**，并非作者已公开参数，也没有实施或证明有效。

| 层次 | A股建议 | 美股建议 | 回答的问题 |
|---|---|---|---|
| 市场主观察范围 | 当时上市的沪深普通A股，覆盖主板、创业板、科创板；北交所单列 | NYSE、Nasdaq、NYSE American上市的美国本土普通股；境外发行人与ADR单列 | 市场上交易最活跃的一批股票是否整体走弱 |
| 资料与异常处理 | 当日停牌不以零收益填补；新股历史不足不计算；ST/退市整理单列，保留覆盖数量 | ETF、杠杆/反向产品、优先股、权证等不混入普通股；合并公司多类股份口径，防重复计算 | 避免把产品类型、上市首日或缺资料当作情绪 |
| 持有ETF对应范围 | 沪深300与中证1000分别观察，按当时有效成员 | 标普500与罗素2000分别观察；纳指100单独作为该指数的范围 | 观察到的冷暖是否与自己关注的宽基一致 |
| 焦点组的形成 | 在上述每个独立范围内部，按人民币成交额选交易最活跃者 | 在各自范围内部，按美元成交额选交易最活跃者 | “资金关注集中在哪里”，避免直接比较不同股价股票的成交股数 |

主观察范围应足够宽；焦点组是在其中再筛出的一小部分。固定只看几只大公司会改变问题：衡量的是这些公司的状态，不能直接命名为全市场焦点。没有必要一开始把所有层次都开发成面板；先选A股市场主线与美股市场主线，各用相关宽基作对照，持仓范围在实际需要时再细分。

跨市场可优先采用相同的排名比例，再同时展示入选数量和其成交额占全范围比例，比机械地两边各选前十只更容易解释。不过比例、活跃窗口和动量窗口仍须先明确固定，不能反复改到图最好看；本轮不编造一个“原模型参数”。美股的零值出现比例和经济含义必须单独核验，不能直接套A股8%。

历史计算须保留当时上市、后来退市的股票，不能把今天名单放回十年前；指数版本同样须有当时有效成员。当前名单可用于当下观察，不等于具备历史验证资格。

## 4. 观察用途与相对已有信息的增量表

最适合本轮保留的用途是为宽基/ETF复盘提供市场状态补充：热门股是独强、随市场一起弱，还是修复开始扩散。可每日收盘更新，按周阅读变化，避免一个日内值直接改变低频计划。

| 用途 | 应与什么简单信息比较 | 目前判断 |
|---|---|---|
| 识别热门股整体降温 | 相同时间内宽基指数涨跌、全范围股票平均涨跌 | 定义上能补充热门部分的状态；是否带来额外判断帮助未测 |
| 分清少数股支撑与整体修复 | 上涨家数占比（有多少股票在涨）、焦点组成交额占比、行业构成 | 建议同屏对照，避免把少数股反弹误读成全市场恢复；未实测 |
| 提前提示未来反弹 | 同样跌幅/波动背景下，单看市场涨跌的判断 | 原片证据不足，不能给胜率、提前天数或改善百分比 |
| 改善ETF低频买卖 | 完整原策略/持有对应母指数，含少亏、漏涨、费用和换手 | 未评价，不据本片改技术规则、仓位或买卖计划 |

可展示的最小观察内容是：焦点组近期平均涨跌、其在各自历史中有多低、焦点成交额占比、整个范围上涨家数比例，以及对应宽基走势。前者回答热门股如何，后几项回答这种状态是否广泛、是否只是结构变化；这仍是候选展示设计，不是已实现或已验证的产品。

若继续检验预测，必须以当天可确认的首次负值或事先固定的确认条件统计后续表现，保留所有冷却区间及未反弹反例，按实际低频用途预先固定观察期限，并与同等市场下跌状态比较。原片未披露完整算法和逐日值，当前无法对原模型执行这项检验；自行确定算法只能称为独立研究版本，不能冒充复现。无需通过猜参数重画视频来证明它。
