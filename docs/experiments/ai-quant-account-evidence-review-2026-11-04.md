# AI量化哪些防错措施值得落地：账户证据预检

## 一句话结论（大白话）

最值得补的是“算账前先核证据”：让AI列清缺月、费用口径和特殊选股分支，错误直接暴露，缺件保持未知。现有研究规范和样本留账继续复用；新增一个可选只读检查入口。检查声明自洽可以减少一类错误，尚未证明提高研究收益或覆盖所有旧回测。

## 能落实的六件事

| 项目 | 对个人低频研究的帮助 | 本次处理与实际边界 |
|---|---|---|
| 复用并核验回测底座 | AI改信号时不用重写交易、时点和费用逻辑 | 沿原版本/指纹和独立复核规范；底座有错仍需有界修复，未设置文件权限锁 |
| 月历与缺失检查 | 防止删掉坏月份或把断续资料说成完整净值 | 新预检要求事前完整月历，返回毛/净收益共同覆盖与连续片段；缺月禁止完整连续指标，不填零 |
| 费用对账 | 防止忘记双边、金额或费用时点 | 新预检仅验证明确声明的“期末按比例现金费用”模型；其他模型保留未评价，不冒充个人实际费表 |
| 异常选股分支留痕 | 看出有多少持仓绕过正常选择，以及是否改变研究含义 | 新预检保留原因、数量和权重占比；缺声明标未知。没有源码/逐股证据时不能证明已穷尽分支 |
| 标准报告与异常解释 | 同时看净超额、风险、恢复等待和操作代价 | 补进公共AI指引；TE上升是要解释的变化，不自动判程序错误；参数表按问题使用 |
| 全部尝试与未见样本留账 | 避免持续对话变成隐藏调参 | 复用原试验史与已见检查；新预检保留样本声明和旧记录指针，不新造锁箱，也不验证自报“未见”为真 |

已存在的程序检查并非零：`workbench_metrics.py`对固定展示数据校验主动收益差与完整月历，缺月时不输出整段IR；`factor_group_curves.py`已有目标缺失、非法权重及现金检查；`factor_lab/validation.py`记录试验史和已看保留段。这些入口各有范围，新预检不改其冻结行为。

## 为什么不能把建议原样写成硬门槛

**程序错误、研究约束、诊断信号是三件事。** 重复月份、非法数值和声明模型内账目不平可以硬阻断。持仓宽度、特殊分支权重和交易量限额应在具体合同中事前约定；3%、15%、20%没有通用不变量地位。风险过滤后TE上升并不违反恒等式：`Var(策略−基准)=Var(策略)+Var(基准)−2Cov(策略,基准)`。降低绝对波动仍可能增加偏离基准的波动。

已有[盈利与缓冲V2比较](cn-profitability-risk-v2-construction-2026-11-04.md)给出直接反例，以下均为历史报价与费用假设情景，非真实账户：

| 费用25bp情景，同122个月 | 细行业盈利V2 | 细行业过滤＋缓冲 |
|---|---:|---:|
| 净主动IR | 0.217 | 0.339 |
| 年化主动波动TE | 4.62% | 5.09% |
| 片段内最深相对回撤 | −12.55% | −9.16% |
| 片段内最深绝对回撤 | −46.09% | −48.71% |
| 最长已观测相对水下期 | 23个月 | 34个月 |

| 相对已有规则的增量 | 已有结果 | 能说明什么 |
|---|---|---|
| 细行业缓冲相对盈利基准 | 费用后月均差＋0.060个百分点，95%描述区间[−0.109,+0.228] | 有候选价值，稳定改善未确认 |
| 细行业缓冲相对同过滤无缓冲 | 交易量58.81%→49.19%，相对减少16.4% | 缓冲确实减少该情景交易；不能承诺所有规则减少50%—70% |
| 新预检相对原散落检查 | 统一列出共同覆盖、声明费用矛盾与缺件 | 工程增量；收益、AI实际错误率和操作效率未评价 |

旧“小行业全留”的31.32%是未按盈利排序筛除部分的平均持仓权重，不证明它们全部是噪音或造成亏损。V2有132目标月、127完整毛收益月、122费用资料共同月，财富路径按五个连续片段分别起算；不能据122个可用月声称完整十一年回撤。

**统计规则也不能照搬。** 在独立同分布的简化假设下，10年月度配对收益差有 `t≈IR(收益差序列)×√10`，1.96对应约0.620；这里是差值序列自身的IR，绝不是两策略IR相减的门槛。相关月份、重叠标签和多次选择还需各自处理。即使假设年度胜负独立且各半，11年赢至少8年的单侧概率仍为11.33%，所以年度胜率与参数高原只能提供稳定性描述，不能替代推断。

DSR使用样本长度、收益偏度/峰度、候选Sharpe的变异和有效独立尝试数量等信息，不能简化为“试了20次，就用t=2.8—3.2”。本次核作者论文相关公式及独立尝试讨论，未据此运行DSR或给本项目设门槛。[Bailey与López de Prado，2014](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

2022—2025完整四年是48个月，若只有43个月须先交代缺月；已看过的数据再改权限仍是已见资料。真正未见历史或冻结后的新观察才可提供不同证据。满仓袖套、日/周风控以及双阈值缓冲都是可比较的设计，不是所有个人策略的唯一正确结构；月频风控也不能仅凭频率就断言必然失败。

## 后续AI如何复用

公共入口仍为项目AGENTS → `lei-lowfreq-research` → [因子发现指引](../research/factor-discovery-playbook.md#ai账户研究把错误检查与投资判断分开2026-11-04)。案例参考增加了小行业、缓冲代价与缺月例子。研究准备增加一条证据提问，以及可选的 `--account-review-file`，未传参数时不伪造已检查状态。

在仓库根目录运行已保存的**合成示例**，不读取行情或运行金融实验：

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m lei_signal.research.preparation \
  --root . --practice-only \
  --account-review-file docs/experiments/raw/ai-quant-account-evidence-review-2026-11-04/synthetic-example.json
```

输入结构见该示例及同目录`implementation-spec.md`。月份使用YYYY-MM、收益使用小数，候选和基准分别给毛/净收益。支持的费用声明名称是`linear_end_period`：同起始资产、同持仓/报价路径，逐笔未取整的比例现金费在期末扣除。检查逐笔费用、费用合计及逐期毛净收益差，不把这个模型套到期初扣费、费用改变持仓、真实税费/最低佣金/冲击或年化复利。缺少该模型所需证据或其他模型返回未评价。

每次结果保留请求内容指纹，文件越界、过大、重复JSON键和非法数值会被拒绝。程序只读声明，不认证来源真实、历史PIT、成交可实现或分支穷尽，也不保证所有AI或旧脚本强制使用。它始终不授予研究运行、实盘或科学有效资格；旧定义严格入口的来源格式兼容问题保持独立，示例采用已有practice-only路径。

## 验收与范围

新增模块与准备入口的相关回归23项通过，语法/导入检查和仓库归置检查通过。主控实际运行上面的CLI，核对请求指纹和原文件未变；错费、非法交易结构与数值溢出均阻断，缺中间月保留两个片段，不支持的费用模型返回未评价，31.32%特殊分支只触发解释提醒。

初版暴露的“报错但仍允许指标”、极端数值溢出和错误明细类型已留下反例并修复。另有既有严格定义入口13项失败，原因是来源登记不满足`path+sha256`要求；修改前后同错，未进入新检查逻辑。本轮没有借此改来源登记、绕过严格定义或声称所有入口通过。

本轮接受为本地可选工程能力和公共AI规范补强；源码尚未提交/推送或部署到其他设备。旧脚本未全部接入，真实账户自动取证、完整费用模型、AI错误率与金融效果仍未评价。原任务无待返修项；已知严格定义入口兼容性问题保持原范围。
