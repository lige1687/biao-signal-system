# 连续讨论体验：三组固定补修（C1 比较口径 / C2 路由窄匹配 / C3 用户事实边界）

## 一句话结论（大白话）

主控复验发现的三个「捷径答非所问」已按固定补修单修好：行情比较现在真的去比内容（系统结论、候选数这些冻结字段），同一天内容变了会如实说有变化，日期倒退会说「这是退回较旧资料」；问「换 ATR 止损会怎样」不再被当成行情新旧问题，两个聊天入口都会老实说「这项比较暂未支持」；股数、外币、否定句里的数字和「如果重仓」这类假设不再被当成你的真实资金和持仓，而且你说过「我持有」「这是闲钱」之后，同一只标的的讨论会记住这些背景、不再重复追问——但这只是讨论背景，不会替你记成交、也不会替你下单。

## 1. C1：资料对比比较真实冻结字段

- 比较对象改为同对象、同口径的**已冻结事实**（历史证据卡 vs 当前材料的资料日期/系统结论/买点候选数），不再只比日期；不引入第二套行情计算。
- 行为矩阵（全部有测试）：同日内容变化→如实报「同一数据日内的资料内容变化」；跨日向前→报日期与新结论；**日期倒退→「退回较旧资料」**；字段缺失→该字段「无法核实对比」；字段全缺→「缺少可对比的字段」；对象不一致/中间隔全局轮→只与最近同对象轮比较，没有就说没有；已比较字段全同→只说「已比较字段相同」并明示「没有完整版本快照，不能断言所有细节都没更新」。
- 路由级验收：`tests/unit/test_agent_continuity_routes_20260916.py` 普通路由（同日内容变化）与流式路由（日期倒退）各验正反例，并核对 `/agent/sessions/{sid}/messages` **落库原文**与响应一致。
- 隔离服务链复验（真实缓存、degraded）：c8 回答「已比较的字段（系统结论、买点候选数）相同，资料日期同为 2026-09-16。系统没有保存每份资料的完整版本快照……不能断言所有细节都没更新」（cfix-chain-probe.json）。

## 2. C2：问题路由窄匹配

- 比较触发改为「锚定此前资料的正则」+「方法/资金/新闻排除项」：ATR 止损、止盈方法、投入金额、与上次回测相比等「变化」问题一律不被资料比较抢答（反例全部进测试），正例「和刚才相比有什么变化/有什么变化」保留。
- ATR 类不支持退出方式的诚实说明从「仅 backtest 意图」扩展到**所有意图**（两入口 AgentConsole/AgentWorkspacePage 同构）：此前 discussion 意图下「如果换成ATR止损，胜率会有什么变化？」会漏进通用讨论，且目录层把「ATR」误解析成同名标的（实测 resolved_symbol=ATR）；修后两入口直接给「这项比较暂未支持」+ 继续讨论入口。浏览器实测通过（cfix-ws-atr.png：诚实说明出现、未误解析成 ATR 标的）。

## 3. C3：用户事实边界与会话背景

- 金额守卫：股数（一万股/一万股值多少钱）、外币（1万美元/两万港币，不默认折人民币）、否定句（我没有一万元预算/不用一万）、截断的复杂中文金额（两万三千五）一律不采信为预算；「预算1万美元」这类单位在数字后的形态交回口语分支被外币守卫拦下。正例（一万元/两万五/预算10000元）保留。
- 持仓守卫：假设句（如果重仓会怎样）、否定句（我没有重仓/担心被套暂时没持仓）、功能词（持仓速览）不识别为持有；明确撤销（我已经卖了/没预算）有独立识别供背景清除。
- 会话背景（同会话同对象）：用户声明过的持有/预算/用途按对象绑定记忆——「我已经持有→那现在重点看哪里」保持持仓管理口径；「有一万闲钱→这笔钱怎么安排」记住 10000 元与闲钱用途，不重复追问、不再声称未提供；明确纠正即时失效；切对象不串用。背景材料同步给模型（user_background），提示词明示「只是讨论背景，不是成交记录/写库授权/新交易许可」。
- 分支顺序：本条明确问钱时资金分支优先于持仓模板（持仓者问钱答钱）。
- 路由链验收：固定验收两链均过（持仓→重点看哪里；一万闲钱→怎么安排），含落库核对与「不会替你下单」。
