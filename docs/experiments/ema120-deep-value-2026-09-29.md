# EMA120乖离本身、组合因子与策略示例（2026-09-29）

## 一句话结论（大白话）

这次把乖离当作独立预测信息、允许不同乖离区间有不同关系，并加入牛熊状态组合，仍没有支持整体收益或起点下跌幅度预测改善。六指数组的状态组合在2024出现严重外推，预测跌幅甚至超过100%；四行业组影子账户虽然比基础模型多赚，但由有色一只产品贡献、2026反而少赚且最大跌幅更大。应暂停这些固定表达的继续参数探索，不把这次局部盈利升级为因子或策略有效。

**对系统的处理：保留乖离作为“价格离均线多远”的描述和极端状态提醒；本轮没有理由把它升级为通用收益预测、止损依据或核心组合因子。** 本结论只限EMA120、固定产品和这两种固定表达，不等于所有均线周期、所有组合方法都无效。
