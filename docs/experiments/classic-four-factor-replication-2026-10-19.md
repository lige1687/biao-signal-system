# 四项经典因子复现：原文、公开结果与本地流程核查

2026-10-19开始，2026-10-20更新。用途是核验研究流程，并为后续选股研究建立准确起点；不是LEI策略效果或交易建议。四项完整逐股复现尚未完成。

## 一句话结论（大白话）

这四个方向适合先按经典方法复现，但目前不能说“我们已经复现成功，流程没有问题”。已取得四篇原文、核清核心口径，并检查公开复现代码；发现名称相同的实现也会改变窗口、价格处理或盈利定义。公开组合核算与人工算例能检查部分计算，仍不能代替从原始股票、退市和公告资料重建因子。现阶段保留四项研究，不据此修改买卖规则。

## 1. 这次究竟检验了什么

原研究一般把股票按指标排序，再比较较强组和较弱组的收益；表中的“强弱组收益差”是这种差额，不是个人账户每月可赚多少，做空、费用和资金约束也尚未纳入。所有历史都是已发表、已见资料，不称为从未参与选择的验证。

此次完成层次：原文主要方法核对 → 公开第三方组合数据独立汇总 → 人工可核算的公式检查。尚缺：逐股重建、完整原表、控制已有价格信息后的增量、适配A股/ETF及真实资金策略。

残差动量原文给年化均值11.20%，表中0.933%是除以12的月度参照，并非原文直接报告的月均值；公开序列缺1930年1—5月，因此两者覆盖也不完全相同。不同因子日期和构造不同，不能横向选这张表中收益最高的一个。

参考数据来自Chen与Zimmermann的[Open Source Asset Pricing](https://www.openassetpricing.com/data/)，2025年10月发布的v2.0.0，代码固定至`b4e911e69678a7424f318617a61d813f54183123`。没有把最新代码与已发布收益文件之间尚未核实的生成关系当成事实。均值只是描述；接近原论文不算复现通过，不接近也不能据此判我们程序有错。

在固定月份及预先写定的相关性处理下，价格动量均值的近似95%区间为0.445%—1.538%/月，高点接近度为0.041%—0.905%/月。这些区间说明该统计方法下估计仍有多大范围，**不是“95%概率有效”或未来收益保证**。残差序列缺5个月，按冻结合同不补零，也不计算完整窗口区间。

反例必须一起看：高点序列1970年代平均为−0.048%/月；一月平均−8.702%，其余月份+1.295%。这些分段在看结果前已写定，仅揭示历史差异，不能据此临时新增“避开一月”的规则。价格动量一月也为负（−6.445%），残差序列一月为−0.863%。所有数值来自第三方组合，构造、融资、交易成本和现实可交易性尚未逐股核实。

## 4. 四篇原文的准确起点

| 因子与原始依据 | 金融解释与竞争解释 | 原研究主要构造、范围和关键细节 |
|---|---|---|
| [Jegadeesh、Titman 1993](https://www.bauer.uh.edu/rsusmel/phd/jegadeesh-titman93.pdf)：横截面动量 | 信息反应较慢可能使相对强势延续；共同市场风险、短期交易影响也可能造成表象 | 1965—1989；过去3/6/9/12个月排名、持有3/6/9/12个月。分10组，同组每只等额，多批持有并行。表I A不留间隔，B留一周；不是直接照搬现代12-1个月动量。此轮只固定A表6个月形成、3个月持有那一格，不挑最好数字。 |
| [George、Hwang 2004](https://www.bauer.uh.edu/tgeorge/papers/gh4-paper.pdf)：52周高点接近度 | 过去高点可能影响投资者对新信息的反应；它也可能只是过去涨幅或风险的另一种表达 | 1963年7月—2001年12月；形成时价格除以截至形成月末过去12个月最高价，取前后30%，持有6个月。表I不跳月；回答增量的表V跳过一月。高点的价格调整和缺失细节仍须绑定字段。 |
| [Chan、Jegadeesh、Lakonishok 1996](https://www.lsvasset.com/pdf/research-papers/Momentum-Strategies-Papers.pdf)：盈利动量 | 市场可能没有立即吸收盈利新信息；规模、价格动量或已被预期的增长也可能解释效果 | 1977年1月—1993年1月形成；只在已公告后用资料，盈利排序要求最近3个月公告。主要SUE是季度每股盈利减一年前同季盈利，再除以此前8季度这种差额的波动；另有公告附近异常收益、分析师预测修订，不能混名。随后收益跳过形成后5个交易日；持有中退市后用市值加权市场收益补剩余期间，并每月末重新调回原组合等额。 |
| [Blitz、Huij、Martens 2011](https://repub.eur.nl/pub/22252/ResidualMomentum-2011.pdf)：残差动量 | 排除市场、规模、价值共同涨跌后，保留股票自身变化；遗漏的共同风险仍可能混在其中，不叫“纯独特优势” | 1930—2009报告期，1926起预热；美国主要股票并排除若干非普通股票类别及价格低于1美元的月份。以连续完整36月估计共同影响，再对过去12月去掉最近1月的剩余变化打分，并按其波动缩放。原表2B的一月持有版年化均值11.20%，另列的10.85%是控制后的收益，不能混比。 |

阅读范围和未唯一确定细节见文末证据目录内的 `methods-reviewed.md` 方法读回文件。前三篇主要方法页已读，第四篇为作者接受稿；没有宣称四篇全文及每个附录均复现。机制是待检验解释，不因为有权威论文就认定本市场有效。

**修正此前盈利研究的门槛说法：** 分析师历史预期并非所有盈利意外版本的必需品。CJL的上述SUE可以用当时已公布的季度盈利历史估计预期；真正需要历史分析师预测的是相应的预测修订/一致预期版本。仍必须防止用后来修订的盈利冒充当时资料；同比增长本身也不等于该SUE。

## 5. 已查到的复现陷阱与处理

- **同名不等于同定义。** 公开`Mom6m`代码实际复合5个滞后月，原固定表格是6个月且不留间隔；其缺收益填零处理也不能默认沿用到我们原始资料。
- **52周高点的窗口与价格基础要一起核。** 读到的v2代码排除当前形成月，对输入价格取绝对值，脚本内未实施拆股调整；上游是否已经调整尚未核实，而元数据写按股份调整。若此前高点100、当前形成价120，含当前时点的接近度为1，排除当前时点可变成1.2。这个例子证明两种定义不同，不能据此认定整份历史发布数据都错。
- **盈利版本不能互换。** 公开`EarningsSurprise`列对应Foster等1984并包含漂移项；本次用户所述价格与盈利互补对应CJL1996，故未拿这一列冒充其复现。
- **残差的估计批次要核实。** 原文每月使用完整36月估计；公开代码拼接各月不同估计所得的末点残差。按本轮对原文的理解，两种构造可能不同；原作者逐步算法和第三方库的末点残差语义还未独立确认，累计方式也未在所读页给出所有计算细节，不能自行补成唯一答案。36行记录不必然是连续36个月。
- **公开回测数字不能反向证明原始数据正确。** 新版本数据、退市补法、样本范围、重叠批次及费用都可能影响结果。参考统计与逐股复现分状态保存，不以结果漂亮替代输入核验。

人工数据21项算术检查通过，覆盖复利、重叠批次、高点窗口、季度差额、公告时间、回归残差、缺月和统计公式；其中盈利波动分母约定只作算例，不擅自补成原文唯一实现。这些检查没有运行四个完整选股因子。独立核算另用不同统计实现检查68项，最大差额约3.6×10⁻¹⁵；不是用同一程序重复报告“通过”。

公开作者链接能取得论文、第三方代码和组合收益，已实际取回；原始CRSP/Compustat资料的权限不会随开源代码自动获得。本次不购买数据、不索取账号、不把仅有当今股票名单的免费行情冒充原数据。不能据限定目录检查断言整台机器永远没有资料。

继续顺序：**普通价格动量作为基准 → 52周高点的额外帮助 → 同池同持有的残差动量 → 合格公告季度数据下的盈利意外**。资料资格可并行核；盈利数据若先合格，可以提前。原市场数据无法到位时，原样复现明确受阻；另一个市场/时期的概念重复必须另列为适配，不悄悄替代本题。

成功标准不是要求抄到小数点相同：须能解释样本/数据版本差异、核若干股票形成与持有全过程、独立复算关键表格，并让未解释差额可定位。复现后再测我们低频选股、持有与风险用途；个人只买不做空的资金安排与原论文买强卖弱要另算。
