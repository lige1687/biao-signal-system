# Agent 因子只读接入：范围决定、实现与主控复核

日期：2026-09-22。状态：本地代码交付，未部署，未作因子有效性判断。

## 一句话结论（大白话）

本轮让 Agent 能读准确因子定义、解释已绑定的研究材料，并在现有资料不足时明确拒绝回答“当前值”；它不会因为一句查询自动取行情、计算因子或启动回测。旧因子面板仍缺少完整来源身份，所以只能作为带日期的历史参考。接入能力的测试通过，不代表因子对投资有效。

## 授权与策略位置

用户在只读核查与方案之后说：“你来定范围吧，我相信你”。据此选定第一批范围：定义说明、已有证据解释、已有观测检查、新实验文本提案。没有生产部署、真实市场计算、预测统计、收益回测或交易授权。

这项工作服务于宽基与 ETF 的研究说明，不增加道路、路牌、A/B/C/D 入场触发或过滤纪律。规则与正式定义仍归原研究线管理。采用研究原则 v1.1、执行合同 v1.0.1、定义标准 v1.1.0；权威文件实际指纹见 [baseline.json](raw/agent-factor-readonly-2026-09-22/baseline.json)。

| 现有研究计算与排序函数 | 保留作为将来由研究线调用的能力 | 本次没有将其暴露给 Agent；没有新建研究平台或计算引擎 |

首次只读核查时，运行中的旧面板生成时间为 `2026-09-04 16:29:58`，未带时区；整体数据日期为 9 月 4 日、研究日期为 8 月 27 日。整体日期也不能代替单只产品的日期。这个事实仅说明当时读到的快照，不代表已经验证了行情输入。

仍缺的是：有完整身份的正式因子观测来源、按因子版本与研究用途绑定的更全面证据索引，以及交易日历和当时可知性说明。接入层不能替研究线补这些证明。

## 第一批如何判断用户问题

1. 先分清查定义、查已有读数、查已有研究、概念比较和提出新实验。因子问题在通用行情分析、模型调用和回测快捷入口之前分流。
2. 标的优先使用本轮明确代码或本地完整名称，其次当前选中，再其次会话最近对象；多个不同对象不自行挑一只。定义编号里的 `mixed`、`trend` 不作为证券代码。
3. “普通动量/12-1动量”采用 `mixed.momentum.raw@1.0.0` 并说明口径。明确版本不匹配时拒绝，不偷换成最新版。高点位置只引用 `candidate:mixed.high52.proximity@draft-2` 草案，不当作正式定义。
4. 指定旧日期的查数请求暂不支持；“昨天”等相对日期、斜杠或中文日期写法也明确拒绝，不自行推算。不会把手上的快照挪到用户所问的日期。没有交易日历时，新鲜程度为未知，不能因为今天是周末就仅凭日期较早判为过期。
5. 数据或材料缺失、版本错误、来源内容变化时，停在本次问题的只读范围内，不回落通用行情查询来“补全答案”。

普通动量的已核定义是比较较早两个有效报价位置的涨幅，并跳过最近 21 条报价；排序是把合格对象按分数排列。它们的计算定义或人工测试不能证明选出来的 ETF 会带来更高收益。

## 三个用户问题与失败返回

| 用户问题 | 第一批实际行为 |
| --- | --- |
| “510300 当前动量如何？” | 核已有逐标的记录，明确“没有合格的当前值来源”；不给旧值冒充当前值，不自动刷新或计算 |
| “这个动量因子过去真的有用吗？” | 解释三份已绑定报告的证据范围：有工程与人工计算核验，没有由这些材料证明真实 ETF 投资有效；不把这句话扩大为全库无证据 |
| “比较一下高点位置与普通动量。” | 解释两者的定义差异与已有提案；明确尚未提供实际效果比较；不新跑研究 |
| “那开始回测吧 / 帮我回测一下” | 沿用因子上下文，仅返回文本提案；不创建研究任务，不启动后台运行 |
| “查某个不存在的版本” | 明确未找到准确版本；不回退至另一版本 |
| “给我旧面板里已有的动量读数” | 仅在记录唯一、日期有效、数值有限时给带日期的历史参考，并说明来源与口径缺口 |
| “当时是否已经知道这个结果？” | 现有资料不能证明历史可知性；不能用文件生成时间或本次读取时间倒推 |
| “按这个直接给买卖信号” | 拒绝把因子描述当交易授权；不改变规则、资格条件或权限 |

首批回答采用固定的、可核对的说明，不调用语言模型推导有效性。未知来源不填零，坏日期不拿整体日期替代，不把风险解释当收益承诺。

## 来源、时间与会话保存

回答材料使用既有 `evidence_card.factor_readonly` 字段保存，原问题快照也保存同一份材料。结构包含请求结果状态、问题类型、准确对象引用、来源和限制；这些请求状态不是因子生命周期。

报告引用保留路径和内容指纹。研究报告可从现有报告库链接打开；正式定义及草案保留真实文件路径，不伪造报告库链接。已有面板的生成时间、逐标的数据截止，以及本次回答组装时间分别标注；缺少的计算时间、历史可知性、价格口径、输入指纹继续明确为未知。

同一请求编号重试，以及答案保存失败后的恢复，都使用原问题保存的材料，不重新读取可能已经变化的面板。当前前端继续显示文字和来源链接；没有新增专用因子图表，也没有修改前端来重新计算判断。

1. 研究线提供具有准确版本、价格口径、输入来源、截止日期和当时可知性说明的正式观测后，再评估是否接入当前值。
2. 扩充证据时，逐项绑定对象、用途、研究区间、比较对象、费用与限制；保留失败或未证明有效的结果。

4. 若要上线，再处理生产采用。此次没有重启服务、提交或部署；当前服务不应因本报告被当作已经更新。

需要用户另作决定的只剩这些范围升级：上线时间、真实实验的具体协议，以及未来是否允许经过资格核验的当前观测。日常实现细节已由主控决定，不再反复索要确认。
