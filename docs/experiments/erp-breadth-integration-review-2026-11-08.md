# ERP与宽度等多指标：现有系统能组合到哪一步

## 一句话结论

**ERP这块已经做成清楚的估值观察，并完成沪深300 ERP×趋势的历史仓位对照；还没有打磨成跨市场通用的多指标择时系统。** 系统里的宽度、趋势、信用、融资、情绪和微观结构数据，成熟度并不一样。可以并列观察“估值、参与面、价格趋势、压力”，但现在没有证据把它们合成总分、四维作战表或自动仓位。

更有用的下一步不是再堆指标，而是先让ERP说明白“为什么变”：盈利收益率变了多少、国债收益率变了多少；再与一个有合格历史的参与面指标做嵌套对照。现存数据对这项组合还不够齐，先保留为观察框架。

## 1. 系统目前已经有什么

| 信息层 | 当前已有 | 当前用途与边界 |

## 2. ERP本身做到了什么

本地“股债收益差”用盈利收益率减名义10年国债收益率，是简化估值代理；它没有把未来分红、盈利增长、回购、权益风险和持有期限完整建模。Damodaran将简单Earnings Yield−Rf视为依赖强假设的代理，并将其与包含现金流和增长假设的隐含股权风险溢价方法区分。[Damodaran方法说明](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/ERP2022Formatted.pdf)

当前A股历史研究锁定的是**沪深300**，不是万得全A或中证800：2008-11-14至2026-11-06，4367个交易日、921个周频ERP观察；研究序列是PE_TTM盈利收益率减中国10年国债，统计参考为三年滚动轨道。历史修订值不能证明每个读数当时已知。

美股序列口径不同：当前历史图用标普500月度盈利收益率对齐日频美国10年名义国债；月度盈利值向后沿用，利率变化可造成日度差值变化。所属月月初不等于实际公布日，历史首发时点未逐期核实。它不是12个月远期PE，也不是TIPS实际利率口径。美联储2025金融稳定报告使用远期盈利收益率与10年实际利率作估值讨论，这是一个机构口径示例，不证明所有机构“只看远期PE”或统一使用该法；它也不能和本地序列直接混成同一信号。[美联储金融稳定报告](https://www.federalreserve.gov/publications/files/financial-stability-report-20250425.pdf)

沪深300最新研究读数截至2026-11-06为5.8319%，三年Z约−0.11、窗口分位约41.6%，不在极端轨道。这个值表示相对本地滚动历史的位置，不表示预期回报或胜率。

## 3. 已有结果：趋势组合有历史增量线索，但没证明同风险更优

下表直接复用[ERP×趋势研究](erp-trend-matrix-2026-11-07.md)，不重跑。范围是沪深300价格指数、周频信号、下一交易日收盘成交、单边5基点、现金不计息且不含股息；当前修订历史。

| 规则 | 净年化 | 最大回撤 | 平均权益仓位 | 调仓/年 |
|---|---:|---:|---:|---:|
| 固定50% | 2.74% | −25.76% | 50.0% | 51.2 |
| 纯计分趋势 | 1.73% | −30.27% | 40.9% | 11.3 |
| ERP＋计分＋连续映射 | 3.56% | −29.86% | 43.4% | 13.5 |
| ERP＋带宽＋连续映射 | 3.80% | −30.90% | 43.8% | 15.3 |

相对纯计分趋势，ERP＋计分连续版年化高1.84个百分点、最大回撤浅0.41个百分点；相对固定50%，年化高0.82个百分点，但最大回撤深4.10个百分点。不是同风险下免费增益。仅等ERP达到+2σ的版本平均权益仓位只有1.5%，不适合当唯一持有开关。2020和2011—2014是明显反例。

宽度研究也没有支持把所有信号拼成“三票共振”：既有ERP—MA200条件对照只保留少量上轨反弹关联，下轨没有可靠顶部信息；美股ERP对已有MA200防守加仓的高低分层差约+0.92个百分点，90%参考范围为−0.80至+2.65，跨零。**ERP＋宽度＋趋势完整嵌套比较尚未完成**，现有结果不能拼接成组合有效性。[ERP—宽度—年线整合复核](breadth-erp-ma200-increment-review-2026-11-02.md)

宽度本身也有用途边界：沪深300成分股B200在相同20日背景下的高低组风险差区间都包含零；2024年方向与全期直觉相反。它可以补充“参与面”，还没有成为稳定的账户风险过滤器。[宽度风险信息复核](breadth-risk-information-findings-2026-09-28.md)

## 4. 对新建议的逐项判断

| 建议 | 复核判断 | 处理意见 |
|---|---|---|
| ERP + B20/B60冰点回升确认底部 | 估值与参与面是不同角度，值得作为观察组合；15–20%、25–30%、30–35%等门槛没有本系统的统一证据。当前宽度序列是B20/B50/B200，B60不是现成历史字段；成员/可得时点边界也限制同日回测。 | 显示ERP位置、宽度水平与方向、指数趋势三者的日期和冲突；不把门槛设成买入确认。合格历史补齐后，优先做一次固定窗口嵌套比较。 |
| ERP低 + 指数创新高 + B60背离预警 | 宽度可能显示权重股和多数个股走势分化；但“立即收紧止盈”属于资金规则，必须检验持有收益、漏涨幅和回撤路径。 | 暂作风险叙述，不直接清仓/止盈。B60与指数MA200均来自价格，可能相关，不能重复计票。 |
| 固定3–5年滚动σ、1.5σ/2σ对应大底/高胜率 | 本地参考是3个自然年滚动，不是统一750个交易日；1.5σ上轨有15个事件，63日相对匹配价格状态高6.64个百分点，时间块探索区间+0.11至+10.73，仍是已看历史且样本有限的线索。2σ上轨7次，2σ下轨10次中6次仍上涨；上下轨不能泛称高胜率和顶部警报。MAD示例还需用正确的同窗中位数算法。 | 作为滚动历史位置保留；阈值、窗口与分位需分开做敏感性，不能说机构“一律”采用或可推导仓位。 |
| 均线计分是零参数；带宽+斜率/连续映射更稳 | MA周期、2.5%带宽、年化±5%斜率、确认天数和映射锚点都是选择。现有比较中带宽日状态切换478次，计分383次；带宽没有自动减少反复。连续插值可减轻阶梯跳变，但锚点和调仓偏离门槛本身仍需检验。 | 计分和带宽均保留作观察/研究定义，不称零魔法参数或天然稳健；不再挑历史最好阈值。 |
| 高ERP + 低换手/低融资比/低实现波动为底部 | 这些读数可能表示不活跃或风险压缩，也可能持续很久，不能推出“下跌空间锁死”。建议的“融资买入额/全A成交额”与系统里已有的“融资余额/流通市值”分母不同，不能互换；这些比例、换手分位和波动阈值未在本系统验证。 | 等当前微观结构链路与历史可得时点验收，再选一个指标测试；不先加三重AND条件。 |
| ERP + 高收益债OAS过滤价值陷阱 | OAS是不同资产的信用补偿，机制上可补充“便宜来自普遍风险压力还是估值变化”的背景；但不能单独识别未来盈利崩塌，500–600bp不是已验证通用切线。FRED说明该OAS是相对国债曲线的信用利差，且自2026年4月起其公开序列仅保留三年，回测前必须核本地历史和许可。[FRED序列说明](https://fred.stlouisfed.org/series/BAMLH0A0HYM2) | 美国市场可保留压力背景观察；不把OAS单点门槛写入ERP仓位表，也不外推到A股。 |
| 低ERP + 低Put/Call + VIX倒挂抓顶部 | 组合含义不统一：低Put/Call通常被解释为乐观，但Cboe说明此解释假设puts看跌/calls看涨，且简单成交量比受行权活动噪声影响；应区分指数、ETF、个股。[Cboe Put/Call说明](https://www.cboe.com/insights/posts/how-early-exercise-order-flow-impacts-equity-option-put-call-ratios) Cboe对VIX期货倒挂的解释则是近端不确定性与短期对冲成本偏高，并指出2010年以来倒挂少于20%的时间；它不是“泡沫顶部”的同义词。[Cboe VIX期限结构说明](https://www.cboe.com/insights/posts/inside-volatility-trading-is-vix-backwardation-necessarily-a-sign-of-a-future-down-market) | 作为不同类型的波动/期权观察，不设顶部组合开关；先确认口径、样本和历史链。 |
| ERP中性时转行业轮动 | 本地没有行业PE/PB/PS/远期PE合格长历史；当前价格相对强弱不等于估值赔率。 | 可以独立做价格动量/宽度排序研究，不能把它称为ERP替代或估值轮动。 |
| `1/PB−Rf`、负PS或动态PE通用Z值 | `1/PB−Rf`不是年度盈利收益率，不能解释成股债收益差；负PB/PS的相对估值也不等于跨标的相同预期回报。此前适配器复核还发现示例MAD用各日不同中心，正确MAD必须在同一窗口围绕同一个中位数计算。详见[估值跨品种复核](valuation-portability-review-2026-11-07.md)。 | 可保留为各自原值/相对历史分位候选；在合格财务历史、披露时点和收益链齐备前，不输出通用odds_z仓位。 |
| +2σ代表战略底、股息率利差P90触发长钱机械配置 | 本地CSI300 2σ上轨只有7个历史事件；2σ下轨10次里6次后市仍上涨。少样本关联不证明“高胜率战略底”。系统也没有合格的沪深300股息率差历史链或机构配置触发证据。 | 轨道只显示相对位置；不把保险/养老金机械配置说法或P90阈值写入信号。 |
| 50% ERP核心仓 + 50%趋势仓 | 这是完整的资金分层规则，不是“解耦后自然更稳”。需要真实可执行的ETF总回报、现金收益、再平衡、成本和风险预算检验。 | 不采用或展示成系统建议。 |
| 用等权SPW排除Mag7看美股ERP | 定义错误：S&P 500等权指数与市值加权指数使用相同成分，仅权重不同，不是剔除Mag7。[S&P 500 Equal Weight官方定义](https://www.spglobal.com/spdji/en/indices/equity/sp-500-equal-weight-index/) | 如要去除Mag7，须另建逐期成分和市值权重都可得的493只篮子，不能将SPW称作剔除Mag7。 |

“机构标准做法”“80%以上视野”“必须某阈值”等说法过于绝对。公开方法能支持某些指标作为估值/风险背景，不足以证明跨机构统一采用上述阈值或仓位矩阵。

## 5. 更合适的组合方式：保留信息层，不做总分

| 观察状态 | 简洁读法 |
|---|---|
| ERP偏高，宽度仍收缩，指数趋势偏弱 | 股票相对滚动估值较低，但参与面和价格趋势尚未确认。 |
| ERP偏高，宽度回升，MA20/60改善 | 估值位置较有利，市场参与开始修复；这是一条观察线索，不是已证明的胜率信号。 |
| ERP中性，宽度扩大，趋势偏强 | 当前行情更多由趋势/参与面描述，ERP没有给出显著折价。 |
| ERP偏低，宽度转弱，信用或波动压力上升 | 估值压力与风险背景同时恶化，可提高风险关注；是否减仓仍未验证。 |

看板可按“估值赔率 / 参与面 / 价格趋势 / 信用与波动背景”四行并列，显示各自**来源、频率、日期、覆盖和状态**。ERP最好分解成：

`股债差变化 = 盈利收益率变化 − 10年国债收益率变化`

因此读者能区分“股价下跌使股票收益率抬高”与“债券收益率下降抬高利差”。再把宽度显示成水平与变化，把趋势保留为价格状态，把OAS/波动仅作为对应市场的风险背景。避免把MA、B200、VIX、融资等压成同一综合分数，也不把估值阈值和交易动作混在颜色里。

## 6. 最值得做的下一项验证

若未来要把这组观察升级为组合研究，优先只验证一项：**ERP对已有趋势规则的增量，加入一个预先定义的宽度变化指标是否进一步改善低频配置的用途。** 固定沪深300、周频决策和同一ETF总回报/现金/费用口径；并列纯趋势、ERP＋趋势、ERP＋趋势＋单一宽度变化三组。先补齐宽度历史成员与决策时点资格，再冻结宽度变量与阈值；完整报告漏掉的大行情、平均暴露、回撤和换手。没有合格历史之前不运行、不用现有跨报告收益拼出结论。

信用利差/期权拥挤是另一支问题，不与上述三组同时加入；等指标来源和历史时间戳合格后再单独评估。否则无法分辨究竟哪种信息带来变化。

## 最小决策卡

- **打磨进度：** 沪深300 ERP观察、三年轨道和ERP×MA仓位对照已较完整；跨市场方法口径、ERP×宽度/信用/拥挤的组合增量及真实账户效果未完成。
- **改善了什么：** 相对只等+2σ，连续仓位研究更贴近参与度；对纯趋势有一定历史增量线索。
- **付出的代价：** 相对固定50%回撤更深；部分样本仅限沪深300价格指数，缺少股息、历史首次发布时间和真实ETF执行链。
- **保留/暂停：** 保留ERP和宽度作为分栏观察；不采用用户示例里的阈值表、顶部清仓、重仓建底或50/50核心卫星仓位。
- **重开条件：** 同口径、点时合格的宽度历史和ETF总回报/费用链就绪后，按固定规则做单一宽度的嵌套增量检验；若要用OAS或期权指标，需另有可复核历史和独立问题。
