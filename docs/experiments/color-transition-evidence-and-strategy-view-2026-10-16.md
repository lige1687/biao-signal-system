# 灰色变黑、变绿：以前测过什么，距离策略还差什么

日期：2026-10-16。本轮核对旧报告、封存分支、策略原文与公开图文，没有新增回测或训练。

## 一句话结论（大白话）

**这个思路可以研究，也更直接对应“变色后价格如何走”。以前确实测过刚转绿、刚转黑，但统计合并了两种来源；没有找到单独“灰→绿、灰→黑”的完整效果与公平对照。我们已有策略框架和部分旧买卖模拟，最新双均线研究仍是局部信息检验，完整LEI策略的资金效果尚未证实。下一步应先补准确的变色事件路径，再评价买卖和账户，不需要等预测模型取得漂亮分数才允许研究策略。**

## 1. 你记得没错：确实做过相近研究

这里的偏差是将大错误给予更高权重后得到的典型误差，不是少赚了多少钱。原报告的日期成段检验范围同时容纳改善与恶化，不能宣称任何用法都无效。

## 2. 这次想法如何测，才不再绕回模型分数

系统当前定义：绿色为收盘同时高于EMA20和20日前收盘；黑色为同时低于二者；其余已具备资料的情况为灰色。相等边界也归灰，缺资料不能当灰。EMA初始化沿被研究的准确版本，不把旧研究种子和生产种子静默混用。

先回答三个具体问题：

1. **灰→绿后，上涨通常有多大、多久出现、途中先跌多少？** 保留上涨、下跌、持平和资料不足，不能只挑后来上涨的例子。
2. **灰→黑后，卖出可能避开多少下跌，又会错过多少反弹？** 固定终点的跌幅和途中最低位置分别报；事后最低点不是能保证成交的卖价或买回价。
3. **多等第二条均线，比一条线先变化，实际改善多少？** 与相同对象、相近已知行情的单线起点比较，记录等候日数、价格变化、始终没有确认的机会。不能仅把转绿组减转黑组就称为额外帮助。

当前灰色可能来自先前绿色，也可能来自先前黑色。应保留“绿→灰→绿”的延续与“黑→灰→绿”的恢复等路径；灰段长度和严格相等情况先描述，再按预先规定的少量分组评价。这样才能判断究竟帮助的是趋势恢复，还是减少反复交易。完整原文还要求多头排列和等待流程；全部变色的描述与符合该前提的结果分开，不能拿前者冒充完整策略。

展示宜以变色日为横轴起点，画之后每天的价格变化、典型中间结果和多数事件的范围，旁边列事件数、上涨比例、平均涨亏以及途中不利波动。先固定主要期限，再把其他期限作为辅助；不能看过结果后挑最好看的期限。多个事件的观察区间重叠，可靠程度要按整段日期及同日市场共同变化估计，不能把每条记录都算独立证据。

信号用收盘资料形成。价格观察可沿旧研究从下一日收盘起，但必须明确这只是参照；买卖模拟应按冻结的下一可成交时刻、费用、停牌与跳空规则执行。同一笔钱不能在重叠事件里重复使用。ETF与个股分别给结果；当前股票名单倒看过去仍有幸存者偏差，未解决前只称有限历史回顾。

本轮只核对上述研究方向与既有证据；这些细分事件没有在本轮新增统计。新检验应作为准确问题登记，不重跑旧周色比较，也不把已看过的历史重新叫作全新验证。

## 3. 抖音图表值得借鉴什么

已通过浏览器打开用户指定作品，实际是SEA的九张图文，页面显示发布时间2026-09-24。已直接看到组合资金曲线及回撤图、月度收益热力图，并读取作者对四策略、相关性和指标的说明。专用读取接口拒绝签名或账号上下文后，改用正常公开网页读取；未登录、未评论或关注。

[指定图文](https://www.douyin.com/note/7688990982465607247)自述年化收益约17%、最大回撤约3%。这些是作者展示结果，本轮没有成交记录、代码、费用和选择历史，不能独立证实。

有三个值得核对的解释问题：

- 收益后来变好，不能排除用整段历史挑选策略或参数。页面列出的2023年12.2%也低于2022年12.6%，不支持文字所称逐年递增；2026只有七个月，和完整年份也应分开标。
- 几种策略的解释不同，不保证未来相关性低。要看同日期真实资金收益、共同持仓、危机阶段是否一起亏，以及扣除成交成本后能否保持。
- 每天恢复相同资金比例可能增加换手和费用，收益不必然优于每周、每月或不调整。图文对信号相关性的计算也明确采用组合层的近似，不能换名当成每只股票因子的标准成绩。

可借鉴的是把“赚多少、亏多深、何时失效、组合是否互补”放在同一套图里；图的外观不能代替这些问题的证据。

## 4. 专业报告如何改成我们看得懂的版本

QuantConnect官方绩效报告展示账户累计变化、逐笔及月年收益、回撤、随时间变化的表现和风险暴露；pyfolio官方示例同时呈现较早开发期、较晚评价期和最差下跌阶段的恢复时间。这些是分析维度的参考，不是对我们策略的背书。[QuantConnect](https://www.quantconnect.com/docs/v2/cloud-platform/backtesting/report)、[pyfolio](https://quantopian.github.io/pyfolio/notebooks/single_stock_example/)。

我们的首屏可以保留以下六块，把技术统计放在展开详情：

| 看哪张图 | 直接回答什么 |
|---|---|
| 同样10万元：策略、单线、买入持有的资金曲线 | 最后多赚还是少赚？闲置现金和费用算进去了吗？ |
| 从曾经最高账户金额跌下来多少、多久才恢复 | 要承受多深和多久的亏损？期末未恢复也显示 |
| 每月、每年的收益表 | 是否只靠少数好月份？不完整年份单列 |
| 每笔盈利与亏损的分布、持有时间 | 胜率不高时，大盈利能否覆盖小亏损？ |
| 持仓比例、交易次数、等待和错过机会 | 低回撤是否主要因为长期没参与？付出了什么代价？ |
| 单条件及组合的同日期比较 | 加一条条件究竟多帮多少？一起用是否只是重复同一信息？ |

对我们这种低频趋势用途，最后一块应首先比较“原规则”和“仅增加这一条件”；若研究多策略组合，再比较每种方法及固定组合、共同亏损阶段和费用。事件价格路径可以现在研究，账户资金曲线必须有完整入场、退出和资金规则后才能画，不能把重叠的事件涨跌简单连乘当账户收益。

## 5. 我们究竟走到哪一步

| 层次 | 当前实际情况 |
|---|---|
| 策略思想与规则框架 | 已有，桌面原文规定道路、结构、触发和退出 |
| 颜色及均线的局部信息研究 | 做过多轮，包括每日状态、首次转色、周色、等待代价与最新个股比较 |
| 严格灰转色的独立结果和对单线增量 | 当前核对未找到完整交付，不能由相近研究代替 |
| 部分旧规则的完整资金模拟 | 做过；研究近似版本有亏损或不如简单基准的结果 |
| 完整LEI策略及这批新股票的资金验证 | 尚未完成，也没有证实稳定交易改善 |

例如[10月13日账户核对](/library?report=docs%2Fexperiments%2Fstrategy-scenarios-attribution-2026-10-13.md)记录六只ETF各10万元，旧日线近似方案35笔完成买卖、4笔扣费盈利；同一批机会原文资格为19笔已知不合、16笔未知、0笔完整确认。因此既不能说我们从未做过策略，也不能把旧近似亏损说成完整原策略已被否定。

之前过多强调“预测误差是否下降”，没有充分回答你的买卖问题。预测涨幅是否准确、减少大亏是否有帮助、完整资金最终是否改善，是不同验收项。我们需要把它们连起来，不要求单个颜色先有漂亮的预测成绩，再允许检验它作为退出或持有条件的作用。

## 最小决策卡

- 当前判断：方向值得做；已有相近变色证据应复用，严格灰色来源仍缺独立结果。
- 现有支持：能准确界定变色事件、保存未来价格路径并比较；不能预设灰转黑一定跌、灰转绿一定涨。
- 研究承接：先准确事件及原策略背景，再买卖决策与同资金基准；新增事件统计与账户模拟在本轮均未执行。
- 原规则与生产：均未修改，无实际交易。
- 本轮完成单位：旧证据核对、图文与专业图表方法辨析、当前阶段说明；不等于有效因子目标完成。
