# 权威研究者怎样发现和验证因子：第一步学习

资料核对日：2026-10-18。用途：学习原始研究方法；本轮未计算新因子表现、未运行新回测。

## 一句话结论（大白话）

值得学习的是研究者怎样把一个金融问题变成可以被推翻的判断，再检验它是否比已有办法多提供帮助。当前先学提出问题、构造指标、反驳和辨认用途；独立低频方案留在后续适配阶段。本报告完成首批方法学习，不代表已经找到适合本系统的有效因子。

用户明确顺序：先看权威研究者和机构如何研究、发掘有金融含义的因子，再因地制宜到系统。原有 LEI 策略问题已经发送给「因子实现」；本对话不接管其完整规则研究。此前候选及资料盘点保留为参考，没有进入市场计算。

## 1. 原始研究给我们的三个具体示范

### Fama 与 French：从估值关系约束候选

2015年五因子论文从已有实证出发，用预期分红的估值关系说明为何研究价格、未来盈利和投资。各项关系有其他条件不变的前提；并非“好公司必然涨”。论文同时披露模型未解释好的股票组合。我们应学习怎样让理论限制候选和方向，并保留失败范围。[出版方原文导言与摘要](https://www.sciencedirect.com/science/article/pii/S0304405X14002323/pdf)

**对发现工作的启发（本库整理）：** 一个可研究的金融含义，要说明谁承担什么风险、哪种预期可能错了，以及为什么当前价格尚未完全反映它。只有“看起来便宜”“经营很好”，还不足以推出之后有额外收益。

### Novy-Marx：改进经济概念的测量，并检查已有因子

作者用“毛利润÷总资产”刻画企业盈利能力，研究它对不同股票后续平均收益的解释，以及与估值信息共同使用的作用。NBER摘要还指出，盈利企业较少陷入财务困境，使某些常见风险解释受到挑战。这示范了从一个经济概念出发，检验更贴近概念的测量及其新增作用。[作者工作论文摘要及2013发表版本索引](https://www.nber.org/papers/w15940)

**本轮阅读边界：** 已核NBER摘要和发表版本信息；作者站PDF未成功读取。没有核完原文的全部分组、财报滞后、行业处理和成本，不能据此复现或采用。

**对我们的启发（本库整理）：** 应追问“这个指标测到了什么”和“已有便宜贵信息之后，它还增加什么”。研究对象是股票间差异，不能把这条摘要直接变成宽基ETF买卖时点。

### Arnott、Harvey 与 Markowitz：主动寻找否定自己的证据

作者用股票代码字母也能筛出漂亮历史成绩的例子，说明漂亮回测不足以证明有效；强调事前经济依据，警惕看到结果以后补故事，并记录尝试过的方法。资料较少时，复杂搜索更容易选中偶然结果。[作者托管稿，PDF第1—6页所读部分](https://people.duke.edu/~charvey/Research/Published_Papers/G138_A_backtesting_protocol.pdf)

**对我们的启发（本库整理）：** AI适合核公式、找原件和反证、保存失败。让AI不断生成指标，再替最好的曲线解释理由，会把同一问题放大。经验观察可以启发假设，但应标为探索；后来用于确认的证据应与发现过程分清。

## 3. 怎样把“有金融含义”写得可以检验

下面是综合上述材料和现行项目规范的学习用提问，不是任何一位作者的原始统一流程，也不替代后续实验合同。

| 要回答的问题 | 合格的回答应包含什么 | 常见不足 |
|---|---|---|
| 为什么可能存在这个现象？ | 风险承担、预期偏差或制度约束；明确尚未证实的解释 | 只说指标看起来合理 |
| 为什么用这个数字测量？ | 公式与经济概念的对应，单位、方向、数据公布时间 | 换名称或周期，却仍表达相同价格信息 |
| 为什么市场没有消除它？ | 实施限制、承担代价或证据不足；可有竞争解释 | 把任何事后故事都当理由 |
| 应在哪些条件下更明显或消失？ | 结果前写出可以反驳机制的条件 | 无论涨跌都能解释 |
| 已经知道其他简单信息后，还多了什么？ | 相同对象、日期、目标下的新增帮助 | 仅展示两组平均差或相关关系 |
| 它能改变什么决定？ | 选对象、控制投入、持有、退出或安排执行 | 只报一个统计分数 |

发现可以来自理论推导，也可以来自可重复的现实观察。两种入口都需要随后说明机制、区分替代解释，并接受反证。“金融含义明确”是值得检验的理由，不是有效性的证明。

## 4. 因子的价值需要按用途评价

这是本库为个人低频投资整理的评价框架，尚未为任何新候选填入效果数字。

| 用途 | 怎样才算提供帮助 | 必须同时计算的代价或对照 |
|---|---|---|
| 增加收益 | 相同投入条件下，扣成本后比简单办法多赚 | 承担了多少额外下跌和集中风险 |
| 识别下跌风险 | 对事先定义的未来损失，判断比历史频率或已有信息更有用 | 漏报、误报，以及是否主要重复已发生的下跌 |
| 改善风险控制 | 加入规则后实际少损失，且代价可见 | 与简单少投入比较；放弃上涨、现金等待及恢复时间 |
| 改善组合 | 加入后共同资金的表现有增量 | 是否仍在同一时候下跌；相关关系是否只在平稳期好看 |
| 降低操作负担 | 效果相近时更少交易、更少人工判断 | 漏掉机会、数据维护、故障恢复与实际耗时 |

风险预测和资金保护需要两层证据：先核信息，再核“据此怎么做”。某个指标能描述高波动，尚不能说明它能预告下跌；减少仓位后少亏，也需要核对少赚的部分。低波动时放大投入还可能需要借款或杠杆，必须另算借款成本和可行性；ETF实施还要区分买卖价差、佣金与适用税费、调仓成本、申赎和成交限制。

适合后续成对精读的是Moreira–Muir的波动管理研究与Cederburg等的实施检验。现有库对两者保留摘要阅读身份；库中所记Cederburg摘要显示，扩展检验并考虑可实施估计后，没有普遍优于原组合。该结论不否定所有风险用途。本次不把重新打开PDF的元数据算作新的全文精读。[现有阅读记录](/Users/yongbiaoli/Desktop/lei-signal-lab/docs/literature-learning/READING.md) · [作者托管反证论文](https://www.lehigh.edu/~xuy219/research/COWY.pdf)

## 5. 后续怎样因地制宜：先做对应，再决定是否实验

| 原论文条件 | 我们必须重新回答的本地问题 |
|---|---|
| 在很多股票之间选强弱 | 只有少量ETF时，是选ETF，还是判断同一ETF不同时间？ |
| 买入一组、同时做空另一组 | 个人只做多时，收益和风险结构还剩多少？ |
| 财报或机构数据 | 历史成分、发布时间和修订能否核实？ |
| 高频观察或大量独立对象 | 月频历史是否只有几十次共同市场经历？ |
| 特征或模型表现 | 是否真的改善一个已定义的买卖、持有或风险决定？ |

这一步只形成适配判断，不自动接入原LEI规则。原有策略的含义仍由两份权威文档定义；独立因子保留独立身份。基本面与消息进入原系统的权限不因论文学习而改变。

每个后续案例用一页方法卡回答：**作者问题与金融机制→实际公式和当时可知资料→原文对照与反例→适合帮助的决定→本地差异与缺口。** 复用现有文献库规范，不另建平台。推荐先把“盈利能力如何测量”读完整，再将“波动管理为何在不同研究中结论不同”作一组成对练习；趋势研究则沿现有相对强弱、时间趋势和行业共同走势条目辨认不同问题。以上是学习顺序，不是待批量运行的策略名单。
