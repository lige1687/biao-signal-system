# 「我的持仓」页面设计（2026-09-04）

## 是什么

把用户养基宝截图里的 29 只基金（合计 ¥85,613.10）录入系统，建成
`/portfolio` 页面：按赛道分组展示持仓，每组附「系统怎么看」结论卡
（已验证回测结论的大白话翻译），并给出组合级提示。回答用户的三个问题：
钱在哪儿 / 每块怎么操作 / 整个组合要注意什么。

## 架构（照 plans 监督员先例：models + store + migration + route + 页面）

- **迁移 020_portfolio**（`storage/sqlite_store.py`）：`portfolio_groups`
  （分组 + 结论）、`portfolio_holdings`（持仓快照，holding_id=名称哈希，
  seed 幂等）、`portfolio_meta`（数据来源/组合提示 KV）。
- **`src/lei_signal/portfolio/`**：models（dataclass）、store（SQLite CRUD，
  UPSERT 且 COALESCE 保留手工回填的 code）、seed（29 只持仓 + 8 组结论 +
  5 条组合提示，全部大白话、遵守 AGENTS.md 说人话红线）。
- **`api/routes/portfolio.py`**：GET /api/portfolio 只读端点；组金额/占比/
  金额加权收益率在 Python 层算好，前端不重复计算（全站口径纪律）。
  分组缺失的残留持仓以「未分组」透出，不静默丢数据。
- **`web/src/pages/PortfolioPage.tsx`**：总览条 + 组合级提示卡 +
  ECharts 环形图（钱在哪儿）+ 分组卡片流（结论卡 + 明细表）。
  收益红涨绿跌与全站一致；QDII/定投/加权收益均带 InfoTip 人话解释。
- **种子脚本 `scripts/seed_portfolio.py`**：幂等，重跑不清 code。

## 边界（红线遵守）

- 结论卡是**叙事标注层**：只翻译已验证结论（美股不择时/独立行业看自身
  趋势/港股未验证区域），不参与任何技术信号判定、不产生买卖指令。
- 与 trade_plans 分工：计划台账记「打算怎么做」（无金额）；本台账记
  「实际拿着什么」（有市值），二者不混。
- 基金代码截图未含 → 留空待补；净值自动更新、季报穿透（拆前十大持仓
  看赛道/美股占比）为后续迭代钩子，本期不做。
