## Task 1：逐指标核对解释合同

输出 `interpretation-review.md`，按“当前定义/实现位置 → 回答什么 → 分母/单位 → 缺失行为 → 不能据此断言什么 → 必修或后续建议”制表。必须涵盖：

- [ ] 真/假/未知状态数量，准备期与评价期区分。未知不算看空。
- [ ] 主目标固定供应商调整价 `P(t+22)/P(t+1)-1`：22个观察格点、21个价格变动区间。不是未来22段收益，不是下单成交收益。
- [ ] 主比较共同合法集合；真假组各自数量、均值、中位数、严格大于0比例；零收益不是上涨，组为空不是收益0。
- [ ] 全资产背景可含未知状态，不能冒充真假组的同一比较集合；不把真组均值直接当作因子贡献。
- [ ] 辅助下行 `min(0,min(P(s)/P(t+1)-1))`，s为t+1..t+22；它是相对起点最差收盘变化，不是最高点到最低点回撤；aux_n与主目标n分别解释。
- [ ] 连续状态段、逐年分组、锚点2019-10-08/间隔23格的稀疏观察：减少重复不等于保证统计独立；真假两组可能处于不同市场时期，差值不是因果贡献。
- [ ] 收益标签成熟截止与快照取得时间分别解释；2026年9月取得的复权快照不得声称在2026年2月已知。当前价格口径未知部分不得借“历史描述”隐去。

## Task 2：四个独立手算例，不研究市场表现

输出 `hand-examples.md`。以下数字只是合成教学资料，不引用项目输出作为期望值；可用标准库小脚本 `check_examples.py` 验算，脚本只读内置常数，不import项目模块，不碰真实数据。

- [ ] 例1：真假组都随市场上涨。真组目标[0.02,0.04]，假组[0.01,0.03]。独立算均值0.03/0.02、差0.01（1个百分点）；两组上涨比例均100%。解释为什么只能描述组间差，不能说因子挣了3%或创造1%收益。
- [ ] 例2：少数赢家。真组[-0.01,-0.01,-0.01,0.15]：均值0.03、中位数-0.01、上涨比例25%。解释报告多个指标的必要性，但不要求删除赢家后仍赚钱，也不据此淘汰趋势规则。
- [ ] 例3：目标重叠。观察序号t=0的目标区间[1,22]，t=1为[2,23]，共同价格格点2..22共21个；t=23区间[24,45]与第一窗无交集，但无交集不证明独立。日期相邻信号不能算许多次独立成功。
- [ ] 例4：分母不一致。真组主目标[0.02,0.04]且辅助目标[-0.03,None]；假组主目标[0.01]；未知状态目标[0.50]。主比较n=3，真n=2/假n=1，背景n=4，真aux_n=1；主比较加权均值=0.07/3，背景均值=0.57/4。解释为何不能混比分母或把缺失辅助值填0。

若认为给定算术有误，先列原期望与独立计算，不静默改题。普通小数采用绝对容差1e-12，不据此新增生产容差合同。
