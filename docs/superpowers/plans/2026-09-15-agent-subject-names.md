# Agent 对象识别、名称展示与主分支收口

用户已授权直接修改并合入主分支。服务于对象识别和解释展示层，交易规格、规则数值、MACD强度口径、板块只观察的边界不变。

1. 用既有目录和本地板块快照识别名称，不为查名字拉行情。代码明确优先；通信板块/版块匹配通信一级板块；通信设备板块匹配子板块；通信ETF仍是ETF。板块无资料如实降级，不取ETF替代。
2. 板块回答使用板块快照的阶段、相对强弱、成分股站上均线比例（宽度）及日期，不把合成指数当可交易产品，不提供买卖计划。只选择既有字段，不引入旧快照附带的未经本轮验证的历史胜率文案。
3. 统一准备与解析接口，资料就绪卡、依据卡、正文的对象提示以及历史展示使用中文名称+代码；未知名称显示名称待核实，不凭空命名。
4. 固定测试含ETF代码、ETF名称、板块/版块、子板块、已选ETF改问板块、缓存缺失与历史显示。隔离回归后应用运行并重启验证只读接口。
5. 按此前49/33文件合入清单及必要依赖收集已验收Agent代码；检查main工作区，保全并行修改，在干净主分支树合入、验证。不得把因子未验收内容一并提交，不盲目git add全部，不覆盖脏工作区。
