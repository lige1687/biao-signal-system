# 系统待升级项目实现计划

目标：交付两类目标、持久进展、证据与逐项授权管理，并录入本次讨论。

策略位置：交易规格 §15—§16 的研究验证管理，以及用户本次批准的候选模块扩展记录；不产生交易规则。已读规格、规则账本、MACD 口径和板块方案。用户明确授权建设页面和登记目标；后续研究推进另行按条目授权。

采用现有 React、React Query、FastAPI、SQLite。沿用蓝灰白和苹方字体。左侧为可搜索的连续目标列表，右侧为目标详情、完成标准、证据与更新记录；窄屏上下排列。两类目标各有筛选，待授权可单独查看。与纯静态文档相比，服务端台账可跨浏览器编辑；与自动任务系统相比，本期只记录，不调度执行。
