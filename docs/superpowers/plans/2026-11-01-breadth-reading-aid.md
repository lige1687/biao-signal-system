# 市场宽度阅读辅助实施计划

2026-11-01；用户已授权实施。限已有 CN_ALL_A/SP500 宽度与价格投影；股债利差复用其在途任务，不占用另一 owner 的代码路径。

## 目标

保留价格/宽度同步日期轴，增加单周期历史 10/50/90 分位轨道、固定经验参考切换和后端提供的参与变化描述。提供明确回看日期与三个周期数值。轨道代表历史分布，不代表置信区间或买卖点；没有 100 日数据，不生成替代数据。

## 实施与验收

1. Python 纯模块计算过去至当日的有效记录窗口（1260，最少252）、五条记录变化、位置/越轨事件与短长周期参与状态。可选 API 字段保持旧 history 完全不变。合成边界、前缀不变与 API 保持测试。
2. React 只显示后端判读。默认50日，可切20/200日或三线；轨道分为历史、固定、关闭。日期回看控件与图表游标联动，缺失保持空白。既有条件色带折叠保留。
3. TypeScript/Vite构建、既有投影关联测试、Python定向测试；真实接口+桌面/390px页面验证。检查陈旧日期、无覆盖、轨道预热不足、CN/US切换和回看。保存截图与结果。
4. 仅更新本任务协调记录与进度文档，不合并/发布共享脏工作区，不写他人的 ERP 路径。

## 基准与边界

基准为当前三线+固定数值筛选。验收改进是更可读且可追溯，不宣称预测效果提升；沿用既有数据源及股票池限制。资料探索见前轮 research-notes 报告。本轮不运行金融效果回测，不更改交易规则。
