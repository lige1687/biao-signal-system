# 经典因子到底给我们的研究增加什么（2026-10-02）

这份笔记帮助你和后续AI选择比较对手、理解收益来源。它采用已有定义和资料；实际结果见[本轮报告](../experiments/classic-factor-increment-2026-10-02.md)。是否值得交易，要有另一份包含买卖、费用和完整资金的证据。

## 先问用途，再选经典因子

| 想回答的问题 | 可以拿来用的东西 | 能增加的价值 | 目前不能据此说什么 |
|---|---|---|---|
| 新技术条件是否只是把价格信息换了个说法 | 单SMA、单EMA、过去20日涨幅、20日每日涨幅的波动 | 给复杂条件一个简单且明确的对手，减少重复研究 | 名字经典不代表在我们的ETF上能预测涨跌 |
| 在原有信息之外，多加一项是否有帮助 | 相同日期的原模型和加入后的模型，以及更简单参照 | 找出真正多出来的帮助，或发现复杂度没有带来改善 | 两个模型误差不同不等于资金多赚同样比例 |
| ETF涨跌是否和市场、大小公司或价值/成长偏好有关 | 中国月频CH3；美股问题另匹配美股FF5等 | 解释多只产品为何一起涨跌，提醒我们别把风格暴露当成技术能力 | 当月已经发生的因子收益不能当作月初就知道的预测信息 |
| 从哪里学习规范的实验过程 | 华泰分类/分布/单项/组合研究，JKP与OSAP的定义资料 | 形成可核查的定义、简单对照、时点和失败记录 | 阅读/登记来源不等于实现所有公式或复现作者结果 |

## 有些经典名称已经在系统里

过去20日涨幅的公式是 `C[t]/C[t-20]-1`。当价格为正时，它大于0，与同周期SMA当日比昨日上升的方向一致：`SMA20[t]-SMA20[t-1]=(C[t]-C[t-20])/20`。因此，把“20日涨幅为正”再加到同周期SMA方向上，不增加新的方向事实。涨了多少仍是另一种表达；是否帮助某个预测模型，要做比较才能回答。

旧试点的S不是所有SMA含义的总称，而是同时要求价格站上SMA、且高于20日前价格；E是旧EMA确认状态。旧试点只能代表这两个状态。完整LEI还包含更长均线、结构、空间和量价条件，不能用一个旧双20结果替整个体系作判断。

波动的名字尤其容易混淆。本库 `etf.reference.volatility20@1.0.0` 使用20个简单日涨幅的样本标准差，不做年化。T03的相应输入只是把它乘100换成百分数；已经知道它时，再加同一数列不会增加信息。另一些研究使用对数变化、不同分母或年化，须按实际公式核对。ATR看的是价格区间，不能只因为也描述起伏就当作同一个东西。

## 怎样学这次实验

页面新增两条真实案例：**复杂模型也要接受简单参照**、**解释得更好，不等于提前知道**。第一条提醒我们，原双20预测的典型误差9.3791个百分点，加入涨幅与波动后9.4643，都不如固定0涨幅的9.0300。第二条说明，CH3同期解释误差平方减少21.21%，约85%的净改善来自科创50，上证50与中证500反而变差；这没有证明能提前预测或多赚。

先读报告的性能表：简单参照、已有信息、加入经典信息，谁的误差更小。再读增量表：相同对象和日期上究竟改善了多少，以及允许的改善和恶化范围。最后看反例：是否只有某只ETF或某一年好；总体改善会不会被少数月份支配。

本轮有两个独立用途。旧预测追加汇总不重新训练，只看过去涨幅和波动**一起加入**旧双20模型后的变化。CH3检验则先用2022—2023确定关系，再用2024—2026上半年已经实现的市场、规模和价值收益解释同月ETF经济指数变化。后者能帮助事后理解结果，不能回答下个月该买哪只ETF。

CH3中的“规模”是小公司组合相对大公司组合的收益差；“价值”是按盈利与价格关系区分的组合收益差。本轮直接读取已公布的月序列，不重新构建股票组合，也不给ETF打财务分。作者的股票构造、原始年代与我们的ETF并不完全相同，尤其科创50必须单列说明。

## 下一位AI的使用卡

1. 从 `docs/research/current-standards.json` 读取当前规范；从 `definitions.v1.json` 解析准确ID和版本。
2. 将任务写成“什么资产、什么日期、当时已经知道B、再加X、想判断Y”。先判断X是否已包含在B中。月频官方收益只允许事后解释，不能扩成日频或回填历史可得时间。
3. 国内ETF日线简单对照用既有 `select_baselines`；它返回匹配项及排除原因。不要把其结果理解成推荐交易清单。
4. 新技术信息检验沿 `--workflow-draft` → `--workflow-contract`。本轮独立的 `--attribution-protocol` 只服务同期收益解释，不能替代技术研究检查，也没有生产用途。
5. 先读本轮报告、冻结协议和所有尝试。已有同一问题不重复跑；旧资料、重新拟合、换文件名都不产生独立新证据。
6. 仅当明确的未回答问题、合格资料及授权都在时安排下一项检验。财务公告/修订时间缺失时，EP/BP/ROE保持资料不足；AQR、公式库和外部目录未接通时如实标记。

自测：三因子对同期ETF涨跌解释更好，能否在每月初用三因子选择ETF？不能。解释时使用了当月完整结果，月初尚未知；要用于提前判断，需要另定义当时可知的输入并检验。
