# 从退出研究学到的三条实验纪律

日期：2026-09-08。每条沿用已有文献ID，可供后续学习页面接入。原文、作者和已读范围见[学习目录](READING.md)。这里记录本地实践，不新增论文原文结论，也不把本文经验称为投资定律。

## brock1992：同一份钱，才能看出新规则多做了什么

**文献索引：** `brock1992`。方法用途：建立简单参照；本条是本地借鉴，不是该论文的直接复现。

**值得学的测试方法：** 新规则只改一件事时，先用同样的投入金额比较。若新规则也改变了投入数量，再单列第二张表，说明减少了多少参与。

**我们的例子：** C类破底翻使用半个ATR缓冲后，没有任何退出时间或原因变化。按相同资金投入，其结果完全不变；按相同计划风险投入，结果与期间损失都变小，因为买得更少。把后一结果称为“卖点更准”，就误认了原因。

**可借鉴的验收要求：** 必须同时提供原机会身份、投入金额、未用现金、退出时间和费用；缺其中之一，不认定增量来自退出规则。

**不能据此推导：** 越简单的策略必定更赚钱，或者复杂规则都无用。

**自测：** 如果新方案亏损更少，但投入金额从50%降到30%，能直接说风控判断更准吗？答：不能，先和同样只投30%的简单对照比较。

**本地证据：** [ATR研究](../experiments/atr-buffer-opportunity-study-2026-09-08.md)，尤其C模块的两种资金视角。

## sullivan1999：保留全部尝试，先保证每笔只算一次

**文献索引：** `sullivan1999`。方法用途：防止从大量尝试里只挑漂亮结果。逐笔计数检查是我们为这个目标加的基础检查，不能冒充论文作者的原始检验方法。

**值得学的实验方法：** 运行前固定比较范围；每个候选对每个原机会保留一个对应结果，包括没交易、仍持有和失败。重复用同一行情的比较不能算作多次独立验证。

**我们的例子：** 899个机会在旧15日方案中变成905个数字，多出的6个是同笔交易被算两次。修正后，原来明显负面的均值变化变成接近零；这还不足以证明方案有价值。两项错误不影响另四项没有重复计数的原结果。

**可借鉴的验收要求：** 报告均值的记录与计算误差范围的记录必须是同一集合；检查唯一身份、条数、排除原因和全部已试候选。不能只检查最终汇总数字能重复跑出来。

**不能据此推导：** 找到程序错误后，修正结果就自动具有统计说服力；同一次市场行情的交易仍可能共同涨跌。

**自测：** 重跑两次数字一致就表示研究正确吗？答：不表示，同一个错误也可以稳定复现，需要独立算法和逐条检查。

**本地证据：** [退出基准核验](../experiments/exit-baseline-full-audit-2026-09-08.md)，5394条独立对照记录。

## cederburg2020：风险数字变好，还要问收益和实施代价

**文献索引：** `cederburg2020`。方法用途：考察风险调整在实施和不同条件下的实际作用。本地结构缓冲与论文研究策略不同，不移植其收益结果。

**值得学的评价方法：** 同时报告风险减少、收益变化、投入比例、现金等待和费用。对降低风险但降低收益的办法，不替用户决定是否值得。

**我们的例子：** A类按相同计划风险投入，平均投入比例由53.96%降至37.18%；平均结果由+0.803%降至+0.641%，持有期最低预算值也改善。这些是独立机会预算的平均，不是年化或一个账户的收益。改变了权衡，不能只选最好看的指标。

**可借鉴的验收要求：** 费用要对应真实产品、真实股数与成交金额；若只有假设费率，要清楚写成情景。目标失效距离更远时重算入场纪律，不偷用原来的盈利/亏损比例。

**不能据此推导：** 本例的比例适合用户真实资金，或风险减少一定值得放弃相应收益。

**自测：** 一个方案最大亏损小了，但大部分时间不投入，算不算无条件改进？答：不算，需要看错过收益、资金用途和用户愿意承担的取舍。

**本地证据：** [ATR研究](../experiments/atr-buffer-opportunity-study-2026-09-08.md)与[费用边界](../experiments/exit-baseline-full-audit-2026-09-08.md)。
