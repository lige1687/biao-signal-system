# 昨天发布的判断，不能被明天的数据悄悄改掉

日期：2026-09-08。

文献索引：`sullivan1999`，归在“实验方法”。沿用既有阅读版本及范围，本批没有新增论文全文阅读。

论文比较思想的本地延伸：先固定范围并保留全部试验，才能知道结果是否来自选择性展示。以下具体检查来自本系统“不使用未来信息”的要求与本地工程验证，不是论文作者为本系统设计的测试，也不是作者提供的数字门槛。

1. **给程序增加明天的数据，昨天已经发布的判断不应消失。** 后来可以出现新的失效事件，但必须保留当时的判断及其可知日期。我们的真实基金检查找到了两个旧日期被改写的例子。
2. **比较截止日以前的完整记录。** 只看截止当天可能漏掉更早的记录被改写；同时比较身份、日期、价格、来源和失败原因。
3. **小例子负责找漏洞，真实历史负责核实实际发生。** 人工指定均线的例子能证明函数存在问题路径，不能证明市场频率。两类证据应分别写清。
4. **已有测试通过，不等于研究输入可靠。** 本批原30项测试通过，新的针对性检查仍找到问题；需要先确认测试究竟检查了什么。
5. **验证失败不等于策略亏钱。** 它意味着当前计算过程不足以支持盈利判断，下一步应修复和复测，而非立即宣布采用或淘汰策略。

验收建议属于本库整理：固定检查日期，公开所有差异，保存失败输入及源文件版本，修复后同时重跑旧问题与原定全套检查。不删除失败例来换取“通过”。
