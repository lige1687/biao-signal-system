# 论文方法学习：买点的历史表现必须带着卖法一起看

日期：2026-09-09。文献索引 `kaminski2014`，Zotero既有条目 `AFXWZZZE`。沿用已读章节，没有新增全文阅读或重新导入文献。

## 1. 同一个买点，没有唯一的胜率

冲着收复支撑买入，可以在原结构破坏时止损，也可以达到事先目标后退出，或者在方向转黑时提前退出。买点一样，最终赚钱次数、每次赚亏和持有时间都可能不同。查询历史时应写明完整买卖办法，不能拿一种卖法的胜率来评价另一种卖法。

论文§3.1把退出、卖后资产和重新进入一起定义。我们在本次组合研究中借用这个问题框架：在同一种卖法内比较入场条件；再固定原机会比较两种卖法，同时另看资金能否继续参与后面的机会。四个重叠条件组和两份费用结果不是八倍独立证据。

## 2. 过去的胜率，只能使用当时已经结束的结果

假设三月买入的一笔交易七月才卖出，五月作决定时，不能把七月赚了多少放进“此前胜率”。没有结束的交易应明确列出来，而不是算作赢、算作输或直接忽略。

这还会带来另一种偏差：卖得快的方法更早留下结果，拿得久的方法暂时没有结果。为公平对照，本批另看买入后已完整走过60根日线的同一批机会：已经卖出的记实际结果，没卖出的记当日持有价值，并明确仍然可能变化。这个观察长度、至少30次的保守展示要求和具体时间检查是我们的本地研究设计，**不是论文给定的参数，也不能保证统计可靠**。
