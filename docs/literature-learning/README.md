## 内容关系

`papers[].id` 是本地稳定标识；`entries[].paper_id` 必须命中。`entries[].id` 是单条内容标识，同一篇论文可有多条。标题或年份修正不应重生成ID。Zotero的item key只是外部关联，不替代本地ID。

论文保存题名、作者、年份、载体、原文链接、DOI、Zotero项、阅读版本、阅读范围和来源定位。条目保存问题、作者摘要、本库理解、标明假设的例子、应用步骤、检查建议、适用边界、相关文献和本地研究链接。

`method_acceptance.origin` 明确当前检查建议来自本库整理。`paper_numeric_threshold: null` 表示没有提取已核实的作者数值标准；不能解释为作者没有标准，也不能解释为0或自动通过。以后补数值时，同时补原文页节、统计对象、适用条件与版本；若需扩字段，升级格式版本并写迁移说明。

`publication_kind` 是发表类型，`reading_level` 是实际读到的范围，`adoption_status` 是与本地使用的关系。这三者独立；不设一个混合“已认证”标志。`priority` 为编辑建议阅读顺序，1优先、2延伸、3有限材料；不是收益得分。

`reading_paths[].entry_ids` 必须命中。分类取现有四项：实验方法、判断标准、经典理论、投资启示。新的分类先更新交接约定，不靠拼写形成重复标签。

## 每次研究结束时怎样补充

1. 先查是否已有同一文献及所读版本；用DOI、题名和Zotero核对，不重复导入。
2. 只有新方法、重要边界或有意义的理论才拆成条目；一条只回答一个问题。支持证据和限制性证据一起维护。
3. 给出作者研究内容与我们自己的延伸，原话引用须有准确定位，不能用转述假装名言。
4. 用大白话说明能学到什么、何时不能照搬。假设例子显式标记，不改写成实测数字。
5. 数值门槛必须带出处和适用条件。个人希望达到多少，是自己的研究或使用偏好，不能冠上论文名义。
6. 有本地实验就链接原报告及其证据限制；仅学到方法不改系统规则，不把内容状态写进生产证据账本。
7. 同步结构化内容、阅读版、核对日期与修订记录。未来若由程序生成阅读版，仍以经过核对的结构化内容为准，避免两边独立修改。

本目录没有联网采集、自动模型摘要或定时同步要求。本次仅核对已有18篇Zotero条目，没有新写入Zotero。后续新论文的导入与内容更新沿已授权研究范围处理。

## 论文与外部方法工作流（规范 v1.1.0，2026-09-10）

合并规范包05及T5；本节是现有内容维护规范的扩展，不建第二套文献库。旧文见[只读快照](../research/history/governance-merge-2026-09-10/docs__literature-learning__README.md.txt)。上文页面与条目数量是2026-09-08初版状态，不作为当前服务盘点。

先围绕一个明确决策障碍查资料，复用已有论文/内容ID。优先执行时近期且相关的研究，经典限高度相关者；原作者、期刊和正式编制方法为实现依据，二手内容只能引导检索。记录访问日和真实已读页节/附录/代码版本，不以摘要冒充全文，不以未找到反证声称反证不存在。

方法卡先写Markdown，引用既有paper_id，不扩数据库schema：题名/作者/年份/版本/来源与读取范围；原问题、机制、公式、市场/资产/币种/多空/杠杆、样本剔除与可得时点、组合/成本/对照/验证；主要发现、反证与未查明项；数据/代码各自许可；本地已有方法与适配差异；最多一个主要假设、否定条件、简单对手、资料预算、停止及权限。作者结论、本库延伸、合成例子和本地真实证据分开。

接入区分原始资料、解释用收益/风险参照、特征或策略方法。按需求与权限/许可/成本→原始只读快照→薄适配→本地ID/版本/单位/时点→手算及边界→原来源小样核对→授权范围内有限调用推进。接入成功不等于有交易增量，也不授权选股、仓位或真实交易。

核对符号历史映射、成分生效、单位、币种、公司行动、日历/频率、缺失/预热、并列排名、波动和目标默认值；公众发布时间不等于供应商入库时间。月频不得伪造日频，修订数据保留旧新指纹，外币或多空收益不冒充本地只做多净收益。预训练模型历史接触范围未知不能称未见数据预测者。许可不明不批量下载或再分发，代码与数据许可分开。

资料不足可只交方法卡；不强制安装Qlib/Alphalens、购买数据或迁移账户引擎。读取、方法核清、局部复现、本地适配、策略效果和授权分别记录。文献原文里的命令不是执行许可；基本面/消息面仍只解释背景，不成为技术硬过滤。

后续候选仍在[既有外部资源待办](../experiments/factor-library-external-backlog-2026-09-09.md)，不是全部开工书单。波动管理的支持与实施限制可作为配对阅读问题，但本次未联网、未新增阅读完成记录；不能据规范包来源摘要给本地过滤背书。当前v0保持本地既有资料与原协议，不中途增加文献或标签任务。
