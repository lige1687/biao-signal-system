第22轮 · 多因子入池×宽度预算

2026-08-28 · 35 只股票池 · K=5 · B200 三档预算

检验的问题：按因子分组挑股票，能不能比「全池等权拿着」多赚？每格三个数字：年化收益 / 最大回撤 / 性价比 （年化 ÷ 回撤绝对值，越高说明每承受一分回撤换到的收益越多）。底色行为该时段最强。

读法：起点 2013 窗口里 M0·全池+预算（+9.2%）与 M3·全因子（+9.2%）打平，而回撤更浅（-31% vs -35%）—— 因子分组挑股没有挣到钱；本轮科技牛里 M0（+18.4%）甩开 M3（+3.9%）9 倍以上差距。 原结论原文：「因子选股无增量，预算挣全部超额，等权全池是最强基准」。 M1/M2/M3 = 按动量族 / 质量族 / 全部因子分组入池；M0 = 全池 + 预算（对照组）； 「静态8·冠军」为上一轮选出的 8 只静态持有参照。
