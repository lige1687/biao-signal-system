# 情绪指标实战检验报告（美股 AAII/NAAIM + A股两融/北向）

日期：2026-09-03
性质：research_proxy 研究回测，不构成投资建议。脚本与数据：`/tmp/sent_bt/`（`common.py` 美股对齐框架、`a_panel.py` A股对齐框架 + `run_A_conditional.py` / `run_A2.py` / `run_A3.py` / `run_B_strategy.py` / `run_C_breadth.py` / `run_C2.py` / `run_C3.py` / `run_a_tests.py`）。跨市场结论速览见文末「D. 美股 vs A股对照」。

## 数据与防前视纪律（美股）

- **AAII 散户情绪**：官方全历史 xls（www.aaii.com/files/surveys/sentiment.xls），1987-07 → 2026-08-27 周频（Bullish/Neutral/Bearish 占比）。发布时间：周四盘前。1993 年前 SPY 未上市，SPY 面板实际起点 1993-01。
- **NAAIM 机构敞口**：MacroMicro 图表数据（源 NAAIM，1047 周），2006-07 → 2026-07-29 周频。周三调查 → 周四发布，对齐时 +1 天。
- **美股宽度**：S&P 500 成分股高于 200 日线占比（S&P Dow Jones Indices，经 MacroMicro），2000-01 → 2026-08-28 日频。
- **行情**：Yahoo（yfinance + v8 chart API 复权价），4 宽指 ETF + 11 板块 ETF + 14 代表个股。
- **对齐规则**：信号在 info_date（发布日）可见 → 执行价 = 发布日后首个收盘（AAII 周四发布 → 周五收盘执行，NAAIM 同理）。锚点滞后 >7 天（未上市）即丢弃。前向收益按日历目标日取价。滚动分位只用历史（与 `classify_sentiment_percentile` 口径一致，3 年窗 / 最少 52 期）。成本：ETF 单边 0.1%、个股 0.2%；现金 1.5%/年。
- 修 bug 记录：初版把 SPY 上市前的 AAII 行错误锚定到上市首日（同段收益重复计入），已全部重跑；本文全部数字为修正版。

## 一句话总结

**两个情绪指标单独做择时规则都不值钱（全部跑输买入持有）；AAII 的价值在「标注」——散户极端贪婪是可靠的 1 年级别逆风（20 资产 18 个负超额）；唯一值得进交易层的发现是「宽度洗盘 + 散户恐慌」双重见底：11 次独立事件、26 周中位 +15.6%，但 2008-10 证明它会接飞刀。**

## 实操指引（按资产类别）

1. **宽指（SPY/QQQ/DIA）**：情绪做仓位标注不做切换。AAII 净多分位 ≥90 → 未来一年预期收益下调 2~10pp，持仓不动、**别加仓、别上杠杆**；分位 ≤10 → 逢跌分批加。NAAIM ≤20 且继续阴跌 → 保留现金耐心（13w 均值还是负的）。
2. **板块/个股 ETF**：散户极端贪婪对高贝塔板块（XLK/QQQ）是更强的 1 年逆风（-10pp 级），对 XOM/KO 这类防御基本无效——**情绪逆风只对成长/高波资产做降仓标注**。
3. **个股**：建仓时机用「双重见底」（宽度≤20 + AAII 恐慌分位≤25）：历史上此后 26 周中位 +15.6%、95% 资产有超额；但要接受 2008-10 型失败（-22.5%），所以**分批进**（事件内每周触发都可以是加仓点，级联危机里后面的触发点更接近真底）。
4. **永远不要**因为「散户太贪了」而做空/清仓——40 年数据里这个方向的规则全部亏损。

# A股部分：有没有类似的机构/散户情绪指标？

日期：2026-09-03（同日追加）。核心问题的回答：**A股没有 AAII/NAAIM 式的调查类指标，但有两类真实行为数据可充任，而且行为数据比调查更硬**——散户/激进资金用**两融**（融资余额变化，日频 2010 起），机构/外资用**北向净买入**（日频 2014-11→2024-08，披露已终止）。公募/私募仓位估算、月度新开户数存在但月频滞后或第三方口径不可得，未纳入（大盘主力资金流只有 120 天历史，弃用）。

## A.1 数据与口径

- **两融**：东财 datacenter（`RPTA_RZRQ_LSHJ`，沪深北合计），2010-03 → 2026-09-02 日频。信号 = 融资余额 20 日变化率的 3 年滚动分位（T 日数据 T+1 盘前披露 → 面板用 ≤T-1 值）。
- **北向**：东财（`RPT_MUTUAL_DEAL_HISTORY` 沪股通+深股通合计），2014-11-17 → **2024-08-16**（此后仅披露成交额；面板在终止后置空，不做「冻结值」信号）。信号 = 20 日净流入合计的 3 年滚动分位。
- **A股宽度**：全 A（5211 只）高于 200 日线占比，由实验室缓存 `~/.lei_signal_lab/cache/a_share_klines_full.parquet`（8714 交易日 × 5211 只）自算，1991-10 → 2026-08-27。与美股 S&P500 宽度同口径。
- **锚点**：510300（2012-05 起，策略与条件收益主资产）、510500/159915（跨标的复制）。周五收盘出信号（两融/北向用周四及以前数据），**下周一收盘执行**，前向收益按日历目标日取价，成本单边 0.1%，现金 1.5%/年——与美股部分同纪律。
- 校验：510300 锚链 B&H 年化 5.82%（14.3 年），与真实一致。

## E.5 A股操作指引手册（汇总）

**触发定义**（周五收盘可算，数据 T+1 盘前披露后自动可得）：
- 主触发：融资余额 20 日变化率 ≤ 其 3 年滚动分布的 10 分位（即去杠杆速度进入历史最快的一成）；
- 确认项（可选，用于条件判断不做闸门）：全A 宽度 ≤20%、价格在年线下方、北向同步流出——出现越多，52w 胜率越高（92%）；但深回撤 ≥20% 是反向确认（短期还会跌）。

**触发后动作**：
1. **买什么**：宽基选小盘成长（中证500/1000、创业板）；行业选高贝塔发动机（证券/军工/超跌半导体与科创）；**明确避开煤炭/银行等红利防御**。
2. **怎么买**：分 2-3 批（事件簇内每 4 周一批，级联危机里后面的触发更接近真底；2015/2018 型深回撤背景必须等宽度 <10% 再上重仓）。
3. **持多久**：宽基 39-52 周，行业 39 周；持有期内不理会两融回升（亢奋端是动量语义，拿着）。
4. **退出**：不用情绪退出（卖出方向全部证伪）；交给既有均线/结构体系（环境层管买多少，技术层管何时卖——与体系分工一致）。
5. **仓位形态**：以「基础仓位+触发加满」overlay 接入（30-50% 基础），不要全仓 episodic 赌触发。

**永不做**：见两融亢奋就清仓（动量语义，26w +9.8%）；用宽度 ≤25 做空仓开关（年化 1.1%）；北向大幅流入当利好追（13w -2.0%）。
