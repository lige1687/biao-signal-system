# 动态导演与避免模板疲劳

适用：从文稿设计分镜、用户反馈“像PPT”，以及小样扩展长片。用户2026-10-09明确喜欢强动态、拒绝整片统一模板。下面是制作约定，不是已经验证的质量提升。

## 先确定哪些统一，哪些变化

字体、色彩含义、材质、线条和角色身份保持一致。构图、景别、主体占比、镜头方向与节奏随解释目的变化。一个贯穿主体可以不断获得新作用，不必每章清空重来；也不强迫所有镜头都变形连接。视觉相似不能暗示不存在的历史师承。

先用[镜头表](storyboard-template.md)写全片节奏图。人物情境、史料近景、关系展开、并排比较、时间穿行、结论留白只是可选表达，按内容选择；不按固定间隔轮换，不规定每片必须用满。固定中心构图可用于一个有意强调的片段，不能作为默认答案覆盖整片。

## 先做导演编排，再制作（用户确认）

理解整篇文案的主线、问题、推进和结论，按完整语义拆成具体镜头，不按标点或固定时长切。对每段先决定“观众此时需要看什么、为什么”，再选择A-roll/B-roll及具体表现；编排结果必须写入[视觉编排表](storyboard-template.md)，不能只口头说采用导演视角。

每镜保留对应文稿段ID与具体原文，写明A/B角色及理由、开始/结束/持续时间、构图与景别、动作阶段、最后落定画面、从上一镜怎样进入及怎样进入下一镜，以及所需素材和声音事件。A/B是本片的叙事角色，必要时注明混合或主叙事图形，不为分类硬加人物。每个时间都标依据：有旁白按实际录音对齐，无旁白按阅读和动作先估算，再用实际小样校准；草案估时不可写成实测。

先核全片信息推进、重复构图、缺素材与难实现镜头，再据表准备素材、从真实工程出静帧、制作中间难点15秒。沿用用户现有确认节点，不新增逐镜审批；表中有影响内容的未决取舍才集中询问。改文稿或实际声音时同步受影响镜头和总时间。视觉编排表是制作依据，不是成片完成凭据。

## 把A-roll / B-roll用于叙事分工

A-roll通常是承担主叙事的画面，B-roll是支持它的补充镜头，不能简单等同于“人物”和“动画”。定义参照[Adobe A-roll说明](https://www.adobe.com/creativecloud/video/discover/a-roll.html)。xilo把人物小剧场与知识图形作为自己的两类表达，这是创作者的具体用法，不是所有视频的固定分类。

本项目借用其思路，分镜先填“叙事职责”，再填素材形式：

| 叙事职责 | 解决什么 | 可选画面与视角 | 避免的问题 |
|---|---|---|---|
| 情境/问题 | 为什么讲、当时面对什么问题 | 环境远景、物件特写、人物行动、第一人称观察；按需使用史料或标明的概念还原 | 无关小人站中间、虚构历史人物台词、每章重复同一小剧场 |
| 证据/背景 | 依据在哪里、时代与对象是什么 | 核实的书页、报纸、照片、时间地点和必要局部放大 | 照片只作装饰；现代画面冒充历史；长篇密字无人能读 |
| 解释/比较 | 关系怎样变化、区别是什么 | 连续变形、关系拆解、并排对照、沿时间展开、细节到整体 | 万能卡片；所有图表同方向描线；为了动态改变事实 |
| 回扣/落定 | 这段终于说明了什么 | 回到刚才的问题或物件，显示变化后的状态，简短文字与停顿 | 重复整段文案、强制再切回主持人 |

这些职责不是新轨道标准，也不是要求每段四项齐全。没有真人、没有旁白时，主叙事可以由场景和图形共同承担，不硬把某些镜头贴成A或B。需要记录A/B时，注明它在本片的具体定义；动画也可能承担主叙事。

### 如何衔接，避免两套模板交替

每次切换先回答“为什么此处需要换一种表达”。问题进入具体解释、历史叙述出现证据、比较完成回到结论，都可以成为切点；不规定每十几秒一换、不设A/B比例，也不机械ABAB。一个解释段可连续多个不同视角，情境也可以省略。

优先通过同一物件、视线、动作方向或声音延续转场。例如纸带在情境中出现，镜头靠近后纸带上的记录展开为示意曲线；曲线上的区别讲清楚，再落到简短结论。情境是入口，解释要新增认识；保留足够阅读时间，不能只换底色。

声音可以先于画面引入下一场景，或让上一镜的声音延续到下一镜，帮助连接；默认只有现有配乐与按需音效，不借此重新启用旁白。先填具体声音事件与时间，再听接点是否自然，不强制每镜用同一转场声。

### 15秒概念示例（未制作、未核为历史场景）

以“从观察行情到写下可重复的规则”为示意：0—4秒，近景纸带不断送出，记录者的手暂时停下；4—10秒，跟随纸带进入解释画面，选出的记录整理成条件关系；10—15秒，拉远让几个独立条件共同约束一次动作，结论落定。三段由一个物件承接，节奏不平均，最后留阅读空间。是否适合讲具体人物及年代，由正式文稿和来源决定，不能当作已经发生的史实。

静帧确认应覆盖不同叙事职责；15秒仍选全片最难的连续段，若其难点正是情境与解释切换，就验证这一接点。职责标签填齐不代表画面好看，继续按实际连续播放和用户认可验收。

## 每个动作有可见的前因后果

- 写具体动作链：起始状态 → 引导注意 → 主体发生变化 → 结果落定 → 必要阅读停留。动作数量服从语义；不要填“高级动效”“图形同步变化”之类无法实现或检查的话。
- 区分装饰与解释：漂浮粒子、呼吸光圈、标题入场不能算知识进展。关系形成、旧结构拆开重组、局部成为整体、两个方法开始分化才可能在讲事情。
- 镜头推近要让观众看清某个细节，拉远要揭示上下文；横移要跟随对象或展开关系。避免每镜机械缩放、持续晃动或靠模糊制造速度。
- 动作有起势、主动作和停稳，主次错开。按材质选择加减速：纸张、线条、实体、界面各有感觉，不把所有元素都做成弹簧。快速运动可局部试运动模糊，标签落定后必须清楚。
- 先确定视觉注意中心。主动作期间减少抢眼字幕/背景运动，结论时留足阅读；不能为了“全程有变化”把事实讲不清。

## 节奏与声音一起设计

在同一时间表标记动作起点、主落点、停顿与下一镜接力，写清每个音效对应的事件及素材ID。需要踩拍时核实际音乐重音，不把默认曲目强行当120 BPM。允许动作跨拍、静音或仅保留配乐；不每次转场都塞whoosh。不恢复用户已停用的旁白，不用换BGM冒充重新剪辑。

## 从短段到长片的检查

1. 静态图由真实视频工程导出，覆盖不同画面类型；照片/海报本身不能证明镜头会动。
2. 中间难点15秒：检查同一主体怎样承接、解释动作是否完整、文字是否读得完、声音是否有用途。记录用户批准的具体版本；新主题不借用旧主题批准。
3. 扩全片前审节奏图：标出相邻镜头在构图、动作、声音上重复之处。若重复为了比较或建立规律，说明用途；否则重写镜头。小样的设计原则延续，布局无需复制。
4. 全片关键帧缩略图检查构图变化；正常速度看各章、接点和后半段检查动作与节奏。两者互补，不能以截图代替播放。留实际时间位置和问题，别用自评8/10、镜头数、特效数当通过证据。
5. 若只能抽查画面或无法听音，明确未完成范围，不能声称完整听看。技术验收与审美认可分开记录。

## 一次失败如何改变制作

趋势历史V14的主体内容长期沿用左文右图，文字隔8—9秒换一次，入场后大量时间只剩循环装饰；V15替换音乐保留画面，并未解决它。后续不再把同一个Chapter组件只换文稿当成扩片方案。可以复用排版/描线/镜头函数，但必须逐段决定主体行为和画面关系。

例如讲交易思想从个人经验走向规则化，可设计：记录簿细节 → 其中一句被选出并展开成条件关系 → 拉远显出多个独立执行节点。它是待核文稿支持的概念示意，不是史实证据，也不是每期必须套用的转场。对照版本若只是“人物卡换规则卡再换电脑卡”，应回到分镜重做。
