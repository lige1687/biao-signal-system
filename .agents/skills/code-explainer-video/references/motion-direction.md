# 动态导演与避免模板疲劳

适用：从文稿设计分镜、用户反馈“像PPT”，以及小样扩展长片。用户2026-10-09明确喜欢强动态、拒绝整片统一模板。下面是制作约定，不是已经验证的质量提升。

## 先确定哪些统一，哪些变化

字体、色彩含义、材质、线条和角色身份保持一致。构图、景别、主体占比、镜头方向与节奏随解释目的变化。一个贯穿主体可以不断获得新作用，不必每章清空重来；也不强迫所有镜头都变形连接。视觉相似不能暗示不存在的历史师承。

先用[镜头表](storyboard-template.md)写全片节奏图。人物情境、史料近景、关系展开、并排比较、时间穿行、结论留白只是可选表达，按内容选择；不按固定间隔轮换，不规定每片必须用满。固定中心构图可用于一个有意强调的片段，不能作为默认答案覆盖整片。

## 先做导演编排，再制作（用户确认）

理解整篇文案的主线、问题、推进和结论，按完整语义拆成具体镜头，不按标点或固定时长切。对每段先决定“观众此时需要看什么、为什么”，再选择A-roll/B-roll及具体表现；编排结果必须写入[视觉编排表](storyboard-template.md)，不能只口头说采用导演视角。

每镜保留对应文稿段ID与具体原文，写明A/B角色及理由、开始/结束/持续时间、构图与景别、动作阶段、最后落定画面、从上一镜怎样进入及怎样进入下一镜，以及所需素材和声音事件。A/B是本片的叙事角色，必要时注明混合或主叙事图形，不为分类硬加人物。每个时间都标依据：有旁白按实际录音对齐，无旁白按阅读和动作先估算，再用实际小样校准；草案估时不可写成实测。

先核全片信息推进、重复构图、缺素材与难实现镜头，再据表准备素材、从真实工程出静帧、制作中间难点15秒。沿用用户现有确认节点，不新增逐镜审批；表中有影响内容的未决取舍才集中询问。改文稿或实际声音时同步受影响镜头和总时间。视觉编排表是制作依据，不是成片完成凭据。

## 把A-roll / B-roll用于叙事分工

A-roll通常是承担主叙事的画面，B-roll是支持它的补充镜头，不能简单等同于“人物”和“动画”。定义参照[Adobe A-roll说明](https://www.adobe.com/creativecloud/video/discover/a-roll.html)。xilo把人物小剧场与知识图形作为自己的两类表达，这是创作者的具体用法，不是所有视频的固定分类。

本项目借用其思路，分镜先填“叙事职责”，再填素材形式：

| 叙事职责 | 解决什么 | 可选画面与视角 | 避免的问题 |
|---|---|---|---|
| 情境/问题 | 为什么讲、当时面对什么问题 | 环境远景、物件特写、人物行动、第一人称观察；按需使用史料或标明的概念还原 | 无关小人站中间、虚构历史人物台词、每章重复同一小剧场 |
| 证据/背景 | 依据在哪里、时代与对象是什么 | 核实的书页、报纸、照片、时间地点和必要局部放大 | 照片只作装饰；现代画面冒充历史；长篇密字无人能读 |
| 解释/比较 | 关系怎样变化、区别是什么 | 连续变形、关系拆解、并排对照、沿时间展开、细节到整体 | 万能卡片；所有图表同方向描线；为了动态改变事实 |
| 回扣/落定 | 这段终于说明了什么 | 回到刚才的问题或物件，显示变化后的状态，简短文字与停顿 | 重复整段文案、强制再切回主持人 |

这些职责不是新轨道标准，也不是要求每段四项齐全。没有真人、没有旁白时，主叙事可以由场景和图形共同承担，不硬把某些镜头贴成A或B。需要记录A/B时，注明它在本片的具体定义；动画也可能承担主叙事。

### 如何衔接，避免两套模板交替

每次切换先回答“为什么此处需要换一种表达”。问题进入具体解释、历史叙述出现证据、比较完成回到结论，都可以成为切点；不规定每十几秒一换、不设A/B比例，也不机械ABAB。一个解释段可连续多个不同视角，情境也可以省略。

优先通过同一物件、视线、动作方向或声音延续转场。例如纸带在情境中出现，镜头靠近后纸带上的记录展开为示意曲线；曲线上的区别讲清楚，再落到简短结论。情境是入口，解释要新增认识；保留足够阅读时间，不能只换底色。

声音可以先于画面引入下一场景，或让上一镜的声音延续到下一镜，帮助连接；默认只有现有配乐与按需音效，不借此重新启用旁白。先填具体声音事件与时间，再听接点是否自然，不强制每镜用同一转场声。

### 15秒概念示例（未制作、未核为历史场景）

以“从观察行情到写下可重复的规则”为示意：0—4秒，近景纸带不断送出，记录者的手暂时停下；4—10秒，跟随纸带进入解释画面，选出的记录整理成条件关系；10—15秒，拉远让几个独立条件共同约束一次动作，结论落定。三段由一个物件承接，节奏不平均，最后留阅读空间。是否适合讲具体人物及年代，由正式文稿和来源决定，不能当作已经发生的史实。

静帧确认应覆盖不同叙事职责；15秒仍选全片最难的连续段，若其难点正是情境与解释切换，就验证这一接点。职责标签填齐不代表画面好看，继续按实际连续播放和用户认可验收。

## 每个动作有可见的前因后果

在现有编排表写具体动作链：起始状态 → 引导注意 → 主体发生变化 → 结果落定 → 必要阅读停留。关系形成、旧结构拆开重组、局部成为整体、两种方法开始分化，才可能在讲事情；漂浮粒子、呼吸光圈、标题入场不算知识进展。不要用“高级动效”“图形同步变化”代替动作。

## 把多个动画编排成一段表现（2026-10-10增量）

用户指出差距“不只是方块”，还在动态设计能力。已有动作语义解决“动什么”，以下补足“怎样一起动、怎样接下去”。依据是用户提供的15秒OPUS作品与现金仓位v06实际画面及本方源码，定位见[案例与观察边界](decision-motion.md)。没有参考工程，不反推原作者用的缓动、物理引擎或工作流程，也不把单个作品比较称为模型能力测评。

### 学习风格，不复制载体（用户2026-10-10澄清）

用户明确：主要学习Opus作品的动态风格，不硬套“100个现金对应100个方块”；实际载体、分镜和运镜可以由我们这边设计收敛。参考模型和制作负责人分别记录。指定参考作品不等于指定由该模型制作，也不要求改掉本期已认可的主体。

- **提炼可迁移的风格。** 从已看过的连续片段提炼注意如何交接、动作如何起势和落定、快慢与停顿、层次与空间、镜头如何揭示关系、画面与声音如何呼应。质感、流畅度和冲击力也是目标；不能把风格学习缩成配色复刻、特效清单，或只追求逻辑正确而忽略观看感受。
- **按内容选择载体。** 先明确本段要解释的关系，再选能清楚承载它的对象。方块、钱币、容器、曲线、K线、实物与影像都只是候选。除非逐个计数本身就是解释重点，不把数字100机械转换成100个可见物件；用比例或汇总形状时保留单位、总量与必要示意标识。也不反过来禁用确实合适的方块。
- **由本地完成导演收敛。** Codex可以提出载体、安排分镜和运镜、实现并查看真实渲染，再依据用户反馈修受影响段。借鉴的是观看体验和动作组织，不必复制参考片的构图、切点、运动路径或完整镜头顺序。镜头跟随、推近、拉远与换景都写清动机；不为凑动态让所有层一起动。
- **用实际样例检验迁移。** 在现有分镜记录一句“借鉴哪种动态特征、本期怎样重新表达”，不新增表单或审批。沿原静帧→中间难点15秒→全片流程，正常速度看焦点、连续性、动作轻重、空间层次与阅读停留，再合音乐看节奏。更换物件后仍能保留已认可的动态感，才说明学到了方法；物件相似或文档更新本身不能证明效果达标。

例如讲现金分配，可让同一资金总量在投入区和保留区之间连续调整，也可用适合本片的比例图或实物；讲涨跌应对，可跟随符合数据条件的行情图，在触及事先说明的条件时切换关注点。两者都能沿用注意交接、动作搭接和强弱节奏，不必插入100个方块。这些是候选表达，不是本片已定分镜或已渲染效果。

### 先编排视觉问题，再分配动画函数

同一段先说清“观众正在看什么，变化后多懂了什么，下一步自然会看哪里”，再选位移、重排、镜头、描线、明暗等手段。若只是“图表淡入→数字淡入→结论淡入”，应重新考虑画面关系；换成弹入仍没有解决编排。方块、钱币、K线都是可选载体，能表达转移、缺口、比较或时间推进的其他对象同样可用。

在原动作栏写清下面相关项，不另建逐镜审批表，不要求每镜用满：

| 编排选择 | 具体写法与实现约束 | 看中间过程时检查什么 |
|---|---|---|
| **注意怎样交接** | 指定当前主角、下一主角及连接位置。旧解释层先减弱或让位，新主体接过显著性；可让已有背景获得新作用，不必全部重建 | 旧层尚未退完时新层是否已抢读；转交间隙是否只剩空等；画面不看字幕能否找到焦点 |
| **哪些一起，哪些错开** | 同一事实的位置、计数、量尺共用状态，保持一致；无须同时理解的动作错开。区分并行比较与依次解释，后者可先突出一路，再转到另一路 | 两个远处的强动作是否要求观众同时追踪；为错开而让数字与图形矛盾也不行 |
| **前后怎样搭接** | 下一动作在上一个“已经可理解”的节点接入，可与其次要收尾重叠；写具体接点，例如量尺到位后数字落定，不是所有动画结束才开始下一组 | 是否每步都慢起、停稳、空等、再慢起；又是否重叠过多，原因还没看清结果就出现 |
| **同一对象怎样换作用** | 明确保留的身份、位置或参照，以及变的是大小、密度、排列、视野还是叙事职责。先规划下一状态需要的空间，再设计让位路径 | 对象缩小后是否仍知道它是谁、去了哪里；无关联对象不要硬变形制造因果关系 |
| **动作怎样有轻重** | 分开考虑起动、推进、收尾。搬动物件可有惯性，结构重排要容易追踪，数据揭示服从真实顺序，文字落定后稳定。路径、时长与加减速一起选 | 是否所有对象共用一种“慢起慢停”的手感；弹跳/模糊是否损害读数。不要为差异而随机换缓动 |
| **何时放大、何时留白** | 推近让细节可见，拉远揭示上下文，横移跟随对象或关系。屏幕空间随当前问题分配；关键变化突出后可收住，让结论读完 | 镜头是否新增认识，还是机械缩放/晃动；标题、背景、装饰是否一直与主体争抢 |

数据图表的坐标、数据和标签随视野共同变化；不能只拉伸主体制造更陡的趋势。实体的轻微旋转、弧线、错峰或运动模糊是候选手段，不是每片必选，更不是参考作品已使用该算法的证据。主要关系在不依赖光效时仍应清楚，最后再用明暗、材质和声音加强少数落点。

### 用一个接点检验，不靠填满动效清单

参考片约9—10秒：大数字先减弱，矩阵轮廓退出，剩余单元向既有曲线低点附近收拢，再由曲线与高低点标记接过注意。有效之处是多层不同步地完成同一次转交；只复制“方块缩小”会漏掉位置联系、明暗顺序与下一主角的接入。并非每镜都要模仿这种转场。

现金v06已做到同一K线延续、资金回到现金区、触及条件后再行动；用户最新反馈“已经不错了”。仍需提升的具体位置：约10.35—13.5秒两条假设路径及两组资金动作几乎同时发生；标题在固定时点直接换句，多类动作共用同一缓动。它们不自动构成错误，但在需要依次理解时容易分散视线，动作轻重也不够区分。改进时先决定观看顺序和哪层让位，再调整时间与运动，不先增加元素。本例15秒还承载规则、风险、仓位和两种后续；信息过多时拆分解释节奏，保留已定内容，不用全片加速解决。

小样沿原流程正常速度看完整动作及接点；可先静音检查视觉解释，再合音乐听审。定位问题才看起点、关键中间态、落点及局部慢放；慢放顺滑不代表正常速度能懂。记录具体时刻的跟丢主体、焦点冲突、语义脱节或空等，修受影响段。没有观看/听审条件就标范围，不能以代码有插值、抽帧漂亮或文档更新声称动态效果已通过。这些是下一次创作的方法增量，尚未用新对照片验证提升幅度。

## 默认渲染质感与粒子设计（2026-10-13）

用户要求“以后默认就这样做，比如粒子、渲染、动态”，本节与既有动作编排合用：从首版把质感做进真实工程，不把它留作用户追问后的装饰补丁。原有注意交接、动作轻重与阅读停留继续执行，不以粒子替代解释。

- **先让主体有材质和体积。** 按物件选择细纹、粗糙度、边缘、厚度、接触阴影或反光；背景、主体、文字有明确前后关系。二维图形也可通过分层合成做到，不强制换渲染器或全部建模。
- **光照跟着焦点走。** 主体可用局部扫光、轮廓光或选择性辉光强调变化；明亮文字和数据不整屏泛光。需要景深或运动模糊时只影响合适层，最终读数与结论落定后恢复清晰。
- **粒子跟着事件发生。** 在接触、汇聚、分散、抬升、揭示或收束位置设计发射点、方向、寿命和衰减；重落点可短促爆发，阅读段收住。背景浮尘只提供低亮空间感，不当内容进展。无合适用途的镜头可不用粒子，不设每镜数量配额。
- **效果也参加卡点。** 主体关键状态、粒子爆发与有效音频瞬态共用事件时间；扫光、尾迹、余音可跨拍延续。先蓄势再到位，落定后留给观众读；不要所有层同幅度抖动或同拍闪白。
- **扩片保持制作水平。** 将材质/光照/粒子发射事件写入现有分镜动作栏；首中尾都核实际导出及转场中途，检查文字遮挡、辉光糊字、拖影读数和粒子抢焦点。不能只有15秒样片精修，后半段退回静态卡片。

美债v04的票券厚度与扫光、图形侧面、曲线辉光和事件粒子可作实现参考；固定纸券、深色网格、粒子形状与120 BPM只是该例选择。制作包由`docs/ops/media/treasury-yield-20261013/external-location.json`定位，先核外盘再取用；它不是已安装的通用特效库。用户认可的是默认制作方向，不据此宣称已验证流量提升或每个细节都获审美认可。这里只更新制作要求，旧视频不会自动重渲染。

## 节奏与声音一起设计

在同一时间表标记动作起点、主落点、停顿与下一镜接力，写清每个音效对应的事件及素材ID。需要踩拍时核实际音乐重音，不把默认曲目强行当120 BPM。允许动作跨拍、静音或仅保留配乐；不每次转场都塞whoosh。不恢复用户已停用的旁白，不用换BGM冒充重新剪辑。

## 从短段到长片的检查

1. 静态图由真实视频工程导出，覆盖不同画面类型；照片/海报本身不能证明镜头会动。
2. 中间难点15秒：检查同一主体怎样承接、解释动作是否完整、文字是否读得完、声音是否有用途。记录用户批准的具体版本；新主题不借用旧主题批准。
3. 扩全片前审节奏图：标出相邻镜头在构图、动作、声音上重复之处。若重复为了比较或建立规律，说明用途；否则重写镜头。小样的设计原则延续，布局无需复制。
4. 全片关键帧缩略图检查构图变化；正常速度看各章、接点和后半段检查动作与节奏。两者互补，不能以截图代替播放。留实际时间位置和问题，别用自评8/10、镜头数、特效数当通过证据。
5. 若只能抽查画面或无法听音，明确未完成范围，不能声称完整听看。技术验收与审美认可分开记录。

## 一次失败如何改变制作

趋势历史V14的主体内容长期沿用左文右图，文字隔8—9秒换一次，入场后大量时间只剩循环装饰；V15替换音乐保留画面，并未解决它。后续不再把同一个Chapter组件只换文稿当成扩片方案。可以复用排版/描线/镜头函数，但必须逐段决定主体行为和画面关系。

例如讲交易思想从个人经验走向规则化，可设计：记录簿细节 → 其中一句被选出并展开成条件关系 → 拉远显出多个独立执行节点。它是待核文稿支持的概念示意，不是史实证据，也不是每期必须套用的转场。对照版本若只是“人物卡换规则卡再换电脑卡”，应回到分镜重做。

## 从动作分镜到整片（用户2026-10-09确认）

纳斯达克v12暴露的具体问题：29镜中25镜、196/256秒使用固定标题/图形/底部解释框架，独立连续主体仅60秒。实际77—106秒多段都是入场完后长停；小样认可没有转化为全片同等动作设计。这个比例是本次诊断，不是通用失败阈值。

1. **先写动作分镜。** 在现有编排表写主体起态→变化→结果→下一镜承接；明确镜头跟谁、何时拉远或靠近、动作快慢与落定原因。“动态曲线”“黑金高级”不能作为可执行分镜。保留静态镜头时写出信息/情绪上的理由。
2. **先做成立的连续动作。** 实际工程搭建代表性起态、关键变化和结果，按原流程出静帧；静帧确认后才导出动态小样。小样先检主体与镜头能否独立讲清关系，再打磨光效、拖影和细节，不用粒子循环填补无信息等待。
3. **补视觉与声音层次。** 已定配乐在小样阶段使用，主次事件按音画落点形成持续接力，核心变化对齐实际乐句或重音；落实本节默认材质、光照和事件粒子，再按需加合法音效。主体、前后层、文字错开行动，变化应有推进和落定，不全片同速。未听审就保留未知，不凭波形宣称声音效果通过。
4. **无配音先减字。** 图形能表达的关系不再重复整段正文；保留必要定义、日期、单位和短结论。用户已定的重要内容不能静默删掉，可调整先后或拆段；不要用恢复TTS、缩小字或全片加速补救。
5. **扩片逐段与认可小样对照。** 在现有节奏表记录各段使用的动作方法及理由；正常速度连续看开头、中段、尾段及接点，查是否退回固定标题页、是否主动作早结束却还在等字。必要阅读停顿保留，无理由的等待或重复构图返工。关键帧、解码、动画数量通过不等于此项通过。

任选[黑金连续演化风格](style-compound-motion.md)时按其动作模块编排；其他风格也沿用上述制作次序。只复核本轮受影响的段及接点，不额外逐镜请求用户批准。

## 已认可案例：纳斯达克v09连续行情主体

2026-10-09用户看过15秒样例后明确：“这个主体不错，可以做到skill里边，作为经验哈。”认可范围是该片的连续行情主体与表现方向，不等于完整片通过或公开发布授权。

- **一个主体完成一段解释。** 近景跟随真实价格尖端→镜头拉远而保留原高点→后续交易日逐步显露→高低点转为跌幅量尺。每次变化新增一个认识，不清空画面换一张卡；此链适合讲历史起伏，其他主题按语义另编排。
- **镜头变，数据关系不变。** 视野扩大时坐标范围、曲线和标签同步调整；保留实际反弹，不为冲击力拉直跌势。只有日收盘则用折线，有可核OHLC才用K线；线段插值用于平滑运动，不能把插值数字标成真实当日报价。
- **先让位，再上结论。** 此次实际视频曾在图表缩小途中提前淡入大数字，造成叠字；改为图表腾出空间、活动价格退出后再显示统计。检查转场前、中、后三帧及连续播放，不能只看两端漂亮的静帧。
- **少字与动静配合。** 短句给当前变化命名，必要日期、数值、来源保留；不再叠加长正文与重复字幕。主体动作完成后给结论阅读时间，不靠循环发光冒充持续解释。无配音版本按阅读和动作重估篇幅，不沿用口播稿总时长。
- **审美复用到层级。** 本例炭黑底、暖白文字、哑金强调价格与关键数字；配色和轻光效可复用，固定标题位置、左右结构和每段秒数不复制到整片。统一视觉语言，按内容换构图。
