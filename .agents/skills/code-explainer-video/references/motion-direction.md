# 动态导演与避免模板疲劳

适用：从文稿设计分镜、用户反馈“像PPT”，以及小样扩展长片。用户2026-10-09明确喜欢强动态、拒绝整片统一模板。下面是制作约定，不是已经验证的质量提升。

## 先确定哪些统一，哪些变化

字体、色彩含义、材质、线条和角色身份保持一致。构图、景别、主体占比、镜头方向与节奏随解释目的变化。一个贯穿主体可以不断获得新作用，不必每章清空重来；也不强迫所有镜头都变形连接。视觉相似不能暗示不存在的历史师承。

先用[镜头表](storyboard-template.md)写全片节奏图。人物情境、史料近景、关系展开、并排比较、时间穿行、结论留白只是可选表达，按内容选择；不按固定间隔轮换，不规定每片必须用满。固定中心构图可用于一个有意强调的片段，不能作为默认答案覆盖整片。

## 每个动作有可见的前因后果

- 写具体动作链：起始状态 → 引导注意 → 主体发生变化 → 结果落定 → 必要阅读停留。动作数量服从语义；不要填“高级动效”“图形同步变化”之类无法实现或检查的话。
- 区分装饰与解释：漂浮粒子、呼吸光圈、标题入场不能算知识进展。关系形成、旧结构拆开重组、局部成为整体、两个方法开始分化才可能在讲事情。
- 镜头推近要让观众看清某个细节，拉远要揭示上下文；横移要跟随对象或展开关系。避免每镜机械缩放、持续晃动或靠模糊制造速度。
- 动作有起势、主动作和停稳，主次错开。按材质选择加减速：纸张、线条、实体、界面各有感觉，不把所有元素都做成弹簧。快速运动可局部试运动模糊，标签落定后必须清楚。
- 先确定视觉注意中心。主动作期间减少抢眼字幕/背景运动，结论时留足阅读；不能为了“全程有变化”把事实讲不清。

## 节奏与声音一起设计

在同一时间表标记动作起点、主落点、停顿与下一镜接力，写清每个音效对应的事件及素材ID。需要踩拍时核实际音乐重音，不把默认曲目强行当120 BPM。允许动作跨拍、静音或仅保留配乐；不每次转场都塞whoosh。不恢复用户已停用的旁白，不用换BGM冒充重新剪辑。

## 从短段到长片的检查

1. 静态图由真实视频工程导出，覆盖不同画面类型；照片/海报本身不能证明镜头会动。
2. 中间难点15秒：检查同一主体怎样承接、解释动作是否完整、文字是否读得完、声音是否有用途。记录用户批准的具体版本；新主题不借用旧主题批准。
3. 扩全片前审节奏图：标出相邻镜头在构图、动作、声音上重复之处。若重复为了比较或建立规律，说明用途；否则重写镜头。小样的设计原则延续，布局无需复制。
4. 全片关键帧缩略图检查构图变化；正常速度看各章、接点和后半段检查动作与节奏。两者互补，不能以截图代替播放。留实际时间位置和问题，别用自评8/10、镜头数、特效数当通过证据。
5. 若只能抽查画面或无法听音，明确未完成范围，不能声称完整听看。技术验收与审美认可分开记录。

## 一次失败如何改变制作

趋势历史V14的主体内容长期沿用左文右图，文字隔8—9秒换一次，入场后大量时间只剩循环装饰；V15替换音乐保留画面，并未解决它。后续不再把同一个Chapter组件只换文稿当成扩片方案。可以复用排版/描线/镜头函数，但必须逐段决定主体行为和画面关系。

例如讲交易思想从个人经验走向规则化，可设计：记录簿细节 → 其中一句被选出并展开成条件关系 → 拉远显出多个独立执行节点。它是待核文稿支持的概念示意，不是史实证据，也不是每期必须套用的转场。对照版本若只是“人物卡换规则卡再换电脑卡”，应回到分镜重做。
