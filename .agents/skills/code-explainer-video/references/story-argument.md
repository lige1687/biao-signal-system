# 主张、增量与叙事连贯性

用于写全文稿、定分镜和审核整片。配合[文稿自然表达](natural-narration.md)、[镜头表](storyboard-template.md)及[motion-direction](motion-direction.md)，本页只补“为什么讲这一段、它怎样推进核心”。不代替来源核查或已约定的视觉确认。

用户要求“看得爽”或音乐卡点时，结合[音乐与动作的落点](music-motion-sync.md)一起设计整段起伏。理解的推进和视听的满足感都要成立，不把任何一项当成另一项的替代品。

## 先回答标题，再展开内容

在现有 brief 写三句话：观众带着什么困惑点进来；看完应能说出什么答案；本片不准备证明什么。答案应包含关系或判断，不能只是复述题目。例如“现金也是一种仓位”只是主题；“机会是否符合规则、风险能否接受，会影响投入多少及保留多少现金”才是可以展开的主张。

开头用具体处境让观众认出自己，尽快接上本片要解决的矛盾。吸引力来自有用的问题、反直觉关系和可见变化，不靠夸大结论、恐吓、反复预告或与正文无关的热词。已有标题能准确承诺内容就保留；正文不足时先补论证，不能靠换一个更大的标题补救。

## 每段给出一个新的理解

沿用镜头表“新增认识”一栏，用具体话填写：观众从原来怎么想，变成能理解哪一件事。只有“风险很重要”“要有计划”不够；“同样的价格跌幅，投入减半，这一笔对账户的损失估算也减半”是可演示的增量。

- 把段落排成有依赖的推进：前段留下什么问题，后段用什么解释回应。不要把机会、纪律、仓位、心态排成互不相关的清单。
- 每个主要判断要有适合它的支撑：事实用来源，数量关系用算例，因果过程用变化，选择用有条件的对照。一个例子够用时继续用它，不为“信息量”引入新人物、新指标或新课题。
- 例子能说明什么就说什么。算术成立不能证明交易方法有效；价格进入示例区间只能说明满足这个假设条件，不能直接变成“好机会”或会赚钱的证据。
- 必要限制放在观众可能误解的地方，并影响表述。例如用“按预案估算”代替“最多只会亏”；关键限制不能仅藏在小字里。
- 收尾回答开头的困惑，回收已解释过的对象；不要再次完整讲一遍清单，也不要在最后引入新命题。

## 从全文稿到屏幕稿，再到分镜

先读一遍不带制作备注的全文，确认论证成立；再压成屏幕短句。压缩时保留条件、因果和限制，不只保留金句。无旁白视频的全文稿是内容母稿，不能按口播语速把整段文字塞上屏幕。

每个镜头应使观众看见该句为什么成立：是什么输入发生了变化，哪一项结果跟着变化，哪些参照必须不变。已有实拍、截图和图形按这个用途选；运动风格与物件种类分开，不强制方块、资金盘或固定版式。

逻辑连续与视觉连续分别核。沿用同一物件不保证讲的是同一情境；切镜也不必然跳跃。同一账户、价格、单位、时间和分支身份要保持清楚。历史到假设、正常过程到另一种可能、单笔风险到整个账户，都要有明确的语义提示。不能让漂亮的连续变形把两个互斥结果伪装成先后事实。

已认可的小样放回全文时，检查它的前一句和后一句。复用有效的动作与组件，不必原封不动拼接整段；删掉上下文已讲过的开头，避免再从零画一遍图。改了接缝就检查接缝，不能把原小样认可当成新全片认可。

## 审核时做四个小检查

1. **倒着列提纲**：从实际屏幕稿或导出片每段提炼一句“它现在说明了什么”，再与核心答案比较。不要只检查原计划。
2. **删段检查**：删掉该段，观众是否少理解一个必要关系？没有就合并或删掉；情绪停顿确有作用时写出作用，不机械追求最短。
3. **换序检查**：两个相邻段随意互换仍不影响理解，检查是否只是平列口号；确实需要并列比较时保留，并写明共同问题。
4. **误解检查**：给主要结论找一个观众可能带走的错误说法。核文案与画面是否一起阻止它，如“现金越多越好”“有止损就不会超额亏损”“示例比例适合所有人”。

最后正常速度连续看整片：是否有来不及读的前提、动作尚未讲清就换场、重复结尾、只有局部漂亮而中段退回文字卡。秒数草案只是预算；时间表与文件检查器只能核结构，不能替代实际阅读、来源判断、全片观感或用户审美反馈。
