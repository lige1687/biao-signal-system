# 信息密度与编年史：V8实作方法

适用于已经有可用画风，但用户仍觉得内容空、镜头只是装饰的修改。用户长期要求匿名：公开视频及其页面不出现自有系统名称、标识或宣传。

## 有证据的借鉴

- [六步动画教程](https://www.douyin.com/video/7689743418313952538)：本轮仅检查146—157秒连续抽帧，并参考已有转写。时间线、人物、笔记依次成为主体；新增说明占据明确空间。画面与音乐共享落点表值得复用，具体音色及作者完整prompt未确认。
- [代码视频原理](https://www.douyin.com/video/7690986300735868223)：检查154—165秒连续抽帧。先保留原图作为视觉参照，再高亮参数，最后把参数拆成表格解释。新增信息来自关系显露，不只是切镜更快。
- [Ben Marriott公开课程大纲](https://www.benmarriott.com/mastermotiondesign)：预备动作、重叠运动、构图、运动弧线、转场与节奏可作检查维度。只读公开大纲，未观看付费课程，不能复述不存在的课程实测。

## 实施方法

1. 写明每站新增什么认识。年代和姓名只是定位，必须再有一个可解释的思想变化。
2. 同一个主体保留足够久：价格线拆成层级；箱体显露突破；一摞规则展开为四项，再连向学员。动作为含义服务。
3. 信息分两三次进入。标题先给问题，主体给机制，短句给结论；每次出现时留可读停顿。不要硬规定每秒切镜。
4. 图表的标签、线条、说明分区。缩小主体后仍核对目标屏幕的可读性；4K不能弥补过小字体。
5. 长片先取最复杂的连续10秒试渲染，检查运动和声画落点，再全片输出。抽帧不能证明配乐听感，播放成功不能证明好看。
6. 密度至少记录历史内容秒数、历史节点数、无关介绍秒数。它们不是完播率或质量分数；没有观众比较就不写百分比效果提升。

V8实际结构：六站占53秒（3—56秒），V7四站占40秒；去掉8秒系统介绍。多出的13秒同时来自缩短开头及替换当代分类段，不能把全部归因于删除8秒结尾。

## 可复用制作prompt（自编，非作者原文）

制作一条60秒趋势交易编年史。面向初次了解趋势交易的普通观众，保留已有深色档案风、清晰中文和有许可的音乐，不接旁白，不用真实行情。

用六个有来源的历史节点组织内容：道氏思想、利弗莫尔、唐奇安、机械执行、海龟实验、2012年跨市场研究。每站回答：此前的问题是什么，这一阶段增加了什么，画面怎样让观众看懂。时间先后不画成未经证实的师承关系。

先给出逐秒表，包含画面主体、解释动作、新信息、阅读停顿和音效落点。保留同一主体，依次改变它的层次、位置或关系；避免整段只有标题加卡片淡入。每个关键日期、人物和数字绑定来源。图形为概念示意，书本封面为书目信息示意，不能伪装原件。

所有可见文字、封面、片尾、字幕、旁白和播放页不出现自有系统品牌及宣传。输出前核对内容清单和实际画面。先做10秒连续小样，再输出4K和1080P；完整解码、浏览器播放、查看实际关键帧，保存许可与失败记录。观众吸引力留待用户评价，不把工具通过写成效果达标。
