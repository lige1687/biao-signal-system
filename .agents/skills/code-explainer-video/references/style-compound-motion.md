# 可选风格：黑金连续演化

选择标识 `compound-motion`，用户口头可说“用《复利》那种连续动态”。2026-10-09用户确认将其作为可选项复用，不把黑金或拟人角色设为所有影片默认。这里是动作设计参考，不是现成渲染插件；尚无本项目同等效果成片验收。

## 何时选、如何选

适合增长、累积、数量分化、时间推进、部分与整体、两种条件比较。历史纪实或材料证据占主导的段落可只借镜头跟随与节奏，不硬插卡通角色、粒子或金色特效。先说清真实关系，再选下列一到若干模块，不凑满全部。

用户2026-10-10澄清主要学习动态风格：下列矩阵、代表单位和物件只作示例，不把“100”固定画成100个方块。载体、分镜与运镜由本期创作者按内容重新设计；方法见[学习风格，不复制载体](motion-direction.md#学习风格不复制载体用户2026-10-10澄清)。选用这个风格也不等于必须交给Opus制作。

制作说明可记 `visual_style: compound-motion` 及所选模块；这是给导演和实现者的设计记录，不是渲染器已支持的参数。字体、色彩、主体身份统一，构图和运动随内容改变。

## 可组合的动作模块

| 模块 | 用什么动作解释 | 镜头与落点 | 适用边界 |
|---|---|---|---|
| 主体成长/增殖 | 同一物件长大，或产生新物件，新物件再继续变化 | 先近看一层关系，再拉远揭示规模 | 仅当确有累积或派生关系；不能让企业/收益凭空倍增 |
| 图表竞速 | 两个量随共同时间轴推进，标记跟随端点 | 视野随规模调整，最后量出差距 | 同口径真实数据或明确假设；保留回落，不能伪造一路上涨 |
| 群体展开与穿行 | 一个关系扩为多层群体，前后层有不同移动速度 | 镜头穿行/拉远后落到明确对象 | 表达网络或规模；飞散粒子不等于新增事实 |
| 聚合为统计图 | 零散单位收拢成矩阵、柱形或比例，分组上色 | 从过程过渡到结构，停在可读结果 | 单位和总量必须一致；代表单位须说明，不能假装精确计数 |
| 物理比较 | 天平倾斜、容器填充、量尺展开表现两种条件差异 | 临界点短停，结果明确落定 | 明确概念示意；几何关系不得制造不存在的数学或因果结论 |

这几类可由二维矢量、Canvas或现有逐帧工程实现；空间穿行需要时增加层次/透视，不因看到效果就断言原作者用了3D或特定框架。角色可用原创物件，不能照搬原作钱袋形象。

## 画面与节奏配方

- 炭黑底、暖白主体，金色只强调关键阶段和结果；红色按语义用于差距或纠错。配色不替代叙事。
- 主体变化优先，镜头跟随第二，文字给当前变化命名；文字阅读时稳定，避免所有层同时抢动。
- 每条动作有起势、推进与落定，可用加速、减速或轻微惯性；不是所有动作套同一种缓动，也不强制弹跳。
- 光晕、拖影、少量粒子和前后景只在需要强调速度、空间或结果时使用。先在没有这些修饰时把动作讲清，再补质感；避免高频闪烁、线条模糊和数据遮挡。
- 紧凑来自删无信息等待、连续推进及强弱交替，不来自全片倍速。参考片也有结果停留，不能据其风格设每秒强制切镜。
- 音乐依本期授权选用，少数动作与真实声音事件对齐；音效有来源且实际听审后再记通过。原片声音分析不足，不能复制或假定其BPM、配乐与音效。

执行顺序复用 motion-direction.md 的“从动作分镜到整片”，确认节点仍为实际工程静帧→中段15秒样例→确认后全片；不因风格已入库自动通过本期效果。

## 本项目可改写的镜头例子

纳指行情：同一真实收盘曲线随日期推进→保留峰值标记→镜头追随后续回落→拉远显示全段→量出峰值到末日跌幅→短句落定。只有收盘数据时不造K线，坐标和数据关系始终同步。

只有有来源的跌幅统计时：100个代表单位缩减到剩余单位，再用量尺解释回到100需要的增幅，显式说明比例示意；它不是历史行情走势。最终数值按本片已核数据计算，不从参考片抄金融结论。
