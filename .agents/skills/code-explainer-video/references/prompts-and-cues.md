# 原创制作prompt

以下是基于多条教程方法重新编写的模板，不是原作者逐字prompt。两篇原推文逐项定位、取舍和完整阶段指令见[prompt-methods.md](prompt-methods.md)，选素材/镜头库见[library-catalog.md](library-catalog.md)。优先使用阶段指令；本页保留简版与共用时间表示例。

## 主题与证据

```text
<role>你是科普作者，擅长把复杂事情讲给第一次接触的人。</role>
<task>制作[主题]的[时长/比例]视频。先列关键事实及出处，再改成一幕一幕的短句。</task>
<check>名字、年份、数字可定位。区分直接史实与自己的归纳。不能核实的部分删掉或明确保留不确定性。</check>
```

## 美术与动作

```text
<role>你是动画导演。按文意设计主体的变化和必要停留，不为凑动态改变事实。</role>
<context>[参考视觉方法]；已有素材、来源和许可在[目录]；用户声音选择为[选择]。</context>
<task>先理解整篇文稿并写导演视觉编排表，再按镜头找素材、回填编排表，用真实视频工程导出样式帧供确认。每镜头包含时间、短句、主体动作、镜头运动、停留与音效。用同一时间表组织声音和画面。先做开头[范围]的小样，检查后按已有授权继续。</task>
<avoid>避免全片复用一种卡片、全部淡入淡出、看不清的光晕、紫蓝渐变、无意义漂浮、主体不动只有标题动。不能为了效果改动真实数据或史实。</avoid>
<check>开头立即出现问题或主体；每句有对应画面；重要内容留足阅读时间；动作能帮助理解；没有文字出框和镜头间语义断裂。</check>
```

## 修改要具体

不要只说“更高级”。例如：“第14—25秒人物记录簿太静。把等待画成钟针走动，关键点到来时停一下，再展开成持有与退出两条路径；保留三秒给观众读完。用一次纸张落点音，减掉连续高频提示音。”

## 共用时间表

```json
{
  "fps": 30,
  "duration": 10,
  "scenes": [
    {"id":"question", "start":0, "end":4, "claim":"问题出处或原创归纳", "action":"物件出现并指向问题"},
    {"id":"answer", "start":4, "end":10, "claim":"来源标识", "action":"同一物件变化为解释"}
  ],
  "cues": [{"time":4, "kind":"paper", "scene":"answer", "purpose":"翻页落点"}]
}
```

若要卡音乐节奏，记录音乐节选起点和可靠拍点。缓慢环境音乐的自动拍速可能不可靠，不可把规则间隔的自造音效叫作已经测到原曲BPM。先挑可听辨的落点，缺少稳定节拍就用段落和留白组织。
