# 财经视频内容与发布审查

更新：2026-10-12。适用：本项目涉及证券、基金、指数、投资观点和交易方法的科普片。目的：实质纠正误导、建议性表达和不符合平台资质要求的发布，不是寻找审核绕过方法。

## 1. 先看账号与规则，再看内容

每个平台单独核对：账号是否具备其要求的专业资质、认证是否有效、内容是否在认证允许范围内。实名、普通身份认证、企业蓝V、获得考试成绩、AI标识、往期通过审核，都不能自行推断为财经专业发布资格。只记录结果与核对日期；证件和个人信息不进工程或Git。

当前核到的规则入口如下。实际发布前检查更新与适用范围，不将一平台的规定当成三平台共同原文。

## 2. 审的是完整含义，不是敏感词表

先用一句话回答：“观众看完会学会什么，或据此做什么？”然后并排看最终成片、音轨、字幕、封面、标题、简介、话题、置顶评论和账号公开简介。下面是项目的审查方法，不冒称平台公开了逐项打分算法。

下表的修改方向用于本项目普通知识片，尤其是资质未核且已收到相关通知时；不是“所有K线、股票名称或历史讨论都被禁止”的清单。具体对象出现本身不等于违法，仍看完整含义、资质与场景；取得资质也不等于获得任意荐股或营销许可。

| 需要找的组合 | 为什么需要改 | 实质修改方向 |
|---|---|---|
| 具体股票/基金/可识别代码 + 看好未来、买卖价位、时间点、仓位或进出条件 | 容易形成观众可照做的投资建议；历史标签不能自动解除 | 撤掉行动方案；只保留本期解释所必需的历史事实和测量。名字本身不等于违规，不能用匿名代码掩盖同一建议 |
| 系统颜色/箭头/B-S标记 + 后续盈利数字/精选成功段 | 即使口头说不是买卖点，画面仍可能暗示有效信号或推荐 | 不展示可照抄的信号与选股结果；讲清计算、描述范围与失败/滞后，若评价效果必须有完整可信检验 |
| “更陡必回撤更大”“两点到三点最值得买”“价格必回价值” | 把形象比喻说成可预测、可交易结论 | 钟面只描述固定尺度下形状；三点水平。改变坐标角度会变；不能据斜率断定下一步。价值是有假设的估计，不是均线或保证回归点 |
| “均线过滤无效噪声”“红色阶段才是主要机会” | 平滑能减少短期变化，也会延迟反映变化；不能事后把亏损段全叫噪声 | 演示同一序列如何计算，明确过去信息与未来未知；区分“变平滑”和“判断对” |
| 具体标的 + 止损价/目标价 + 投入60%→30%等建议 | 组合起来已经接近交易执行教程 | 改讲概念或一般算术关系，删真实标的执行图和可套用资金比例；不要仅加“教学假设” |
| 名人头像/名言 + 自有方法/盈利曲线 | 可能构成权威背书，原文不同语境也会误导 | 史料只支持历史观点，核原文语境，不让名人替本策略站台；拿不到原文就不用引号和精确归因 |
| 开户、返佣、私信领代码/标的、联系方式、荐股群、虚拟资产服务 | 涉及额外金融营销/服务/导流风险 | 本知识片不纳入这些内容；不能以谐音和藏字继续表达 |

### 必须保留的事实条件

- 同一行情不同周期必须同一底层数据真实聚合；没有日内数据不得从日线编造日内走势。周线不是天然更准确。
- K线要有真实开高低收及使用权限；只有收盘价画折线。教学序列明确标示，不能套真实指数名称。匿名教学例子也不能用于掩盖实际交易指令。
- SMA是价格平均，不是投资者实际持仓成本，更不是内在价值；EMA给近期输入更高权重，仍只处理过去与当前输入。
- 历史涨跌幅、策略收益、账户收益分清；注明对象、日期、价格/含分红口径和样本选择。不能以少数后续20日数字证明系统。
- 复盘仅逐步显示当时已知信息；“噪声”与“关键变化”的定义不能事后重命名。没有正式规则不得冒充真实信号。
- 风险提示须可读，但首先要让正文真实、完整、合适；在违规或误导内容旁写免责句不解决正文问题。

## 3. 把审查接进原制作流程

**写稿前：** 核账号与目标平台规则。给每个中心观点留来源或标为个人观点/待检验；金融观点不是加“个人”就能发布。发现具体推荐或证据不足，先修改论证，再排分镜。

**分镜与样例：** 检查真实标的、行情日期、颜色、箭头、筹码/成本、买卖/仓位图标的合成含义。动态效果继续围绕问题、比较、计算和反例设计；爽点来自理解，不靠催买、收益刺激和财富焦虑。改稿不等于把一片改成静态风险告示。

**重制旧片：** 用户要求重做时，要逐项落到文稿、分镜、素材、精确图表、字幕、声音和剪辑。原买卖标记、价格条件、仓位条或收益数字若仍在画面里，只改旁白、封面或配文不能算修复。复用已认可的节奏与场景组件；受影响镜头重新编排、渲染并检查实际结果，避免拿新文稿配旧执行画面。原件保留，重制与发布分别记录；用户限定先改Skill时，不提前开做样片或全片。

**成片前：** 用准确文件指纹对应实际发布稿；逐段看画面、听完整音轨并核字幕，抽帧只能补充定位，不能宣称代替完整播放。标题、封面和说明同步重写，清除与正文相矛盾的标签。Astra等AI制作归因和平台AI声明单独记录，均不替代财经资质与事实检查。

**发布前：** 核资质/规则、用户已确认内容、准确导出、标题简介/话题/章节/AI声明及音乐授权。任何未核项如影响能否发布就保留草稿。禁止用换词、换分类、裁边、删代码、加免责声明或连续试发来探测/绕过审核。

**收到通知后：** 保存通知全文、规则链接、作品ID、时间、封面、配文与成片指纹。分“平台明示”“实际内容”“我们的推测”三栏。限制继续发布与通知相关的原版本；内部核查继续，不默认整个账号都被处罚。需申诉时先备事实和定位证据，获得发送授权再提交；不编造资质、不承诺申诉成功。

## 4. 记录与自检

写入已有production/发布回执或该片审查文档，不另造平行台账。最低记录：平台与核对日期、规则URL及适用范围、账号资格状态（已核/未核/不符合）、作品ID/版本/SHA、逐项内容问题和修改位置、还需用户确认的实质改稿、审核与公开状态。私人证件不入库。

本参考是文本要求；现有check_preproduction/check_public_text没有实现专业资质或语义审核，不能把它们退出0说成财经发布审查通过。人工核以下反例：

1. 未核资质，稿里每页都有“非投资建议” → 仍不能判可发。
2. 历史个股图有买点箭头及随后+20%，配文称学习 → 仍需查隐含建议/效果证据。
3. 股票名换成字母或股票话题换AI话题，正文未变 → 不能视为修复。
4. 中性均线计算演示无交易动作 → 内容建议性降低；仍需核平台对专业财经内容的资质要求。
5. 史料讲唐奇安的方法，但旁边是自有策略收益 → 名人背书风险仍在。
6. 通知列出荐股、开户、虚拟资产等类别，但未给时间码 → 不断言全部行为都在视频里发生；核实际证据。
7. B站曾发布成功 → 不代表抖音/XHS允许，也不代表以后不会复核。
8. 保留钟面比喻、紧凑动作，删掉斜率预测结论 → 可继续创作验收；不保证平台审核结果。
