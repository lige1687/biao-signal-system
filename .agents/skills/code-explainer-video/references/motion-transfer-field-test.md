## 写进现有分镜的四项细节

1. **明确交接的是哪一个对象。** 写出它在前后镜的屏幕位置、大小和含义。相机围绕它推近或拉远，让观众能追踪；画面缩小后标签可独立保持字号。相机运动必须让下一步关系更容易读懂，不能只缓慢缩放整页。
2. **容器变化与文字换场分开。** 旧标签先退出，新标签在有足够空间后进入；主体可继续移动，不必等全部停止。对最拥挤的转场看约25%、50%、75%进度，检查路径相撞、标签叠字和空白断裂，再看正常速度。
3. **把运动轻重落实到不同对象。** 非数据性的边框、展开或把手可快起、轻缓收尾，前后缘可稍错开；价格、比例与刻度须由同一个实际数值驱动，不能为了弹性动画越过不存在的金额或触发位。颜色变化跟真实条件，不跟预设时间打勾。
4. **区分可复现与观感通过。** 从不同时点跳回同一帧应相同，预览和导出应一致；这只证明工程可靠。观感检查另看连续追踪、重点交接、动作质感、正常速度可读性。记录具体时间和问题，不用特效数量、文件生成或自己的高分替代用户认可。

来源间对短片镜头数、固定BPM、是否只用一个形状的建议并不一致。选择依据是本片内容、已认可风格和实际小样，不能把不同作者的默认值全部堆进流程。文字、价格、声音仍共享同一时间表；音效落点与音乐拍点可以不同，不为机械踩拍牺牲阅读。

## 本地15秒试验：先量风险，再定投入

样例 `v10-motion-style-trial-20261010`，既有现金片独立新版本，实际工程与媒体位置见仓库 `docs/ops/media/cash-position-20261009/motion-research-trial-20261010.json`。详细分镜共用工程 `cue-plan.json`，来源快照及指纹在 `sources/index.json`。

- 基线：v06真实K线版已获用户正面反馈；本次缩为一个关系，故不将效果差异全部归因于某一个动效技巧，更不是模型能力排名。
- 实现：真实K线 → 止损距离量尺 → 保留末根K线的空间锚点 → 投入和损失估算共同缩小。重新选择资金比例长条，不套用100方块；同一止损预案下60%投入变30%，现金由40%到70%。
- 事实边界：历史收盘599.3699951171875，590为教学止损假设。先用精确值计算价差，再乘投入比例，显示账户损失估算0.94%→0.47%；本例预算0.5%同属假设。止损不保证成交价，未计费用、滑点和跳空。不能写“最大只亏0.47%”。
- 第一轮实帧发现5.4秒转场旧图与新说明相压、6.17秒缩小图碰标签。调整图表终态锚点/比例与文字入场时序，旧稿和失败记录保留。以修复后实际导出核验，不能只改文档宣布效果提高。
- 最终15.00秒、450帧、1920×1080/30fps完整解码通过；从最终MP4抽取11个关键帧检查，继续修复4.93—5.20秒残余旧标签碰撞并放大关键说明。播放器从头到尾及1.8/4.6/8.3秒跳转已实际验证。初始服务缺少分段读取支持，能播放却不能跳转，修复后才通过；播放、拖动和重播分别核验。小字号来源说明需放大阅读，独立听审和用户主观效果认可仍未完成。
