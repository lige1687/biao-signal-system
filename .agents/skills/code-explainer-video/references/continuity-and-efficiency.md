# 连续镜头与制作效率

在用户已确认视觉风格、希望进一步提升视频质量或减少返工时使用。依据为本项目V9—V12制作记录，以及xilo两篇教程的有限文字核对。原帖访问受阻，实际读了对应转载和关联开源仓库README；未完整观看其演示或运行外部脚本。不得据此声称某模型/框架更优。

## 制作决定

1. **选一个连续主体。** 每段写明“前镜的哪个物件，在后镜变成什么”。记录前后位置、大小、颜色和形状对应关系；重用同一组参数或路径，避免物件只是消失再出现。例：价格纸带→价格曲线→被圈出的关键位置。视觉承接不等于历史因果或师承。
2. **按表达目的选择画面。** 情境负责引入问题，档案照片负责人物与时代，解释图负责条件、变化和结果。已有风格不强制新增主持人或三方案；对当前主题无帮助的三维和粒子效果不默认接入。
3. **每镜记录五项。** 观众要理解什么、起始画面、主体变化、落定结果、与下一镜的关系。画面上的文字给变化命名，不反复复述整段正文。
4. **声音围绕事件。** 列出动作时间和声音用途。配乐实际节拍未测时，不声称“逐拍对齐”。需要踩拍时先核重音，关键字阅读和语义优先；不要求每拍都加声音。
5. **旁白是独立选项。** 当前用户选择无旁白。未来恢复时，用同稿短段试听语气、停顿和专名；连续合成只是候选，不保证自然。根据实际录音对齐时间，保留停顿，不用无空隙时间表压缩呼吸。

## 减少返工

- 保存获批制作说明及具体素材版本；复用本地已可用渲染工具，先评估现有能力，不为换工具重搭工程。
- 先渲转场前、中、后的关键帧；确认没有字形、重叠和主体越界问题，再渲短片。静帧不能证明动作自然，最终仍看连续视频。
- 同一时间表驱动画面与音效；所有动画由时间或帧确定，随机细节固定种子。
- 画面未变而只调声音时，保留视频流，只处理音频；只改某镜头时先验受影响片段。不要无理由反复渲染全片。
- 分别记录渲染耗时、失败返工和账号用量显示。未做对照不能声称节省多少时间/费用；账号共享整数额度不能精算单任务。
- 已认可风格→10—15秒改进样片→用户认可后扩片。新教程不覆盖用户已经确定的步骤、内容限制或安装/付费权限。
