# 视频目录与配套文档

用户2026-10-09要求：“产生的视频都搞到外部磁盘，创建合适的目录层级，每个视频都要产生对应的描述文件，和对应的文稿，定位啥的。”适用于本工作流全部后续视频及改版，不能只归档最终MP4。

## 位置与版本

先读项目运行存储管理，运行storage核固定UUID、挂载、可写状态和容量，为本片绑定外盘任务目录。用户要求能放外盘的都放外盘：新文稿、分镜、字幕、来源/许可/事实核查、描述和文件清单也直接写外盘；可移植工程和工程导出随片保存。本机仅留确需本机运行或版本管理的源码/依赖及最小路径索引，不重复留一份完整制作包。确需本机的例外要记录具体用途、路径和预计新增量，不笼统称“工具需要”。

启动下载、TTS或渲染前逐项绑定素材、声音、导出、帧缓存、临时目录和日志到本片外盘目录。使用工具支持的输出/缓存配置和仅对本次进程生效的临时目录设置；不能只改MP4出口，仍让中间帧或音频落内盘。读回配置及实际生成路径后才能称已生效。工具若无法控制某类写入，先核真实位置、空间需求和适用限制；不能假称全部在外盘，也不擅自搬运行环境。

视频制作与因子实验分开选择入口。只有实际调用实验输出入口时，才按实验大结果存储说明使用其预检；不能仅凭实验启动器的内盘5 GiB拒绝消息就认定普通视频无法制作。先核是否有符合视频工具实际要求、全部普通产物写外盘的执行路径。确实适用的设备/容量检查仍须通过，不降低现有阈值或绕过拒绝；若仍阻塞，说明哪个实际入口需要多少内盘空间。错盘、无盘、外盘容量不足或运行中断盘时停止该视频写入，不回退内盘。

规则不是对所有第三方工具的程序级拦截。仅写了文稿或修改了本说明，不称作完成渲染或外盘归档；历史文件不自动移动或删除。

在已批准外盘的视频任务根目录组织“视频库/主题/日期-视频短名/版本”。主题保持少量稳定分类；视频ID在改标题时不变；版本有独立文稿和清单，不能覆盖旧版。

```text
视频库/
  趋势交易/
    20261009-趋势交易简史/
      视频索引.md
      v14/
        00-定位与描述.md
        01-文稿.md
        02-分镜与声音.json
        03-来源与授权.md
        04-文件清单.json
        成片/
        封面与预览/
        素材/画面/
        素材/声音/
        制作记录/
```

目录是逻辑交付结构，实际绝对位置必须由当次设备/容量核对和archive-plan记录。新视频可直接绑定已批准外盘的视频任务目录；使用已有运行器时，已绑定的result路径不改写，在视频库建小索引指向其交付包。不为了美化目录搬旧片或重复复制大文件。清单注明“引用既有文件”及相对/绝对路径。跨设备盘符不同按设备UUID和盘内相对路径恢复。

## 必备内容

- **定位与描述**：视频ID、标题、版本、主题、目标观众、观众看完应理解什么、内容范围、计划平台与已适配平台、时长比例、风格、旁白/配乐选择、发布简介、关键词、当前批准/发布状态。未确认的平台或定位写建议，不能冒称用户确认。
- **对应文稿**：与本版成片一致的章节、起止时间、标题、屏幕文字；有旁白时另列实际旁白文字和字幕。无旁白时明确“屏幕文稿”，不可把提纲充作完整稿。额外口播改写稿须独立标草稿，不能说已入片。
- **分镜与声音**：复用实际时间表，记录关键动作、配乐段落、音效事件及素材ID，不手抄一份易失配时间轴。
- **来源与授权**：史实出处、使用范围、图片/音乐许可、所需署名、AI素材标识、未核实内容；沿用已有来源映射并保留边界。
- **文件清单**：成片和重要素材的真实路径、字节数、SHA256、媒体参数、对应文稿版本、制作源位置/commit、验收状态。未知填null并说明；不能拿旧版SHA充新版。只在实际读回后写“已归档”。
- **制作记录**：用户确认节点、修改原因、媒体检查、播放检查、未通过项、额度记录。共享账号额度变化不得算作单片精确费用。

## 交付核对

核对成片、文稿、时间表的版本和时长；读取归档文件并核SHA，打开成片检查实际播放。定位/发布简介延续无品牌要求。用户审美待确认与文件检查通过分开写。盘断开则保留小恢复记录，标待落盘；历史片补档逐条核原文件，不删除、改名或重复生成旧片。小样也有独立版本和描述，可引用同视频的共同来源，但注明采用哪些内容。
