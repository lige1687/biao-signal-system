[Remotion官方skills](https://www.remotion.dev/docs/ai/skills)覆盖动画、字幕、声音、布局、预览与渲染，并支持Codex等代理；[官方动画文档](https://www.remotion.dev/docs/animating-properties)要求用当前帧驱动，说明CSS时间动画可能闪烁。教程里的SVG原生时间动画应改成帧控制后再用于Remotion导出。

制作时优先复用已有渲染环境。小型二维解释可用Canvas/SVG/逐帧绘制；复杂可复用React场景可以用Remotion；教程提及HyperFrames，使用前另核已安装环境和当前文档。FFmpeg用于编码、混音和文件核验，不替代分镜与审美；skill负责组织流程，也不等于生成模型或渲染器。
