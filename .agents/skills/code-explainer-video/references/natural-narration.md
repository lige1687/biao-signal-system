# 自然旁白

用户2026-10-09明确：旁白去掉像AI的话和说明，可以用说人话处理文案。与无品牌、分阶段确认、外盘归档要求一起沿用。

## 文稿整理

先区分三份内容：观众听的旁白、观众看的屏幕文字、制作人员查的来源和备注。不能把屏幕稿里的“补充标注”“以下是思想概括，不是人物原话”“这里不声称世界第一”逐条读成旁白。没有旁白的旧片保留准确屏幕稿；另建旁白候选稿，不静默覆盖成片对应文稿。

用现有humanizer-zh做一轮编辑：删空泛开场、机械三段排比、夸张意义、反复“强调/关键/值得注意”、教科书连接词；用具体的人和动作讲清事情，句子长短有变化，术语第一次自然解释。不得编造口头禅、个人经历、人物引语或收益数据来增加人味。说话自然不等于每句都加“哈、其实、你知道吗”。

删去制作说明和重复免责声明，保留必要事实条件：例如不把人物按年份排列写成亲自传授，也不把过去的观察改成未来必然赚钱。表达有争议时可直接采用有依据的较窄说法，不把审核过程读给观众。金融历史片不需要每章结束都补一句“并非保证盈利”；实际涉及风险的段落讲清它具体是什么即可。

## 配音前核验

逐段读一遍，检查能否一口气讲顺、相邻句子是否重复、每段是否新增具体信息。改写后对照已核来源，尤其检查名字、日期、数字、关系和观点归属。章节时间先作安排，不把文字长度估算当实测配音时长；实际声音出来后再调整停顿与画面。自然度最后由实际听感和用户反馈判断，不能靠自评分数宣称解决。
