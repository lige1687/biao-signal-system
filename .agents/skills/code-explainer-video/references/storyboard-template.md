## 制作前检查与15秒样例

- 全片信息是否逐步推进；各镜是否帮助理解对应文案；是否重复或过载。
- 素材缺口、未决视觉方向、较难实现的镜头：只列实际存在的项。
- 样例的全片位置、选择理由、完整解释动作、转场和最容易失败处：待填。
- 静帧版本及认可原话；样例版本及认可原话：分别记录，不能预先标通过。
- 对照参考的具体方法、实际看到的位置、尚未核验部分：待填。
- 全片关键帧和正常速度播放：各记范围及问题；表格填全、技术可播不代表艺术质量通过。
