# 紧凑节奏与第二篇教程增量

## 默认偏好怎样落实

2026-10-09用户：“我喜欢紧凑一点的节奏，可以放到skill里边做一个偏好设置”。制作说明默认 `pacing_preference: compact`；它是创作偏好，由导演读取执行，并非渲染器自动加速开关。本期明确指定舒缓等节奏时覆盖，记录理由即可，不重复询问已知偏好。

- **文稿**：尽快进入本段要解决的问题；删重复复述和空泛铺垫，保留事实的条件。无旁白时改成短屏幕句，不沿用口播稿长度硬塞屏幕。
- **编排**：把长镜头分成可见的解释节点，写相对时间和结果。例如同一条线被选中→展开比较→差异被量出；不需要每个节点都切镜。动作已经讲完、文字也读完后的等待优先缩短。
- **动作**：减少无目的入场和漫长缓动，主动作果断、落定清晰；新镜可承接上镜结果，避免每次清屏后重新搭台。阅读中的文字保持稳定，背景运动不能抢注意。
- **声音**：沿用默认配乐，选其中适合该段的乐句，标实际可用的重音/转折及原音频偏移；主体推进和声音连续呼应，关键动作重落定、次要变化轻接力，不能只在少数转场配声、正文长时间没有可感知落点。不机械每拍切镜或用同一种重击，也不直接加速音乐；结论可以收声或减弱。未实际听审时如实记录。
- **15秒样例**：同样验证中间最难段，按正常速度检查是否有空等、跟丢主体、读不完、音效抢戏。遇到过快先减字/拆信息/调整动作次序，仍需要才延长停留。一次只改有证据的问题；用户确认仍是既有样例确认，不新增节奏审批。
- **全片**：沿用已认可小样的紧凑程度，检查中后段是否重新变慢或连续同速。短推进与关键结论停顿交错；片长由内容成立，不为凑分钟拉长，不因节奏偏好擅删已定内容。

现有编排表的动作栏填“相对时间→可见变化→结果”，声音栏填“音源偏移→实际事件→动作落点”，可读栏填“必要停留/可删等待”。不设每镜统一秒数或中文字/秒硬门槛；在目标播放尺寸实际读看校准。历史画面承接是视觉联系，不能因此暗示不存在的师承或因果。

### 三类输入怎样选

1. **真实素材承载**：观众必须看具体人物档案、界面、操作或数据证据时使用。标素材ID、来源、裁切/放大关注区与前后状态；缺素材列缺口，不用生成画面冒充。
2. **原创图形解释**：表达比较、筛选、聚合、层级、替换、展开等关系。先写关系，再挑动作；金融因果必须有证据，无证据时只表达可支持的关联或流程。
3. **文字强调**：短结论、概念替换或章节提示。重点文字必须承担作用，不把每句都做成满屏大字；不要用它掩盖缺失的图解。

A/B是叙事职责，上述三类是材料与制作方式，不能当成同一列的互斥分类；图形也能承担主叙事。角色参考包、三视图和视角只在需要角色时调用，不强制IP人物。

## 全流程接续与失效检查

已定文稿→导演表（职责、材料类型、动作时间、声音与停留）→按表找素材并回填→正式工程静帧确认→带默认音乐的中间难点15秒确认→按已批原则完成整片→正常速度完整播放、声音和交付核验。

修改后沿已有镜头ID查受影响项：文稿变化查事实/屏幕文字/镜头；素材或构图变化查风格帧/边界/可读；时长变化查后续起止/转场/音乐偏移；更换音频查声音落点。仅重新验证受影响部分和接点，风格方向实质改变才回到对应已约定确认阶段，不无理由重做所有文件。

本轮仅完善规则与调用链，没有新影片对比，因此不能宣称已量化提升留存、观感或节省制作时间。原文的一分钟样片、固定两种底色、付费语音开通和逐模板审批不替代用户现有流程。
