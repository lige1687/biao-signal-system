# 音乐与动作的落点

用于“看得爽”、特效与音乐卡点的导演任务。目标是观众能期待变化、感到变化落下、看清变化结果。沿用现有镜头表、声音时间表与真实15秒样例；不增加强制软件、审批或自评分。

## 先安排起伏，再对齐瞬间

配乐在分镜阶段进入：找适合本段情绪的音乐段，把推进、强调、收束的变化对应到叙事。按用户2026-10-11认可的趋势片v13，默认让主体动作与声音形成持续可感知的接力：重要变化踩明确重音，次要推进轻落点，文字阅读和连续描线可跨拍；不能只给少数转场加声而让正文松散。全片同速、每拍都切或每次都“嗖—砰”，都会抹平主次。不要为赶下一拍压缩必要的阅读，也不要为了下一个拍点空等。实际案例与复用边界见[紧凑节奏](tight-pacing.md#趋势片v13用户认可的连续卡点基准2026-10-11)。

卡的是**观众感到变化成立的瞬间**。例如线条到达边界、两个物件接触、投入缩到目标值、镜头揭出完整关系；不是把所有动画起始时间设在拍上。通常让动作先蓄势、加速，在所选声音落点达到强调状态，再减速落定留给观众读。具体缓动与提前量由对象重量和距离决定，不硬套固定帧数。真实数据、账户余额和阈值不能为弹性效果越过真实值；回弹可给装饰边缘或镜头。

落点也不一律是动画终点：点击声跟点击，滑动声跟位移，撞击声跟接触，完成提示跟结果揭示。先说明声音在表达哪个事件，再定时间。网上“对起点”与“对终点”的口诀各有适用对象，不照抄成全片规则。

用对比创造力量：一段稍密，一段稍疏；大位移后给稳定画面；关键信息出现时让其他运动和音效让位。需要接力时，下一对象可在前一对象收尾时接入，不用等每件东西完全停稳；焦点必须仍只有一个。

## 在已有时间表里写清楚

每个采用的落点记：镜头ID、语义事件、音源路径及指纹、原音频秒数、片内秒数/帧号、动作起点/主落点/落定点、对应音效、确定程度。无需给每个装饰填记录。

音乐原音源 m 秒在片内 s 秒处开始，原音乐事件 b 秒的片内时间为 `s + (b-m)/rate`，帧号为 `round(time*fps)`；默认rate=1。切换音源或做循环后分段计算，不沿用整片一个偏移。音效文件开头有空白或蓄势时，应让**音效的有效瞬态**对上画面事件，而不只对齐文件起点。保存原秒数和取整残差；最终用导出片正常速度核，不把算式正确当成听感通过。

代码实现优先让动作和音效引用同一个事件ID/时间锚点；改镜头时同步移动，不在两份脚本里手改相近的小数。做音频拼接时保留源段→片段映射，核首段起点与最终音轨偏移，避免混音重置时间戳后整段一起错位。音乐未确认拍号和乐句时，不照搬“四拍一小节”的切法。

自动波形峰值、频谱突变和BPM估计只用于找候选，不等于乐句、强拍或鼓点已确认。既有音源实测若出现半速/倍速候选，保留歧义；优先核本段实际重音，不强行生成120BPM网格。音频未能听审就标候选，用精确小数不能掩盖未知。

## 音效、转场与验证

- 每类关键动作有相符的声音触感：接触/锁定用短促声音，拉开/位移用连续声音，收束可少声或留尾音。声音服务对象和情绪，不为所有文字逐字打点。
- 已有鼓点足以支撑事件时可不叠撞击声；控制叠加峰值，避免更响被误判为更好。密集行情段与从容结尾应有不同能量。
- 声音可提前引出下一场，但历史/假设或账户身份变化仍需明确提示，不能靠顺滑转场消除必要区别。
- 先静音看动作是否清楚，再合声正常速度看是否顺畅、有落点、不过载；定位偏差才逐帧看。检查完整导出片及接缝，必要时用同画面同音源的两个时序比较，保持音量接近。
- 验收用具体位置描述：抢拍/拖拍、尚未读完就换、主动作被次动作抢走、重音连续过多、结尾突然截断。无听审条件时明确范围，不声称“已精准卡拍”或“更爽已验证”。

## 现金片v12失败后的纠正（2026-10-11）

用户明确“卡点我没看到啊？”。旧版零时序偏移仍保留为技术事实，但其长缓动、短小环形强调和弱瞬态没有达到用户观感。修改须让主体本身有可见速度差和停顿，与有主次的声音对应；仅放大音量、报精确秒数或添加装饰环不算解决。先做同段正常播放对比，再由用户确认，不把新方案写成已验证配方。镜头实例与连续手机审片按[整片节奏与镜头实例](animatic-and-shot-library.md)执行。
