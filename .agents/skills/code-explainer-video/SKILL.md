# 视频制作（统一入口）

## 第一创作优先级：卡点清楚、节奏紧凑、读看顺畅

用户2026-10-11观看趋势片v13后确认：“就这种卡点以及节奏紧凑，让观众读的爽，看的爽，抓住观众眼球”，要求放在Skill最优先位置。**后续此类知识讲解、金融科普和动态图形视频，默认按这一观感制作；从文稿、分镜到成片都执行，不等到最后补音效。** 这是创作首要标准，事实准确、文字可读和用户的阶段确认仍须满足；用户当期指定其他节奏时服从当期要求。

- **开场就有问题和变化。** 直接进入有意义的动作、反差或疑问，尽早让观众知道看什么；不以无信息片头、Logo或长铺垫消耗注意。
- **主体持续接力。** 用推进、揭示、比较、聚焦、转向、让位和落定承接解释；一个动作将结束时，下一处注意点已准备好。长镜头内部也有进展，避免静态卡片轮播、长缓动和动作结束后的空等。
- **卡点必须看得出、听得出。** 主体有明确的加速—到位—短停，关键变化配清晰声音落点；轻动作与重动作交错，阅读时也可让不抢字的解释动作推进。不能只在少数转场敲几下，或用小装饰环、均匀缩放、加大音量冒充连续卡点。
- **让观众读完，也想继续看。** 短句逐层交代，文字落定后稳定可读，给看图留时间；过密先减重复、分配信息和重排动作，不用快速闪字硬卡拍。抓眼球靠问题被展开、差异被看见、结果落定，不靠持续闪烁抖动。
- **按实际播放验收。** 用拟采用音乐和音效，正常1倍完整播放15秒样例并看目标手机尺寸；检查是否能跟住主体、读完主句、感到落点并理解逻辑。扩片后保持这一节奏，尤其检查中后段。事件数量、时序零偏移、技术检查通过都不能代替用户观感。

每次制作分镜或改动态时读[紧凑节奏](references/tight-pacing.md)和[音画落点](references/music-motion-sync.md)。已认可实例和复用边界见紧凑节奏中的“趋势片v13”；复用动作组织方法，不固定每秒动作数、镜头数、音乐、配色或图形载体。

把知识变成能看懂的动作，交付可播放视频、共用时间表和来源。参考片用于提取方法；作品主题、声音和制作范围服从用户当前要求。学习Opus等参考作品时，主要迁移动态风格与编排能力，载体、分镜和运镜可由Codex结合本期内容设计收敛；不因参考来自某模型就强制换模型或移交导演职责，具体见[学习风格，不复制载体](references/motion-direction.md#学习风格不复制载体用户2026-10-10澄清)。

## 开工入口：把资料接到制作

先读[前置材料与工作流](references/preproduction-workflow.md)。用户只给主题也能启动，本Skill先补需求摘要、内容事实和自然文稿，再接分镜与制作；不要求用户先交齐文档。已有材料用制作索引引用，避免重写。正式动效前使用`scripts/check_preproduction.py <production.json> --stage sample`核材料，完整片改为`--stage full`；它只核文件与状态，不自动安装/调用配音服务，也不替代内容质量和用户确认。旧版已完成作品不因新检查重跑。

## 固定协作顺序（用户2026-10-09再次确认，适用于每期视频）

**文稿与内容探讨确认 → 查找可入片素材 → 正式风格图确认 → 中间高风险段15秒样例确认 → 完整成片。**

用户已经给过的信息直接沿用；只问尚缺的关键取舍。先交具体可看的产物再请用户评价，不能用计划或文字形容代替样例。用户明确说“先给图”时，本轮搭建真实视频场景并导出指定静帧，不提前渲染动态样片或完整片；用户确认静态图后才进入动态小样，确认小样后才扩展全片。这里的停点来自用户明确要求，不能因技术检查通过自行越过，也不为历史已确认项重复索取确认。

默认每期先交几张关键镜头的完整静态排版图（通常3张，按实际画面类型选择），等用户确认具体版本；再交15秒实际动态小样，等用户确认后才制作完整片。收到完整制作包、定稿文案或“直接执行、不要重新讨论选题”的Prompt，不等于取消这两个确认点。只有用户明确针对本期要求跳过相应确认阶段时才调整；另一主题的视频认可不能代替本期认可。当前阶段和两次确认分别保存，缺少确认就停在已交付的图或小样，不预先渲染下一阶段。

先按文稿准备可入片素材，再用这些实际素材制作静态图，覆盖主要画面类型；同一套风格应统一。15秒小样优先从全片中间选择最容易出问题的连续段，覆盖复杂解释、主体承接、图文密集或声音衔接等本片实际难点，包含完整解释动作与一次转场，用默认配乐和拟采用音效检验节奏。分镜写明该段在全片的位置、为何容易出问题、这次验证什么；不能为容易通过只选漂亮片头。确认范围分别记录：选中的具体版本、用户原话、允许进入的下一阶段、保留部分和待改部分；一句对原始素材的“不错，继续”只认可该素材，不等于认可尚未展示的三张排版或最终视频。

流程示例、参考来源分级和可复用提示词见[分阶段制作与确认](references/staged-workflow.md)。只在用户另有明确新要求时调整顺序。

### 预览图必须是真实视频工程的渲染帧（用户2026-10-09明确）

“先给图”“关键帧”“中间效果”“看看风格”默认要求最终视频里会真实出现的画面。先在实际视频工程中搭建代表性镜头，再用该工程的渲染器导出指定帧；可以直接渲染静帧，无需先导出整段视频。后续动画与成片复用同一套场景组件、素材、字体、排版、图表和材质设置，不能另写一套不与视频共用的绘图脚本，只承诺以后照图还原。

不得用imagegen生成的整幅概念图、海报或拼贴板冒充视频效果预览。imagegen可按镜头需要提供素材，但必须把素材放进真实场景后再渲染预览；只有用户明确要求概念探索或情绪板时，才交对应概念图，并标明它不是视频实帧。准确文字、数字、图表保留为工程中可编辑、可继续动画的元素。

深色、哑光等用户指定的审美，要落实到实际场景的色彩、纹理、光效和材质参数，再检查导出效果，不能只在生图提示词里描述。本期风格不自动变成所有主题的固定配色。

每张预览在制作记录中保留工程/源码路径及版本、场景或composition ID、帧号或时间点、画幅尺寸与导出图片路径，确保可重现。交付前查看实际导出，核对文字、图表和材质；静帧通过只代表静态效果通过，仍按“静帧确认→15秒动态样例确认→完整片”推进。

## 长期内容约束（用户 2026-10-08 明确）

所有后续视频、封面、字幕、旁白、片头片尾和播放页均不出现 LEI / LeiSignal 名称、标识、口号或隐含的品牌宣传。即使以后讲自有系统，也只讲方法，不透露系统名称。此期只讲趋势交易的来源、历史和编年，不插入自有系统介绍。旧导出保留为历史存档，不能当作符合新要求的交付。

无品牌检查同时看文字源与实际导出；源码内部路径不等于用户可见内容。可见文字集中到内容清单，并运行 `scripts/check_public_text.py`；该检查不能替代图像/声音人工核对。

## 默认无配音（用户2026-10-09明确）

用户明确“配音也不用了……配音不用了写到Skill里边”。本工作流后续默认 `voice_mode: none`，以精简屏幕文稿、用户选定的配乐和必要音效叙事；不调用TTS、不自动克隆或补录旁白。旧制作包的“优先配音”、旧稿标题“口播”和历史有声样片不覆盖这一新偏好。只有用户之后明确要求恢复配音，才进入有旁白的条件流程。

无配音不是把长口播整段塞到屏幕：按阅读速度拆成短句，留出观看素材的时间；文稿、分镜和字幕同步改为屏幕叙事。保留旧版本，不把关闭播放器声音当作已导出无旁白新版。

## 素材按需使用（长期制作规则）

用户明确：“让你找素材不是让你找一堆啊，不是让你全贴。”**找素材是为了挑选合适的镜头，不是堆素材，也不是搜到多少就用多少。** 按文稿和初步分镜需要检索；没有明确镜头用途时，不继续扩大采集。素材清单区分“候选”和“采用”，已找到或已下载都不等于必须入片，不以素材数量衡量制作进度。

每个采用素材的镜头写清“用在哪里、帮助观众理解什么、保留多久”。实拍适合交代地点、时代、人物、实物或确有作用的转场；代码动画负责把数字、关系、历史变化和逻辑讲清楚。不全片铺实拍，不给每段文字配循环底图，不按每分钟机械插素材，也不设机械使用比例。若拿掉某段素材不损失信息、场景交代或必要节奏，就从剪辑中去掉；这不授权删除原文件。不要反过来强制所有镜头都用代码，按表达需要选择。

K线必须来自可核的真实开高低收数据；只有真实收盘价时用折线，不伪造影线或历史曲线。没有可用数据及相应用途许可时，用有来源的统计、比例或明确的关系示意，不能冒充历史行情。风格变化按已定顺序先交实际关键帧，再交中间高风险15秒样例。

本期删掉“指数是什么”的通识讲解，直接从纳斯达克新闻、发展历史和科技企业切入；保留综合指数COMP与纳斯达克100 NDX的必要口径区别。不要把这一期的删节扩大为所有主题都不解释概念。纽约证券交易所的交易大厅不能标成纳斯达克现场；通用机房/芯片素材不能标成某家公司的真实设施，现代画面不能冒充历史档案。来源、许可和署名逐项记录，AI还原明确标注。

## 视频制作默认全程写外盘（用户2026-10-09明确）

用户要求：“就你能放的都放到外盘里边呗。”本视频任务能放外盘的新文件，从生成时就直接写已核验外盘，不先写内盘再搬：成片、样片、封面、素材、配音、配乐、字幕、文稿、分镜、来源与许可清单、事实核查、制作描述、可移植工程与工程导出、可配置的渲染缓存、临时文件和日志。按主题 → 视频 → 版本组织，每条视频都有对应文稿、定位与描述及文件清单。

本机仅保留确需本机运行或版本管理的当前源码、依赖/环境，以及最小定位和接续索引；不为方便重复保存整套制作包。开始制作、改版和交付时读[视频目录与配套文档](references/storage-and-packaging.md)，逐项核实际输出位置。视频流程不能仅因借用了实验启动器，就把其内盘5 GiB保留量当成所有视频的统一前提；应核当前视频工具的真实内盘写入和适用规则，不能绕过确实适用的检查或擅改阈值。

断盘时停止外盘写入，不创建假挂载目录或回退内盘。既有固定路径、活动数据库和运行环境不自动迁移或删除；旧片用索引关联。本条规定后续写入位置，不声称已有工具自动完成了路径配置或历史文件迁移。

## 先分清参考证据

读取视频详情、可用转写、关键帧与有关评论，记录时间位置。找原作者的工具或prompt声明，不把评论猜测当事实。自动转写会错认工具名；用画面文字或官方文档复核。只有抽帧或转写时，不能声称完整听看过。

同类效果可以由Remotion、HyperFrames、Canvas、SVG或其他逐帧绘制实现。不要看到动画就断言用了某个框架。已有渲染路径能实现目标时先复用；安装、账号、付费或声音接入不由本skill自动授权。

## 制作顺序

1. 从用户要求提取主题、观众、成片时长、比例、声音选择和交付位置。已有明确要求直接使用，不重复问。
2. 核对内容。给每个名字、日期、数字和历史关系绑定来源。历史发展图说明是思想线索还是实际师承；时代先后不能证明直接传承。金融科普不以历史声望或示意图声称收益。
3. 将内容拆成问题、解释、反差和收束。每个镜头写出观众应理解的一件事、画面主体、主体怎样变化、可读停留、音乐和音效事件。不要把文案逐段放进同一种卡片。
4. 挑符合主题的视觉语言，遵守上方用户指定的确认顺序。已有认可的风格沿用，换风格时重新给相关静态图；小样未解决的主要问题先修复，用户认可小样后再扩展全片。
5. 为画面和声音使用同一份时间表。有旁白时先测实际时长，无旁白时按文字阅读与动作设计时长。轻敲对应落点，纸声对应翻页，笔声对应描线；重要观点出现时给画面和声音留白。
6. 实际渲染、完整解码、查看导出关键帧、打开播放页。分别记录文件检查和用户观感；不能把脚本启动、工具success或图检通过叫作主观效果已解决。

参考学习的验收是动作与信息的对应，不是配色相似。V6 的纸张配色和固定卡片布局虽通过文件检查，仍被用户否定。抽取连续片段，标记主体、视角、信息落点实际怎样变化；不能把单张风格帧当成剪辑学习完成。历史人物优先核实可用档案照片，不以低细节卡通头像代替人物质感。

## 让动作承担解释

### 动态效果与冲击力（用户2026-10-09明确）

用户希望视频加入更多动态效果，增强冲击力。写文稿、分镜和转给Pro的创作要求时，一并明确关键动态：主体连续变化、镜头推进或拉远、局部放大、线条交织、节奏停顿与声音落点；不能只交静态卡片加淡入淡出。每个关键镜头说明“什么在动、怎样动、帮助理解什么”，先突出一个视觉落点，再展开细节。

双均线讲解可让同一段价格逐日推进：SMA窗口新价进入、旧价退出；EMA向新价递推；两条线随计算靠近、分开、交织、共同抬升或回落，再拉远到20/60/120交易日视角。用精确计算驱动曲线，交叉处短暂停留或局部放大，不人为制造交叉、夸大波动或暗示EMA必然先转向。

冲击力服务于解释：转场承接同一主体，动静有节奏，重要数字和标签留足阅读时间。轻量描线、适度层次与音效可增强落点；持续抖动、频繁闪烁、无关粒子和遮挡数据的装饰不作为默认效果。静态风格图与动态小样仍按既有确认顺序进行，特效数量不替代用户观感验收。

- 描线：逐段显露有意义的轨迹，而非反复淡入标题。
- 连续性：同一物件换到下一镜头的新角色，例如报纸折成记录簿、记录簿展开为规则表；镜头变化后仍看得懂关系。
- 层次：前景标签、中景主体、背景时间线可有不同速度。先给观众视觉落点，再增加细节。
- 强调：用圈画、划线、局部移动或短暂放大指向关键部分，保留真实比例与语义。
- 人物：允许原创示意插画；不把它标成真实历史照片或复制他人角色。
- 图表：需要时直接绘制清晰矢量或原生高分辨率图形；用户取消真实案例时改用明确注明的概念示意。

Remotion动画由当前帧驱动，避免CSS时间动画导致离线渲染与预览不同；SVG组件按需要动的部分分组，二维解释足够时不为炫技引入3D。若用其他绘制器，同一时间点也应生成相同画面。

已认可风格后要提升连续叙事、素材表达或减少返工时，读[连续镜头与制作效率](references/continuity-and-efficiency.md)。该方法要求实际物件承接和分段核验，不把特效数量、工具名称或账号额度变化当作质量与效率证明。


讲规则、风险与行动，或用户指出“打勾不直观”时，读[让判断在画面里发生](references/decision-motion.md)：把条件落到对象的位置与状态，连接输入、量尺、结果和行动；历史与假设后续明确区分。此方法来自现金仓位旧A的具体缺口，不是模型效果评测。

## 镜头变化与全片节奏（2026-10-09）

制作分镜、15秒样例和扩展全片前，读[动态导演与避免模板疲劳](references/motion-direction.md)。统一字体、配色、材质和主体身份，不统一每镜的构图、景别、运动和转场。复用绘制与动作组件，按每段内容重新编排，不让一个章节组件只换标题撑满全片。反馈“都有动画，但动态设计仍弱”时，重点用其中“把多个动画编排成一段表现”：安排注意交接、同步与错开、前后搭接和动作轻重，再选动效；不把问题归结为缺方块或特效数量。

用户要求搜索 Opus/Astra 相关制作方法并实测时，读[公开动效方法与15秒检验](references/motion-transfer-field-test.md)：区分源码方法、作者示例和模型宣传，将锚点衔接、文字分时、运动轻重及转场中途检查补进现有分镜。学风格，按内容选载体；外部 Skill 的默认镜头数、审批和评分不自动移植。

用户2026-10-09确认的制作次序：**动作分镜先行 → 连续主体与镜头动作成立 → 补光效及声音层次 → 全片逐段对照已认可小样**。落实方法见上述参考的“从动作分镜到整片”小节；无配音先减字并让画面承担解释。该次序嵌入既有静帧→15秒→全片确认，不增加审批，不以静帧或文件检查替代动态验收。

可选风格 **黑金连续演化（`compound-motion`）**：适合增长、累积、分化和数量比较。用户选此风格、引用《复利》或要求类似强动态时，读[风格卡与动作模块](references/style-compound-motion.md)。它是有视觉证据的设计选项，尚非已实现并验收的通用组件；不作为所有视频默认，不复制原作角色、数据或音画。

金融行情解释可复用其中“已认可案例：纳斯达克v09连续行情主体”：同一真实曲线推进→镜头拉远→揭示后续→量出变化，文字只给动作命名。用户认可的是这段主体表现；黑金是可选审美，不是所有视频的固定模板，也不自动授权扩片。

分镜增加构图/镜头动机、动作阶段与阅读停留；同时列全片节奏图，检查中后段和相邻镜头是否重复。样例仍选中间最难的一段，不能只验漂亮开头。技术可播、截图好看或动效数量都不能代替连续观看和用户认可；不把此次Skill更新称为影片效果已达标。


先理解整篇文稿，以导演视角填写视觉编排表，明确每镜对应原文、A/B选择理由、起止与时长、动作阶段和双向承接，再进入素材与制作。A-roll/B-roll按主叙事与补充镜头理解；本片可进一步用情境、证据、解释、回扣分工，详见动态导演参考。分镜写叙事职责与切换理由，不机械AB交替，不因此增加主持人或旁白。
