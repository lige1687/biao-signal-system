# 多方案共同误差比较

当试了多个候选、只挑最好者时，偶然好看的结果会更容易出现。此工具在**已声明的候选集合**里共同检查预测误差，辅助研究者判断这种偶然性；不补齐未记录的历史尝试，也不把已看过的行情变成新资料。

## 使用归档预测

```bash
python3 .agents/skills/lei-quant-tools/scripts/multiple_comparison.py compare-workflows RUN_A RUN_B RUN_C --start 2025-01-02 --end 2025-12-02 --baseline B0 --block-size 20 --reps 1000 --seed 20261002
```

上面的日期和参数只是2026-10-02工程演示的固定配置，不是以后研究的默认科学设计。先在本轮合同中固定：问题/目标、完整候选列表与尝试史、来源资格、同一基准、日历和资产集合、权重、日期片段长度、次数与种子。既有信息模型为`B1`；较早训练历史平均为`B0`。简单对手须另并列，不能只比较一个较差的复杂模型。

读取各运行的`contract.json/preflight.json/result.json/receipt.json`，由原`workflow_bridge`核回执、文件指纹、执行登记及目标。所有候选的`asset/date/id/fold/y/label_end`和所选基准逐行完全相同，完整日期上资产集合相同，且只含一个拟合评价时期时才计算。缺日期、跨时期、资产或目标错位会返回`not_applicable`及退出码2；不取交集、压缩空档或填零。显式缩小区间需说明原因，后验区间只作历史辅助检查。

每天将同一组资产的误差平方取平均，然后对所有候选和基准同步抽取连续日期段。此时原等资产/等日期权重一致；其他权重和不完整资产集合未适配。归档指纹一致只证明读取了旧产物，不重新证明当前来源、源码、资格或科学设计。工具不会写入原目录或重新拟合。

## 直接输入已核好的每日误差

`compare-losses INPUT.json`支持`schema_version: lei-multiple-losses/1.0`。提供：

- `frequency: qualified_session`，完整、递增、不重复的`calendar`；
- `unit: percentage_point_squared`或`probability_squared`，全部方案使用同一单位；
- `benchmark_id`、唯一`candidate_ids`、`block_size/reps/seed`；
- 每个日历日恰有一行`{date, benchmark_loss, models}`，`models`键与全部候选精确对应，损失为非负有限数字。

直接输入只核结构，调用者仍负责日期、损失、资产汇总、来源与未来结果的真实性。程序要求至少3日、最多64候选、最多10,000次抽取，这是算术/资源边界，不是足够科学证据的标准，也不授予新增尝试预算。

## 计算范围与拒绝边界

采用固定arch8.0.0包中的8个Python支持模块，只有内部导入前缀改为`lei_arch_bootstrap`；算法和许可保持。全量软件、波动模型、编译模块和Numba未采用。完整指纹见`scripts/lei_arch_bootstrap/provenance.json`，许可见同目录`LICENSE.md`。

调用`SPA`类时固定`bootstrap=circular/studentize=False/nested=False`，仅输出`upper`：按各候选平均“旧误差减新误差”取最大值，与共同抽取、减去各自原均值后的最大值比较。不同大小误差的方差不会归一化；只支持同单位、同损失含义的比较。该版本的`studentize`参数没有按参数缩放统计量，本工具不声称已采用方差归一化的方法。

循环抽取会把区间末端与开端接起；需要该时期足够稳定且这种日期处理合理，工具不能自动证明。片段长度需考虑目标重叠和序列联系，不能把演示20日当通用正确值。

不同身份的完全同值候选、与基准恒定的差额、差额溢出及退化抽取分布均拒绝。后者包括“逐日有变化，但特定循环片段让每次汇总完全一样”的已复现反例；最终数值容差为32倍浮点精度乘差额尺度，只用于阻止不稳定算术结论。

`upper_pvalue`是给定抽取方法下的统计检查数字，不是因子有效概率。`simulation_resolution`为1/抽取次数；抽取1,000次出现0不能解释成现实错误概率为零。结果不证明投资收益、未来行情有效或生产采用；未通过也不代表所有其他用途无效。

## 已核证据

本轮21项初始合成检查、退化反例修补后22项回归；3组合成×1,000次与独立NumPy算式逐次一致。真实工程演示为已见的四ETF、2025-01-02至2025-12-02的888行/222日期、同基准三种tsfresh接法；完整2025—2026区间因缺尾日及跨拟合时期拒绝。两基准共同检查数值1.000/0.997与独立计算一致，旧负结果保持，0新增拟合。
